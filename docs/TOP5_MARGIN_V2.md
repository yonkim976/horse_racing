# Top5 착차 성능 보조모델 V2

상태: **연구용 challenger — 운영 모델 미교체, test 미평가**

## 결론

착차를 LambdaRank relevance로 직접 바꾸는 방식은 기각했다. 대신 기존 1~5착 순위학습은
그대로 유지하고, 과거 주파기록 차이를 예측하는 연속형 보조모델을 순위점수에 결합했다.
최근형 75%와 장기형 25%를 결합한 V2 challenger가 V1보다 확률분포 지표는 좋아졌고,
후보 5두의 실제 입상마 포괄력은 거의 유지했다.

평가 범위는 2026-03-01~2026-05-31의 669경주, 6,969두다. 2026-06-01 이후 test는
평가하지 않았다.

## 설계

기본 LambdaRank target은 `1착=5, 2착=4, 3착=3, 4착=2, 5착=1, 6착 이하=0`을
유지한다. 별도의 LightGBM Huber 회귀모델은 다음 값을 학습한다.

```text
착차 성능 = clip(100 × log(경주 중앙 주파시간 / 개별 주파시간), -10, 10)
최종 순위점수 = 기본 순위점수 + w × 경주 내 중심화·스케일된 착차 성능 예측값
```

- 최근형의 `w=1.50`, 장기형의 `w=1.25`는 calibration 구간의 ordered Top5
  Plackett–Luce NLL로 선택했다.
- `finish_time_ms`와 `margin_text`는 과거 학습 target·품질점검용 보조 컬럼이며 예측
  feature에는 들어가지 않는다. 따라서 예측 대상 경주의 결과를 참조하지 않는다.
- 예측 출력에 `rank_score_base`, `margin_performance_score`, `rank_score`를 함께 남겨
  보조신호의 승격·강등 효과를 추적할 수 있다.
- 과거 정상 결과 중 주파시간이 없는 8행은 착차 보조손실에서만 가중치 0으로 제외하고,
  순위학습에는 그대로 사용한다.

## 직접 착차 relevance 실험 기각

착차가 작은 말에 비슷한 0~10 relevance를 주는 방식은 순위 경계를 지나치게 흐렸다.

| 모델 | win LL | win AUC | Top1 | Top5 LL | RPS | 실제 순위 NLL |
|---|---:|---:|---:|---:|---:|---:|
| 동일 데이터 기본 순위 | 0.27243 | 0.7845 | 31.84% | 0.58446 | 0.15296 | 1.33354 |
| 직접 착차 relevance | 0.27680 | 0.7665 | 31.84% | 0.59490 | 0.15610 | 1.34690 |
| 연속 착차 보조 최근형 | **0.26992** | **0.7895** | 32.88% | **0.57660** | **0.15150** | **1.32433** |

따라서 `relevance_mode=margin`은 실험 재현용으로만 남기고 V2에는 사용하지 않는다.

## V1 대비 최종 결과

V2 challenger는 최근형 75%와 장기형 25%의 동일 확률 평균이다. Top1~Top5에 같은
가중치를 적용해 정확한 순위확률과 누적확률의 일관성을 보존한다.

| 지표 | Top5 Hybrid V1 | Margin V2 75:25 | 변화 |
|---|---:|---:|---:|
| win log loss | 0.27183 | **0.26976** | -0.00207 |
| win AUC | 0.7873 | **0.7916** | +0.0043 |
| Top1 적중 | **33.63%** | 32.88% | -0.75%p |
| 우승마 후보 3두 포함 | 66.07% | 66.07% | 0.00%p |
| 우승마 후보 5두 포함 | 83.41% | **84.16%** | +0.75%p |
| 실제 1·2위 모두 후보 5두 | 65.92% | **66.22%** | +0.30%p |
| 실제 1·2·3위 모두 후보 5두 | **41.55%** | 41.41% | -0.15%p |
| Top2 log loss | 0.41078 | **0.40842** | -0.00236 |
| Top3 log loss | 0.50641 | **0.50252** | -0.00388 |
| Top4 log loss | 0.56145 | **0.55477** | -0.00668 |
| Top5 log loss | 0.58330 | **0.57530** | -0.00799 |
| truncated Top5 RPS | 0.15287 | **0.15125** | -0.00162 |
| 실제 순위 버킷 NLL | 1.33248 | **1.32308** | -0.00941 |

경주 단위 bootstrap 5,000회에서 V2의 win log loss 차이(V2-V1)는 -0.00217이고
95% 구간은 -0.00337~-0.00088이었다. 우승마 후보 5두 포함률 차이는 +0.75%p
(-0.75~+2.24%p), 실제 1·2·3착 모두 후보 5두 포함률 차이는 -0.15%p
(-2.39~+2.09%p)였다.

확률 손실 개선은 일관되지만 후보 포괄력 차이는 표본오차 범위다. 또한 75:25 결합비율을
같은 valid에서 탐색했으므로 bootstrap 구간은 확정적 검정이 아니라 기술통계로만 본다.

## 해석과 사용 기준

- 정확한 우승확률·Top2~Top5 확률과 순위분포가 필요하면 V2 challenger가 우선이다.
- 한 경주의 Top1 한 마리만 반드시 맞히려는 목표에서는 V1이 0.75%p 높았다.
- 후보 5두 포괄력은 V2가 우승마와 1·2위에서 소폭 높고, 실제 1·2·3위 전체에서는
  V1과 사실상 같다.
- 아직 미래 test를 보지 않았으므로 운영 champion을 자동 교체하지 않는다. 다음 미사용
  기간에서 같은 지표와 구간별 안정성을 확인한 뒤 승격한다.
