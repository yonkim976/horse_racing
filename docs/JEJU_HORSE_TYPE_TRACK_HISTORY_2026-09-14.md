# 제주 말 분류와 경주로 변천 확인 (2026-09-14)

## 수집 범위 결정 (사용자 지시, 2026-09-14)

향후 **제주 과거자료 신규 수집·저장·모델 학습 범위는 마종이 공식 근거로 확인된 제주마 경주만** 포함한다. `한`(한라마)과 `래`(한라마(래))는 수집하지 않는다. 구형 등급 이름만으로 마종을 추측하지 않는다. 연도 단위 공식 API가 여러 마종을 함께 반환할 때는 메모리에서 명시적 `제` 구분만 통과시키고 `한`·`래` 원문 행은 저장하지 않는다. `제` 접두사가 없는 구형 행도 별도 원천에서 제주마임이 확인되면 포함할 수 있으며, 그렇지 않으면 격리한다. 기존 DB·원문을 이 결정만으로 삭제하지는 않으며, 이번 확인에서는 DB 적재·모델 학습을 하지 않았다.

## 제주마 경주 시작과 초기·최근 기록

혈통 등록 제주마의 **첫 경주는 2002-07-28 제주 4경주, 800m**다. 제주도의 당시 행정자료는 2002년 7월 등록마 첫 경마 시행을 기록한다. 공식 경주결과 API에서 날짜와 경주번호를 확인했고, 출전 8두 중 우승마 주파기록은 **66.5초(1:06.5)**였다. 제주경마 자체는 1990년에 시작했으나, 이를 2002년 등록 제주마 `제` 경주 개시일과 혼동하면 안 된다. [제주도 행정자료(제주도의회 보존본)](https://record.council.jeju.kr/CLRecords/Files/FileAppendix/a7/A000544.pdf), [KRA 경주결과 API 정보](https://www.data.go.kr/data/15089492/openapi.do), [공식 원문 비교 감사](../data/logs/jeju_native_era_times_20260914.json)

같은 **800m 경주의 우승마 주파기록**만 비교했다. 초기 연도는 공식 API의 등급 코드가 명시적으로 `제`로 시작하는 경주, 최근 기준은 마지막 완결 연도인 2023~2025년이다. 기록이 없는 경주는 평균·중앙값에서 제외했다.

첫해 2002년 중앙값과 최근 3년 중앙값을 비교하면 최근이 **0.75초 느리다**. 반대로 초기 4년을 합치면 최근이 **4.45초 빠르다**. 비교 기준을 어떻게 잡느냐에 따라 부호가 바뀌는 이유는 2002년이 단 6경주이고, 2003~2005년 제주마 경주가 빠르게 확대되며 기록 분포가 달라졌기 때문이다. 같은 달(7~12월)로 제한해도 최근 157경주 중앙값은 66.4초이며 2002년 6경주와의 차이는 +0.95초다. **이 수치만으로 제주마가 빨라졌거나 느려졌다고 결론낼 수 없다.** 당시 `제1`과 현재 `제6등급`은 같은 경쟁수준으로 볼 근거가 없고, 마필·상대 집합, 부담중량, 주로 상태, 기후, 관리·훈련 방식이 다르다. 원문 첫 경주의 `track` 값은 `불량 (0%)`로 기록되어 있어, 0%를 실제 주로 함수율로 해석하지 않았다.

이번 감사에서는 엄격하게 등급 코드가 `제`로 시작하는 경주만 비교했다. 기존의 느슨한 분류 감사가 센 제주마 경주 수(2003년 13, 2004년 55, 2005년 89)와 이번 수(12, 53, 88)는 일부 다르다. 구분 코드가 비어 있는 행을 제주마로 추정하지 않았기 때문이다. 초기 2002~2005 공식 응답 SHA-256은 [기존 감사](../data/logs/historical_jeju_native_early_20260914.json)와 모두 일치한다. 기록이 비어 있는 경주 키는 [감사 JSON](../data/logs/jeju_native_era_times_20260914.json)의 `missing_winning_time_races`에 남겼다. [재현 스크립트](../scripts/audit_jeju_native_era_times.py)는 `한`·`래` 행을 저장하지 않는다. 2026년의 800m 경주는 현재 로컬 DB에 3개뿐이어서 최근 대표 비교에서는 제외했다.

최근 기록의 독립 대조로 2024~2025년 공식 API `제` 800m 175경주의 우승기록을 로컬 DB와 경주 키로 결합했다. **공통 175/175, 누락·추가 0, 주파기록 차이 0초**였다. 2023년은 공식 API 127경주 중 로컬 DB가 123경주여서 최근 기준 계산에는 API 쪽 127경주를 사용했다. 이는 2024~2025년 해당 800m 부분의 일치만 확인한 것이며 전체 DB 완전성 보증은 아니다.

## 결론

`한`·`래`·`제`는 한국마사회 제주 성적 화면의 경주 구분 약자이며, 각각 **한라마**, **한라마(래)**, **제주마**다. 한라마는 제주마와 외산마의 교잡 계열로, 등록 제주마와 같은 혈통 모집단이 아니다. `래`는 공식 성적 화면에 한라마(래)로 표기된 과거의 세부 경주 범주이다. 이것을 제주마와 다른 세 번째 독립 품종이라고 단정하지 않는다. `래`의 당시 출전자격을 정한 원문 조항은 이번 조사에서 확보하지 못했다. [KRA 경주성적 화면](https://m.kra.co.kr/race/jeju/recordKindsDetail.do), [국립축산과학원 한라마 설명](https://www.nias.go.kr/front/qaBoardView.do?boardSeqNum=112&cmCode=M120927150325063)

기존 공식 API 감사에서 2000년 제주 903경주 중 `한` 648, `래` 255, `제` 0이었다. 확인된 첫 `제` 경주는 2002-07-28의 800m 경주이고, 2023년 조사한 715경주는 모두 `제` 코드다. 국립축산과학원도 2023년 제주마 경주의 전면 시행을 설명한다. [2000년 집계](../data/logs/historical_course_first_era_20260914.json), [제주 초기 제주마 경주](../data/logs/historical_jeju_native_early_20260914.json), [전환기 집계](../data/logs/historical_race_regime_transitions_20260914.json)

## 예측모델에 주는 의미

`한`/`래`를 현재 제주마 경주의 승부 라벨과 그대로 섞지 않는다. 제주마 `제` 경주도 2002년부터 무조건 동일한 실험 조건이었다고 보지 않는다. **마종, 거리, 시행 연도**를 분리하고, 2019년 배수공사 전후의 원시 주파기록을 직접 같은 기준으로 비교하지 않는다. 배수공사가 실제 속도를 얼마나 바꾸었는지는 별도 자료와 검증이 필요하다. 경주 내 상대 성적이나 거리·날짜·주로상태 보정값으로 과거 제주마 경주를 추가했을 때 현재 예측 손실이 개선되는지는 독립된 시간순 비교로 판정한다.
