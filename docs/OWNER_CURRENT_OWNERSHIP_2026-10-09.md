- `/owners`의 누적 등록두수 표시를 공식 API309 `ownerHorses` 기반 **현소유두수**로 변경했다. 우리 DB의 `Horse.is_active`를 이용한 추정 집계로 대체하지 않는다.
- 기존 `totHorses`는 `total_registered_horses`로 계속 보존하고, `current_owned_horses`를 별도로 저장한다. 새 수집에서는 누락·음수·소수·누적 등록두수보다 큰 값을 거부한다.
- 과거 수집본은 현소유두수를 구조화해서 저장하지 않았으므로 새 컬럼을 nullable로 추가했다. 과거 값을 0이나 누적 등록두수로 채우지 않는다. 이전 실행 21711의 1,049행은 원래 관측을 유지하며 현소유 값은 null이다.
- 현소유두수만 변한 경우에도 새 전체 스냅샷을 추가하도록 수집 재실행 비교 기준에 포함했다. 동일 데이터 재실행의 중복 방지 및 공식 번호로만 연결하는 방식은 유지한다.

## 화면·검증

- 전체 목록은 최신 완료 전체 수집본의 동일 마주 ID별 지역 현소유 합계를 `총소유두수`로 표시한다. 지역별 화면은 해당 지역의 `현소유두수`만 표시한다. 숫자에 마우스를 올리면 지역별 내역을 확인할 수 있다. 일부 지역 값이 미확인이면 합계도 미확인으로 남긴다.
- 기본 정렬은 전체·지역별 모두 소유두수 내림차순이다. 헤더 클릭으로 `sort=owned`(많은 순)와 `sort=owned_asc`(적은 순)를 전환하며, 전체 대상 정렬 후 페이지를 나눈다. 검색어·지역·전적 기간은 보존하고 첫 페이지로 이동한다. 기존 `sort=registered`도 `owned`로 해석한다.
- 검색하지 않은 기본 목록은 소유두수가 확인되는 1두 이상 마주만 표시한다. 0두·미확인·과거 마주는 이름/마주번호 검색으로 찾는다. 지역 화면에서는 해당 지역의 소유두수로 판단한다. 공백만 입력한 경우 검색으로 취급하지 않는다.
