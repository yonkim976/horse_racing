# 마필로그 광고 도입과 수익 지급 안내

작성 기준일: 2026년 10월 12일

마필로그는 기록 표의 가독성을 유지하면서 주요 표 아래에 수동 광고 한 자리를 배치하는 방식으로 시작한다. 충분히 넓은 데스크톱 화면의 오른쪽 광고와 하단 고정 광고는 운영 결과를 보고 검토한다. 모든 페이지의 좌우를 지금부터 비워둘 필요는 없다.

이 문서는 추후 도입을 위한 계획이다. 이번 작업은 문서 저장이며 광고 코드 설치나 배포를 포함하지 않는다. Google 정책과 지급 조건은 실제 도입 시 다시 확인한다.

## 현재 레이아웃과 광고 위치

현재 데스크톱 공통 콘텐츠는 가운데 정렬되며 최대 폭이 1,520px이다. 일반 화면에서는 좌우 여백이 약 24px이고, 좁은 화면에서는 약 14px이므로 노트북에서 콘텐츠가 화면 대부분을 차지해 보인다. 관련 설정은 `src/horse_racing/web/static/css/dashboard.css`에 있다.

글 중심의 페이지는 좁은 본문과 사이드바를 쓰기 쉽지만, 마필로그의 분석·전적 화면은 여러 컬럼을 비교해야 하므로 넓은 표를 유지하는 편이 적합하다. 아래 수치는 마필로그의 설계 제안이며 광고 플랫폼의 필수 규격이 아니다.

| 페이지와 화면 | 초기 배치안 | 추후 확장 |
|---|---|---|
| 데스크톱 경주 분석·전적 | 주요 표 아래 또는 큰 섹션 사이에 반응형 광고 1개 | 표의 가독성이 유지되는 넓은 화면에서 오른쪽 광고 검토 |
| 말·기수·조교사·마주 기본정보 | 본문을 필요에 따라 최대 1,200~1,280px 정도로 정리하고 섹션 아래 광고 | 화면 폭이 충분할 때 약 300px 사이드 영역 검토 |
| 모바일 | 카드 묶음이나 섹션 아래에 반응형 광고 | 이용 흐름을 확인한 뒤 위치 조정 |
| 화면 하단 고정 광고 | 초기에는 사용하지 않음 | 의견 남기기 버튼과 하단 조작 영역의 겹침을 해결한 뒤 검토 |

사이드 광고는 화면 폭에서 본문·광고·간격·외곽 여백을 모두 확보할 수 있을 때만 표시한다. 좁은 화면에서는 사이드 영역을 없애고 본문 아래에 배치한다. 좌우 양쪽 광고를 기본으로 두지는 않는다.

광고를 활성화한 자리에는 화면 크기에 맞는 높이를 미리 확보한다. 광고가 늦게 로딩되어 표나 버튼이 갑자기 밀리는 현상을 줄이기 위해서다. 광고를 끈 상태에서는 전체 페이지에 빈 광고 여백을 상시 유지하지 않는다. [레이아웃 이동 방지 안내](https://web.dev/articles/optimize-cls/)

## 광고 연결 방식

Google AdSense에는 Google이 위치를 정하는 자동 광고와 사이트에서 위치를 정하는 수동 광고 단위가 있다. 마필로그는 표·탭·영상 버튼이 많으므로 초기에는 수동 광고 단위를 사용해 위치를 관리한다. 앵커 광고 등 일부 형식은 자동 광고 설정에서 다룬다. [광고 설정 방식](https://support.google.com/adsense/answer/7037624?hl=ko)

현재의 GA4·Google 태그 관리자는 방문 통계 수집을 위한 연결이다. AdSense 계정·사이트 심사·광고 단위는 별도로 설정해야 하며, 방문 통계 설치만으로 광고 수익이 발생하지 않는다.

도입 순서는 다음과 같다.

1. AdSense 계정을 준비하고 `mapilog.xyz`를 사이트로 등록한다.
2. 계정에서 안내하는 방법으로 소유권을 확인하고 사이트 심사를 요청한다. 사이트 접근성, 콘텐츠와 탐색 기능, 정책 준수 등이 심사에 영향을 주며 승인이 보장되는 것은 아니다. [사이트 심사 안내](https://support.google.com/adsense/answer/12176698?hl=en-GB)
3. AdSense에서 발급한 광고 코드를 데스크톱·모바일 공통 템플릿에 연결하고, 선택한 위치에 광고 단위를 배치한다. 게시자 ID와 광고 단위 ID는 계정에서 받은 실제 값을 사용한다. [광고 코드 설치 안내](https://support.google.com/adsense/answer/9274019?hl=en-GB)
4. 계정에서 제공하는 판매자 정보를 `https://mapilog.xyz/ads.txt`로 제공한다. `ads.txt`에는 광고 코드의 `ca-pub-…`가 아닌 게시자 ID인 `pub-…`를 사용한다. [ads.txt 안내](https://support.google.com/adsense/answer/12171612?hl=en-EN)
5. 광고 처리에 맞춰 개인정보 안내와 필요한 동의 설정을 검토하고, 화면·성능 검증 후 배포한다.

## 구현 시 확인할 부분

현재 웹의 보안 헤더는 GTM·GA4용 외부 도메인을 허용하도록 설정되어 있다. 광고 도입 시에는 실제 광고 요청에 필요한 CSP 허용 목록을 확인하고 최소한으로 추가해야 한다. 태그 관리자 설치가 광고 리소스까지 자동으로 허용하는 것은 아니다.

| 확인 대상 | 적용 기준 |
|---|---|
| 공통 템플릿 | 데스크톱과 모바일에 광고 로더를 중복 없이 연결 |
| 광고 영역 | 표 헤더·정렬·탭·영상 링크 등 조작 요소와 분리 |
| 의견 남기기 | 데스크톱 우측 하단 버튼, 모바일 하단 버튼과 겹치지 않도록 배치 |
| 초기 로딩 | 광고를 비동기로 로딩하고 본문 표시가 지연되지 않는지 확인 |
| 화면 안정성 | 광고 로딩 전후 표 위치가 갑자기 이동하지 않는지 확인 |
| 비활성화 | 광고 설정을 끄면 광고 요청과 불필요한 빈 영역도 제거 |
| 운영 확인 | AdSense의 광고 노출·수익과 GA4의 페이지 조회·이용 흐름을 함께 확인 |

관련 구현 위치는 `src/horse_racing/web/app.py`, `src/horse_racing/web/templates/base.html`, `src/horse_racing/web/templates/mobile/base.html`, `src/horse_racing/web/static/css/feedback.css`다. 실제 수정 전 최신 구조를 다시 확인한다.

## 수익 발생과 단가

AdSense 콘텐츠 광고는 광고주 입찰을 반영한 노출 기준인 eCPM 방식으로 게시자에게 지급한다. 광고 클릭이 있어야만 수익이 발생하는 구조는 아니다. [Google 수익 배분 안내](https://support.google.com/adsense/answer/180195)

고정된 클릭당 금액이나 방문자당 금액은 없다. 수익은 트래픽, 콘텐츠 종류, 방문자 국가, 광고 설정 등에 따라 달라진다. 마필로그의 실제 단가는 광고를 운영한 뒤 확인한다. [수익 결정 요인](https://support.google.com/adsense/answer/9902?hl=ko)

운영비와 비교할 때는 페이지 RPM을 사용하면 편하다. 페이지 RPM은 페이지 조회 1,000회당 예상 수익을 나타내는 계산 지표이며, 고정 지급 단가가 아니다. 광고 노출 1,000회당 지표인 광고 RPM과 구분한다. [페이지 RPM](https://support.google.com/adsense/answer/112030?hl=en), [광고 RPM](https://support.google.com/adsense/answer/112032?hl=en-EN)

`예상 수익 = 페이지 조회 수 ÷ 1,000 × 페이지 RPM`

아래 금액은 계산법을 설명하기 위한 가정이다. 한국 사이트의 평균 단가나 마필로그의 예상 실적을 뜻하지 않는다.

| 가정한 페이지 RPM | 월 10만 페이지 조회 시 예상 수익 |
|---|---:|
| 1,000원 | 100,000원 |
| 3,000원 | 300,000원 |
| 5,000원 | 500,000원 |

방문자 수와 페이지 조회 수는 다르다. 한 사람이 여러 페이지를 열면 방문자 한 명이 여러 조회를 만들 수 있다. GA4 조회 수와 AdSense의 측정값이 항상 같다고 가정하지 말고 실제 수익 계산에는 AdSense 보고서의 지표를 사용한다.

## 수익금 수령

AdSense에서 필요한 본인·주소 확인과 요청되는 지급 정보를 완료하고 은행 계좌를 등록한다. 한국은 해외 은행 송금 방식의 지급을 지원하며 계좌 정보는 은행에 등록된 정보와 일치하도록 입력한다. 실제 수령액에 영향을 주는 송금 수수료·환전 조건은 이용 은행에 확인한다. [은행 송금 안내](https://support.google.com/adsense/answer/3372975?hl=ko)

USD 지급 계정의 기본 지급 기준은 누적 100달러다. 기준에 미달하면 잔액이 다음 달로 이월된다. 지급 기준은 계정 통화와 설정에 따라 확인한다. [지급 기준 안내](https://support.google.com/adsense/answer/1709871?hl=ko)

월말까지 지급 기준을 충족하고 지급 보류가 없으면 다음 달 21~26일에 지급 절차가 진행된다. 이 날짜는 은행 계좌의 입금 완료일과 다르며 은행 처리 시간이 추가될 수 있다. 예를 들어 10월 말까지 기준을 충족하고 필요한 확인이 끝나면 11월 21~26일 지급 대상이 된다. [지급 절차 안내](https://support.google.com/adsense/answer/1709858?hl=ko)

## 단계별 도입안

1. **준비:** AdSense 계정과 사이트 심사를 진행하고, 광고를 넣을 주요 표 아래 위치 한 곳을 정한다.
2. **초기 운영:** 데스크톱·모바일에서 수동 광고를 적용하고 화면 겹침, 로딩과 콘텐츠 이동을 확인한다.
3. **실적 확인:** 몇 주간 실제 페이지 RPM·수익·페이지 조회·이용 흐름을 확인하고 월 운영비와 비교한다.
4. **확장 판단:** 이용에 불편이 적고 효과가 있을 때만 넓은 화면의 오른쪽 광고나 추가 위치를 검토한다.

초기 목표는 광고 수를 늘리는 것보다 마필로그의 실제 수익성을 확인하는 것이다. 분석 표의 가독성과 탐색 흐름을 유지하는 범위에서 배치를 조정한다.
