# RaceFit V4 게이트·초반속도 전개 모델

## 목적

출발 게이트를 최종 착순의 고정 가산점으로 사용하지 않고, 게이트가 S1F 초반 속도와 선행권 확보에 미치는 조건부 효과로 모델링한다.

## 구현

1. 각 경주의 S1F 시간을 경주 내 중앙값 대비 로그 상대속도로 변환한다.
2. 대상 경주일 이전 3년만 사용해 경마장×정확거리×출전두수군×게이트 구역의 초반속도 효과를 계산한다.
3. 표본이 적은 세부 셀은 정확거리와 경마장 부모 효과로 계층 수축한다.
4. 1단계 모델이 예상 S1F 위치를 예측한다.
5. 동일한 말을 중간 게이트에 배치한 반사실 예측과 실제 게이트 예측의 차이를 계산한다.
6. 외곽 선행 비용, 내측 추입 막힘 위험, 예상 선행 경쟁을 2단계 LambdaRank에 전달한다.

게이트 효과는 공식 `gate_number`를 사용하며 결측일 때만 출전번호로 대체한다. 동일 날짜의 결과는 그 날짜의 feature를 모두 출력한 뒤에만 이력에 반영한다.

## 2026 시간순 검증

2025년 데이터로 학습하고 2026년 1,624경주를 평가했다. 비교 기준은 RaceFit V3 우승·축마 모델이다.

| 지표 | RaceFit V3 | V4 게이트 전개 | 변화 |
|---|---:|---:|---:|
| 우승 Log Loss | 0.27199 | 0.27223 | +0.00024 |
| 우승 AUC | 0.77964 | 0.78080 | +0.00116 |
| Top1 적중률 | 32.64% | 31.83% | -0.80%p |
| 우승마 Top3 포함 | 64.78% | 65.64% | +0.86%p |
| 우승마 후보 5두 포함 | 83.50% | 83.00% | -0.49%p |
| 실제 1·2위 모두 후보 5두 포함 | 61.33% | 62.87% | +1.54%p |
| 실제 1·2·3위 모두 후보 5두 포함 | 37.99% | 38.73% | +0.74%p |

실제 1·2위가 후보 5두에 함께 포함되는 비율의 paired race bootstrap 95% 구간은 `0.00%p ~ +3.08%p`였다. 반면 Top1 변화 구간은 0을 포함해 축마 모델 교체 근거는 부족하다.

게이트 초반속도 변수를 일반 순위 모델에 직접 넣는 방식은 Log Loss 0.27480, Top1 32.08%로 악화됐다. 전개 2단계 안에서만 사용하는 편이 적합하다. 같은 2단계 구조끼리 비교하면 기존 전개 모델 대비 Log Loss는 0.27470→0.27223, AUC는 0.77619→0.78080, Top3는 64.90%→65.64%로 개선됐다.

## 결정

- RaceFit V3를 우승·축마 기본 모델로 유지한다.
- V4는 복승·복연승 및 삼연승 후보군의 보조 전개 모델로 보존한다.
- `racefit_v1_core`에서는 게이트 초반속도 실험 변수를 제외한다.
- 전용 `racefit_v4_gate_pace` 프로필에서만 변수를 허용해 일반 모델로 잘못 확산되는 것을 막는다.
- 2027년 신규 미래 구간에서 1·2위 후보 5두 포함 개선이 재현되면 후보군 앙상블 승격을 검토한다.
