# KRA 질병 용어·설명 대조 현황 · 2026-10-01 기준

이 문서는 질병명 대조 작업의 현재 인수인계 요약이다. 수집 근거와 행 단위 판정은 링크된 연구 산출물에 보관한다. 문서 보존·정리 기준은 [문서 등록부](KRA_DISEASE_GLOSSARY_DOCUMENT_REGISTER_2026-10-01.md)를 참고한다.

2026-10-02 사용자 결정: **질병 설명의 운영 DB 적재와 웹 화면 연결은 보류한다.** 기존 진료 원문, 문구 대응 판정, 설명 수집물과 출처는 보존한다. 아래 수집 순서와 운영 연결 제안은 재개 시 참고용이며 현재 실행 지시가 아니다. [보류 결정과 독립 검증](MEDICAL_GLOSSARY_HANDOFF_REVIEW_2026-10-02.md)을 참고한다. 이 결정으로 기존 집계나 연구 판정을 변경하지 않았다.

## 현재 결론

- 운영 로컬 DB와 Supabase에서 대조한 고유 진료 원문은 동일한 **5,397개**, 최신 사용 빈도 합계는 **677,219건**이다. 이전 검토표보다 기존 문구 사용량만 1,172건 증가했고 새 문구는 없었다.
- 연구 검토에서 질병 표제 또는 구성요소 대응이 닫힌 것은 **5,392개 문구·677,174건**이다. 나머지 5개 문구·45건은 사용자 지시 또는 화면 근거에 따라 연결 후보에서 제외했다. 운영 원문은 삭제하거나 수정하지 않았다.
- API33은 표제 대조에 사용했다. 수집된 3,523행의 `illDesc`는 **전부 `-`**여서 API33 자체에서 설명 문장을 연결할 수 없다.
- KRA 공식 프로필 진료명 상세 화면에서 설명을 추가 수집해 2026-10-01 기준 설명 상태를 갱신했다. 모든 대응 구성요소에 설명이 있는 문구는 1,141개·531,777건, 일부 구성에 설명이 있는 문구는 1,812개·5,592건, 대응 표제는 있지만 설명이 없는 문구는 2,439개·139,805건이다. 제외/비대상은 5개·45건이다.
- 연구용 용어 대응과 설명 출처 연결만 갱신했다. 운영 로컬 DB, Supabase, 운영 진료 원문, 예측 모델에는 설명을 쓰거나 연결하지 않았다.

## API33 사전과 중복 정리

공공데이터포털 [마필 질병 정보 API33](https://www.data.go.kr/data/15036577/openapi.do)의 전체 응답을 2026-09-30에 수집했다. API `totalCount` 3,523과 페이지별 합계 1,000+1,000+1,000+523이 일치한다. 영문명 빈 값은 98행이고 `illDesc` 빈 값은 0행이며 `-`가 3,523행이다.

동일한 한글명·영문명·설명이 모두 같은 반복행 12개는 파생 사전에서만 제외했다. 원본 JSON과 페이지 XML은 그대로 보존했다. 파생 사전은 3,511행·고유 한글명 3,500개이며, 영문명 등 다른 필드가 다른 동일 한글명 그룹 10개(추가 11행)는 유지했다. [중복 감사 보고서](../data/research/kra_disease_glossary_api33_20260930/exact_deduplication_report.md)와 행별 목록을 참고한다.

기존 KRA 공식 공개 질병용어 화면은 50개 항목이다. API33과 대조해 한글명 완전 일치 15개, 공백 정규화 후 일치 16개, 설명 완전 일치 0개를 확인했다. 화면 사전 표제 35개는 API33에서 찾지 못했다. 웹 화면 설명과 API33 `illDesc`는 서로 다른 출처로 관리한다.

## 프로필 설명 추가 수집

2026-10-01 KRA 프로필 10마리(서울 7, 부산경남 2, 제주 1)의 진료행 288개를 확인했다. 한글명·영문명·설명 조합 38개를 보존했으며, 38개 한글 표제는 API33과 완전 일치하고 37개는 영문명도 일치한다. `교돌상`은 API33 영문명 필드가 비어 있다. 과거 KRA 프로필 설명 원문과 비교해 신규 설명 34개를 추가 확보했고, 프로필 상세 설명 출처 표제는 33개에서 67개로 늘었다. 대지초이스에서 좌·우 각막찰과상과 진드기성외이염 등을 확인했고, 새내힐에서 좌·우 전지 교돌상과 건강검진 설명을 추가했다. 건강검진 설명은 보험 목적의 행정성 항목이다. 원문·출처·수집 시각·해시는 상세 보고서와 매니페스트에 보존했다.

현재 설명 커버리지는 모든 구성 설명 있음 1,141개 문구·531,777건, 일부 설명 있음 1,812개·5,592건, 표제는 있지만 설명 없음 2,439개·139,805건이며, 제외/비대상 5개·45건이다. 최신 전체 합계는 5,397개 문구·677,219건이다. 프로필 설명 추가 수집과 최신 사용 횟수는 연구 대조표에만 반영했다.

2026-10-01 DB 재대조에서 고유 문구는 직전 목록과 완전히 같고, 기존 문구 117개의 사용량이 증가해 총 1,172건 늘었다. 최신 진료일은 2026-09-30이며, 로컬과 Supabase는 전체 문구별 빈도 해시 및 전체 이력 277개월의 진료 원문 해시가 일치했다. [DB 갱신 대조 보고서](../data/research/kra_disease_glossary_api33_20260930/profile_hover_expansion_20261001/db_refresh_comparison_20261001.md)에 근거와 스냅샷을 남겼다.

현재 설명 상태와 변경량, 수집 원문·출처·시각·해시는 [추가 수집 보고서](../data/research/kra_disease_glossary_api33_20260930/profile_hover_expansion_20261001/coverage_report_20261001.md)에 있다. KRA 프로필의 동일 진료행에서 얻은 설명을 저장했으며 API33 설명이라고 표기하지 않았다.

## 다음 설명 수집 순서

1. 설명이 없는 표제 중 운영 고유 문구 사용 빈도가 높은 항목부터 대표 말·경마장·날짜를 읽기 전용 DB에서 찾는다.
2. KRA 프로필의 같은 말·meet·날짜 진료행에서 한글명·영문명·설명을 확인한다. 다른 날짜 설명이나 부분 문자열은 대체 근거로 쓰지 않는다.
3. 표제+영문명+설명 원문, 근거 행, 출처 URL, 수집 시각, 해시를 연구 폴더에 남긴다.
4. 누적 설명은 연구 검토표에서만 연결하고, 빈 설명은 빈 상태로 둔다. 전체 공식 설명이 필요하면 한국마사회에 API33 필드 갱신 여부와 공식 용어집 제공 가능성을 문의할 수 있다.
