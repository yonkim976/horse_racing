# 연도별 재검증·확정배당 회수율 실행 계획

실행 전 고정. 결과 종료일2026-09-12. 새 미래자료를 요구하지 않고 기존 자료만 사용한다.

## 연도 비교

- 2024·2025년을 추가 평가하고 기존2026년 결과를 함께 보고한다.
- 각 평가연도Y는 FIT2018-08-31~Y−1년6월말, TUNE Y−1년7~9월, CAL Y−1년10~12월, EVAL Y년 전체(2026은9월12일까지)로 분리한다. 각 경주의 과거 상태는T−2까지 순차 갱신한다.
- 같은108개 HY_R_FORM 순위 입력과68개 순서 입력·기존 설정·시드17/43를 사용한다. 2024/2025에는 해당 연도 이전 자료로 각각 재학습한다. 2026년 모델을 과거 연도에 적용하지 않는다.
- 2024는 기준+PACE_BURDEN을 비교한다. 심판 자료가2024부터라2023까지의 FIT/TUNE/CAL에 심판 사건이 없어 STEWARD 학습 평가는 부적격으로 명시한다.
- 2025는 기준+STEWARD+PACE_BURDEN을 비교한다. 추가 순위10회·순서4회=14회 학습. 기존2026년 후보는 재학습하지 않는다.
- A/B/C 연도별 성적·분기·자료coverage·시드별 학습상태를 보고한다. 주 비교는2024 1후보×3목표 +2025 2후보×3목표=9개, 경기일bootstrap5000·Bonferroni9.
- 기존2025년 분기별 재학습 결과와 이번 연1회 고정학습은 다른 프로토콜이므로 동일 결과로 합치지 않는다. 이미 여러 분석에 사용한 자료로서 미사용 독립검증이라고 부르지 않는다.

## 승식·확률차이·회수율

- 연도별 기준모델만으로 7승식 최상위1선택, 삼복승 전체/축고정 상위1·3·6·10조합, 최상위 복승조합을 양방향 쌍승2조합으로 나눈 정책을 고정한다. 배당을 보고 선택하거나 나쁜 배당 경주를 제외하지 않는다.
- 3/4순위 확률차이 구간은 기존0~2,2~5,5~10,10%p 이상 유지. 연도별 실제 차이와불확실성을 보고한다.
- 총예산은 매경주 가상1단위, K조합에1/K 균등 배분. 세전 총회수율=실제 확정배당 지급합/총투입. 원금포함, 수익률=회수율−100%. 확정배당에 이미 반영된 시행 공제를 다시 빼지 않는다.
- 거래·입금·실제 구매 없음. 세금·최소구매단위·반올림·배당에 미치는 자기투표 영향은 미반영한 연구용 세전 정산이다.
- 동착·3착경계 동착은 정산 초기범위에서 제외한다. 실제 출전마 기준이며 사전 취소·환불을 포함한 운영수익률이 아니다. 제외 사유와건수를 공개한다.
- 원천 배당은 결과문서 또는 확정배당 API 캐시/DB에서 말번호·경주일·경주번호·승식별로 연결하고, 필요한 적중배당의 공백·충돌을 확인한다. 배당 미확인을0으로 대체하지 않는다. 자료가 없는 연도/승식은 미평가로 표시한다.
- 정책 고정과 예측 저장을 먼저 완료하고 이후 배당 정산을 시행한다. 출발 전 가격을 사용한 가치선택 전략 성과라고 주장하지 않는다.
- 경기일bootstrap5000으로 회수율 불확실성, 연도/분기, 고배당 상위3경주 기여 및 이를 제외한 민감도를 보고한다. 최고 회수율 셀을 보고 추천정책을 새로 고르지 않는다.
