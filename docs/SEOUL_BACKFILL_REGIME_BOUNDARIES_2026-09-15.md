# 서울 2000년 이후 백필: 레이팅·주로·1600m 경계

작성일: 2026-09-15. 대상은 서울경마장 `meet=1`이다. 이 문서는 **원문 보존 시작점**과 서로 다른 제도의 경주를 비교할 때 필요한 경계를 기록한다. 경계가 예측력에 미치는 영향은 아직 실험하지 않았다.

## 확인된 사실과 근거

[KRA 경주로 구조](https://race.kra.co.kr/chulmainfo/RacingcourseStructure.do?Act=02&Sub=11&meet=1). 모래 보충·교체, 살수, 함수율, 배수 보수는 경주일별 기록에 영향을 줄 수 있으나 모든 관리 작업을 새로운 영구 경주로로 취급하지 않는다. 예를 들어 KRA의 2026-09-13 현황에는 2026-09-08 내주로 전 구간 모래 교체가 기록돼 있다. [KRA 주로 현황](https://race.kra.co.kr/chulmainfo/trackView.do?Act=02&Sub=10&meet=1).

## 백필 범위와 데이터 경계

- 서울 공식 말별 경주결과 API는 2000-01-08부터 양성이다. 2000년은 1,114경주·12,519행, 2004년은 1,110경주·11,734행으로 기존 연도별 API 감사에 기록돼 있다. 이는 응답 집계이지 모든 말 ID·구간기록의 전수 연결 승인이나 전체 시행경주 완전성 증명은 아니다. [과거 결과 감사](PRE2015_RACE_RESULT_AVAILABILITY_2026-09-14.md), [감사 JSON](../data/logs/pre2015_race_result_availability_20260914.json).
- 일별 조교 API는 1998-09-25부터 양성으로 2000년 경주의 과거 이력에 쓴다. 체중 Text의 첫 파일은 2003-09-06, 진료 Text의 첫 파일은 2003-09-25, 출발조교 API는 2009-05-21부터 양성이다. 첫 파일일은 개별 사건일·당시 게시일과 다르며, 원천 시작 전 결측은 `사건 0건`으로 치환하지 않는다. [원천 수집 감사](HISTORICAL_SOURCE_COLLECTION_2026-09-14.md), [경마장별 시작 범위](OLDEST_MODEL_DATA_BY_MEET_2026-09-14.md).
- 2000~2014년 결과는 연도별 조회·집계됐지만 현재 정규화 DB에 전수 적재된 상태가 아니다. 서울 2000년부터 최신 **공식 확정 경주**까지 원문을 봉인하고 경주·말 행을 실제로 구축해야 한다. 이미 저장된 2015년 이후 DB와는 공식 원문 키로 대조한다.

## 정규화·분석 계약

1. 모든 원문값을 보존한다. `rating_system`은 `pre_rating / rating / transition_unverified`, `surface_regime`은 `pre_2016_aug / surface_transition_or_unknown / post_2016_aug`, `mile_1600_era`는 `not_operated / operated` 등을 **근거가 확인된 경주에만** 부여한다. 전환일은 검증 전 임의로 하루로 고정하지 않는다.
2. 레이팅 이전의 군/등급 숫자와 레이팅 이후 등급 숫자·점수를 동일 척도로 직접 비교하지 않는다. 원문 `grade`, `burden_type`, `rating`, 부담중량 및 경주조건을 각각 유지한다.
3. 기록 비교는 서울×정확한 거리×경주 당시 주로 상태/함수율×시대별로 나눈다. 2016년 모래 변경 전후의 절대 주파시간을 한 기준속도로 섞지 않는다. 서울 1600m의 과거 같은 거리 표본은 2019-08-25 이전에 만들지 않는다.
4. 서울 API 구간시간과 과거 `dacom11` Text의 `G3F/G1F`는 누적시간과 종반 주파시간으로 의미가 다를 수 있다. 원천 provenance를 확인한 뒤 변환하며, 원문 구간값을 같은 열에 무조건 병합하지 않는다. [서울 구간 감사](SEOUL_SECTION_AUDIT_2026-09-08.md), [canonical 연구](CANONICAL_SECTION_RESEARCH_2026-09-11.md).
5. 경주 결과·사후 심판보고서는 해당 경주의 예측 입력이 아니다. 이전 경주의 확정 결과 이력으로만 연결한다. 2000년 자료를 모두 보존하되 학습에 어느 연도를 투입할지는 최신 기간을 남긴 시간순 성능 비교로 정한다.

## 남은 확인 항목

- 2015년 서울 레이팅제의 첫 **경주별 적용일**과 전환 주간의 예외 조건.
- 2016년 모래 두께 작업의 KRA 원문 공지·실제 경주별 적용 경로 및 작업 전후의 기록 변화.
- 2019년 1600m 첫 시행일을 공식 경주결과 원문과 DB 행으로 교차확인하고, 공사가 다른 거리의 코스까지 바꿨는지 확인.

이 미확정 사항은 전체 결과 수집을 중단할 이유가 아니다. 해당 행의 시대 분류만 미확정으로 남겨 검증된 핵심 결과·이력을 먼저 구축한다.
