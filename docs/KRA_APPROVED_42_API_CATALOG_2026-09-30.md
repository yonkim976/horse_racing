## 자주 혼동하는 API

- **예정 경주:** `#3 경주계획표(API72_2)`와 `#41 AI학습용 경주계획(API154)`은 별도 서비스다. 운영 수집 기록은 API154에 있다.
- **출전 전 단계:** `#33 출전 등록말(API23_1)`은 신청 후보, `#42 출전표 상세(API26_2)`는 확정 출전마 기본행, `#8 출전표정보(API78)`는 KRA 화면 기반 출마표 스냅샷이다. API78의 장구 `+/-`는 [기존 사용 목록](KRA_API_USAGE_INVENTORY_2026-09-30.md)에 저장 방식이 기록돼 있다.
- **말의 상태:** `#9 경주마 상세(API8_2)`와 `#32 영문추가(API310)`는 현역마 중심이며, `#4 마필종합 상세(API42_1)`은 포털 설명상 은퇴마도 포함한다. 단순히 최근 출전이 없다는 사실로 은퇴 상태를 확정하지 않는다.
- **수영:** `#6 경주마 수영조교(API144)`와 `#20 수영훈련(API216)`은 별도 승인 서비스다. 현재 보존 수집 기록은 API216에 있다.
- **구간:** `#35 API303`은 경주 코너 통과순위·주로빠르기, `#36 API37_1`은 말별 과거 구간 최고/최저/평균, `#37 API6_1`은 경주별 상세 구간, `#38 API4_3`은 말별 경주기록과 구간기록이다. 값의 시간 의미·운영 원천 우선순위는 별도 품질 검증 문서를 따른다.
- **진료·질병:** `#27 API16_1`은 개별 진료기록, `#2 API33`은 질병명·설명, `#17 API141`은 최종 경주 전 1년 진료내역, `#18 API24_1`은 출전 장구와 폐출혈 정보다. 서로 대체할 수 없다.
- **배당:** `#34 API301`은 경주 후 **확정** 배당이며 경주 전 실시간 배당이 아니다.
