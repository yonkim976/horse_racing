# 원문 혼합 기준과 API 전용 기준의 시작·종료 시점 (2026-09-14)

사용자 질문의 `2007년`은 공식 API와 KRA Text 원문을 **혼합**하여, 경주결과·일반 조교·전용 체중·진료라는 네 종류가 세 경마장 모두에서 관측되기 시작한 가장 이른 후보 기간이다. 출발조교까지 넣으면 `2009-05-21` 이후다. 어느 날짜도 전 경주·전 출전마의 완전성 승인을 뜻하지 않는다. 자세한 범위는 [공통 시작 시점 조사](HORSE_RECORD_COMMON_START_2026-09-14.md)에 있다.

## API만 볼 때의 최초 양성 범위

- 말별 경주결과 `API4_3`: 서울·제주 2000년, 부경 2004년부터 양성 응답을 확인했다.
- 일반 일별 조교 API: 서울 1998-09-25, 제주 2007-10-01, 부경 2004-06-30부터 실제 행이 수집됐다.
- 출발조교 API: 서울·부경 2009-05-21, 제주 2007-10-17부터 실제 행이 수집됐다.
- 전용 출전마체중 API: **2019-01**에 서울 1,131행, 제주 544행, 부경 740행으로 세 경마장 양성을 확인했다. 이 조회만으로 해당 API의 절대 최초 연도나 2019년 전체 완전성을 주장하지 않는다.
- 마필진료 `API16_1`: **1990~2025년**의 `clinic_year` 응답을 연도별로 검사했다. 제주는 2008년에 1건이 먼저 나오지만 `illName1/2`가 모두 `-`여서 진단·처치 내용이 없다. 내용이 있는 진료는 제주 **2012년**(5건 중 3건), 서울 **2018년**(18건 중 15건), 부경 **2019년**(64건 중 51건)부터 확인된다. **세 경마장 모두 내용 있는 API 진료행이 확인되는 첫 연도는 2019년**이다. 2019년 전체 응답은 서울 99건·제주 381건·부경 64건으로, 2025년의 각각 47,263·2,991·37,387건보다 매우 적다. 따라서 2019년 양성은 그 시기 진료 사건을 완전히 포괄한다는 뜻이 아니다.

질문에서 열거한 경주결과·일반 조교·출발조교·마체중·진료 **다섯 종류의 API가 모두 양성임을 확인한 가장 이른 연도는 2019년**이다. 이는 원천 종류별 존재 확인이다. [경주마 상세정보 API](https://www.data.go.kr/data/15058115/openapi.do)의 현재 현역마 프로필·통산 수치를 2019년 상태로 소급할 수 없으므로, `경주마 관련 모든 기록`까지 과거 시점에 완전하게 존재한다는 의미는 아니다. 실제 정규화 DB에서 다섯 종류가 말 ID로 함께 조회되는 실무 시작은 2025년이다.

API 진료 연도별 `totalCount`·응답 hash는 [`1990~2010`](../data/logs/api_medical_year_availability_1990_2010_20260914.json), [`2011~2025`](../data/logs/api_medical_year_availability_20260914.json)에, 초기 진단 내용 대조는 [`초기 실제 내용`](../data/logs/api_medical_early_content_20260914.json)에 있다. 2019년 1월 체중과 최신 진료일의 첫 페이지 응답은 [`api_weight_medical_boundary_20260914.json`](../data/logs/api_weight_medical_boundary_20260914.json)에 있다. 공식 서비스 설명: [진료](https://www.data.go.kr/data/15057799/openapi.do), [일별훈련](https://www.data.go.kr/data/15058782/openapi.do), [출발훈련](https://www.data.go.kr/data/15059043/openapi.do), [경주기록](https://www.data.go.kr/data/15058305/openapi.do).

## 현재 조회되는 최신 날짜

- 실제 경주결과의 최신 경주일은 **2026-09-13**이다. 현재 DB에서도 서울·영천의 그 날짜 결과가 있다. 제주 마지막 결과일은 9월 12일, 부경은 9월 11일이다.
- 진료 API를 `clinic_date=20260912/13/14`로 세 경마장에 각각 재조회했다. **9월 13일은 서울 56·제주 37·부경 221행**, 9월 14일은 모두 0행이었다. `0`만으로 그날 진료가 전혀 없었다거나 이후 게시가 없을 것이라고 단정하지 않는다.
- 2026-09월 체중 API 전 페이지를 읽어 `wgHr > 0`을 실제 체중으로 분리했다. 양수 체중의 최신 경주일은 서울 **9월 13일**, 제주 **9월 12일**, 부경 **9월 11일**이다. 제주에는 9월 17~19일의 `wgHr=0` 예고행도 있어 이를 측정 완료 자료로 세지 않았다. [`api_weight_latest_valid_20260914.json`](../data/logs/api_weight_latest_valid_20260914.json).
- 수집된 일반 조교 API 원문의 최신 기록일은 세 경마장 모두 **9월 13일**이다. 출발조교는 서울 **9월 11일**, 제주 **9월 13일**, 부경 **9월 12일**이다. 날짜별 조회 범위의 끝과 실제 사건 유무는 다르다.

따라서 사용자가 말한 **‘API에서 조회 가능한 가장 최신 경주·말 사건 데이터’는 현재 2026-09-13까지**다. 이와 별도로 말 프로필은 현재 상태의 스냅샷이며, 과거 경주일의 스냅샷이 아니다. 최근 API 응답도 완전한 사전 예측 입력으로 자동 승인하지 않는다.
