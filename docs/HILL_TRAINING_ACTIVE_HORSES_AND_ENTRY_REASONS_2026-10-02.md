# 언덕조교 현역마 연결과 목장 입소 사유 확인

작성일은 2026-10-02다. 현재 보유한 언덕조교 기록을 로컬 운영 DB의 말 기본정보와 경주 결과에 연결해, 현역마도 언덕조교를 받는지와 육성·휴양·재활 기록을 구분할 수 있는지 확인한 내용을 보존한다.

현역으로 저장된 말 47두에 언덕조교 기록이 있으며, 그중 38두는 해당 훈련 전에 정상 착순이 있는 경주 결과가 확인됐다. 따라서 보유 언덕조교 자료는 어린 말의 데뷔 전 육성 기록만으로 구성되지 않는다. 이번 사용자 요청은 문서화만이며, 추가 수집·DB 변경·모델 변경·예약 활성화는 수행하지 않는다.

## 확인 범위와 기준 시점

- 확인 DB: `/Users/kimyongjin/Desktop/horse_racing/data/horse_racing.sqlite3`
- 언덕조교 테이블: `horse_hill_training`
- 보유 훈련일 범위: 2025-08-28부터 2026-09-30까지
- 보유 기록: 3,770행, 공식 말 ID 기준 191두
- 현역 판정: `horses.is_active = 1`
- 연결된 현역마의 상태 확인 시각: 2026-10-01 16:02:02~16:02:09 KST

수치는 이번에 확인한 로컬 DB의 스냅샷이다. 모든 시기의 전체 언덕조교 이력을 확인한 수치가 아니며, Supabase에 대해 이번 결과를 별도로 전수 재검증한 것은 아니다. 훈련일과 현역 상태 관측일도 서로 다르다.

현재 운영 말 기본정보에 연결된 47두는 모두 현역으로 저장되어 있으며, 이들의 언덕조교 기록은 420행이다. 나머지 144두의 3,350행은 `horse_id`가 연결되지 않았다. 미연결 144두는 육성 138두와 휴양 6두이며, 미연결이라는 이유로 비현역·은퇴마로 분류하지 않는다.

특히 육성 138두의 현역 연결 수가 0인 것은 현역마가 없다고 확정한 결과가 아니다. 현재 운영 말 기본정보와 연결되지 않아 현역 여부를 판정할 수 없는 상태다. `육성`은 API가 제공한 입소 사유이며, 이 값 하나만으로 공식 신마 자격이나 첫 출전 여부를 확정하지 않는다.

표의 행 수는 저장된 관측 기록 수다. 기록값이 모두 정상인지, 각 행이 서로 다른 실제 시행인지와 별개이므로 이를 검증된 훈련 횟수로 표현하지 않는다.

## 경주 경험 이후 언덕조교를 받은 사례

`horse_hill_training.horse_id`를 `race_entries.horse_id`에 연결하고, `race_results.finish_position IS NOT NULL`인 경주 중 `races.race_date_local < horse_hill_training.training_date_local` 조건을 만족하는 이력을 확인했다.

이 조건을 충족한 현재 현역마는 38두이며, 해당 언덕조교 기록은 314행이다. 입소 사유별로 휴양 29두와 휴양(재활) 9두다. 정상 착순이 없는 출전이나 미수집 과거 경주는 이 판정에 포함되지 않으므로, 조건을 충족하지 않은 말을 경주 경험이 없는 말로 확정하지 않는다.

## 저장 필드와 공식 API

[한국마사회 언덕주로 훈련정보 API](https://www.data.go.kr/data/15086327/openapi.do)는 목장, 말 ID, 출생일, 입사일과 입사 사유, 조교일·시간, 구간 및 합계 기록을 제공한다. 우리 DB는 다음과 같이 저장한다.

| API 필드 | 운영 DB 필드 | 의미 |
|---|---|---|
| `areq` 또는 실제 응답 `areqNm` | `farm_name` | 훈련 목장 |
| `hrNo` | `kra_horse_id_raw` | 원천의 공식 말 ID |
| `inStDate` | `farm_entry_date` | 목장 입소일 |
| `stCause` | `farm_entry_reason` | 원천의 입소 사유 |
| `startDt` 또는 실제 응답 `startDate` | `training_date_local` | 훈련일 |
| `startTime` | `training_time_local` | 훈련 시각 |
| `firstRecord`, `secRecord`, `thiRecord`, `sumRecord` | `f1_seconds`, `f2_seconds`, `f3_seconds`, `total_seconds` | 구간 및 합계 기록 |

공식 API 명세는 필드 제공 여부의 근거다. 위의 47두·138두 등 집계 수치의 근거는 로컬 운영 DB이며, API 설명 자체에서 얻은 통계가 아니다.

## 해석과 후속 작업의 제한

현역 여부와 목장 입소 사유는 서로 다른 구분이다. 현재 현역으로 저장된 말도 휴양이나 재활을 목적으로 목장에 입소한 언덕조교 이력을 가질 수 있다. 입소 사유는 해당 원천 관측의 정보이며, 현재 휴양 중인지 또는 현재 경주장에 있는지를 확정하는 실시간 상태 필드로 사용하지 않는다.

`휴양(재활)` 표기만으로 특정 부상·질병, 심각도, 완치 여부를 추론하지 않는다. 언덕조교 이력만으로 출전 가능 여부나 경기력 향상도 확정하지 않는다. 제주목장의 기록이라는 이유로 말의 품종을 제주마로 분류하지도 않는다.

이 문서는 사실 확인 결과를 보존한 것이다. 미연결 말의 자동 현역 분류, 신마 분류 추가, 휴양 상태 변경, 예측 피처 채택은 승인하거나 시행한 작업이 아니다. 기존 모델과 원천 데이터는 그대로 유지한다.
