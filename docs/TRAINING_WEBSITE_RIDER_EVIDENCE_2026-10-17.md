# 공식 홈페이지 조교 기승자 구분 보완

API의 구분 누락 및 기수트랙라이더 오표시를 공식 말 프로필의 기승자 범례로 보완한다.
`profileTrainState.do`의 이름은 기수, 조·관·생·후·트는 각각 조교사·주로조교·교육생·기수후보생·기수트랙라이더다.
표시용 이름은 기수에만 허용한다. 원본 API 필드는 수정하지 않는다.

말 ID와 마명을 확인하고 날짜·입퇴장 시각·조교 시간이 양쪽에서 유일하게 일치할 때만
`horse_training_rider_observations`에 연결한다. 원본 필드가 바뀌면 fingerprint 불일치로 연결을 무효화한다.
공식 HTML은 `SourceDocument`와 원문 파일로 보존한다. 홈페이지의 시간 불일치 행은 제외하고
행 번호를 수집 이력에 남긴다. 나머지 정상 행은 계속 처리한다.

수집 범위는 기준일로부터 7일 이내 예정 경주의 출전마, 최근 28일 조교다.
경주 개최지가 아닌 실제 조교 장소의 meet를 사용한다. 최대 500개 프로필, 직렬 요청,
요청 간 0.2초, 최대 응답 2MiB를 적용한다. 웹페이지 요청 중에는 외부 수집을 하지 않는다.

수동 실행은 기본 계획 확인 후 `--apply`를 지정한다.

```sh
.venv/bin/python scripts/sync_training_riders.py --race-id 55244
.venv/bin/python scripts/sync_training_riders.py --race-id 55244 --apply
```

`daily_training.collect_window`의 API 수집 후 같은 수집기를 호출하도록 소스를 연결했다.
이번 작업에서는 클라우드 Job 이미지나 웹 서비스를 배포하지 않았으므로 배포 전까지
기존 클라우드 예약 실행에는 새 홈페이지 보완 단계가 포함되지 않는다.

2026-10-17 운영 DB에 신규 테이블·RLS와 serving view 보완을 적용하고 4,592개 이벤트의
공식 구분을 저장했다. anon/authenticated 권한은 부여하지 않았다. 프라임스타 13개 이벤트에서
기수 이혁의 이름과 나머지 직책 표시를 로컬 화면으로 확인했다. 이번 수집 중 발견한
범위 내 시간 불일치 4행은 저장하지 않았다.
