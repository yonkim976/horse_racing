## 1. 현재 출전집합과 원천 감사

dataset.apply_label_policy, live prediction_frame, RaceEntry/RaceResult, 원문 저장·수집기 및 예측 원장을 추적한다. 다음을 각각 정의하고 교집합·차집합·제외 원인을 경주/출전 키로 집계한다.

- t=예정 출발 30분 전의 공개 출전집합 F_t
- 사후 실제 출발 집합과 정상완주 집합
- 기존 학습·평가 집합과 live 경로가 사용하는 집합

현재 scratched boolean만으로 과거 t 시점 상태를 복원했다고 주장하지 않는다. 원문·snapshot의 published/event/observed/ingested 시각을 구분한다. 경주일 또는 사후 수집시각을 공개시각으로 대체하지 않는다. 증거가 충분한 복원, 공개시각 가정에 의존한 복원, 복원 불가능을 명시적으로 구분한다. 근거 경로·키·시각과 충분성 판단 이유를 보존한다.

기존 dataset manifest의 scratched=267, special_finish_code=48 등이 어떤 후보 범위와 필터 순서에서 나온 수인지 확인한다. 목표 경주, 기간, 분모를 맞추기 전 서로 다른 집계와 직접 비교하지 않는다. 오류가 있는 경주에서 일부 말만 제거한 후 완전한 출전집합으로 처리하지 않는다.

## 2. 상태와 라벨 계약

실제 원천 코드·rank_remark·disqualified·scratched 조합을 열거한 뒤 사전 취소, 시점 이후 취소/출발 제외, 실제 출발 후 DNF, 실격, 정상완주, 결과 미수집/미확정, 경주 취소/무효, 공식 동착을 구분하는 매핑을 작성한다. 특수착순 >=90 전체를 DNF라고 가정하지 않는다. 모호한 상태는 unknown으로 보존한다.

- F_t의 선택과 starters_at_prediction은 해당 경주의 결과 라벨에 의존하지 않아야 한다.
- 실제 출발 후 확정된 DNF는 win/topK 비입상 라벨을 줄 수 있지만, 결측 결과나 출발하지 않은 말을 자동으로 같은 0 라벨로 바꾸지 않는다.
- 취소/무효는 예측 대상 확률 사건과 정산 규칙이 무엇인지 따로 명시한다. t 이후 취소를 사전에 안 것처럼 제거하지 않는다. 사후 출발자 조건부 분석을 별도 보조 분석으로 한다면 이름·분모·조건을 표시한다.
- 공식 순위, 정확 순위/누적 topK, 동착, 완주자 부족 시 확률합과 손실의 정의를 명시한다. 실격/취소의 공식 의미가 불명확하면 확인된 원문 근거와 미확정 항목을 구분한다.
- 정상완주 순위/기록에 대해서만 정의 가능한 보조 target은 mask한다. DNF에 가짜 최하위 순위나 가짜 완주시간을 대입하지 않는다. DNF 위험과 정상완주 조건부 능력을 나누는 후속 모델 선택지는 명세에만 적고 이번에 학습하지 않는다.

## 3. feature·평가 경계

사전 starters, 마번 비율, 경주 내 상대평가, pace 경쟁자 수, 확률 정규화가 어떤 집합을 써야 하는지 추적한다. 'DNF 행을 추가하면 끝'이라고 결론 내리지 않는다. F_t가 바뀌면 이 값들과 live/offline 입력 계약도 달라진다.

출전집합의 적합성 검증과 결과 확정에 따른 평가 가능성 검증을 분리한다. 불명확한 레이스는 제외 이유와 전체 분모에 남긴다. 정상완주 조건부 legacy NLL과 전체 출전집합 NLL을 그대로 빼서 개선이라고 보고하지 않는다. 후속 통제 비교에 필요한 동일 F_t·동일 라벨·동일 평가 사건의 조건을 명세한다.
