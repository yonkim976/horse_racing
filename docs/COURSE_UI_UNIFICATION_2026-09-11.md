# 제주·서울 지도 조작 통일

- 주로 형상, 거리 계산, 측정 지점 근거는 경기장별 기존 계산을 유지한다.
- 공통 `_course_records.html`에서 측정 순서도, 마지막 600m·200m 선택, 기록 패널을 렌더링한다.
- 공통 `course-explorer.js`에서 단일 선택 상태와 패널 전환을 관리한다. 서울 전용 스크립트는 경로·도면 비교·참고 위치 강조를 담당한다.
- 두 경기장 모두 지도 아래 거리 미리보기, 그 아래 순서도와 기록 패널을 배치한다. 좁은 화면에서는 패널을 아래로 내리고 순서도를 가로 스크롤한다.
- 제주에 기존 경로 계산을 이용한 거리별 미리보기, 확대, 막판 구간 선택을 추가했다. 다른 거리 미리보기에서는 현재 경주의 측정점을 숨기고, 기록 선택 시 현재 거리로 복귀한다.
- 서울 지도 G3F/G1F 클릭은 해당 지점의 직전 구간 기록을 선택한다. 막판 기록은 별도 버튼으로 선택하여 제주와 조작 의미를 맞춘다.
- 서울의 미확정 코너는 지도 강조 없이 기록만 표시한다. 제주 1110m·1610m S1F 210m 규칙을 유지한다.
- 검증: 지도·상세·구간 관련 테스트 75개, 브라우저에서 제주 1110m 210m 선택/1610m 미리보기/현재 경주 복귀/막판 기록, 서울 지점과 막판 선택, 모바일 폭의 4C 미확정 안내 확인.
