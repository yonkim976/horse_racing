마필로그 공유 IP 접속 검증 — 2026-10-03

작업 위치: codex/web-ui 워크트리. 기존 변경 보존.
운영 배포, Cloud Run 설정 변경, 운영 DB 쓰기, 모델/예측 변경 없음.

로컬 검증 조건
- 외부 네트워크와 프로세스 fork 차단, 소스/도구 읽기 전용.
- 비밀값 없는 허용목록 환경, 지정 scratch의 SQLite만 사용.
- CPU 30/31초, RSS 512MiB, 디스크 32MiB, 파일 8MiB, wall 60초 제한.
- 수집 봇/일반 IP 분리, 요청 크기, 캐시, 큐, 취소 복구를 검증.
- scripts/verify_shared_ip_load.py: 같은 peer IP의 100명, 모바일/PC 및 화면 선택 쿠키 혼합.
- 경주 목록, 로컬 정적 파일, 달력, 이용 안내, 개인정보처리방침, 3개 경주 상세 조회.
- SQLite 시드: 말 20두, 과거/본 경주 13개, 본 경주 10두씩. 실제 운영 데이터가 아님.

100명 검증 결과
첫 접속: 100/100 여정 완료, 요청 1750건, 모두 200, 오류/429=0.
첫 접속 전체 여정 지연: p50 2546.89ms, p95 2610.03ms.
첫 접속 SELECT 363회. 달력 1회, 홈 2회, 경주/분석 각 10회 로더 실행.
재접속: 10.1초 토큰 보충 후 같은 100명. 100/100 완료, 요청 1750건.
재접속: 200=700건, 304=1050건. 오류/429=0, SELECT=0, 비싼 로더=0.
재접속 전체 여정 지연: p50 1121.04ms, p95 1196.38ms.
추가 캐시 검사 포함 총 3505건. 최대 동시 DB 세션 작업 3개.
DB 세션 시작에 합성 지연 4ms 사용. PostgreSQL 지연을 재현한 것이 아님.
추가 쿠키/Authorization 요청은 홈 로더 2회 우회 확인.
정적 자산 Cache-Control: public, max-age=3600; ETag 재검증 304.

회귀 검증
화면/확률/공개 문구/요청 정책/보안 관련 기존 검사 119개 확인.
홈 성능 3개와 공유 IP 통합 1개 포함, 서로 다른 검사 총 123개 통과.
실패한 과거 문구/한도 기대값은 수정 후 해당 검사 재검증 완료.
기존 Starlette/httpx deprecation 경고 1종 있음.
Ruff 및 dashboard.js Node --check 통과. git diff --check 통과.

적용한 정책
알려진 Claude, Ahrefs, Serpstat 봇은 DB 전에 403. 다른 크롤러는 엄격 제한.
일반 이용자의 공유 IP 허용량 확대. UA 위장을 포함한 모든 봇 차단을 보장하지 않음.
일반 IP/크롤러 상태 분리, 제한된 대기 큐와 동일 응답 중복 계산 방지.
DB 동시 작업 3개 유지. CSV/입력/응답 크기 및 캐시 용량 제한 유지.
반복 애플리케이션 로그 제한. Cloud Run 자동 접속 로그와 보관 설정은 변경 안 함.

운영 한계
이 결과는 로컬 ASGI/SQLite 시뮬레이션이다.
실제 Cloud Run 큐/콜드 스타트/네트워크 및 Supabase PostgreSQL 처리량은 검증하지 않았다.
확인한 운영 설정: Cloud Run 내부 접근, 동시성 8, 최대 인스턴스 3. 공개 주소 404.
수정본은 배포하지 않았다. 실제 현장 공개 전에 배포 및 공개 접속 복구가 필요하다.
개인정보 국외 처리 조건은 추가 확인 필요. 이메일 7일 파기는 수동 운영 절차이다.
