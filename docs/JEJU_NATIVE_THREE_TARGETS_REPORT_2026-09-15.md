# 제주마 세 목표 병행: 입상·집합·정확순서 비교 결과

작성일: 2026-09-15 · 연구 버전: `jeju_three_targets_v2`

## 1. 실행 결과와 판단

사용자가 승인한 세 방향을 실제로 구현하고 비교했다. **한 마리 입상에서는 새 P_H2 후보가 444/715경주(62.10%)로 수치상 최고였다. 세 마리 집합과 정확순서는 기존 M0_H2가 49/715경주(6.85%), 18/715경주(2.52%)로 최고를 유지했다.**

같은 말의 데이터를 사용해도 학습 목표에 따라 결과가 달라졌다. 새 입상 모델로 기존 모델을 일괄 교체할 근거는 없다. 다음 연구의 목표별 비교 후보를 **입상 P_H2 / 집합 M0_H2 / 정확순서 M0_H2**로 유지한다. 이는 개발 후보 지정이며 최종 운영 승인이 아니다.

2025-01-03~12-27의 동일한 715경주·98경주일·6,953출발행을 사용했다. 후보별 예측 coverage는 100%이며 적중률과 구분한다. 2026년 모델 평가와 실제 사전 예측은 이번 단계에 포함하지 않았다. 하위 구현·검토는 사용자 지정 GPT-5.6 Luna / high로 수행했다.

## 2. 세 목표의 정의

1. **한 마리 입상:** 각 경주에서 딱 한 마리를 선택하고 그 말이 공식 정상 1·2·3착인지 평가한다. 예측한 세 마리 중 우승마가 있는지를 보는 지표와 다르다.
2. **세 마리 집합 완전 적중:** 예측한 세 마리가 동착 호환 정답 집합과 일치하는지 본다.
3. **정확순서 완전 적중:** 같은 세 마리의 1·2·3착 순서까지 일치하는지 본다.

기존 모델의 말별 입상 확률은 전체 PL 순서 분포에서 해당 말이 1·2·3착에 등장하는 확률을 합산했다. 정상적인 동착 없는 경주에서 말별 합은 3이다. 최고 점수의 말이 최고 PL 입상 확률의 말이며, 정확한 점수 동점은 고정 말 ID로 처리했다.

3착 경계 동착에서는 공식 입상마가 네 마리일 수 있다. **단일 말·집합·순서 적중률은 전체 715경주를 유지했다.** PL의 세 자리 확률과 공식 입상 라벨을 공통 비교하는 Brier·로그 손실·선택 확률 보정표에서만 경계 동착 **6경주를 제외한 709경주**를 사용했다. 원시 예측에는 경계 동착 flag와 해당 경주의 진단값을 보존했다.

- H2의 역사 공개시각은 여전히 가정이다. 출전 당시 등급·중량·기수 등 H3 정보는 이번 비교에 새로 넣지 않았다.

## 4. 새 입상 모델은 어디에서 달라졌나

직전 대표 후보 M0_H2를 고정 비교점으로 사용했다.

| P_H2 − M0_H2 | 차이 | 경주일 95% 구간 |
|---|---:|---:|
| 한 마리 입상 | **+19경주 · +2.66%p** | **[+0.14, +5.16]%p** |
| 세 마리 집합 | −5경주 · −0.70%p | [−2.24, +0.70]%p |
| 정확순서 | **−8경주 · −1.12%p** | **[−2.09, −0.28]%p** |

입상 목표에서 증가한 반면 정확순서 완전 적중은 감소했다. 집합 차이는 구간이 0을 포함하므로 악화가 확정됐다고 말하지 않는다. 이 결과는 **이미 여러 모델을 비교한 2025 개발 자료에서의 탐색적 비교이며 다중 비교 보정을 하지 않았다.** 새 최고 후보의 일반화나 실제 경주 성능을 확정한 것이 아니다.

P_H2는 PL 입상 Brier 0.1911, 로그 손실 0.5663으로 이번 후보 중 수치상 최저였다. 집합 NLL 4.2277, 순서 NLL 5.9629도 낮았지만, 정확순서 적중 수는 기존 M0_H2보다 적었다. 확률 분포의 품질과 최고확률 한 결과의 적중은 별개로 관리해야 한다.

기존 M0_H2의 단일 말 동점 무작위 기대 적중률은 59.65%, 고정 ID 실제 적중률은 59.44%다. P_H2는 62.10%로 동일하다. 작은 동점 차이도 기록해 임의의 말 ID 선택 효과를 숨기지 않았다.

## 5. 두 종류의 입상 확률

새 P 모델에는 동일한 원시 점수에서 계산하는 두 확률이 있다.

- **공통 PL 입상 확률:** 순서 분포를 만든 뒤 1·2·3착 확률을 합산한다. 상대 출전마의 점수가 함께 영향을 준다. 모든 12개 후보의 공통 확률 비교에 사용한다.
- **직접 이진 확률:** CAL에서 양의 기울기를 가진 Platt 보정으로 공식 입상 확률을 계산한다. 각 말의 확률을 독립적으로 변환하므로 경주 내 합을 3으로 강제하지 않는다. 세 마리 동시 입상 확률로 곱하지 않는다.

P_H2의 직접 이진 확률 Brier는 0.1950, 로그 손실은 0.5757로 공통 PL 확률보다 높았다. 따라서 **직접 입상 라벨로 학습했다고 그 이진 확률이 가장 정확하다고 가정하지 않는다.** 두 보정은 모두 CAL 자료에서만 적합했고, 정답을 보고 평가 경주의 확률을 다시 맞추지 않았다.

P_H2의 선택한 말 평균 PL 입상 확률은 62.47%, 전체 실제 적중률은 62.10%다. 직접 이진 평균 확률은 56.66%다. 전체 평균이 비슷하다는 사실만으로 구간별 확률 보정이 완벽하다고 주장하지 않는다.

## 6. 구현과 검증

- 새 이진 모델: 3개 입력 묶음 × 4개 fold × 2개 seed = **24회 적합**. TUNE의 경주 가중 이진 로그 손실로 조기 종료했다.
- CAL 보정: 직접 이진 12회 + 공동 PL 12회 = **24회**. 전처리는 FIT에서만 적합했다.
- 새 모델·전처리·두 보정 묶음 **12개**를 저장하고 별도 프로세스에서 재실행하여 저장 원시 점수와 이진 확률을 1e-12 이내로 대조했다.
- 12개 후보 × 715경주 = **8,580개 경주 예측**, 12개 후보 × 6,953출발행 = **83,436개 말별 확률 행**을 저장했다.
- 기존 9개 후보의 집합·순서 예측과 손실이 v1과 그대로 일치함을 확인했다. 새로운 목표를 추가하면서 과거 결과를 바꾸지 않았다.
- 공식 입상 라벨·한 마리 선택·말별 PL 확률 합 3·확률 범위·중복·누락·기간·원본 보존·모델 재현 검사를 완료했다.
- 관련 테스트 **61개 통과**. 입상 확률이 1착 확률로 잘못 대체되지 않도록 균등 10두 경주에서 선택 입상 확률 30%를 별도 검사했다.

## 7. 다음 실행 방향

1. **목표별 후보 유지:** 입상 P_H2, 집합·정확순서 M0_H2를 다음 실험의 비교점으로 고정한다. 서로 다른 모델이므로 단일 말 선택과 다른 모델의 세 마리 집합이 항상 일치한다고 가정하지 않는다. 통합 운영 출력은 별도 일관성 검사가 필요하다.
2. **H3 출전 당시 조건 구축:** 등급·부담중량·게이트·기수·연령/성별 등의 경주별 값과 당시 가용시점을 검증한다. 데이터에 현재 값이 있다는 이유로 과거 경주에 소급하지 않는다.
3. **경주 내 상대 비교와 공동학습:** 입상 경계와 세 마리 내부 순서를 함께 학습하는 후보를 비교한다. 목표별 성능을 각각 보고해 입상 개선과 순서 악화를 감추지 않는다.
4. **후보·출력·보정 정책 고정 후 2026 역사 평가:** 2025 개발을 더 반복한 결과는 탐색적이라는 표시를 유지한다. 2026은 다른 연구에 노출된 역사 자료라는 한계도 보존한다.
5. **경주 전에 기록하는 실제 사전 원장:** 선택 경주만 남기지 않고 전체 적격 경주의 예측과 변경 이력을 기록하여 이후 성능을 판단한다.

100% 접근이라는 장기 목표는 유지한다. 현재 확인한 것은 한 마리 입상 62.10%, 세 마리 집합 6.85%, 정확순서 2.52%라는 **서로 다른 목표의 개발 성능**이다. 이번 단계에서 H3나 실시간 운영까지 완료한 것으로 표현하지 않는다.
