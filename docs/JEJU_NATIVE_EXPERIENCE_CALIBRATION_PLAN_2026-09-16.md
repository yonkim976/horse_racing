## 사전 고정 구간과 진단

- 같은 거리 과거 출전 수: 0회, 1~2회, 3~5회, 6회 이상, 미상.
- 구간 결측: 과거 초반 상위 3 빈도 또는 최근 막판 상대속도 중 하나라도 유효값이 없으면 결측. 원본 모든 구간 정보의 유무를 뜻하지 않는다.
- 경험 구간, 결측 여부, 두 조건의 교차 구간을 보고한다.
- 전체 출전마와 기존 모델이 선택한 한 마리를 각각 보고한다. 비교 모델에서도 ‘기존 선택마’ 모집단을 고정한다.
- 경계 동착을 제외한 709경주를 확률 진단에 쓴다. 경주 결과를 보기 전에는 경계 동착 여부를 알 수 없으므로 실제 예측은 모든 715경주에 적용한다.
- 평균 예측 확률−실제 입상률이 양수면 과대 예측, 음수면 과소 예측이다. 경주일 단위 5,000회 재표본 구간을 보고한다.
- 구간별 100개 출전 행 또는 10개 경주일 미만이면 소표본으로 표시한다. 확률 구간은 [0,.2), [.2,.4), [.4,.6), [.6,.8), [.8,1]로 고정한다.

세 자리 입상 확률 합은 경주마다 3이고 정상 입상 라벨 합도 3이므로, 전체 출전마의 평균 확률 오차 합은 원래 0이다. 전체 평균 하나만으로 확률이 잘 보정되었다고 판단하지 않는다. 하위 구간, 확률 구간, 선택마의 오차를 확인한다.

## 비교할 보정기와 선택 방식

두 보정기만 CAL에서 학습한다.

1. C_GLOBAL: 기존 집합 확률의 분포를 조절하는 양수 온도 하나.
2. C_EXPERIENCE: 같은 온도와 경험·결측별 가산 보정 5개. 경험 0회·1~2회·3~5회·미상, 구간 결측을 표시하며 경험 6회 이상·구간 관측을 기준으로 둔다.

새 조합 점수는 `exp(log_scale) × 기존 log 집합 확률 + 세 말의 보정값 합`이다. 모든 집합에 softmax를 적용한다. 따라서 입상 확률 합 3, 집합 확률 합 1을 보존한다. 보정 방향을 미리 음수로 강제하지 않는다.

- 목적함수: 경주별 동일 비중, 경주 내 말별 평균 입상 이진 로그손실.
- 경계 동착 경주는 CAL 목적함수에서 제외한다. FIT·TUNE은 기존 모형을 유지하고 새 학습에 쓰지 않는다.
- L2=.01을 모든 새 모수에 적용해 원래 분포에 가까운 보정을 선호한다. 모수 범위 [-2,2], 최대 최적화 150회로 고정한다.
- 기존 분포에는 이미 기존 CAL에서 정한 온도가 포함된다. 새 보정도 같은 CAL을 사용하므로 두 번째 독립 표본으로 보정한 것은 아니다. 새로운 평가 구간은 건드리지 않는다.
- 기존 순서 모델과 순서 온도는 그대로 사용한다. 보정으로 바뀌는 것은 집합 확률이다.

세 출력 정책을 사전에 고정한다.

| 출력 | 확률 | 한 마리·집합·순서 선택 |
|---|---|---|
| C_GLOBAL_FIXED | 전체 온도 보정 | 기존 선택 유지 |
| C_EXPERIENCE_FIXED | 경험·결측 보정 | 기존 선택 유지 |
| C_EXPERIENCE_SELECT | 위와 동일한 경험·결측 보정 | 최대 입상 주변확률 한 마리, 최대 확률 집합, 집합 내 최대 확률 순서 |

FIXED는 보정 확률이 달라도 행동을 유지한다. SELECT와 경험 FIXED는 모든 확률 손실이 동일하고 적중만 달라질 수 있다. 신뢰도 값은 각 정책이 실제 선택한 말·집합·순서의 확률이다.

## 실행 수와 판정

4개 시간순 폴드×보정기 2개=8보정, 8저장 묶음. 기존 모형 재학습 0회. 2025년 715경주·98일의 세 목표와 확률 오차를 비교한다. 경주별 성능 집계는 경주 동일 비중, 하위 구간 진단은 해당 출전 행 동일 비중임을 구분한다.

- 확률 보정 후보: 기존 대비 Brier 차이의 경주일 95% 상한이 0보다 작고 로그손실 점추정이 나빠지지 않아야 한다.
- 선택 변경 후보: 기존 대비 집합 적중 차이의 경주일 95% 하한이 0보다 크고 한 마리·순서 적중 점추정이 낮아지지 않아야 한다.
- 조건을 만족해도 반복 개발 자료의 연구 후보이며 독립 실전 우위가 아니다. EVAL을 보고 구간·규제 강도·후보를 바꾸어 재학습하지 않는다.
