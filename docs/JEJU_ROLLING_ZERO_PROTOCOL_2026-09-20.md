# 이력 0회: 시간순 보정 표본 확대 — 사전 계획

2026-09-20. 결과 상한 2026-09-12. 기존 평가 기간을 재사용하는 후향 개발 실험이다.

## 고정 설계

- 기존 HY_R_FORM 108개 입력과 순위 학습 설정·시드 17/43을 고정한다.
- 2023~2025년 각 분기를 예측하는 12개 전진 검증 구간을 만든다. 분기 시작 전 직전 분기를 온도 보정, 그 이전 분기를 조기종료 선택에 사용하고, 나머지 과거(2018-08-31 이후)만 학습한다. 분기 예측 대상의 정답은 학습·선택·온도 보정에 사용하지 않는다. 순위 학습은 총 24회, 순서 학습은 0회다.
- 연도 Y의 보정에는 Y−1년 4개 분기의 과거 외부 예측만 사용한다. 2024/2025/2026 평가에는 기존 연간 BASE 확률을 그대로 사용한다. 따라서 과거 분기 모델에서 연간 모델로 보정을 이전하는 데 따른 분포 차이는 남는다.
- 직전 분기의 온도 보정은 기존 방식의 허용 착순 손실을 사용한다. 최종 입상 확률 보정에서는 경계 동착 경주를 제외한다.
- 최종 보정 두 종류: OOF_GLOBAL(전체 공통 단조 보정), OOF_ZERO(공통 보정 + 이력 0회 계수). 기존 PositivePlatt/ZeroHistoryCalibrator를 사용한다. 경주별 총 가중치 1, zero 계수 벌점 .01을 유지한다. 결과 확인 후 후보/벌점/기간을 변경하지 않는다.
- 비교 대상은 BASE와 직전 실험 BASE_ZERO(Q4_ZERO)다. A 한 마리 공식 입상만 선택 변경하며 B/C 모델·출력은 유지한다. 입상 확률의 합 3이나 결합분포를 보장하지 않는다.

## 평가·판정

- 2024년 695경주, 2025년 715경주, 2026년 510경주 전체 A 및 연도별 A를 보고한다. 경계 동착은 A에 포함하고 확률 평가에서 제외한다.
- OOF_ZERO 대 BASE 및 Q4_ZERO 두 주 비교: 연도 층화·경기일 단위 5,000회 paired bootstrap, 두 비교 Bonferroni 동시 95% 구간.
- 연구 후보 승격 조건: 두 주 비교 모두 통합 구간 하한 > 0, BASE 대비 2개 이상 연도 증가 및 2026년 증가. 실제 운영 승격은 별도 결정이며 자동 교체하지 않는다.
- 보정 표본 수, 이력 0회 예측/실제 확률·Brier, 선택 변경 경주, 분기별 결과를 함께 공개한다. 새 미사용 검증으로 표현하지 않는다.

## 능력값·주행심사 진단

- 평가 기간의 이력 0회 말 기본 Elo·거리 Elo·불확실성 값, 같은 경주 유경험 말 Elo와의 차이를 확인한다.
- 주행심사 입력의 유효 기록 관측률, 결측 처리 및 실제 모델 사용 여부를 확인한다. 이력 0회 말의 관측/미관측별 예측과 실제 입상을 비교한다.
- 기존 연간 순위 모델의 입력 기여도에서 Elo 계열과 trial 계열을 확인한다. 이는 모델 내부 설명이며 실제 성적의 인과관계가 아니다.
- 원천 데이터·기존 번들 불변, 시간 경계, 예측 재현, 보정 계산 및 선택 집계를 검증한다. 결과·검증·후속 계획을 새 보고서와 평가 이력에 남긴다.
