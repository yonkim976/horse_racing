# 더러브렛 경주 분석 방식과 모델 반영 가설

작성: 2026-09-28 · 범위: 사용자와의 대화에서 정리한 서울·부산 더러브렛 분석 방식

이 문서는 **사용자님의 관찰·해석·가설을 다시 꺼내 볼 수 있게 보존하는 메모**다. 여기 적힌 판단이 이미 검증되었거나 운영 예측 모델에 적용되었다는 뜻은 아니다. 모델 상태에 관한 설명은 2026-09-25까지 완료된 A/B/C 더러브렛 연구를 기준으로 한다. 다른 모델 계열이나 이후 연구의 채택 상태는 별도 기록에서 확인한다.

## 1. 사람이 경주를 분석하는 흐름

사람은 경험으로 쌓은 직관을 이용해 여러 전개를 상상하고, 자료와 영상을 근거로 그 판단을 수정한다. 분석자마다 판단 기준은 다르다. 아래는 사용자님의 방법과 접한 전문가들의 견해를 합쳐 정리한 순서다.

| 단계 | 확인할 내용 | 답하려는 질문 |
|---|---|---|
| 경주 파악 | 경주 종류·거리·등급, 출전 두수와 말, 게이트, 기수, 편성의 상대 수준 | 어떤 능력이 필요한 경주인가? |
| 과거 능력 | 각 말의 착순·최종 기록, 같은 거리 경험, 출발 200m와 마지막 600m·200m 기록, 상대 수준 | 성적과 기록이 말의 실제 능력을 얼마나 보여주는가? |
| 주행 성향 | 선행·선입·추입, 초반 위치, 끝걸음, 거리 변화에 따른 양상 | 원하는 방식으로 달릴 때 얼마나 잘 뛰는가? |
| 준비 상태 | 최근 출전 주기, 조교 횟수·담당자·영상, 부상·진료 이력과 이후의 회복 기간·출전 | 과거 능력을 이번에 발휘할 준비가 됐는가? |
| 직전 경주 재해석 | 당시 주로, 출발, 게이트, 선행 실패, 코너 외곽 주행, 진로 막힘, 접촉·모래 반응, 직선의 걸음과 채찍 반응 | 착순보다 능력이 좋은 말인가, 아니면 편한 경주를 하고도 한계가 드러났는가? |
| 이번 경주 전개 | 선행 경쟁, 게이트×거리×주로, 기수의 기승 성향, 예상 위치·경주 흐름, 부담중량 변화 | 어떤 말이 유리한 주행 위치와 흐름을 얻는가? |
| 실전 이력 부족 | 신마의 혈통, 조교·주행심사 기록과 영상, 출발 악벽·선행/추입 가능성 | 직접 경주 기록이 부족할 때 어떤 근거가 있는가? |
| 관계자 변화 | 마방·조교사 이동, 마주와 마방의 기수 선택, 마방의 최근 성적 | 이번 출전을 평소와 다르게 준비했다는 신호가 있는가? |
| 당일 재점검 | 실제 마체중과 변화, 확정 기수·출전 변경, 예시장·주로 입장 모습, 당일 주로 | 출마표를 처음 봤을 때의 판단을 바꿀 정보가 생겼는가? |
| 최종 판단 | 가능한 전개를 몇 가지로 나누고 각 말의 능력·조건을 다시 비교 | 한 가지 전개가 빗나가면 결론도 바뀌는가? |

## 2. 과거 경주를 다시 읽는 기준

착순과 기록을 그대로 능력으로 간주하지 않는다. **실제로 관찰한 일 → 그것이 기록에 미쳤을 가능성 → 이번 경주에서 달라질 조건**의 순서로 생각한다.

| 관찰 가능한 일 | 가능한 해석 | 이번 경주에서 확인할 점 |
|---|---|---|
| 출발이 늦거나 선행 자리를 잃었다 | 원래 강점인 전개를 못 했을 수 있다 | 출발 악벽의 반복 여부, 이번 게이트와 선행 경쟁 |
| 코너에서 외곽을 돌거나 말 사이에 갇혔다 | 거리 손해 또는 가속 기회 상실이 있었을 수 있다 | 비슷한 상황이 재현될 가능성 |
| 모래 반응·접촉·진로 방해가 보였다 | 당시 기록을 낮게 평가하면 능력을 과소평가할 수 있다 | 사건의 근거 영상·공식 기록과 반복 여부 |
| 채찍에 반응해 다시 갔거나, 거의 쓰지 않고도 여유 있게 달렸다 | 최종 착순에 드러나지 않은 여력이 있을 수 있다 | 보는 사람마다 판정이 같은지, 이후 기록이 뒷받침하는지 |
| 충분히 편한 전개에서 전력을 다했으나 마지막 걸음이 둔했다 | 능력·거리·체력의 한계일 수 있다 | 상대 수준과 당시 경주 흐름을 감안해도 같은 결론인지 |

**포화·불량 주로에서 기록이 더 빨라질 수 있다**는 사용자님의 관찰은 중요한 가설이다. 고정된 초 단위 가산·감점으로 쓰기 전에 서울/부산, 거리, 함수율·주로 상태, 같은 날 다른 경주의 기록으로 실제 빠르기를 비교한다. 주로 표기만으로 날짜별·시간별 기록 변화를 모두 설명할 수 있다고 가정하지 않는다.

영상 판단도 `출발 지연을 봤다`처럼 확인 가능한 사실과 `다음에는 더 뛸 것이다`라는 추론을 구분한다. 특히 **채찍을 적게 썼다 = 능력이 남았다**, **체중이 적정 범위로 돌아왔다 = 컨디션이 좋다**, **부상 후 시간이 지났다 = 회복됐다**는 자동 결론이 아니다.

## 3. 편성과 사람의 역할

전개를 한 가지로 고정하지 않는다. 예를 들어 `선행 경쟁이 적은 흐름`, `여러 말이 초반에 다투는 흐름`, `게이트 때문에 주력마가 예상보다 뒤로 밀리는 흐름`을 구분해 각 말의 유불리를 다시 평가한다. 기수는 전체 성적뿐 아니라 **그 말의 각질과 맞는 기승 방식**을 본다. 초반 위치를 적극적으로 확보하는지, 직선에서 추입을 이끌어 내는지, 다리바꿈과 주행 정리를 잘하는지 등이 사용자가 관찰한 세부 판단 요소다.

사용자님의 추가 가설은 다음과 같다.

- **마방·조교사 이동:** 새 환경이나 조교 방식이 말의 능력 발휘를 바꿀 수 있다. 이동 전후의 조교·출전·기록을 함께 비교한다.
- **마주·마방의 기수 선택:** 평소보다 좋은 기수를 기승시키는 일이 이번 출전을 중시하는 신호일 수 있다. 그 말의 평소 기수, 새 기수의 해당 각질 적합성, 기존 기수가 기승할 수 없었던 사정 등을 구분한다.
- **마방의 성적 필요:** 최근 성적과 상황에 따라 특정 말의 준비에 집중할 수 있다. 실제 준비·기수 선택·출전 변화가 관찰되는지 살핀다.

`승부를 건다` 또는 `성적이 급하다`는 **직접 관측할 수 없는 의도에 관한 가설**이다. 기수의 이름이나 마방의 최근 부진만으로 확정하지 않는다. 대안 설명과 실제 예측 증분을 확인해야 한다.

## 4. 신마와 당일 정보

신마는 실전 기록이 적으므로 혈통, 조교·주행심사 영상과 기록, 게이트 진입·출발 행동, 구간별 걸음, 상대 말의 수준을 같이 본다. 혈통이 좋다는 평가는 가능성에 관한 사전 정보일 수 있으나 확정 능력으로 취급하지 않는다. 주행심사는 합격 기록 외에 출발과 주행 상태도 확인한다.

조교 영상은 강도와 횟수뿐 아니라 **그 말에게 적합한 준비였는지**가 문제다. 사용자는 조교 영상을 직접 평가하는 기준과 예시장·주로 입장 때 좋은 상태를 판별하는 기준을 아직 확립하지 않았다고 명시했다. 이 항목은 당장 주관적 가중치를 주기보다 관찰 기준과 판정 일치도를 먼저 만드는 편이 낫다.

당일 마체중·기수·출전 변경·주로는 마지막 점검 항목이다. 출마표를 만들 때 알 수 있던 정보와 당일 뒤늦게 나온 정보를 구분해서 기록해야 과거 경주를 재현할 때 미래 정보가 섞이지 않는다.

## 6. 현재 연구 모델과의 연결

이 대화에서 기준으로 삼은 더러브렛 연구 모델은 A(`한 말의 3위 이내 입상`)는 v5 반기 모델, B(`순서 없는 입상 세 말`)·C(`정확한 1→2→3착`)는 v4 조합 모델과 기존 순서축을 유지했다. [v13 연구 결과](../data/research/thoroughbred_seed_ensemble_20260925_v13/REPORT.md)에서는 같은 학습법의 세 난수값을 평균한 후보가 확률 오차를 줄였으나 공통 채택 조건을 통과하지 못했다. 이는 **이 연구 계열의 선택 상태**이며 운영 예측 시스템 전체의 모델 목록을 뜻하지 않는다.

| 사용자님의 분석 요소 | 이 연구 계열에서 확인한 상태 |
|---|---|
| 최근 성적, 보정 기록, 상대 수준, 거리·게이트, 휴양 간격, 부담중량, 기수 식별·교체, 기본 전개와 선행 경쟁 | 기준 110개 변수에 포함되거나 그 요약값으로 일부 반영. [변수 목록](../data/research/thoroughbred_followup_20260918_v4/model/candidate_features.json) 확인 필요. |
| 말별 적정체중·거리별 참고범위, 변화 기간과 휴양, 체중·기록의 동시 변화 | [v8 체중 연구](../data/research/thoroughbred_weight_20260919_v8/REPORT.md)와 [v9 체중 맥락 연구](research_archive/source/thoroughbred_weight_context_20260920_v9/REPORT.md)에서 시험했으나 기준 모델에는 채택되지 않음. |
| 출발 지연·막힘·접촉·모래 반응 등 사건 | 심판 보고서에서 일부 사건을 후향적으로 추출했지만 공개 시점 검증 등의 제약이 있어 기준 모델의 직접 변수로 확정하지 않음. [추출 감사](research_archive/source/thoroughbred_followup_20260918_v4/steward/REPORT.md). |
| 조교·진료·주행심사 영상, 채찍 반응, 마방 이동과 승부 의도, 예시장 상태 | 이 연구의 기준 110개 변수에서 사용자가 설명한 세부 판단까지 직접 구현한 것은 아님. 원천 자료 존재 여부, 공개 시점, 관찰 기준과 효과 검증을 각각 확인해야 함. |

현재 B는 각 말의 입상 점수를 세 마리씩 더해 조합을 평가한다. 따라서 **세 말이 동시에 선행을 고집해 서로 방해하는 상황처럼 조합 자체에 생기는 효과**를 별도 항목으로 직접 학습하지는 않는다. 현재 C의 오답 중 대부분이 순서 이전에 세 말 선택부터 틀렸다는 [v13 오류 분해](../data/research/thoroughbred_seed_ensemble_20260925_v13/REPORT.md)도 조합 선택을 우선 연구할 근거다. 단, 과거 자료를 반복 검토한 결과이므로 새 자료의 성능을 보장하지 않는다.

## 7. 모델에 반영할 때의 실험 원칙

1. **판단을 작게 나눈다.** `직전 경주 불리함`, `그 뒤에도 유지된 속도`, `이번 경주에서 불리함이 줄어드는 조건`을 한 문장짜리 주관적 점수로 합치지 않는다.
2. **관찰과 추론을 별도로 저장한다.** `코너에서 외곽을 돌았다`는 영상 관찰이고, `다음에는 능력을 더 발휘한다`는 검증할 가설이다.
3. **사용 가능 시점을 확인한다.** 과거 결과·심판 보고·진료·조교·당일 마체중 등이 실제 예측 시점 전에 공개되었는지 확인한다. 수집 시각과 최초 공개 시각도 구분한다.
4. **개별 가설을 기존 모델과 같은 경주에서 비교한다.** 먼저 기존 모델 + 한 변수군을 기존 모델과 비교하고, 개선이 반복되면 다른 가설과의 결합을 별도 실험한다. 변수만 늘리거나 입력 숫자를 배로 키우는 것은 원하는 판단 비중을 보장하지 않는다.
5. **목표별로 검증한다.** A 한 말의 입상, B 입상 세 말, C 정확한 착순의 적중과 확률 오차를 함께 본다. 서울·부산·연도·신마·휴양 복귀 등의 결과도 확인하고, 나중에 잘 나온 집단만 골라 채택하지 않는다.

## 8. 말별 분석 메모 양식

한 경주에 여러 말이 있어도 아래 항목을 같은 기준으로 적으면, 경주 후 자신의 판단을 다시 검토하기 쉽다.

```text
경주 / 일시 / 경마장 / 거리 / 출전 두수:
말 / 게이트 / 확정 기수 / 마방·조교사 / 마주:
기준 시각: 출마표 분석 시점 ____ / 당일 갱신 시점 ____

기본 능력: 최근 착순·보정 기록·동일 거리·상대 수준
구간과 각질: 출발 200m / 마지막 600m·200m / 선행·선입·추입
직전 경주에서 직접 확인한 일: 출발 __ / 위치 __ / 코너 __ /
  막힘·접촉·모래 반응 __ / 직선 걸음·채찍 반응 __
그 일에 대한 해석과 대안 설명:
출전 간격·조교·진료·회복 관련 근거:
게이트×거리×주로 및 이번 편성의 선행 경쟁:
기수의 변경·기승 스타일 / 마방 이동·기수 선택의 변화:
마체중 / 주행심사·혈통·예시장 (해당하면):

가능한 전개 1: ____  유리한 말: ____  근거: ____
가능한 전개 2: ____  유리한 말: ____  근거: ____
결론을 바꿀 당일 정보:
근거가 약하거나 확인하지 못한 항목:
경주 후 확인: 맞았던 관찰 / 틀렸던 해석 / 다음에 수정할 기준
```

이 문서는 분석 방법과 연구 가설을 보존한다. 개별 경주의 확률, 승부 의도, 부상 회복이나 미래 성능을 확정하는 자료로 사용하지 않는다.
