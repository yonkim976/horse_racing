# 오프라인 경마 예상지 V1 — 편집·제작 초안

작성일: 2026-09-13. 이 문서는 실제 예상을 발행한 것이 아니라, 인쇄물의 내용과 지면 계약을 정의한 기획안이다.

## 결론

기존 예상지의 **정보 항목과 익숙한 탐색법**은 유지하되, 읽는 흐름은 새로 설계한다. 독자는 종합예상표에서 경주를 찾고 → 해당 경주의 한눈 요약을 보고 → 모든 출전마의 찬성·반대 근거를 확인하고 → 필요하면 당일 정정 사항을 확인한다. 별표와 번호만 크고 이유가 뒤섞인 판형은 그대로 복제하지 않는다.

### 시장에서 이미 제공되는 것

- 명승부의 공식 ‘예상지 보는 법’은 종합예상표, 주행습관, 베팅전략, 기본 출마표, 최근 성적·기록, 훈련, 상금·마주·기수, 상대전적, 개별 마필 분석 등 17개 항목을 설명한다. 따라서 기본 데이터의 존재 자체는 차별점이 아니다. [출처](https://www.okrace.co.kr/okrace_help/race_doc_help9.php)
- 코리아레이스의 PDF 판매 목록에는 ‘큰 글자’, ‘확률’, ‘삼복승 전문’, ‘전개’ 등을 이미 내세우는 예상지가 있다. 우리 메시지는 단순한 ‘AI 확률’이나 ‘보기 쉬움’에 머물러서는 안 된다. [출처](https://gam.korearace.com/Material/PDF/default.asp)
- 한국마사회 공식 출전표는 기본 출전 정보의 기준으로 삼는다. 원천 표기와 수정 시각을 유지한다. [출처](https://board.kra.co.kr/board/viewBoard.do?boardNo=68)

## 독자에게 하는 약속

1. **한 경주를 두 페이지에서 끝낸다.** 승부의 핵심과 모든 출전마의 이유를 펼친 면에서 읽는다.
2. **모든 말에 같은 질문을 적용한다.** 유리한 점, 불리한 점, 승부가 뒤집히는 조건을 누락 없이 쓴다. 하위권 말도 설명한다.
3. **예상 순위와 베팅 판단을 분리한다.** 우승확률이 높다는 사실이 곧 배당상 유리한 선택이라는 뜻은 아니다. 인쇄 시점에 실제 배당이 없으면 가치판단을 확정하지 않는다.
4. **모르면 모른다고 쓴다.** 신마, 장기휴양, 구간기록 부재 등은 ‘자료 부족’으로 표시한다. 근거 없는 조교평·현장 정보는 쓰지 않는다.
5. **발행 시점을 명시한다.** ‘목요일 ○○시 자료 기준’과 모델 버전을 각 경주에 찍는다. 출전취소·기수변경 등은 당일 정정표와 QR로 확인하도록 한다. QR이 없어도 지면 본문만으로 분석을 이해할 수 있어야 한다.

## 독자가 보는 순서와 필수 내용

| 위치 | 넣을 것 | 편집 원칙 |
|---|---|---|
| 표지·1쪽 | 발행일, 적용 경마일, 경마장, 수록 경주, 발행 기준시각, 정정 확인 QR | 전날 자료와 당일 확정 자료를 혼동하지 않게 한다. |
| 앞쪽 1~2쪽 | 전체 경주 색인: 시간·경마장·거리·출전두수·중심마·혼전도·해당 페이지 | ‘강승부’ 같은 표현보다 경주가 얼마나 열린 판인지 설명한다. |
| 각 경주 펼침면 왼쪽 | 경주 조건, 출전마 전체 표, 우승/2착권/3착권 예측확률, 전개 지도, 상위 후보와 경계 대상, 이 경주의 핵심 변수 | ★ ◎ ○ △ ※ 등 기존 기호를 보조적으로 쓰되 범례를 고정한다. 순위와 확률은 별도 열로 둔다. |
| 각 경주 펼침면 오른쪽 | 모든 말의 개별 카드, 최근 경주 해석, 이번 조건의 유리·불리, 불확실성, 메모 여백 | 10~12두라면 1두당 4~5줄을 기본으로 한다. 말번호순으로 배열해 찾기 쉽게 한다. |
| 끝쪽 1~2쪽 | 기호·지표 읽는 법, 확률의 뜻, 인쇄 후 변경 확인법, 발행 정보·정정 이력 안내 | 모델 검증 수치가 있으면 표본·기간·버전을 함께 명시한다. |

### 출전마 한 장 카드의 고정 형식

`말번호·마명 | 기수·부담중량·게이트 | 모델 순위·우승확률·2착권 확률·3착권 확률`

- **최근 모습:** 직전 1~3전의 성적을 단순 착순이 아니라 거리·주로·전개·상대 수준과 함께 짧게 해석한다.
- **이번에 유리한 점:** 거리 적성, 전개, 게이트, 부담중량, 기수 조합 등 확인된 근거 중 가장 중요한 한 가지.
- **이번에 불리한 점:** 선행 경합, 거리 첫 도전, 기록 표본 부족, 휴양 복귀 등 가장 중요한 반대 근거 한 가지.
- **승부 조건:** 어떤 전개가 나오면 상향 또는 하향 평가될지 한 문장.
- **자료 상태:** 표본 수와 결측을 표시한다. ‘조교 좋음’처럼 출처나 수치가 없는 문장은 허용하지 않는다.

예시 문구(실제 말·실제 확률 아님): “최근 두 번은 초반 선두 다툼으로 막판 둔화. 이번에는 빠른 선행마가 세 마리라 같은 위험이 있다. 중간에 자리를 잡으면 직선 탄력은 유지할 수 있으나, 동일 거리 기록은 한 번뿐이다.”

## 한 경주 펼침면의 지면 골격

```text
왼쪽:  서울 4R | 1200m | 11:40 | 국6 | 11두 | 기준: 목 17:00
        경주 한 줄 판단: 선행 경쟁이 많은 편, 초반 300m가 관건

        말번호  마명      예상기호  우승%  2착권%  3착권%  각질  핵심 한 줄
          1    [마명]      △       --      --       --    선입  [한 줄]
          2    [마명]      ★       --      --       --    선행  [한 줄]
          …    모든 출전마를 말번호순으로 기재

        예상 전개: 초반 선행 후보 → 코너 진입 → 직선 유리마
        예상이 틀릴 조건: [주로 변화/선행 경합 부재/출전취소 등]

오른쪽:  1번 [마명]  ─ 최근 모습 / 유리 / 불리 / 승부 조건
          2번 [마명]  ─ 최근 모습 / 유리 / 불리 / 승부 조건
          … 모든 출전마. 하위권도 동일한 형식과 최소 공간 보장
          하단: 당일 변경 확인 QR + 발행 버전 + 독자 메모란
```

기호는 확률 순위의 **빠른 탐색 보조**다. 예컨대 ★ 1순위, ◎ 2순위, ○ 3순위, △ 4순위, ※ 5순위로 고정한다. ‘복병’은 확률 순위와 다른 개념이므로 별도 테두리/문구로 표시하되, 운영 검증 전에는 배당 가치가 입증된 추천처럼 쓰지 않는다. 사용자가 보여준 기존 지면의 `★ 2 / ◎ 8 / ○ 3 / △ 5 / ※ 4`처럼 읽을 수 있게 하면서, 옆에 수치와 이유를 붙이는 방식이다.

## 인쇄 시점과 데이터 계약

| 항목 | 목요일 인쇄에서의 처리 |
|---|---|
| 확정 출전마·게이트·기수·부담중량·경주 조건 | 인쇄 직전 공식 출전표와 대조. 아직 미확정이면 미확정으로 표기. |
| 과거 성적·구간기록·거리 적성·기수/조교사 이력 | 기준시각 이전에 확인된 공식 자료만 사용. 신마나 누락은 표본 수 표시. |
| 조교·진료·장구 | 데이터 수집·검증된 범위만 표시. 정성 평가 문장은 근거 확인 후 작성. |
| 당일 마체중·주로·실제 배당·늦은 변경 | 목요일 지면에 미래 사실로 쓰지 않음. 당일 정정표/웹에서 시각과 함께 제공. |
| 모델 우승·2착권·3착권 확률 | 발행시각 기준 버전을 고정하고 경주별 합계와 관계를 검증. 실제 prospective 발행 원장과 연결. |
| 베팅 조합·기대 환수율 | 인쇄 시점의 실제 배당이 없거나 전략 검증이 연구 단계면 확정 추천·예상 수익 표현 제외. |

## 페이지 수와 2,000원 가격의 관계

모든 경주를 펼침면 2쪽씩 주고 표지·색인·범례 등 4쪽을 더하면 `4 + 2 × 경주 수`쪽이다. 16경주면 36쪽, 17경주면 38쪽이므로 중철 4쪽 단위로는 보통 36쪽 또는 40쪽 판형을 검토한다. 17경주라면 40쪽이 자연스럽다. 10~12두 × 16~17경주는 160~204개 말 카드다. 각 말에 긴 문단을 주면 이 페이지 수를 넘어간다. 2,000원 판매에 적합한지 여부는 판형(A4/B5), 흑백/2도, 용지, 인쇄부수, 중철·배송·판매수수료별 **실제 견적**으로 결정한다. 내용 요구 때문에 본문 글씨를 작게 줄이지 않는다.

검토할 제작안:

1. **풀 버전:** 모든 경주 2쪽, 36~40쪽. 사용자 경험은 가장 좋지만 소량 인쇄 원가가 부담일 수 있다.
2. **파일럿:** 모든 경주 1쪽 요약 + 중요 경주만 추가 1쪽, 24~28쪽 범위. 단, 모든 말의 ‘자세한 분석’ 약속을 충족하는지 독자 테스트가 필요하다.
3. **경마장별 분권:** 서울/부경/제주 등 경마일의 실제 경주 구성에 맞춰 별도 상품. 물류·재고가 늘어나므로 수요 확인 뒤 결정한다.

최초 파일럿은 풀 버전에서 임의의 한 경주를 실제 데이터로 조판해 가독성을 테스트하고, 같은 사양으로 36/40쪽 견적을 각각 받는다. 원가가 맞지 않으면 가격, 범위, 판형 중 하나를 조정한다. ‘자세한 분석’과 ‘2,000원’을 모두 확정 조건으로 두고 폰트만 줄이는 선택은 하지 않는다.

## 제작 검수 게이트

1. 출전마 명단·말번호·기수·경주 조건과 공식 출전표가 일치한다.
2. 말별 예측확률은 발행 원장에 기록된 동일 버전이며 숫자 반올림 오차를 제외한 합계가 맞는다.
3. 모든 출전마에 유리·불리 근거가 있고, 같은 문장 반복·서로 모순된 문구가 없다.
4. 데이터가 없는 항목에 추정 표현을 사실처럼 쓰지 않는다.
5. 발행 기준시각과 당일 정정 경로가 표지와 각 경주에 있다.
6. 실제 크기로 인쇄해 9pt 안팎의 본문과 표의 말번호가 읽히는지 5명 이상에게 확인한다.
7. 파일럿 판매 후 독자에게 ‘경주 찾는 시간’, ‘하위권 말 정보의 충분함’, ‘두 페이지를 다 읽는지’를 묻는다.
