# 미분류 조교사 상태 사전 분류 — 2026-09-29

## 범위와 주의

로컬 운영 SQLite와 Supabase `horse-racing-prod`에서 공식 현역 관측(`trainer_affiliation_snapshots`)과 공식 종료 지역 관측(`trainer_historical_regions`)이 없는 `trainers` 행은 모두 **436개**다. 이는 436명이 아니다. `text:trainer:*` 임시 ID 434개와 인물이 아닌 `휴양마(0AAAAA)`·`외부마(0BBBBB)` 자리표시자 2개다. 한 인물에 여러 임시 ID가 있을 수 있다. 이번 작업은 **읽기 전용 사전 분류**이며 양쪽 운영 DB의 상태값·출전행·원천 파일은 변경하지 않았다.

공식 현역 API [한국마사회 현역조교사](https://www.data.go.kr/data/15089698/openapi.do)를 2026-09-29 16:22 KST에 별도로 조회했다. 서울 39, 제주 18, 부경 28개, 합계 85개다. API 응답에는 공식 조교사 번호 `trNo`가 없으므로, 2026-09-29 보존 [조교사 정보 API](https://www.data.go.kr/data/15130588/openapi.do)의 `(경마장, 이름, 소속조)`와 대조해 공식 번호를 연결했다. 그 조합은 이번 응답에서 중복되지 않았다. 현역 API 응답 SHA-256은 서울 `c70334c7683302b927a90b49ee61682aa71bba516983c6ced636c98321cbca15`, 제주 `0450689bdcff4c72430ee1afd107a68834cff5bb2ac284ae2c9fb983a38f9eba`, 부경 `b30c867819d21cdd271dda6e0efbbf5c235203b646907b75c0cb6f2255c27aa0`이다. 이 응답 원문은 저장하지 않았으므로, 해시와 건수는 조회 시점의 증거이며 나중에 원문 재생은 불가능하다.

보존 조교사 정보 API 및 KRA 웹 현역 명단에는 **88개**가 있다. 현역 API의 85개는 그 부분집합이다. 서울의 `구자흥(070157·7조)`, `김윤섭(070103·32조)`, `최용구(070168·8조)` 세 명이 현역 API에는 없지만, 2026-09-29 조교사 정보 API에서 종료일 `-`이고 당일 조회한 KRA 현역 웹 명단에도 있다. 따라서 이 세 번호는 은퇴로 전환하지 않고 `현역 자료 간 불일치`로 둔다.

서울·부경 임시 ID 후보는 `docs/research_archive/source/seoul_text_id_linkage_20260915_v1/candidate_evidence.csv`와 `docs/research_archive/source/busan_temp_id_linkage_20260915/candidate_evidence.csv`를 사용했다. 제주 6개 임시 ID는 현재 운영 출전행과 보존 제주 공식 연구 DB의 `(경주일, 경주번호, 출전번호, 말 공식 ID)`가 **8,415/8,415행 일치**했고, 각 임시 ID에 공식 `trNo`가 한 종류씩 관측됐다. 앞서 확정한 푸른장군 4행의 운영 연결 정정 후의 수치다. 과거 서울·부경 공식 결과 API 원본 전체는 현재 보존돼 있지 않으므로, 그곳의 임시 ID 연결은 보존·해시 검증된 대조 산출물 기반임을 유지한다.

특히 현역 API 쪽 141행은 **현역 조교사 141명**이 아니라, 공식 번호 38개에 매달린 Text 임시 ID다. 은퇴 쪽 222행도 공식 번호 60개와 연결된 임시 ID다. 운영 반영 시에는 별도 인물을 새로 만들거나 출전 원문을 지우지 말고, 임시 ID에서 공식 번호·인물로 가는 검증된 연결을 사용해야 한다.

## 판단 또는 추가 확인이 필요한 예외

1. **현역 자료 우선순위 — 공식 번호 3개/임시 ID 14개.** `구자흥`, `김윤섭`, `최용구`는 현역 API에서만 빠지고 KRA 웹 현역 명단 및 공식 조교사 정보 API에는 남아 있다. 권장 임시 상태는 `active_source_conflict`다. 사용자 결정 또는 KRA 정정 전에는 은퇴로 표시하지 않는다.
2. **이름이 다른 현역 번호 후보 — 공식 번호 2개/임시 ID 11개.** 보존 경주행 후보는 `070167 이신우`에 Text의 `이신영` 계열 5개(2,239 출전행), `070133 윤영훈`에 Text의 `윤영귀·윤주혁` 계열 6개(1,335 출전행)를 연결한다. 특히 `070133`은 이름이 여러 형태이므로 일괄 병합 금지다. `이신영→이신우`는 이름 변경 보도와 일부 KRA 경주 문서가 있지만, 운영 DB 신원 변경에는 공식 번호별 과거 원문 대조 또는 사용자 확인을 권한다.
3. **종료일은 있지만 은퇴 명단 제외 — 임시 ID 54개.** 모두 20경주 미만이라 명단 제외 기준에 부합한다. `국내 등록·방문 종료`라는 사실은 확인되지만 직업상 은퇴 여부는 별개다. 권장 표시명은 `활동 종료(은퇴 미확인)`이며, `초청·해외`는 별도 근거가 있는 경우에만 붙인다.
4. **자리표시자 2개.** 인물 레코드로 집계하지 않는다. 출전행 참조가 있어서 단순 삭제도 하지 않는다.

따라서 UI용 대분류를 만들더라도 `현역`, `은퇴확정`, `활동 종료·은퇴 미확인`, `출처 불일치/신원 보류`, `인물 아님`을 구별하는 것이 안전하다. 특히 `현역 API에 없음`은 `은퇴확정`과 동의어가 아니다.
