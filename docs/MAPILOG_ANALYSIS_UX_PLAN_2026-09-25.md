# Mapilog 분석 UX 평가와 개선 계획 (2026-09-25)

## 목표

사용자는 지금 한국마사회 홈페이지에서 출마표, 과거 성적, 주행심사, 조교, 영상을 페이지마다 옮겨 다니며 보고,
자기 엑셀에 옮겨 적어 표시한다. Mapilog는 이 데이터를 미리 묶어 **엑셀·태블로처럼 데이터와 분석 양식이 채워진 화면**을
제공하고, 이후에는 사용자가 자기 표시·메모·보기를 저장하는 곳이 된다. 톤은 지금처럼 깔끔하고 현대적이며 부드럽게 유지한다.

미래 예측, 예측 검증, 거리별 분석 페이지는 제거 예정이므로 설계 대상에서 뺐다.

## 현재 디자인 평가

### 잘된 점

- **토큰 체계가 일관적이다.** 라이트·다크 두 테마가 같은 변수 이름(`--surface-*`, `--accent`, `--muted`)을 공유하고,
  Pretendard(한글)와 JetBrains Mono(기록·배당) 조합이 숫자 많은 화면을 정돈해 준다.
- **부드러운 인상이 이미 있다.** 18px 둥근 패널, 옅은 그림자, 초록→라임 활성 알약, 초록 그라데이션 요약 카드,
  배경의 옅은 원형 광원이 딱딱하지 않은 분위기를 만든다. 유지할 자산이다.
- **모바일 홈의 마번 색 포스터 카드가 독창적이다.** 마사회 새들클로스 색을 그대로 써서 말을 번호·색으로 바로 찾을 수 있고,
  라운드 점프 칩과 `전력 구도` 요약이 모바일에서 훑어보기 좋다.
- **데이터 자체는 이미 풍부하다.** 데스크톱 `/analysis`에 과거 경주, 주행심사, 조교, 기수, 구간기록(S1F/G3F/G1F),
  영상 링크, 비교 체크, 메모, CSV까지 있다. 부족한 것은 데이터가 아니라 배치다.

### 문제점

1. **데스크톱 경주 분석이 세로로 긴 패널 나열이다.** 트랙 애니메이션(화면 높이 대부분), 모델 예측 표, 현재 출전마 표,
   말별 기록이 위아래로 이어져 있다. 같은 11두가 범례, 모델 표, 출전마 표, 좌측 말 목록에 **네 번 반복**되고,
   비교하려면 위아래로 계속 스크롤해야 한다. "한 화면에서 옆으로 비교"라는 목표와 반대 방향이다.
2. **상단 메뉴가 11개다.** 좁은 폭에서는 가로 스크롤로 밀려나고, 핵심인 `경주 분석`이 여러 메뉴 사이에 묻힌다.
3. **빈 값 표기가 잡음이 된다.** `자료 없음`, `—`, `0전 · 승 — · 입상 —`가 행마다 반복돼 읽어야 할 숫자보다 눈에 먼저 띈다.
4. **구간기록을 비교하기 어렵다.** S1F/G3F/G1F 숫자는 있지만 누가 빠른지 색이나 순위로 드러나지 않아
   사용자가 머릿속에서 정렬해야 한다. 엑셀에서 사용자가 하던 조건부 서식이 없다.
5. **모바일 카드의 색이 강하다.** 마번 색을 카드 전체 그라데이션으로 칠해서 흰색·노랑·회색 마번 카드는 글자 대비가 떨어지고,
   카드가 많으면 화면이 과하게 화려해진다.
6. **사용자 소유 영역이 없다.** 표시(◎○▲△✕), 말별 메모, 내 보기 저장이 없고 경주 메모 하나만 브라우저에 저장된다.
   "추후 본인 분석을 갖는 페이지"라는 목표의 뼈대가 아직 없다.
7. **첫 화면이 결과 중심이다.** 데스크톱 홈은 날짜별 결과 표가 중심이라 "다가오는 경주를 분석하러 간다"는 흐름이 약하다.
8. **작은 회색 글자가 많다.** 11~12px 보조 문구가 많아 표가 빽빽해 보이고, mono 폰트가 설명 문구까지 쓰여 소란스럽다.

## 개선 계획

### 0단계 — 정리 (작음)

- 미래 예측, 예측 검증, 거리별 분석 라우트와 메뉴 제거.
- 상단 메뉴 재구성: `경주` · `경주 분석` · `내 분석`(신규) · `말·기수·조교사·마주`(검색 하나로 통합) · `예측 원장` · `데이터`.
- 첫 방문 기본 테마: **라이트로 결정·반영 완료(2026-09-25)**. 저장된 선택이 있으면 그대로 따른다.

결정 사항(2026-09-25): 분석 화면은 A안으로 간다. 모바일은 당분간 현재 버전을 유지한다.

### 0.5단계 — 경주 탭 출마표·기록표 다듬기

현재 `/` 경주 탭 평가:

- 요약 카드 네 장(공식 경주, 주행심사, 공식 출전마, 심사 참가마)이 한 줄을 통째로 쓰는데, 주행심사가 없는 날엔 `0`이 두 장이다.
- 왼쪽 경주 목록이 좁아 `상태`·`우승마` 열이 가로 스크롤 뒤로 잘린다. 1440px에서 오른쪽 출전표의 `연승` 열도 잘린다.
- 같은 표 하나가 경주 전 출마표와 경주 후 결과표를 겸한다. 경주 전에는 기록·착차·배당 열이 비고,
  정작 출마표에서 필요한 최근 성적·장구·진료가 없다.
- 경주 헤더의 진한 초록 배너가 무겁고, 분석으로 넘어가는 버튼이 없다(`구간 · 배당 · 심판`만 있음).
- 경주 상세(`/races/{id}`)는 코스 지도가 먼저 나와서, 결과표가 약 1,500px 아래에 있다.

다듬은 구성(Superdesign 시안 두 장, 같은 틀에 상태만 다름):

- 요약 카드 네 장 → 제목 아래 한 줄 요약(`공식 경주 17 · 출전 185두 · 주행심사 없음`)과 진행 상태.
- 날짜 ‹ › 이동과 경마장 세그먼트(경주 수 표시)를 오른쪽 한 덩어리로.
- 왼쪽 레일: 경주당 두 줄 카드(시간·거리·상태 / 우승마·기록 또는 등급·두수), 임박 경주는 `32분 후`.
- 가벼운 경주 헤더: 작은 경주 배지, 제목·등급, 조건 칩, `분석 시트로 열기`(주 버튼), 영상, 이전·다음 경주.
- 탭: `출마표` · `결과` · `구간기록` · `장구 · 진료` · `배당 · 심판`. 경주 전에는 결과 계열 탭을 `경주 후`로 잠근다.
- **출마표(경주 전)**: 표시(◎○▲△) · 마번·마명 · 최근 5전 칩(1~3착 메달색) · 레이팅 · 부담 · 마체중과 증감(±10kg 강조)
  · 기수 · 조교사 · 장구(BF 강조) · 진료(파행·호흡기 같은 주의 소견만 강조, 나머지는 건수) · 단승 · 메모.
  위에 인사이트 카드 네 장: 인기 순위, 레이팅 상위, 컨디션 체크, 내 표시.
- **결과·기록표(경주 후)**: 착순 메달 · 마번·마명 · 기록 · 착차 · 통과순위 흐름 미니 그래프(S1F-3C-G3F-4C-G1F)
  · 초반 200m / 막판 600m / 막판 200m(빠를수록 진한 초록) · 마체중 · 단승 · 연승 · 내 표시 적중.
  위에 카드 네 장: 결과·배당, 전개 흐름(통과순위 곡선), 막판 600m 빠른 말, 내 표시 결과.

구현 메모: 필요한 값은 대부분 이미 있다. 통과순위와 구간 기록은 `race_page.py`의 구간 표에서, 장구·진료는
`race_detail`의 장구 표에서, 최근 성적은 `PosterHorse.form`에서 온다. 진료 "주의 소견" 분류 규칙과
최근 5전 정렬 기준은 새로 정해야 한다. 시안의 최근 5전 값은 4번 말을 빼면 예시 값이다.

### 1단계 — 분석 시트 (핵심, Superdesign A안)

한 경주 = 한 장의 시트. 세로 패널 나열을 하나의 넓은 표로 합친다.

- 상단 경주 띠: 날짜, 경마장 알약, 1R~11R 칩(시간·종료/예정), 경주 조건과 날씨·함수율.
- 보기 프리셋 탭: `기본` `전개` `컨디션` `기록` `+ 내 보기 저장`.
- 열 묶음 토글: 최근 5전, 동일거리, 구간기록, 주행심사, 조교 28일, 체중 변화, 기수·조교사 승률, 레이팅, 배당.
- 조건부 서식: 구간기록 상위권 초록 농도, 최근 착순 1~3위 메달색, 체중 증감 빨강·파랑.
- 좌측 고정 열(표시, 마번, 마명·기수)과 고정 헤더.
- 행 클릭 시 오른쪽 360px 서랍에 말 상세: 과거 경주 / 주행심사 / 조교 / 기수 탭, 최근 착순·G3F 추이 미니 차트, 영상 버튼.
- 빈 값은 행마다 문구 대신 옅은 점(·)으로, 설명은 열 머리 툴팁 하나로.

현재 `race_analysis.py`가 이미 계산하는 값(과거 경주, 주행심사, 조교 합계, 기수 통계, 구간기록, 레이팅, 체중)만으로
대부분 채울 수 있어 백엔드 변경은 작다. 배당 열은 `odds_snapshots` 연결이 필요하다.

### 2단계 — 내 표시와 메모

- 행마다 신문 예상지식 표시 ◎ ○ ▲ △ ✕ 선택, 말별 한 줄 메모.
- 화면 하단 고정 `내 분석` 바: 고른 표시 요약, 메모, CSV 내보내기, 보기 공유.
- 먼저 브라우저 저장(localStorage)으로 시작하고, 계정이 생기면 Supabase로 동기화.

### 3단계 — 비교와 전개

- 핀 고정한 말 최대 4두를 같은 행 기준으로 정렬해 비교(최근 착순, S1F, G3F, G1F, 주행심사, 조교).
- 트랙 애니메이션은 시트 위 큰 패널에서 `전개` 보기 탭 또는 서랍 안의 작은 전개 지도로 축소.
- 영상은 지금처럼 공식 플레이어 도크로 열되 시트를 가리지 않게.

### 4단계 — 내 보기 저장·공유

- 열 조합·정렬·필터를 이름 붙여 저장(`내 선행마 보기` 등), 경주가 바뀌어도 같은 양식 적용.
- 서식이 유지되는 엑셀/CSV 내보내기, 읽기 전용 공유 링크.
- `내 분석` 페이지에서 날짜별로 내가 표시한 경주와 결과 적중을 모아 보기.

### 5단계 — 모바일 적용

- 같은 개념을 모바일로: 마번 고정 열 + 가로 스크롤 시트, 행 탭 시 하단 시트(bottom sheet)로 말 상세.
- 카드 방식을 유지할 경우 마번 색은 카드 전체 대신 왼쪽 띠와 번호 칩에만 써서 대비 확보.
- 표시 선택은 카드에서 한 번 탭으로.
