# RaceValue V1

RaceValue V1은 RaceFit V5의 순위확률과 예상 시장인기를 분리해 실력 대비 저평가된
복병마를 찾는 연구 모델이다. 현재 상태는 `RESEARCH_ONLY`이다.

## 복병 정의

학습 label은 **실제 단승 인기 4위 이하이면서 3착 이내에 든 말**이다. 최종
단승배당은 이 label과 사후 환수율 정산에만 사용한다. 예측 feature에는
현재 경주의 실제 최종배당, 실제 인기순위, 착순을 넣지 않는다.

## 2단계 구조

1. RaceFit V5로 말별 1·2·3착 확률을 얻는다.
2. 평이한 과거 성적, rating, 기수·조교사 성적, 게이트와 부담중량으로
   예상 시장 단승배당과 인기순위를 만든다.
3. 모델 3~8순위 중 예상 시장인기 4위 이하만 복병 후보로 남긴다.
4. 다음 점수로 적중과 배당의 균형을 조절한다.

```text
sleeper_score = log(P(top3)) + alpha * log(predicted_market_win_odds)
```

`alpha=0`은 적중 중심, alpha가 커질수록 배당 중심이다. alpha는 테스트 결과를
보지 않고 2026-05~06 검증구간에서 선택한다.

## 시간 분할

- 학습: 2026-01-01~2026-03-31
- 확률보정: 2026-04-01~2026-04-30
- 전략선택: 2026-05-01~2026-06-30
- 연구 테스트: 2026-07-01~2026-08-31

2026년은 이미 반복해 분석한 표본이므로 완전한 미래 검증은 아니다.

## 최신 결과

복병 event 확률모델의 성능은 검증 AUC 0.6581, 테스트 AUC 0.6239였다. 확률
평균은 테스트 13.43%, 실제는 13.28%, ECE는 0.0187이었다.

| 테스트 전략 | 적중률 | 복병 label | 평균 적중배당 | ROI | 최고수익 3경주 제거 ROI |
|---|---:|---:|---:|---:|---:|
| 복병 연승 | 24.59% | 18.03% | 3.40 | 83.52% | 74.33% |
| 1순위-복병 복연승 | 12.57% | 18.03% | 6.12 | 76.91% | 62.56% |
| 1·2순위-복병 삼복승 | 3.83% | 18.03% | 20.16 | 77.10% | 49.45% |

기존 모델 3순위 후보와 비교하면 복병 label 비율은 14.48%에서 18.03%로 증가했다.
연승 ROI는 80.30%에서 83.52%, 삼복승 ROI는 62.70%에서 77.10%로 증가했지만
복연승 ROI는 80.82%에서 76.91%로 감소했다.

신뢰점수 상위 10% 복병 연승은 테스트 45경주에서 ROI 101.78%였지만, 최고
수익 3경주를 제거하면 41.67%로 낮아진다. 이 결과는 수익 증거가 아니다.

## 실행

```bash
.venv/bin/python scripts/run_race_value_v1.py
```

산출물은 `data/experiments/race_value_v1/<run_id>/`에 저장된다.

- `model.pkl`: 복병 event 모델과 시장배당 예측모델
- `horse_scores.parquet`: 말별 복병확률과 예상 시장배당
- `validation_candidates.parquet`: 검증기간 선택 후보
- `test_candidates.parquet`: 테스트기간 선택 후보와 정산
- `manifest.json`: 모델 설정과 지표
- `report.md`: 연구 보고서

## 승격 조건

- 테스트 AUC 0.65 이상
- 구매 경주 100개 이상
- 최소 한 승식 ROI 100% 이상
- 해당 승식의 최고수익 3경주 제거 ROI 95% 이상

현재는 조건을 만족하지 못해 `RESEARCH_ONLY`이다.
