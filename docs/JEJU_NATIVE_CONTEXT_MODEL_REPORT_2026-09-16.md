# 제주마 편성·전개·변화 반영 v5 실험 보고서

작성일: 2026-09-16

## 결론

편성·초반 경쟁과 과거 수행 변화 40개 변수를 만들고, 기존 68개 변수와 함께 학습했다. 새 `R_FORM`의 세 마리 선택에 기존 별도 순위 모델을 결합한 `HY_R_FORM`은 2025년 개발 평가 715경주에서 **한 마리 입상 454회(63.50%), 세 마리 집합 일치 57회(7.97%), 정확한 순서 21회(2.94%)**를 기록했다.

기존 비교 후보의 목표별 최고치는 각각 446회·57회·18회였다. 새 결과는 한 마리 입상과 순서 적중에서 더 높고 집합 적중은 동률이다. 그러나 적중률 개선의 짝지은 95% 구간은 0을 포함한다. 새 조합은 후속 검증 후보이며, 실전 우월성이 확정된 운영 모델은 아니다. 100%에 가까워졌다고 해석할 근거도 아직 없다.

## 1. 같은 경주에서 비교한 전체 결과

각 경주에서 한 마리, 세 마리 집합 하나, 순서 하나를 선택한다. 세 마리 중 일부만 맞은 경우를 집합 적중으로 세지 않는다. 공식 동착에는 가능한 정답을 인정한다.

| 모델 | 내용 | 한 마리 입상 | 세 마리 전체 일치 | 정확한 1·2·3위 |
|---|---|---:|---:|---:|
| `M0_H2` | 이전 순서 적중 기준 | 425/715 (59.44%) | 49/715 (6.85%) | 18/715 (2.52%) |
| `P_H3` | 기존 입상 전용 | 445/715 (62.24%) | 52/715 (7.27%) | 14/715 (1.96%) |
| `R_H3` | 기존 순위 모델 | 437/715 (61.12%) | 57/715 (7.97%) | 15/715 (2.10%) |
| `J_H3_w10` | 기존 집합·순서 결합 | 446/715 (62.38%) | 44/715 (6.15%) | 17/715 (2.38%) |
| `R_CTX` | 편성·초반 18개 추가 | 440/715 (61.54%) | 52/715 (7.27%) | 15/715 (2.10%) |
| `R_FORM` | 신규 40개 전체 추가 | 454/715 (63.50%) | 57/715 (7.97%) | 14/715 (1.96%) |
| `HY_R_H3` | 기존 집합 유지 + 별도 순서 | 437/715 (61.12%) | 57/715 (7.97%) | 17/715 (2.38%) |
| `HY_R_FORM` | 신규 집합 + 별도 순서 | 454/715 (63.50%) | 57/715 (7.97%) | 21/715 (2.94%) |

핵심 분리 결과: `R_FORM`만으로는 순서 적중이 14회였다. 같은 말 세 마리를 그대로 둔 채 별도 순위 모델을 적용하면 21회가 됐다. 따라서 입상마를 고르는 능력과 입상마 사이의 순서를 정하는 능력을 별도로 개선할 이유가 있다. 반면 편성 변수만 추가한 `R_CTX`는 집합 적중이 기존 57회에서 52회로 줄었다. 변수의 타당한 해석이 곧 적중률 향상을 보장하지는 않는다.

## 2. 불확실성과 확률의 품질

98개 경주일 또는 715개 경주를 공통으로 5,000회 재표본 추출했다. 아래는 경주일 단위 95% 구간이며, 차이의 단위는 퍼센트포인트다. 여러 개발 비교에 대한 보정은 적용하지 않았으므로 탐색적 결과로 읽어야 한다.

| 비교 | 지표 | 관측 차이 | 95% 구간 |
|---|---|---:|---:|
| HY_R_FORM − J_H3_w10 | 한 마리 입상 | +1.12 | [-1.96, +4.22] |
| HY_R_FORM − R_H3 | 세 마리 집합 | +0.00 | [-2.06, +2.05] |
| HY_R_FORM − M0_H2 | 정확한 순서 | +0.42 | [-1.14, +1.95] |
| HY_R_FORM − R_FORM | 순서 모델 교체 효과 | +0.98 | [-0.28, +2.28] |

입상 확률의 평균 제곱오차(Brier, 낮을수록 좋음)는 기존 `P_H3`의 **0.185874 → 0.183670**, 정확한 순서에 부여한 확률의 손실(NLL, 낮을수록 좋음)은 기존 `J_H3_w10`의 **5.810638 → 5.751719**였다. 이 비교의 경주일 구간은 각각 [-0.003862, -0.000534], [-0.102153, -0.018835]로 개선 신호가 있다. 다만 확률 손실 감소와 최종 선택 적중률 향상은 서로 다른 결과다.

선택한 말의 예측 입상확률이 90% 이상인 경주는 45개(전체의 6.29%)였고, 실제 입상은 38회(84.44%)였다. 따라서 확률 90%라는 출력 자체를 실제 90% 정확도로 보장할 수 없다. 이 필터는 진단용이며 검증된 선택 정책이 아니다. 제한된 경주만 골랐을 때는 적중률과 함께 대상 경주 비율·표본 수·불확실성을 반드시 보고한다.

## 3. 사용자 관점을 어떻게 반영했는가

| 관점 | 이번 구현 | 남은 한계 |
|---|---|---|
| 경쟁마의 강도·편성 | 현재 상대의 전체/거리별 사전 Elo와 최근 3회 상대 강도 비교 | Elo는 과거 대결 결과의 능력 추정치이며 확정 능력값이 아님 |
| 출발 위치·전개 경쟁 | 선언 출주번호의 위치, 낮은/높은 번호 방향의 초반 경쟁마 수 | 물리 게이트와 취소 후 배치는 미확인, 인과적 게이트 효과 미추정 |
| 부담중량·기수 | 현재 선언 중량과 과거 중량 차이, 기수 교체, 기수의 과거 초반 경향 | 당일 교체·감량 공지의 시각별 반영은 후속 |
| 마체중 변화 | 과거 마지막 체중, 직전 두 관측 차이, 최근 3회 추세 | 이번 경주 당일 마체중 증감은 사용하지 않음 |
| 초반·추입 능력 | S1F/G1F 통과순위, 구간 사이 순위 변화, 마지막 200m 상대속도 | GPS 경로, 외곽 주행 거리, 실제 전술 의도는 알 수 없음 |
| 직전 부진·반등 | 낮은 최종 착순과 좋은 막판 속도의 동시 관측, 최근 5회 최고 수행 | 포기·부상·방해의 원인을 확정하지 않음 |
| 발전 가능성 | 최근 3회와 그전 3회의 상대 착순 수행 변화 | 성장 자체의 직접 측정이 아니며 어린 말/장기 휴양은 별도 검증 필요 |
| 날씨·주로 | 과거 명시 함수율별 성적, 같은 과거 경주의 중앙 기록 대비 차이 | 순수 날씨 보정이 아니며 현재 주로·예보는 미사용 |

특히 G1F 통과순위와 최종 200m 구간 속도를 분리했다. 결승 200m 전 앞에 있었다는 사실만으로 마지막 추입력이 좋았다고 표시하지 않는다. 함수율은 정규화 DB 열의 결측을 원문의 `건조 (4%)` 같은 명시 수치로 보완했다. 비가 왔다는 설명만으로 젖은 주로를 임의 생성하지 않았다.

전체 변수는 [현재 변수와 신규 40개 정의](/Users/kimyongjin/Desktop/horse_racing/docs/JEJU_NATIVE_CONTEXT_VARIABLES_2026-09-16.md)에 정리했다. 신규 데이터는 **79,731 출전 행·8,172 경주**, 입력 이름은 `R_CTX` 86개·`R_FORM` 108개다. 결측 표시·시대 구분·상수 제거 이후 실제 학습 열은 각각 112개·154개였다. 과거 습한 주로 성적은 2025년 6,953행 중 6,250행, 건조/양호 묶음 성적은 6,514행에 관측됐다.

## 4. 공개 시점: 수요일 예측과 경주 당일 예측

KRA 제주 출전상세 화면은 출전정보·PDF 공개를 **수요일 15:30**으로 안내한다. [KRA 출전상세정보](https://race.kra.co.kr/chulmainfo/ChulmaDetailInfoList.do?Act=02&Sub=1&meet=2)

자료갱신주기 표는 출전표 **수요일 16:00**, RSS 안내는 제주 **목요일 15:00**으로 서로 다르다. 하나의 시각을 모든 과거 자료에 소급하지 않고 원문별 실제 수집·공지·수정 시각을 기록해야 한다. [KRA 갱신주기](https://race.kra.co.kr/dbdata/renewDBDate.do?Act=12&Sub=2&meet=2), [KRA RSS 안내](https://race.kra.co.kr/raceguide/RaceRssServiceIntro.do)

마체중은 출발 60분 전 장안소 집합 **후 입력**된다고 안내한다. 이는 정확히 60분 전 공개 완료를 뜻하지 않는다. 실제 관측 시각이 확인된 뒤 사용하는 당일 갱신 변수로 분리해야 한다. [KRA 금일출전마체중](https://race.kra.co.kr/raceFastreport/ChuljumaWeightWeight.do?Act=03&Sub=4&meet=2)

기수변경·말취소·주로 상태 역시 경마일 자료이며 변경 화면에는 공지 시각이 있다. [KRA 출전표변경](https://race.kra.co.kr/raceFastreport/ChulmapyoChange.do?Act=03&Sub=1&meet=2)

이번 평가는 T−2까지의 과거 이력과 복원 선언카드를 사용했다. 원문 파일 날짜가 실제 최초 공개·수정 시각을 증명하지 않으며, 평가 필드도 실제 출전마로 확정된 구성이다. 따라서 이번 수치를 **수요일에 이미 알 수 있는 정보만으로 검증된 실전 정확도**라고 부를 수 없다. 취소 전 선언 필드와 시점별 변경 내역을 복원하는 작업이 우선 필요하다.

## 6. 실험·재현 확인

- 사전에 고정한 두 신규 학습 후보 × 4개 시간 분할 × 2개 시드 = 학습 16회. 확률 보정 16회. 기존 기준 모델 재학습 0회.
- FIT 학습, TUNE 반복 수 선택, CAL 확률 보정, EVAL 보고를 분리했다. EVAL 결과를 본 뒤 후보·반복 수를 추가하지 않았다.
- 2025년 715경주·98경주일을 공통 평가했다. 입상자가 4마리가 되는 경계 동착 6경주는 세 자리 주변확률 오차에서 제외해 709경주로 비교했다. 적중 평가에는 포함했다.
- 과거 이력의 T−2 제한, 미래 기수 ID 영향 차단, 구간 속도와 통과순위 구분, 확률 합과 하이브리드 보존 등 관련 테스트 **69개 통과**. 새 파일 Ruff 검사 통과.
- 저장 모델 묶음 **16개**를 다시 불러 독립 실행으로 점수·확률·선택을 재현했다. FIT 전처리 통계도 다시 계산해 일치했다.
- 하이브리드가 원래 모델의 한 마리 선택·세 마리 집합·입상 주변확률을 보존하는 것을 확인했다. `pl_place_probability`라는 기존 열 이름은 하이브리드에서는 결합분포의 세 자리 주변확률을 뜻한다.
- 결과 행은 경주 단위 5,720개, 말 단위 55,624개다. 원본 데이터 및 이전 실험의 해시를 대조했다. 2026년 모델 예측·평가 **0회**.
- 학습 전 초안에서 발견한 미래 이름-ID 연결, 잘못된 막판 위치, 함수율 결측 문제는 수정 후 다시 구축했다. 폐기 초안 두 디렉터리는 감사용으로 보존했고 모델 학습에는 사용하지 않았다.

2025년은 이미 여러 차례 개발에 사용했으므로 새로운 독립 시험이 아니다. 이번 결과를 바탕으로 계속 후보를 고르면 선택 편향이 생길 수 있다. 다음 후보·판정 규칙을 고정한 뒤에만 남겨둔 평가 구간을 열어야 한다.

## 7. 다음 개선 순서

1. **예측 시점부터 확정한다.** 주간 출마표와 경주 직전 업데이트를 분리하고 출전취소·기수변경·마체중·주로의 공지/수집 시각과 원문 수정 이력을 남긴다. 선언 필드와 실제 출전 필드의 차이를 재현한다.
2. **반등과 전개 변수의 원인을 검증한다.** 새 변수 묶음을 편성, 구간 능력, 체중·중량, 성장, 주로로 사전 분리해 어느 묶음이 도움이 되는지 확인한다. 게이트×거리×초반 경쟁, 기수×말의 주행 성향을 표본 수와 함께 분석한다. 이번 결과만으로 특정 변수의 효용을 단정하지 않는다.
3. **순서 모델에도 새 관측을 적용한다.** 이번 하이브리드 순위 모델은 기존 68개 입력을 그대로 썼다. 집합 선택을 보존한 비교 구조를 유지하면서 추입·초반 경쟁·중량 변화가 순서 예측에 추가 기여하는지 검증한다.
4. **심판보고·영상의 관측을 추가한다.** 방해·진로 불리·출발 지연·부상처럼 확인된 사실을 기록한다. ‘포기’나 ‘숨은 의도’를 성적만 보고 라벨링하지 않는다. 영상 의견은 게시일과 발언 시각을 보존한다.
5. **최종 판정 규칙을 고정한다.** 세 목표와 확률 오차, 예측을 제시할 경주 비율, 불확실성 구간을 함께 고정한 뒤 2026년 미사용 구간 또는 이후 전향적 수집 결과로 한 번 검증한다.
