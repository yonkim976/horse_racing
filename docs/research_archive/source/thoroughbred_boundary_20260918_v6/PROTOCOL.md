# v6 기존 자료 내부의 경계마 선택·확률 보정 실험

새 자료를 수집하지 않고 v3 사전 맥락, v4 추가 변수, v5 저장 모델만 읽는다. 운영 DB·모델과 기존 연구를 수정하지 않는다. 2021~2024년 서울/부산은 반복 사용한 개발 외부 평가 구간이고, 2025~2026년 9월 13일까지는 이미 노출된 참고 구간이다. 시계열 분리는 새 후보 내부의 누수를 막지만 기존 연구에서 이 기간을 보았다는 사실을 없애지 않는다.

## 기준선과 고정 후보

- 현재 A: v5 `rolling_all`, 각 반기 저장 모델과 기존 A 보정.
- 현재 B/C: 연간 v4 `top3_growth_strength`의 목표별 보정.
- A 후보 `context_temperature`: 같은 A 점수에 경주별 온도 보정만 적용한다. 출전두수, 점수 표준편차, 최고 두 말의 점수 차이 및 절편의 4개 계수다. 원래 개최지별 온도에 곱하며 CAL에서 말별 이진 로그손실의 경주 평균 + 0.01×계수제곱합/2를 최소화한다. 계수 범위 ±0.5, 최종 온도 0.25~4. 후보마 순위는 변하지 않는다. 영천은 새 보정을 적용하지 않는다.
- B 대조 `fixed60`: 연간 v4 직접 입상 트리의 처음 60개만 사용하고 CAL에서 B 온도를 보정한다.
- B 후보 `global_residual`: `fixed60` 말별 점수에 기존 사전 변수 14개의 선형 보정을 더하고 정확한 3두 조합 로그손실을 직접 최소화한다.
- B 후보 `boundary_residual`: 같은 보정에 원래 점수순위 3 부근의 가중치 exp(-0.5×((순위−3)/1.5)^2)를 곱한다. 상위 두 마리를 강제 고정하지 않고 모든 3두 조합을 허용한다.

보정 변수는 우승 점수, 보정 평균 속도, 속도 잠재력 차이, 직전 속도 변화, Elo, 레이팅, 휴양 로그, 거리 변경 절대값, 과거 출전 수 로그, 거리 경험 로그, 전개 후반 상승(서울만), 직전 대비 누적 성적 변화, 상대 Elo와 현재 편성 차이, 최근 게이트 지수다. 경주 안 순위 백분위로 [-1,1] 변환하고 결측은 중립값 0으로 처리한다. 우승 점수는 v2 트리 처음 100개로 고정한다. 필드의 실현 착순·기록·배당은 입력하지 않는다. 각 세 말의 보정 변수 합으로 조합 에너지를 보정한다. 계수 범위 ±2, 규제 후보 0.01/0.1/1과 보정 없는 0 계수만 허용한다.

## 시간 분리와 안쪽 선택

B는 연간 평가 Y에 대해 FIT에서 이미 학습된 트리의 고정 접두부만 사용한다. 저장된 부모 모델은 이전 Q3에서 60/120 또는 100/200/300회를 선택했으므로 부모의 선택 결과를 안쪽 검증에 노출하지 않기 위해 모든 표본에 입상 60회·우승 100회만 사용한다. 사전 변수 목록 자체와 이전 모델 연구는 이미 노출됐다는 한계를 기록한다.

- 안쪽 학습: Y−1년 Q3의 관측 경주일을 정렬한 뒤 앞 2/3(날짜 수 올림). 같은 날짜 전체를 한쪽에 배정한다. 각 규제 계수를 적합하고 같은 안쪽 학습에서 온도 1개를 적합한다.
- 안쪽 검증: 나머지 마지막 1/3의 경주일. 합산 B 로그손실 최저, 동률이면 강한 규제 순으로 선택한다. 보정 없는 선택은 가장 강한 규제로 취급한다. Q3에 경주일이 3개 미만이면 중단한다. 2020년 9월에 관측 경주가 없어 최초 학습·평가 결과 생성 전에 월 고정안을 이 규칙으로 수정했다.
- 보정 계수 최종 적합: Y−1년 7~9월 전체. 선택된 규제만 사용한다.
- CAL: Y−1년 10~12월. B 온도는 GLOBAL과 서울/부산별로 학습한다(개최지 100경주 미만이면 GLOBAL).
- 외부 평가: Y년. 2021~2024년까지 완료한 뒤 아래 선택을 저장하고 나서 2025~2026년 후보 평가를 실행한다.

A의 기초 점수는 v5 반기 계약을 그대로 따른다. H1은 이전 Q4, H2는 당해 Q2 CAL에서 고정 규제의 4개 보정 계수만 적합하고 다음 반기를 평가한다. A에는 추가 하이퍼파라미터 선택이 없다. CAL과 외부 평가를 분리한다.

## 개발 기준 채택

A는 현재 모델 대비 개발 평균 로그손실과 Brier가 모두 나쁘지 않고 하나 이상 엄격히 개선되어야 한다. 서울/부산 각각 로그손실과 Brier가 별도로 4년 중 3년 이상 나쁘지 않아야 한다. 순위와 최고 선택 적중은 그대로여야 한다. B는 개발 적중률 이상·로그손실 이하(하나 이상 엄격한 개선), 서울/부산 각각 손실/적중이 4년 중 3년 이상 나쁘지 않아야 한다. 적격 B 후보 중 적중률 높은 순·로그손실 낮은 순·이름 순으로 선택한다. 허용오차는 1e-12다. C는 유지한다. 참고 기간을 보고 탈락 후보를 다시 고르지 않는다.

A는 경계 동착을 제외하고 B는 모든 호환 정답 조합의 확률을 합산한다. 취소/실격 등 비입상마를 결과에 따라 임의 제거하지 않는다. 고확률 구간 표본·실제 적중·보정, B의 한 마리 누락·오답 교체는 사후 진단으로 보고한다. 채택한 목표만 기존 9월 17일 보존 출마표의 27경주에 적용하고 완전한 정규화 분포를 검사한다. 개선이 없으면 그 사실을 그대로 기록하며 확률 숫자를 높여 성능 개선으로 표현하지 않는다.
