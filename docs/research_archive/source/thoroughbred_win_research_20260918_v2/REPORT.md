# 더러브렛 우승확률 연구 v2 — 능력·최근 상태·상대 편성

선택 후보는 **H3_relative**다. 2021–2024년 개발 평가와 사전에 고정한 채택 조건으로 선택했고, 선택 파일을 저장한 뒤 2025·2026년 참고 평가를 실행했다. 운영 모델은 승격하지 않았다. 2025–2026년은 이미 과거 연구에서 확인한 자료이므로 새 독립 테스트라고 부르지 않는다.

서울·부경의 동일 경주를 경주 수로 가중한 핵심 비교다. Log loss와 Brier는 낮을수록 좋고, top1 accuracy는 모델 1순위 말이 우승한 비율이다.

## 실험 설계

- B0: v1의 38개 피처를 동일한 새 시간 분할로 재학습한 대조군.
- H1_form: B0 + 최근 성적·중량/거리 변화 12개.
- H2_ability: H1 + 상대 착순 기반 Elo·개최지/거리 Elo·보정 기록 15개.
- H3_relative: H2 + 이번 상대마 대비 Elo·레이팅·보정 기록 차이 등 7개.
- 비교 기준: 균등 확률, 공식 레이팅만, 자체 Elo만, 보정 기록만. 모든 후보의 평가 경주·출전마는 같다.

평가연도 Y마다 2006년부터 Y−1년 6월 말까지 FIT, Y−1년 3분기 TUNE, 4분기 CAL, Y년 EVAL이다. FIT으로 300회 학습한 모델에서 TUNE 손실로 100/200/300회 중 하나를 고르고 그 모델을 고정한다. CAL은 바로 그 모델의 예측으로 개최지별 온도를 적합하며 이후 재학습하지 않는다. 개최지 CAL이 100경주 미만이면 공통 온도를 쓴다. 중간 모델을 보정한 뒤 다른 모델로 재학습하는 v1의 한계를 제거했다. 모든 수치 대체·범주 사전은 FIT에서만 만든다.

2021–2024년은 과거 개발 평가다. 선택 조건은 서울·부경 각각 B0보다 평균 log loss와 Brier가 낮고, 각각 4년 중 3년 이상 log loss가 개선되며, 날짜 단위 paired bootstrap 2,000회 구간 상한이 0 미만인 것이다. 세 후보 비교에 대해 98.3333% 구간을 사용했다. 다만 이미 관측된 개발 자료의 선택 편향까지 제거하는 독립 성능 보장은 아니다. 통과 후보 중 개발 log loss 최저를 선택하며 없으면 B0를 유지한다.

## 피처와 데이터 검증

기존 410,168행·36,748경주와 38개 피처·라벨은 그대로 보존했다. 2000년부터의 확정 이력 486,979행을 사용하고 비확정 251경주·2,872행은 제외했다. 모든 당일 출전 피처를 먼저 출력한 뒤 해당 날짜 결과를 일괄 반영한다. 미래 결과 변조, 같은 날 결과 혼입, 행 순서 변경에 대한 테스트가 있다.

Elo는 기존 multiplayer 방식의 1500 초기값, K=32/28, 730일 감쇠를 재구현했다. 정상 순위가 있는 완주마 사이에서만 능력을 갱신한다. DQ/DNF·취소는 학습 대상에 유지하되 Elo에 가짜 꼴찌 순위를 부여하지 않는다. 최근 성적은 동착을 반영한 상대마 대비 착순 비율을 사용한다.

기록 지수는 과거 730일의 개최지·정확거리 기준 기록을 사용하며, 충분하면 과거 경주의 주로 조건을 반영한다. 과거 하루의 주로 변동 보정은 그날이 지난 후의 예측에만 들어간다. 현재 경주 주로·날씨·체중은 사용하지 않는다. 유효 기록이 없는 경우 결측과 관측 수를 보존한다. 속도 원천 이상 15행은 `invalid_speed_source_audit.csv`에 기록하고 시간 피처에서 제외했다.

기존 Elo/기록 알고리즘을 새 공식 ID·통합 모집단에 맞게 재구현한 비교다. 기존 149개 피처의 운영/confirmed-starter 모델 전체를 같은 계약으로 복제했다고 주장하지 않는다. 원천·시점·모집단 차이는 `legacy_reuse_review.md`에 명시했다. 구간 전개·조교·진료·심판·입상/조합 모델은 이번 1차 연구 범위 밖의 후속 후보로 남겼다.

## 실제 경주 사전 예측 적용

서울 2026-09-19·20, 영천 2026-09-20의 27경주·294두에 대해 `legacy_v1`, `v2_B0`, `v2_selected`를 같은 출마표에 적용한다. 저장 상태: **prospective_predictions_locked_no_results_yet**, 선택 모델: H3_relative, 고정 시각 UTC: 2026-09-18T06:46:03.698887+00:00.

입력은 9월 17일 수집된 공식 출전·게이트 원문이다. 새 API 조회는 타임아웃되어 최신 최종 출발마를 확인했다는 주장은 하지 않는다. 원래 관측 시각과 현재 예측 시각을 따로 기록하고, 모든 예정 출발 이전에 전체 카드 확률을 고정한다. 결과·배당·미검증 당일 조건은 입력하지 않는다. 이력 원천은 9월 13일까지이며 그 이후 결과를 반영한 최신 상태는 아니다. 부경 9월 18일 전체 카드는 이미 시작해 제외했다.

이는 보존된 사전 출마표 버전에 대한 전향 연구 예측이다. 경주 결과는 아직 없으므로 실전 적중률·수익률을 주장하지 않는다. 취소나 기수 변경이 확인되면 원본 예측을 보존한 별도 버전이 필요하다. 실제 베팅·운영 registry 변경·자동 반복 실행은 수행하지 않았다.

카드별 고정 원장: `shadow/predictions/*.json`. 사람이 볼 비교표: `shadow/predictions/comparison.csv`. 입력 시각·완전성·금지 열·확률합·모델/피처 SHA를 검증하고 기존 원장은 덮어쓰지 않는다.
