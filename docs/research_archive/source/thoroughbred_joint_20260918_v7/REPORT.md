# 기존 자료만 사용한 추가 연구 최종 결과 — v6·v7

추가 자료를 수집하거나 다음 주를 기다리지 않고 두 단계 연구를 완료했습니다. v6는 B 경계마/전체 말 보정과 A 표시 확률 보정의 30개 연도·반기 묶음, v7은 전체 과거 자료에 대한 6개 연간 공동확률 모델을 실제로 적합했습니다. **이번 추가 실험에서 단일 최고 선택의 적중률 개선은 입증하지 못했습니다. A는 v5 전체 이력·반기 모델, B/C는 v4 모델을 유지합니다.**

## 표시 확률과 실제 적중률

표시 확률은 예측 시점에 가진 출마표·과거 이력으로 모델이 계산한 사건의 추정확률입니다. A 80%는 한 말이 3위 이내일 확률, B 8%는 표시한 세 말이 순서 없이 1~3위를 모두 차지할 확률, C 2%는 표시한 1→2→3착이 모두 맞을 확률입니다. B/C는 이미 전체 조합 사건의 확률입니다. A 세 개를 곱하거나 표시된 B/C를 다시 곱하지 않습니다.

같은 확률 구간을 충분히 모아 실제 적중률과 대조해야 그 숫자를 믿을 수 있는지 판단할 수 있습니다. 현재 A의 참고 자료에서 표시 80% 이상인 180경주는 실제 146경주가 맞아 81.1%였습니다. 다만 그 180경주의 평균 표시 확률은 83.7%이고, 전체의 5.9%에 해당합니다. 90% 이상은 단 3경주라 3/3이라는 결과를 신뢰도 높은 100% 성능으로 해석하지 않습니다.

B에도 과신이 있습니다. 표시 15% 이상인 참고 327경주의 평균 표시 확률은 20.1%였으나 실제 적중은 49경주, 15.0%였습니다. C의 높은 확률 구간은 표본이 작습니다. 모든 임계값의 표본·표시 평균·실제 적중은 `current_probability_thresholds.csv`에 공개했습니다. 이 표는 사후 진단이며 특정 구간을 골라 전체 모델의 성능으로 포장하거나 확률을 재조정하지 않았습니다.

[자세한 설명](../thoroughbred_boundary_20260918_v6/PROBABILITY_EXPLAINED.md)과 [표시 구간별 과거 근거를 붙인 27경주 예상표](../thoroughbred_boundary_20260918_v6/UPCOMING_PREDICTIONS.md)를 함께 볼 수 있습니다. 9월 17일 보존 출마표·9월 13일까지 이력에 근거한 예상이며 이후 취소·기수 변경은 반영되지 않았습니다. **현재 이 27경주에는 A 표시 확률 80% 이상인 대상이 없습니다.** 영천은 역사 검증 표본 6경주뿐이므로 서울·부산의 과거 적중률을 그대로 적용하지 않습니다.

## 실제 추가 실험

v6에서는 Q3의 앞 관측 경주일로 보정 계수를 학습하고 뒤 날짜로 규제 강도를 고른 뒤, Q4에서 확률을 보정해 다음 해를 평가했습니다. 기존 모델의 Q3 튜닝 결과가 안쪽 검증에 섞이지 않도록 고정 트리 접두부를 사용했습니다. 전체 말을 보정한 방법은 단순 접두부 대조보다 나았지만 현재 모델보다 못했습니다. A의 맥락별 온도 보정도 확률 오차를 줄이지 못했습니다. [v6 상세 결과](../thoroughbred_boundary_20260918_v6/REPORT.md)에 실패 결과를 보존했습니다.

v7에서는 110개 변수를 그대로 두고 학습 목표를 바꿨습니다. 말별 입상 이진 손실 대신 세 마리 집합의 공동확률 손실을 직접 학습했습니다. 각 연도에 2006년부터 이전 6월 말까지 전체 자료로 학습하고, 이전 Q3에서 60/120회를 선택하고, 이전 Q4에서 A/B/C 확률을 보정했습니다. 경주별 공동 손실을 동일 비중으로 학습하므로 기존의 말별 손실 평균과 가중 척도도 다릅니다. 결과를 단순한 변수/기간 효과라고 해석하지 않습니다.

| 기간 | 목표 | 현재 적중률 | 직접 공동학습 적중률 | 현재 로그손실 | 직접 공동학습 로그손실 |
|---|---|---:|---:|---:|---:|
| 개발 2021~2024 | A | 62.62% | 62.02% | 0.503770 | 0.503835 |
| 개발 2021~2024 | B | 7.72% | 7.54% | 4.286377 | 4.284037 |
| 개발 2021~2024 | C | 1.89% | 1.80% | 6.019371 | 6.017035 |
| 참고 2025~2026 | A | 62.68% | 62.28% | 0.513220 | 0.512651 |
| 참고 2025~2026 | B | 7.70% | 7.64% | 4.255431 | 4.251277 |
| 참고 2025~2026 | C | 1.78% | 1.81% | 5.983672 | 5.979525 |

직접 공동학습의 B/C 확률 손실은 양 기간에서 소폭 줄었지만, 개발 B 적중은 516/6,681에서 504/6,681로, C는 126/6,681에서 120/6,681로 줄었습니다. 개발 기준에서 탈락한 C를 참고에서 한 번 더 맞았다는 이유로 채택하지 않았습니다. A의 참고 확률 오차 개선 역시 개발 적중률 하락을 상쇄하는 채택 근거로 삼지 않았습니다. 현재 선택을 바꾸지 않았으므로 예상표의 확률과 순위도 그대로입니다.

두 단계 모두 2024년 완료 직후 선택 파일을 저장하고 나서 2025~2026년의 새 후보 평가를 실행했습니다. 다만 이 역사 자료는 이전 연구에서 이미 보았으므로 새로운 독립 테스트가 아닙니다. 목표별 동일 경주 비교, 연도/개최지별 값, 경주일 단위 bootstrap 차이는 `comparison.csv`, `annual_metrics.csv`, `paired_differences.csv`에 있습니다.

## 검증과 보존

v7의 정확한 주변확률 계산을 모든 조합의 완전 열거와 대조했고, 연속 점수 이동 불변성과 수치 그래디언트·대각 Hessian을 검사했습니다. 단위 검사 3개가 통과했습니다. 410,168행 키를 일치 대조하고 6개 FIT 범주 사전·변수·시간 분할을 검증했습니다. 저장된 모델로 96개 경주/목표 사례를 재생한 평가 오차는 0이며, 빠른 주변확률 계산과 전체 조합 계산의 최대 차이는 5.6×10⁻¹⁶이었습니다. 개발 선택도 저장 자료에서 다시 계산해 일치했습니다.

v6의 별도 단위 검사 5개와 모델 재생 102개 사례도 통과했습니다. 두 단계의 결과가 기대보다 낮다는 이유로 모델·실패 지표를 삭제하지 않았습니다. 최종 평가와 바이트·해시가 같은 체크포인트만 확인 후 정리하며 `cleanup_log.json`에 기록합니다. 원천 데이터·기존 모델·운영 DB·registry는 수정하지 않습니다.

기존 자료로 더 진행한다면 우선순위는 **상위 한 조합의 과신을 검증하는 전용 보정**과 **적중률과 확률 오차의 상충을 개발 기간 안에서 비교하는 선택 규칙**입니다. 이를 이번 참고 결과를 보고 즉시 교체하는 방식으로 처리하지 않습니다. 이번 작업의 성과는 실제 추가 모델과 검증·실패 원인·해석 가능한 확률표까지 완성한 것이며, 추가 적중률 향상 자체가 달성됐다고 주장하지 않습니다.
