# v7 전체 과거 자료로 3두 공동확률 직접 학습

v6의 짧은 기간 선형 보정은 기존 모델을 넘지 못했다. 새 후보는 변수 추가 없이 v4의 110개 사전 변수를 사용하고, 기존 말별 입상 이진 손실 대신 3두 조합의 공동확률 손실로 처음부터 트리를 학습한다. 기존 보정 점수에 덧붙이는 모델이 아니다. 결과가 나오기 전에 후보를 `direct_joint110` 하나로 고정한다.

각 경주의 가능한 세 마리 집합 S에 대해 P(S)=exp(sum(s_i,i∈S))/sum_T exp(sum(s_i,i∈T))다. 학습 손실은 log Z − sum_i y_i s_i이며 y는 합이 3인 입상 슬롯 라벨이다. 동착이 없으면 정확한 3두 조합 음의 로그가능도와 같고, 동착이면 슬롯 질량을 분배한 교차엔트로피다. 평가에서는 기존처럼 동착과 호환되는 정답 집합의 확률을 합산한다. 경주별 손실을 동일한 비중으로 더하며 출전마 수로 다시 나누지 않는다. 그래디언트는 입상 주변확률−라벨, 대각 Hessian은 p(1−p)다. 경주 내 비대각 공분산은 LightGBM의 대각 근사에서 생략한다. 수치 안정성을 위해 Hessian 하한 1e-6만 적용한다.

조합을 전부 펼치지 않고 양의 기본대칭다항식 e3와 앞/뒤 e1,e2의 동적 계산으로 주변확률을 구한다. 모든 조합을 열거한 계산 및 수치 미분과 일치하는 단위 검사를 통과한 뒤 실제 학습한다.

연간 2021~2026 각 평가 Y에 대해 FIT는 2006년부터 Y−1년 6월 말까지, TUNE은 Y−1년 Q3, CAL은 Y−1년 Q4다. 부모 모델을 합치거나 미래 시점을 학습에 사용하지 않는다. LightGBM 120회 학습 후 60/120회 중 TUNE B 로그손실이 낮은 회수를 고르고, CAL에서 목표 A/B/C별 GLOBAL·서울·부산 온도를 기존 규칙으로 보정한다. 기존 학습률 0.05, 31 leaves, 최소 leaf 30, L2=1, seed=20260918, 4 threads를 유지한다. 학습 목표 및 손실의 경주 단위 가중 방식 차이를 문서화하고 변수나 기간 효과로 혼동하지 않는다.

현재 A 기준선은 v5 반기 rolling_all, B/C는 v4 연간 growth_strength다. 개발 2021~2024년 서울/부산 동일 경주에서 각 목표의 적중률이 기준선 이상, 로그손실이 이하이며 하나 이상 엄격히 개선되고, 서울/부산 각각 손실과 적중이 별도로 4년 중 3년 이상 나쁘지 않아야 그 목표를 채택한다. 허용오차 1e-12. A 경계 동착은 제외한다. 2024년 완료 직후 목표별 결정을 저장하고 나서 2025~2026년 후보를 평가한다. 단일 후보이므로 참고 기간을 보고 설정을 바꾸거나 후보를 늘리지 않는다.

모든 역사 기간은 이전 연구에서 이미 노출된 자료다. 이 단계의 시간순 평가도 새로운 독립 테스트로 부르지 않는다. 2006년 이후 자료 410,168행의 원천·기존 모델·운영 DB를 수정하지 않고 새로운 폴더에 모델, 평가, 확률 검증과 재현 코드를 보존한다. 채택된 목표만 보존 출마표에 적용한다. 최근자료만 남기는 방법이 앞 단계에서 성능을 낮춘 결과를 반영해 전체 이력을 사용한다.
