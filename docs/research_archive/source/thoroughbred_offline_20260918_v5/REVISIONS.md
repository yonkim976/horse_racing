# 실행 검토와 수정 기록

후보·선택 기준은 최초 계약을 유지한다. 다음은 결과에 맞춘 변수 탐색이 아니라 구현 및 재생 계약 검토에서 발견한 수정이다.

- 조건부 착순의 선형 `후보−선택마` 차이는 softmax에서 선택마 항이 상쇄된다. 학습·지표 생성 전에 제곱 차이로 고쳤으며, 상대 승산이 선택마 맥락에 따라 실제로 변하는 검사와 선형 차이의 상쇄 대조 검사를 추가했다. 해당 분담 폴더의 `pre_result_amendment.json`에 최초 기록이 있다.
- 조건부 착순 실행기에 존재하지 않는 `A_top1_hit` 조회가 있었다. 이 후보의 사전 선택 목표인 C만 평가하도록 고쳤다. 영천 보정은 기존 평가와 같은 미등록 개최지 기본값을 사용하고, 우승 비교군은 기존 C용 보정 온도를 그대로 사용하도록 했다.
- 조건부 계산을 캐시된 설계행렬과 벡터 연산으로 바꾸고 정확한 해석적 기울기를 추가했다. 수정 전 식과 확률이 일치하는 검사, 동착을 포함한 수치 미분과의 기울기 일치 검사를 통과했다. 가설·목적함수·계수 범위·규제 강도는 유지했다. 최초 코드는 `conditional_core_initial.py`, `run_conditional_order_initial.py`로 보존한다.
- 조합 모듈의 독립 import 경로와 공용 추론의 입력 검사를 보완했다. B 확률과 지표에는 영향이 없다. 이 연구에서 이미 완료된 조합 결과는 덮어쓰기 방지에 의해 재실행이 거부됐으며 그대로 보존하고 별도 재생 검증을 수행한다.
- 학습 기간 실행기의 추측 행 수 상수를 원천 행 수와 키 검사로 바꿨다. 실제 결합은 410,168행이다. A 동착 경계 행은 보관하되 일차 집계에서 제외한다.

병렬 에이전트의 사용 한도가 도달해 이후 실행 관리와 검증은 주 에이전트가 이어받았다. 완료된 부분과 계속 실행 중인 프로세스를 확인해 중복 학습 및 기존 결과 덮어쓰기를 피했다. 사용 한도를 초기화하거나 크레딧을 사용하지 않았다.

- 조건부 착순 실행기의 출력 폴더를 스크립트 위치 기준으로 바꿨다. 새 형제 폴더에서 재현할 수 있도록 한 경로 수정이며 계산식·이미 생성된 결과는 바뀌지 않는다.
- 기간 분담 초안은 A를 일차 목표로 설명하지만 최종 통합 판정은 사전 고정한 루트의 목표별 선택 계약과 선택 코드를 따른다. 기간 후보의 B/C도 같은 루트 규칙으로 대조한다. 기간 실행기는 모든 연도를 처리한 다음 결과를 한 번에 저장하므로 통합 선택 파일을 참고 지표 생성 이전에 동결했다는 분담 초안의 설명은 충족하지 못했다. 최종 선택은 실행 종료 후 개발 행만 입력해 계산하며 이 한계를 명시한다. 이전에 노출된 참고 자료라는 지위는 그대로다.
- 기간 실행기의 A 원래 집계는 경계 동착을 포함한다. 원본은 보존하고 일차 집계는 별도 `*_primary.csv`와 루트 통합 비교에서 경계 동착을 제외한다. 원래 초안에 나열했던 모든 말의 역사 확률과 상위 조합 ID를 중복 저장하지는 않았으며, 저장 모델·입력과 경주 지표를 재생 검증한다. 최고확률과 상위 K 적중 자료는 보존한다.
- 마지막 저장 전 환경 점검에서 pandas Parquet 엔진이 설치되지 않은 것을 발견했다. 진행 중인 기간 실행기가 보유한 결과를 보존하기 위해 프로젝트 `.venv`에 `pyarrow==25.0.1`만 설치했다. 기존 학습 라이브러리 버전·모델·원천 자료는 변경하지 않았다. 버전은 `environment.json`에 기록했다.
- 기간 원래 프로세스는 48개 모델 저장 후 평가 결과 파일 없이 종료됐다. 원래 프로세스의 종료 stderr 세션은 회수할 수 없어 최종 오류 메시지 자체는 확인하지 못했다. `windows/recover_evaluation.py`가 저장 모델만 불러 동일한 평가 함수를 다시 실행하고 DuckDB로 Parquet을 저장하도록 복구했다. 재학습·보정·후보 변경은 하지 않았으며 후속 독립 검증에서 날짜·사전·재사용 모델·재생 지표를 대조한다.
