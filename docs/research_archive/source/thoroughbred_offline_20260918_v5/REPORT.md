# 고정 데이터 더러브렛 v5 연구 결과

기존 데이터로 12개 반기 구간의 학습 기간·최근성 4개 후보, 입상 3두 상호작용, 조건부 착순을 실제 학습하고 평가했습니다. 48개 기간 모델 묶음 중 42개를 새로 학습했고, 동일 계약인 첫 반기 기준선 6개는 기존 모델과 바이트까지 대조해 재사용했습니다. 조합·착순 후보는 각각 6개 연도 계수를 학습했습니다.

선택은 2021~2024년 개발 자료의 적중률·로그손실과 서울/부산 각각의 연도 일관성으로 결정했습니다. 2025~2026년은 이미 여러 차례 확인한 참고 자료이며, 새로운 독립 테스트가 아닙니다. 기존 운영 DB·모델·registry에는 적용하지 않았습니다.

## 동일 경주의 현재 선택 성능

A는 매 경주 최고 입상확률 말 한 마리의 3위 이내 적중, B는 최고확률 3두 조합 전체 적중, C는 최고확률 1→2→3착 전체 적중입니다. B/C 수치는 말별 확률이나 여러 조합을 선택한 적중률이 아닙니다. A의 로그손실은 경주 안 말별 이진 손실 평균, B/C는 실제 정답 조합/순서의 확률 손실입니다. 목표 사이의 손실 크기를 직접 비교하지 않습니다.

## 검증·보존·재현
