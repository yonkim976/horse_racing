# 고정 데이터 기반 v5 연구 계약

이 연구는 2026-09-18에 존재하는 보존 데이터만 사용한다. 운영 DB와 v1~v4 연구·모델·예상표는 읽기 전용이다. 새 경기 결과를 수집하거나 기다리지 않는다. 2021~2024년은 반복 사용한 개발 자료, 2025~2026년(9월 13일까지)은 이미 노출된 참고 자료다. 새 독립 테스트라고 표현하지 않는다.

## 비교할 후보

1. `windows`: v4의 동일한 110개 변수와 직접 입상 모델로 학습 표본의 시간 범위를 비교한다. 전체 기간, 최근 3년, 최근 5년, 전체 기간에 2년 반감기 가중치의 네 후보만 허용한다. 2021H1~2026H2 반기마다 FIT/TUNE/CAL을 앞으로 이동한다. H1은 전년도 6월 말 FIT 종료, 전년도 Q3 TUNE, Q4 CAL; H2는 전년도 12월 말 FIT 종료, 당해 Q1 TUNE, Q2 CAL이다. 기간 효과 자체는 같은 갱신 주기의 전체 기간 후보와 비교한다.
2. `set_interaction`: 고정된 연간 v4 말별 점수에 세 마리 조합의 상호작용을 더하는 후보 한 개. 이전 Q3에서 소수의 정규화·규제된 계수를 학습하고 Q4에서 보정한다. B만 채택 대상으로 삼는다.
3. `conditional_order`: 고정된 연간 v2/v4 점수와 사전 정보로 1위에 따른 2위, 1·2위에 따른 3위 분포를 계산하는 후보 한 개. 이전 Q3에서 학습하고 Q4에서 보정한다. C만 채택 대상으로 삼는다.

각 분담 폴더의 세부 변수·목적함수·계수 한계·보정 규칙은 결과 생성 전에 고정한다. 결과를 보고 후보를 추가하거나 변수를 바꾸는 탐색은 이번 연구에 포함하지 않는다. 구현 오류는 원인과 무효 실행을 기록하고 같은 가설로 정정한다.

## 현재 채택 기준선과 선택

- A: v3 `top3_allcore`.
- B/C: v4 `top3_growth_strength`.
- 기존 `win72_pl`은 비교용으로 계속 표시한다.

사용자가 단일 최고 예측의 적중률을 중시하므로, 이번에는 **적중률 우선, 확률 손실 악화 방지** 규칙을 미리 고정한다. 목표별로 2021~2024년 서울·부산의 동일 경주에서 다음을 모두 만족해야 채택 후보가 된다.

1. 합산 최고 예측 적중률이 기준선 이상이고, 평균 로그손실이 기준선 이하이며, 둘 중 하나는 엄격히 개선된다.
2. 서울과 부산 각각에서, 로그손실이 나빠지지 않은 연도가 4년 중 3년 이상이고 적중률이 나빠지지 않은 연도도 별도로 3년 이상이다.
3. 적격 후보 중 합산 적중률이 높은 순, 로그손실이 낮은 순, 후보 이름 순으로 선택한다. 없으면 현재 모델을 유지한다. 숫자 비교 허용오차는 1e-12다.

A는 3위 경계 동착을 제외한다. B/C는 공식 동착과 양립 가능한 모든 정답 집합/순서를 인정한다. 경주별 전체 출마표를 일차 평가 대상으로 삼고 영천은 채택 평가에서 제외한다. 구간·출전두수·확률 기준 분석은 사후 진단이며, 참고 자료의 유리한 구간을 찾아 현재 선택을 바꾸지 않는다.

반기 재학습 후보와 연간 기준선의 차이는 재학습 주기까지 포함한다. 이를 학습 기간만의 효과로 표현하지 않는다. 정확한 확률 정규화, 라벨과 날짜 차단, 같은 경주의 비교를 검증한다. 목표별로 선택·보정한 A/B/C를 하나의 동일한 공동분포로 해석하지 않는다.

## 완료 기준

고정한 후보를 실제로 학습·평가하고 개발 기준 선택을 저장한다. 같은 경주의 지표, 연도·경마장별 결과, 고확률 구간의 표본 수와 적중률, 오답 변화, 무결성과 재생 검증을 제공한다. 선택이 바뀌면 보존된 9월 17일 출마표의 9월 19·20일 27경주에 새 연구 모델을 적용한다. 두 날짜 모두 9월 19일보다 이른 이력만 사용하고 미래 결과는 입력하지 않는다. 실제 운영 모델 승격이나 DB 기록 변경은 하지 않는다.
