# 더러브렛 세 목표 연구 v3

현재 데이터로 과거 시점의 예측을 재현하는 연구를 완료했다. 미래 경기 결과를 기다려야 이 연구를 평가할 수 있는 구조가 아니다. **A 선택 후보는 top3_allcore, B는 top3_allcore, C는 top3_allcore**다. 목표별 후보가 같을 수도 다를 수도 있으며, 서로 다른 보정/모델의 확률을 한 공동분포처럼 섞지 않는다.

2025–2026년 참고기간의 단일 최고확률 선택 적중률은 A 61.46% → 62.25%, B 7.80% → 7.31%, C 2.07% → 1.81%다. B, C는 확률 오차 감소와 별개로 한 조합 적중률이 낮아졌다. 세 목표 모두의 적중률이 개선됐다고 결론 내리지 않는다.

## 목표와 평가 계약

- A: 한 경주에서 선택한 한 마리가 공식 3착 이내인지. 저장 확률은 세 자리 배분 분포의 말별 포함 확률이다.
- B: 순서를 무시한 입상 3두 전체를 맞힐 확률.
- C: 1·2·3착 세 말과 순서를 모두 맞힐 확률.

B는 가능한 모든 3두 집합, C는 가능한 모든 서로 다른 순서에 걸쳐 확률합이 1이다. 각각의 목표용 보정분포에서 A 포함확률 합은 3이다. 3착 경계 동착에서는 공식 입상마가 4두 이상일 수 있어 공식 입상 이벤트와 자리 배분 확률을 구분한다. A 주 손실·표의 적중률은 경계 동착 제외 표본이며, 경계 동착 진단과 전체 출전마 예측은 따로 보존했다. 실제 연승의 7두 이하 조건과 연구의 일률적 top3 정의도 다르다.

FIT은 평가 전년 6월 말까지, TUNE은 3분기, CAL은 4분기, EVAL은 다음 해다. FIT 전용 범주 사전, TUNE 중단시점, CAL 확률 보정 후 모델을 다시 학습하지 않는다. 2021–2024년으로 후보를 선택하고 파일을 고정한 뒤 2025–2026년을 평가했다. **2025–2026년은 이미 확인한 과거 참고자료이며 새로운 독립 테스트가 아니다.**

후보는 서울·부경 각각 개발 4년 중 3년 이상 기준선보다 목표 손실을 개선해야 하며, 이 조건을 통과한 후보와 기준선 중 합산 손실이 가장 낮은 모델을 유지한다. 아래 부트스트랩 구간은 날짜별 경주를 묶은 차이 진단이다. 개발 후보 선택과 여러 후보 비교의 영향을 제거한 독립 유의성 증명은 아니다.

## 실제 계산 결과 파일과 오류 분석

`selected_B_error_horses.csv`는 틀린 집합에서 잘못 고른 말과 놓친 실제 입상마를 과거 기록·부담중량·휴양·전개 변수와 함께 나란히 추적한다. `selected_C_order_only_errors.csv`는 세 마리는 맞지만 순서가 틀린 경주만 분리한다. 실제 착순은 이 오류 분석의 정답 열이며 모델 입력으로 들어가지 않는다.

사용자 요청 항목별 구현·한계는 `HYPOTHESES.md`, 원천의 실제 필드·연도 coverage는 `DATA_AVAILABILITY.md`, 공식 경주로 자료 확인은 `OFFICIAL_CONTEXT.md`에 있다. 다음 우선 후보는 성장/노화 추세, 승급 및 상대 수준 변화, 3~5순위 입상 경계와 선행형 조합 상호작용, 경마장 이동 적응, 자료 부족에 따른 과신 점검이다. 현재 결과가 해당 후속 변수의 개선을 입증하는 것은 아니다.

## 정리 가능한 데이터

기존 v2의 `features_v2_rows.csv` 약 133.3MiB는 최종 Parquet과 410,168개 키·34개 피처가 모두 같다. 코드로 재생성 가능한 중간물이며, 보관 인덱스·manifest 계약을 정리한 뒤 제거할 수 있는 후보로 기록했다. 기존 모델, 원천·통합 DB, 고정 예측, 실패 실험의 최소 증적은 보존한다. 이번 작업에서 기존 파일은 삭제하지 않았다.

v3는 중간 CSV를 임시 디렉터리에서만 생성하고 자동 정리한다. 저장소 전체 크기, SHA 동일 사본, 조건부 회수량과 기준은 `STORAGE_AUDIT.md`·`storage_audit.json`에 있다. 큰 DB들은 생성 단계와 계보가 다르므로 이름이나 용량만 보고 폐기하지 않는다.

## 검증과 재현

피처 검사: pass. 독립 검사 상태: True. 보호 파일 보존: False. 모델과 예측의 검증 세부는 `verification.json`, 최종 산출물 해시는 `manifest.json`이다. 원래 운영 DB·모델·registry는 변경하지 않았다.

공유 작업폴더의 소스 파일 변경이 발견돼 전체 보호 범위의 보존 검사는 실패로 남겼다. 기존 파일 변경/누락 4개와 새 외부 파일 6개를 기록했다. 기존 모델·DB 보호 해시 유지 여부는 True다. 같은 프로젝트에서 별도 웹 작업이 진행 중임을 확인했으며 해당 파일을 되돌리거나 보존 실패를 자동 통과시키지 않았다. 해시만으로 작성자를 확정하지 않는다. `preservation_check.json`과 `preservation_investigation.json`에서 범위를 확인할 수 있다.

공개 추론 CLI의 서울·부경·영천 대표 경주 재생에서는 A/B/C 확률과 조합이 저장 평가와 정확히 일치했다. `inference_smoke.json`에 최종 결과가 있다. 최초 검사에서 영천 C의 미학습 개최지 보정 기본값 차이를 찾아 고정 평가와 동일하게 수정했다. 기존 모델과 역사 예측은 바꾸지 않았고, 실패한 첫 검사와 처음 만든 미래 예상도 `inference_correction.json` 및 원 폴더에 보존했다. 미래 예상의 유효 수정판은 `_r2` 폴더다.

전체 재현은 `code/reproduce_targets.py`로 새 격리 경로를 생성한다. 기존 모델/예측 폴더를 덮어쓰는 재실행은 하지 않는다. 명령과 입력 계약은 `USAGE.md`, 신규 54개 피처의 실제 계산식·단위·결측 규칙은 `FEATURE_DICTIONARY.md`에 있다.
