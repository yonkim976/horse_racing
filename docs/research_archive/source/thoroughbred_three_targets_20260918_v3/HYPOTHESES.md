# 사용자 가설과 이번 연구의 범위

세 목표는 A 말 한 마리의 3착 이내, B 상위 3두 집합 전체, C 1·2·3착 순서 전체다. 확률 숫자를 크게 만드는 것이 목적이 아니라, 높은 확률을 부여한 예측이 실제로 그만큼 맞고 전체 확률 오차도 줄어드는지를 본다. 가장 높은 한 예측의 적중률과 상위 K개 조합을 모두 고르는 적중률은 분리한다.

## 이번에 비교할 항목

| 가설 | 이번 구현/비교 | 해석 한계 |
|---|---|---|
| 게이트와 거리별 안/밖 | 출전번호의 상대 위치, 개최지·거리별 과거 3년 효과, 최근 1년 변화, 관측량에 따른 축소 | 출전번호는 출발 위치의 대리값. 실제 주행 레일과는 다르며 원인 효과가 아님 |
| 부경의 특정 시기 유불리 | 이전 자료만 사용한 최근 효과와 장기 효과 차이, 기존 시점 외 예측의 분기별 잔차 진단 | 분기별 사후 유불리 발견을 그대로 규칙으로 채택하지 않음. 경주 시각·살수·바람·레일 사건은 별도 원천 필요 |
| 착순 대신 실제 기록 | 기존 v2의 개최지·거리·과거 주로 보정 기록과 Elo를 보존, 최고/평균/최근 기록 차이 추가 | 착순과 기록을 함께 사용. 보정 기록도 상대 편성·전개·주로 영향을 완전히 제거하지 못함 |
| 선행·선입·추입 및 편성 | 검증된 과거 초반 위치, 위치 변동, 종반 순위 회복, 이번 상대의 선행 성향 수와 경쟁 정도 | 과거 성향이며 이번 실제 전개가 아님. 부경 미검증 구간을 서울 구간처럼 사용하지 않음 |
| 거리 변화·기수 변화 | 같은 거리 출전/성적, 말×기수 경험, 기수 교체 | 기수 ID의 크기를 수치 능력으로 해석하지 않음. 교체 자체에 임의의 가산점 없음 |
| 부담중량·휴양 | 말의 최근 부담중량 범위 대비 변화, 과거 중량과 수행의 관계, 출전 간격·짧은 재출전·휴양 | 부담중량의 과거 수행 관계는 등급·능력·성장과 얽힌 관측 관계이며 인과적 kg당 기록 변화가 아님 |
| 마체중·말별 정상 범위 | 별도 실험에서 당일 체중과 과거 중앙값·변동폭·편차 비교 | 관측된 정상 범위이지 의학적/인과적 최적 체중이 아님. 당일 값 공개시각 미검증 |
| 조교·신마 주행심사 | 별도 실험에서 엄격히 과거의 조교량과 확정 연결 심사 이력/속도 | 조교·심사 최초 게시시각 미검증. 심사 속도를 정식 경주와 동일 능력 척도로 단정하지 않음 |
| 날씨·현재 주로 | 별도 실험에서 현재 함수율·주로·비 여부 추가 | 사후 데이터 이용 가능성 실험. 경기 전 모델의 검증 성능으로 섞지 않음 |
| 잠재력·일시 부진 | 보정 기록의 최근 대비 최고 차이, 변동성, 초반 위치 대비 결승 위치 변화 | 출발 지연·진로 방해를 관측했다는 뜻이 아님. 사건 원문 없이는 부진 원인을 단정할 수 없음 |
| 서울 모래 보충 | 원천 가용성 확인 및 누락 기록 | 과거 보충 날짜·위치·물량 원장이 없어 직접 효과는 이번에 측정하지 않음 |
| 상위마 휴양 컨디션 | 높은 과거 능력과 출전 간격·최근 기록·조교 이력의 상호작용 후보 | 실제 생리 상태를 관측한 것이 아님. 의료·회복 상태는 별도의 신뢰할 사건 자료 필요 |

심판 원문은 프로젝트 전체에 없는 것이 아니다. 운영 SQLite에 서울 1,780경주·부경 1,244경주의 2025–2026년 원문이 있고 경주 자연키로 연결된다. 아직 이번 통합 데이터의 공식 말 ID별 사건 표로 연결·추출 검증하지 않았으며, 수집 시각은 원래 게시 시각의 증거가 아니다. 기존 `sand_response.py`는 모래를 맞은 말의 반응을 다루며 경주로 모래 보충 작업을 뜻하지 않는다. 이 원문과 추출기는 다음 고정 실험의 우선 후보로 보존한다.

기본 변수 효과는 같은 직접 입상 모델에서 `base72`, `+gate`, `+condition`, `+pace`, `+allcore`를 비교한다. 공개시각 미검증 변수들은 하나의 별도 묶음으로 비교하므로, 성능 차이를 특정 체중·조교·심사 변수 하나의 효과라고 설명하지 않는다. 이번 단계는 소수의 사전 고정한 가설 묶음 비교이며, 모든 가능한 조합을 탐색한 최고 성능 증명이 아니다.

## 추가로 우선 검증할 가설

다음 항목은 다음 실험 후보이며 이번 결과가 좋아질 것이라고 확정하지 않는다.

1. **성장과 노화:** 연령·데뷔 후 경주 수에 따른 기록 변화, 어린 말의 최고 기록 갱신 속도. 한 번의 최고 기록은 관측 수가 적으면 평균 쪽으로 축소한다.
2. **상대 수준 변화:** 최근 경주 상대들이 이후에도 강했는지, 승급·강등과 이번 상대의 능력 분산. 상대의 이후 결과는 해당 예측일보다 이전에 확인된 것만 사용한다.
3. **편성의 입상 경계:** 3~5순위 후보의 차이, 비슷한 선행형 말들의 동반 입상 가능성. B 집합 직접 상호작용 모델은 말별 점수의 단순 합을 넘어서는 후속 후보다.
4. **경마장 이동 적응:** 서울↔부경 이동 후 첫 출전과 재출전, 이동 전후 거리·기수 변화. 영천은 표본을 이유 없이 확대 해석하지 않는다.
5. **신뢰도와 결측:** 신규마·장기 공백·적은 거리 경험·낮은 구간 coverage를 별도 관리해 고확률 과신 여부를 평가한다. 자료 없음은 부진이나 조교 0회와 구분한다.
6. **마방 변화·장구·회복 사건:** 조교사 이동, 장구 변경, 진료 후 복귀는 날짜·말 ID·공개 시각의 근거를 갖춘 뒤 시험한다.

채택은 중요도 순위나 개별 성공 사례로 정하지 않는다. 시간 순서를 유지한 같은 경주에서 목표별 확률 손실, 최고확률 예측 적중률, 확률 보정, 연도·개최지 일관성을 함께 확인한다. 이미 본 2025~2026년 참고 결과를 반복 조정한 뒤 새로운 독립 검증으로 부르지 않는다.

## 실패를 다음 실험으로 연결하는 방법

- A 실패: 선택한 말이 공식 3착 밖으로 밀린 경주를 분석한다.
- B 실패: 실제 입상마와 예측 집합이 0·1·2두 겹친 경우를 구분한다. 특히 2두를 맞히고 한 마리를 놓친 경우가 어떤 조건에 몰리는지 본다.
- C 실패: 3두 집합부터 틀린 경우와 집합은 맞지만 순서만 틀린 경우를 구분한다.
- 고확률 실패: 확률 구간별 표본 수와 실제 적중률을 기록한다. 일부 경주만 선택해 높아진 적중률은 전체 경주의 성능과 구분한다.

실패 사례에서 만든 새 가설은 다음 고정 실험에서 평가하며, 지금 본 오답에 맞춰 수동 가산점으로 현재 모델을 덧칠하지 않는다.
