# 더러브렛 후속 연구와 정리 결과

기존 자료로 성장·성적 추세·상대 편성 강도 후보 한 개와 기존 두 모델의 확률 결합 후보 세 개를 비교했습니다. 선택 기준은 결과를 보기 전에 정했으며 2021~2024년 개발 자료에만 적용했습니다. 2025~2026년은 이미 본 참고 자료입니다.

최종 선택: A **top3_allcore**, B **top3_growth_strength**, C **top3_growth_strength**. 운영 모델은 변경하지 않았습니다.

선택된 모델로 [9월 19·20일 27경주 예상표](UPCOMING_PREDICTIONS.md)를 새로 계산했습니다. A의 294개 확률은 이전과 같고, 최고 예측은 B 8경주·C 9경주에서 달라졌습니다. 출마표는 9월 17일 저장본이며 이후 변경은 갱신하지 않았습니다.

## 같은 경주에서 비교한 결과

각 경주에서 가장 높은 확률의 한 마리 또는 한 조합만 선택한 적중률입니다. A는 3위 이내이며, 실제 연승식의 소두수 2위 이내 규칙과 다릅니다.

| 기간 | 후보 | A 입상 | B 입상 3두 | C 정확순서 |
|---|---|---:|---:|---:|
| 개발 2021–2024 | 기존 입상 모델 | 61.58% | 7.51% | 1.80% |
| 개발 2021–2024 | 성장·편성 추가 | 62.51% | 7.72% | 1.89% |
| 개발 2021–2024 | 우승 모델 25% 결합 | 61.96% | 7.33% | 1.75% |
| 개발 2021–2024 | 우승 모델 50% 결합 | 61.85% | 7.44% | 1.83% |
| 개발 2021–2024 | 우승 모델 75% 결합 | 61.49% | 7.08% | 1.63% |
| 참고 2025–2026 | 기존 입상 모델 | 62.25% | 7.31% | 1.81% |
| 참고 2025–2026 | 성장·편성 추가 | 62.88% | 7.70% | 1.78% |
| 참고 2025–2026 | 우승 모델 25% 결합 | 61.85% | 7.37% | 1.74% |

| 참고 2025–2026 | 우승 모델 75% 결합 | 61.95% | 7.54% | 1.78% |

참고 기간에서 새 후보의 B는 222/3,038 → 234/3,038로 12경주 늘었고, C는 55/3,038 → 54/3,038로 1경주 줄었습니다. C의 참고 적중률 개선은 확인되지 않았습니다. B의 적중률 변화 95% 날짜 bootstrap 구간도 약 −0.17~+0.96%p로 0을 포함합니다. 참고 자료를 보고 채택 규칙을 바꾸지 않았으며, 이 작은 차이를 확실한 성능 향상으로 표현하지 않습니다.

개발 표본은 A 6,666경주, B/C 6,681경주이며 참고 표본은 A 3,033경주, B/C 3,038경주입니다. 평균 로그손실과 적중률이 모두 기존 모델보다 나쁘지 않고, 서울·부산 각각에서 두 지표가 별도로 4년 중 3년 이상 나쁘지 않아야 채택합니다. 기준을 통과한 후보끼리는 개발 로그손실, 적중률 순으로 선택합니다. 전체 확률 오차가 조금 줄어도 단일 조합 적중이나 연도별 일관성이 부족하면 유지합니다.

모든 상세 확률 손실·Brier·적중 변화는 `comparison.csv`, 날짜 단위 paired bootstrap 구간은 `paired_differences.csv`, 탈락 사유는 `selection.json`에 있습니다. 여러 번 확인한 데이터에서의 변화이므로 새로운 독립 성능 증명으로 해석하지 않습니다.

## 새 변수와 검토 중 수정

기존 104개 변수에 6개를 추가했습니다. 최근 5회 정규화 착순의 추세, 최근 3회와 누적 평균 착순의 차이, 과거 상대들의 경주 전 Elo 평균, 현재 상대들과의 Elo 차이, 연령, 연령×출전 경험입니다. 실제 기록 보정 변수는 기존 모델에서 계속 사용하며, 이번 성장 변수의 추세는 기록초가 아닌 정규화 착순입니다.

첫 구현에서 누적 평균 정의·상대 평균에 본인 포함·원래 착순과 정정 착순 선택의 불일치를 발견했습니다. 부분 실행은 `model/invalid_attempt_01`에 무효로 보존하고 정정된 정의로 전 연도를 다시 실행했습니다. 당일 결과는 날짜 묶음을 모두 예측한 다음 이력에 반영하며, 상대 평균에서 해당 말을 제외합니다.

## 심판 원문과 다음 출전마 참고

서울·부산 심판 원문 3,024경주에서 말 ID로 연결한 사건 5,136건을 추출했습니다. 번호·이름·출마 명단과 근거 문장을 함께 확인합니다. 58개 층화 표본은 모두 연결과 서술이 맞았으나 전체 정확도나 재현율을 뜻하지 않습니다. 모호한 서술은 별도로 남겼고 이전 경주를 가리키는 추가 심판 문장은 제외했습니다.

[다음 출전마 참고표](upcoming_context/PRIOR_EVENTS.md)에는 27경주 294두 중 67두의 직전 3회 실제 출전에서 찾은 기록이 있습니다. 원문이 현재 작성 시점 전에 수집됐는지 확인했습니다. 과거 당시의 게시 시각은 증명되지 않아 역사 모델 학습에는 넣지 않았으며, 이 설명으로 확률이나 순위를 조정하지 않았습니다. 바깥 주행은 실제 불리함을 입증하지 않으며, 추출 기록 없음도 사건이 없었다는 증거가 아닙니다.

## 정리한 파일과 보존

중간 CSV 139,748,563바이트를 원래 해시로 복원 가능한 gzip 47,928,499바이트로 보관한 뒤 원본을 제거했습니다. 캐시 27개도 제거해 정리 작업 자체로 약 88.0MiB를 확보했습니다. 이 수치는 새 연구 산출물 전체 용량을 차감한 프로젝트 총 순감소량은 아닙니다.

최종 묶음 작성 직전 측정에서는 새 연구 결과·압축본·감사 자료까지 포함해 약 31.8MiB가 순감소했습니다. 다른 작업의 파일 변화는 제외한 수치이며, 이후 추가되는 최종 manifest 등 작은 메타데이터는 포함하지 않았습니다. 상세 기준은 `storage_accounting.json`에 있습니다.

모델·원천 DB·Parquet·기존 manifest는 삭제하지 않았습니다. v2 원래 manifest 검증기는 CSV가 빠진 상태에서 실패하는 것이 정상입니다. 새 보관 대응 검증기는 해당 CSV 한 개만 압축 스트림으로 대조합니다. 기존 1,173개 artifact가 모두 검증됐습니다. 복원은 `cleanup/restore_features_v2_rows.py`, 보관 대응 검증은 `review_blend/verify_prior_manifests.py`를 사용합니다.

## 해석과 다음 우선순위

새 단위 검사 7개가 통과했고, 2026년 서울·부산·영천 1,286경주의 모델 재생에서 A 13,802개 확률과 B/C 상위 조합 25,720개의 확률·키가 저장 결과와 정확히 일치했습니다. 새 예상표 294두의 A 확률도 이전과 완전히 같습니다. 전체 검증 요약은 `validation_summary.json`, 파일 해시는 최종 `manifest.json`에 있습니다.

변수 추가나 확률 결합이 자동으로 개선을 뜻하지 않습니다. 선택된 모델만 현재 예상 기준으로 유지합니다. 심판 기록을 현재 예측 설명에 연결하는 작업은 완료했으며, 다음 모델 실험은 원문의 과거 공개 시점과 모호한 사건 연결 검증을 보강한 뒤 별도 고정 실험으로 진행해야 합니다.
