# 한국 경마 과거 원천 수집 결과 (2026-09-14)

## 범위와 결론

공식 KRA 월별 API의 일별 조교 및 출발조교를 현재 조회 가능한 2026-09월까지 실제 수집했다. 일별 조교는 1990-01부터 최초 양성 월 전까지의 세 경마장 빈 응답 구간도 검사했다. 공식 Text 자료실의 조교·의료·출전 관련 9개 유형도 목록의 오래된 끝부터 최신 파일까지 수집·검증했다. 이 결과는 [이전 소량 가능성 확인](PRE2025_HISTORY_SOURCE_FEASIBILITY_2026-09-14.md)의 "API 과거 응답 미조회" 상태를 갱신한다. **이는 원문 보존 작업이며, 2015년부터의 정량 비교용 경주-말-조교사 통합 데이터셋이 완성됐다는 뜻은 아니다.** 운영 모델과 registry는 건드리지 않았다.

일별 조교의 2015–2024년만 합치면 3,999,500행(서울 1,716,639; 제주 768,093; 부산경남 1,514,768)이고, 출발조교는 473,248행이다. 일별 조교 전 행에 공식 말 번호 `hrNo`, 조교일, 시간 `trTerm`, 두 강도별 횟수 `run1Cnt`·`run2Cnt`가 있다. 2015–2024년의 시작·종료 시각도 전 행에 있다. 서울의 최초 양성 월 전 1990-01~1997-12, 제주의 1990-01~2006-12, 부산경남의 1990-01~2003-12는 월별 API에서 모두 0행이었다. 따라서 위 시작일은 **1990년 이후 조회 범위에서 관측된 첫 기록**이다. 1990년 이전까지 없었다고 단정하지 않는다.

원문은 `data/raw/kra_api_monthly/{horse_training,start_training}/meet_{meet}/{YYYYMM}/page_0001.json`에 저장했고, append-only 요청 원장에 URL·조회 범위·응답 hash·행 수를 남겼다. 월·페이지 누락, API `totalCount`, 일자·경마장·말 번호를 대조한 결과는 [일별 조교 감사](../data/logs/historical_horse_training_monthly_audit_20260914.json), [출발조교 감사](../data/logs/historical_start_training_monthly_audit_20260914.json)에 있다. 수집기는 [월별 수집 스크립트](../scripts/collect_historical_training_monthly.py), 검증기는 [API 원문 감사](../scripts/audit_historical_training_monthly.py)다.

### 품질과 통합 장애

- 2015–2024년 공식 말 번호는 전 행에 있으나 마명이 빈 행이 11,367개(서울 8,375; 제주 3; 부산경남 2,989)다. 기존 `HorseTrainingItem` 파서는 `hrName`을 필수 필드로 취급하므로 이 행을 그대로 DB에 넣을 수 없다.
- 같은 기간 조교사명 `trName`은 연도·경마장별 편차가 크다. 서울 2015년 68.76%, 2016년 이후 100%; 제주·부산경남 2016–2020년 0%, 2021년 약 19–20%, 2022년 이후 거의 전부가 채워져 있다. 정확한 과거 조교사 소속 이력과 조인하기 전에는 말별 조교량은 계산할 수 있어도 모든 시점의 조교사별 비교는 할 수 없다. 연도별 계수는 [품질 감사](../data/logs/historical_horse_training_2015_2024_quality_20260914.json)에 있다.
- 서울 2018-09-02에는 동일 말·시각·지속시간에 조교사명만 다른 원문 2행이 있다. 전체 일별 조교 원문 자연키 중복은 서울 8개다. 출발조교 제주 원문에는 정확히 중복된 payload가 4,202행 있으며 감사 자연키 중복은 4,203개다. 원문을 조용히 제거하지 않았다.
- 2025년 기존 DB와 비교하면 중복 원문을 제외한 조교 자연키는 세 경마장 모두 누락·추가 0, 지속시간·강도 횟수 차이 0이다. 서울 조교사명은 2행이 다르다. 이는 기존 2025 저장값에 대한 강한 대조군이지만, 과거 2015–2024년의 모든 말-조교사 연결을 승인하는 증거는 아니다. [2025 DB 대조](../data/logs/historical_horse_training_2025_db_overlap_20260914.json).
- 현재까지 과거 API 자료는 원문 저장·감사 단계다. 읽기 전용 점검 시 기존 `horse_training` 도메인 DB는 752,358행, 날짜 2025-01-01~2026-09-12이고 `horse_medical`은 176,811행, 날짜 2025-01-01~2026-09-12였다. 과거 API/Text 행을 이 테이블이나 모델 입력 데이터셋에 적재하지 않았다.

## 공식 Text 자료실

파일별 원문, 목록, SHA256, 날짜, 응답 상태와 경마장 키를 보존했다. 유형별 완주 여부와 최초·최종 파일일은 각 감사 JSON에 기재한다. 오래된 Text는 마명 중심이거나 레이아웃이 달라 공식 말 번호를 모든 행에 바로 붙일 수 없고, 2015년 자료에 최신 parser를 그대로 적용하면 실패하는 유형이 있다. 따라서 원문 파일 수와 모델에 투입 가능한 관측행 수는 다르다.

표의 날짜범위는 세 경마장을 합친 범위다. 예를 들어 제주 `dacom55` Text는 2015-04-29부터지만, 월별 API는 2007-10-01부터 조교 행을 반환한다. `db5` Text는 2014년부터지만 출발조교 API는 제주 2007년, 서울·부경 2009년부터다. 원천별 최초 관측일을 혼동해서는 안 된다.

공식 자료실의 일부 과거 항목은 목록에 있으나 다운로드 요청에 HTTP 200과 빈 본문을 반환했다. `dacom12`의 5건(서울 1, 제주 4)과 `dacom13`의 1건(서울)을 원문 내용이 없는 예외로 `verified_empty_source` 표시했다. 재개 수집기의 신규 빈 응답은 같은 파일을 두 번 더 조회해 확인하도록 했고, 그 전에 발견된 명시적 예외는 앞선 실패·재조회 기록을 보존했다. 이전 실패 이벤트와 최종 상태를 함께 보존하고, 유형별 감사에 빈 파일 수를 표시한다.

## 모델 개발 전 필요한 작업

1. 2015년 이후 API 조교 행을 공식 말 번호로 경주·출전 이력에 연결하고, 동일 자연키의 충돌과 비어 있는 마명을 규칙 없이 자동 병합하지 않는다.
2. 조교사 ID·소속 변경 이력과 과거 빈 `trName`을 대조해, 검증된 연결과 미확정 연결을 따로 표기한다.
3. Text 진료·장구·주행심사·당일 정보의 연도별 parser를 구축하고 경주·말 단위 연결율과 원문 대조율을 측정한다.
4. 원천에 기록된 조교일과 **실제 게시·관측 시각**은 다르다. 과거 원문을 재조회한 사실만으로 해당 정보가 당시 T−30분에 이용 가능했다고 주장하지 않는다. 예측 feature로 사용하기 전에 시간 가용성 정책을 고정해야 한다.
5. 위 품질표와 경주·말·조교사별 정량 커버리지가 완성되면, 시간순 연구 데이터셋을 새 버전으로 만들고 그때 학습을 재개한다.

## 검증 상태

두 API 원천은 총 **9,484,794행**이다. 9개 Text 유형의 목록 항목은 총 **52,885개**이며, 최종 상태가 없는 항목은 0개다. 그중 빈 원문은 위의 6개이므로 내용이 있는 파일은 52,879개다. 유형별 감사는 저장 바이트를 다시 읽어 SHA256, 목록 건수, 날짜 범위와 HTML 오응답 여부를 확인했으며 HTML 오응답은 0개였다. API 수집기는 원문 월·페이지의 hash와 총 행 수를 별도로 대조했다. 전체 감사 경로와 hash는 [통합 요약 JSON](../data/logs/historical_source_collection_summary_20260914.json)에 있다. 수집·감사 코드의 관련 Ruff 검사와 전체 pytest **673 passed, 2 warnings**를 확인했다. 기존 다른 작업의 파일은 수정하지 않았다.
