# 제주마 v13 조건 변화 보강과 2026년 고정 검증

## 목적

v12 오류 진단에서 나온 승급·중량·거리·직전 성적 재현 가능성을 시험한다. 한 마리 입상, 상위 세 마리 전체, 정확한 순서의 세 목표를 유지한다. 100% 근접은 지향점이며 검증 수치가 아니다.

## 고정 후보

- 기준: 기존 R_FORM 108개 변수와 HY_R_FORM 설계를 동일 분할에서 재학습한다.
- 기본 보강: 직전 등급, 등급 숫자 차이, 상위등급 이동 여부, 6→5등급 여부, 거리 변화, 직전 상대착순점수 6개 추가(114개).
- 결합 보강: 승급×중량 변화, 6→5×중량 변화, 직전 성적×중량 변화, 직전 우승×중량 변화, 직전 성적×거리 변화, 직전 성적×선행형 상대 수 변화, 승급×직전 성적 7개 추가(121개).
- 현재 등급·부담중량은 저장 출마표에서만 가져온다. 이전 경주는 같은 공식 ID의 T−2 이전 마지막 출전이다. 등급은 1~6이면서 같은 연도일 때만 비교한다. 공식 레이팅의 일괄 변경값을 자체 Elo에 적용하지 않는다.
- 결측은 결측으로 유지한다. 현재 결과·구간·마체중·날씨는 새 변수에 넣지 않는다.

## 독립 비교 절차

이미 정한 frozen_2026 분할을 그대로 사용한다. FIT/TUNE/CAL은 2025년까지이고 EVAL은 2026-01-02~09-12의 510경주·4,852출전행이다. 순위 모델 3종×seed 2개와 공통 순서 모델×seed 2개, 총8학습을 고정한다. 순위 확률 온도3회와 기준 모델의 순서 온도1회만 CAL에서 보정한다. 두 보강 하이브리드는 기준과 동일한 순서 모델·온도를 사용한다.

모든 2026년 점수를 저장하고 해시를 고정한 후 정답을 결합한다. EVAL을 본 재시도·특징 추가·재학습은 하지 않는다. 모델 가중치는 2025년에 고정하며, 말의 과거 이력은 대상 경주 T−2까지 순차 갱신한다. 따라서 연초에 한 번 연간 전체를 예측하는 검증은 아니다.

## 판단 기준

주 비교는 두 보강 하이브리드 각각과 HY_R_FORM의 집합 적중 차이다. 경기일 대응 bootstrap5,000회 seed17. 두 주 비교에 각각97.5% 양측 구간을 적용한다. 집합 적중 차이의 하한>0이며 한 마리·순서 적중 점추정이 감소하지 않을 때만 연구 후보로 인정한다. 둘 다 통과하면 결합형의 집합 적중률이 더 높을 때 결합형, 그렇지 않으면 기본형을 선택한다. 실전 자동 교체는 하지 않는다.

입상 확률 오차와 같은 연도6→5등급 집단 과신은 별도로 보고한다. 후자는 전체 해당 출전행을 사용하며 정답 사례만 고르지 않는다. 보조 지표95% 구간은 다중 비교 미보정 탐색으로 표시한다.

## 해석 한계

실제 출전마와 사후 수집된 날짜 표시 출마표를 사용한다. 원래 게시·수정 시점 증빙이 완전하지 않아 수요일 실전 정확도를 뜻하지 않는다. 이번 실행 후 2026년 기간은 검증에 사용한 자료로 기록하고 다시 미사용 자료라고 부르지 않는다. 후속 개선은 새로운 기간의 사전 저장 예측으로 검증한다.
