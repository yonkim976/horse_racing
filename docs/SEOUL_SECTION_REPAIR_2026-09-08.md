# 서울 구간기록 복원 및 화면 반영 · 2026-09-08

## 완료 사항

보관 공식 원본을 서울 완료 경주 출전 129,122건 모두와 연결해 재저장했다. 913개 dacom11 보고서와 174개 API 응답을 사용하고, 겹치는 출전은 최신 API 응답을 우선했다.

- 코너 시간 행 265,607개 추가: 1C 21,698 / 2C 23,219 / 3C 110,345 / 4C 110,345.
- 기존 행 432,701개 수정: 통과순위 복원, 기록 종류 및 수집 출처 명시. 실제 시간값 변경은 S1F 2개와 G1F 2개.
- 원문 `#####`를 S1F 값으로 잘못 저장한 G3F 행 4개 제거. 미제공 시간은 생성하지 않았다.
- 긴 지역 마명 때문에 파싱하지 못했던 완주기록 8건 복원. 해당 말의 누락 체중/증감/착차도 원문에서 보완.
- 서울 구간 행 총 698,308개. `time_basis`와 `source_kind`는 서울 전체 행에 지정됨.

## 저장 및 파서

`race_section_results.elapsed_time_ms`는 원본의 시간값을 밀리초로 유지한다. 신규 컬럼 `time_basis`는 `cumulative`(출발부터 누적) / `closing`(해당 지점부터 결승), `source_kind`는 `api4_3` / `dacom11`을 구분한다. 현재 서울의 분포는 다음과 같다.

| 종류 | 출처 | 행 수 |
|---|---|---:|
| closing | dacom11 | 220,686 |
| cumulative | dacom11 | 375,952 |
| cumulative | api4_3 | 101,670 |

웹은 명시된 종류를 우선해서 변환한다. 서울 복원 데이터에서 숫자 크기로 종류를 추정하지 않는다. 아직 종류가 지정되지 않은 다른 지역의 기존 자료에는 기존 호환 변환을 유지한다. 향후 API 및 dacom11 수집도 기록 종류를 함께 저장한다.

서울 dacom11은 고정폭 셀을 유지해 코너를 읽으며, 배당 빈칸과 `#####` 때문에 다른 항목이 당겨지지 않는다. 지역 접두어 및 긴 마명 잘림도 본문 기록 파싱에서 처리한다.

## 웹

- `/racecourses/seoul/distances`: 서울 거리별 분석, 연도·등급 필터, 완료 경주 및 정상 완주기록 집계. 서울/제주 전환 제공.
- 서울 경주 상세: 누적기록 / 인접 지점 간 구간시간 / 마지막 600m·200m 기록 분리.
- 서울의 3C·G3F·4C는 서로 다른 지점으로 유지. 1,000m S1F/3C, 1,600m S1F/2C, 1,700m S1F/1C만 해당 경주의 복수 말 기록과 제공 순위가 일치할 때 통합.
- 서울 경주로를 간결한 SVG와 기록 선택 패널로 교체. 주행 방향, 출발, 결승, 다른 출발점 옵션 제공. 좁은 화면에서는 기록 패널을 아래에 배치.

## 검증

- 서울 11개 거리의 최신 보유 경주 공식 웹 성적표를 각각 재조회했다. 1,100m는 2015-01-17 표본이다.
- 웹 표본 시간 셀 **813개 대조, 불일치 0개**. API 누적 G3F/G1F는 전체기록에서 빼서 웹의 막판 기록과 비교했다.
- 복원 스크립트 읽기 전용 재실행: 변경 0건, 추가 완주 복원 0건.
- SQLite `quick_check`: ok. `foreign_key_check`: 위반 없음.
- 전체 테스트 **352개 통과**. 수정 Python 파일 Ruff 검사 통과.
- 실제 브라우저에서 서울 1,700m 구간 선택, 거리/등급 필터 및 좁은 화면 배치 확인.

## 남은 정확도 범위

서울 공식 일반 용어해설의 코너 거리와 일부 내주로 경주의 측정 지점은 단순 대입으로 일치하지 않는다. 따라서 코너를 포함한 미확정 구간 길이는 `거리 미확정`으로 표시하고, 확정한 S1F·G3F·G1F·FIN의 거리만 수치로 표시한다. 지도는 공개 배치와 치수를 이용한 구조도이며 연장주로/연결부는 개략 형상이다. 코너 측정 좌표를 지도 위에 확정 위치로 표시하거나 이 SVG로 길이를 재는 기능은 제공하지 않는다.

성적표 하단의 경주 전체 선두 통과타임·펄롱타임은 별도 성격의 자료다. 이번 복원은 말별 결과·구간 기록을 대상으로 했으며, 경주 전체 타임을 위한 새 테이블 수집은 포함하지 않았다. 기존 분석용 추출 데이터·모델 파일은 재생성하지 않았다.
