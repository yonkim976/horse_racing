# RaceFit V3 생애주기·조교 상태 챌린저

## 목적

말의 나이, 직전 출전 후 경과일, 최근 조교량을 단순 원자료가 아니라 비선형 상태와 말별 기준 대비 변화로 표현한다. 모든 이력 윈도우는 목표 경주일보다 앞선 이벤트만 사용한다.

## 추가 변수

- 경마장 체계별 연령 단계와 전성기 전·후 개월 수
- 출전 간격 구간, `log(1 + 경과일)`, 41일 초과 휴양량
- 성장기 단기 재출전 및 고령 장기휴양 상호작용
- 최근 7일 대 28일 조교 빈도 비율
- 최근 28일 조교량과 직전 29~180일 말별 기준의 차이·비율
- 최근 28일 훈련일당 시간, 습보 및 구보 횟수

## 시간순 검증 결과

최근 상세 데이터 비교는 2025년으로 학습하고 2026년 1,624경주를 평가했다. 두 모델은 같은 `racefit_v1_core` 프로필과 LambdaRank 설정을 사용했다.

| 지표 | 기존 상세 모델 | V3 챌린저 | 변화 |
|---|---:|---:|---:|
| 우승 Log Loss | 0.27341 | 0.27199 | -0.00142 |
| 우승 AUC | 0.77577 | 0.77964 | +0.00386 |
| Top1 적중률 | 31.34% | 32.64% | +1.29%p |
| 우승마 Top3 포함률 | 64.10% | 64.78% | +0.68%p |
| 우승마 후보 5두 포함률 | 83.19% | 83.50% | +0.31%p |
| 실제 1·2위 모두 후보 5두 포함 | 61.21% | 61.33% | +0.12%p |
| 실제 1·2·3위 모두 후보 5두 포함 | 37.93% | 37.99% | +0.06%p |

경주 단위 paired bootstrap 95% 구간은 우승 Log Loss 변화가 `[-0.00266, -0.00014]`로 개선 방향이었고, Top1 변화는 `[-0.06%p, +2.65%p]`였다. 확률 품질 개선은 비교적 일관됐지만 적중률 증가는 아직 경계 수준이다.

최종 챌린저에서 새 변수군은 전체 LightGBM gain의 3.11%를 차지했다. 새 변수 중에는 최근 28일 조교량의 개인 기준 대비 차이, 경마장별 연령 단계, 7일/28일 조교 빈도 비율이 가장 많이 사용됐다. 반면 `41일 초과 휴양량`과 `고령 장기휴양`은 최종 트리에서 사용되지 않아 다음 반복에서 제거 후보로 둔다.

장기 이력(2022~2025, 9,778경주)에 생애주기 변수만 추가한 결과는 기존 모델보다 악화됐다.

| 지표 | 기존 장기 모델 | 생애주기 추가 | 변화 |
|---|---:|---:|---:|
| 우승 Log Loss | 0.27291 | 0.27440 | +0.00150 |
| 우승 AUC | 0.76963 | 0.76568 | -0.00395 |
| Top1 적중률 | 31.46% | 31.36% | -0.10%p |
| 우승마 Top3 포함률 | 63.04% | 62.54% | -0.50%p |

또한 1~5위 전체를 직접 최적화한 Top5 LambdaRank에서는 기존 상세 모델 대비 V3가 악화됐다. 우승 Log Loss는 0.27516에서 0.27677로, Top1은 32.39%에서 31.47%로 변했다.

## 채택 결정

- 우승·축마 확률용 최근 상세 모델에는 V3를 챌린저로 채택한다.
- 장기 운영 모델과 Top5 순위분포 모델은 기존 버전을 유지한다.
- V3의 후보 5두 포함 개선은 매우 작으므로 삼연승 조합 생성 로직의 기본 모델로 승격하지 않는다.
- 새 데이터가 누적되면 2027년 완전 미래 구간에서 다시 검증한 뒤 정식 운영 승격을 판단한다.
