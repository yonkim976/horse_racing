### V5 보정 속도지수 계약

과거 한 경주의 말별 속도지수는 `100 × log(실제속도 / 보정 기준속도)`로 계산한다.
기준속도는 해당 경주일보다 앞선 730일의 경기장×정확거리 기록만 사용하며, 주로상태별
표본이 12경주 이상이면 같은 주로상태를 우선하고 부족하면 정확거리 20경주 이상으로
fallback한다. 기준속도 계산에는 같은 날 결과를 넣지 않는다.

이미 끝난 과거 경주의 당일 track variant는 그날의 다른 거리 결과까지 이용해 사후
보정할 수 있지만, 이 지수는 이후 날짜의 예측에만 사용한다. 같은 날짜 경주의 결과는
날짜 단위 일괄 갱신 뒤에야 이력에 들어가므로 당일 예측으로 누수되지 않는다. 최근 지수
커버리지는 94.0%, 동일거리 지수는 77.8%, 단독 누수 카나리는 0개였다.

고차원 조합 문자열 4개(`course_distance_key`, `course_distance_gate_band`,
`style_pace_key`, `style_gate_key`)는 트리 모델의 원변수 상호작용과 중복되어 valid에서
과적합을 만들었다. `ability_v2_core`에서는 이를 제거하되 강선행마 수·경합 강도·게이트
구역 원변수는 유지한다.

## Plackett–Luce 순서 3두 가치진단 — 2026-09-01

V5의 보정된 `P(win)`을 Plackett–Luce worth로 사용해 상위 4두의 순서 3두
24조합을 만들었다. 조합확률은
`p(i→j→k)=pᵢ×pⱼ/(1−pᵢ)×pₖ/(1−pᵢ−pⱼ)`이며, 동착은 공식 착순이 허용하는
모든 적중 순서를 생성한다. 조합별 `확률×배당−1`이 임계값보다 큰 표만 1단위씩 산
확정배당 사후진단이다.

- 진단 run_id: `80c8eb75-cc0b-4673-828b-b890d64b63d9`
- valid 669경주, 상위 4두 24조합 16,056건
- 정상 확정배당 16,045건, 평균 PL 4두 박스 적중확률 27.45%
- `EV>0`: 8,671베팅/649경주, 경주당 13.36표, 표본 ROI +24.53%
- `EV>0.10`: 7,891베팅/638경주, 표본 ROI +29.87%
- `EV>0.30`: 6,570베팅/603경주, 표본 ROI +35.08%
- `EV>0` 경주 bootstrap 95% 구간은 **-28.05%~+85.23%**로 0을 넓게 포함
- `EV>0`은 3월 +63.86%, 4월 -11.07%, 5월 +16.01%로 월별 편차가 큼
- 최고 환급 1건 제외 ROI +3.94%, 상위 3건 제외 ROI -14.08%

따라서 양(+) 표본 ROI는 흥미롭지만 고배당 소수 적중에 의존하며 수익성 증거가 아니다.
PL이 계산한 EV 구간과 실현 ROI도 단조롭지 않아 순서조합 확률의 별도 calibration이
필요하다. 기존 test는 열지 않았고, 구매시점 배당이 수집되면 `EV>0`을 1차 연구 기준으로
고정한 미래 paper trading에서 재검증한다.

재현 명령:

```bash

  --run-id 9ef33e36-dfd0-4fc4-b395-cbec2531bde3 \

```

## V6 거리·계절 게이트 보정 실험 — 2026-09-01

출발 게이트 효과가 경기장 평균이 아니라 정확거리와 계절에 따라 달라지는지를 모델에
반영했다. 과거 3년의 정상 착순만 사용하며, 각 경주의 출전두수로 `3/출전두수` 기대
입상 슬롯을 계산한다. 게이트는 출전두수 대비 안쪽·중간·바깥쪽 3구역으로 정규화했다.

- 모든 값은 대상 경주일보다 **엄격히 이전 날짜**의 결과로만 계산
- `경마장×정확거리×게이트`는 경마장 게이트 평균으로 수축
- 계절·주로·계절×주로 세부값은 정확거리 부모값으로 추가 수축
- 동일일 착순을 뒤집어도 feature가 변하지 않는 누수 테스트와 3년 이전 표본 탈락 테스트 통과
- 표본이 전혀 없는 거리·조건은 중립값 100으로 fallback

6개 지수 전체를 넣은 형식은 최근 valid win LL이 0.2683으로 core 0.2676보다 나빠
기각했다. 분리 ablation에서는 주로·5중 결합 지수가 잡음을 늘렸고, 정확거리와 계절
두 지수만 남긴 `ability_v2_gate` 프로필이 가장 안정적이었다.
