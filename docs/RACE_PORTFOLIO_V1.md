# RacePortfolio V1

RacePortfolio V1은 RaceFit V5 Sand Event의 말별 우승확률을 승식별 ticket 확률과
구매 금액으로 변환하는 연구용 계층이다. 현재 상태는 `RESEARCH_ONLY`이며 실전
배팅용으로 승격되지 않았다.

## 구조

1. RaceFit V5의 경주별 `prob_win`을 Plackett–Luce 순위 분포로 확장한다.
2. 단승, 연승, 복연승, 쌍승, 삼복승 ticket의 적중확률을 계산한다.
3. Logistic beta calibration으로 승식별 적중확률을 보정한다.
4. LightGBM quantile regression으로 최종배당의 q20과 중앙값을 예측한다.
5. q20 기준 기대환급이 원금 이상인 ticket만 남기고, 예산을 정수 단위로
   배분하여 원금 회수 확률을 최대화한다.
6. 개별 ticket 확률 5% 미만 또는 포트폴리오 원금회수확률 10% 미만은
   자동으로 `PASS`한다.

최종배당은 배당 모델의 학습 target과 사후 정산에만 사용한다. RaceFit 능력
모델의 입력이나 ticket 선택 시점의 실제배당으로는 사용하지 않는다.

## 최신 연구 결과

- 학습: 2026-01-01~2026-04-30
- 검증: 2026-05-01~2026-06-30
- 연구 테스트: 2026-07-01~2026-08-31
- 생성 ticket: 495,331개
- 안전장치 적용 후 검증 구매: 1경주
- 안전장치 적용 후 테스트 구매: 0/367경주

| 고정 기준선 | 테스트 적중률 | 테스트 ROI | 최고 수익 3경주 제거 ROI |
|---|---:|---:|---:|
| 1순위 연승 | 64.02% | 91.16% | 89.43% |
| 1순위 단승 | 33.33% | 98.33% | 90.96% |
| 1-2순위 복연승 | 27.25% | 75.80% | 69.81% |
| 1-2순위 쌍승 | 8.72% | 94.58% | 70.16% |
| 1-2-3순위 삼복승 | 5.72% | 62.53% | 42.61% |

이 결과는 2026년 자료를 이미 반복 탐색한 연구 결과다. 1순위 단승 ROI 98.33%도
최고 수익 3경주를 제거하면 90.96%로 낮아지므로 수익성을 입증하지 못했다.

## 실행

```bash
.venv/bin/python scripts/run_race_portfolio_v1.py
```

실행 결과는 `data/experiments/race_portfolio_v1/<run_id>/`에 저장된다.

- `model.pkl`: 확률 보정과 배당 분포 모델
- `scored_tickets.parquet`: 전체 ticket 확률과 예측배당
- `test_selections.parquet`: 안전장치를 통과한 테스트 구매표
- `manifest.json`: 설정, 지표, 승격 상태
- `report.md`: 사람이 읽는 결과 보고서

## 승격 조건

연구 테스트에서 아래를 모두 만족해야 `PROMOTED`로 바꾼다.

- 구매 경주 50개 이상
- ROI 100% 이상
- 최고 수익 3경주 제거 ROI 95% 이상

최종 승격은 과거 구간을 다시 조정하여 하지 않고, 2026-09 이후 append-only
paper betting 원장으로 확인한다.
