# 제주 심판 사건 연결·전개 후보 진단 계획

이번 단계는 보유 리포트로 말별 사건 연결의 품질과 과거 사건의 다음 출전 활용 가능성을 검증한다. 경주 종료일2026-09-12, 기존 모델·예측·DB 유지. 신규 학습과 전수 과거 수집에 앞선 데이터 검증 단계다.

1. 2025~2026 보유 리포트의 본문을 경주키로 기존 제주마 출전행에 연결한다. 말 번호와 말 이름이 모두 맞아야 사건을 연결한다. 원문, 문장 위치, 출처 해시, 수집시각, 언급된 말, 실제 피해 말, 진술/심판 서술, 구간을 보존한다.
2. 우선 대상은 진로 막힘/진로 제약, 외곽 주행, 주행 불편이다. 2025년1월 예문으로 보수적 규칙을 만든다. 피해 역할이 명시된 구문만 자동 연결하고 다중 사건·진술·역할 불명확 문장은 검토 대기한다. 미언급=정상으로 취급하지 않는다. 추가재결은 시점 불명확하므로 예측용 이력에서 제외한다.
3. 규칙 고정 후 2025년7~12월에서 해시 순서로 자동 연결32문장과 대기16문장을 추출해 원문과 역할을 수동 대조한다. 이 표본을 본 뒤 같은 버전 규칙을 수정하지 않는다. 정확도는 문장 전체 피해말 집합 일치로 판단하고, 전체 리포트 재현율로 일반화하지 않는다. 신뢰구간과 미연결률을 함께 보고한다.
4. 전개 후보와 기존 모델의510경주 예측에서 새로 맞힌/잃은 집합, 공통 적중, 공통 실패를 분해한다. 교체된 말의 입상 여부와 누락마 순위, 과거 전개 변수 및 당일 사후 위치를 별도 저장한다. 사후 상황을 실제 원인으로 단정하지 않는다.
5. 새 입력은 T−2 이전 직전 출전의 보고서 보유 여부, 명시된 사건 유형, 사건 후 경과일로 제한한다. 연결된 리포트가 있어도 미언급은 ‘추출된 사건 없음’이고 정상 라벨이 아니다. 실제 최초 게시 시각·수정 이력을 복원하지 못한 한계를 명시한다.
6. 기존2026 개별 말 입상확률을 고정하고, 직전 명시 사건군의 실제 입상률·예측확률·잔차를 관찰한다. 직전 비입상군도 별도로 본다. 경기일 bootstrap5,000회로 잔차 구간을 제시한다. 이는 기존 점수가 해당 집단을 과소평가하는지 확인하는 진단이며 새로운 모델의 적중률 검증이 아니다. 목표A/B/C별로 수정 가설을 좁힌다.
7. 정확성·T−2·누락과미언급 구분·말 역할 오연결 방지 테스트와 해시 재현 검증을 수행한다. 데이터 상태와 표본 수에 근거해 다음 학습/백필 범위를 정하고 결과 보고서를 작성한다.

2026년은 이미 사용한 개발 기간이다. 사후 표본 분석의 유의성이나 적중 상승을 독립 검증이라고 부르지 않는다. 영상은 이번 범위에서 제외한다.
