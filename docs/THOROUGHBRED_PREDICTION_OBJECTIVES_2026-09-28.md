# 더러브렛 예측 목표 재정의 — 우승축·착순·동반 후보

결정일: 2026-09-28. 상태: 사용자와 합의한 후속 연구 목표. 구현·학습·성능 검증 완료를 뜻하지 않는다.

서울·부산의 보유 자료로 데이터 분석을 먼저 진행한 뒤, 아래 목표에 맞춰 모델을 비교한다. 신규 자료를 기다리는 것을 연구의 선행 조건으로 삼지 않는다. 현재 운영 모델은 비교 기준으로 보존한다.

## 1. 용어와 사용자 의도

- **축마 = 1등할 것으로 예상하는 말(우승 예상마).** 선행마나 단순 입상 안정마라는 의미로 사용하지 않는다.
- 선행마는 초반 주행 위치·전개 특성이다. 우승 예상 여부와 별개의 속성이다.
- 동반 후보는 선택한 축마의 뒤를 이을 2·3착 후보, 또는 해당 승식에서 함께 적중할 후보다. 어떤 조건인지 명시한다.
- ‘정확히 3착’과 ‘3착 이내’를 구분한다. 축마 선택은 실제 경주를 바꾸는 개입이 아니라 예측 분포에서 조건을 지정하는 동작이다.
- ‘쌍축’이라는 말만으로 두 말의 동시 우승을 가정하지 않는다. 후속 출력에서는 **우승 후보 2두 중 하나가 우승**, **두 말이 1·2위 동반**, **두 말이 3위 이내 동반**, **1→2위 고정** 중 해당 조건을 표시한다. 이 네 의미를 동일하게 취급하지 않는다. 기본 UI 용어 선택은 구현 전에 확정한다.

## 2. 필수 말별 출력

전체 출전마를 대상으로 다음을 제공한다. 추천 5두만 확률을 계산하지 않는다.

| 항목 | 정의 | 용도 |
|---|---|---|
| 우승 확률 | P(착순=1) | 축마 후보 |
| 2위 이내 확률 | P(착순≤2) | 1·2위권 평가 |
| 3위 이내 확률 | P(착순≤3) | 입상 후보 평가 |
| 정확히 2위 확률 | P(착순≤2)−P(착순=1) | 2착 후보 |
| 정확히 3위 확률 | P(착순≤3)−P(착순≤2) | 3착 후보 |

기본 화면에는 앞의 세 확률, 상세에는 정확한 2·3위 확률을 함께 제공하는 방향이다. 확률은 모델 추정치이며 실제 적중 빈도와의 일치 여부를 별도 검증한다.

## 3. 공통 착순 분포와 승식별 출력

설계 방향은 서로 다른 말 i, j, k의 `Q(i,j,k)=P(1위=i, 2위=j, 3위=k)`를 구성하고, 필요한 경우들을 합산해 말별·승식별 확률을 얻는 것이다. 단일 학습기 사용을 확정한 것은 아니다. 우승·입상 점수를 별도로 학습하는 방식도 비교하되 최종 확률의 일관성을 검증한다.

동착이 없고 정상적으로 상위 3위가 확정되는 경주의 기본 계약은 다음과 같다.

- Q는 음수가 아니며 전체 합은 1이다.
- 각 말의 우승 확률 ≤ 2위 이내 확률 ≤ 3위 이내 확률이다.
- 모든 말의 우승 확률 합은 1, 2위 이내 합은 2, 3위 이내 합은 3이다.
- 말별 확률을 단순 곱해 동반 입상 확률을 만들지 않는다.
- 동착·실격·미완주·출전취소의 학습 및 정산 규칙은 데이터 계약에서 별도로 확정한다. 엄격한 순열 계약을 예외 경주에 그대로 적용하지 않는다.

| 승식 | 필요한 사건 |
|---|---|
| 복승 | 지정 두 말이 순서 없이 1·2위 |
| 쌍승 | 지정 두 말이 순서대로 1→2위 |
| 복연승 | 지정 두 말이 모두 3위 이내 |
| 삼복승 | 지정 세 말이 순서 없이 1·2·3위 |
| 삼쌍승 | 지정 세 말이 순서대로 1→2→3위 |

승식 정의 참고: [한국마사회 안내자료](https://board.kra.co.kr/down/KRAFile_per_BoardNo/1250/20210527132436227737.pdf), 2026-09-28 확인. 이 문서의 다섯 승식 범위는 복승·쌍승·복연승·삼복승·삼쌍승이다.

## 4. 축마 선택 이후의 동반 후보

축마 A를 선택하면 다음을 구분해 제공한다.

1. A 자체의 우승 확률.
2. A가 우승한다는 조건에서 B가 2위일 확률, C가 3위일 확률, B·C가 함께 2·3위를 차지할 확률.
3. 조건을 떼고 계산한 실제 조합 확률: A→B 쌍승, A→B→C 삼쌍승 등.
4. 복승·복연승·삼복승에서는 A의 우승을 강제하지 않은 해당 승식의 전체 적중 확률.

가상 예: A 우승 30%, A 우승 조건에서 B 2위 40%이면 A→B 쌍승 확률은 12%다. 조건부 40%를 실제 적중 확률로 표시하지 않는다. 이 곱은 조건부 확률의 정의에 따른 것이며, 두 말의 독립성을 가정한 곱이 아니다.

축마를 바꾸면 조건부 후보 순위가 달라질 수 있다. 전개·편성의 상호작용을 반영하는 것은 연구 가설이며, 이러한 설명을 모델이 이미 검증해 구현했다는 뜻은 아니다. 조건 사건의 확률이 0이면 조건부 확률은 미정으로 처리하고, 극히 작으면 안정성 정보를 함께 표시한다.

## 5. 추천 5두와 조합 구성

추천 5두는 역할(우승 후보·2착 후보·3착 후보·순서 없는 입상 후보)을 표시한다. 핵심 집합 평가는 **선정한 5두 안에 실제 1·2·3위가 모두 포함되는가**다. 말별 입상 확률 상위 5두를 단순 기준선으로 두고 조합 분포를 활용한 선택과 비교한다. ‘5위 이내 확률을 예측하는 문제’와 구분한다.

축마 미선택 시 전체 상위 3두 포함 확률을, 우승축 고정 시 그 말이 우승하고 나머지 두 말이 동반 후보에 포함될 확률을 구분한다. 전자는 후자의 성공을 보장하지 않는다. 축이 불확실한 경주도 표시한다.

같은 총 5두라도 삼복승 전체 조합은 10개, 1두 고정+4두 동반은 6개, 2두 고정+3두 동반은 3개다. 추천 수 확대 자체를 성능 개선으로 판단하지 않고 같은 두수·조합 수 또는 총비용 조건에서 비교한다. 여러 마권 중 하나 이상 적중할 확률은 사건의 합집합으로 계산한다. 복연승처럼 여러 조합이 동시에 적중할 수 있으면 확률의 단순 합을 적중 확률로 쓰지 않는다.

## 6. 평가 목표와 진행 순서

| 층위 | 평가 내용 |
|---|---|
| 말별 확률 | 우승·Top2·Top3 각각의 Brier/log loss와 보정 상태, 확률 구간별 실제 적중 빈도 |
| 선택 결과 | 우승축 적중률, 명시한 조건별 두 말의 동반 적중률, 추천 5두의 실제 상위 3두 포함률 |
| 승식 조합 | 다섯 승식의 확률 정확성 및 고정 조합 수·비용에서의 적중률 |
| 실용성 | 배당과 비용을 반영한 성과를 정확성과 별도로 평가; 소수 고배당 적중 의존도 확인 |

서울·부산, 기간, 거리, 편성 크기별 표본 수와 불확실성을 함께 보고한다. 하나의 최고 적중률만으로 최종 모델을 결정하지 않는다. 세부 지표 우선순위, 후보 수, 학습 가중치 및 채택 기준은 실험 전에 고정하고 평가 결과를 본 뒤 유리하게 바꾸지 않는다.

기존 자료를 시간순으로 나누고 이전 자료만으로 학습·변수 선택·확률 보정을 수행한다. 이미 여러 차례 관찰한 기간은 새로 나누어도 완전히 독립적인 미관측 테스트라고 부르지 않는다. 최신 최종 가중치로 과거 학습 구간을 재예측한 값을 공정한 과거 성능으로 사용하지 않는다.

기존 자료에 예측 마감 시점 배당이 없다면 배당 기반 선택 전략의 실전 검증은 제한된다. 최종 배당을 사전에 알고 조합을 선택한 것처럼 평가하지 않는다. 적중 가능성 개선을 수익성 개선과 동일시하지 않는다.

다음 작업 순서는 데이터 품질·시점 계약 → 기록/환경·게이트·전개 분석 → 소수 변수 기준선 및 기존 구조 비교 → 변수 묶음 추가/제거 → 위 출력·평가 확장이다. 데이터 분석의 순서는 [재시작 계획](THOROUGHBRED_RESTART_PLAN_2026-09-28.md)을 따른다. 예측 목표와 축마 용어는 이 문서가 그 계획의 A/B/C 중심 목표를 확장·명확화한다. 이전 계획은 정리 감사의 보존 문서이므로 덮어쓰지 않는다.

## 7. 현재 구현과의 관계

기존 A(말별 입상), B(순서 없는 상위 3두), C(정확한 상위 3착)는 비교 지표로 유지한다. 현재 코드에도 우승·Top2·Top3를 계산하는 기능이 있지만, 새 목표 전체가 검증된 상태는 아니다. A와 B/C의 모델·보정 설정이 다르므로 기존 출력들을 그대로 혼합해 하나의 일관된 분포라고 간주하지 않는다.

운영 프로필은 `thoroughbred-main-20260919-v1`이다. 등록부·운영 가중치·DB·제주 모델 변경 없이 연구 목표를 기록했다. 새 모델의 학습이나 운영 승격은 이번 문서 작성에 포함되지 않는다.

## 8. 실제 폴더 구조 (2026-09-28 확인)

현재 프로젝트 전체가 더러브렛 전용인 것은 아니다. 제주·더러브렛, 공통 수집·DB·웹 코드가 `horse_racing` 아래 함께 있다. 연구 이름/파일명과 운영 등록부 도메인으로 구분되며, 더러브렛 전체를 담은 독립 패키지 하나로 모여 있지는 않다.

| 위치 | 현재 역할 |
|---|---|
| `data/research/thoroughbred_*` | 더러브렛 데이터셋·모델·추론 코드·실험 기록이 여러 폴더에 분산 |
| `research/thoroughbred_*` | 최근 입력 목록·전개/게이트 분석·재시작 정리 감사 |
| `docs/THOROUGHBRED_*` | 더러브렛 설명·가설·목표 문서 |
| `scripts/` | 제주·더러브렛·공통 실행 스크립트가 함께 있음 |
| `src/horse_racing/analysis/` | 공통 분석 모듈과 제주 전용 모듈 등이 함께 있음 |
| `src/horse_racing/{collectors,db,services,web}/` | 프로젝트의 수집·저장·서비스·화면 코드 |
| `config/prediction_model_registry.json` | 더러브렛과 제주 운영 프로필을 도메인별로 구분 |

더러브렛 최종 가중치 위치:

- A: `data/research/thoroughbred_offline_20260918_v5/windows/models/2026H2/rolling_all/top3.txt`
- B/C 입상 점수: `data/research/thoroughbred_followup_20260918_v4/model/models/2026/top3_growth_strength/top3.txt`
- C 순서 점수: `data/research/thoroughbred_win_research_20260918_v2/models/2026/H3_relative/model.txt`

가중치 외에 메타데이터·보정값·추론 코드도 필요하다. 과거 버전 이름의 폴더가 남아 있다고 해서 폐기한 학습 가중치가 그대로 남아 있다는 뜻은 아니다. 원천 데이터·코드·보고서·현재 모델 의존성은 보존되어 있다.

향후 구조 개선안은 **공통 원천과 수집 기능은 공유하고, 새 더러브렛 연구의 코드·설정·결과는 전용 경로로 모으는 방식**이다. 이는 제안이며 이번에 폴더를 이동하지 않았다. 기존 경로 이동은 등록부와 코드의 참조 관계를 점검한 뒤 별도 작업으로 진행한다.
