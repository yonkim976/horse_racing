# 제주마: 세 목표 분리와 과거 심판 리포트 활용 방향

> **현재 우선순위(2026-09-18 사용자 재지정): 배당·회수율 연구 보류, A/B/C 적중률 개선 우선.** 모델·자료 정리와 다음 후보 두 개의 실행 범위는 [적중률 재정비 계획](JEJU_ACCURACY_RESET_AND_ASSET_REVIEW_2026-09-18.md)을 따른다. 아래 단계별 우선순위는 당시 결정 이력이며 최신 계획을 대체하지 않는다.

2026-09-16 사용자 협의 반영. 이번 문서는 후속 연구 방향이며 새 모델의 학습·성능 개선 완료 보고가 아니다.

## 범위와 기존 계획과의 관계

- 경기 자료의 마지막 날짜는 2026-09-12로 고정한다. 이후 경기 확보를 개발의 전제 조건으로 두지 않는다.
- 영상 수집·분석은 후순위로 미룬다. 현재 저장된 심판 리포트의 정형화·결과 연결을 먼저 검토한다.
- 기존 평가 산출물과 봉인된 예측은 보존한다. v13 이후 계획의 '미래 자료가 있어야 다음 개선 가능'이라는 해석을 이 방향으로 대체한다.
- 이미 성적을 확인한 2025·2026년을 다시 미사용 최종 검증이라고 부르지 않는다. 기존 자료의 시간 순서 회고 검증으로 후보를 비교하고 탐색 이력을 공개한다.

## 세 목표의 독립된 후보 선택

| 구분 | 출력 | 주 평가 | 보조 평가 |
|---|---|---|---|
| A 한 마리 입상 | 말별 입상 확률과 선택한 한 마리 | 선택한 말의 공식 3위 이내 적중 | Brier·로그손실·확률 보정 |
| B 입상 세 마리 | 순서 없는 정확한 세 마리 집합 | 실제 입상 세 마리와 집합 일치 | 0/1/2/3마리 겹침, 누락마 예측 순위 |
| C 정확한 순서 | 1·2·3위 순서 | 전체 경주의 정확한 순서 적중 | 집합 적중 경주에서의 순서 적중, 공통 집합에서 순서 모델 비교 |

목표별 기준·후보·채택 판정을 따로 둔다. 모든 목표가 동시에 개선되어야 개별 목표 후보를 인정하는 기존 통합 조건은 후속 실험에 적용하지 않는다. 세 모델의 다른 목표 성적도 함께 보고한다. C의 조건부 순서 적중만으로 전체 정확한 순서 적중을 대체하지 않는다. 경주 선별을 도입한다면 전체 경주 성적과 선별 비율·표본 수를 병기한다.

## 확인한 기존 자산

- 운영 DB를 읽기 전용 조회한 결과, meet=2 심판 리포트는 2025년 722건(01-03~12-27), 2026년 516건(01-02~09-12)이다. 이는 보고서 행 수이며 제주마 모델의 적격 경주 수·말 연결 완료 수가 아니다.
- `race_steward_reports`, 수집 서비스와 CLI가 존재한다.
- E9-A/B 사건 추출 코드는 재사용 가능성 검토 대상이다. 기존 평가는 서울의 사건 포함 30문서·단일 AI 기준 라벨에서 precision 81/82, recall 81/121이었다. 제주 정확도나 예측 개선의 증거가 아니다.
- 현재 확인한 DB에는 2025년 이전 제주 보고서 행이 없다. 다른 보관 원천의 존재와 연도별 지원 범위는 미확인이다. 과거 보고서 부재를 사건 없음으로 채우지 않는다.

## 정형화와 연결

1. 원문·출처·수집 시각·게시/수정 시각 증빙·해시·추출 버전을 보존한다. 수집 시각을 과거 게시 시각으로 간주하지 않는다.
2. 경마장+경주일+경주번호로 경주를 연결하고, 해당 경주의 출주번호와 마명을 대조해 공식 말 ID를 연결한다. 충돌은 보류한다.
3. 원문 근거 구절, 사건 종류, 발생 구간, 관련 말, 피해/행위/역할 미상, 확정 관찰/기수 진술/검사 결과, 부정·추정·판정 보류를 구분한다.
4. 초기 범위는 출발 지연, 진로 막힘·제어, 접촉, 진로 방해다. 건강·검사와 기수 진술은 별도 범주로 보존하고 초기 사건 변수에 자동 합산하지 않는다.
5. 보고서 미확보, 보고서 내 미언급, 추출 판정 불가, 확인된 사건을 분리한다. 미언급·미추출은 실제 무사건의 증거가 아니다.
6. 제주 표본에는 사건 포함 문서와 미언급 문서를 모두 포함하고, 추출 출력과 착순을 보지 않는 판독을 가능한 범위에서 실시한다. 말 오귀속·역할·부정·다중 말 문장과 사건별 누락을 확인한다.

## 결과 연결의 두 용도

- 사후 진단: A경주의 리포트와 A경주의 착순·구간·기존 예측 오차를 연결한다. 어떤 관측 사건이 오판에 함께 나타나는지 확인한다. 사건이 착순을 일으켰다는 인과로 단정하지 않는다.
- 사전 예측: A경주 리포트에서 확인한 과거 사건을 같은 말의 다음 B경주 이전 이력으로 연결한다. B경주의 리포트·결과는 B의 입력에 넣지 않는다. 기존 T−2 경계와 공개·수정 시점 적격성을 별도 확인한다. 공개 시각이 불명확한 자료는 회고 가정으로 표시하며 실전 사전 가용성 증빙과 구분한다.
- 비교 모집단은 다음 출전 결과가 2026-09-12까지 관측된 적격 사례다. 마지막 출전 이후 결과 미관측을 실패로 처리하지 않는다.
- 인기마 인터뷰와 검사 대상은 선택된 집단이다. 인터뷰/검사 없음으로 정상이나 문제 없음을 추정하지 않는다. 보고서 내용은 공식 관찰·진술·검사에 따라 증거 수준이 다르다.

## 모델 실험을 분리하는 원칙

최근 v13은 기존 순위 학습 방식에 새 조건 변수를 추가하고 처음부터 재학습한 보강 실험이었다. 새 하이브리드의 순서 모델은 공통으로 유지했다. 과거에는 별도 집합·순서 학습 방식도 시험했지만, 매번 완전히 다른 모델을 만든 것은 아니다.

후속 비교는 목표별로 다음 순서를 따른다.

1. 기준: 기존 입력+기존 학습 방식.
2. 정보 보강: 기존 입력+과거 심판 사건, 기존 학습 방식으로 재학습.
3. 학습 방식 변경: 동일한 기존 입력으로 목표별 학습 방식만 변경.
4. 결합: 개별 비교 결과가 유망할 때만 정보 보강과 학습 방식 변경을 함께 시험.

부진 기록을 임의로 삭제하거나 방해마다 일정 점수를 가산하지 않는다. 단발성 피해와 반복되는 출발·주행 문제의 예측 효과를 분리해서 검증한다. 후보 수·설정 선택 구간·채택 기준은 각 실행 전에 고정한다.

## 진행 순서와 완료 기준

1. 기존 후보의 평가 기간·입력·학습 조건을 대조하고 세 목표별 기준표 작성. 비교 불가 후보는 분리 표시.
2. 누락 입상마의 예측 순위, 2마리 적중의 마지막 선택, 집합이 맞은 경주의 순서 오류를 분해. 결과를 보고 가설을 만든 사실을 기록.
3. 기간별 성능·표본 수·학습 수렴을 확인. 시간 순서 분할에서 설정 선택은 평가 구간보다 앞선 자료만 사용. 이미 확인한 기간이라는 한계는 유지.
4. 심판 원문 확보·연결·추출 품질과 시점 적격성 점검은 1~3단계와 함께 준비. 모델 입력과 사후 설명 데이터를 분리해 저장.
5. 적격한 과거 심판 사건 보강을 먼저 제한된 후보로 평가. 추출 정확도와 다음 경주 예측 성능을 따로 보고. 보고서 보유 집단의 동일 경주 비교와 전체 대상 경주 성적·결측 범위를 함께 제시.
6. 전개·능력 변화의 학습 방식 실험은 심판 보강과 구분해 진행. 기간별 경기일 대응 불확실성과 세 목표별 결과로 판단.

이번 턴에서는 위 방향과 기존 자산을 확인했다. 제주 심판 사건의 전수 추출·모델 연결·추가 학습은 아직 수행하지 않았다.
