## 최소 사건 계약

원문이 명시하는 다음 세 유형만 우선 다룬다: **출발 지연, 주행 중 진로/접촉 방해, 진로 막힘 또는 제어**. ‘피해를 받은 말 / 행위를 한 말 / 역할 불명’을 구분한다. 모래 반응만 있는 사례는 기존 기능과의 중복으로 별도 표시한다.

각 사건에는 race/source/raw hash, 문장 또는 span 위치, 식별된 말의 source key, 사건 유형, 역할, 명시된 위치/구간, 추출 규칙 버전, 명확/모호 판정과 사유를 남긴다. 명시되지 않은 거리 손실·초 단위 손실·severity 점수·승률 보너스를 만들어 넣지 않는다. 주행상의 관측에서 의학적 상태나 인과 효과를 단정하지 않는다.

여러 말이 한 문장에 등장하면 귀속 근거를 분리한다. 이름 부분일치·같은 이름·번호 충돌·부정문·조건문·인용·추정 표현은 반례로 다룬다. 불명확한 사건은 abstain/unknown으로 남기고 ‘사건 없음’과 구분한다. 원문 미확보·보고서 미수집도 사건 없음으로 채우지 않는다.

## 구현과 검토 산출물

격리된 작은 rule-based 추출기와 사건 evidence 테이블을 만든다. 60개 보고서에는 원문에 근거한 검토용 라벨을 별도 열로 기록하고 추출 결과와 불일치·미귀속·누락 사례를 공개한다. 같은 에이전트가 만든 검토용 라벨을 독립 전문가 gold standard라고 부르지 않는다. 규칙을 고치는 데 읽은 보고서를 독립 test라고 부르지도 않는다.

기존 sand 추출과의 중복, 추가 사건을 가진 report/horse 수, 표본별 유효 식별·abstain·결측 수를 보고한다. 이 수량은 정보 존재·추출 가능성의 지표이고 예측력 지표가 아니다. 추가 정보가 거의 없거나 귀속 신뢰도가 낮으면 억지로 후보를 만들지 말고 보류 결론을 낸다.

보고서의 source observation/publication/effective 시각은 분리한다. 사후 수집된 과거 보고서는 `retrospective_only / availability_unverified`로 남긴다. 후속 feature에서는 사건 경주일이 target 경주일보다 엄격히 이전이어야 하며, 실제 공개 지연을 검증하지 않고 다음 날부터 알려졌다고 단정하지 않는다.

회귀 테스트는 문장별 피해자/행위자 구별, 다중 말 귀속, 부정·모호 표현, 식별 충돌, 결과/다음 경주 데이터 없이 추출 가능함, 입력 순서 불변에 집중한다. 실제 모델 dataset의 136열을 수정하지 않는다.
