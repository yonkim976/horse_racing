기준: 2026-09-30, 로컬 SQLite와 Supabase `horse-racing-prod` (`xkykmhhkjtosptoibduo`).

## 결과

- 공식 KRA 출마표 API78의 `equipCrs` 원문과 장구 `+`(신규)·`-`(해제)를 2017-01-01~2026-09-30 경주에 소급 연결했다. 대상은 운영 DB에 출전행이 있는 경주일·경마장 2,648개 조합이며, 양쪽 DB의 원문 조회 이력이 모두 2,648개 조합을 덮는다. 처리 실패 또는 재실행 대기 조합은 0개다.
- 이 기간 운영 출전행 238,278건 중 238,174건(99.96%)에 API78 장구 출마표 원문과 관측 시각이 연결됐다. 남은 104건에는 원문이 연결되지 않았으므로 `장구 없음`으로 단정하지 않는다.
- 연결된 장구 증감 표시는 42,420건이다: `+` 27,980건, `-` 14,440건. 연도별 출전행·원문 연결행·증감 표시 수는 로컬과 Supabase가 모두 일치한다.
- API24 기반 장구 사용 목록 `entry_equipment`는 변경하지 않았다. 이 테이블의 기존 범위는 2003-09-20~2026-09-20, 499,671행이다. API78 증감 표시는 이 목록과 별개의 출마표 관측 자료다.

## 연결 기준과 보류 자료

- 경마장, 경주일, 경주번호, 출전번호, 정규화한 마명이 모두 맞는 출전행에만 장구 원문과 표시를 붙였다. 2017년 출마표의 장식용 `★` 접두어만 제거해 비교했다. 번호가 다르거나 경주·출전행이 없는 자료를 추정 병합하지 않았다.
- API78 응답에는 운영 DB에 없는 경주의 출전마 10,169행과, 경주는 있으나 운영 출전행이 없는 2,371행이 있었다. 이 12,540행은 운영 출전행·증감 테이블에 억지로 추가하지 않았다. 날짜별 API 원문과 불일치 사유는 `source_documents` 및 상태 `partial`인 `ingestion_runs`에 남아 있다. 이는 위의 *운영 출전행 104건에 원문 미연결*과 방향이 다른 수치다.
- 예시: 2020-12-20 서울 API78 출마표에는 제1~15경주가 각 14두씩 들어 있지만, 운영 DB에는 제1~5경주 출전행만 있다. 출마표의 나머지 경주는 운영 경주 결과에 자동 생성하지 않았다.
- **후속 교차 검증:** 위의 미연결을 전부 경주취소·출전취소로 해석하면 안 된다. 제주에서는 실제 착순이 있는 과거 경주 996개가 운영 DB에 빠져 있고, 서울·부산에서는 반대로 운영 DB에 없는 경주 23개 모두 정상 착순이 없다. 말 단위 미연결 2,371건의 대부분은 특수 착순 코드지만 정상 11착 1건도 있다. 자세한 원천별 대조와 사용 기준은 [독립 검증 보고서](API78_EQUIPMENT_HISTORY_INDEPENDENT_VALIDATION_2026-09-30.md)에 기록했다.
- 이번에 소급 조회한 과거 응답의 관측 시각은 **2026-09-30 조회 시각**이다. 해당 경주 당일 사전 공개 여부를 입증하는 시각이 아니다. 과거 예측의 사전 입력자료로 사용할 때는 별도의 당시 시점 증거가 필요하다.
- API 원문 JSON은 로컬 `data/raw/kra/gate_entry_sheet/`에 보존했고 SHA-256과 경로는 양쪽 DB의 `source_documents`에 기록했다. Supabase의 경로는 로컬 파일 경로를 가리키므로, 원문 재현을 장기간 보장하려면 별도의 백업·스토리지 보존이 필요하다.

## 재검증과 재실행

백필 명령은 `scripts/backfill_api78_equipment_history.py`에 있다. `--apply` 없이 실행하면 대상 및 미처리 경주일·경마장 수만 확인한다. 완료 후 전 범위 읽기 전용 재확인 결과는 `target_meet_days=2648 pending=0`이었다. 이미 완료된 관측분은 다시 덮어쓰지 않는다. 보류 날짜를 교정 후 재처리해야 할 때만 `--retry-partial`을 사용한다.

`tests/test_gate_entry_sheet.py`와 `tests/test_backfill_api78_equipment_history.py`의 관련 테스트 7개가 통과했다. 기존 모델, 예측, API24 사용 목록, 배포 환경은 변경하지 않았다.
