# 제주마 예측의 세 목표: 다음 단계 실행 계획

> **실행 완료:** 실제 세 목표 비교 결과와 후속 우선순위는 [세 목표 결과 보고서](JEJU_NATIVE_THREE_TARGETS_REPORT_2026-09-15.md)에 기록했다. 아래는 실험 전 정의한 범위이며 실행 당시 사본은 실험 폴더에 보존했다.

작성일: 2026-09-15. 사용자의 세 방향 병행 지시에 따라 기존 Top3 계획을 확장한다.

## 이번에 실행할 내용

1. 기존 9개 후보의 동결된 2025년 점수에서 각 말의 1·2·3착 주변확률을 합산한다. 경주마다 가장 유력한 **한 마리**를 선택해 실제 공식 3위 이내 진입 여부를 측정한다.
2. 공식 3위 이내 여부를 직접 학습하는 LightGBM 이진 모델을 만든다. H0 과거 결과, H1 기록·구간 추가, H2 조교·진료 등 추가의 세 묶음을 비교한다.
3. 같은 이진 모델 점수를 순서 확률로 변환하여 기존의 **세 마리 집합 완전 적중**과 **정확순서 완전 적중**도 함께 평가한다. 한 목표의 개선을 다른 목표의 개선으로 간주하지 않는다.
4. 세 목표의 적중 수, 경주일별 불확실성, 선택한 말의 확률과 실제 적중의 일치 정도를 기록한다. 경주별 선택 한 마리·집합·순서와 전체 말별 확률을 저장한다.

## 비교 조건

- 기준 데이터는 봉인 dataset r2다. 2025년 715경주·6,953출발행의 네 개발 fold를 동일하게 사용한다.
- 기존 9개 후보는 재학습하지 않는다. 세 목표 모두에 대한 고정 비교점은 직전 실험의 M0_H2다.
- 새 이진 모델은 각 입력 묶음마다 seed 17·43을 적합하고 두 원시 점수를 평균한다. 3개 묶음 × 2개 seed × 4개 fold = 24회 적합이다.
- 전처리와 계수는 FIT, 조기 종료는 TUNE, 확률 보정은 CAL로 분리한다. 이진 손실은 경주마다 같은 가중치를 준다.
- 단일 말의 이진 확률은 단조 Platt 보정, 집합·순서 확률은 별도 PL 온도 보정으로 계산한다. 12개 모델 묶음에 보정 2개씩 총 24회다.
- 두 확률은 추정 방식이 다르므로 별도 열로 저장한다. 공통 PL 주변확률을 모든 후보에서 비교하고, 새 모델의 직접 이진 확률은 별도로 진단한다. 말별 확률을 서로 곱해 세 마리 동시 입상 확률로 사용하지 않는다.

## 정답과 예외

- 한 마리 예측은 매 경주 한 마리만 선택한다. 확률/점수가 같으면 고정 말 ID로 결정하고 동점 무작위 선택의 기대 적중률도 병기한다.
- 공식 정상 착순이 3 이하인 말은 단일 말 입상 정답이다. DQ/DNF는 출발 집합에 유지하고 입상 정답 0으로 처리한다.
- 3착 경계 동착에서는 공식 입상마가 네 마리일 수 있다. 한 마리 적중률은 해당 경주도 포함한다. PL은 세 자리 확률이므로 공식 입상 확률과 차이가 생기는 경계 동착 경주는 모든 후보의 공통 이진 확률 품질 비교에서만 제외하고 그 분모를 공개한다.
- 집합·순서의 정답은 기존 동착 호환 계약을 유지한다.

## 판정과 산출물

- 한 마리 입상·세 마리 집합·정확순서 최고 후보를 각각 보고한다.
- 말별 확률은 Brier 손실·로그 손실과 선택된 말의 확률 구간별 실제 입상을 함께 확인한다. 전체 출발마의 단순 이진 정확도는 주 지표로 사용하지 않는다.
- 같은 경주와 경주일을 함께 재표집하는 5,000회 bootstrap으로 차이의 95% 구간을 계산한다. 이미 다른 후보를 비교한 2025년 자료이므로 탐색적 개발 결과다.
- 50/60/70/80/90% 확률 기준의 선택 경주 수와 적중을 진단하되, 사후에 유리한 기준만 뽑아 전체 경주 성능으로 표현하지 않는다.
- 새 출력 경로는 `data/research/jeju_native_three_targets_v2_20260915`다. 원본 dataset·실험 v1·운영 모델은 보존한다.
- 2026년 평가와 실제 사전 예측 원장은 후보·목표별 정책을 고정한 후의 단계다. H3 출전 조건 구축도 이번 목표 비교 결과를 반영하여 진행할 후속 작업으로 유지한다.

목표는 장기적으로 세 방향의 정확성을 함께 높이는 것이다. 이번 완료 기준은 실제 모델 비교와 검증 가능한 결과 저장이며, 특정 적중률 달성을 보장하는 것이 아니다. 하위 작업에는 사용자 지정 GPT-5.6 Luna / high를 사용한다.
