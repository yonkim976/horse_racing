# 9월18일 준비·당일 체중·공식 주로빠르기 고정 실험

2026-09-17. 다음 경주일은2026-09-18로 고정한다. 기존HY_R_FORM과 기존 데이터·모델은 보존한다.

## 실행 범위

1. 2024년 기존 제주마 모집단의 경주일별 공식 심판리포트를 API215로 수집하고 명세·수량·경주키를 확인한다. 이전에 고정한 역할 추출기를 그대로 적용하고 새 표본을 검토한다. 운영DB는 수정하지 않는다.
2. 내일 공식 출마표와 사전 보조자료를 수집하고 검증된 기존HY_R_FORM으로 예측을 고정한다. 경주 성적·배당을 조회하지 않는다. 취소·기수변경·자료 누락은 준비도에 명시한다. 당일 체중은 발표 전에는 준비 완료라고 하지 않는다.
3. 기존 모델이 과거체중을 사용하고 당일체중은 사용하지 않는지 저장모델 입력·실행 코드·표시 코드로 확인한다.
4. WEIGHT 후보는 기존108개 순위 입력에 현재 마체중, 최근 관측 대비kg·%, 절대 변화%, 과거3개 관측 평균 대비%, 관측 개수6개를 추가한다. 과거 체중은 T−2 이전의 유효 관측만 쓴다. 현재 체중은 보유 과거 결과 자료에서 얻은 측정값으로, 당시 경주 전 최초공개 시각은 미검증이다. 후향 실험이며 실시간 검증으로 주장하지 않는다.
5. TEMPO 후보는 공식주로①~⑤별 과거 기준시간 대비 전체·초반·종반 잔차 평균, 기준시간 이동량, 참조 수, 유효보정 이력 수6개를 추가한다. 과거A경주 보정 기준도 A−2 이전730일, 같은 정확거리·등급·제도구분에서 계산한다. 기본 셀과tempo 셀 모두20경주가 있어야 보정한다. 부족하면 결측이며 임의0초 보정하지 않는다. 제도구분은2018-08-31 전후 및2025·2026년을 나눈다. 현재B경주의tempo는 입력하지 않고 B−2 이전 같은 거리 최근3회 이력을 쓴다.

## 제한된 실험과 비교

- 기존v13 FIT/TUNE/CAL/EVAL 재사용. 평가2026-01-02~09-12의510경주는 이미 본 개발 자료다.
- 순위 후보WEIGHT/TEMPO 각각 seed17·43, 기존LightGBM 설정 및 TUNE 종료 선택. 총4학습.
- 순서 후보는 기존68입력+WEIGHT6개, 같은JointTop3MLP 설정으로 seed17·43. 총2학습. 수렴 상태 보고.
- 기준/WEIGHT/TEMPO 순위×기준/WEIGHT 순서의6조합. 결합 결과는 탐색으로만 보고한다.
- 주 비교6개: WEIGHT의A·B, 고정 기존집합의WEIGHT순서C, TEMPO의A·B, WEIGHT의경주평균Brier 개선. 경기일 대응bootstrap5,000회와Bonferroni6 보정 구간. 0을 포함하면 개선 확정하지 않는다.
- 온도보정은 CAL에서만 수행. 모델·점수 해시를 고정한 뒤2026 정답을 결합한다. 결과를 보고 재시도하지 않는다. 기존317/32/7 재현, 분기별 성능, 체중·tempo보정 관측률을 보고한다.
- 실험 승격 여부와 무관하게 내일 기본 예측은 검증된 기존모델로 우선 준비한다. 당일체중 모델을 검증 없이 실사용 모델로 교체하지 않는다.
