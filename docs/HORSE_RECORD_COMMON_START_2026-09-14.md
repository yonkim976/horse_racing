# 경주·말·훈련·체중·진료 자료의 공통 시작 시점 (2026-09-14)

## 먼저 답

- **현재 정규화 DB에서 경주 결과와 말 ID를 기준으로 조교·출발조교·체중·진료 이력을 함께 조회할 수 있는 연도는 2025년부터**다. DB 자체는 경주 결과가 2015년부터이나, 해당 이력 테이블은 2025년부터다.
- **과거 원천 파일/API의 날짜 범위만 교집합으로 잡으면**, 질문에 명시된 경주 결과·일반 조교·전용 마체중·진료는 세 경마장 공통으로 **2007-10-01 이후**, 출발조교도 포함하면 **2009-05-21 이후**가 최초 후보 범위다. 이는 원천 종류별 첫 관측일의 최댓값일 뿐, 이후 모든 경주·말·항목이 완전하다는 검증이 아니다.
- **‘모든 기록이 전부 있는 해’는 현재 확정할 수 없다.** 진료는 사건 기록이므로 말마다 기록이 없는 것이 정상일 수도 있고 누락일 수도 있다. 오래된 Text 진료·체중 자료의 말 ID 연결, 원천별 연속성, 경주별 출전집합, 당시 공개 시각을 전수 검증하지 않았다.

## 확보 원천의 최초 관측 범위

| 질문에서 지정한 자료 | 서울 | 제주 | 부산경남 | 기준 |
| --- | --- | --- | --- | --- |
| 말별 경주결과 | 2000-01-08 | 2000-01-08 | 2004-11-28 | 공식 `API4_3`의 1999~2014년 연도별 응답. 서울은 1985년 영문 상세 결과도 별도 확인; 제주는 1990년 목록이 있으나 최초 상세 주 결과 표가 `No data` |
| 일반 일별 조교 | 1998-09-25 | 2007-10-01 | 2004-06-30 | 공식 월별 API 원문 첫 양성 행 |
| 출발조교 | 2009-05-21 | 2007-10-17 | 2009-05-21 | 공식 월별 API 원문 첫 양성 행 |
| 전용 출전마체중 | 2003-09-06 | 2003-07-12 | 2004-11-28 | Text `dacom12` 목록 첫 파일일. 경주결과 API에도 체중 필드가 있으나 과거 값의 연도별 완전성은 별도 미검증 |
| 말 진료·치료 | 2003-09-25 | 2005-11-03 | 2005-05-11 | Text `dacom72` 첫 파일일. 과거 Text는 말 ID가 모든 행에 직접 붙어 있지 않아 일치 검증 필요 |

경주 결과 상세는 [경주결과 원천 감사](PRE2015_RACE_RESULT_AVAILABILITY_2026-09-14.md), 조교 API와 Text 9종의 날짜·해시는 [역사 원천 수집 보고서](HISTORICAL_SOURCE_COLLECTION_2026-09-14.md) 및 `data/logs/historical_*_audit_20260914.json`을 기준으로 했다. 공식 서비스 설명은 [경주기록](https://www.data.go.kr/data/15058305/openapi.do), [일별훈련](https://www.data.go.kr/data/15058782/openapi.do), [진료](https://www.data.go.kr/data/15057799/openapi.do), [출발훈련](https://www.data.go.kr/data/15059043/openapi.do)에서 확인했다. 포털의 설명은 각 서비스의 조회 항목을 보여 주지만 역사적 전체 완전성을 보증하지 않는다.

말 기본정보의 경우 [경주마 상세정보 API](https://www.data.go.kr/data/15058115/openapi.do)는 현재 현역마의 프로필·통산 성적 스냅샷을 제공한다. 그 응답을 2009년의 말 상태나 당시 통산 성적에 그대로 붙일 수는 없다. 따라서 ‘경주마 관련 기록 전부’까지 포함한 과거 공통 시작 연도는 위 표로 확정되지 않는다. Text 장구·출전마 진료 등 추가 항목까지 ‘모든 기록’에 넣으면 범위가 다시 달라진다.

## 현재 DB에서 실제로 결합 가능한 기간과 빈칸

읽기 전용 SQLite 대조: `data/horse_racing.sqlite3`의 경주 27,129개는 2015-01-02~2026-09-13이다. 말별 결과 288,606행도 이 경주에 연결되어 있다. 일반 조교는 752,358행(2025-01-01~2026-09-12), 출발조교 70,068행(2025-01-02~2026-09-12), 진료 176,811행(2025-01-01~2026-09-12), 전용 마체중 44,803행(2025-01-03~2026-09-13)이다. **2015~2024 조교·진료 원문은 확보했지만 해당 DB 이력 테이블에 아직 적재되지 않았다.**

2025년 출전 26,076행은 전용 체중 이력 키가 모두 연결되지만 실제 `body_weight_kg` 값은 25,881행이다. 2026년 출전 18,947행 중 전용 체중 이력 연결은 18,727행이다. 일반 조교는 2025~2026년 출전 45,023행 중 44,951행(99.84%)에 출전 전 28일 이내 기록이 최소 1건 연결된다. 진료 0건을 건강 문제 없음으로 해석할 수 없다. 세부 검사는 [모델 데이터 준비 감사](MODEL_DATA_READINESS_AUDIT_2026-09-14.md)에 있다.

따라서 **2009년은 과거 원천 범위의 공통 시작 후보**, **2025년은 현재 정규화된 상세 데이터의 실무 시작 연도**다. 어느 것도 ‘모든 기록 100% 완비’ 판정은 아니다.
