E6-B 독립 검증에서 수치는 재현됐다. 중량 묶음은 승격하지 않는다. 이번에는 아래 테스트 실행 보완과 최근3회 실제 출발의 개별 이력 feature 감사·격리 산출물·후속 비교 protocol을 완성하라. 실제 경마 모델 학습·성능 평가·새 수집·운영 변경은 수행하지 않는다. 본 지시를 사용자가 전달하면 이 범위는 승인된 것이므로 재확인 때문에 멈추지 않는다.

## 1. 테스트 실행 회귀 보완

`.venv/bin/pytest -q`가 새 E6-B 테스트의 `scripts` import에서 실패하지만 `python -m pytest -q`는554개 통과한다. 프로젝트 루트를 명시하는 pytest pythonpath 설정 등 최소 수정으로 두 실행 방식이 모두 작동하게 하라. 기존 pyproject.toml dirty 내용은 보존하고 관련 항목만 추가·수정한다. 봉인 E6-B 파일을 수정하거나 공통 학습 수학을 복제할 필요는 없다. 해결 방법과 두 명령의 결과를 기록한다.

## 2. 연구 가설과 고정 입력 후보

기준은 중량을 추가하지 않은 H1 기존136열이다. 가설은 최근 평균에 압축된 개별 출발 관측과 경과일의 추가 정보다. 새 신경망·objective·부담중량·등급·레이팅·배당·심판문서 모델을 동시에 추가하지 않는다.

대상은 서울 H1 A 전체15,579행·1,488경주다. 과거 출발 슬롯은 전 경마장의 같은 말에 대해 target_date보다 엄격히 이전인 최근 실제 출발3회를 최신순으로 고정한다. 각 슬롯 j=1,2,3에 다음4개 수치 관측을 연결하는12열 후보를 감사하라.

- `sequence_start{j}_early_rel`: 해당 과거 출발의 canonical S1F 상대지수.
- `sequence_start{j}_last200_rel`: 해당 과거 출발의 canonical 마지막200m 상대지수.
- `sequence_start{j}_speed_figure`: 해당 과거 출발 자체의 보정 성능 관측.
- `sequence_start{j}_days_ago`: target 경주일−해당 과거 출발일의 양수 일수.

평균·추세 feature를 다시 lag해 과거 출발 관측인 것처럼 사용하지 않는다. canonical_energy의 집계 전 상대지수와 speed_figure.performance_observations의 출발별 관측을 구분한다. 기존136열과 새12열의 정확 중복·높은 중복률은 데이터 계약 진단으로 보고하고, 발견했다고 성능 확인 없이 열을 임의 교체하거나 탐색하지 않는다. 최종 실행할 feature 목록은 독립 검증 이후 확정한다.

## 3. 슬롯·원천·시간 계약

E6-A v2의 전 경마장 실제 출발 선택 및 E1 결과 분류를 재사용하거나 동등하게 검증한다. 정상완주·DNF·실격은 출발 슬롯을 차지한다. DNF/실격에 믿을 수 있는 완주 관측이 없으면 해당 수치를 null로 두되, 오래된 정상완주를 끌어와 슬롯을 채우지 않는다. 확정 미출주는 슬롯에서 제외한다. 최근 미확정 출발 또는 같은 날 모호한 복수 출발이 있으면 어떤 슬롯을 확정할 수 없는지 표시하고, 모호한 순서를 임의로 정하지 않는다. 보수적으로 그 영향 이후 슬롯을 null로 격리할 수 있으나 명세와 영향을 제출하라.

슬롯이 존재하면 출발키·경마장·날짜·상태를 evidence로 남긴다. 슬롯 없음, 실제 출발은 있지만 원문 미확인, 구간 측정 없음, 물리적으로 변환 불가능, 상태 모호성을 구분한다. metadata는 학습 열에 포함하지 않는다. 실제 출발·날짜가 확인된 경우 다른 관측이 null이어도 days_ago는 계산 가능하다.

canonical S1F/last200은 기존 승인된 source_kind/time_basis/거리 계약을 적용한다. 제주·부경 NULL provenance를 closing으로 추정하지 않는다. 과거 출발 슬롯의 구간이 미확인이라는 이유로 이전 서울 슬롯으로 건너뛰지 않는다. 기존 relative 산식의 유효 관측수·모집단·clip 정책을 명시하고 그대로 재현한다. 분모는 그 과거 경주의 허용된 측정 관측이며 target 경주의 결과/완주집합을 사용하지 않는다.

보정 성능은 원래 과거 출발의 거리·완주시간·경마장·기준 기록·주로 보정 근거를 추적한다. baseline par 추정에 미래 날짜가 들어가지 않아야 한다. 과거 날짜의 하루 전체 관측으로 계산하는 기존 day variant는 그 날이 target보다 엄격히 이전일 때만 허용한다. 과거 출발 당일 예측용 feature와 target 시점에 이미 끝난 과거 하루를 요약한 feature를 혼동하지 않는다. 빈 par나 불완전 원천을 전 기간 평균으로 대체하지 않는다.

새 원천 조회는 read-only DB/기존 raw 파일에 한정한다. 모든 시간가변 조회의 상한은2026-05-31이며 target별 이전 날짜 제한을 별도로 적용한다. 과거 이력의 시작일과 left truncation을 명시한다. 당일·미래 target 결과, 2026-06-01 이후 실제 자료는 읽지 않는다. 원문이 사후 수집됐다는 사실과 실제 당시 이용 가능했다는 증거를 구분하며, 기존 후향 자료를 PIT 통과로 바꾸어 표시하지 않는다.

## 4. 구현·검증 산출물

기존 H1을 바꾸지 않고 전체15,579키에 맞춘 새12열 후보 parquet와 슬롯별 evidence/원천 manifest를 생성한다. 키 누락·추가·중복과 inner join 축소를 거부한다. 기존136열·label·A field를 변경하지 않는다. 숫자 비교에는 null↔값 변화와 nonfinite 정책을 명시한다.

각 슬롯의 키·날짜 선택과 관측 산식을 독립 집계로 전수 비교한다. 최소한 아래 반례는 실제 구현 경로를 호출해 확인한다.

- 각 단일 target에서 target 결과행 삭제·상태 변경 및 당일/미래 결과·구간 변경이 새 predictor를 바꾸지 않음.
- target들의 입력 행 순서 역전과 history 순서 역전에도 키별 결과 동일.
- DNF/null 구간이 슬롯을 차지해 오래된 비결측 기록으로 채워지지 않음.
- 최근 부경 출발 뒤 서울 target, 구간 provenance 미확인, 동일일 모호성·미확정 출발 처리.
- 과거 관측 자체를 바꾸면 명세상 그 관측을 사용하는 이후 target만 영향받음. 모든 target의 과거 결과까지 바꾸고 전체 predictor 불변을 요구하는 잘못된 테스트는 만들지 않음.
- baseline par/day variant 계산에 target 또는 미래 날짜를 주입해도 이전 target 관측이 변하지 않음.

슬롯·열별 coverage/null 사유, DNF/실격 target별 coverage, 경마장별 이전 출발·원천 범위, 기존136열 대비 중복을 보고한다. 신마·원천 미확인행을 없애 분모를 줄이지 않는다. 자료 부족은 유효한 감사 결과이며 성능을 시험해 가며 후보를 바꾸지 않는다.

## 5. 후속 protocol 초안과 종료

후속 비교는 기존136열 vs 감사 통과한 최근 출발별 이력 묶음의 두 후보로 설계한다. E6-B의 세 시간순 fold/fit-only encoder/custom BINARY/selector→refit→별도T→공통gate를 유지하며, 실행 시 예정 fit 예산은12회다. 이번 단계에서는 실제 fit0회다. E6-B에 없는 새 조정·ensemble·seed 탐색은 없다.

평가 지표와 paired race/race-date bootstrap은 E6-B 정의를 유지한다. 모든 fold를 보고하고407개 기존 개발 경주를 새 독립 test로 부르지 않는다.3~5월의 새 성능과6월 이후 실제 결과는 계속 사용하지 않는다. 실제 출발 슬롯 정책도 바뀌므로 결과가 좋아도 순서 정보만의 순수 효과나 개별12열의 인과효과를 분리했다는 주장을 하지 않는다.

새 보고서, feature/evidence parquet, 원천 및 전수 검증 JSON, 테스트, 후속 protocol 초안, 보존 hash manifest를 제출한다. 기존 평가 실행 문제는 수정 후 두 pytest 명령으로 검증하고 관련 Ruff/format·diff-check도 기록한다. 새 이력 데이터의 독립 검증과 별도 실행 지시 전 실제 모델 학습·성능 평가·운영 승격 없이 종료하라.
