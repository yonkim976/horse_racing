# 2000년대 경주로·경주 구성과 2026년 비교 (2026-09-14)

## 결정

**조회 가능한 최초 연도와 2026년 예측모델의 동일 모집단 시작 연도는 다르다.** 서울은 2000년 결과를 보존할 수 있으나 거리 구성·부담중량 제도와 2019년 1600m 주로 개선을 분리해야 한다. 부경 2004년 결과 38경주는 전부 모의경주이며, 2005년의 정식경주 첫날은 9월 30일이다. 제주 2000년 결과 903경주에는 현재의 `제` 등급 제주마 경주가 없으며, 2023년 조사한 715경주는 모두 `제` 등급이다. 그러므로 오래된 모든 행을 2026년 경주와 동일하게 섞어 학습하면 안 된다.

이 판단은 공식 `API4_3/raceResult_3`의 경주별 중복 제거 집계와 2026-09-13까지 `completed`인 현재 DB 경주를 비교한 것이다. [초기 연도 API 집계](../data/logs/historical_course_first_era_20260914.json) · [제주 전환기 API 집계](../data/logs/historical_race_regime_transitions_20260914.json) · [제주 초기 제주마 집계](../data/logs/historical_jeju_native_early_20260914.json) · [2006 부경 API 집계](../data/logs/course_comparability_followup_api_20260914.json) · [2015/2025/2026 DB 집계](../data/logs/course_comparability_current_db_20260914.json). 각 API 집계에는 원응답 SHA-256이 있다. 2026년 API 별도 조회는 분석일 이후 날짜의 행까지 반환했으므로 분석에서 배제하고, 2026년 비교는 로컬 DB의 9월 13일까지 완료 경주만 사용했다.

API의 `rank`가 `한`/`래`/`제`로 시작하는 경주를 각각 구분했다. 이 경주 단위 구분은 과거 말별 마종 마스터와의 전수 대조가 끝난 개별 마필 라벨은 아니다. 그러나 2000년 `제` 경주가 0이라는 결론은 903경주 전수의 관측값이며, 당시 경주 구성이 현재와 크게 다르다는 판정에는 충분하다.

### 서울

한국마사회는 서울 경마공원의 1989년 개장 이후 서러브레드 평지경주와 현재 두 면의 모래 주로를 설명한다. [현재 서울 경주로 구조](https://race.kra.co.kr/chulmainfo/trackView.do?Act=02&Sub=10&meet=1). **물리 경주로까지 완전히 불변이라고 단정할 수는 없다.** 공식 [2019년 시행계획](https://race.kra.co.kr/down/raceplan_2019.pdf)은 경주로 개선공사 후 2분기부터 서울 1600m 경주를 신설한다고 명시한다. 실제 2000년 API에는 1600m 경주가 없고 2026년 DB에는 있다. 따라서 1600m의 과거 같은 거리 비교는 2019년 도입 후부터 해야 한다. 다른 동일 거리도 2000년 원시 기록을 2026년 기준 기록과 직접 비교하지 않는다.

2000년은 마령 496/1,114, 핸디캡 169/1,114경주이고, 2026년은 핸디캡 512/751경주다. [공식 레이팅 설명](https://race.kra.co.kr/down/ratingQNA_20250118.pdf)은 **2015년 2월 이전의 승군점수 체계**와 이후의 레이팅 체계를 구별한다. 동일 이름의 등급·부담중량을 전 시대에 같은 숫자 의미로 합치면 편성 강도와 핸디캡 효과가 왜곡될 수 있다.

### 부산경남

[한국마사회 공원 연혁](https://www.kra.co.kr/globalEn/park/02/park02.jsp)은 2005년 9월 개장을 기재하고, 현재 [경주로 구조](https://race.kra.co.kr/chulmainfo/RacingcourseStructure.do?Act=02&Sub=10&meet=3)는 내·외 모래 경주로와 반시계방향 평지경주를 설명한다. API에서는 2004년 38경주가 모두 `일반(모의)`이고 2005년 1월 7일~8월 12일의 모의 328경주 뒤 9월 30일부터 정식 `일반`/개장기념 경주가 나타난다. 앞선 “부경 2004년부터 모델 결과 수집” 권고는 **API에 결과 행이 존재하는 날짜**를 정식 승부 라벨의 시작으로 오해한 것이므로 철회한다.

정식경주에서도 2006년 마령 304/578, 핸디캡 97/578인 반면 2026년은 핸디캡 368/530이다. 현재 1300m는 81경주지만 2006년에는 0경주였다. 부경의 초기 정식 자료는 역사적 말 성적·모델 후보로는 보존하되, 현재 편성 분포와 동일하게 가중하지 않는다.

### 제주

현재 [제주 경주로 현황](https://race.kra.co.kr/chulmainfo/trackView.do?Act=02&Sub=9&meet=2)은 하나의 1,600m 모래 경주로를 설명한다. 이 기본 평지경주 형태만으로 2000년의 말 모집단이 현재와 같아지는 것은 아니다. 공식 결과 API 집계에서 `제` 등급의 첫 양성은 **2002-07-28**이며 2002년 6경주, 2003년 13경주, 2004년 55경주, 2005년 89경주에 그쳤다. 2010년에는 `제` 275/858, 2015년 430/846, 2022년 602/696, 2023년 715/715경주다. 2015년 현재 DB에는 제주 428경주가 있어 같은 연도 API `제` 430경주와 2경주 차이가 있으므로 재수집 때 키 대조가 필요하다.

후속 [제주 마종·경주로 정밀 검토](JEJU_HORSE_TYPE_TRACK_HISTORY_2026-09-14.md)는 `한`=한라마, `래`=한라마(래), `제`=제주마라는 공식 표기를 확인했다. 2003년 문화관광부 자료와 현재 KRA 안내는 모두 제주를 **길이 1,600m·폭 20m의 모래주로**로 설명한다. 반면 제주마 경주 도입 뒤인 2019년 경주로 배수인프라 개선공사 **계약**도 확인했다. 계약 목록만으로 실제 완공 범위나 성능 변화는 알 수 없다. 2015~2018년의 400m 정식경주가 2019년 이후 현재 DB에 없고 현재 공식 출발지점 목록에서도 400m가 빠졌지만, 이것이 타원 주로의 둘레 변경 또는 출발 설비 철거를 입증하지는 않는다. 과거 주로의 상세 단면·시공 이력은 미확보다.

2026년에도 운영 조건이 변했다. [공식 제주 시행 변경사항](https://race.kra.co.kr/raceoper/RaceoperView.do?Act=13&Sub=2&meet=2)은 2025-12-28부터 기존 레이팅을 일괄 조정하고, 6등급 거리 범위를 2025년 800·900m에서 2026년 800·900·1000m로 넓혔다고 밝힌다. 2025년 DB의 제주 800m 52/722경주가 2026-09-13 현재 3/534인 변화와도 부합한다. 최근 자료도 레이팅과 거리 조정을 명시적으로 취급해야 한다.

## 수집·학습 권고

1. **결과 원문 보존**: 서울·제주 API는 2000년부터, 부경은 2004년부터 받을 수 있다. 원문 보존 범위와 모델의 학습 라벨 범위는 분리한다. API 원문 수집 자체는 이후 더 오래된 자료의 마필 이력·제도 변화 연구에 도움이 된다.
2. **본 모델의 우선 비교 구간**: 서울·부경은 레이팅 제도의 첫 온전한 연도인 **2016년 이후 정식 서러브레드 경주**를 우선 기준으로 삼는다. 2015년 2월 이후는 제도 전환 경계와 함께 별도로 검토한다. 서울 1600m는 **2019년 도입 후**의 이력으로 취급한다. 제주 모델은 먼저 **2023년 이후 `제` 등급 경주**로 같은 마종 중심의 기준선을 만들고, 2015~2022년의 `제` 경주를 추가했을 때 실제 개선되는지 별도 비교한다. 2025-12-28 레이팅 조정은 시점 경계로 기록한다. 부경 2005-09-30~2014, 서울 2000~2014, 제주 초기 `제` 경주는 확장 후보로 남긴다. 이것은 학습·검증 설계의 권고이며 아직 예측력 실험의 결론이 아니다.
3. **확장 판정**: 오래된 데이터가 도움이 되는지 여부는 물리 구조와 경주조건만으로 확정할 수 없다. 최신 기간을 검증용으로 남겨 두고, 오래된 경주를 추가했을 때 경마장·거리·마종·시대별 확률 손실이 개선되는지 시간순으로 비교한다. 오래된 원시 주파시간이나 등급 숫자를 현대 값과 바로 합치지 않는다. 말의 과거 성적은 같은 마종·거리·시대의 경주 내 상대값으로 변환하고, 충분히 오래된 개체 이력은 현행 예측 말과 연결성이 약할 수 있다.

이번 작업은 읽기 전용 API·DB 감사와 문서화만 수행했다. 모델 학습, 운영 변경, 2026-09-13 이후 경주 결과 평가는 하지 않았다.
