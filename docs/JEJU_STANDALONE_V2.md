- 제주 경주의 `한국`/`제` 산지 표기를 학습 feature에서 `제주마`로 통합한다.

## 해석과 결정

- 표기 정상화는 재생성 안정성을 확보하면서 최근 모델의 Win LL·AUC·우승마 Top3를 개선했다.
- 기수 승률 계열을 완전히 제거하면 우승마 Top3가 2.24%p 하락했다. 기수 정보는 실제 신호를 포함하므로 삭제하지 않는다.
- 기수 승률 gain을 절반으로 제한하면 해당 계열의 gain 중요도가 14.37%에서 2.20%로 감소했지만 확률 품질과 Top3가 악화됐다. 운영 기본값으로 채택하지 않고 소거실험 후보로 보존한다.
- 중간·강한 규제는 전반적인 확률 품질을 악화했다. 기존 기본 규제가 제주 표본에도 더 적합했다.
- 운영 후보는 `20047697-0b2e-4dac-9a4d-762271f5e1f9`다. 기존 V1 대비 Top1은 동일하고 우승마 Top3는 1.68%p 상승했으며 Top5 확률 log loss도 소폭 개선됐다.
- Top3 개선은 179경주에서 순증 3경주이고 paired bootstrap 95% 구간이 -1.68~+5.59%p이므로 아직 통계적으로 확정된 개선은 아니다. 미래 미사용 구간 판정 전까지 V2 후보로 운용한다.
