# 2015년 이전 경주결과 원천 가용성 재확인 (2026-09-14)

## 결론

현재 DB의 경주 27,129건은 2015-01-02~2026-09-13에 한정되지만, 이는 과거 공식 경주결과가 없다는 뜻이 아니다. 앞선 `dacom11` 원천 조사에서 언급한 2003년은 **그 Text 목록의 시작**이었다. 별도의 한국마사회 영문 결과 화면은 서울 1985년, 제주 1990년, 부산경남 2004년의 경주일 목록을 제공한다. 다만 목록에 날짜가 있다는 것과 그 날짜의 **완전한 말별 결과**가 있다는 것은 구분해야 한다.

| 경마장 | 공식 영문 결과 목록에서 최초 확인한 날짜 | 경계 확인 | 상세 화면의 말별 결과 | 공식 경주기록 API에서 확인한 최초 양성 연도 | Text `dacom11` 첫 파일 |
| --- | --- | --- | --- | --- | --- |
| 서울 | 1985-01-12 | 1984년 목록 0일, 1985년 143일 | 1985-01-12 1R에 마명·순위·기록이 있는 행 확인 | 2000년 | 2003-07-12 |
| 제주 | 1990-10-28 | 1989년 목록 0일, 1990년 4일 | **1990-10-28 1R의 주 결과 표는 `No data`**. 아래 구간 표에는 일부 내용이 있으나 말별 완전성 미확인 | 2000년 | 2003-07-12 |
| 부산경남 | 2004-11-28 | 2003년 목록 0일, 2004년 6일 | 2004-11-28 1R에 마명·순위·기록이 있는 행 확인 | 2004년 | 2004-11-28 |

경계 연도의 목록은 1년 검색으로 마지막 페이지까지 확인했다. 앞 연도의 목록 0일은 **이 화면에서 조회되지 않았다는 뜻**이지, 그 경마장의 역사상 경주나 다른 보관 자료가 없다는 증명이 아니다. 서울 [1985-01-12 1R](https://race.kra.co.kr/globalEn/resultsRaceDetailSeoul.do?rcDate=19850112&rcNo=1), 제주 [1990-10-28 1R](https://race.kra.co.kr/globalEn/resultsRaceDetailJeju.do?rcDate=19901028&rcNo=1), 부산경남 [2004-11-28 1R](https://race.kra.co.kr/globalEn/resultsRaceDetailBusan.do?rcDate=20041128&rcNo=1)의 상세 화면을 직접 HTTP 200으로 조회했다. 응답 해시, 크기, 검색 페이지별 날짜 수는 [`pre2015_race_result_web_boundary_20260914.json`](../data/logs/pre2015_race_result_web_boundary_20260914.json)에 기록했다.

## API와 Text 목록의 정량 대조

[한국마사회 경주기록 정보 API](https://www.data.go.kr/data/15058305/openapi.do)의 `API4_3/raceResult_3`에 대해 경마장별 1999~2014년 연도 전체를 조회했다. 응답의 `totalCount`와 실제 행 수가 일치하는지 확인하고, `(경마장, 경주일, 경주번호)`로 경주를 셌다. 서울·제주는 2000-01-08부터, 부산경남은 2004-11-28부터 양성 결과가 나왔다. 1999년은 세 경마장 모두 해당 API에서 0행이었다. 따라서 API의 이 조회 결과만으로 2000년 이전 경주결과의 부재를 판단하면 틀린다.

| 경마장 | 2000~2014년 API 말 결과 행 | 서로 다른 경주 | Text 시작 이후 API에는 있지만 Text 목록에는 없는 경주일 |
| --- | ---: | ---: | ---: |
| 서울 | 186,519 | 16,533 | 5일 |
| 제주 | 124,128 | 13,302 | 7일 |
| 부산경남 | 77,878 | 7,111 | 2일 |
| 합계 | **388,525** | **36,946** | **14일** |

누락 14일을 API에 날짜별로 다시 요청하니 **134경주·1,418마리 결과 행**이 반환됐다. 원천별 날짜와 각 응답의 SHA256은 [`연도별 API·Text 대조`](../data/logs/pre2015_race_result_availability_20260914.json), [`14일 API 재확인`](../data/logs/pre2015_race_result_text_gap_api_counts_20260914.json)에 남겼다. 제주 Text 목록의 `2007-06-07` 파일은 파일명과 달리 본문이 `2007-06-02` 경주들이어서 별도 6월 7일 경주일로 계산하지 않았다.

이 대조는 **Text 파일명에 나타난 날짜와 API 경주일**의 비교다. 같은 날짜의 개별 경주·말 행까지 양쪽 원문을 전수 비교한 것은 아니다. API 자체의 역사적 완전성도 독립된 공식 경주 캘린더와 대조하지 않았다. 따라서 `36,946경주`는 해당 기간 API에서 **현재 조회되는 경주 수**이지 절대적인 시행 경주 총수라고 단정할 수 없다.

## 학습 데이터로 쓰기 전 남은 일

1. 1985~1999년 서울 및 1990~1999년 제주의 영문 상세 화면에서 경주·출전마·결과 행의 실제 충실도를 연도별로 검사한다. 제주 1990년의 `No data`처럼 목록만 존재하는 사례를 명시적으로 격리한다.
2. 2000~2014년 API 결과를 현재 스키마에 적재하기 전에 경주·말 식별키, 동착·실격·미출주, 구간기록의 정의와 결측률을 확인한다. 과거 영문 화면은 표시 마명과 필드가 현행 API와 다를 수 있으므로 ID 매칭을 검증한다.
3. 독립 경주 목록이나 다른 공식 원천과 날짜·경주번호·출전마 키를 비교해 완전성을 평가한다. Text가 없는 14일은 API 결과를 활용할 수 있지만, 나머지 날짜도 행 단위 비교가 필요하다.

이번 조사는 **읽기 전용 원천 확인**이다. 2015년 이전 결과를 현재 DB·학습 데이터셋에 적재하지 않았고 모델·운영 경로도 바꾸지 않았다. 재현용 조회 코드는 [`audit_pre2015_race_result_availability.py`](../scripts/audit_pre2015_race_result_availability.py)에 있다.
