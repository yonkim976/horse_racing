기존 순위 학습은1·2·3착을 다르게 평가하지만 입상 분류기는 모두 정답1이다. 입력은 같아도 학습 목적과 종료 선택 지표가 다르다. P_FORM은 경주당 학습 가중치가 같도록 각 출전행을1/N로 가중했다. 기존과 같은 나무 설정·시드17/43·250트리 상한·조기 종료30을 사용하고 두 시드 원점수를 평균했다.

각 평가 연도 직전6월까지 FIT,3분기 TUNE,4분기 CAL을 사용했다. 전처리는 FIT만, 분류기 학습종료는 TUNE logloss만, 보정계수는 CAL만 사용했다. 과거 이력은T−2까지 갱신했다. 저장 모델·확률을 잠근 뒤 평가 정답을 결합했다. 2024~2026년은 이미 연구에 사용한 후향 개발 재검증이며 새 미사용 평가가 아니다.

이력0회 보정은 감점을 미리 정하지 않고 과거 CAL에서 방향과 크기를 학습한다. 너무 큰 소집단 보정을 억제하는 고정 페널티를 사용했으며 결과를 보고 강도를 바꾸지 않았다. 공식 신마 자격과 관측 이력0회를 동일시하지 않는다.

## 4. 이력0회 과신은 얼마나 줄었나

공식 입상마4두가 되는 경계 동착6경주는 확률 품질 비교에서만 제외했다. 적중률은 전체1,920경주를 사용한다.

신마 포함282경주의 A는 BASE184회→BASE_ZERO188회, P_FORM188회,P_FORM_ZERO194회였다. 전원 유경험1,638경주는 BASE1,004회,BASE_ZERO1,004회,P_FORM/P_FORM_ZERO1,006회였다. 이것은 소집단 진단이며 모델을 경주 유형별로 사후 골라 붙인 전략이 아니다.

1. **운영 HY_R_FORM 유지.** B/C도 기존 출력 유지. BASE_ZERO는 제한 보정 연구 후보로 보존하고 새 분류기는 현 설정으로 교체하지 않는다.

4. C의 동일 집합 순서 안정성 점검과 B의 PACE 소집단 가설은 별도 후속으로 유지한다. 한 번에 모두 결합해 개선 이유를 알 수 없는 모델을 만들지 않는다.
