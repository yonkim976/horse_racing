# 제주 구간기록 복원 · 2026-09-08

제주의 저장된 완료 경주 전체 11개 거리, 출전 기록 83,544건을 보관 원본과 연결해 구간기록을 다시 저장했다. 원본과 연결하지 못한 출전 기록은 0건이다. 과거 자료는 보관된 공식 dacom11 성적표, 최근 자료는 API4_3 원본 응답을 사용했고 중복 시 최근 API 응답을 우선했다.

## 발견 및 수정

- API 제주 항목에 빠진 `je_1cTime`, `je_2cTime`과 통과순위를 추가했다.
- 과거 제주 고정폭 성적표의 1C~4C를 저장하도록 수정했다. 이전 파서는 숫자만 추출해 S1F/G3F/G1F만 기록했다.
- 400m처럼 빈 G3F 칸이 있는 행에서 값이 당겨지는 오류를 수정했다. 음수 특수결과 값은 기록으로 사용하지 않는다.
- 원문 말별 통과순위를 복원했다. 원자료에 없는 값은 만들어 넣지 않았다.

| 거리 | 공식 표본의 측정 항목 특징 |
|---|---|
| 400m | S1F·G1F, G3F와 코너시간 없음 |
| 800m | S1F와 3C/G3F 지점이 일치 |
| 900·1,000·1,110·1,200m | S1F·3C·4C·G3F·G1F |
| 1,300m | 2C가 S1F보다 먼저 나타남 |
| 1,400m | S1F와 2C 시간이 일치 |
| 1,610m | S1F와 1C가 일치하며 2C도 제공 |
| 1,700·1,800m | S1F와 1C·2C를 각각 제공 |

웹페이지는 실제 누적시간 순서로 표시하고, 복수 말에서 시간과 제공된 순위가 일치하는 지점을 합친다. 1C·2C 거리 설명을 추가했다. 제주 1,110m·1,610m S1F는 210m이며 코너 거리 표시는 공식 근사값에 따른다. 구간 주파시간은 인접한 표시 지점 사이에서만 계산한다.
