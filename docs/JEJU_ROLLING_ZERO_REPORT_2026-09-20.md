## 1. 무엇을 바꿨나

2023~2025년 각 분기를 예측할 때 직전 분기는 온도 보정, 그 앞 분기는 조기종료 선택, 그 이전은 학습에 사용했다. 해당 분기의 정답을 학습하지 않은 예측만 보정 표본으로 모았다. 입력 108개·학습 설정·시드 17/43은 고정했다.

2024/2025/2026 평가에는 기존 연간 모델의 확률을 그대로 사용하면서 직전 1년의 분기별 예측으로 계산한 보정만 적용했다. 과거 분기 모델과 적용 대상 연간 모델이 다르므로 보정을 이전할 때 분포 차이가 남는다. 무작위 교차검증을 사용하지 않았다.

### 후속 계산에서 확인한 제약

현재 보정은 이력 0회 계수를 0 쪽으로 당기는 벌점 0.01을 사용한다. 이력 0회 표본이 과거 전체 가중치의 약 3.9~4.4%여서, 벌점과 적합 오차가 균형을 이루는 해에서도 이 집단의 과대평가가 남는다.

최종 해에서 `가중 평균 오차 = −0.01 × 이력0회 계수 / 이력0회 가중치 비율`이 계산상 일치했다. 보정에 사용한 과거 표본 자체의 잔여 과대평가는 평가 연도별 **2.42/2.30/4.84%p**다. 이는 평가 기간의 5.45%p와 다른 집계다.

따라서 표본을 단순히 늘리는 것만으로 과신이 사라지는 구조가 아니다. 다만 벌점을 줄이면 미래 적중이 오른다는 결론은 아직 없으며, 이 계산은 결과 이후의 진단이다. 이번 후보를 바꾸는 데 사용하지 않았다.

## 4. 기본 능력값과 주행심사에서 확인한 점

- 전체 평가의 이력 0회 762출전은 모두 global/distance Elo 1500, 불확실성 1에서 시작했다. 공식 신마 자격과 관측 본경주 이력 0회를 동일시하지 않는다.
- 762건 중 618건(81.1%)은 같은 경주 유경험 말의 평균 Elo보다 높았다. 평균 차이는 +4.36점이다. 반대로 상대 최고 Elo보다 높은 경우는 0건이며 평균 차이는 −7.36점이다.
- 기존 순위 모델의 입력 기여도에서 이력 0회 말의 본인 Elo 계열은 평균 +0.026/+0.064/+0.044의 순위 원점수 기여를 보였다. 상대 Elo 계열도 평균 양의 기여였다.
- 모델이 초기값을 유리하게 활용하는 경향은 점검할 가치가 있다. 다만 Elo 차이·모델 내부 기여도는 실제 성적의 원인이나 기본값 변경 효과를 증명하지 않는다. 기여도는 확률 %p가 아니다.

### 주행심사 기록은 이미 거의 모두 들어가 있다

- 이력 0회 762건 중 유효 주행심사 기록 760건, **99.7%**. 확률 평가용 경계 동착 제외 집단에서는 758건 중 756건이다.
- 현 입력은 T−2일까지의 과거 기록에서 유효한 마지막 주행심사 기록과 관측 횟수다. 이 두 입력을 기존 연간 모델이 실제 분기에 사용했다.
- 유효 기록이 있는 756건의 실제 입상률 32.41%, BASE 예측 40.93%, 이번 보정 38.03%다. 미관측은 2건뿐이므로 관측 유무의 성능 차이를 일반화할 수 없다.
- 이력 0회 말의 trial 계열 평균 원점수 기여는 2024/2025/2026 각각 +0.129/+0.194/+0.240이었다. 같은 경주의 유경험 말보다 평균 기여가 크지만 인과 효과가 아니다.
- `trial_coverage_unknown=1`은 수집 완전성 미확인 표시다. 기록 부재와 같은 뜻이 아니며, `trial_observed_any`와 구별해야 한다. 상수인 완전성 표시는 전처리에서 제외된다. 결측 기록은 학습부 중앙값으로 대체되고 결측 표시가 별도로 생성된다.
- 현재 108개 입력에는 주행심사 기록의 날짜 차이나 같은 심사일·거리·주로 대비 상대 기록이 직접 포함되지 않는다. 단순 관측 여부 추가보다 기록을 비교하는 기준이 다음 검토 대상이다. 과거 TRIALRECENCY 실험도 이미 승격에 실패했으므로 최근성만 다시 추가하는 실험은 반복하지 않는다.
