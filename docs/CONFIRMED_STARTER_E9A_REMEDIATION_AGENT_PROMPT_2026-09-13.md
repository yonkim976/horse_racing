## R1: 술어별 말 귀속

독립 로그의 실제 race 3275, 3095, 277을 원문 hash·span·출전키와 대조하여 다음 오류를 제거한다.

- `출발이 늦은 후`를 뒤 말의 관형절로 해석하지 않는다. 3275에서 ③디아나에 잘못 붙인 출발 지연을 제거하고, 직접 명시된 ④한강캡틴을 올바르게 처리한다.
- `출발이 좋지 못했던 ⑦…`을 앞의 ⑨에 붙이지 않는다. 3095에서 명시 대상인 ⑦히어아이엠을 확인한다.
- 서로 다른 술어에 연결된 `과/각각`을 하나의 공동 주어로 확대하지 않는다. 277에서 ⑨의 출발대 진입 불량에 ①의 출발 지연을 붙이지 않는다.
- blocked 경로의 “직전 90자 내 모든 말” 규칙도 같은 절의 주체를 보장하도록 수정한다. 독립 로그의 정상 주행 ①/진로 막힘 ② 반례를 통과시킨다.
- 쉼표로 나열된 공동 주어의 출발 지연 반례를 다룬다. 누락·미해석을 사건 부재 0으로 바꾸지 않는다.

원문에서 주체·역할이 명확한 패턴은 정확히 귀속하고, 모호한 패턴은 근거와 함께 abstain/unknown으로 처리한다. 특정 race_id·말 이름별 예외, 기존 행 번호에 따른 패치, 미해석 전부 무조건 clear 또는 전부 무조건 삭제는 금지한다. 말 이름·번호·입력 순서 치환 반례로 일반화된 규칙인지 확인한다.

## R2: 인용·부정·조건의 절별 판정

interference victim/actor를 생성하기 전에도 start/contact/block과 일관된 관찰 확정 조건을 적용한다. 독립 로그의 quoted_interference, negated_interference가 clear 사건이 되지 않아야 한다. 원문의 진술을 심판의 독립 확정 관찰로 자동 승격하지 않는다.

같은 bullet 안의 별도 직접 관찰은 유효하게 보존한다. 인용·부정·조건의 적용 범위를 구분할 수 없다면 그 부분의 역할을 보류한다. 긍정 사실, 인용만 존재, 후행 부정, 사실+인용 혼합, 조건문의 대응 회귀를 넣고 해당 조건과 기대값을 적는다. 합성 반례를 실제 자료에서 발견한 빈도로 표현하지 않는다.

## R3: clear 행별 검토와 재집계

기존 한 report당 하나의 앵커 60개는 수정하지 않고 문서 탐지용 참고값으로 보존한다. `extractor_anchor_matched`는 말·역할 승인 gate로 쓰지 않는다.

고정 60건 내 기존 clear 197행 전부와 새 버전에서 clear로 유지/추가하려는 모든 행을 원문으로 검토하라. 별도의 검토 원장에 기존 evidence 식별자, 신규 evidence 식별자, 원문 hash/field/좁은 근거 절의 offset, 사건 유형, 말 source key, 역할, 유지/수정/삭제/보류, 이유, 검토 provenance를 남긴다. 기존 197행 중 설명 없이 사라지는 행과 검토되지 않은 신규 clear는 0이어야 한다. 동일 에이전트의 라벨을 독립 전문가 gold 또는 독립 test라고 부르지 않는다. 전수 대조는 이 개발 표본 내 감사다.

독립 검증자가 행별 의미를 다시 읽을 수 있는 간결한 Markdown/JSONL 표를 제공한다. `clear`는 실제 검토가 완료된 사건·말·역할 조합에만 사용하고 모호한 역할을 unknown으로 남긴다. 표본군별, 유형·역할별, clear/ambiguous/abstain, report 수 및 경주·말 key 수를 다시 계산한다. 종전 57/171을 목표로 맞추지 않는다.

report 단위 앵커 불일치와 사건·말·역할 불일치를 별도로 보고한다. 동일 사건의 처분 문장과 관찰 문장이 반복되는 경우 evidence 행과 고유 사건의 관계를 기록한다. 미래 victim count 초안의 중복 처리 정의만 적고 feature 계산은 하지 않는다. 사건 부재·자료 부재·판독 불명·신원 불명·시점 미검증을 구분한다.
