# 경주 분석 화면 개편

## 사용 흐름

`/analysis`에서 오늘의 출전표를 열고 경기장과 라운드를 선택한다. 오늘 자료가 없을 때는 가장 가까운 수집 경주일과 대체 사유를 표시한다. 특정 날짜를 지정했는데 자료가 없으면 빈 상태를 표시한다.

1. 출전마 표에서 각질, 최근 착순, 같은 경기장·거리 출전 횟수, 최신 심사, 조교를 훑는다.
2. 최대 4두를 체크해 기록과 조건을 나란히 비교한다.
3. 말 이름을 눌러 같은 화면의 과거 경주·주행심사·조교·기수 기록을 확인한다. 경주 이력이 없는 말은 주행심사를 먼저 연다.
4. 날짜를 펼쳐 주로 상태, 코너 통과순위, 당시 마번 등을 확인한다. 영상 버튼은 해당 경주/심사의 공식 플레이어 창을 바로 연다.
5. 초반·중반·종반 전개도를 수정하고 메모한다. 배치와 메모는 경주별로 현재 브라우저에 저장된다.

## 데이터 처리

- 선택한 경주일 전날까지의 자료만 사용한다. 과거 자료의 후속 수집·정정까지 동결한 백테스트는 아니다.
- 최근 경주는 기본 12회, 최대 60회까지 펼칠 수 있다. 조회 기간과 거리 필터의 범위를 화면에 표시한다.
- 운영 DB와 검증된 공식 보존자료를 말 고유번호로 연결한다. 보존자료는 읽기 전용이며 중복·격리된 카드는 제외한다. 보존 DB가 없으면 운영 DB 자료만 사용한다.
- 확정된 시간 기준에 따라 통과 누적시간과 종반 구간시간을 구분한다. 기준이 불명확한 수치는 `원문 · 기준 미확인`으로 남기고 비교 집계에서 제외한다.
- 제주 1110m·1610m의 S1F는 초반 210m임을 표시한다. 코너 및 지점의 통과순위는 구간 속도 순위와 구분한다.
- 조교는 최근 28일, 기수 및 말·기수 조합은 이전 365일의 수집 자료를 사용한다. 기수 비율의 분모는 정상 완주이며, 중지·실격 등 제외를 화면에 명시한다.
- 부경 CSV는 해당 경기장의 구간 코드를 사용한다. 누락된 코너 키로 발생하던 오류와 원문 기록이 숨겨지는 문제를 수정했다.

## 전개도

- 공식 평면도를 대체하지 않는 직선–코너–직선 개념도다. 경기장·거리 및 확인된 진행 방향을 표시한다. 영천의 미확인 방향을 임의로 확정하지 않는다.
- 최근 최대 6회 정상 완주의 S1F, 4C/3C(부경·영천은 보유한 G3F 지점 순위도 활용), G1F 통과순위를 출전두수로 정규화한다.
- 같은 측정 지점의 별칭은 중복 근거로 사용하지 않는다. 해당 단계 자료가 없으면 초반 대체임을 표시하고, 초반 자료도 없으면 대기 영역에 둔다.
- 각 단계의 초기 위치, 측정 지점, 표본 수를 표시한다. 실제 주행 라인·이동 궤적이나 승률을 뜻하지 않는다.
- 마번별 색상, 드래그·방향키, 구간별 저장, 되돌리기, 초기화, 대기 배치를 지원한다. 이전 수동 배치는 보존한다.
- 선택된 말에 따라 기록표 높이가 달라져도 전개도 드래그 위치가 튀지 않도록 보정했다.

## 검증

- 관련 Python 테스트 54개 통과: 대시보드, 분석 데이터, 보존자료 연결, 영상 URL.
- Ruff 및 JavaScript 문법 검사 통과.
- 전개도 동작 검증: 구간별 독립 배치, 결측·0 처리, 키보드·포인터, 저장 복원, 이전 수동 배치 보존, 저장 실패, 좁은 화면의 다두수 배치.
- 실제 브라우저에서 제주 출전표, 신마 심사 우선 표시, 말 비교/전환, 당시 마번, 전개도 드래그·새로고침 복원을 확인했다.
- 모바일 크기에서 페이지 전체 가로 넘침이 없음을 확인했고, 고정 메뉴 높이를 측정해 겹침을 수정했다. 다크·라이트 테마를 확인했다.
- 공식 영상 주소는 별도 브라우저 탭에서 영상 로딩을 확인했다. 내장 브라우저의 iframe이 빈 문서에 머물러 최종 UI는 공식 팝업 연결로 구성했다. 외부 팝업 창의 자동 검증은 컴퓨터 제어 권한 부족으로 완료하지 못했다. 팝업이 차단되면 일반 새 창 링크를 제공한다.

## 범위와 남은 제약

데이터 미수집과 실제 이력 없음은 동일하게 해석하지 않는다. 영상 게시 여부는 공식 제공 상태에 따른다. 메모·배치는 계정/기기 간 동기화되지 않는다. 이번 작업은 분석 화면과 조회 경로 개편이며, DB 이전·운영 배포·동시접속 1000명 부하 검증은 포함하지 않는다.
