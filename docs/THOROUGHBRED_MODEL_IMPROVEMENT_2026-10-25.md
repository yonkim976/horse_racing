# 서울·부산 운영 모델의 지속 개선

2026-10-25 사용자가 personal_t2 조교 변화 모델로 운영 교체하고 지속적으로 발전시키라고 지시했다. 이 대화의 주간 개선 작업은 이 문서를 기준으로 한다.

## 현재 운영과 불변 기록

현재 선택은 항상 `config/prediction_model_registry.json`의 Thoroughbred active_profile을 resolver로 확인한다. 최초 승격 프로필은 `thoroughbred-training-state-20261025-v1`, 원본은 `production_models/thoroughbred_training_state_20261025_v1/`다. 새 추론은 `scripts/predict_thoroughbred_main.py`를 사용한다. 제주 프로필은 이 범위에 포함하지 않는다.

운영 가중치·온도·피처 수학·승격 결정·이전 예측을 덮어쓰지 않는다. 새 데이터는 날짜/해시가 있는 입력 스냅샷으로 보관하고, 새 후보는 별도 연구 폴더에서 학습한다. 신규 연구가 이전 보고서의 production_changed:false를 소급 변경하지 않게 한다. 새 후보의 추가 운영 승격은 별도 사용자 지시와 기술 검증 후 수행한다.

## 주간 작업

매주 월요일 오전10시(한국시간), 먼저 이전 개선 기록과 새 예측/결과의 추가 여부를 확인한다. 이미 같은 데이터·변수·모델 조합을 시험했으면 반복하지 않는다.

1. `data/predictions/`와 승인된 연구DB/수집 원장에서 새 입력·사전 예측·공식 결과를 확인한다. 모델과 입력이 경기 전에 고정된 실제 예측을 후향 재생과 구분한다. 이력이 갱신됐으면 원문·모델 입력 관측일·공개/수집시각·범위·빈 응답을 감사한다. 새 source manifest를 별도 경로에 만들고 기존 고정 manifest를 수정하지 않는다. 원천DB 전체 복제와 조교/진료 미관측의0 대체는 피한다.
2. 사전 예측과 결과를 경주키·공식말ID·출전마 전체로 대조한다. 취소/미완주/동착을 보존하고, 예측 후 취소를 이유로 결과를 유리하게 필터링하지 않는다. 공식 결과가 없으면 평가를 보류한다. 연구/운영 DB 쓰기와 실제 예측 게시를 이 주간 연구 요청만으로 실행하지 않는다.
3. 축1두,삼복6조합,복승/복연1·3조합의 고정 예산으로 현재 운영과 복구용 이전 모델을 비교한다. 서울·부산,등급/거리,신마/저경력/휴양,입력 누락,축 확률 구간을 진단한다. 부산 복연3조합 악화와 사전 조교자료 지원률을 계속 관찰한다. Brier/NLL과 경주일 단위 구간을 함께 보고한다. 수익률은 구매 시점 배당/배당금/단위 구매액이 일치할 때만 별도 평가한다.
4. 새로운 증거가 있으면 다음 입력 묶음/구조 가설을 하나 고르고 계획·주지표·평가기간을 먼저 고정한다. 모델/변수를 학습결과에 맞춰 계속 늘리지 않는다. 연도/경주 단위 시간순 분할을 유지한다. 먼저 이미 실행한 조교 묶음과 비교하고, 미사용 미래 예측이 없다면 독립 미래검증이라고 부르지 않는다. 2027년에는 현재2026 가중치를 자동 적용하지 말고 새 연도 모델을 별도 검증한다.
5. 선택한 실험을 실행·재추론·검증한 뒤 연구 원본·중앙 결론·출처 해시·미게시 요약·용량 명세를 갱신한다. 동일 문제로 중복 실행하지 않도록 `production_models/.../IMPROVEMENT_LOG.md`에 데이터 종료일·입력/모델 해시·다음 가설을 남긴다. 대규모 수집/스키마/배포/새 자동 승격은 이 연구 점검의 기본 동작이 아니다.

새 자료나 실행 가능한 새 가설이 없으면 기존 검증/학습을 다시 돌리지 않고 기록만 남긴다. 의미 있는 성능/품질 변화,새 실험 완료,실패 또는 사용자 조치가 필요할 때만 이 대화에 알린다. 같은 보류 사유를 반복 보고하지 않는다. 다른 채팅/Discord/메일에는 메시지를 보내지 않는다.

승격 시점의 운영 대비 축 비교는1,258경주800→830건(+2.38%p)이다. 독립 미래검증은 아니며,조교만 추가한 효과는817→830건이고 구간은0을 포함한다. 부산 복연3조합314→299건 감소도 보존한다. 새 평가에서 불리한 결과가 나와도 과거 모델·예측·판단 근거를 삭제하거나 과거 승격을 독립 검증 통과로 바꾸지 않는다.

실시간 예측은 결과 없는 완전한 출마표·사전 관측시각·출전마 수·30분 전 기한을 확인하고,재현 가능한136입력을 생성한다. 누락된 입력열/지원하지 않는 지역/잘못된 날짜/소스 해시 변경은 이전 가중치로 몰래 대체하지 않고 실패를 드러낸다. 오래된 이력·불완전 조교창은 partial로 표시한다. 실제 게시가 필요하면 별도의 사용자가 승인한 발행 절차를 따른다.
