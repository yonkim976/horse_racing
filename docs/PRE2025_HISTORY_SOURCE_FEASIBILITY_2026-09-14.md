# 2025년 이전 조교·보강자료 수집 가능성 확인

**결론: 수집 가능하다.** 앞선 [모델 데이터 감사](MODEL_DATA_READINESS_AUDIT_2026-09-14.md)의 “2015~2024년 조교 미보유”는 현재 운영 DB와 학습 파일의 상태를 뜻한다. 공식 원천에 과거 자료가 없다는 뜻이 아니다. 이번에는 KRA Text 자료실의 2015년 목록을 읽고 6개 표본 파일을 실제로 내려받아 내용을 확인했다. 대량 수집이나 DB 적재는 하지 않았다.

| 자료 | 2015년 공식 목록 | 실제 내용 표본 | 현재 DB의 2025년 이전 행 | 수집 판단 |
|---|---|---|---:|---|
| 일반 조교 `dacom55` | 서울·제주·부경 모두 있음 | 세 경마장 모두 내려받아 말별 조교행 확인 | 0 | 원문 수집 가능, 새 파서·말 연결 필요 |
| 진료 `dacom72` | 서울 있음 | 날짜·말명·마방·진단/처치 내용 확인 | 0 | 원문 수집 가능, 새 파서·말 연결 필요 |
| 출전마 진료·장구 `dacom71` | 서울 있음 | 이번에는 목록만 확인 | 0 | 원문 후보, 내용/연도별 완전성 추가 확인 |
| 주행심사 `dacom23` | 서울 있음 | 2015년 결과 파일 내려받음 | 0 | 원문 수집 가능. 현재 주행심사 파서는 이 표본에서 경주 블록을 찾지 못해 시대별 파서 보완 필요 |
| 출발조교 `db5` | 서울 있음 | 날짜·조/조번·말명·기승자·훈련평가 확인 | 0 | 원문 수집 가능, 새 파서·말 연결 필요 |
| 출발심사 `db4` | 서울 있음 | 이번에는 목록만 확인 | 0 | 원문 후보, 내용 확인 필요 |
| 출전마체중 `dacom12` | 서울 있음 | 이번에는 목록만 확인 | 현재 DB에는 과거 경주 성적표 체중이 있음 | 별도 사전 시점 체중 원천으로 검토 가능 |

2015년 서울 일별조교 파일 목록의 검색 결과는 31페이지, 제주 21페이지, 부경 31페이지였다. 이는 해당 연도의 검색 목록 페이지 수이며 전체 파일의 파싱·경주별 연결·모든 날 완전성을 증명하지 않는다. 서울 일별조교 무검색 목록의 마지막 페이지에는 **2003-09-21 파일**이 있었고, 중간 350페이지에는 **2015-03-18~28** 파일이 있었다. 2025년 이전 자료가 자료실에 실재한다는 추가 근거다.

2015년 서울 조교 표본은 훈련일, 소속조·조번, 마명, 기승자 유형, 입장·퇴장 시각, 훈련시간과 출전예정 표식을 포함한다. 제주·부경 표본도 같은 종류의 말별 훈련 행을 포함한다. **공식 말 ID는 표본에 보이지 않으며, 최근 API의 구보·습보 횟수 열도 없다.** 2015년 진료 표본에는 말명과 진료 내용이 있으나 공식 말 ID가 보이지 않는다. 따라서 기존 2025년 API 행과 같은 열 집합으로 무검증 병합하면 안 된다. 말명과 당시 경마장·소속조·말 이력으로 결정적인 경우에만 연결하고, 동명이마·마명변경·조교사 이동은 미해결로 보존해야 한다.

현재 코드는 Text 파일의 일반 다운로드 경로를 갖고 있지만 `dacom55`·`dacom72`·`db5`의 DB 적재 파서는 없다. `dacom23` 주행심사 수집기는 2025년 이후 파일에 사용됐으나, 이번 **2015-12-31 표본의 `parse_running_trial_report` 시험은 `ValueError: 주행심사 보고서에서 경주 블록을 찾지 못했습니다`**로 끝났다. 이는 원문을 가져올 수 없다는 뜻이 아니라 오래된 서식에 현재 파서가 맞지 않는다는 뜻이다.

공공데이터포털의 [일별훈련 상세정보 API](https://www.data.go.kr/data/15058782/openapi.do)는 훈련일·훈련월 조회를 설명하지만, **이 API의 2015~2024 실제 응답은 이번에 호출하지 않았다.** KRA Text 자료실의 실제 파일로 수집 가능성을 확인한 것이다. [KRA 서울 Text 자료실](https://race.kra.co.kr/dbdata/textData.do?Act=12&Sub=1&meet=1)의 목록과 원문을 한정 조회했다. 서울 외 진료·심사 등 기타 분류의 2015년 존재 여부는 이 표에서 주장하지 않는다.

모델 연구에는 두 경로가 있다. 현재 데이터로 기준 모델을 진행하면서, 병렬로 **2015~2024 Text 조교의 소량 파서·말 ID 연결 시험**을 수행할 수 있다. 먼저 서울·제주·부경에서 서로 다른 연도·서식의 고정 표본을 파싱하고, 말 ID 유일 연결률·원문 보존·훈련시간 분포를 수치로 확인한다. 충분하면 원문을 보존하며 과거 기간을 백필한다. 구보·습보가 없는 시대는 해당 항목을 결측으로 유지하고, 공통 훈련일수·훈련시간 같은 공통 정의부터 이용한다. 2015년부터 모든 조교 세부항목이 이미 표준화돼 있다고 표현하지 않는다.

증거는 [목록·표본·해시 manifest](../data/experiments/pre2025_source_feasibility_20260914/artifact_manifest.json), [기계 판독 결과](../data/experiments/pre2025_source_feasibility_20260914/findings.json)에 남겼다. 이번 한정 조회에서 저장한 Text 목록은 11개(2015년 조교 3개, 2015년 기타 6개, 서울 조교 중간·마지막 목록 2개)이며, 조교 최신 목록도 한 차례 확인했다. 표본 파일 6개를 내려받았다. URL·SHA256은 산출물에 보존했다. 표본 크기로 전체 연도 완전성을 추정하지 않았다.
