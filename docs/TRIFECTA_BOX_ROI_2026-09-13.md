# 삼쌍승식 Top-N 박스 환수율 비교 — 2026-09-13

## 질문과 정의

모델 우승확률 상위 `N=3..10`두를 고른 뒤, 선택한 말로 만들 수 있는 모든
1·2·3착 **순서 있는** 조합을 동일 금액으로 한 장씩 구매한다. 경주당 장수는
`N×(N−1)×(N−2)`다. 최종 `TRI` 배당은 정산에만 사용하고 마권 선택에는 사용하지
않는다.

- **환수율** = 총 환급액 / 총 구매액 × 100. 100%가 손익분기점.
- **순 ROI** = 환수율 − 100%.
- **경주 적중률** = 해당 박스에서 환급되는 순서 조합이 하나 이상 나온 경주 비율.
- 투자 단위는 조합당 1단위이며, 아래 환수율은 단위를 1,000원 등으로 바꿔도 동일하다.

  평가연도 2026에 대해 이전 연도까지 학습한 모델의 확률을 사용한다.

- 결과의 1·2·3착 순서와 공동착순은 `ordered_winner_keys`로 판정했다.
- 공식 DB의 최종 삼쌍승식 `odds_snapshots.bet_type='TRI'`을 사용했다.
- 완전한 정상 1·2·3착은 1,624경주 모두 있었고, 공식 승리 조합 배당이 누락되거나
  비정상인 8경주를 제외해 1,616경주가 정산 가능했다. 그중 공동착순 경주는 8개다.

  수익 검증이나 오늘(2026-09-13)의 실현 ROI가 아니다.
