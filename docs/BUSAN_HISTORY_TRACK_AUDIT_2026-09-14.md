# 부산경남 정식 경주와 주로 변화 조사 (2026-09-14)

## 판단

부산경남의 공식 경주결과 API 첫 양성은 2004-11-28이지만, 그해 38경주는 모두 `일반(모의)`다. 2005년에도 474경주 중 328경주가 모의이며 정식 경주 첫날은 2005-09-30이다. 따라서 승부 예측용 역사적 라벨은 그날부터 후보로 삼고, 모의경주는 별도 보존한다. 2006년은 모의경주가 없는 첫 온전한 연도다. 이는 `data/logs/historical_course_first_era_20260914.json`, `data/logs/historical_race_regime_transitions_20260914.json`, `data/logs/course_comparability_followup_api_20260914.json`의 연도별 공식 API 집계에 근거한다.

공식 KRA의 현재 안내 두 곳이 부경 주로 제원을 서로 다르게 제시하므로, **2005~2026년 주로 형상이 변하지 않았다는 결론도, 실제로 특정 연도에 바뀌었다는 결론도 아직 낼 수 없다.** `경주로 현황`과 KRA 기업 소개는 내주로 1,470m·외주로 2,000m·조교주로 1,300m, 단거리 내주로라고 쓴다. 같은 사이트의 `경주로 구조`는 각각 1,460m·2,008m·1,292m, 단거리 외주로라고 쓴다. 단순 반올림으로 설명할 수 없는 단거리 경로 충돌도 있다. 문서 갱신 이력 또는 도면/시행 계획의 시점별 원본 없이 이 차이를 공사 완료 사실로 간주하지 않는다.

KRA 계약 정보에는 경주로용 모래 구매가 [2018년](https://ebid.kra.co.kr/cti/all/view.do?b_code=2018040280&ct_code=2018040056&ct_round=0&work_type=%25B9%25B0%25C7%25B0%25B1%25B8%25B8%25C5), [2021년](https://ebid.kra.co.kr/cti/all/list.do?const_end_date=2021-06-09&const_start_date=2021-03-09&cont_method=&cont_name=&end_amount=&order_place=&page=2&select_method=&start_amount=&work_type=), [2023년](https://ebid.kra.co.kr/cti/supp/list.do?const_end_date=2023-11-12&const_start_date=2023-08-12&cont_method=&cont_name=&end_amount=&order_place=&page=3&select_method=&start_amount=&work_type=04), [2024년](https://ebid.kra.co.kr/cti/supp/list.do?const_end_date=2024-09-20&const_start_date=2024-06-20&cont_method=&cont_name=&end_amount=&order_place=&page=1&select_method=&start_amount=&work_type=04)에 보인다. 이는 표면 관리·보충 가능성의 증거이나 구매계약만으로 교체 범위, 반영 경주일, 주로 구조 변경을 확정하지 않는다. 현재 `경주로 현황`은 평균 모래 두께 8cm, 함수율·살수 계획을 게시한다.

## 경주 구성 변화

| 범위 | 확인된 경주 구성 | 해석 |
| --- | --- | --- |
| 2004 | 38/38 모의; 1,000m 23, 1,200m 15 | 정식 승부 라벨에서 제외 |
| 2005 | 모의 328, 정식 146; 첫 정식 9월 30일 | 모의/정식 분리 필요 |
| 2006 | 정식 578, 모의 0; 핸디캡 97 | 현재와 부담중량 분포 차이 |
| 2015 | DB 완료경주 813; 1,300m 84 | 2015년에는 이미 1,300m 시행 확인 |
| 2026-09-13까지 | DB 완료경주 530; 1,300m 81; 핸디캡 368 | 2006년과 거리·부담 유형 구성 차이 |

2006년 1,300m 정식경주는 기존 공식 API 감사에서 0건이다. 이 조사만으로 1,300m의 정확한 신설일은 확정하지 않는다. [KRA 공식 레이팅 설명](https://race.kra.co.kr/down/ratingQNA_20250118.pdf)처럼 2015년 2월 이전 승군점수와 이후 레이팅은 다른 제도다. 초기 마령·국산/외산 분리와 현재의 등급·핸디캡 구성도 같은 모집단으로 취급하지 않는다. 2026년 영천은 영남 메뉴에 함께 표시되지만 부경 경주장(meet=3)과 별개로 구분해야 한다.

## 원천·ID 연결 상태

과거 공식 결과 API에서 2004~2014년 부경 7,111경주·77,878 말별 결과행이 확인되지만 현재 정규화 DB에는 적재되지 않았다. 그중 2004년 및 2005년 정식 이전 모의경주를 모델 라벨에서 제외해야 한다. 현재 DB의 2015~2024년 부경 출전 78,215행 중 조교사 또는 마주가 `text:` 임시 ID인 행은 35,157개다. 2025년 이후 부경 출전행에는 이 임시 ID가 없다. 따라서 2015~2024년 공식 경주결과 원문으로 당시 경주의 말·조교사·마주 ID를 대조해야 한다.

일별 조교 API의 부경 첫 양성 행은 2004-06-30, 출발조교는 2009-05-21이다. 2015~2024년 일반 조교 원문은 1,514,768행 확보됐지만, 원천의 조교사명은 2016~2020년에 비어 있다. 말 번호를 통한 말별 조교량과, 조교 발생일 당시의 조교사별 귀속은 구분한다. 과거 진료 Text는 2005-05-04 사건이 포함된 2005-05-11 파일부터 확인되나 말 ID 연결이 필요하다. 진단 내용이 있는 의료 API의 첫 확인 연도는 2019년이고 당시 응답 64행 중 51행에 내용이 있다. 이를 전 말의 의료 이력 완전성으로 해석하지 않는다.

근거: `docs/PRE2015_RACE_RESULT_AVAILABILITY_2026-09-14.md`, `docs/HISTORICAL_SOURCE_COLLECTION_2026-09-14.md`, `docs/API_COMMON_RECORD_AVAILABILITY_2026-09-14.md`, `data/horse_racing.sqlite3` 읽기 전용 연도별 집계. 과거 결과·조교·주로상태의 사후 조회 가능성과 당시 경주 전 이용 가능성은 별개다.

## 모델용 권고와 남은 확인

1. 2005-09-30 이후 정식경주를 부경 역사적 결과 후보로 보존하되, 비교 기준은 우선 2016년 이후 레이팅 체계의 정식경주로 둔다. 2005~2014년을 추가할지는 독립적인 시간순 비교로 판단한다.
2. 경주기록은 부경 × 정확거리 × 경주일 주로 함수율/상태 × 등급/부담중량 시대를 조건으로 정규화한다. 단순 연도별 평균속도 변화만으로 모래나 구조 변경을 판정하지 않는다.
3. KRA의 상충 안내 두 곳에 대해 시점별 공식 도면·시행 계획·공사 준공자료를 확인하고, 각 거리의 실제 출발지점 및 내/외주로 사용을 연도별로 매핑하기 전까지 `단거리 내/외주로`를 확정 feature로 만들지 않는다.
4. 2015~2024년 공식 사람 ID를 결과 API로 복원하고, 경주 원문의 전수 키·중복·모의 여부 및 경마장 코드가 맞는지 대조한다. 영천 경주를 부경으로 읽지 않는다.

이번 조사는 기존 DB와 원천 파일을 읽기 전용으로 점검했다. 신규 모델 학습·운영 변경은 하지 않았다.
