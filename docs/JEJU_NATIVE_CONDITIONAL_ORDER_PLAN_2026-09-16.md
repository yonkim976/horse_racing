## 고정한 비교

이전 실험에서 공동모델의 순서 출력을 그대로 교체했을 때 순서 적중이21→13회로 감소했다. 이번에는 입상 집합을 학습하는 출력 없이 순서만 학습한다. 동시에 원시 발전·반등4개를 같은 거리·상대 강도를 고려하는10개 변수로 교체한다.

두 변경을 구분하기 위해2×2조합을 모두 평가한다.

| 순서 모델 | 기존 집합 R_FORM | 보강 집합 R_REBOUND |
|---|---|---|
| 기존108개 입력의 순서 전용 O_BASE | HY_C_BASE | HY_RB_BASE |
| 발전 변수 보강114개 입력의 순서 전용 O_REBOUND | HY_C_REBOUND | HY_RB_REBOUND |

집합 모델 자체의 교체 효과는 R_REBOUND와 기존 R_FORM·R_NO_GROWTH를 별도로 비교한다. 기존 HY_R_FORM, HY_FORM_ORDER, J_FORM도 저장 예측을 재사용한다. 이번 결과를 보고 다른 조합을 추가하지 않는다.

## 순서 목적함수

- 각 학습 경주의 **실제 공식 입상 세 마리** 사이 순서에 조건부 Plackett–Luce 확률을 부여한다. 입상 집합을 맞힌 학습 경주만 골라 쓰지 않는다.
- 일반 경주는 정답 순서 확률의 음의 로그를 최소화한다. 동착은 가능한 정답 순서 확률을 합산한다. 경계 동착으로 가능한 세 마리 집합이 여러 개면 각 고유 집합에 같은 비중을 준다.
- 다른 착순 말에는 그 경주 순서 손실의 직접 기울기가 없다. 공유 모형은 다른 경주에서 관측된 해당 말의 변수로 일반화한다.
- 적용할 때는 집합 모델이 선택한 세 마리의 순서를 산출한다. 학습의 실제 입상 집합과 예측 집합이 다를 수 있으며, 집합 자체가 틀린 경우 순서 모델이 그 실패를 해결할 수는 없다.
- CAL에서는 각 집합 모델의 고정된 집합 확률과 조건부 순서 확률을 곱한 결합분포의 정답 확률을 보정한다. 경계 동착의 학습 균등 가중과 CAL의 집합 모델 가중 차이를 명시한다.

## 발전·반등 보강

같은 거리의 최근 유효 정상 이력을 최대6회 사용한다. 상대 승점은 함께 정상 완주한 비교 가능한 말에게 이기면1, 동률이면0.5다. 사전 Elo로 계산한 기대 승점과 실제 승점의 차이를 surprise로 정의한다. 좋은 착순 자체와 기대 이상 수행을 구분한다.

- 최근3회 surprise 평균, 최근3회와 그전3회 차이, 최근5회 최고 surprise
- 같은 거리 유효 이력 수, 같은 과거 경주 중앙 기록 대비 시간(ms/100m)
- 막판200m 상대속도와 실제 상대 승점의 차이
- 같은 거리의 과거 건조/양호 및 습한 주로 surprise와 각 관측 수

surprise 평균과 최고값은 관측 수 n에 대해 n/(n+3)으로0쪽으로 줄인다. 상대 시간 평균에는 이 축소를 적용하지 않는다. 자료가 전혀 없는 성적은0으로 만들지 않고 결측으로 둔다. 현재 경주의 실제 날씨·함수율·마체중은 사용하지 않는다. 과거 주로와 같은 경주 상대 기록은 순수한 날씨 인과효과 보정값이 아니다.

상대 Elo는 해당 과거 경주 이전의 값이고, 모든 대상 말 이력은T−2까지만 사용한다. 새10개 변수는79,731행으로 별도 저장하며 기존 봉인 자료는 수정하지 않는다.
