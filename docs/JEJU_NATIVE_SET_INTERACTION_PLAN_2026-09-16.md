# 제주마 입상 세 마리 조합 직접 학습 v8 계획

## 목적과 고정 범위

v7에서 기존 후보의 715경주 중 집합 실패 658경주, 집합 정답·순서 실패 36경주를 확인했다. 이번에는 누락 입상마를 진단하고, 세 마리 조합 자체의 확률을 학습한다. 기계 판독 프로토콜은 첫 학습 전에 `data/research/jeju_native_set_interaction_v8_20260916/protocol.json`에 고정했다.

- S_ADDITIVE: 기존 108개 입력 → 은닉 16개 tanh → 말별 점수 → 세 말 점수 합 → 모든 조합에 softmax 확률.
- S_INTERACTION: 위와 동일한 모형에 세 말 사이의 대칭적인 상호작용 19개를 추가한다.
- 두 후보 모두 집합 정답의 음의 로그 확률을 직접 학습한다. 경계 동착은 가능한 고유 정답 집합 확률을 한 번씩 합한다.
- 기존 HY_R_FORM, v6의 R_NO_GROWTH, v7의 HY_C_REBOUND는 예측을 재사용한다. 후보를 결과에 따라 추가하지 않는다.

개별 말의 점수를 합하는 모델은 조합마다 다른 경쟁 관계를 직접 표현하기 어렵다. 대조 모델을 같은 구조·시드로 맞춰 상호작용 추가의 효과를 분리한다. 기존 LambdaRank와의 차이는 학습 목표와 모델 구조의 차이도 포함하므로 전부 상호작용 효과로 해석하지 않는다.

## 상호작용 19개

경주 내 다음 8개 사전 변수의 유효 값 중간 순위를 −1~1로 변환한다. 결측 또는 유효 관측이 2개 미만이면 0이다. 입력의 결측 여부는 기존 말별 전처리에도 남는다.

1. 전체 Elo
2. 거리별 Elo
3. 과거 초반 상위 3 빈도
4. 과거 막판 200m 상대 속도
5. 선언 출주번호의 상대 위치
6. 선언 부담중량
7. 현재와 이전 상대마 Elo 차이
8. 직전 출전 이후 경과일

각 변수의 세 쌍 곱 평균 8개, 세 말 곱 8개, 서로 다른 말 사이의 선행×추입·선행×번호 위치·전체 Elo×중량 교차 곱 평균 3개다. 세 말을 어떤 순서로 나열해도 같으며 미래 결과나 추정한 기수 의도를 쓰지 않는다. 출주번호를 물리적 게이트 위치의 인과효과로 해석하지 않는다.

이 값들은 조합 내 상대적 유사성과 다양성을 표현하는 가설이다. ‘선행마 두 마리는 무조건 불리하다’ 같은 방향을 규칙으로 강제하지 않는다. 순위 변환은 값의 절대 차이를 버리며, 결측은 중간 순위와 같아진다는 제약이 있다.

## 학습·적용·검증

- 기존 시간순 FIT/TUNE/CAL/EVAL 4폴드, 시드 17/43, L2=.001, 최대 L-BFGS 100회.
- FIT만으로 결측 대체·스케일을 학습한다. TUNE 집합 NLL 최소 체크포인트를 선택하고, 두 시드의 조합 점수를 평균한다.
- CAL에서 양수 집합 온도 하나를 보정한다(log 범위 −4~4).
- 기존 HY_R_FORM의 순서 모델과 순서 온도는 그대로 사용한다. 순서 모델 재학습·재보정은 하지 않는다.
- 한 마리는 입상 주변확률이 가장 높은 말, 세 마리는 확률이 가장 높은 집합, 순서는 그 집합 안에서 가장 확률이 높은 순서 하나를 선택한다.
- 2후보×4폴드×2시드=16학습, 8보정, 8저장 묶음. 모든 학습 경주와 가능한 모든 세 마리 집합을 쓴다. 기존 예측이 두 마리를 맞힌 경주만 골라 학습하지 않는다.
- 공통 2025년 715경주·98일에서 세 목표, 확률 손실, 경주/경주일 재표본 5,000회 구간을 보고한다. 경계 동착 6경주는 말별 확률 오차에서 제외한다.

연구 후보 승격 조건도 사전에 고정한다. HY_R_FORM 대비 집합 적중 증가의 경주일 95% 하한이 0보다 크고, 한 마리·순서 적중 점추정치가 낮아지지 않아야 한다. 만족해도 반복 개발 자료의 잠정 후보이며 미사용 기간 검증 전 실전 우위를 확정하지 않는다.

## 누락 입상마 진단

기존 335개 ‘두 마리 정답’ 경주 중 경계 동착 3경주를 제외한 332경주에서 빠진 입상마 한 마리와 잘못 고른 말 한 마리를 비교한다. 거리 이력, 상대 강도, 초반·막판 성향, 중량·체중·기수 변화를 저장한다.

이는 이미 실패한 경우로 조건을 건 사후 진단이다. 높은 모델 점수로 선택된 말과 누락된 말의 변수 차이가 있다고 해서 원인이나 새로운 선택 규칙이 증명되지는 않는다. 후보·변수 정의는 진단 결과에 따라 추가 변경하지 않는다.

## 정보 시점과 제한

기존 T−2 과거 이력과 선언 출마표 변수를 재사용한다. 당일 실제 결과·함수율·체중은 넣지 않는다. 2026년 결과·예측은 열지 않는다. 실제 출전마 기준, 과거 출마표 공개·수정 시각 미입증, 2025년 반복 개발이라는 제한을 유지한다. 기존 봉인 산출물은 변경하지 않는다.


## v8 실행 완료와 후속 계획

두 고정 후보의 16학습·8보정·8저장 묶음 재현 검증을 완료했다. 개별 점수 합 집합 모델은 한 마리 460회·세 마리 46회·정확한 순서 13회, 상호작용 모델은 456회·44회·14회/715경주였다. 상호작용 모델은 기존 두 마리 정답 335경주 중 15경주를 세 마리 정답으로 바꾸었지만 기존 집합 정답 28경주를 잃었다. 새 후보를 채택하지 않고 기존 HY_R_FORM(454·57·21회)을 유지한다.

동착 경계를 제외한 누락 말 대응 진단 332건을 저장했다. 누락 입상마의 같은 거리 경험 중앙값은 6회, 잘못 선택한 말은 2회였으며, 선택된 말 쪽의 과거 구간 이력 결측도 더 많았다. 실패 사례에 조건을 건 사후 비교이므로 인과나 새 선택 규칙의 증거로 삼지 않는다. 후속은 전체 대상에서 경험 부족·구간 결측에 따른 확률 과신 여부를 사전 고정 구간으로 점검하고, 보정 효과와 선정 효과를 분리하는 방향이다. 2025년은 반복 개발 자료, 2026년은 미사용으로 유지한다.
