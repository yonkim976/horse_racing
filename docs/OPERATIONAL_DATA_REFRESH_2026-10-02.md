# 운영 데이터 최신화 결과

2026년 10월 2일 사용자 요청으로 로컬 운영 SQLite와 Supabase 운영 DB를 수동 갱신했다. 최종 집계와 오늘 말별 값의 대조 시각은 23:20 KST다. 경주 당일 변경과 결과, 최근 조교, 진료 원문과 주행심사를 갱신했으며 심판리포트도 다시 조회했다. 모든 종류의 데이터가 오늘 날짜까지 저장됐다는 뜻은 아니다.

대상은 로컬 `data/horse_racing.sqlite3`와 Supabase `horse-racing-prod` 프로젝트 `xkykmhhkjtosptoibduo`다. 제주와 더러브렛 폴더의 별도 연구 DB, 모델과 예측 원장은 수정하지 않았다.

## 저장 검증

최근 7일 진료 원문 983행과 진단 슬롯 연결 748행은 공식 말 ID와 원문을 기준으로 정렬한 내용 해시가 양쪽에서 일치했다. 내부 PK와 재조회 시각은 대조값에서 제외했다. 슬롯 연결과 원래 진단 문구의 불일치는 양쪽 모두 0건이었다.

조회 범위 내 일반조교, 출발조교 회차, 진료, 체중의 업무 키 중복 그룹은 양쪽 모두 0건이었다. 제주 하루 두 번 조교를 중복으로 제거한 것이 아니라 같은 회차의 반복 적재 여부를 검사했다. 전체 역사 데이터에 대한 중복 감사는 이번 검사 범위가 아니다.

당일 수집과 일별 조교 관련 테스트 30개가 통과했다. 새 운영 코드를 배포하거나 스키마를 변경하지 않았다.
