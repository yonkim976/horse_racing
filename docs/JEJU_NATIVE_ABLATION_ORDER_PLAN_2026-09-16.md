# 제주마 변수 묶음 제거·순서 확장 실험 v6

## 고정한 질문

1. 신규 40개 변수 중 어떤 묶음이 전체 모델의 성능에 추가로 기여하는가?
2. 기존 세 마리 선택을 유지한 채 새 변수로 학습한 순서 출력을 쓰면 정확한 순서 예측이 개선되는가?

## 실험 후보

기존 H3의68개 + 신규40개 =108개 입력을 사용한 R_FORM을 기준으로 신규 변수 묶음을 하나씩 제거한다.

| 제거 묶음 | 개수 | 의미 |
|---|---:|---|
| 편성 강도 | 9 | 현재·과거 경쟁마의 전체/거리별 사전 Elo |
| 전개·구간 | 16 | 출주번호 방향, 초반 경쟁, 기수 초반 경향, 통과순위, 막판 구간속도 |
| 중량·체중·기수 변화 | 6 | 과거 중량과 체중 변화, 현재 선언 중량과의 차이, 기수 교체 |
| 발전·반등 | 4 | 자기 Elo 변화, 최근 수행 변화, 최고 수행, 부진한 착순에도 좋은 막판 속도 |
| 주로 | 5 | 과거 함수율별 성적·관측 수, 같은 과거 경주의 중앙 기록 대비 차이 |

이는 신규 묶음의 추가 기여 검증이다. 기존 H3에도 체중·구간 등의 정보가 남으므로 해당 개념을 완전히 제거한 실험이나 인과효과로 해석하지 않는다. 다른 묶음과의 중복·상호작용 때문에 제거 효과를 단순 합산하지 않는다.

J_FORM은 기존 J_H3_w10의 구조(공유 tanh16, 집합/순서 두 출력), 목적함수, 시드, 정규화와100회 반복 한도를 유지하면서108개 입력으로 학습한다. HY_FORM_ORDER는 기존 R_FORM의 한 마리 선택·집합·주변확률을 고정하고 J_FORM의 순서 출력만 사용한다. 기존 HY_R_FORM과 비교하면 집합 변경 없이 순서 모델 교체를 평가할 수 있다.

## 학습·검증 규칙

- 제거 후보5개×4폴드×2시드=40회 + J_FORM 4폴드×2시드=8회, 총48학습.
- 제거 후보 확률보정20회 + J_FORM 두 온도 보정4회 + 하이브리드 순서 온도 보정4회=28보정. 저장 묶음28개.
- FIT 전처리·학습, TUNE 체크포인트 선택, CAL 확률보정, EVAL 최종 개발 보고를 분리한다. 기존6개 기준모델은 재학습 없이 저장 예측을 사용한다.
- 2025년715경주·98경주일, 확률오차는 경계동착 제외709경주. 같은 경주/경주일을5,000회 짝지어 재표본 추출하며95%구간을 보고한다.
- 결과를 보고 후보·변수묶음·반복횟수를 추가하거나 재학습하지 않는다. MLP 수렴 실패 또는 반복한도 도달은 감추지 않고 보고한다.
- 2025년은 반복 개발용이므로 구간은 탐색적이며 다중비교 보정을 적용하지 않는다. 새로운 독립 검증 성능으로 발표하지 않는다.
- 2026년 결과와 이번에 수집한206두 선언자료는 이 학습·평가에 넣지 않는다. 과거 공개·수정 시각 불확실성도 그대로 유지된다.

프로토콜은 첫 학습 전에 저장했고, 기존 데이터/실험 해시·실행 대장·저장 모델·예측·독립 재현 검증을 보존한다.

## 실행 결과 및 결정

48회 학습·28회 보정·28개 저장 묶음 재현을 완료했다. 신규 순서 출력 교체는 기존21회에서13회로 감소해 채택하지 않는다. 발전·반등 제거 후보는459회·59회·14회/715경주였지만 적중 개선 구간이0을 포함하므로 자동 승격하지 않는다. 기존 HY_R_FORM(454·57·21회)을 비교 기준으로 유지하고, 다음에는 고정 집합에 맞춘 조건부 순서 학습과 발전·반등 변수의 거리·편성 맥락 보강을 검토한다.
