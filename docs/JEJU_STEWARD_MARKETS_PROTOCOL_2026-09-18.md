# 심판·구간 보강 및 승식 확률 진단 실행 계획

2026-09-18. 이번 실행 전 고정한 계획. 결과 cutoff2026-09-12, 기존2025/2026 재사용 개발 평가.

## 정보 보강

- 기존 v1 심판 규칙은 보존하고 v2에서 출발 지연의 직접 주어, 공식 판단 문단의 진술 언급, 명시된 상호 접촉 집단을 보강한다. 불확실한 간접 역할은 자동 확정하지 않는다.
- 기존 감사 표본은 개발 자료다. 새 감사 표본은 기존 표본을 제외하고 문단ID 해시로 자동추출32개·보류/비추출16개를 선택한다. 표본 판독은 모델 성능을 보기 전에 수행한다. 동일 에이전트 검수이지 독립 사람 정답이 아니다.
- 심판 이력과 구간 프로필은 T−2 이전만 사용한다. 심판 미관측/추출불확실을 사건 없음과 구분한다. 현재 선언 부담중량은 이전 실제 중량과 비교한다.
- 두 순위 후보만 학습: 기존108개+STEWARD, 기존108개+PACE_BURDEN. 기존FIT/TUNE/CAL/EVAL·시드17/43·rank_params 사용. 기존 순서모델 유지. 순위4회, 신규 순서학습0회.
- 주 비교는 A/B/C×2후보의6개. 경기일 bootstrap5000, Bonferroni6 동시구간. 각각 별도 채택 판단. 전체 정확순서는 선택 집합 변화 영향도 포함한다. 무조건 결합/운영 채택하지 않는다.

## 승식·3/4위 차이·조합

- 저장된 HY_R_FORM의2026년510경주 확률을 그대로 사용한다. 3/4순위는 실제착순이 아니라 모델 입상확률 순위다.
- 확률 차이 구간은0~2,2~5,5~10,10%p 이상으로 고정. 경계는 하단 포함. 두 말의 실제 입상 차이를 경기일 대응 bootstrap5000으로 집계하고 4구간 동시구간도 제시한다. 표본을 보고 최적 임계값을 고르지 않는다.
- 기존 전체 순서분포에서 단승·연승(7두이하top2)·복승·쌍승·복연승·삼복승·삼쌍승 확률을 합산한다. 주변 입상확률끼리 곱하지 않는다. 동착은 승식 확정/환급 규칙을 구현하지 않은 초기 승식 비교에서 제외하고 제외 수를 보고한다.
- 같은 비용/조합수1·3·6·10에서 삼복승 확률상위K조합과 최고입상확률 축마 포함 상위K조합을 비교한다. 균등 총예산1의 가상 비중만 사용한다. 실제 구매/금액 추천은 하지 않는다.
- 확률 합이 포괄하는 사건과 실제 적중을 대조한다. 연승·복연승처럼 여러 티켓이 동시에 적중할 때 합확률을 적어도 하나 적중할 확률로 쓰지 않는다.
- 모든 승식의 최상위1조합 확률/적중률/확률오차를 보고하되 전용 모델보다 우수하다고 주장하지 않는다. 기존 삼쌍승은 최고집합 안의 최고순서이며 전체순서 중 최고확률과 다를 수 있어 구분한다.
- 로컬 배당 자료의 승식·기간·수집시각·원천을 확인한다. 경기 후 수집한 확정 배당을 경기 전 이용 가능한 가격으로 처리하지 않는다. 사전 가격이 없으면 가격 기반 조합 선택의 수익성은 미검증으로 남긴다.
