# 제주마 Top3 집합·정확 순서 계획 및 데이터셋 생성 보고서

작성일: 2026-09-15 (Asia/Seoul)

## 1. 새 목표와 완료 범위

사용자 목표를 다음 두 가지로 변경했다.

- **상위 3두 집합 완전 적중:** 예측한 세 마리가 실제 상위 세 자리의 말과 모두 일치.
- **상위 3두 순서 완전 적중:** 그 말들의 1착·2착·3착까지 모두 일치.

실제 A–B–C에 예측 A–C–B는 집합 성공/순서 실패, A–B–D는 양쪽 실패다. 두 지표 모두 전체 경주의 사전 예측에서 100%에 최대한 접근하는 것이 목표다.

[현재 계획 r3](JEJU_NATIVE_TOP3_MODEL_V1_PLAN_2026-09-15.md)을 작성하고 실제 dataset builder·상태 생성기·검증기와 Parquet 묶음을 만들었다. **이번에는 모델 학습이나 예측 성능 평가를 하지 않았다.** 데이터셋 행 수나 검증 통과가 적중률 향상 실적을 뜻하지 않는다.

## 3. 만들어진 상태 feature

| 묶음 | 등록 수 | 내용 |
|---|---:|---|
| H0 결과 이력 | 20 | 과거 Elo·거리별 Elo·출전/완주/승리/Top3·최근 결과·휴양·변동성/불확실성 대용값 |
| H0 공통 조건 | 3 | 대상 거리·두수·시대 구분 |
| H1 기록/구간 | 14 | 거리·시대별 과거 기준 residual, 같은 거리의 과거 시간, 유효 관측 수, 초반/후반 구간 |
| H2 공개시각 가정 보조 | 20 | 조교량·출발조교·진료 사건·주행심사·과거 체중·관측 여부/완전성 불명 |
| 합계 | **57** | 원천 그룹별 allow-list로 사용 |

57개 등록항목에는 같은 값을 다른 능력 표시명으로 둔 열과 관측 flag가 포함된다. 서로 독립된 57개 정보 원천이나 학습된 잠재 능력이라는 뜻이 아니다. Elo·수축·변동성은 재현 가능한 기준 feature이며, 최적 파라미터 학습은 다음 단계다.

### 시점과 구간 처리

- 각 출전 전날 18:00 KST를 cutoff로 저장한다. 날짜만 있는 과거 정보는 전전날까지 사용한다.
- 대상 경주의 착순·시간·구간·최종 배당은 `horse_states`에 들어가지 않는다. 결과 원천과 라벨은 별도 table이다.
- S1F 200m와 1110m/1610m 경주의 정확 S1F 210m를 별도 열로 저장한다. 210m를 200m 기록으로 오인하거나 섞지 않는다.
- G1F 200m·G3F 600m는 `closing` 기준 원시 소요시간을 사용한다. 원천의 누적시간과 혼동하지 않는다.
- 말별 구간 요약은 같은 경주 거리에서 관측한 과거 값만 사용한다. 400m는 별도 거리 상태이며 현행 전역 능력에 섞지 않는다.
- API와 Text의 동일 조교/진료를 중복 합산하지 않는다. `observed_any`와 `coverage_unknown`을 구별한다. 사건이 한 번 있었다고 원천 전체가 완전하게 관측됐다고 할 수 없다.

### 남아 있는 제약

- 역사적 실제 공개시각은 미확정이다. H0/H1도 공개 지연 가정을 사용하며 H2는 그 가정을 명시한 보조 arm이다.
- 당시 전날 출전집합을 복원한 자료가 아니라 사후 실제 출발마 조건부 자료다.
- 현재 중량·게이트·기수·장구·당일 체중/주로를 포함한 H3/T-30 입력은 이번 생성본의 완성 범위가 아니다.
- 주로/day variant 보정, 학습된 latent state와 확률 calibration은 아직 수행하지 않았다. 시간 residual은 같은 거리·시대의 과거 기준이며 말별 과거 residual pooling 정책을 registry에 명시했다.
- 주행심사 석차를 합격 여부로 바꾸지 않았다. 공식 합격 의미가 확인되지 않아 합격 feature는 제외했다.
- 이력 시작 이전의 말 경력은 관측되지 않을 수 있다. 첫 관측을 생애 첫 출전으로 단정하지 않는다.

## 4. 정답과 품질 처리

### 동착

상위 3착에 동착이 있는 target 경주는 **39개**다.

- 1착 동착 12개, 2착 동착 10개, 3착 경계 동착 17개.
- 정확 순서는 일반 8,643경주×1개＋동착 39경주×2개 = **8,721개**.
- 집합은 8,665경주×1개＋3착 경계 동착 17경주×2개 = **8,699개**.
- 3착 경계 동착의 공식 3착 이내 말은 네 마리다. 출력 세 마리로 네 마리 전원을 포함했다고 표현하지 않는다.

### 제외와 보존 경고

- 공식 연결 미해결 실제 출발마가 있는 8경주는 전체를 제외했다. 해당 25행만 빼고 경주를 재구성하지 않았다.
- 양수 정상 결과가 없는 135경주, 미출주 690행, 400m target 598경주는 이유를 보존했다.
- Top3 target에는 정상 완주 **84,372행**, DQ **161행**, DNF **50행**을 보존했다. DQ/DNF는 출발마이지만 정상순위/시간 target은 mask다.
- race_id 6867(2023-10-27)에는 하위 착순 공백이 있다. 상위 3착이 명확하므로 Top3 학습에서는 유지하고 전체 순위 target만 mask했다. 원착순을 임의로 재번호 매기지 않았다.
- 400m 598경주 중 25경주는 2018-08-31 이후다. 2018년 자료를 모두 같은 기간으로 처리하지 않고 실제 날짜로 분할했다.

원장의 1,457행은 경주와 행 단위 기록을 합친 수이므로 ‘1,457경주가 제외됐다’고 읽으면 안 된다. `scope/action/reason_code`로 집계해야 한다.

## 5. 검증과 재현

하위 작업 세 개는 사용자 지정 **GPT-5.6 Luna / high**로 진행했고, 주 담당자가 라벨/상태/성능 병목을 검토·보완했다. 별도 감사 작업의 SQL 수량과 정답 조합을 대조했다.

검증 항목:

- 입력 DB hash가 기준값과 일치하고 생성 후에도 변하지 않음.
- 원천 SQL의 기대 key와 entries/labels/states key가 동일함.
- 모든 출발행에 상태가 존재하며 중복과 비유한 feature가 없음.
- 동착 정답 수·순서 제약·집합 투영을 독립 계산으로 검사.
- 대상/미래 결과 변경, 같은 날/전날 결과 제외, 행 순서 불변, DQ/DNF, 400m 분리, H2 실제 source 경로, 200m/210m 구분, fold 경계와 봉인본 덮어쓰기 방지를 테스트.
- 관련 테스트 **17개 통과**, 관련 Ruff 검사 통과.

재현/검증 명령:

```bash
.venv/bin/python scripts/build_jeju_native_top3_dataset.py \
  --output /absolute/new/jeju_native_top3_dataset
.venv/bin/python scripts/verify_jeju_native_top3_dataset.py
.venv/bin/pytest -q tests/test_jeju_native_top3_dataset.py \
  tests/test_jeju_native_top3_states.py tests/test_jeju_native_top3_artifact.py
```

이미 존재하는 출력 디렉터리는 덮어쓰지 않는다. `reproduce/`는 manifest의 git commit과 함께 연구 파일 복원에 사용한다. 원천 DB는 manifest에 기록된 절대 경로와 SHA-256으로 식별한다.
