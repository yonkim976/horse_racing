서울 338개 임시 ID의 33,260행, 부경 경주에 등장한 130개 임시 ID의 20,774행은 각각 보존된 `temporary_id_link.csv`의 ID별 근거 건수와 현 DB 건수가 **모두 일치**한다. 양쪽 경주에 나타난 임시 ID가 40개여서 합집합은 428개다. 각 CSV의 `candidate_evidence.csv` 후보별 건수 합도 ID별 근거 건수와 전부 일치한다. 남은 6개는 제주 전용 ID다.

부경 `manifest.json`에 기록된 보존 CSV·보고서 5개 파일의 SHA-256과 실제 파일 해시가 모두 일치한다. 서울 `sha256_manifest.csv`에 기록된 현재 보존 CSV·README의 해시도 모두 일치한다. 따라서 CSV가 이후 변조된 흔적은 없지만, 이것이 당시 공식 API 원문을 오늘 다시 읽었다는 뜻은 아니다.

## 원문 재검증의 현재 장애

이전 서울·부경 검증 산출물이 참조한 다음 원본은 현재 작업 폴더에 없다.

- `data/research/seoul_backfill_20260915_v1/history.sqlite3` 및 `raw_results/2015`–`2024`
- `data/research/busan_history_20260915/history.sqlite3` 및 `raw/2015`–`2024`

2026-09-29에 설정된 공공데이터 API 인증키의 존재는 확인했다. 그러나 KRA `API4_3/raceResult_3`의 2015년 서울 연간 시험 조회는 응답 대기 중 중단했고, 2015-01-24 하루만 요청한 읽기 전용 조회도 20초 후 `ReadTimeout`으로 실패했다. 따라서 **서울·부경 54,034행의 현재 시점 공식 원문 전수 재인증은 아직 미완료**다. API 응답 문제를 인증 실패나 자료 부재로 단정하지 않는다.

## 후속 작업의 안전 조건

1. 위 공식 원본 DB/JSON을 복원하거나 KRA API가 다시 응답할 때 별도의 새 연구 경로에 재수집한다. 원본 요청 조건·응답 해시·총건수·수집 시각을 남긴다.
2. 현재 출전행을 `(경마장, 경주일, 경주번호, 말 공식 ID, 출전번호)`로 공식 결과 원문과 행 단위 대조한다. 말 이름 충돌은 자동 연결하지 않는다.
3. 임시 ID별 후보가 둘 이상이면 경주행별 공식 번호만 사용한다. 이름 충돌 14개와 제주 4행은 별도 검토한다.
4. 이번에 사용자가 확정한 제주 4행과 방문 조교사 동일인 연결을 제외한 나머지는 운영 DB의 `trainers`·`race_entries`에 자동 반영하지 않는다. 추가 전수 대조와 별도 승인 후 진행한다.
