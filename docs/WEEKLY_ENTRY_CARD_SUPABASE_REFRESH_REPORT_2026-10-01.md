## 4. 재수집 안전 보완

출전표 적재 코드가 기존 출전취소를 해제하지 않도록 `src/horse_racing/services/entry_sheet.py`의 무조건적인 `scratched=False` 대입을 제거했다. 신규 출전행은 기존 기본값 False를 사용하고, 기존 취소는 보존한다. 재출전 승인·취소 철회는 별도 공식 근거로 처리해야 한다.

- 기존 취소된 말과 정상 말을 포함한 재적재 회귀 테스트 추가.
- 출전표·출마표·일일 동기화·경주 보강·경주일 수집 관련 테스트: **36개 통과**.
- 변경한 Python 파일 Ruff 검사 및 `git diff --check`: 통과.
- 보안·Postgres 스킬 기준으로 대상 프로젝트를 확인하고, 원천을 DB 쓰기 전에 검증했다. 비밀값은 출력·문서화하지 않았다. 검증 쿼리는 읽기 전용 트랜잭션으로 실행했다.
