# 제주 네이티브 pre-race 자료원 검토

작성일: 2026-09-16  
범위: 한국마사회(KRA) 공식 경마사이트와 공공데이터포털의 KRA 제공자료를 읽어, 제주 경주의 출마표·기수변경·마체중·주로/날씨·출주번호가 언제 어떤 의미로 이용 가능한지 확인했다. 별도로 요청받은 YouTube 채널은 공개 페이지와 검색 노출 범위를 확인하되, 실제 자막이나 설명이 확인되지 않은 영상의 제목만으로 발언을 추정하지 않았다.

## 먼저 확인할 한계

- 아래 KRA 페이지는 현재 공개된 갱신 안내와 동적 페이지다. 현재 안내가 2025년 과거 경주의 실제 공개·수정 시각을 증명하지 않는다.
- `경주일`, `공지시각`, `페이지 갱신주기`, `파일 생성시각`은 서로 다른 시각이다. 과거 재현에서는 경주별 원문 스냅샷과 공지시각을 함께 보존해야 한다.
- 공공데이터 API가 어떤 필드를 제공한다는 사실은 그 필드가 과거 어느 시점에 공개되었는지, 또는 경주 전에 확정되었는지를 뜻하지 않는다.

## 1. 출마표와 사전 공개

### 출전상세정보 화면의 공개 안내

제주 출전상세정보 화면에는 출전정보·PDF 공개시각이 **매주 수요일15:30**으로 표시된다. 자료갱신주기 표의 수요일16:00 및 RSS의 목요일15:00 안내와 차이가 있다. 어느 안내가 최신인지 확인되지 않았으므로 하나를 확정 규칙으로 채택하지 않고 실제 수집 시각을 저장한다.

근거: [KRA 제주 출전상세정보](https://race.kra.co.kr/chulmainfo/ChulmaDetailInfoList.do?Act=02&Sub=1&meet=2).

### KRA 제주 자료실의 주간 갱신표

KRA 제주 `자료갱신주기` 표는 다음과 같이 적고 있다.

| 자료 | 페이지에 표시된 갱신주기 | 모델링 해석 |
|---|---|---|
| 출전표 | 수 16:00 | 주간 출마표의 기준 시각으로 기록하되, 해당 주 실제 공지·수정 로그가 없는 과거 행에는 단정하지 않는다. |
| 출전마 진료 및 장구현황 | 수 16:00 | 출마표와 같은 수요일 갱신 안내다. |
| 출전마 체중안내 | 경마일 | 사전 수요일 카드 값으로 취급하면 안 된다. |
| 기수변경 / 말취소 / 주로상태 | 경마일 | 경주일 변경·상태를 별도 시계열로 다룬다. |
| 출전등록말 현황 | 토 19:00 | 출마표 확정 시각과 같은 의미로 사용하지 않는다. |

근거: [KRA 제주 자료갱신주기](https://race.kra.co.kr/dbdata/renewDBDate.do?Act=12&Sub=2&meet=2) (표의 `개최정보`, `갱신주기`).

### RSS는 별도 배포 채널이다

KRA RSS 안내에는 제주 `출마정보` 피드가 별도로 있고, RSS의 제주 출마표 갱신 시간은 `매주 목 15:00`으로 표시된다. 같은 KRA 사이트의 자료실 표가 `수 16:00`이라고 표시하는 것과 다르므로 두 값을 하나의 “공개 시각”으로 합치지 않는다.

근거: [KRA 경마정보 RSS 서비스](https://race.kra.co.kr/raceguide/RaceRssServiceIntro.do). 제주 피드 URL은 `http://race.kra.co.kr/down/rsschulma_info_jeju.xml`로 안내된다.

**실험용 규칙:** 출마표를 사용할 때는 `source_channel`(DB 자료실/RSS/API), `observed_at`, `race_date`, `revision_or_notice_at`을 저장한다. “수요일 16시” 또는 “목요일 15시”를 2025년 모든 주에 소급하는 규칙은 사용하지 않는다.

### 공공데이터의 출전표 상세정보

공공데이터포털의 KRA `출전표 상세정보`는 시행예정 경주의 출전마 정보로 설명되며, 경주일·경주번호·`마번(출주번호)`·`마번(고유번호)`·마명·부담중량·레이팅·기수·출발시각·경주조건 및 과거 누적 성적 필드를 나열한다.

근거: [한국마사회 출전표 상세정보](https://www.data.go.kr/dataset/3075638/openapi.do?lang=en).

이 설명만으로는 각 행이 처음 공개된 시각이나 마지막 수정 시각을 알 수 없다. API 응답 수집 시 호출 시각을 보존하고, 경주 전 cutoff를 넘은 값은 별도 표시한다.

## 2. 기수변경·말취소·출전표 변경

KRA 제주 경마속보의 `출전표변경` 화면은 말취소와 기수변경을 별도 표로 제공한다. 표에는 지역, 경주일, 경주번호, 출주번호, 마명, 기존/변경 기수, 부담중량, 사유가 포함되며, 빠른 경마속보 화면에는 `공지시각` 열도 표시된다. 이 자료는 카드 작성 시점의 기수와 경주일 변경을 분리해서 다룰 수 있게 한다.

근거: [KRA 제주 출전표변경](https://race.kra.co.kr/raceFastreport/ChulmapyoChange.do?Act=03&Sub=1&meet=2) 및 [KRA 자료갱신주기](https://race.kra.co.kr/dbdata/renewDBDate.do?Act=12&Sub=2&meet=2).

공공데이터포털도 KRA `기수변경 정보`와 `경주마 출전취소 정보`를 제공 목록으로 안내하지만, API의 기본 최근 조회기간과 필드 목록은 공개 공지의 최초 시각을 대신하지 않는다.

근거: [공공데이터포털 KRA OPEN API 목록](https://www.data.go.kr/bbs/ntc/selectNotice.do?originId=NOTICE_0000000004487).

**누수 방지:** T-2 또는 수요일 카드 모델은 그 cutoff 이후에 공지된 교체 기수·말취소를 사용하지 않는다. 경주일 직전 또는 경주일 변경을 평가에 넣으려면 별도의 “경주일 업데이트” 모델/실험으로 표시한다.

## 3. 마체중

KRA 제주 `금일출전마체중` 화면은 “체중입력은 출발시각 60분전 장안소 집합 후 이루어집니다”라고 안내한다. 따라서 마체중과 증감은 수요일 출마표에 존재하는 고정 사전변수로 간주할 수 없고, 경주일에 가까운 시점의 자료다.

근거: [KRA 제주 금일출전마체중](https://race.kra.co.kr/raceFastreport/ChuljumaWeightWeight.do?Act=03&Sub=4&meet=2).

공공데이터포털의 KRA 출전마 체중 데이터도 경주일·경주번호·출주번호·마명·마체중·마체중 증감 등을 제공하는 것으로 설명한다. 이는 값의 구조를 확인하는 근거이지, 해당 값의 사전 공개 시각을 증명하는 근거는 아니다.

근거: [공공데이터포털 KRA 출전마 체중 데이터](https://www.data.go.kr/dataset/3075629/fileData.do).

**실험용 규칙:** `body_weight_known_at`은 원문에서 확인한 공개 시각 또는 실제 수집 시각으로 기록한다. 장안소 집합이 출발 60분 전이라는 안내만으로 공개 완료 시각을 자동 생성하지 않는다. T-2 사전 예측 표에 이 값을 넣으면 시간 누수가 될 수 있다.

## 4. 주로 상태·함수율·날씨

KRA 자료갱신표는 `기수변경 / 말취소 / 주로상태`를 경마일 자료로 묶는다. 공공데이터포털의 KRA 경주조건별 최고기록 설명은 경주로 상태와 함수율·날씨를 제공하고, 함수율 구간을 다음처럼 표기한다고 설명한다.

| 함수율 | KRA 설명 |
|---:|---|
| 1–5% | 건조 |
| 6–9% | 양호 |
| 10–14% | 다습 |
| 15–19% | 포화 |
| 20% 이상 | 불량 |

또한 `TRACK`·`WEATHER`가 없으면 `-`로 처리한다고 명시한다.

근거: [한국마사회 경주조건별 최고기록](https://www.data.go.kr/dataset/3075644/openapi.do?lang=en).

KRA 경주기록 정보 API는 경주조건(날씨·주로 포함)과 결과의 출주번호·부담중량·기수·마체중 등을 함께 제공한다. 이 자료는 결과/사후 데이터이므로 pre-race 예측에 바로 넣을 때는 공개·관측 시점을 먼저 확인해야 한다.

근거: [한국마사회 경주기록 정보](https://www.data.go.kr/data/15089492/openapi.do).

**보수적 사용:** 경주 전 수집 로그가 없는 함수율·날씨는 결과 API의 사후 필드로 표시한다. 결과 API의 값을 “출발 전 알려진 날씨/주로”라고 바꾸어 부르지 않는다.

## 5. 출주번호와 실제 출발대 칸

공공데이터포털의 예정 출전표 설명은 `마번(출주번호)`과 `마번(고유번호)`를 별도 필드로 구분한다. 따라서 모델 입력의 출주번호는 우선 “공개된 출주번호”로 이름 붙이고, 고유 말 ID와 혼동하지 않는다.

근거: [한국마사회 출전표 상세정보](https://www.data.go.kr/dataset/3075638/openapi.do?lang=en).

KRA 시행계획/출발 운영 자료는 `출발번호 추첨`을 컴퓨터 무작위 추첨으로 설명하고, 출발 운영지침은 출발대 칸 번호판, 칸 변경, 말취소 전후의 칸 이동을 별도 운영 절차로 다룬다.

근거: [KRA 2026 제주 경마시행계획 PDF](https://race.kra.co.kr/down/raceplan2026_jeju.pdf) 및 [KRA 출발운영지침 PDF](https://race.kra.co.kr/down/starters_Instructions_2024.pdf).

이 자료만으로 공개된 출주번호가 항상 물리적 출발대 칸과 1:1로 동일하다고 결론 내리지 않는다. 물리적 게이트를 feature로 사용하려면 해당 경주의 공식 출발대 배치/변경 기록을 별도로 수집해야 한다.

## 6. 기수·말·기본정보의 갱신

KRA 제주 자료갱신표는 경주마·기수·조교사·마주 기본정보를 `해당주 마지막 경주일 19:00 / 수 17:00`로 안내한다. 이 값은 기본정보 페이지의 갱신 안내이고, 특정 경주 출마표의 공지 시각이나 기수변경 공지시각과 동일하지 않다.

근거: [KRA 제주 자료갱신주기](https://race.kra.co.kr/dbdata/renewDBDate.do?Act=12&Sub=2&meet=2).

## 7. YouTube 채널 검토

요청 채널: [대기만성- YouTube](https://www.youtube.com/@%EB%8C%80%EA%B8%B0%EB%A7%8C%EC%84%B1-)

2026-09-16 브라우저에서 요청 주소를 직접 열었으나 YouTube의404 페이지로 연결됐다. 사이트 검색에는 ‘그린트리(@대기만성-q4w)’라는 후보가 나왔지만 같은 채널인지 사용자 확인이 필요하다. 실제 내용을 확인하지 못했으므로 영상 제목만으로 편성·선행/추입·성장·마체중·주로에 관한 발언이나 가설을 만들지 않았다. 자막(또는 영상 설명의 실제 텍스트)이 확보되면 영상 URL, 게시시각, 발언 시각, 발언 원문을 별도 표로 기록한 뒤 연구 가설로만 연결해야 한다.

## 8. 데이터 수집·모델 cutoff 권고

다음 필드를 모든 pre-race 자료에 추가한다.

```text
source_url
source_channel              # KRA DB / KRA RSS / data.go.kr API / notice
race_date
observed_at                 # 우리 수집기가 본 시각
published_or_notice_at      # 원문에 실제 표시된 경우만
known_at                    # 모델이 사용할 수 있다고 선언한 cutoff
revision_or_correction_at   # 변경/정정이 확인된 경우
field_availability_class    # scheduled / race_day / post_race / unknown
historical_timestamp_evidence  # exact / page-policy-only / none
```

권장 분리:

1. **T-2 사전 카드:** 출마표, 출전 예정 기수, 부담중량, 레이팅, 공개된 기본정보만 사용하며 각 값의 `known_at`을 기록한다.
2. **경주일 업데이트:** 기수변경·말취소·주로상태·날씨·마체중을 별도 시계열로 수집한다. 마체중은 KRA 안내상 출발 60분 전 장안소 집합 후 입력되며 실제 공개·관측 시각을 별도로 확인한다.
3. **사후 결과:** 착순, 최종 마체중, 함수율·날씨·주로 결과 필드는 결과 API로 보존하되 pre-race feature와 섞지 않는다.
4. **2025 replay:** 현재 KRA 갱신 규칙만으로 2025년의 정확한 공개 시각을 복원하지 않는다. 원문 아카이브나 수집 로그가 없는 행은 `historical_timestamp_evidence=none`으로 남긴다.

## 결론

공식 자료는 출마표, 경주일 변경, 경주일 마체중, 결과의 주로·날씨를 서로 다른 자료 계층으로 구분한다. 따라서 모델에는 “모든 제주 feature가 수요일에 공개됐다”는 단일 가정을 넣지 말고, 필드별 시점과 revision을 보존해야 한다. 현재 페이지의 수요일/목요일 안내는 현재 배포 경로의 참고자료이며 2025년 과거의 실제 공개 시각을 확정하는 증거가 아니다.
