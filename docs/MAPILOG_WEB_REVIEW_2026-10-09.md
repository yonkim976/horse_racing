# Mapilog 웹 종합 점검 — 2026-10-09

경주 일정·상세·분석·거리별 분석, 말·기수·조교사·마주 목록과 상세, 모바일 화면 및 공개 안내 페이지의 누적 웹 변경을 검토했다. 웹 코드와 필요한 ORM/구간 조회 의존성만 출시한다. 수집기·운영 작업·연구 변경은 제외한다.

## 이번 점검에서 수정한 사항

- 경주 분석은 선택한 탭의 본문만 서버에서 렌더링한다. 숨긴 탭의 대형 테이블과 중복 JSON 전송을 없애고, 탭별로 필요한 데이터만 전달한다. 비교 선택·전개·메모 상태는 기존 브라우저 저장 방식을 유지한다.
- 예측 탭 이외에서는 예측 전용 DB 조회를 생략한다.
- 말·관계자 상세 데이터는 60초 동안 재사용해 탭 전환 시 같은 DB 조회가 반복되지 않게 했다. 응답 캐시에는 지역·등급·산지·기간·탭별 구분을 반영했다.
- 거리별 구간 통계는 경기장·연도·거리·등급 기준으로 120초 동안 재사용한다. 페이지 이동과 함수율 표시 변경은 전체 집계를 다시 실행하지 않는다. 주행심사 집계는 경기장·연도별로 따로 재사용한다.
- `/horses/list`에도 목록 요청 제한을 적용했다. 200페이지 초과, 중복 페이지 인자, 지나치게 긴 검색어는 DB 접근 전에 거절한다.
- 캐시 크기 계산에서 공유 ORM 클래스의 전역 메타데이터를 페이지별 데이터로 잘못 계산하던 문제를 수정했다.
- 비정상적으로 큰 착차가 경주 그래픽의 축과 눈금 수를 무한히 늘리지 못하게 제한했다. 정상 범위의 마신 축척은 유지한다.
- 내부 번호에서 공식 번호로 이동할 때 상세 탭·기간 쿼리를 유지한다. 출전마 비교의 주행심사 버튼도 페이지 전환 후 해당 심사 탭을 바로 열도록 했다.

## 확인 결과

- 작업 트리 관련 Python 테스트 341개 통과(수집 연계 14개 포함). 웹만 분리한 정확한 출시 트리에서도 Python 테스트 327개가 통과했다. 목록·기간별 성적·상세·경주 분석·거리 통계·캐시·요청 제한·공개 안내·마이그레이션을 포함한다.
- 브라우저 그래픽/문자열 렌더링 Node 테스트 8개 통과.
- 웹 Python 코드 Ruff 검사 및 변경 공백 검사 통과. 모든 브라우저 JavaScript 파일 문법 검사 통과.
- 별도 출시 체크아웃에서 웹 모듈 로딩과 빈 SQLite DB의 전체 Alembic 업그레이드(0030까지) 통과.
- 실제 로컬 브라우저에서 분석의 비교→말별 기록 이동, 비교 선택 유지, 전개·메모 탭을 확인했다. 검증 중 추가한 비교 선택은 복원했다.
- 100명이 하나의 IP를 공유하는 SQLite 모의 검증에서 cold/warm 각 700회 이상 요청과 100명 흐름이 완료됐다. 오류·429 없이 DB 세션 동시 진입은 최대 3개 이내였다. 운영 DB 부하 시험은 수행하지 않았다.

## 보안 검토와 범위

공개 읽기 전용 웹 변경 72개 파일의 고정 스냅샷을 검토했다. ORM 파라미터 처리, Jinja 출력 이스케이프/JSON 삽입, 브라우저 DOM 처리, 영상 링크, 요청 인자 제한, 캐시 구분, 원본 서버·프록시 경계와 DB 동시 진입 제한을 확인했다. 확인된 후보 3건은 입력 상한 및 성능 보강으로 수정했으며, 공개 경로에서 악용 가능한 보안 취약점으로 확정할 증거는 없었다. 이는 취약점 부재 보증이 아니다.

Codex Security 검토 ID: `82aec250-9c2e-45a7-9b60-7395dd3a78ee`. 정식 검토 대상은 수정 전 고정 스냅샷이며, 후속 수정은 회귀 테스트와 별도 출시 트리 검증으로 확인한다. 보호된 보안 분석 기능은 계정 권한 제한이 있어 일부 결과 표시가 제한될 수 있다.

운영 DB의 실효 권한/RLS, statement timeout, 실제 배포 인스턴스 수 및 최초 전체 역사 집계 시간은 이번 로컬 점검에서 독립 검증하지 않았다. 캐시와 동시 진입 제한은 프로세스 단위이며 전체 배포의 합산 제한은 아니다. 거리별 전체 역사 통계는 캐시가 비어 있으면 데이터량에 비례한 최초 계산이 필요하다. 자료량이 더 커지면 운영 측정에 따라 사전 집계 또는 DB statement timeout 설정을 별도로 검토해야 한다.

운영 DB에 이번 점검으로 데이터를 쓰거나 마이그레이션을 실행하지 않았다. 웹 기능에 이미 필요한 스키마의 마이그레이션 소스만 출시 범위에 포함한다.
