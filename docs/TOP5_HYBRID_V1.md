# Top5 장기·최근 하이브리드 V1

상태: **연구용 challenger — 운영 모델 미교체, test 미평가**

## 목적

2016년 이후 장기 공통정보와 2025년 이후 상세정보를 함께 사용해 말별 정확한
1~5위 확률과 누적 Top1~Top5 확률을 만든다.

## 구성

- 장기 Top5: `racefit_v3_lifecycle_history/day_before_18`, 2016년 이후 공통 feature 131개
- 최근 Top5: `racefit_v5_sand_rich_v2_matched/start_minus_30m`, 2025년 이후 V5 feature 177개
- 두 모델 모두 LambdaRank relevance `5,4,3,2,1,0`과 full Top5 Plackett–Luce 보정을 사용
- 고정 50:50 확률 평균. Top1~Top5에 같은 비율을 사용해 누적확률과 정확한 순위확률의
  일관성을 보존한다.
- 검증 기간: 2026-03-01~2026-05-31, 669경주. 2026-06-01 이후 test는 평가하지 않았다.

최근 단독 대비 50:50 하이브리드의 win log loss 개선은 0.00081이다. 경주 단위 bootstrap

후보 5두 포함은 +0.90%p였고 95% 구간은 -0.90~+2.69%p였다. 두 차이 모두 아직 0을
포함한다.

valid를 보고 고른 값이므로 향후 신규 미래구간에서만 재확인한다.

## 확률 계약

앙상블은 `prob_win`, `prob_top2` ... `prob_top5`와 `prob_rank1` ... `prob_rank5`를 함께
출력한다. 각 경주에서 정확한 순위별 확률 합은 1이며, 누적확률은 말별로 단조 증가한다.
Top1~Top5에 서로 다른 member 비중을 주면 이 계약이 깨질 수 있어 코드에서 금지한다.

## 남은 범위

이 V1은 장기·최근 정보의 결합과 Top5 확률 출력을 검증한 단계다. 착차를 직접 반영하는
soft target, 접전군 분류, 일반 심판보고서의 전개 불리, 다음 경주 상승 기대점수는 아직
포함하지 않았다. 해당 기능은 V2 실험으로 분리한다.

후속 착차 성능 보조모델 결과는 [TOP5_MARGIN_V2.md](TOP5_MARGIN_V2.md)에 정리했다.
