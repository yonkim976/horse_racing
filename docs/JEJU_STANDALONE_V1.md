# 제주마 단독 모델 V1

상태: **제주 전용 challenger — valid 평가 완료, test 미평가**

## 목적과 범위

- 학습·추론 대상 경마장: 제주(`meet_code=2`)만 허용
- 한라마: 운영 DB에서 제거된 뒤 원천 feature를 전부 다시 계산
- 최근 상세형: 2025-01-03~2026-09-05, 11,637행 / 1,203경주
- 장기 공통형: 2016-01-08~2026-09-05, 62,301행 / 6,281경주
- 검증 구간: 2026-03-01~2026-05-31, 1,701두 / 179경주
- 2026-06-01 이후 결과는 미사용 test로 유지

두 모델 모두 1~5착 LambdaRank, full Top5 Plackett–Luce 보정, 착차 성능 보조축을
사용한다. 최종 V1은 최근 상세형 75%, 장기 공통형 25%의 동일 순위확률 평균이다.

## 사용 판단

- 순위분포와 후보 3~5두 조합이 목적이면 제주 V1을 우선 후보로 사용한다.
- 단승 Top1 한 마리 적중이 목적이면 기존 통합 V2가 valid에서는 더 높았다.
- valid가 179경주뿐이므로 차이는 확정적이지 않다. 운영 champion 교체는 미사용 미래
  구간을 한 번 평가한 뒤 결정한다.
