# 2015년 이전 경주성적표 원천 확인 (2026-09-14)

> 후속 확인에서 더 오래된 공식 경주결과 화면과 2000년 이후 공식 API 결과를 찾았다. 이 문서는 **Text 경마성적표(`dacom11`) 원천만** 조사한 초기 기록이다. 현재 확인 범위와 원천별 누락은 [후속 가용성 조사](PRE2015_RACE_RESULT_AVAILABILITY_2026-09-14.md)를 참고한다.

현재 `races` DB가 2015-01-02부터 시작하는 것은 원천의 부재를 뜻하지 않는다. 한국마사회 Text 자료실의 `dacom11`(경마성적표) 목록에서 세 경마장의 마지막 페이지를 확인하고, 각 경마장의 가장 오래된 날짜가 적힌 파일을 실제로 내려받아 본문 제목을 확인했다. 세 요청 모두 HTTP 200이며 내용이 있는 CP949 원문이었다.

공식 경마성적표 목록의 마지막 페이지는 각각 서울 218, 제주 215, 부산경남 192페이지였다. 제주 마지막 페이지에는 날짜 없는 디렉터리 링크 한 개가 함께 있어 파일로 취급하지 않았다. [서울 Text 자료실](https://race.kra.co.kr/dbdata/textData.do?Act=12&Sub=1&meet=1), [제주](https://race.kra.co.kr/dbdata/textData.do?Act=12&Sub=1&meet=2), [부산경남](https://race.kra.co.kr/dbdata/textData.do?Act=12&Sub=1&meet=3)에서 `경마성적표` 유형을 조회했다.

이번 확인은 **2015년 이전 결과 원문이 존재하고 다운로드된다는 양성 표본**이다. 2003년 이전의 결과가 다른 공식 API·자료실에 있는지, 2003–2014년 모든 경주의 성적표가 빠짐없이 있는지, 과거 서식을 현행 파서로 모두 읽을 수 있는지는 아직 확인하지 않았다. 해당 기간을 현재 DB나 학습 데이터셋에 적재하지 않았고, 모델·운영 경로도 변경하지 않았다.
