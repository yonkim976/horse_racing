## 최소 계약

1. **관측 원문과 시간.** 원문 바이트 hash, source 식별자, 요청/수신/영속화 시각, parser 버전, 파싱 상태를 기록한다. 공개·적용 시각은 원문에 있으면 별도 보존하고 추정하여 채우지 않는다. 정보 사용시각은 수신/파싱/영속화까지 완료된 보수적인 시각으로 정의한다. 오래된 원문을 지금 읽은 일을 과거 관측으로 기록할 수 없어야 한다. 실제 시각은 저장기가 부여하고 합성 시계 주입은 테스트 경로에서만 허용한다.
2. **정정과 중복.** 동일 내용의 재관측도 관측 이벤트로 남길 수 있되 바이트 저장은 hash로 중복 제거한다. 정정 내용은 새 버전으로 추가한다. 늦게 도착한 과거 effective 이벤트가 이미 봉인된 snapshot을 바꾸지 못한다. 단순 hash가 악의적인 전체 기록 재작성이나 외부 공인시각까지 방지한다고 주장하지 않는다.
3. **사전 field 봉인.** result 테이블 없이 관측 이벤트만으로 E1 `SealedFieldManifest`를 만든다. T−30은 관측 당시 일정 버전과 함께 기록한다. 일정 지연/변경을 이유로 기존 cutoff를 소급 이동하지 않는다. 불완전 출전표·모호한 취소·누락된 일정은 승인 실패로 남기고 임의 복구하지 않는다. 관측 명단의 완전성을 검증할 독립 키/원문 근거를 명시한다.
4. **snapshot과 prediction 연결.** 원문→파싱 이벤트→field manifest→feature snapshot→prediction의 hash 연결을 유지한다. feature별 관측·계산 계약과 결과 모집단을 기록한다. key 누락/추가/중복 또는 시각·feature availability 미확인 상태에서는 prospective 예측 적격을 주지 않는다. 현재 A 연구 모델을 F_t 모델로 자동 간주하지 않는다. 이번에는 합성 확률만 사용하며 실제 136개 feature 전체를 다시 구현하지 않는다.
5. **격리된 shadow 기록.** 기존 공개 원장의 경주 중복 발행 규칙을 변경하지 않는다. 독립 shadow namespace에 `(experiment_version, model_version, race_key, cutoff_policy, sealed_field_hash)`와 snapshot·모델 hash를 연결한다. 재시도는 같은 내용이면 idempotent, 같은 식별자에 다른 내용이면 거부한다. 결과/정정은 별도 append 이벤트로만 표현하고 입력·예측을 덮어쓰지 않는다. 쓰기 실패·동시 중복 요청에도 부분 기록을 승인 완료로 오인하지 않도록 최소 원자성 계약을 둔다.
6. **취소와 평가 한계.** 봉인 이후 DNS·DNF·실격·동착·경주무효가 발생해도 과거 field·예측은 불변이다. DNS 사건 정의가 미확정이면 평가 보류 상태를 명시한다. 사후 A로 자동 축소하거나 재정규화한 값을 원래 실전 예측으로 표시하지 않는다. 정산·배팅 정책 구현은 이번 범위에서 제외한다.

배당 스트림은 이번 최소 구현의 필수 기능이 아니다. 기존 확정배당을 당시 시장 관측으로 재명명하지 않는다. 실제 이용 가능한 시장 원천과 관측주기는 별도 활성화 계획의 미검증 항목으로 남긴다.
