# KRA API 사용 목록과 제공 데이터

확인 기준: 2026-09-30. `data/horse_racing.sqlite3`의 `source_documents.endpoint`, 현재 수집기·운영 명령, 별도 조교사 동기화 스크립트, 로그인된 공공데이터포털의 [활용신청 현황](https://www.data.go.kr/iim/api/selectAcountList.do) 5쪽을 대조했다. 인증키는 기록하지 않았다. 이 문서의 **사용 수**는 공공데이터포털의 **활용신청 수**와 다르다.

2026-09-30에 확인한 승인 경마 API **42개 전부의 endpoint·제공 정보·사용 상태**와 이후 추가 신청은 [종합 API 카탈로그](KRA_APPROVED_42_API_CATALOG_2026-09-30.md)를 참고한다. 이 문서는 그중 실제 수집 경로와 장구 증감 저장 방식에 초점을 둔다.

포털 상단 숫자는 **전체 44 / 활용 중·승인 42 / 활용중지 2**다. 앞서 말한 42는 한국마사회 승인 서비스 수이고, 44에는 경마와 무관한 중지 서비스 2건이 포함된다. 이 숫자는 신청 **서비스** 수이고 22는 확인된 **endpoint 경로** 수다. 23건 대조는 서비스명·기능 경로를 기준으로 한 분류이며, 19건은 “현재 주요 수집·동기화 경로와 연결이 확인되지 않음”이지 “한 번도 호출하지 않음”이 아니다.

## OpenAPI 외 원천과 목록 해석

- **KRA 경마정보 Text 자료실** `/dbdata/fileDownLoad.do`: 과거 대량 파일 원천. `dacom01`, `dacom11`, `dacom12`, `dacom13`, `dacom23`, `dacom55`, `dacom71`, `dacom72`, `db1`~`db5`, `db7` 등으로 작업 유형이 달라도 한 다운로드 endpoint다. `dacom11_parse`는 내부 처리 라벨이므로 별도 외부 API로 세지 않는다.
- `/API6_1/raceDetailSectionRecord_1`처럼 코드 또는 [기존 소스 카탈로그](DATA_SOURCE_CATALOG.md)에 정의·검토만 된 API는 수집 이력이 확인되지 않으면 위 22개에 포함하지 않는다. 서비스 페이지에 접근 가능하다는 것과 운영에서 사용 중이라는 것은 다르다.
- 중앙 장부의 21개는 **기록된 수집 실행 범위**다. 정기 동기화, 수동 백필, 연구용 일회성 수집이 섞여 있으므로 “현재 자동으로 주기 호출하는 API 21개”라는 의미가 아니다. 각 endpoint의 실행 주기와 소유 명령은 `src/horse_racing/cli.py`, `scripts/` 및 스케줄 설정으로 별도 확인해야 한다.
- 조회 재현 시에는 `source_documents`의 endpoint, operation, 조회 시각, 원본 경로와 해시를 함께 본다. 인증키 또는 완전한 요청 URL을 문서나 로그에 복사하지 않는다.
