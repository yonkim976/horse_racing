# 기수의 직접 조교 참여와 실제 경주 성적

2026-10-17 연구. **기수가 조교에 참여했다는 사실만으로 기록·착순·입상률이 좋아진다는 안정적인 차이는 확인하지 못했다.** 이번 경주 기수가 직접 조교한 말은 다른 기수만 조교한 말보다 원시 성적이 좋았지만, 말의 능력·편성·최근 수행·기수/조교사·조교량을 고려하면 그 차이는 불확실했다. 무효임을 증명한 결과나 고정 가점의 근거로 해석하지 않는다.

## 무엇을 비교했나

1. **기수 참여 대 다른 종류만 관측:** 확인된 기수 원행이 있는 창과, 조교자 종류가 모두 확인됐고 기수는 없는 창을 비교했다.
2. **이번 경주 기수 참여 대 다른 기수만 참여:** 기수 참여 창 안에서 현재 경주 기수의 공식 ID가 조교의 공식 사번과 정확히 일치하는지를 비교했다.

주창은 **경주일−14일부터 경주일−2일까지**, 직전 실제 출전이 있으면 **그 출전일 이후**다. 당일·전날 조교와 직전 경주일 이전 조교를 포함하지 않았다. ‘14일’은 이 달력 경계 이름으로, T−1/당일을 제외한 최대13개 날짜다. 7/28일도 같은 경계 규칙으로 확인했다. 사건일은 공개시각의 증명이 아니며 과거 사전 가용성은 미확정이다.

일별조교만 사용하고 출발조교·출발심사와 합산하지 않았다. 기수후보생·주로조교·조교사 등을 기수로 바꾸지 않았다. 미분류 한 행이라도 포함된 창은 주비교에서 제외하고, 조교 원행이 없는 창도 미조교로 간주하지 않았다. 조교자의 종류는 확인됐더라도 실제 모든 훈련을 보유 자료가 빠짐없이 담았다는 뜻은 아니다. 원행 수와 관측 날짜 수를 구분하고 실제 시행 횟수·강도로 단정하지 않았다.

자료는 기존 불변 정상 완주 완전편성 **52,155출전·5,206경주·2,813두, 2017-01-13~2026-09-19**다. 현재8거리 800/900/1000/1110/1200/1300/1400/1610m, 원천7~13두이며 400m와 제외말3005648의 결과는 편입하지 않았다. 2026년은 부분연도다. 최신 로컬 DB의 `daily_training_rider_types_analysis_2026`에서 해당 말 ID의 2016-12-16~2026-09-17 조교641,228행을 읽기 전용으로 추출했다. 최신 DB에는 이후 조교도 있지만 이번 고정 경주 상한 밖 기록은 사용하지 않았다. 이전52,155출전 결과 코호트를 최신 DB 갱신만으로 확대하지 않았다.

기수 종류 전체를 합치면 전체21,414출전의 Top3는29.35%다. 기수가 참여하지 않은 것으로 관측된 그룹31.16%보다 단순 성적이 더 좋은 것은 아니다. 반면 기수 참여 그룹 안에서는 이번 경주 기수가 직접 조교한 경우가 원시 Top3 약5.26%p 높다. 서로 다른 두 비교를 혼동하지 않는다. 이번기수 참여 그룹은 과거 수행과 기수 배정도 달라 원시 차이를 직접 조교의 효과로 볼 수 없다. 2026년 다른 기수만 참여한77출전은70두이고, 이번기수 참여1,140출전은449두다. 같은 말거리에서 양쪽 상태가 관측된 교차말은36두이나 음성집단 최소100출전 기준을 충족하지 못해 **2026년 두 번째 조정 비교는 보류**했다. 원시28.51% 대16.88%를 조정 후에도 남는 최근 우세로 주장하지 않는다.

## 능력·편성·최근 수행을 고려하면

각 비교 안에서 경주 효과와 말×정확거리 효과를 함께 제거했다. 전자는 공통 편성·주로·계절·등급·페이스 수준을, 후자는 말의 거리별 고정 능력을 고려한다. T−2까지의 과거 착순·상대기록·이력수·직전성적, 실제 관측 출전간격, 현재 부담·체중·게이트·기수·조교사와 조교 관측 일수·시간을 함께 고려했다. 기수 ID 효과를 고려해 좋은 기수의 배정 차이를 일부 조정했지만, 시간에 따라 변하는 건강·승부 선택·말과 기수의 친숙도까지 전부 제거한 인과 비교는 아니다. 조교량을 제외한 비교도 별도 보존했다.

기록 목표는 `해당 말 기록−같은 경주 평균 기록`인 상대기록이다. 환산 착순은 `9×[1−(착순−1)/(출전두수−1)]`로 출전두수 차이를 맞춘10두 기준이다. 아래 모든 목표는 **양수가 더 좋음**, 구간은 날짜 군집95%다. 말 군집95%는 별도로 계산했으며 두 군집을 동시에 적용한 구간으로 부르지 않는다.

|---|---|---:|---:|---:|
| 전체 | 기수 참여 대 다른 종류만 | −0.008 (−0.048~+0.033) | +0.018 (−0.067~+0.102) | +0.15 (−1.33~+1.62) |

전체 ‘이번기수’의 원시 Top3 차이+5.26%p는 조정 비교에서+0.54%p로 줄고 불확실해졌다. 전체 기록의 말 군집 구간도 기수 참여−0.054~+0.039초,이번기수−0.046~+0.125초로0을 포함한다. 주지원은 각집단100출전·30두·20경주일 및 교차말20두·식별·잔여자유도>20이다. 전체/최근 두 기간×두비교×3목표의 계획18개 중2026 이번기수3개를 보류하여 **지원15검정**을 BH로 보정했고, 지원되는 방향은0개다. 최근 두 기간 반복 지원도0개다. 보류를 효과0으로 표시하지 않았다. ## 창·조교량·기존 기대기록 확인

7일·28일 창, 조교량 통제 제외, 기수 참여가 확인된 양성창만 미분류 혼재까지 넓히는 사전 민감도에서도 지원되는 기록 비교의 날짜 구간은 모두0을 포함했다. 양성 확대는 음성의 완전확인 조건을 유지하므로 확인 정도가 비대칭인 별도 비교다. 이를 전체 미분류의 종류를 복원한 분석으로 해석하지 않는다. 2026 이번기수 비교는 모든 창·민감도에서 음성 표본이 부족해 보류했다.

기존 연도 고정H1의 기대초과 기록은2024~2025 기수 참여+0.157초(날짜95%−0.109~+0.422),이번기수−0.060초(−0.531~+0.411),2026 기수 참여−0.176초(−0.672~+0.320)였다. 계획4검정 중2026 이번기수1개를 보류해 지원3검정을 별도BH 보정했고 모두 불확실했다. 기존 H1은 과거 수행·능력·편성 기대를 포함한다. 이번 분석은 H1을 새로 학습하거나 조교 참여 입력을 더해 미래 예측 성능이 개선되는지 비교한 실험은 아니다.

## 검증과 원천 상태

[독립 재계산](verification02/verification.json)은 메모리 SQL의 별도 창 조회로156,465출전×창의 조교 종류·사번·미분류·시간 집계와1,033,484원행ID 연결을 검산했다. T−1/미래 조교를 변경·추가한50개 검사는 피처가 동일했다. 원시 표·구간과25적합그룹의78목표 계수·공분산·대비·주BH15/H1 BH3검정을 별도 합동 고정효과 행렬로 재계산했다. 2026 이번기수의5개 모형 그룹 보류도 확인했다. 입력 해시·바이트와 DB SHA는 추출 전후·검산 후 동일하다. [원천 및 시점 계약](input01/source_manifest.json), [출전별 피처](input01/features.csv), [원행 연결](input01/lineage.csv), [설계](PLAN.md).

현재 조교 원천에는10월17일 별도 갱신이 적용돼 있다. [현재 원천 근거](verification02/current_source_context.json)는 최신 종류 조회의 원천 변경 차단 전수검사와 DB SHA 일치를 확인한다. 해당 DB 갱신 보고서는 별도 manifest에 파일크기를24,576바이트 작게 기록한 메타데이터 한 항목 때문에 전체통과 상태가 아니다. 이번 추출은 실제 파일크기와SHA를 직접 기록했으며 이전 보고서를 수정하거나 전체통과로 바꾸지 않았다. 최초 검증이 전체통과를 요구해 중단한 [실패 원장](verification01/FAILED_ATTEMPT.md)도 남기고 두 번째 검증에서 해당 메타데이터 차이만 따로 확인했다. 효과·표본·통계 기준은 변경하지 않았다.

원시 거리별 표와 확인 정도별 표는 후향 기술통계다. 주조정은 전체거리 통합 비교이며 거리별 인과효과·거리별 고정초 보정은 산출하지 않았다. 정상 완주·완전편성과 종류 완전확인 조건, 조교자 배정의 비무작위성, 조교 강도·속도·건강·게시시각 미관측이 남는다. 과거 같은 기간 반복 사용을 독립 새 미래검증이라고 부르지 않는다.

추가로 [모든 기술통계 표 검산](report_verification01/verification.json)에서112개 셀·1,093개 군집 구간 및 거리 합계·확인 정도별 모집단 합계가 일치했다. [저장 전 원천 변경 감사](PUBLICATION_PROVENANCE.md)에는 별도 DB 갱신과 문서함 색인의 이미 발생한 차이를 구분해 기록했다.

실행 순서는 [자료 추출](data.py) → [집계·효과](analysis.py) → [독립 검산](verify.py) → [기술통계 검산·채택 상태](verify_tables.py) → [결론 저장](publish.py)다. 산출 경로가 존재하면 중단하므로 재현은 새 경로로 수행한다. 기존 날짜별 연구를 덮어쓰지 않는다. [채택 상태](decision.json)에 따라 직접 조교 가점·고정 기록 보정·운영 반영은 채택하지 않았다. 이번 제한된 후속 연구와 별개로 기수 전체·각질의 추후 재개 상태는 유지했다.
