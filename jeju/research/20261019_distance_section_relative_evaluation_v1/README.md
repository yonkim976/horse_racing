# 거리별 구간 상대기록 후보의 고정 점수 평가

## 결론

거리별 구간 상대기록 10개를 추가한 `F1_STYLE6_DISTANCE_SECTION_RELATIVE10`은 사전 지정 주 평가 gate를 통과하지 못했다. 네 거리를 합친 주 평가에서 log loss와 Brier 점추정치는 기준선보다 조금 낮았지만, 두 지표의 paired date-bootstrap 95% 신뢰구간 상한은 모두 0보다 높았다. 따라서 기존 `F1_STYLE6`을 유지하고 이번 단일 후보는 보류한다. 결과를 확인한 뒤 추가 튜닝이나 재학습은 하지 않았다.

## 주 평가

주 표본은 2024년부터 2026년 9월 19일까지 900m·1000m·1110m·1200m에 해당하는 14,714출전·1,503경주다. 말별 Top3 이진 log loss와 Brier를 먼저 경주 안에서 평균하고 경주에 동일 가중을 두었다. 차이는 후보−기준선이며, 고정된 269일 일정에서 날짜 단위 paired bootstrap 2,000회를 사용했다.

| 지표 | 기준선 | 후보 | 차이 | paired 95% CI |
|---|---:|---:|---:|---:|
| Top3 log loss | 0.568927 | 0.568822 | −0.000105 | [−0.001177, +0.000886] |
| Top3 Brier | 0.192643 | 0.192607 | −0.000036 | [−0.000504, +0.000398] |

두 점차이는 모두 음수지만, 적어도 한 지표에서 95% 구간 상한이 0보다 낮아야 하는 조건을 만족하지 않아 gate는 실패했다. 주 평가 수치는 root의 독립 검산에서 모델 점수와 예측 확률, 경주 지표, 조합 확률 및 양 지표의 4,000개 bootstrap 값을 오차 없이 재현했다.

## 선택·조합 보조지표

주 표본에서 최고 점수 말의 Top3 적중률은 기준선 57.29%, 후보 57.62%(차이 +0.33%p; 95% CI [−1.15, +1.92]%p)였다. Top5가 실제 상위 3두를 포착한 비율은 69.06%→69.48%(+0.42%p; [−0.22, +1.07]%p), Top5 안에 실제 상위 3두가 모두 포함된 비율은 29.21%→29.94%(+0.73%p; [−0.53, +2.01]%p)였다. 모든 구간이 0을 포함한다. Trio NLL 차이는 −0.000894(95% CI [−0.010173, +0.007573])였다.

기존 `STYLE.OLD.evaluate` 규칙으로 만든 경주당 canonical 최대 6개 3두 조합 중 주 표본 적중은 기준선 346/1,503경주(23.02%), 후보 350/1,503경주(23.29%)였다. 두 모델이 모두 적중한 경주는 302개, 후보만 적중한 경주는 48개, 기준선만 적중한 경주는 44개였다. 추천 순위까지 여섯 조합이 전부 일치한 경주는 131개였고, 총 9,018개 티켓 슬롯 가운데 3,896개가 동일했다. 조합 적중률 차이는 +0.27%p(95% CI [−1.01, +1.60]%p)로 불확실하다. 후보의 여섯 조합 확률 질량은 22.54%에서 23.33%로 높아졌지만, 이 변화만으로 적중 성능 개선을 주장하지 않는다.

전체 1,779경주 보조 코호트에서 log loss는 0.568159→0.568039(차이 −0.000120; 95% CI [−0.001013, +0.000748]), Brier는 0.192256→0.192224(−0.000032; [−0.000432, +0.000347])였다. 대상 외 거리 276경주의 차이는 log loss −0.000201([−0.001588, +0.001123]), Brier −0.000011([−0.000595, +0.000535])였다. 전체 코호트의 Top1 적중률은 57.50%→57.73%, Top5 capture는 69.10%→69.50%, Top5 all3는 29.17%→29.79%였다.

## 범위와 한계

기준선은 저장된 30개 `F1_STYLE6` 입력과 2024·2025·2026 모델을 사용했다. 후보는 같은 30개 입력에 거리별 구간 상대기록 평균·지원량 10개를 더한 40개 입력과 세 저장 모델을 사용했다. 후보 학습 완료 영수증에는 세 모델, 여섯 학습 호출, 세 저장 보정 온도가 기록되어 있다. 평가기는 동결된 평가 원점수·피처·저장 온도만 읽었으며, 자체 모델 예측·재학습·보정 호출은 각각 0회였다. 평가기는 DB를 열거나 운영 모델·registry를 변경하지 않았다.

평가 기간은 이전 실험에서 사용한 2024년부터 2026년 9월 19일까지의 날짜다. 날짜 bootstrap 일정도 기존 269일 일정 2,000회를 재사용했다. 2026년은 부분 연도이고, 신규 기간·전향 운용 결과를 포함하지 않는다. 원천 경주 날짜는 자료 공개 시각을 증명하지 않으며, 각 과거 기준값의 T−2 cutoff도 실제 당시 예측자가 해당 자료를 볼 수 있었음을 보장하지 않는다. 따라서 이 결과는 해당 역사적 표본에 대한 단일 고정 비교로 한정한다.
