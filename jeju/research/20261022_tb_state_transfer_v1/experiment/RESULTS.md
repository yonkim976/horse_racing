# 실행 결과

2026-10-22에 한 번의 승인된 적합·평가 실행을 마쳤다. 비교는 이전 F1_STYLE6의 raw-score/연간 PL 기준 R, F1_STYLE6 30개 입력만 쓴 새 LightGBM 기준 C, 그리고 같은 30개에 더러브렛에서 이식한 순위·거리 상태 10개를 더한 S로 구성했다. C와 S는 2024·2025·2026 순차 vintage에서 각각 3개 모델을 저장했고, 총 12회 학습과 6회 PL 온도 보정을 했다. 보정 온도는 C에서 1.248380, 1.285645, 1.123975, S에서 1.283936, 1.323028, 1.165540이었다.

공통 평가는 2024~2026-09-19 재사용 개발기간 1,779경주, 17,412두, 269일이다. 연승은 발매 시작 시 출전두수 불명인 실제 5~7두 경주 36건을 격리해 1,743경주를 썼고, 나머지 승식은 1,779경주다. 아래는 경주별 평균 proper loss 차이이며 음수는 왼쪽 arm이 개선된 값이다.

사전 정의한 S−C와 S−R 확률 게이트를 모두 통과했다. S−C의 TRI ΔNLL은 −0.042750이고 날짜 paired bootstrap 95% 구간은 [−0.062419, −0.023661]이다. S−R은 −0.044051, 구간 [−0.063639, −0.024781]이다. 두 비교 모두 TRI Brier와 WIN NLL/Brier 점추정 보호조건도 통과했다. C−R은 기술 비교로만 보고하며 TRI 구간이 0을 포함한다.

WIN 최대확률 말의 Top3 적중은 R 1,023/1,779, C 1,026, S 1,044였다. S는 R 대비 21건, 2.05% 높았지만 10% 목표인 1,126건에는 이르지 못했다. S−R 차이는 2024년 +1, 2025년 +14, 2026년 +6이었다. 거리별 선택 적중 수와 gain/loss는 [`diagnostics/win_axis_year_distance_gain_loss.parquet`](diagnostics/win_axis_year_distance_gain_loss.parquet)에 있다. 1,610m 결과는 9경주뿐이므로 해석하지 않는다.

확률 손실의 개선이 최대확률 한 장의 적중수 증가를 뜻하지는 않는다. R→S의 WIN 선택 적중은 487→481, 삼복 TLA는 107→97, 삼쌍 TRI는 26→25로 줄었다. 감독관의 독립 검산 [RESULT_VERIFICATION.json](../supervisor/RESULT_VERIFICATION.json)과 선택 비교 bootstrap [PAIR_BOOTSTRAP.json](../supervisor/PAIR_BOOTSTRAP.json)은 모두 PASS이며, QNL/QPL 선택 1·3장 hit-any 차이의 날짜 bootstrap 구간은 모두 0을 포함한다.

감독관 독립 재검산은 [RESULT_VERIFICATION.json](../supervisor/RESULT_VERIFICATION.json)에서 PASS다. 이 결과는 별도 full-field 순차 Plackett–Luce 공동분포를 사용한 연구용 확률 비교다. 2024~2026 평가기간을 다시 사용했으므로 독립 미래 검증이 아니며, 적중축도 10% 개선에 도달하지 않았다. 수익률·실제 발매가격 효과는 평가하지 않았다. 운영 모델 변경이나 승격 근거로 사용할 수 없다. 출력과 6개 모델은 `outputs/`와 `models/`에 보존했다. 실행 receipt의 15,970,786 bytes는 post-run diagnostics와 문서 추가 전 중간값이며, 최종 전체 byte 수는 root가 작성하는 `supervisor/FINAL_MANIFEST.json`에 기록한다.
