# 더러브렛 상대능력 상태를 제주마에 이식한 단일 비교

2026-10-22 완료. **사전 확률 기준 통과: 차기 검증 후보 S를 보존한다.** F1_STYLE6은 고정 연구 비교 기준선으로 유지하며, 운영 등록부와 HY_R_FORM은 변경하지 않았다. 적중률 10% 향상과 시장 우위는 입증하지 못했다.

## 확인한 더러브렛 연구와 이번 전이 범위

요청한 새 더러브렛 연구 세션(`01a160a1-4227-7b92-9136-cc205c7d376b`)을 읽고, 완료된 [58C 연구](../../../thoroughbred/research/20261022_dynamic_race_model_v1/README.md)의 설계와 코드를 확인했다. 시작 당시 후속 ablation은 진행 중이었으므로 완료된 58C 파일의 해시를 고정했다. 해당 채팅에 메시지를 보내거나 그 연구의 코드·산출물을 수정하지 않았다.

더러브렛 연구는 상대전적에서 갱신하는 능력·거리 상태, 기록 상태, 초·종반 상태, 미완주 위험을 기존 입력에 추가하고, 같은 입력을 쓴 신경망과 GBM도 비교했다. 이번에는 데이터 정의가 명확하게 대응하는 **상대 순위·거리 상태 10개**만 옮겼다. 제주 거리 중심은 1,100m로 두고, 근사 순위 필터의 prior·쇠퇴·분산·쌍별 업데이트 계수는 TB의 고정값을 사용했다. 기록·초 단위 구간 상태, 위험 상태, 신경망, TB의 집합/순서 확률 연결은 이번 비교에 넣지 않았다. 제주에서는 기존 full-field Plackett–Luce(PL) 확률 연결을 모든 arm에 공통으로 적용했다.

핵심은 단순한 최근 착순 평균을 넘어, **당시 어떤 상대에게 이겼는지와 거리별 능력 상태가 어떻게 달라지는지**를 추적하는 것이다. 말의 마지막 관측일은 마지막 유효 순위 갱신일이며 TB의 모든 관측 출발일과 다르다. state sd는 근사 필터의 공분산 특징으로, 보정된 예측 불확실성은 아니다.

## 결과 전에 고정한 비교

| arm | 말 평가 입력 | 학습 및 확률 |
|---|---|---|
| R | 기존 F1_STYLE6 30개 | 저장된 연도별 raw 점수·기존 연간 PL 온도 재사용 |
| C | 동일 30개 | 최대 800회 GBM; 조기종료 규칙 고정 |
| S | 동일 30개 + 상태 10개 | C와 같은 학습 규칙·파라미터·표본 |

R의 원래 학습 상한은 200회다. C−R로 추가 학습량 효과를 설명하고, 주 비교 S−C로 상태 정보 추가의 효과를 평가했다. 보호 비교는 S−R이다. 연도 Y의 초기학습은 2017..Y−3, 조기종료 검증은 Y−2, 선택한 반복 수로 Y−2까지 재학습, 확률 보정은 Y−1, 평가는 Y다. 범주 어휘는 초기학습에서만 정한다. C/S 각각 2024·2025·2026 최종 모델을 저장했다(6개 모델, 초기+재학습 12회, 새 PL 온도 6개). 추가 seed·후보·결과 후 튜닝은 하지 않았다.

상태는 2010년 이후 정상 완주·완전 착순 과거 7,066경주(69,752행)에서 생성했다. 2010~2016은 warm-up 1,860경주다. supervised cohort는 기존 5,206경주·52,155행을 그대로 썼다. 각 경주 T의 상태에는 **기록된 경주일 ≤ T−2일**만 포함하며, 같은 경주·같은 날짜는 모두 갱신 전 상태로 계산 후 함께 commit한다. 원천 공개 시각과 당시 출전명단 공개시각은 확인되지 않는다.

평가는 반복 사용된 2024~2026-09-19의 1,779경주·17,412두·269일이다. 연승은 개시두수 미확인인 실제 7두 경주 36개를 제외한 1,743경주이며 다른 6승식은 1,779경주다. 모든 arm은 동일 경주·표수·선택 규칙을 쓴다. [공식 사건 정의 및 적용 한계](../20261022_joint_wager_baseline_v1/rules_contract/rules_contract.json)를 재사용했다. 동착·취소·미완주 경주까지 지원한다고 일반화하지 않는다.

## 확률 정확성

자연로그 Log loss와 Brier는 낮을수록 좋다. 단승/복승/쌍승/삼복승/삼쌍승은 상호배타 사건의 경주별 점수, 연승/복연승은 각 경주 모든 표의 binary 점수 평균이다. 마지막에는 경주를 같은 비중으로 평균한다. 서로 다른 승식 간 수치 크기를 비교하지 않는다.

| 승식 | 경주수 | R Log loss | C Log loss | S Log loss | R Brier | C Brier | S Brier |
|---|---:|---:|---:|---:|---:|---:|---:|
| 단승 | 1,779 | 2.055422 | 2.054108 | 2.033763 | 0.841770 | 0.841366 | 0.836038 |
| 연승 | 1,743 | 0.567172 | 0.567045 | 0.562379 | 0.191772 | 0.191713 | 0.189729 |
| 복승 | 1,779 | 3.389129 | 3.387012 | 3.356140 | 0.951256 | 0.951147 | 0.948835 |
| 복연승 | 1,779 | 0.237009 | 0.236973 | 0.235076 | 0.062999 | 0.062994 | 0.062631 |
| 쌍승 | 1,779 | 4.072611 | 4.070420 | 4.038138 | 0.975101 | 0.975052 | 0.973750 |
| 삼복승 | 1,779 | 4.291004 | 4.290157 | 4.250665 | 0.979531 | 0.979528 | 0.977535 |
| 삼쌍승 | 1,779 | 6.045632 | 6.044330 | 6.001580 | 0.996168 | 0.996165 | 0.995770 |

전체 기간에서는 S가 R과 C보다 7승식 모두 두 점수를 개선했다. 모든 연도·승식·지표가 개선된 것은 아니다. 예를 들어 2026 쌍승 Brier의 S−R은 +0.000019다. [연도별 전체 비교](experiment/outputs/pool_year_comparisons.parquet)를 보존했다.

주 기준은 공동 Top3 착순 사건(삼쌍승) Log loss 차이의 날짜 bootstrap 95% 상한 < 0, 같은 승식 Brier 차이 ≤ 0, 단승 Log loss/Brier 차이 ≤ 0이다. S−C와 S−R 모두 통과해야 한다. 단승 보호는 점추정 조건이며 통계적 비열등성 검정은 아니다.

| 비교 | 삼쌍승 ΔLog loss | 날짜 bootstrap 95% 구간 | 판정 |
|---|---:|---:|---|
| S−C (주 비교) | −0.042750 | [−0.062419, −0.023661] | 통과 |
| S−R (기준선 보호) | −0.044051 | [−0.063639, −0.024781] | 통과 |
| C−R (기술 비교) | −0.001302 | [−0.003456, +0.000896] | 개선 기준 미통과 |

동일하게 더 오래 학습한 C보다 S가 개선돼, 이 기간에서는 상태 정보 추가의 기여를 지지한다. 2,000회 paired date bootstrap은 고정된 예측의 표본 변동만 반영하며 학습 불확실성이나 전체 연구의 반복 탐색을 보정하지 않는다. 새 독립 검증기간의 증거는 아니다.

[고정 확률구간별 실제 발생률](experiment/outputs/reliability_bins.parquet)은 7승식×3 arm×전체/3연도×16구간을 보존했다. 이 빈도표는 표 사건 수 가중이고 위 proper loss는 경주 가중이다. 남은 보정 오차도 있다. 예컨대 S 단승 25~50% 구간의 평균 예측은 32.10%, 실제 우승은 37.18%(753 말 사건)다. 이 표의 사건들이 서로 독립이라고 가정하지 않는다.

## 동일 선택 규칙의 적중 성과

축은 최대 단승확률 말의 Top3 여부다. 복승·복연승 3장은 개별확률 상위 3쌍 중 하나 이상 적중한 경주 수다. 같은 예산으로 3장을 선택하며 복연승의 사건 중첩은 전체 Q에서 정확하게 합산한다.

| 보조 선택 지표 | R | C | S | S−R |
|---|---:|---:|---:|---:|
| 축 Top3 | 1,023 / 1,779 (57.50%) | 1,026 (57.67%) | 1,044 (58.68%) | +21회, +1.18%p |
| 복승 상위 3장 중 적중 | 471 (26.48%) | 477 (26.81%) | 494 (27.77%) | +23회, +1.29%p |
| 복연승 상위 3장 중 적중 | 843 (47.39%) | 844 (47.44%) | 865 (48.62%) | +22회, +1.24%p |

S−R 축 차이의 95% 구간은 −0.73~+3.05%p다. 복승 3장은 −0.34~+2.86%p, 복연승 3장은 −0.61~+3.08%p로 모두 0을 포함한다. 적중률 상승이 재현될 것으로 확정할 수 없다. 축 상대 개선은 **+2.05%**로, 상대 +10%에 필요한 1,126회에 미달했다.

| 각 승식 최대확률 1장 적중 수 | R | C | S |
|---|---:|---:|---:|
| 단승 | 487 | 496 | 481 |
| 연승 | 998 | 1000 | 1019 |
| 복승 | 203 | 205 | 223 |
| 복연승 | 429 | 430 | 445 |
| 쌍승 | 118 | 125 | 133 |
| 삼복승 | 107 | 105 | 97 |
| 삼쌍승 | 26 | 25 | 25 |

단승·삼복승·삼쌍승 1장 선택 적중은 감소했다. 전체 분포의 확률 점수 개선과 가장 높은 한 표의 적중 증가는 서로 다른 결과다. 복승 1장의 상대 변화도 +9.85%(203→223)이며 95% 차이 구간은 0을 포함한다. 유리한 선택 지표만 골라 10% 개선으로 표현하지 않는다.

축 S−R은 새 적중 163회, 잃은 적중 142회다. 연도별 순증은 +1/+14/+6회다. [연도·거리별 진단](experiment/diagnostics/win_axis_year_distance_gain_loss.parquet)은 기술통계이며 거리별 재선정에 쓰지 않았다. 1,610m는 9경주뿐이다. [복승/복연승 선택 및 적중수 구간](supervisor/PAIR_BOOTSTRAP.json)과 [전체 선택 원장](experiment/outputs/pair_selection_diagnostics.parquet)을 함께 보존했다.

## 감독관 판정 및 다음 연구 질문

**S를 다음 독립 검증의 연구 후보로 채택하고, 운영 채택은 보류한다.** F1_STYLE6 연구 기준선은 계속 비교용으로 남긴다. 이전 보류된 축 선택기와 동적 A/B 모델을 채택 모델로 사용하지 않았다. 이번 결과는 상대전적·거리 상태 정보를 더 연구할 근거이며, 전개·시장까지 완성된 예측기의 증거는 아니다.

확인한 사실은 입력·계보·전체 확률 계산의 일관성, 고정 개발기간에서의 proper-loss 개선, 혼재된 선택 적중 변화다. 아직 불확실한 것은 새로운 기간의 개선 유지, 공개시각/당시 출전명단의 가용성, 비정상 경주까지의 확장, 완전한 확률 보정이다. 다음 연구 가설은 제주 구간의 의미를 확인한 뒤 상대 능력 상태와 초반 위치·페이스 시나리오를 결합할 가치가 있는지다. 이는 이번 결과를 보고 바로 추가 학습한 실험이 아니다.

구매 전 배당을 확보하지 못했고 이번 비교에 배당·인기·favorite ID를 입력하지 않았다. 시장 대비 기대수익, 실제 수익, 배당 변화 효과를 계산하지 않았다. **시장 우위의 증거는 없다.**

## 만든 것·재사용한 것과 검증

- 새로 작성: 정상 전체 출전명단 감사, 상태 10개와 계보, C/S 연도별 모델 6개, raw OOS 점수, 공동분포에서 유도한 7승식 평가·선택·주변확률·확률구간 집계, 고정 비교·감독관 검산.
- 재사용: 기존 source snapshot, DB 읽기 전용 명단 조회, F1_STYLE6 원본 feature/모델 메타/raw 점수, 이전 R 온도, 공식 승식 계약, 날짜 bootstrap schedule, 봉인된 probability helper. 큰 원천 파일을 복사하지 않았다.
- 역할: 실제 조사·입력/코드 구현·학습·평가는 현재 세션 GPT-6 Luna xhigh 서브에이전트가 담당했다. 메인은 조건 고정, 사전 코드 검토, 독립 수학 검산, 판정을 담당했다.

[상태 검산](supervisor/STATE_VERIFICATION.json)은 52,155×10개 값을 독립 rank-one covariance 공식으로 재계산했다(최대 차이 1.34e−15). [계보 검산](supervisor/LINEAGE_VERIFICATION.json)은 전행 T−2·최신 원천 경주/날짜·횟수의 독립 as-of join이다. [DB 검산](supervisor/ROSTER_VERIFICATION.json)은 전체 명단 7,066경주·69,752행 일치와 DB 경로·크기·SHA를 기록한다.

[결과 검산](supervisor/RESULT_VERIFICATION.json)은 저장된 6개 모델의 raw 값 73,314개, 보정 온도 9개, 전체 ordered triples 3,625,272개, 경주별 점수·선택 각 37,251행, 주변확률 52,236행, pair 적중수 분포 21,348개, reliability 1,344행, 주 비교 bootstrap 6,000개를 확인했다. 모델 raw 값은 정확히 일치했고 확률/점수 오차는 수치 반올림 수준이었다. 모델을 다시 학습하거나 실험 엔진을 가져와 검산하지 않았다.
