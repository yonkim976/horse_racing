## 질문과 동일성 범위

제주 F1_STYLE6의 기존 30개 입력을 유지하면서, 과거 상대의 당시 능력을 고려해 순차 갱신하는 능력·거리 반응·불확실성 상태를 추가하면 승식 확률이 좋아지는가? TB에서 유망했던 상태 입력의 증분 효과를 먼저 시험한다. TB의 수치 성과를 제주 예상 효과로 사용하지 않는다.

TB의 전체 29개 상태 중 단위가 없는 상대 순위·거리 상태만 이식한다. TB의 기록지수 Kalman, 초기/종반600m 시간 상태, 비완주 위험은 제주 대응 정의가 충분히 같지 않으므로 이번에는 추가하지 않는다. S1F 210m 예외, 다른 구간 정의를 초 단위 상수나 거리 비율 환산으로 덮지 않는다. 기존 제주 STYLE6의 품질 검증된 구간순위 6열은 그대로 유지한다. 공동착순 신경망을 동시에 추가하지 않는다. 따라서 이번은 TB 전체 파이프라인의 복제가 아니라 핵심 상태 입력의 통제된 이식이다.

담당: asset_audit는 audit/와 inputs/, baseline_experiment는 experiment/, rules_contract는 review/, 감독관은 supervisor/와 최종 루트 보고서. 모든 작업자는 GPT-6 Luna xhigh. 기존 제주 연구와 더러브렛 코드·모델·DB·문서·운영 등록부는 읽기 전용이다.

## 원천과 과거 관측

대상은 10/10 F1_STYLE6의 정확한 52,155행·5,206경주다. 기존 features.parquet를 경로·해시로 참조하고 복사하지 않는다. 평가 2024~2026-09-19의 17,412행·1,779경주·269일은 세 arm 모두 동일하다. 기존 정상 완주·완전 고유순위와 최종 기록 명단에 조건부인 회고 모집단을 유지한다.

순위 상태는 10/08 outputs_v2/source_snapshot.parquet 원천에서 2010-01-01 이후의 과거 경주만 사용한다. 2010~2016은 상태 warm-up이고 supervised training은 2017부터다. 유효 이력 경주는 전체 기록 출전집합의 ID·행수와 대조된 명단이며, 말 ID·마번·출전 ID 중복 없음, 실제 전원 정상 완주 및 양의 유한 완주시간, 순위가 정확한 1..N 고유순열, N>=4, 경주 내 일관된 양의 거리, 제주 기존 거리 {800,900,1000,1110,1200,1300,1400,1610}를 모두 요구한다. 비정상/동착/누락/부분 명단은 상태 이력에서 제외하되 이유·분모를 보존한다. 비완주를 최하위 또는 기록 0으로 입력하지 않는다. 원천의 full-roster 증거가 없으면 read-only DB 대조 또는 기존 검증 원장을 사용하고 그 해시를 저장한다. 평가 집합은 이력 제외로 축소하지 않는다.

새 상태의 경주 결과 사용 여부는 원천 감사에서만 정하며 후보 결과를 보며 변경하지 않는다. 전체 원천 중 미래에 있는 행은 해당 예측 입력에 포함하지 않는다. 기록된 경주일 기준 T−2까지 포함; 공개시각과 당시 출전명단은 미확인이므로 실시간 가용성을 입증한 것으로 표현하지 않는다. 같은 날짜에 같은 말이 두 유효 이력 경주에 있으면 진행을 중단해 식별 문제를 검토한다. 현재 말 이름·현재 관계자로 과거 ID를 추정하지 않는다. 기존 제외 말 정책을 유지한다.

## 순차 상태식과 정확한 10개 입력

TB state.py의 rank 부분을 고정 연구 하이퍼파라미터로 이식한다. 숫자가 제주에서 최적화되거나 검증됐다고 주장하지 않는다. 거리 좌표만 제주 중심으로 `h(d)=[1,(d−1100)/500]`로 고정한다(TB는 1500m 중심). 각 말의 사전 평균 m=[0,0], 공분산 V=diag(2,.5), 유효 관측수 n=0. 공통 사전 평균 0은 미관측 능력이 0이라는 관측값이 아니다. 관측수와 마지막 관측일을 함께 보존한다.

마지막 유효 관측으로부터 D일 경과하면 a=exp(−D/1500), dt=min(D/30,24), m*=a*m, V*=a²V+diag(.035,.008)*dt. 두 대각 원소는 각각 2,.5로 상한을 두며 양의 준정부호와 유한성을 검사한다. 첫 관측 전에는 사전분포를 유지한다. Query는 저장 상태를 변경하지 않고 해당 cutoff까지 전파한다. 날짜만으로 갱신한 상태를 다시 전파해 시간 경과를 중복 적용하지 않는다.

유효 과거 경주의 모든 말에 대해 갱신 전 상태를 먼저 복사한다. i의 상대 j에 대해 μ=h·m, v=h·V·h, c_ij=(1+π(v_i+v_j)/8)^(-1/2), p_ij=sigmoid((μ_i−μ_j)c_ij), y_ij=1[rank_i<rank_j]. `g_i=4*mean_j((y_ij−p_ij)c_ij)`, `k_i=4*mean_j(p_ij(1−p_ij)c_ij²)`, `V_i'=(V_i^(-1)+k_i*h*hᵀ)^(-1)`, `m_i'=m_i+V_i'*h*g_i`. 相手는 반드시 당시 사전 상태이고 같은 경주 먼저 갱신된 말의 값을 쓰지 않는다. 같은 날짜의 모든 경주도 갱신 전 상태를 사용한 뒤 일괄 commit한다. n+=1, 마지막 관측일=그 경주일. 이는 pairwise logistic 근사 갱신이며 정확한 베이지안 사후분포나 인과적 능력의 확인이 아니다.

10개 열: `state_rank_mean`, `state_rank_sd`, `state_distance_slope`, `state_distance_sd`, `state_rank_current`, `state_rank_current_sd`, `state_rank_n`, `state_days_since_rank_observation`, `state_rank_current_field_gap`, `state_rank_current_field_rank`.

앞 6개는 m0,sqrt(V00),m1,sqrt(V11),h·m,sqrt(h·V·h). 미관측 이력의 days는 NaN이고 n=0; 사전 평균·분산은 명시적으로 유지한다. field_gap은 대상 편성 current 평균을 뺀 값, field_rank는 동일 편성 average-tie percentile rank(오름차순, 클수록 높은 상태). 직접 ID·현재 정답·날짜·lineage·누수 점검 열은 학습 입력에서 제외한다. 상태별 마지막 원천일과 cutoff, n, 이력 관측 지원 및 신규 말 분포는 compact ledger로 보존한다.

`rank_sd`, `distance_sd`, `rank_current_sd`는 근사 필터의 공분산 특징이며 보정된 예측 불확실성이나 정확한 사후 불확실성이 아니다. 모든 순위 갱신에는 서로 비교 가능한 정상 완주마가 최소 4마리 필요하며, 위 전원 정상·완전 명단 N>=4 조건이 이를 보장한다. 구현에서 이 조건을 완화하지 않는다. 마지막 상태 날짜는 마지막 유효 순위 갱신일이고 TB의 모든 관측 출발일과 다르다는 점을 명시한다.

## R, C, S와 학습 예산

- R: 기존 F1_STYLE6의 저장된 200회 상한 원시 점수와 이번 세션 앞선 dynamic_ability_pace_v1에서 고정한 연간 R PL temperature를 경로·해시로 재사용. 이 보정은 같은 provider의 Y−1 원시 점수로 맞춘 값이다. 기존 native 가산 집합 확률이나 HY_R_FORM 운영 확률과 혼동하지 않는다.
- C: 기존 F1_STYLE6의 동일 30개 입력과 binary Top3 목적·경주당 합계1 가중치(말마다1/N), 같은 전처리·분할·seed를 쓰고 최대 boosting만 200→800. 학습량 대조군이다.
- S: C의 30열에 위 10개 상태를 더한 40열. 그 외 모든 설정은 C와 동일.

모든 arm의 `Q(i,j,k)`는 동일한 full-field PL(s/T)의 첫 3착 분포다. C/S의 T는 해당 provider Y−1의 ordered Top3 joint NLL을 최소화하며 경주 동일 가중, [.35,4] 범위, 총6개. R의 기존3개 T는 목적함수·시점·raw score 해시를 재검증한다. TB의 가산 집합+조건부 순서 분포를 함께 바꾸지 않는다. R이 앞선 이 연구의 연간 PL 기준과 수치상 같은지 확인한다.

## 평가·판정

주 비교 S−C, 기준선 보호 S−R. C−R은 추가 학습량 진단이며 별도 성공 후보를 선택하는 탐색이 아니다. 각 비교의 공동확률 기준은 TRI Log loss 차이의 날짜 paired bootstrap 95% 상한<0, TRI Brier 차이<=0, WIN Log loss 및 Brier 차이<=0. S는 S−C와 S−R 모두 통과해야 개선 연구 후보로 판단한다. 단승 보호는 점추정이며 통계적 비열등성 주장 금지. 2024~2026은 재사용 개발기간으로 어떤 결과도 새 독립 검증·운영 승격 근거가 아니다.

기존 봉인 rules_contract와 2,000×269 bootstrap schedule을 재사용한다. 연승 1,743경주, 다른6승식1,779; 실제7두의 발매시작 명단 미확인36경주는 연승만 격리한다. 모든7승식 Log loss/Brier와 전체·연도별 고정 확률구간 빈도, full Q 질량·주변확률 일관성을 확인한다. 조합 파일 전체를 저장하지 않고 경주별 스트리밍한다.

기존처럼 승식마다 최대확률 표 1장을 고른다. 추가 TB 비교 지표는 복승/복연승의 개별확률 상위3쌍, 그 중 하나 이상 적중 여부와 정확한 합집합 확률, 복연3 적중 쌍 수0..3 및 기대 적중수/분포다. 세 쌍의 사건확률을 독립으로 곱하지 않는다. 수치 동률 허용오차1e−12와 마번사전순을 적용한 순차 선발로 각 정확한 표를 기록한다. 모든 arm의 경주수·표수·선택정책은 동일. 이 추가 선택 지표는 기술·보조 지표로 주 확률 기준을 바꾸지 않는다. 축은 기존 max WIN 말의 Top3; R1023회 재현, 상대10% 목표1126회, 절대/상대 차이와 날짜 구간을 보고한다. 연도·거리별 비교 및 gain/loss 원장은 진단이며 유리한 하위집단을 채택하지 않는다.

## 검토·보존

입력 전에 합성 미래 결과 변조 불변성, query 비변경, 같은 경주/날짜 순열 불변성, 현재 결과 입력 금지, 상대 상태의 사전 사용, 공분산 유효성, 휴양 전파를 점검한다. 휴양 시 분산이 모든 상황에서 단조 증가한다고 주장하지 않는다(평균회귀·상한이 함께 존재). 감독관은 표본 이력의 상태식을 별도 구현해 재계산하고, 저장모델 점수와 전체 승식 사건 계산·bootstrap을 독립 검산한다. 확률 합과 모든 평가 분모·선택원장을 생략하지 않는다.
