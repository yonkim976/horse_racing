# 최종 실행 결과 검토

**판정: 계약된 research-candidate gate 통과. 독립 미래 검증 또는 운영 채택 근거로는 불충분.** 이 결과는 2024–2026 반복 사용 개발 평가이며, 전개·시장 효과나 실제 구매전략 성과를 검증하지 않았습니다.

승인된 1회 실행 receipt는 `COMPLETED_RESEARCH_ONLY`이고 6개 모델(각 연도 C/S), LightGBM 12회, 온도 적합 6회로 계약 예산과 일치합니다. 1,779개 경주·17,412개 주자를 평가했고, 저장된 28개 산출물의 크기와 SHA-256이 receipt와 일치합니다. 연구 폴더 총량은 15,970,786 bytes로 100 MB 한도 아래이며 production/database 변경 표시는 모두 false입니다. 실행 승인·코드·입력·preflight 해시가 연결되어 있고, root의 독립 검증 receipt가 이 fit receipt SHA와 일치합니다.

## 사전 gate 결과

`S`는 30개 F1_STYLE6 입력에 과거 상대 순위와 거리 반응에서 만든 10개 상태 입력을 추가한 비교 arm입니다. 이식한 것은 더러브렛 58C의 rank/distance 상태 핵심부뿐입니다. 더러브렛 29개 전체 입력/모형을 옮기거나 neural network를 쓴 실험이 아닙니다. `C`는 같은 30개 입력으로 새로 적합한 대조군, `R`은 고정된 기존 F1_STYLE6 점수 기준입니다.

계약의 주 gate는 통과했습니다. TRI 공동확률에서 S−C의 race-mean NLL 차이는 −0.04275이고 날짜 paired bootstrap 95% CI는 [−0.06242, −0.02366], Brier 차이는 −0.000395입니다. S−R은 각각 −0.04405, [−0.06364, −0.02478], −0.000398입니다. 두 비교 모두 WIN NLL과 Brier 점추정도 기준 arm보다 낮아 사전 보호조건을 만족합니다. C−R은 학습량 진단용이며 주 후보 gate를 대체하지 않습니다. 그 TRI NLL CI 상한은 +0.000896이므로 C−R gate는 통과하지 않았습니다.

이 판정은 사전 정의한 research-candidate gate의 결과입니다. Gate는 TRI NLL/Brier와 WIN proper-loss 보호를 평가하며 적중률 +10% 조건은 아닙니다. WIN 축은 경주마다 승 확률 최댓값 말 한 마리의 Top3 진입을 세는 보조 진단입니다. 기준 R은 1,023/1,779, S는 1,044/1,779로 21회 증가, 상대 +2.05%(절대 +1.18%p)입니다. 사전 표기한 +10% 상대 목표는 1,126회였으므로 **목표에 도달하지 못했습니다**. 날짜 bootstrap S−R CI는 절대 차이 [−0.73%p, +3.05%p], 상대 변화 [−1.24%, +5.41%]로 0을 포함합니다. 따라서 이 축의 통계적 개선 또는 10% 적중률 상승을 주장할 수 없습니다.

## 범위·독립 검산·주의점

일곱 승식 전체에 대해 race-pool metric/선택 원장 37,251행이 있고, 분모는 연승 1,743경주, 나머지 6종 각각 1,779경주입니다. 각 arm은 같은 경주를 평가했습니다. 연도별 분모도 팔별로 동일하며, 2024/2025/2026의 일반 승식은 637/654/488, PLC는 637/650/456입니다. 36개 actual 5–7두 PLC 경주는 개시 명단 미관측으로 격리되어 있습니다. 7승식×3 arm×4 기간 신뢰도 표와 선택 확률 자료가 보존됐습니다. 저장된 전체 pool 평균 손실은 S가 R과 C보다 모두 낮지만, 공식 추론 gate는 TRI/WIN에 한정되므로 이를 7개 승식 각각의 통계적 개선으로 읽으면 안 됩니다. QNL/QPL 1장·3장 선택과 합집합/적중수 진단은 기술 통계이며 구매정책 탐색이 아닙니다.

root의 독립 검증은 6개 모델의 raw score 73,314개, 온도 보정 9개, 37,251개 pool metric/selection, 52,236개 주변확률, 3,625,272개 ordered triple, 21,348개 pair-count 분포, 6,000개 TRI bootstrap draw를 재계산해 통과했습니다. 최대 오차는 7승식 NLL `3.55e−15`, Brier `1.33e−15` 이내였습니다. 기준 R의 저장 성능과 WIN 축 1,023회도 재현됐고, 승인된 보호 파일은 변경되지 않았습니다. 이 검토는 해당 계산을 다시 실행하지 않았습니다.

신뢰도 표의 ticket-event 풀링은 빈도 설명용이고 proper NLL/Brier는 경주 동일 가중치입니다. fit 불확실성은 포함되지 않았습니다. 2024–2026은 반복 사용 개발 자료이며 독립 test set이 아닙니다. 상태는 완전한 정상 순위 이력에 한정되고 covariance SD는 calibrated posterior uncertainty가 아닙니다. T−2는 공개 timestamp가 아니라 기록된 경주일 기준이고, target roster의 당시 가용성도 확인되지 않았습니다. 배당/시장 기준·ROI·실제 구매전략은 이번 실험 범위와 결과에 없습니다.
