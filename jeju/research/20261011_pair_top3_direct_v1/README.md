# 제주 Top3 pair 직접모형 평가

저장된 F1_STYLE6 점수와 여섯 style 입력으로 학습한 대칭 pair 전용모형을 동일한 역사 평가 경주에서 비교했다. 평가기간은 2024-01-05~2026-09-19이며, 2026년은 9월까지의 부분연도다. 이 평가는 반복 개발 표본이며 새 holdout은 아니다. 예측 pair 확률은 공동 Top3 분포가 아니므로 경주별 모든 pair 확률의 합이 3으로 보장되지 않는다.

평가 코호트는 1,779경주, 269경주일, 76,848개 무순서 pair다. 각 경주에서 각 방식은 pair 하나를 선택했다.

Primary gate: 미통과. Direct 모델의 전체 pair hit-rate가 raw-score Top2보다 높고 paired date-cluster 95% CI 하한도 0보다 커야 통과다. 차이는 -0.17%p, CI -0.55%p ~ +0.22%p다 (유효 2,000, 분모 0 미정의 0회). 이 반복 개발 표본에서 사전 정의한 pair 선택 개선 신호를 확인하지 못했다. 현재 결과만으로는 이 모형을 적용 방식으로 채택하지 않는다.
Direct 모델은 raw-score Top2와 31경주에서 다른 pair를 골랐고, 변경된 경주 안의 성적 차이는 +4승 / -7패 / 20동률이다.
