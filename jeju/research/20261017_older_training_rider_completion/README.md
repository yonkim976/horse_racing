## 공식 원천과 전수 대조 범위

KRA **조교사정보 → 일일조교 → 전체 일별상세조교현황**을 사용했다. [공식 일일조교 메뉴](https://race.kra.co.kr/trainer/dailyDayTrainList.do?Act=10&Sub=3&meet=2)의 날짜 지정 공개 폼을 따라 `https://race.kra.co.kr/trainer/dailyAllTrainDetail.do`에 제주 `meet=2`로 POST했다. 수집 대상 기간은 2007-10-01~2026-04-16이며, 먼저 반영한 609행을 제외한 **280,351행·4,122일**을 대조했다.

- **4,122일 모두 성공**, 최종 실패 날짜 0일. 공식 화면 전체 1,106,004행에서 대상 API 사건키를 대조했다. 화면 전체 행을 제주마 DB의 신규 행으로 적재한 것이 아니다.
- 공식 말 ID 링크·날짜·입장·퇴장시각·조교시간이 유일하게 일치해야 분류 후보로 채택했다. 웹 시각 차이와 표시 기간도 일치해야 한다.
- stdlib `HTMLParser` 수집기와 별도 `BeautifulSoup` 검증기가 4,122개 페이지 및 모든 대상 행의 판정을 독립 대조했다.
- 요청 URL·POST 필드·응답 날짜/경마장·범례·표·원문 SHA·결과 파일 SHA를 보관했다. GET의 HTTP 200 오류 페이지는 성공으로 취급하지 않는다.
- 최초 DNS 실패는 재개 후 해소했으며 시도 기록을 보존했다. 실패한 최초 스냅샷 경계 단정과 경로 해석 오류도 수정했고, 실제 사용한 스냅샷과 동결 원장은 아래에 명시한다.

## 미분류로 유지한 과거 94,532행

| 사유 | 행 |
|---|---:|

미확정 표기 75,740행의 내역은 `선` 44,416행, `부` 16,647행, `감` 11,576행, `외` 3,098행, 공란 3행이다. `선·부·감`은 공식 정의를 확인하지 못했으므로 현재 직책에 대입하지 않았다. 사번·다른 날짜 이름·현재 명부로 과거 직책을 소급 확정하지 않는다. 시각 미제공 18,028행은 2007~2008년에 있다. 정확 대응 미확인은 실제 미조교·휴식·오류 확정을 뜻하지 않는다.

남은 과거 미분류 중 2007~2012년은 90,668행, 2013년 이후는 3,864행이다. 모든 대상 행의 사유는 [전수 판정 원장](collection/official_daily_all/outcomes.jsonl), 연도별 상세는 [완료 요약](completion_summary.json)에 있다.
