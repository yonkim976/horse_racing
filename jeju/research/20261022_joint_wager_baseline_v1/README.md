# 제주 공동 착순·7승식 확률 최소 기준선 — 감독관 최종 보고

2026-10-22. **F1_STYLE6 말 평가를 고정한 공동분포 기준선과 단일 보정 비교를 완료했다.** 공통 temperature 후보는 사전에 정한 삼쌍승 중심 연구 게이트를 통과했다. 단승은 악화했고 일부 연도·지표에서는 개선되지 않았다. 이번 결과로 7승식 전체의 우위, 시장 대비 우위, 새로운 기간의 성과를 주장하지 않는다.

판정은 **최소 PL 확률 계산 기준선 구축 완료, 보정값은 후속 비교를 위한 연구 후보로 보존, 운영 적용·기존 확률 체계 교체는 보류**다. 연구의 말 평가 기준선은 계속 F1_STYLE6이고, 등록부의 운영 모델은 HY_R_FORM이다. 보류된 10/20 축 선택기는 사용하지 않았다.

## 실제로 만든 것과 재사용한 것

조사·구현·적합·평가는 현재 세션의 GPT-6 Luna xhigh 세 에이전트가 각각 `assets_audit/`, `rules_contract/`, `experiment/`를 맡았다. 감독관은 비교 조건, 입력·시간 경계·코드 검토, 별도 구현을 통한 전수 검산과 이 판정을 담당했다. 별도 채팅은 만들지 않았다.

| 구분 | 이번 처리와 증거 |
|---|---|
| 말 평가 | F1_STYLE6 raw score와 저장 모델을 재사용했다. 재학습·새 피처·관계항·축 선택기 변경은 없다. |
| 원천·환경 | 기존 52,155행 feature 표, OOS 점수, metadata, 모델 7개, 날짜 bootstrap schedule을 경로와 SHA-256으로 참조했다. 모델·원천·DB 사본이나 새 환경을 만들지 않았다. |
| 새 확률 계산 | 전체 출전집합의 순차 Plackett–Luce(PL)로 모든 서로 다른 1→2→3 조합의 공동확률을 계산했다. 그 하나의 분포에서 7승식 확률과 말별 1·2·3착/Top2/Top3 주변확률을 합산했다. |
| 새 결과 | 승식별 Log loss·Brier, 고정 확률 구간별 실제 적중률, 연도별 결과, 선택 티켓 원장, 규칙·제외 원장, 보정값·환경·입력 해시와 독립 검산 결과를 보존했다. |
| 저장 방식 | 전체 순열은 경주별 메모리에서 집계한 뒤 버린다. 선택 티켓 파일은 전체 분포 파일이 아니다. 전체 확률은 원점수·T·코드로 복원하며 상위 조합을 재정규화하지 않는다. |

기존 자산을 새로 구현된 것으로 세지 않았다. 운영 코드에는 `P(Top3 집합) × P(집합 내 순서)` 형태의 공동분포 계산 경로와 말별 확률 출력이 이미 있다. 10/17 조건부 순서 연구에도 ordered Q와 네 승식 평가가 있다. 다만 이번 공식 연승 분기·예외·시간·7승식 손실 계약 전체를 만족하는 검증 자산과는 구분한다. 기존 F1_STYLE6 native 집합분포와 이번 full-field PL은 서로 다른 확률 구성이다. **이번 비교는 T=1 PL 대 보정 PL이며, native F1_STYLE6 또는 HY_R_FORM보다 좋다는 비교가 아니다.**

10/17 순서 후보는 자체 게이트를 통과했지만 기존 2026 공통 467경주에서는 HY_R_FORM의 네 승식 손실이 더 좋았다는 선행 결과가 있다. 관계·직접 pair·거리·축 선택 연구의 보류 상태도 유지했다. 상세 원천과 상태는 [자산 감사](assets_audit/README.md), 파일별 경로·해시는 [자산 manifest](assets_audit/assets_manifest.json)에 있다. 과거 계획 문서의 설명보다 현재 등록부·저장 산출물과 실제 코드 상태를 우선 확인했다.

## 결과 전에 고정한 비교

`Q_T(i,j,k) = w_i/W × w_j/(W−w_i) × w_k/(W−w_i−w_j)`, `w_i=exp(score_i/T)`이다. 구현은 안정적인 log-sum-exp를 쓴다. 서로 다른 말의 1→2→3 전체 공간을 다루며, 4착 이후의 모든 순열을 별도 계산·저장하지는 않는다. 이 Top3 공동분포로 이번 7승식 사건을 모두 표현할 수 있다. 구조적 착순 제약을 반영하지만, 학습된 말 간 상호작용을 입증한 모델은 아니다.

| 조건 | 고정 내용 |
|---|---|
| 기준선 | F1_STYLE6 원점수, PL `T=1` |
| 유일 후보 | 같은 원점수, 공통 양의 T 한 개 |
| 보정 | 2019-01-11–2023-12-30 OOS 2,492경주·25,278출전의 정확한 1→2→3 NLL을 경주 균등 최소화 |
| 탐색 범위 | T ∈ [0.35, 4.0], bounded scalar optimizer와 양 끝점만 비교 |
| 평가 | 2024-01-05–2026-09-19, 1,779경주·17,412출전·269경주일 |
| 주 판정 | 삼쌍승 후보−T1 NLL의 날짜 paired bootstrap 95% 상한 < 0, 삼쌍승 sum-Brier 점차이 ≤ 0 |
| 보조 선택 | 각 승식 최대확률 티켓 1개, 완전히 같은 계산값이면 마번 사전순 |
| 가격·구매 | 배당 입력·ROI 계산·구매 전략 최적화 없음 |

2019–2025 OOS 원점수 자산 3,783경주·38,017행을 먼저 확인했다. 이 중 2019–2023만 새 T 적합에 사용했다. 기존 same-year tau는 적용하지 않았고 2024·2025 정답으로 T를 갱신하지 않았다. 각 평가 연도에 제공된 frozen score vintage는 두 arm에서 동일하다.

피처의 `history_cutoff = 경주일 − 2일`을 행별 검사했다. 과거 이력은 cutoff 당일을 포함하는 기존 계약을 유지하고, provider `refit_max`도 대상 경주보다 최소 이틀 앞섰다. 키 중복·누락·비유한 점수·경주 분할 혼입이 없는지 확인했다. 새 결측 대체는 하지 않았다. **사건 날짜 검사는 실제 공개 시각이나 당시 확보 가능했던 출전 명단의 증명이 아니다.** OOS는 해당 경주를 모델 학습에 쓰지 않았다는 뜻이며, 연구자가 보지 않은 독립 기간이라는 뜻이 아니다. F1_STYLE6 자체의 선정과 2024–2026 자료에는 후대 연구 이력이 있다.

[사전 설계](supervisor/DESIGN_DECISION.md), [고정 계획](experiment/PLAN.md), [소스 검토](supervisor/SOURCE_REVIEW.json), [학습 전 코드 검토 및 승인](supervisor/CODE_REVIEW.md)에 근거와 해시를 보존했다. 계획 파일의 ‘preflight 단계’ 문구는 고정 당시 상태이며 현재 완료 상태는 이 보고서와 결과 영수증을 따른다.

## 공식 사건 정의와 평가 분모

단승은 1착, 복승은 무순위 1·2착, 쌍승은 순서 있는 1→2착, 삼복승은 무순위 Top3 집합, 삼쌍승은 정확한 1→2→3 순서다. 연승은 **발매 개시 시점** 출전두수 5–7두에서 Top2, 8두 이상에서 Top3다. 복연승은 5두 이상에서 Top3 안의 두 말이며 연승과 같은 두수 분기를 적용하지 않는다. 최소 성립 두수는 단승 2, 복승·쌍승 3, 삼복승·삼쌍승 4, 연승·복연승 5두다. 근거는 [한국마사회법 시행규칙 제4조](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=122175)이며 예외와 역사 적용 한계는 [공식 규칙 계약](rules_contract/README.md)에 기록했다.

보유 자료에는 발매 개시 명단이 없다. 실제 8두 이상은 ‘발매 개시 후 추가 출전마가 없다’는 전제에서 개시 두수의 하한으로 Top3를 정한다. 관측한 개시 두수로 위장하지 않고 `N_at_open=null`, 하한 추론 provenance와 실제 발매·정산 여부 미감사 상태를 원장에 남겼다. 실제 7두인 36경주(2025년 4, 2026년 32)는 Top2/Top3를 확정할 수 없어 **연승에서만** 제외했다. 따라서 연승 1,743경주, 나머지 6승식 각각 1,779경주다.

평가는 기존 정상 완주·완전 유일 순위 코호트에 조건부인 결과다. 동착·미완주·실격·취소·불성립을 처리하는 완성된 정산 엔진으로 주장하지 않는다. 원천 상태코드를 임의의 공식 취소·동착 라벨로 바꾸지 않았다. 기존 2017년 이후 모집단 5,901경주 중 포함 5,206, 제외 695경주의 이유는 [기존 제외 원장](../20261008_horse_profile_baseline_v1/outputs_v2/race_inclusion_ledger.csv)과 이번 자산 감사에서 참조한다. 이번 평가 안에서 연승 36경주 외 손실 분모를 줄이지 않았다.

## 동일 조건 결과

적합된 T는 **1.1837152381349905**다. 확률을 완만하게 만드는 보정이며, 예측 숫자를 일괄 높인 것이 아니다. 아래 손실은 낮을수록 좋다. Δ는 후보−T1이다.

| 승식 | 경주 수 | Log loss T1 → 후보 | Δ Log loss | Brier T1 → 후보 | Δ Brier |
|---|---:|---:|---:|---:|---:|
| 단승 | 1,779 | 2.050420 → 2.053897 | +0.003477 | 0.840612 → 0.841440 | +0.000828 |
| 연승 | 1,743 | 0.569745 → 0.567135 | −0.002609 | 0.192619 → 0.191733 | −0.000886 |
| 복승 | 1,779 | 3.390667 → 3.387475 | −0.003192 | 0.951172 → 0.951149 | −0.000023 |
| 복연승 | 1,779 | 0.237744 → 0.236978 | −0.000767 | 0.063165 → 0.062993 | −0.000172 |
| 쌍승 | 1,779 | 4.072693 → 4.070836 | −0.001857 | 0.975076 → 0.975072 | −0.000005 |
| 삼복승 | 1,779 | 4.313723 → 4.290790 | −0.022932 | 0.980556 → 0.979504 | −0.001052 |
| 삼쌍승 | 1,779 | 6.063341 → 6.045074 | −0.018267 | 0.996286 → 0.996165 | −0.000121 |

단승·복승·쌍승·삼복승·삼쌍승은 categorical NLL과 전체 사건의 sum-Brier다. 연승·복연승은 당첨/비당첨 ticket의 binary 손실을 경주 안에서 평균한 뒤 경주 균등 평균한다. 서로 다른 승식의 손실 절대값으로 우열을 비교하지 않는다. Log loss에만 ε=1e−15를 적용하고 Brier에는 원확률을 썼다.

삼쌍승 Δ NLL **−0.0182671075**, 날짜 단위 2,000회 paired bootstrap 95% 구간 **[−0.0269433365, −0.0092957929]**, Δ sum-Brier **−0.0001214193**로 사전 게이트를 통과했다. T를 고정한 bootstrap이므로 T 적합 불확실성은 포함하지 않는다. 다른 승식의 점차이에 별도 통계적 우위 판정을 붙이지 않았다.

| 삼쌍승 기간 | 경주 수 | Δ NLL | Δ Brier |
|---|---:|---:|---:|
| 2024 | 637 | −0.033715 | −0.000429 |
| 2025 | 654 | −0.008071 | +0.000064 |
| 2026-09-19까지 | 488 | −0.011767 | +0.000032 |

전체 Brier 개선은 2024에 크게 의존한다. 단승의 전체 손실은 악화했고, 복승·쌍승도 2025·2026 Log loss/Brier에서는 악화했다. 이 차이를 숨기거나 평가 후 유리한 기간을 골라 성공으로 삼지 않는다. 전체 7승식·연도별 값은 [pool_year_summary.parquet](experiment/outputs/pool_year_summary.parquet)에 있다.

## 감독관 독립 검산과 증거 수준

실험 코드를 가져오지 않은 별도 확률 구현으로 두 arm의 **2,416,848 ordered triples**, **24,834 승식·경주·arm 손실 행**, **34,824 말·경주·arm 주변확률 행**을 재계산했다. 전체 확률 합, 순위별 합 1, Top2·Top3 합 2·3, 복승 incidence=Top2, 복연승 incidence=2×Top3, 복수 당첨 승식의 질량, 실제 사건·선택 확률, 모든 구간 집계, 전체·연도별 요약을 확인했다. 수치 차이는 race NLL 최대 3.11e−15, bootstrap 구간 최대 3.47e−17이었다.

T를 다시 적합하지 않고 역온도 α=1/T에 대한 NLL 미분과 Hessian을 독립 계산했다. gradient −2.80e−8, 양의 Hessian 1.373707로 내부 최솟값을 확인했다. 선택 동점 61건도 별도 원점수·확률 계산으로 확인했다. [RESULT_REVIEW.json](supervisor/RESULT_REVIEW.json), [CHOICE_REVIEW.json](supervisor/CHOICE_REVIEW.json)에 검산값과 수치 동점 사례를 보존했다. 입력·저장 모델·운영 등록부·운영 bundle·inference 코드의 해시는 그대로다.

| 증거 대상 | 현재 판단 |
|---|---|
| 7승식 확률의 수학적 일관성 | 정상 완전 순위·관측/조건부 두수 계약에서 전수 검산 통과 |
| 확률 정확성 | 이번 T1 PL 대비 삼쌍승 주 게이트 통과. 단승 악화 및 기간별 혼재 존재 |
| 모든 승식의 충분한 calibration | 미입증. 고정 구간 실제 빈도와 잔여 오차 공개 |
| 말 평가 개선·축/후보 선택 개선 | 이번 질문이 아니며 개선 근거 없음 |
| native F1_STYLE6·HY_R_FORM 대비 우위 | 이번에 비교하지 않았음 |
| 새 독립 기간의 성과 | 미입증. 2024–2026년 9월은 반복 사용한 연구 자료 |
| 시장 대비 기대수익·실제 수익 | 미입증. 구매 전 동일시점 배당 없음; 이번 ROI 미계산 |

시장 검증 시에는 동일 경주·승식·사건·구매시점의 원금 포함 배당 D에 `p×D−1`을 적용해야 한다. 공제를 중복 차감하지 않으며 복수 당첨 승식의 역배당을 합 1로 임의 정규화하지 않는다. 사후 배당은 사전 입력이나 실제 구매 전략의 성과로 쓰지 않는다. 이번 결과만으로 수익 전략을 선택하지 않았다.

후속 연구 가설은 ‘주변 순위별 보정 요구가 달라 하나의 T가 단승과 Top3 순서에 다른 영향을 준다’이다. 검증된 사실로 바꾸어 말하지 않는다. 다음 비교를 한다면 기존 말 평가를 계속 고정하고, native 집합분포 보존 방식과 이번 PL을 같은 계약으로 비교하는 별도 사전 설계가 필요하다. 새 평가기간·당시 구매 가능 가격 검증은 별도 미해결 과제다. 추가 적합·가격 수집·운영 변경은 이번 작업에서 실행하지 않았다.

## 재현·실행 기록·저장공간

입력 파일과 환경은 [source_preflight.json](experiment/outputs/source_preflight.json), [fit_receipt.json](experiment/outputs/fit_receipt.json), [모델 참조](supervisor/MODEL_REFERENCES.json)에 있다. 계산·평가 코드는 [baseline.py](experiment/baseline.py), independent reference는 [math_reference.py](supervisor/math_reference.py)다. 기존 결과를 덮어쓰지 않는 전수 재검산 명령은 프로젝트 루트에서 다음과 같다.

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python jeju/research/20261022_joint_wager_baseline_v1/supervisor/verify_results.py --check-only
```

원 실행의 temperature optimizer 호출은 **총 2회**, 성공한 전체 비교 평가는 **1회**다. 첫 시도는 T를 계산한 뒤 첫 경주의 NumPy 정수 JSON 직렬화에서 실패해 결과를 저장하지 못했다. 직렬화만 수정하고 동일 입력·설계로 재승인했다. 첫 결과를 보고 조건을 고르거나 후보를 추가한 것이 아니다. 두 승인 영수증과 수리 이유를 `supervisor/`에 보존했다. 현재 `--fit-evaluate`는 결과가 있으면 덮어쓰기 방지로 실행을 거부한다.

신규 파일은 이 연구 폴더 안에만 있다. 총량은 **약 4.7 MB(300 MB 예산의 약 1.6%)**이며 최종 정확한 바이트 수·파일별 해시·측정시각·디스크 잔여량은 [FINAL_MANIFEST.json](FINAL_MANIFEST.json)을 따른다. 완료 직전 디스크 잔여 공간은 약 **30.28 GB(28.21 GiB)**다. 시작 시 잔여량은 30,358,315,008 bytes였다. 호스트 디스크 잔여량 변화 전체를 이 작업의 사용량으로 계산하지 않았다.
