# 감독관의 사전 비교 결정

2026-10-22. 신규 적합과 평가 결과 생성 전에 고정한 결정이다. 이 문서는 과거 연구의 알려진 결과를 처음 보는 검증이라고 주장하지 않는다.

## 질문과 보존

고정 F1_STYLE6 원점수로 만든 최소 Plackett–Luce 공동 착순 분포에 과거 OOS 자료로 맞춘 온도 하나를 적용하면, 온도 1인 동일 분포보다 확률 정확성이 좋아지는가?

말 평가의 30개 입력, 저장된 연도별 모델과 원점수는 재사용한다. 기존 native additive Top3 집합분포, 말별 확률, 10월 17일 조건부 착순 헤드, 운영 HY_R_FORM을 덮어쓰거나 이번 비교의 기존 운영 확률로 바꾸어 부르지 않는다. 이 비교는 **새 최소 확률 변환의 보정 비교**다. 10월 20일 보류 축 선택기와 미통과 관계/pair 후보는 사용하지 않는다.

## 유일한 후보

서로 다른 i,j,k에 대해 w_i=exp(score_i/T), W=sum(w)일 때

Q_T(i,j,k) = w_i/W × w_j/(W−w_i) × w_k/(W−w_i−w_j).

계산은 수치적으로 안정적인 등가식으로 한다. 모든 순서의 전체 질량이 1인 출전집합 위 분포이며, 상위 저장 조합만 재정규화하지 않는다. 3착 이후 순서는 이번 승식 계산의 필요 범위 밖이다. 이 단순 모형의 선택독립성 가정은 실제 말 사이 상호작용이 검증되었다는 뜻이 아니다.

- 기준선: T=1.
- 후보: 2019–2023 OOS raw score와 정확 1→2→3 정답으로 경주 균등 joint NLL을 최소화한 양의 공통 T 한 개.
- 후보 구조/입력/규제 탐색 없음. 온도 범위·최적화 방식·실패 조건은 실행 코드와 계획을 검토하여 승인 전에 해시로 잠근다.
- 2024–2026년 9월 19일 평가 중에는 T를 갱신하지 않는다. 재사용 말 점수 모델의 연도별 vintage는 양쪽에서 같다.
- 기존 말 평가기의 과거 모델선택, 이번 한 모수 확률 보정, 결과 평가의 역할을 구분한다. 새 말 평가 학습은 없다.

## 시점과 모집단

과거 c년 raw score는 F1_STYLE6_(c+1)의 calibration_scores 파일에서 가져온다. 해당 점수 제공 모델의 refit은 c년 시작보다 이전이어야 한다. c년 결과에 맞춘 tau나 보정 확률을 c년 OOS 입력으로 사용하지 않는다. 기존 이력의 한국 경주일 T−2일을 포함하는 경계를 유지한다. 날짜 조건은 역사적 공개시각 가용성의 증명이 아니다.

보정: 2019–2023, 2,492경주. 평가: 기존 정상 완주·완전 편성 코호트 2024–2026-09-19, 1,779경주·17,412두·269일. 데이터 구조 감사 결과와 다르면 중단한다. 정답으로 정상 코호트를 고른 후향 평가이므로 전체 실전 경주의 성과로 일반화하지 않는다. 기존 자료의 취소/불성립/DNF/동착 제외를 새 표본에서 숨기지 않고 상위 원천 분모와 연결한다.

연승 지급 범위는 발매 시작 시 두수에 따른다. 관측 실제 출주수 8두 이상은 발매 후 추가 출전이 없다는 조건의 하한 추론으로 Top3를 쓰며, opening_count 미관측을 기록한다. 실제 7두인 평가 36경주는 opening count가 없어 연승 손실·보정 분모에서 제외한다(연승 1,743경주). 다른 6승식은 동일 1,779경주를 유지한다. 복연승은 연승과 달리 5두 이상에서 Top3 중 두 말 사건이다. 실제 승식 발매·정산의 전수 역사 확인과 이 정상 경주의 구조적 사건 평가를 구분한다. 공식 계약과 합성 사례는 5–7두 연승 Top2 분기도 검증한다.

## 지표와 사전 판정

주 지표는 삼쌍승 전체 순서공간의 categorical NLL이다. 후보−기준선 날짜 paired bootstrap 95% 상한이 0보다 낮고, 삼쌍승 categorical Brier 점차가 0 이하일 때만 이 보정 후보의 연구 게이트를 통과한다. 이전에 고정된 2,000×269 날짜 재표집 파일을 그대로 참조한다. 적합 모수는 bootstrap에서 고정하므로 보정·학습 불확실성은 포함하지 않는다.

7승식 각각 동일 사건공간·경주집합에서 확률 손실, Brier, 고정 구간 reliability, 연도별 결과를 보고한다. 단일 당첨 사건공간은 categorical NLL 및 sum Brier, 연승·복연승의 복수 당첨 사건은 사건별 binary log loss와 Brier의 경주 내 평균 후 경주 균등 평균을 쓴다. 서로 다른 종류의 loss 절댓값을 승식 간 우열로 비교하지 않는다. 후보가 어떤 승식에서 악화하더라도 숨기지 않는다.

선택 보조 규칙은 각 승식·경주마다 최대 확률 티켓 1개, 동률은 마번 사전순이다. 양쪽 구매수는 같다. 이는 확률 순위 진단이며 배당을 사용하지 않는다. 시장 기대수익/ROI/운영 우월성 게이트는 이번에 실행하지 않는다. 구매 전 가격이 없기 때문이다.

2024–2026년 9월은 반복 사용한 개발 기간이다. 게이트 통과도 새 독립기간 성과나 시장 우위, 기존 native 분포 또는 운영 모델의 교체 근거가 아니다.

## 저장 및 실행

세 Luna xhigh 서브에이전트는 assets_audit/, rules_contract/, experiment/에만 쓰고 감독관은 supervisor/와 최종 보고서를 소유한다. DB 접속·사본·feature 복사·환경 복제·외부 경주 수집은 필요 없다. 원천 경로와 SHA-256, 핵심 작은 파라미터·선택 및 경주 지표 원장·구간 집계·코드를 보존한다. 전체 순열은 경주 단위로 계산 후 집계하며 영구 저장하지 않는다.

신규 영구 저장 예산은 총 300,000,000바이트다. 실행 전 자료·누수·코드 검토 PASS와 승인 파일이 필요하다. 이 감독관 게이트는 사용자의 추가 승인을 요청하는 절차가 아니다. 결과 확인 후 새 후보/추가 보정은 실행하지 않는다.
