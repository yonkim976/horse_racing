## 보유 범위 해석

- endpoint별 API source log의 최근 요청범위는 현지 operational DB의 `source_documents`에서 조회했다. 날짜 키 API의 로컬 호출은 대부분 2025–2026 구간이며, 과거 row가 같은 운영 테이블에 있어도 그 전체가 API에서 왔다고 단정할 수 없다.
- phase2 연구층의 과거 진료·조교·출발조교·체중은 `jeju_native_text_phase2_db_20260915`의 Text 수집 산출물이다. 위 API들이 존재하므로 새 역사층에서는 API 응답을 먼저 보존·coverage 비교하고, 실제 API 미제공 기간/필드만 해당 Text 원문으로 보완한다.
- 현재 접속·스키마가 확인된 endpoint와 연도별 원문 보유는 서로 다른 상태다. `VERIFIED`나 단일 API 호출 기록만으로 전기간 coverage를 뜻하지 않는다.
