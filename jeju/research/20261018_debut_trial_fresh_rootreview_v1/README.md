# 주행심사 후보의 새 기간 비교: 감독 검토

새 기간에서 주행심사 추가 후보의 개선은 재현되지 않았다. GPT-6 Luna xhigh가 원천 감사와 평가를 진행했고, 감독 검토에서는 별도 계산으로 입력·예측·조합·지표를 재현했다. 검산 통과는 계산의 일치를 뜻하며 후보 채택을 뜻하지 않는다. 기존 연구모델 유지와 주행심사 후보 채택 보류를 권고한다.

## 비교 대상과 기간

- 기존 30입력 `F1_STYLE6_2026`과 기존 34입력 `F1_STYLE6_DEBUT_TRIAL4_2026`의 저장 가중치·범주 목록·온도 보정값을 그대로 사용했다. 이번 작업의 학습과 보정 최적화는 각각 0회다.
- 이전 평가 상한 2026-09-19 이후 보유 자료를 전수 검토했다. 2026-10-02~10-17의 7일에 49경주·464행이 있으며, 원래 평가 편성 규칙을 적용한 45경주·426출전을 평가했다. 10/3 2R, 10/5 3R, 10/9 2R, 10/10 2R은 완주 상태·착순 완전성 조건을 충족하지 않아 제외했다. 이 경주의 실제 출전 이력은 이후 경주의 T−2 이력에 유지했다.
- `observed_starts=0`은 T−2까지 DB 정의상 실제 출전 이력이 없는 경우다. 평생 첫 출전의 완전한 증명은 아니다. 이번 해당 표본은 14두·6경주·6일이며 전부 900m다. 실제 입상마는 4두다.
- 이 날짜들은 두 모델의 학습·확률 보정·앞선 성과 평가에 사용하지 않았다. 모든 다른 연구에서 미열람한 기간이라고 주장하지 않는다. 이번 평가를 마친 뒤에는 이 날짜도 이미 확인한 평가 자료다.

새 기간의 날짜로 고정한 20,000회 쌍체 재표집(시드 20261018)에서 무이력마 Log loss 차이의 95% 구간은 **[−0.166234, +0.344572]**, Brier 차이는 **[−0.074633, +0.145383]**다. 전체·경력마 차이의 구간도 모두 0을 포함한다. 표본이 작아 후보의 열세를 확정할 근거는 부족하지만, 개선을 채택할 근거도 확보하지 못했다. 첫 출전마끼리 입상·비입상을 구별하는 진단은 양쪽 결과가 있는 3경주·4쌍만 가능했고 두 모델 모두 경주 평균 0.5였다.

## 감독 검산과 원천 한계

원천에서 기존 2026년 평가 4,673건의 30개 입력을 독립 재구성해 저장값과 오차 0으로 일치시켰다. Luna의 원래 계산 함수 재현도 52,155건·34열에서 일치했다. 새 기간에는 서로 다른 계산 코드의 426×34 입력이 모두 일치했다. 원천 자료는 공식 말 ID로 연결하며 현재 나이·성별·소속을 과거 능력 입력으로 소급하지 않았다.

새 경주 원문 464행/7페이지와 주행심사 원문 121행/2페이지를 바이트 수·SHA256·1부터 시작하는 항목 위치·원문 payload까지 대조했다. 새 대상의 최근 동일거리 5회 이력은 1,319슬롯이다. 기존 캐시에 없던 205개 원천 ID는 해당 66경주의 전체 출전 명단으로 다시 검증했다. 통과순위·API303 상태 허용 규칙과 결측 처리는 원래 계약을 유지했다. 주행심사 21개 등록 기록·14개 사건·전체 제주 동반마 121행을 사용했고, 최근 3개 등록 슬롯 19개 중 18개의 상대시간이 유효했다. 취소·무효 슬롯을 오래된 유효 기록으로 채우지 않았다.

최종 검산은 양 모델의 말별 예측 852행, 경주 지표 90행, 조합 540개, 재표집 차이 120,000개를 대조했다. 원점수·조합 식별자·적중은 정확히 같고 확률·오차의 최대 차이는 부동소수점 수준인 약 1.1×10⁻¹⁵였다. 저장 가중치·기존 평가 자료·운영 모델·등록부의 해시도 유지됐다. 공유 DB는 읽기 전용으로 열었다.

이번 결과는 **새 날짜에 대한 후향 평가**다. 주행심사 수집 시각은 9/29와 10/16이며 사건 날짜는 공개 시각의 증명이 아니다. 당시 T−2에 공개돼 있었는지는 미확정이다. 14두 모두 유효 심사 기록이 있었으므로 심사 정보가 전혀 없는 말에 대한 실증 성능도 검증하지 못했다. 800m·1000m의 첫 출전마로 확대 해석하지 않는다.
