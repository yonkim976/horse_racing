# KRA 명칭·성별 불일치 확인

2026-10-01 KST에 KRA 공개 프로필, 공식 경주 결과 HTML, 2026-01-16 제주 1경주 출전 PDF와 기수별 기승 PDF를 조회해 원본과 SHA-256을 보존했다. 출처 URL·조회 시각·응답 바이트·해시는 [source_fetches.json](source_fetches.json)과 [additional_sources.json](additional_sources.json)에 있다.

**3107458:** 현재 KRA 프로필은 `무명전설`로 표시되고 등록기간은 2025-10-15~2026-04-01이다. 당시 출전 PDF와 기수표는 같은 생년월일·성별·모색·부마/모마·조교사·마주 조합의 3번 말을 `동방라오`라고 부른다. 최종 경주표는 `무명전설`로 적고 왼 앞다리 절음에 따른 `출전제외`를 기록하지만, 심판 설명문에는 `동방라오`라는 명칭이 남아 있다. **명칭이 바뀐 뒤 정적 출전자료와 심판 문구에 이전 이름이 남았을 가능성이 높다.** 다만 API42의 이전 이름·마명변경일 필드는 `-`이고 `hrNmDt`는 공식 명세상 마명부여일이므로, 정식 변경일과 사유는 공개 자료에서 확인되지 않았다.

**3005897:** KRA 프로필은 `토종등극`, 암, 1994-04-01생으로 표시한다. 2002-12-14 공식 성적표는 같은 말 이름의 3R 2번을 수·8세·10위(1:12.0)로 기록했다. 22일 전 API20 주행심사 원문은 같은 ID·이름을 암·8세로 기록한다. 출전취소가 아닌 **단일 경주 성별 기록 불일치**다. 공개 기록만으로 원천 이벤트 입력 오류인지 이후 프로필 정정인지 구분할 수 없다.

상세 판정 및 프로젝트 내 API20 원문 참조는 [judgment.json](judgment.json)에 있다. 이 조사는 SQLite를 `mode=ro`로만 열었으며 DB를 수정하지 않았다.
