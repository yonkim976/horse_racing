## 바꾼 것과 고정한 것

F1_STYLE6 말 평가와 원점수는 그대로 사용했다. 이전 연구의 동결된 공동 입상관계 확률을 재사용해 가능한 모든 5두 집합 중 실제 Top3 집합을 포함할 예측확률 합이 가장 큰 집합을 골랐다. 새 학습은 0회이며, 이번에 새롭게 시험한 것은 5두 선택 규칙이다. 새로운 5두 전용 학습모델을 만들거나 검증했다고 해석하지 않는다. 확률 402,808개는 원래 입력·계수에서 최대 차이 0으로 복원됐고, 1,779개 선택은 별도 구현과 모두 일치했다.

기존 방식의 주 평가 실패 1,064경주 중 759경주(71.3%)는 입상마 한 마리만 5두 밖에 있었다. 다음 가설은 이 누락을 줄이는 전용 선택 학습이다. 이번 후보의 부진은 그 가설의 효과를 검증한 결과가 아니다. 결과를 보고 거리·선택 수·가중치 등을 재조정하지 않았다.

## 해석과 보존

기간은 2024-01-05~2026-09-19이며 2026년은 부분연도다. 이미 반복 사용된 과거 개발 표본이므로 독립 미래검증 결과가 아니다. 검토자의 원천 스키마 조회 중 세 행의 결과값 노출이 있었고, 선택 규칙과 집계에 사용되지 않았음을 기록했다. 선택 프로그램은 결과 열을 읽지 않았고 원장 해시를 잠근 뒤 별도 보고 단계에서 정답을 열었다.

기존 모델·운영 등록부 해시는 그대로다. DB는 열거나 복사하지 않았다. 원천 parquet와 모델은 경로·해시로 참조하고, 새 저장물은 경주별 선택·결과 원장과 작은 검토 파일뿐이다.
