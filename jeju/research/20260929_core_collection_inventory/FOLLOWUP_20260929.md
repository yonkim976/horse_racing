## 공식 경주결과 후보 대조

보유 제주마 성적표에서 추출한 후보는 22경주·206출전행이다. 운영 DB의 경주·출전 ID와 공식 말 ID를 대조해 206행이 모두 연결됐지만, 운영 DB는 경마장 단위 자료이므로 이 대조만으로 마종이나 공식 결과를 확정하지 않았다.

한국마사회 경주성적 목록에서 2026-09-17 8경주, 09-18 7경주, 09-19 7경주가 확인되어 날짜별 경주 수 합계 22경주는 맞는다. 이는 경주일·경주 수 수준의 대조다. API가 DNS에서 실패해 출전마별 ID·착순·기록을 공식 결과 응답과 비교하지 못했다. 206행은 계속 `candidate`로 두며 확정 원장에 합치지 않는다.

- 실패 기록: [`attempt_manifest.json`](raw/2026/attempts/20260929T070858.176641Z/attempt_manifest.json)
- 재시도 시각: 2026-09-29 07:08:58~07:09:29 UTC, 호스트 `apis.data.go.kr`, 6회 재시도 후 `ConnectError`/`gaierror` errno 8로 실패. 응답 페이지는 0개이고 서비스키는 기록하지 않았다.

## 미해결 ID와 마종 교집합

phase2 SQLite를 읽기 전용으로 다음 교차표로 확인했다.

```sql
SELECT en.identity_status, en.breed_status, COUNT(*)
FROM entry en
JOIN event ev ON ev.id = en.event_id
WHERE ev.event_type = 'trial' AND ev.meet = 2
GROUP BY en.identity_status, en.breed_status
ORDER BY en.identity_status, en.breed_status;
```

| ID 연결상태 | 마종상태 | 행 수 |
|---|---|---:|
| 공식 말·조교사 ID 연결 | 제주마 확정 | 15,633 |
| ID 미해결 | 마종 미확정 | 14 |
| ID 미해결 | 제주마 확정 | 41 |

전체 15,688행 중 ID 미해결은 55행이고 마종 미확정은 14행이다. 14행은 55행 안에 포함된다. 두 숫자는 서로 배타적인 제외 수가 아니다.

## `rank` 접두와 마종 근거

제주 race 결과 92,208행 전부 `breed_status=native_confirmed`, `breed_evidence=official_result_rank_explicit_je`로 저장돼 있다. 즉 기존 9,423경주 원장의 종별 확정 표시는 전부 `rank` 접두 규칙에서 왔으며, 말별 명시 마종 필드를 연결했다는 뜻은 아니다.

공개된 [KRA 경주별 상세성적 API 설명](https://www.data.go.kr/data/15089492/openapi.do)은 `racedetailresult/getracedetailresult`라는 별도 서비스다. 해당 필드 목록은 산지와 경주 결과를 열거하지만 마종은 명시하지 않는다. 이는 현재 수집 코드의 `API4_3/raceResult_3` 스키마에 대한 직접 증거로 사용할 수 없다. 별도 [KRA 경주마 명단 API](https://www.data.go.kr/en/data/15089503/openapi.do)는 그 API의 `rank`를 경주마 등급으로 설명한다. 현재 API4_3의 같은 이름 필드도 등급이라는 판단은 원장 값과 유사한 API 필드 정의에 따른 추론이며 직접 스키마 문서로 확인되지 않았다. 또 [KRA 1년 전적 50걸 API](https://www.data.go.kr/data/15089725/openapi.do)는 제주에 `blood` 값을 별도로 제공하고 제주마·재래마·한라마 코드를 설명한다.

따라서 현 시점에 `제` 접두는 개별 말의 제주마 품종 확정 근거가 아니다. 기존 92,208행의 `native_confirmed` 상태는 마종 재감사 때까지 provisional로 취급해야 한다. 재수집 코드는 `rank`를 등급 기반 후보 필터로만 기록하고, 말 ID를 공식 프로필 또는 품종 코드에 연결해 확인하도록 바꿨다. API4_3의 직접 스키마, 말별 공식 품종 근거, 경주일자 유효성을 확인하기 전까지 공유 원장이나 정규화 제주마 원장에 합치지 않는다.

## API 식별과 2026년 9월 최신 공시

실패한 요청은 `https://apis.data.go.kr/B551015/API4_3/raceResult_3` (`raceResult_3`)였다. 요청 범위는 `meet=2`, `rc_year=2026`, `_type=json`; 클라이언트는 `pageNo=1`, `numOfRows=20000`, `ServiceKey`를 추가한다. DNS 해석이 HTTP 요청 전 실패해 응답 페이지/바이트가 없다. 같은 host 아래의 `15057985`를 호출한 것이 아니다.

공식 [한국마사회 마필종합 상세정보](https://www.data.go.kr/data/15057985/openapi.do)는 별도 GET API `https://apis.data.go.kr/B551015/API42_1/totalHorseInfo_1` (`totalHorseInfo_1`)다. 포털 Swagger가 `ServiceKey`, `pageNo`, `numOfRows`를 필수 요청항목, `hr_no`, `hr_name`, `hr_eng_name`을 선택 요청항목으로 명시한다. 응답 말 ID·마명·품종 필드는 `hrNo`, `hrNm`, `breed`이며 `breed` 설명은 “품종”이다. 포털 시간범위는 `-`이고 과거 유효일/기준일 파라미터는 없다. 기존 92,208 결과행의 고유 말 ID 3,996개에 대한 현재 프로필 교차확인 원천으로는 유망하지만, 과거 경주일의 품종 근거로 소급 적용할 수는 없다. 이 서비스는 결과 착순·기록 대조 API가 아니다. API 응답 바이트는 수집하지 않았다.

2026-09-29에 확인한 [KRA 제주 경주성적 목록](https://race.kra.co.kr/raceScore/ScoretableScoreList.do?Act=10&Sub=1&meet=2)의 최신 완료일은 9/19다. 9/17 8경주, 9/18 7경주, 9/19 7경주로 후보 22경주와 일치한다. 목록에는 9/24 결과가 없고, 공식 [2026년 경마시행계획](https://race.kra.co.kr/down/raceplan2026_20260516.pdf)은 9/25~27 추석 휴장을 표시한다. 추가 최신 경주일은 확인되지 않아 후보 범위는 9/19까지다. [주행심사 목록](https://race.kra.co.kr/referee/RacingTrainCheckList.do?Act=06&Sub=7&meet=2)의 최신은 9/16 20두·13합격이며 로컬 원문 마지막 날짜 9/9 이후 공백은 계속 격리 상태다.

KRA 결과 목록의 상세 링크는 화면 스크립트 `ScoreDetailPopup`에서 `/raceScore/ScoretableDetailList.do`로 `meet`, `realRcDate`, `realRcNo`를 POST한다. 이는 공식 웹 상세표를 경주별로 재조회할 단서이며, 이 경로의 206행 원문을 이번 실행에서 보관하거나 대조했다는 뜻은 아니다.

조정자 측 셸 진단에서 `apis.data.go.kr`, `race.kra.co.kr`, `www.data.go.kr` 모두 `socket.getaddrinfo`/`gaierror` errno 8이 확인됐다. 이 진단 뒤 같은 DNS 요청은 반복하지 않았다. 따라서 브라우저에서 확인한 공식 HTML/API 명세와 로컬에 보존된 원문 바이트를 구분한다. 네트워크 복구 후에는 먼저 API4_3 응답 원문을 새 시도 폴더에 보존해 206행의 말 ID·착순·기록을 비교하고, 별도 API42_1의 `hrNo`/`breed` 응답으로 품종 후보를 교차 확인하되 시점 한계는 유지한다.
