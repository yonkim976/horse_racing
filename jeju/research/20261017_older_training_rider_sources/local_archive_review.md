# 제주 과거 일별조교 원문 보유분 검토

## 범위와 결론

로컬에 보유한 제주 공식 일별조교 RPT(`dacom55`, `meet=2`)는 **2015-04-29부터 2026-09-13까지 3,248개 날짜 파일**이다. 따라서 이 아카이브만으로는 2007–2012년의 누락 기승자종류를 복구할 수 없다. 해당 구간에서 발견된 출전표, 마체중, 취소, 능력검사, 출발조교, 출발심사, 진료 자료는 일별조교 사건의 대체 원문으로 보지 않았다.

별도로 보관된 공식 일별조교 상세 웹페이지는 2010-01-04와 2012-08-01 표본에서 말 ID·날짜·입장·퇴장·조교시간이 API18 원행과 일치하는 `관` 라벨을 각각 30건과 26건 복구한다. 이는 해당 표본일의 근거이며 전체 280,960행의 복구율을 뜻하지 않는다. 2007-11-22 표본은 API18 원행에 시각과 양수 조교시간이 없어 같은 사건을 시각으로 확정 연결하지 않았다.

2022 이후 보유 RPT는 기승자 라벨, 입·퇴장시각, 조교시간을 제공해 API18 사건과 교차 대조할 수 있다. 다만 RPT 행 자체에는 공식 말 ID와 기승자 사번이 없다. 로컬 표본에서는 날짜·마명·소속조/조번·시각·분을 함께 대조했고, 말 ID가 직접 들어 있는 API18 원행 및 공식 웹 상세 페이지가 ID 근거를 제공한다. 모호한 행은 확정 연결로 세지 않았다.

## RPT 필드와 사건 대조 예시

제주 RPT의 날짜별 행은 보통 **소속조(괄호 속 조교사)·조번·마명·기승자 라벨·입장시각·퇴장시각·조교시간·비고**를 포함한다. 말 ID와 기승자 사번은 RPT 행에 없다. 라벨의 뜻은 파일 안의 당일 범례를 기준으로 해야 한다.

| 공식 RPT 원문 | RPT 행과 날짜별 범례 | 같은 날짜의 API18 원행 |
|---|---|---|
| `data/raw/kra_text/dacom55/meet=2/year=2022/month=01/day=03/20220103dacom55.rpt` | 5행 범례 `관:주로조교`; 10행 열 머리글; **13행** `달빛스타` `관` `08:30–08:45` `0:15`, 1조/17번 | `daily_training_api_rows` ID 528083, horse ID **3018842**, 2022-01-03, 달빛스타, 1조/17번, 08:30–08:45, 900초. 원 API의 `prGubun_raw='-'`, `prNo_raw='005202'`, 분류상태 `미분류`. |
| `data/raw/kra_text/dacom55/meet=2/year=2023/month=01/day=02/20230102dacom55.rpt` | 5행 범례 `관:주로조교`; **12행** `갈색물결` `관` `07:33–07:52` `0:19`, 1조/16번 | API18 원행 ID 594769, horse ID **3018248**, 2023-01-02, 갈색물결, 1조/16번, 07:33–07:52, 1,140초. `prGubun_raw='-'`, `prNo_raw='005331'`. |
| `data/raw/kra_text/dacom55/meet=2/year=2025/month=01/day=02/20250102dacom55.rpt` | 5행 범례 `관:주로조교`; **13행** `길벗` `관` `07:28–07:43` `0:15`, 1조/11번 | API18 원행 ID 764458, horse ID **3103785**, 2025-01-02, 길벗, 1조/11번, 07:28–07:43, 900초. `prGubun_raw='-'`, `prNo_raw='005202'`. |

위 RPT 원문은 각각의 로컬 파일에서 확인했다. `dacom55`는 일별조교 보조 자료로서 입·퇴장과 분 단위 시간, 해당 일자의 라벨을 제공하지만 ID가 없으므로 API18 말 ID를 RPT 자체의 ID처럼 취급하면 안 된다. 날짜·마명·조번·시각·분을 교차 대조하고, 둘 이상 후보가 남으면 확정하지 않는 방식이 적절하다.

범례는 시대별로 다르다. 예를 들어 `20150429dacom55.rpt` 5행은 `보:조교보`, `후:기수후보생`, `승:조교승인`을 기록하고, `20220103dacom55.rpt` 5행은 `관:주로조교`, `후:기수후보생`을 기록한다. `20250102dacom55.rpt` 5행은 `생:교육생`을 쓴다. 그러므로 현행 범례나 현재 기수·조교사 명부를 과거에 소급 적용하지 않고, 각 날짜 원문의 라벨 정의를 따라야 한다. `승`을 `관`과 같은 종류로 간주하는 근거도 이 표본에서는 확인되지 않았다.

## API18 보유 원문에서 확인한 한계

공식 API18 일별조교 보유분은 `data/raw/jeju_native_training/horse_training_confirmed_native.jsonl.gz`이며 manifest `data/raw/jeju_native_training/horse_training_confirmed_native.manifest.json` 기준 확인 말 3,996두, 원 페이지 441개, native row 884,383건, 날짜 2007-10-01–2026-09-13이다. 이 파일과 `jeju/data/jeju_native_core.sqlite3`의 `daily_training_api_rows`를 사용했다.

구체적인 2007-11-22 원행 예시는 API18 행 ID 1428, horse ID 3009795, `건곤`, `prGubun='-'`, `prNo='003002'`, `trTerm=0`이며 `stTime`과 `spTime`이 없다. 이 원행은 기승자종류를 스스로 복원해 주지 않고, 날짜·말 ID만으로 웹 행과 같은 일별 사건이라고 확정하기에도 시각 근거가 부족하다. 다른 공식 날짜별 상세 페이지에서 ID와 시각을 얻을 수 있는 시기에는 exact event 대조가 가능하지만, 이를 2007년 자료 전체나 280,960행 전체로 일반화할 근거는 이 조사에서 확보되지 않았다.

## 검토 경계

- 이 검토와 `sample_verification.json` 생성 중 DB 쓰기는 없었다.
- 온라인 수집이나 원문 변경은 수행하지 않았다.
- 표본 결과는 날짜가 다른 전체 모집단에 대한 포괄률이 아니다.
- 마명만으로 말 ID를 자동 연결하지 않았고, 현재 명부로 역할을 과거에 소급하지 않았다.
- 출발조교·출발심사·능력검사는 일별조교 사건의 대체 자료로 간주하지 않았다.
