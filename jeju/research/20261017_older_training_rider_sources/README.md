# 최근 6개월 이전 조교 기승자 미분류: 공식 보완 원천 조사

후속 실제 반영 완료: [과거 일별조교 전수 대조·DB 반영](../20261017_older_training_rider_completion/README.md)에서 표본 609행과 추가 185,819행을 실제 반영하고 독립 검증했다. 아래는 그 이전 원천 조사 단계의 기록이며, 당시의 DB 미변경·후보 수치는 조사 시점의 상태다.

조사일: **2026-10-17 KST**. 사용자 요청은 과거 미분류를 다른 공식 자료로 구분할 수 있는지 확인하는 것이다. **이번에는 DB를 변경하지 않았으며, 확인한 609행도 분류 후보로 보존했다.**

## 결론

**보완할 수 있는 공식 조회 경로를 찾았다.** 마사회 **조교사정보 → 일일조교 → 전체 일별상세조교현황**은 날짜별 공식 말 ID·기승자 원표기·입장·퇴장시각·조교시간을 제공한다.

[공식 일일조교 메뉴](https://race.kra.co.kr/trainer/dailyDayTrainList.do?Act=10&Sub=3&meet=2)는 목록에서 최근 1개월을 안내하지만, 이 화면의 공개 폼을 따라 과거 날짜를 POST하면 과거의 실제 상세 행이 반환됐다. 말별 프로필의 최근 6개월 표시 범위를 과거 공식 자료 전체의 보존 한계로 해석하면 안 된다.

2007·2010·2012·2022·2024·2026년의 6개 날짜를 실제 조회했다. 그중 5개 날짜에서 **미분류 609행을 주로조교로 직접 구분할 근거**를 확인했다. 전체 과거 280,960행 중 몇 행이 해결되는지는 전수 수집 전에는 확정하지 않는다.

## 표본 검증 결과

| 날짜 | 해당 날짜 보유 미분류 | 정확 사건 연결 | 주로조교 확인 후보 |
|---|---:|---:|---:|
| 2007-11-22 | 72 | 0 | 0 |
| 2010-01-04 | 125 | 125 | 30 |
| 2012-08-01 | 124 | 124 | 26 |
| 2022-12-30 | 182 | 181 | 178 |
| 2024-10-16 | 202 | 202 | 202 |
| 2026-04-16 | 173 | 173 | 173 |
| **합계** | **878** | **805** | **609** |

- 말 ID는 마명 셀의 공식 `goPage4('<horse_id>')` 링크에서 읽었다. 이름 유사도로 ID를 만들지 않았다.
- 말 ID·조교일·입퇴장시각·기간이 전부 일치하고 홈페이지의 `관` 또는 `이름(관)` 표기가 있으면 범례 `관:주로조교`로 판정했다. 기승자 사번이 없는 2010년 행도 동일 사건의 공식 표식을 직접 확인할 수 있었다.
- 예: **고랑몰라(ID 3011374), 2010-01-04 07:31~07:46, 15분**은 API 종류·사번이 모두 `-`지만 공식 상세의 기승자 칸이 `관`이다.
- 2007년 표본은 API와 홈페이지에 조교 시각·기간이 없어 기존의 정확 사건 연결 기준을 통과하지 못했다. 말 ID와 날짜만으로 자동 분류하지 않았다.
- 정확 연결된 나머지 196행은 구형 `선` 100행·`감` 43행·`부` 50행 및 `외` 3행이다. [공식 약어 조사](legacy_markers.md)에서 `선/감/부`의 명시적 대응표를 찾지 못했으므로 뜻을 추정하지 않았다.
- 2022년 표본 1행은 같은 사건키에 복수 홈페이지 행이 대응해 보류했다. 이를 오류 중복으로 단정하거나 대표 한 행으로 합치지 않았다.

이 표본은 시기별 가능성을 확인하기 위한 목적 표본이다. 609/878 비율을 과거 전체의 분류 성공률로 일반화하지 않는다.

## 다른 공식 자료의 역할

| 자료 | 확인 내용 | 사용 범위 |
|---|---|---|
| **전체 일별상세조교현황** | 공식 말 ID·날짜·시각·기간·기승자 종류 표식 | 이번에 직접 보완 가능성을 검증한 우선 원천 |
| 과거 출전상세정보의 조교현황 탭 | 예: 2026-04-17 1R에 전주·금주 요일별 `관13` 등의 기승자·분 표기 | 입퇴장시각이 없는 요일 격자이므로 날짜 해석과 연결 검증이 더 필요한 보조 원천 |
| 보유 공식 일별조교 RPT/TXT | 제주 일별조교 RPT 3,248개, 2015-04-29부터 보유. 기승자 표기와 시각·기간이 남아 있음 | 공식 말 ID가 없는 문서는 이름만으로 확정 연결하지 않고 보조 대조에 사용 |
| API234 기수일일조교일자 | 기수별 날짜·조교두수 집계 | 특정 말의 조교 사건을 식별할 말 ID·시각 키가 부족 |
| API307 기수·API308 조교사 명부 | 공식 ID와 등록 기간 | 당시 등록 자격 참고. 해당 말의 해당 조교행 종류를 대신 확정하지 않음 |

API18은 기존 일별조교 원천으로 유지한다. 홈페이지는 API의 기승자 종류 `-`를 보완하는 직접 근거로 연결하며 API 원문·ID·시각을 대체하지 않는다. API234의 화면상 1개월 안내를 API 자체의 과거 보존 제한으로 단정하지 않았다. [공식 API 검토](api_review.md)를 함께 본다.

## 검증과 저장 근거

- [표본의 원행별 대조](daily_sample_matches.json), [모집단·표본 요약](scope_and_sample_summary.json).
- [보유 RPT/TXT 인벤토리·표본 대조](local_archive_review.md): 일별조교 원문과 경주·출발조교 등 다른 자료를 구분했다.
- [독립 HTMLParser 검산](sample_verification.json): 루트의 BeautifulSoup 파서와 다른 구현으로 공식 원문 6개, 정확 사건 805행, 주로조교 후보 609행을 검증했다. DB는 `mode=ro`와 `query_only`로 열었다.
- 공식 응답·SHA·요청 폼은 `homepage/daily_all_*/manifest.json`, HTML은 같은 폴더의 `1.html`에 보존했다. 각 날짜의 요청·응답 날짜와 `meet=2`를 확인했다.
- [공개 화면 탐색기](probe_official_pages.py), [표본 연결 코드](match_daily_samples.py).

상세 URL은 `/trainer/dailyAllTrainDetail.do`이며 공개 화면의 POST 폼을 사용한다. 실제 확인한 예:

```text
meet=2
Act=10
Sub=3
trDate=2026/04/16
trDateReplace=20260416
trYo=
trNo=
trName=
```

같은 값을 GET 링크로 열면 오류 화면으로 전환된 사례도 보존했다(`homepage/daily_april_link/`). HTTP 200만 보고 정상 자료로 판정하지 않는다. 최초 제한 환경 DNS 실패는 `homepage/initial/`에 보존하고 허용된 공식 읽기 조회로 재시도했다.

## 다음 수집을 위한 범위

최근 창 이전의 현재 미분류는 **280,960행·4,124개 날짜**, 2007-10-01~2026-04-16이다. 양수 기간이 있는 행은 262,932행, 기간 미제공은 18,028행이다.

후속 전수 대조는 이 **4,124개 날짜의 공식 전체 상세**를 원천으로 삼을 수 있다. 날짜별 자료 제공 여부를 각각 검증하고, 공식 말 ID·시각·기간이 유일하게 연결되며 뜻이 명확한 표식만 분류한다. 구형 약어·시간 미제공·`외`·복수 대응·응답 실패는 미분류로 유지한다. 이번 조사는 이 전수 수집이나 DB 적재를 실행한 것이 아니다.
