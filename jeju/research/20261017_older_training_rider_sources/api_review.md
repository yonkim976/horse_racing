# 제주 과거 일별조교 기승자 종류: 공식 API 대안 검토

조사일: 2026-10-17 KST  
범위: 최근 6개월 창보다 오래된 제주 일별조교 미분류 280,960행에 직접 연결 가능한 공식 자료가 있는지 확인. 데이터베이스는 읽기 전용으로 조회했다. 신규 API 신청·서비스 승인 요청과 대량 재수집은 하지 않았다.

## 요약

공식 API234 `기수일일조교일자`는 기수별 일자·조교두수 집계라 말별 일별조교 행의 구분을 복원하지 못한다. 제주 API307 기수 명부와 API308 조교사 명부는 직원 ID와 데뷔·은퇴 또는 시작·종료 날짜를 제공한다. 이를 보유 중인 공식 응답으로 과거 미분류행에 정확한 ID와 유효기간을 대조했을 때 66,818행이 당시 기수/조교사 등록기간과 겹쳤다. 이 수치는 당시 등록 역할에 대한 후보이며 실제 해당 말의 해당 조교행 역할을 직접 기록한 결과는 아니다. 나머지 직원 종류(조교보, 조교승인, 교육생, 주로조교 등)를 덮어 분류하는 근거로 쓸 수 없다.

공식 KRA 일일조교 상세 POST 경로가 최근 화면 안내보다 오래된 날짜도 반환하는 것을 표본으로 확인했다. `/trainer/dailyAllTrainDetail.do`에 `meet=2`, 과거 `trDate`와 이에 대응하는 날짜 필드를 넣어 2007-11-22, 2010-01-04, 2012-08-01, 2022-12-30, 2024-10-16, 2026-04-16 상세 원문을 받았다. 2010·2012 표본에서는 exact event 연결 249행 중 `관` 56행을 주로조교로 직접 확인했고, `선/감/부` 193행은 뜻을 확인하지 못했다. 2022·2024·2026 표본에서는 exact event 연결 556행 중 `관` 553행을 직접 확인했고, `외` 3행은 미확정이었다. 이 3개 후대 표본의 553행과 2010·2012 `관` 56행을 합한 분류 가능 표본은 609행이다. 2007 표본은 말 ID·날짜만 일치하고 사건 시각이 없어 종류를 붙이지 않았다. 상세와 미확정 구형 토큰의 범례 검토는 [공식 과거 표식 조사](legacy_markers.md), 날짜별 exact-match 결과와 원문 해시는 `daily_sample_matches.json` 및 `homepage/daily_all_*/manifest.json`에 있다. 이 결과는 표본 날짜에 대한 가능성을 증명할 뿐 280,960행 전체를 재수집하거나 분류한 결과가 아니다.

## 보유 공식 로스터와 과거 미분류행 대조

2026-10-17 기준 창 이전(`training_date < 2026-04-17`)의 현재 미분류 280,960행을 읽기 전용으로 확인했다. API307 제주 응답(보유 원문 관측 2026-10-08)과 API308 제주 응답(2026-09-29)의 ID를 정확히 문자열 일치시키고, 각 행 날짜가 API 응답의 데뷔/은퇴 또는 시작/종료 구간에 들어오는지 계산했다.

| 공식 로스터 | 일치 행 | 유효기간 내 일치 행 | ID 수 | 비고 |
|---|---:|---:|---:|---|
| API307 기수 | 53,346 | 53,346 | 43 | 92명 응답 중 제주 ID 기준; 일치 행 전부 데뷔–종료 구간 안에 있음 |
| API308 조교사 | 13,472 | 13,472 | 21 | 40명 응답 중 제주 ID 기준; 일치 행 전부 시작–종료 구간 안에 있음 |
| 합계 | 66,818 | 66,818 | 64 | 두 응답의 직원 ID 교집합 없음; 전체 미분류의 23.78% |

나머지 214,142행은 이 두 로스터로는 당시 역할을 확인하지 못한다. 그중 43,408행은 기승자 사번 자체가 비어 있다. 이는 조교보·조교승인·기타 역할 명부가 공식적으로 없다는 단정이 아니라, 이번에 확인한 API307/308 범위로는 분류 불가하다는 뜻이다.

표본에서 확인한 사건 날짜는 2007-10-31이며, 예를 들면 API307 데뷔 1996-06-01~은퇴 2022-06-04 구간의 ID가 포함된 미분류행과 API308 시작 1996-05-01~종료 2025-09-30 구간의 ID가 포함된 미분류행이 있었다. 이는 날짜 구간 대조가 작동한 표본이며, 두 건 자체로 전체 모집단의 역할 정확도를 검증하지 않는다.

## 분류 판단 경계

- 같은 말·날짜·입장·퇴장·조교 분까지 직접 일치하는 공식 사건행에서 명시된 역할을 읽으면 분류 근거가 가장 강하다.
- API307/308의 ID와 유효기간 일치는 직원의 당시 자격/등록 역할에 대한 별도 근거다. API18이 별도의 `prGubun`을 `-`로 기록한 사실과 사건별 역할 확정은 구분해서 보고해야 한다.
- API234 날짜별 기수 조교두수는 여러 말의 aggregate일 뿐, API18 행에 rider employee ID를 연결하지 못한다.
- 출발조교는 다른 사건이므로 일별조교의 `prGubun` 대체 근거로 삼지 않는다.
- `trName` 담당 조교사명, 현재 소속·현재 명부, 사번 접두, 다른 날짜의 같은 사람 이름으로 나머지 과거 행의 역할을 소급 추정하지 않는다.
