# 짝의 기록 지원도·변동성 반영: 감독 검토

GPT-6 Luna xhigh가 사전 고정한 7개 입력의 단일 후보를 구현·학습·보고했고, 감독은 원천 정의, H1 전용 정규화, 학습 목적함수·기울기, 76,848개 예측, 1,779개 선택, 22개 요약, 242개 날짜 bootstrap 비교와 사후 배당 5구간을 독립 재계산했다. 산술·연결 검토는 PASS지만 사전 지정한 개선 기준은 통과하지 못했다.

비교 대상은 기존 **기수 고유 효과 연구 후보**다. 운영 `HY_R_FORM`과의 직접 비교가 아니다. 말 평가 `F1_STYLE6` 점수와 원천 DB는 유지했고, 두 말 동시 Top3 모델 단계만 다시 학습했다. 2024~2026-09-19의 1,779경주·269경주일은 이전에도 사용한 개발 자료이며, 2026년은 부분연도다.

## 무엇을 추가했나

두 말 중 적은 보유 출전수와 동일거리 유효기록수, 최근 같은 거리 5회 출전 슬롯의 최소 유효시간수, 두 말 중 큰 시간 변동계수(표본 표준편차/평균), 같은 거리 마지막 출전으로부터의 최대 간격을 반영했다. 변동계수와 출전 간격의 미확보 말 수도 별도 입력했다. 총 7개이며 한 말의 기록이 없다고 0초나 낮은 능력으로 치환하지 않았다. 과거 이력은 T−2까지다.

변동계수는 유효시간이 3개 이상인 말에만 정의한다. 출전 간격은 최근 유효기록의 나이가 아닌 최근 **출전**의 간격이다. 지원도는 보유 원천에서 관측한 수이며 생애 전수 경력이 아니다. 원기록 변동에는 주로·중량·등급 차이가 섞일 수 있어 이를 말 자체의 생리적 신뢰도라고 해석하지 않는다.

선택 변경은 4경주로 새 적중 2·기존 적중 손실 1·양쪽 미적중 1이었다. 입상률 차이 +0.056%p의 날짜 95% 구간은 −0.114~+0.278%p다. 2024년은 155→154, 2025년 157→158, 2026년 126→127로 연도별로 일관된 적중 개선도 확인되지 않았다.

고정 선택쌍의 Brier 차이는 −0.00001844(95% 구간 −0.00005036~+0.00001170), log loss 차이는 −0.00004788(−0.00013728~+0.00003675)다. 두 지표 모두 점추정치는 작게 개선됐지만 구간이 0을 포함했다.

전체 쌍에 대한 경주균등 평균은 Brier −0.00000200, log loss −0.00001361로 작게 개선됐고 각각의 날짜 구간도 0 아래였다. 이는 전체 확률 분포에 약한 신호가 있다는 결과다. 그러나 사용자가 실제 고르는 한 쌍의 확률·적중 개선까지 입증한 것은 아니므로 이 보조 지표만으로 채택하지 않는다.

2025~2026년 기존 선택쌍 1,142경주의 최종 복연 배당별 사후 진단도 거의 변하지 않았다. 5~10배 층의 과대평가는 +7.676→+7.679%p, 10배 이상은 +16.893→+16.917%p다. 이번 입력만으로 고배당 과대평가를 해결했다고 볼 수 없다. 10배 이상 관측 적중 0/68은 실제 확률 0을 뜻하지 않으며 최종배당을 사전 입력으로 사용하지 않았다.

## 다음 연구 방향

기존 말 평가와 기수 ID 연구 비교기를 유지하고 이번 후보는 미채택으로 보존한다. 이번 결과는 사전 지정한 선형 7열 후보의 한계이며 기록 지원도 자체에 가치가 없다는 증거는 아니다.

후속 후보는 단순히 저경력 말을 감점하기보다 **기존 확률 수준과 기록 지원도의 상호작용**을 제한적으로 검토하는 방향이 적절하다. 예를 들어 같은 높은 확률이라도 두 말 중 한 말의 동일거리 근거가 적을 때 오차가 달라지는지, 두 말의 불확실성 불균형이 잔차와 이어지는지를 먼저 과거 학습 영역 안에서 조사한다. 원기록 CV가 환경 차이를 섞는다는 한계도 확인해야 한다. 조정계수·가중치를 임의로 키우거나 이번 4개 변경 경주에 맞춘 규칙을 만들 근거는 없다.

새 실험은 하나의 가설과 입력을 고정하고 H1 학습·H2 보정·시간순 평가를 유지해야 한다. 현재 평가 기간을 다시 쓰면 반복 개발 검증임을 명시하고, 채택 판단은 이후 독립 기간에서 재현되는지 확인해야 한다. 이번 작업에는 추가 후보 학습·사전배당 수집·운영 승격이 포함되지 않는다.
