# 두말 동시 Top3 직접모형

상태: central 발행 전 검토용 초안. 아래 적중 수는 A 실행의 예비 결과이며 독립 C 검토·최종 신뢰구간·최종 A/C/B manifest 잠금이 끝나지 않았다. 이 문서를 중앙 결론으로 옮기거나 성능 확정값으로 인용하지 않는다.

저장된 `F1_STYLE6` 말 점수를 고정하고, 경주마다 하나의 무순서 두말 조합이 실제 Top3에 함께 드는지를 직접 학습한 후향 비교다. 목표는 `P(두 말 모두 Top3)`인 pair 사건 하나의 선택이다. 정확한 순위, 복승, 세 번째 말까지 포함한 조합 또는 티켓 적중을 예측하는 모델은 아니다. 직접 pair 확률은 전체 Top3 공동분포를 정의하지 않으며, pair 확률 합이 경주마다 3이 되도록 강제하지 않았다.

## 예비 주 결과

2024-01-05~2026-09-19의 1,779개 경주·269개 경주일에서 direct pair 모형은 426/1,779회(23.946%)를 적중했다. 사전 지정한 저장 raw-score 상위 두 말은 429/1,779회(24.115%)였다. direct pair 모형의 점추정은 3회 낮아 주 성능 gate는 점추정 기준으로 통과하지 못했다. 날짜 cluster 신뢰구간과 최종 독립 재계산은 아직 대기 중이다.

같은 과거 코호트의 고정 참고 정책은 candidate joint Top3 runner marginal 상위 두 말 434/1,779회(24.396%), candidate joint maximum-mass pair 422/1,779회(23.721%), matched-baseline joint maximum-mass pair 429/1,779회였다. 이는 재사용한 과거 자료의 맥락 비교이며 독립 검증값이 아니다. 평가 결과를 보고 비교군을 고르지 않는다.

이 기록은 점추정 예비치만 담는다. 날짜 paired bootstrap, 확률 품질, pair 확률의 racewise sum-to-3 편차, 비교군 전체 재현은 최종 A 결과와 C 독립 검토 receipt를 대조한 뒤 확정한다. 새 지표나 신뢰구간은 이 초안에서 계산하지 않았다.

## 해석과 범위

주 비교의 점추정이 raw-score 상위2보다 낮으므로 현재 증거는 직접 pair 보정의 적중 개선을 지지하지 않는다. 최종 신뢰구간이 산출되더라도 점추정 조건 실패를 뒤집지 않는다. 이 결과는 앞선 연구에서 사용한 날짜와 라벨을 재사용한 후향 개발 자료이고 2026년은 9월 19일까지의 부분연도다. 독립 미래검증, 인과효과, 수익성 또는 운영상 개선으로 해석하지 않는다. 현재 말 평가와 운영 모형은 유지한다.

pair 사건 확률은 완성된 Top3 확률이나 ticket probability가 아니다. exact Top2, 복승, 조합 완성률, 배당·수익은 이 연구 목표에 포함하지 않는다.
