# 제주 작업 지침

이 디렉터리에서 제주마 분석·연구 작업을 시작할 때 이 문서와 `docs/RESTART_PLAN_20260928.md`를 먼저 읽는다.

수집·적재·검증의 최신 상태와 과거 보고서 취합본은 [통합 점검 문서함](review_documents/README.md)을 함께 읽는다. 날짜별 사본의 과거 미완료 표시는 당시 상태이며 최신 상태표·후속 실제 적용 원장이 우선한다. 검토용 사본은 원문 근거·실행 코드·DB의 대체물이 아니다.

## 목표와 범위

- 새 예측 목표는 [제주마 예측 목표 재정의](docs/JEJU_PREDICTION_OBJECTIVES_2026-09-28.md)를 따른다. 우승축, 말별 우승·Top2·Top3 및 정확한 2·3착 확률, 조건부 동반 후보, 공동 착순 분포에서 계산한 승식별 조합 확률을 연구 목표로 둔다.
- 기존 `HY_R_FORM`의 A(한 마리 입상 선택), B(상위 3두 집합), C(상위 3두 순서) 평가는 기존 결과와 비교 기준으로 유지한다. 새 목표와 같은 의미로 취급하지 않는다.
- 현재 기준 모델은 `HY_R_FORM`이며 운영 등록부가 유일한 모델 선택 근거다. 실험 후보를 기준으로 표시하거나 자동 승격하지 않는다.
- 사용자가 요청하지 않는 한 새 외부 자료 수집을 요구하지 않는다. 기존 모델 재현·평가의 보유 자료 상한은 2026-09-12다. 사용자 승인으로 확장한 제주 전용 DB 경주결과 상한은 2026-09-19이며, 이후 조교 원문은 별도 보관하고 분석 뷰에서는 해당 경주 상한을 적용한다. 시장 배당·인기 자료와 영상 입력은 현재 범위 밖이다. 말별 확률·공동 착순 확률은 목표별 평가와 조합 사건 계산에 필요하다.

## 분석 순서

### 조교 적재 및 입력 기준

- 2026-10-17 과거 미분류 609행을 공식 날짜별 전체 상세의 동일 사건 `관` 표기로 주로조교에 실제 반영했다. [과거 보완 적용·전수 대조 상태](research/20261017_older_training_rider_completion/README.md)를 우선한다. 1차 적용 후 전체 미분류는 280,874행이며, 남은 과거 280,351행·4,122일은 전수 대조 진행 중이다. 수집 후보와 실제 반영을 구분하고 미확정 구형 약어·시각 결측·모호한 사건키는 미분류로 유지한다. 아래 최근 보완 수치는 그 단계의 스냅샷이다.

- 2026-10-17 사용자 승인으로 최근 6개월 미분류의 홈페이지 보완을 실제 DB에 반영했다. [최신 적용·검증](research/20261017_training_rider_website_completion/README.md)을 먼저 읽는다. 19,885행을 주로조교로 보완해 전체 미분류는 281,483행이며 최근 대상 미분류는 523행이다. 종류는 동일 사건의 공식 홈페이지 범례로 확인한 값이고 API 원문 `-`와 사번·시각은 보존했다. `외`나 대응 행 미확인은 미분류를 유지한다. 사번의 다른 날짜 전체에 직책을 소급하거나 기존 분류기로 홈페이지 보완값을 덮어쓰지 않는다. 최신 전체 조회 `training_current`와 기존 상한의 `daily_training_rider_types_analysis_2026`을 구분한다.
- 사용자 지정 기승자 종류·기수 이름 분석은 [종류 저장·집계](research/20261015_training_rider_types/README.md) 및 `daily_training_rider_types_analysis_2026`를 사용한다. `rider_type`은 확인된 원문 종류 또는 동일 조교행의 홈페이지 표식만으로 정하고 나머지는 미분류다. 이름 분석 필드 `jockey_name`은 종류=기수일 때만 제공하며 기수 외·미분류는 NULL이다. API `기수후보생`과 웹 `교육생`은 별도 표기를 유지한다. `(관)`은 주로조교이며 관리사 직책으로 자동 분류하지 않는다. 다른 날짜의 이름·현재 직책·사번 접두로 과거 종류를 소급 추정하지 않는다.
- 사번별 이름 참조를 별도로 추적할 때 [2026-10-15 사번·실명 연결](research/20261015_training_rider_identity/README.md)과 `daily_training_riders_analysis_2026`를 따른다. `rider_name`은 사번별 참조명이고 `rider_name_on_website`·`rider_name_same_event_website_verified`는 이번 홈페이지의 동일 조교행 직접 확인이다. 원문 구분 `-`인 과거 직책을 현재 명부로 소급 확정하지 않는다. 사번 미제공·홈페이지 `외`·미연결 실명은 NULL이며 `trName_raw`를 기승자로 대입하지 않는다. 이 연결을 기존 모델 입력에 자동 반영하지 않는다.
- 조교 자료를 조회·적재·집계하거나 새 모델 입력으로 사용할 때 [조교 API 자료와 모델 입력 기준](docs/JEJU_TRAINING_API_INPUT_CONTRACT_2026-10-01.md) 및 [원문 중복 감사](research/20261001_training_audit/README.md)를 먼저 읽는다. 출발조교의 홈페이지 기준 적재와 정규 조회는 [적재 보고서](research/20261001_starting_training_website_load/README.md)를 따른다. 출발조교 조회는 `starting_training_website_rows_latest`, 2026년 분석 조회는 `starting_training_website_rows_analysis_2026`을 사용한다. 일별조교 API18도 [적재 보고서](research/20261001_daily_training_api_load/README.md)에 따라 적재·전수 검증을 완료했다. 원행은 `daily_training_api_rows`, 2026년 분석 조회는 `daily_training_api_rows_analysis_2026`이다. 4,545두·908,316행을 저장하며 경주 상한까지 907,389행을 조회한다. 감사 JSONL은 별도 감사 산출물이며 두 종류의 조교 적재 모두 모델 입력 채택을 뜻하지 않는다.
- 제주 경주장 전체 응답을 공식 말 ID로 보유 제주마에 선별한다. 마명·ID 접두·현재 관계자로 과거 조교를 연결하지 않는다. 형식이 맞지 않는 ID는 확인 전 연결에서 제외한다.
- 일별조교 `run1Cnt`/`run2Cnt` 전 기간 0값은 실제 횟수 0으로 입력하지 않는다. 초기 `trTerm=0`, 자료 시작 전 결측과 `remark='-'`도 미조교·휴식·양호로 변환하지 않는다. API18 시각은 원문 형식·날짜·기간 차이를 전수 검증했다. 양수·시각 일치 890,288행만 `duration_seconds`로 제공하고 시간 미제공 18,028행은 NULL 상태로 둔다. `trName_raw`는 조교사명, `prNo_raw`는 기승자 사번으로 구분한다. 원문과 공개시각 제한은 유지하며 다른 미검증 필드는 변환·집계 피처에서 제외한다.
- 출발조교의 전체 item 내용이 같은 것은 동일 내용 반복 관측이며 오류 중복이나 같은 사건임을 뜻하지 않는다. 사용자 제공 화면에서도 반복행이 확인됐다. 같은 내용의 서로 다른 item도 각각 보존하며 내용 해시로 유일화하거나 대표 한 행만 남기지 않는다. 재적재 방지는 원문 artifact ID와 item 순번으로 처리한다. 같은 말·날짜의 다른 내용도 유지하고, 이벤트 식별 근거 확인 전 원문 행 수를 실제 시행 횟수로 단정하지 않는다. [화면 대조](research/20261001_training_website_crosscheck/README.md)를 따른다.
- 사용자의 홈페이지 기준 출발조교 지시에 따라 공식 마명 링크의 말 ID를 API42 제주마 프로필에 직접 연결하고, 홈페이지의 서로 다른 400M·800M 행을 각각 보존한다. API22의 말별 행 수나 필드가 달라도 홈페이지 기록과 원문 대조 근거를 함께 보관한다. 분석 뷰의 `current_horse_name`과 `current_horse_age_2026`은 최신 이름·2026년 고정 나이이며 원문 마명은 `horse_name_raw`다. `stable_horse_number_raw`는 소속조 안의 말 번호로 조교사 ID가 아니다.
- 과거 경주 입력은 예측시점 이전 조교만 집계하고 출전키당 한 행으로 연결한다. 사건 날짜를 공개 시각으로 간주하지 않는다. 당일 가용 근거가 없는 기록은 제외하며 날짜뿐인 자료에는 최소 `trDate < race_date`를 적용하고 공개 시점 미확정을 표시한다. 이 자료를 기존 모델 입력에 자동 반영하지 않는다.

### 출발심사 API21 적재 및 입력 기준

- 출발심사를 조회·재적재·집계할 때 [적재·검증 및 입력 계약](research/20261002_starting_exam_db_load/README.md)을 먼저 읽는다. 현재 원문 연결 테이블은 `starting_exam_api_rows`(10,664행·4,636두), 2026년 분석 조회는 `starting_exam_api_rows_analysis_2026`(2026-09-19까지 10,620행)이다. 추가 API42 프로필 21두를 반영해 전체 최신 프로필은 4,637두다. 주행심사·출발조교와 별도 이벤트로 유지한다.
- `current_horse_name`과 `current_horse_age_2026`은 최신 API42 이름·2026년 고정 나이다. 원문 이름·성별·나이를 보존하며 심사 당시 값과 현재 프로필 값을 혼동하지 않는다. 원문 item JSON·타입·키 부재·페이지 SHA·1부터 시작하는 item 위치를 추적한다. 재적재 방지는 원문 artifact와 item 순번으로 처리하고 같은 말·날짜의 다른 경주번호 779그룹·1,558행을 유지한다.
- `rider_raw` NULL 5,795행은 API 항목 미제공이며 미기승을 뜻하지 않는다. `rider`는 이름 문자열이다. `daySerial`은 심사차수, `trainNo`는 경주번호, `chulNo`는 마번이다. 판정 `-` 4행은 unknown/NULL, `1차합격` 651행은 별도 판정으로 보존한다. 외부마 조교사 이름·`0BBBBB`는 원문에 유지하고 정규 조교사 ID는 NULL이다. 출발불합격 사유 미제공·고령 나이·알려진 성별 충돌은 선행 감사 이력을 따른다.
- `meet='제주'`와 `name='한국'`을 품종 근거로 해석하지 않는다. 현재 프로필 품종은 과거 심사일의 품종 확정이 아니다. `exam_date`는 공개시각이 아니며 향후 경주 연결에는 최소 `exam_date < race_date` 및 공개시각 미확정을 적용한다. 이 적재를 모델 입력에 자동 반영하지 않는다. 사용자 제외 말은 재적재하지 않는다.

### 진료 API16 적재 및 입력 기준

- 진료 조회·재적재·집계는 [적재·독립 검증 보고서](research/20261002_medical_db_load/README.md)를 먼저 읽는다. 원문 연결 테이블은 `medical_api_rows`(12,030행·944두), 2026년 분석 조회는 `medical_api_rows_analysis_2026`(2026-09-19까지 11,991행·939두)이다. API42 미연결 81두의 현재 제주마 프로필을 추가해 최신 프로필은 4,718두다. 현재 프로필 품종을 과거 진료일의 품종 확정으로 해석하지 않는다.
- 원문 날짜·마명·병원·두 진료 문구·part·JSON 타입과 item 위치를 보존한다. `part` 의미는 미확정이며 식별자로 사용하지 않는다. 같은 내용의 반복행과 같은 날 복수행을 유지하고 원문 행 수를 진료 횟수로 단정하지 않는다. 재적재는 source artifact와 1부터 시작하는 item 위치로 막는다.
- `medical_api_diagnosis_slots`는 원문 두 슬롯이며, 검토·구성요소·설명 조회는 각각 `medical_api_diagnosis_slot_review`, `medical_api_diagnosis_components`, `medical_api_diagnosis_explanation_terms`로 분리한다. 1:N 설명 조인으로 출전키·진료 원행을 증식시키지 않는다. 공유 사전은 진료 사건이 아니며 TB의 진료 사건을 편입하지 않았다.
- API33 설명 `-`를 설명문으로 쓰지 않는다. 실제 확보한 공식 설명만 출처와 함께 사용한다. 접두어 파서 의존 356개와 사건 조건부 8개 규칙은 일반 연결에서 차단한다. 제외·미검토·설명 미확보 문구는 원문과 감사 상태를 보존한다. 진료 `-`는 unknown/NULL이며 건강함·미진료로 해석하지 않는다. 재료판매·검사·장제·예방·처치 문구를 질병으로 자동 분류하지 않는다.
- 최신 이름과 2026년 고정 나이는 기존 사용자 지정 정책을 따른다. `clinicDate`는 사건 날짜이며 공개시각은 미확정이다. 미래 경주 연결에는 최소 `clinic_date < race_date`와 공개시각 미확정을 적용하고 기존 모델 입력에 자동 반영하지 않는다. 과거 API 0행은 진료가 없었다는 증거가 아니다. 공식 말 ID가 확인되지 않은 제주 TXT는 보완 후보이며 이번 확정 ID 연결 테이블에 편입하지 않았다. 제외 말은 재편입하지 않는다.

### 구간기록·통과착순·통과조 검증 기준

- 제주 구간 자료를 정규화·적재·집계할 때 [2026-10-02 검증 보고서](research/20261002_section_passing_audit/README.md)를 읽는다. 현재 후보 92,513행·9,494경주와 취소·불성립 147경주를 구분한다. 말별 API4 측정, 경주별 API303 통과조, 경주 전체 API6 시간을 서로 다른 단위로 유지한다.
- 시간 원문 4건은 아래 홈페이지 대조·후속 적재 기준을 따른다. 남은 항목은 [공식 홈페이지·API 재조회·TXT 보완 검증](research/20261002_section_remaining_review/README.md)을 먼저 읽는다. 최초 통과순위·통과조 후보 27경주 중 6경주는 API303 지점 대응 차이, 2경주는 홈페이지 순위 차이로 설명됐으며 19경주·70관측·20지점은 홈페이지와 TXT에서도 내부 충돌이 남는다. 설명된 8경주는 DB 정정 완료를 뜻하지 않는다. 통과조 괄호 내부 순서를 개별 착순으로 만들지 않는다.
- 홈페이지와 최신 API4·TXT가 다른 양수 순위 14개(2025-10-17 7R·2026-03-06 8R)는 사용자 승인에 따라 2026-10-03 홈페이지 값으로 DB 반영했다. - 2026-10-03 미해결 19경주를 최신 API4·홈페이지로 재검토한 [보류 반영 보고서](research/20261003_unresolved_section_review/README.md)를 읽는다. 70개 순위·20개 통과조의 정답은 여전히 미확정이며 `section_internal_conflict_reviews` 90행으로 보류 근거를 연결했다. **현재 새 사후 분석은 `jeju_race_postrace_sections_quality_2026`를 사용한다.** 충돌 순위 70개·통과조 20지점은 NULL·`unresolved_official_internal_conflict`, 다른 기록과 홈페이지 정정 14개·광해청명 G1F 시간 NULL은 유지한다. 미적용·API SHA 변경도 NULL로 차단한다. `_raw`와 이전 조회의 원값으로 보류를 우회하거나 괄호 내부 순위를 복원하지 않는다. 최종 착순·전체 경주 삭제는 하지 않았고 기존 모델 입력 채택도 아니다. 충돌 지점의 시간·그룹·순위 파생값은 추가 검토 없이 정확한 계측 피처로 사용하지 않는다. 시간 진단 후보는 오류 확정이나 추정 보정을 뜻하지 않는다.

### 2026-10-01 사용자 지정 이름·나이 분석 기준

- 새 로컬 DB 분석은 `data/jeju_native_core.sqlite3`의 `horse_analysis_2026`, `jeju_race_analysis_2026`, `jeju_trial_analysis_2026` 뷰를 기본 입력으로 사용한다. 구현·검증은 `research/20261001_horse_analysis_2026/README.md`를 따른다.
- 표시·분석 마명 `horse_name`은 말 ID에 연결된 최신 API42 프로필명이다. 과거 경주·심사의 연결키는 공식 `horse_id`이며 마명 문자열로 연결하지 않는다. 과거 원문 이름은 `historical_horse_name_raw`로 추적한다.
- 기본 분석 나이 `age`/`age_2026`는 **2026 − 최신 API42 출생연도**다. 기준연도는 2026으로 고정하며 시스템 날짜나 과거 경주 날짜로 자동 변경하지 않는다. 경주·심사 원천 나이는 `age_at_race_raw`/`age_at_trial_raw`다. 2026년 기준 나이를 경주 당시 나이로 설명하지 않는다.
- 경주·심사의 기본 성별 `sex`는 각 이벤트 API 원천 값을 유지한다. 현재 프로필 성별은 `sex_current_profile`로 별도 제공한다. 토종등극(ID `3005897`)의 과거 수/현재 암 불일치는 사용자 승인에 따라 현행 기록을 유지하고 출처 충돌 기록으로 남긴다.
- 과거 나이 27행의 강줄기·득점기록 출생연도 차이는 미확정 상태를 유지한다. 분석용 2026년 마령 계산은 현재 API42 출생연도를 사용한 사용자 지정 정책이며 과거 생년의 정합성을 확정하는 판정이 아니다.
- 이름·2026년 나이 조회 기준은 새 분석에 적용한다. 저장된 과거 피처와 기존 모델의 재현에는 해당 시점의 원래 입력 계약을 유지한다.

1. 입력의 원천, 말·경주 식별자, 단위, 정의, 중복·결측·제외, 최초 공개 시점을 확인한다.
2. 원천 관측과 모델 입력 사이의 계산·절단·결측 처리를 재현한다.
3. 관측값, 분석자의 추정, 검증 전 가설, 관측 불가능한 값을 서로 구분한다.
4. 가능한 가설과 반례를 정리한 후에만 제한된 피처 또는 모델 비교를 제안한다.
5. 과거 기간의 반복 사용을 독립 검증으로 부르지 않는다. 경주일 전체를 시간 순서로 묶고 미래 정보가 입력에 들어가지 않았는지 확인한다.

## 보존과 실행

- 사용자 승인으로 삭제한 말은 `data/horse_exclusions.json`에서 공식 말 ID로 확인한다. `reimport_allowed=false`인 말은 제주 DB 재구축·수집 결과의 편입·분석 후보 생성에서 제외한다. API 원문과 과거 감사·삭제 백업은 증거 보관이며 활성 입력으로 사용하지 않는다. 작은곰(3005648)의 2026-10-02 삭제와 검증은 `maintenance/small_bear_removal_20261002/deletion_receipt.json`을 따른다.
- 새 문서·코드·결과는 `jeju/` 안에 둔다. 공통 운영 앱, 데이터베이스 스키마, 모델 resolver와 등록부는 이 디렉터리에서 수정하지 않는다.
- 기존 실험 및 원천을 임의로 삭제하거나 덮어쓰지 않는다. 2026-09-28에 별도 승인된 `jeju/maintenance/cleanup_20260928/` 및 `jeju/maintenance/legacy_review_20260928/` 정리만 예외이며, 범위와 결과는 각 기록에 남긴다. 그 기록에 없는 삭제는 별도 명시적 승인 전에는 수행하지 않는다. 필요한 공통 자료는 읽기 전용 참조로 연결하고 새 결과 경로를 사용한다.
- 공유 DB는 읽기 전용으로 연다. 제주 프로젝트용 분석은 Supabase 접속 없이 로컬 보유 자료에서 진행한다.
- `jeju/cli.py replay`는 고정된 역사적 입력만 읽고 `jeju/predictions/`의 새 하위 경로에 결과를 만든다. DB·네트워크·운영 등록부 쓰기를 추가하지 않는다.
- 모델 학습은 현재 데이터 감사와 분석 결과가 정리되고 사전 평가 절차가 고정된 뒤에만 제한된 비교로 시작한다.
