# 제주 승식별 실제 당첨배당 빈도

## 범위와 읽는 법

2025-01-01~2026-09-19 로컬 제주(meet 2) 완료 경주 가운데, 공식 결과의 1·2·3위가 각각 한 마리로 확인되고 일곱 승식의 당첨 선택키와 최신 완전 API301 배당 원문이 모두 연결되는 경주를 집계했다. 후보 1,274경주 중 1,237경주(97.1%)가 공통 분석 코호트에 포함됐다. 2026년 값은 9월 19일까지의 부분연도다.

배당은 실제 적중한 선택의 확정배당만 사용했다. 구간 `[1,2)`, `[2,3)`, `[3,5)`, `[5,10)`, `[10,20)`, `[20,50)`, `[50,100)`, `[100,∞)`의 전체 빈도는 quote 기준이다. `저배당 <5배`와 `고배당 ≥20배`는 비교를 위한 고정 기술 경계이며, 베팅 임계값이나 수익성 기준이 아니다.

아래의 주 표는 경주 단위다. 경주 안에 실제 당첨 배당이 여러 개 생기는 연승(PLC)과 복연승(QPL)은 모든 당첨 quote 중 최댓값으로 저·중·고 범주를 나눈다. 따라서 PLC/QPL의 경주 수 분모는 각각 1,237이지만 quote 수 분모는 다르다. 중앙값과 구간 히스토그램은 실제 당첨 quote 기준으로 별도 집계했다.

## 정산 정의와 제외

- 단승(WIN): 1위; 연승(PLC): 실제 출주 7두 이하면 1·2위, 8두 이상이면 1·2·3위; 복승(QNL): 1·2위의 순서 없는 쌍.
- 복연승(QPL): 1~3위의 순서 없는 두 마리 조합 3개; 쌍승(EXA): 1위→2위; 삼복승(TLA): 1~3위 조합; 삼쌍승(TRI): 1위→2위→3위.
- 1~3위에 동착이 있는 10경주와 유효한 고유 1·2·3위가 확인되지 않은 27경주는 모든 승식에서 공통 제외했다. 4위 이하 결측·주행중지는 유효한 podium을 바꾸지 않는 한 제외 사유가 아니다.
- 전체 후보 날짜 174일의 로컬 원천 사전점검에서 883개 원문 파일 해시를 확인했다. 적격 경주가 있는 171일은 최종 완전 API301 실행으로 다시 확인했고, 당첨 quote를 포함한 506개 페이지의 SHA-256이 일치했다. 1,237경주 모두 일곱 승식의 당첨키·배당 연결이 완전했다.
- 이는 저장된 로컬 자료의 기술 통계다. 사전 배당, 승률, 기대수익, 모델 예측 성능 또는 베팅 전략을 추정하지 않는다.

## 재현 및 원자료 연결

재현할 때는 입력 감사자료와 코드를 복제한 깨끗한 작업 폴더에서 프로젝트 루트 기준으로 `.venv/bin/python -B jeju/research/20261014_pool_dividend_frequency_v1/analyze.py`를 실행한다. 기존 결과를 덮어쓰지 않도록 산출물이 하나라도 이미 있으면 중단한다. 분석은 공유 DB를 SQLite read-only / `query_only` 모드로 열고, 이미 보유한 API301 원문만 검증해 읽으며 네트워크 요청이나 DB 쓰기를 하지 않는다.

- [`PLAN.md`](../20261014_pool_dividend_frequency_v1/PLAN.md): 사전 범위와 지표 정의.
- [`SOURCE_PREFLIGHT.json`](../20261014_pool_dividend_frequency_v1/SOURCE_PREFLIGHT.json) 및 [`SOURCE_PREFLIGHT_NATIVE_FOLLOWUP.json`](../20261014_pool_dividend_frequency_v1/SOURCE_PREFLIGHT_NATIVE_FOLLOWUP.json): 후보 경주, 원천 완전성, 제외 사유 감사.
- [`winning_quotes.csv`](../20261014_pool_dividend_frequency_v1/winning_quotes.csv): 실제 당첨 quote별 원문 경로·SHA-256 포함.
- [`race_pool_summary.csv`](../20261014_pool_dividend_frequency_v1/race_pool_summary.csv): 경주×승식별 max/min 분류.
- [`histogram_by_pool_year.csv`](../20261014_pool_dividend_frequency_v1/histogram_by_pool_year.csv): 전체·연도별 quote 및 경주 구간 수·비율.
- [`race_frequency_by_pool_year.csv`](../20261014_pool_dividend_frequency_v1/race_frequency_by_pool_year.csv): 전체·연도별 경주 분류, quote 중앙값·범위.
- [`SOURCE_PAGE_INDEX.csv`](../20261014_pool_dividend_frequency_v1/SOURCE_PAGE_INDEX.csv), [`REPORT.json`](../20261014_pool_dividend_frequency_v1/REPORT.json), [`SOURCE_HASHES.json`](../20261014_pool_dividend_frequency_v1/SOURCE_HASHES.json): 원문 페이지, 결과 영수증, 입력·출력 해시.

감독은 실제 당첨 13,560행·경주×승식 8,659행·히스토그램168행·요약21행을 독립 원문 추출과 대조했다. [최종 독립 검토](../20261014_pool_dividend_frequency_v1/ROOT_FINAL_REVIEW.json)는 PASS이며 모델 선택·확률·수익 계산은 포함하지 않았다.
