# 제주마 입상 조건 분포와 조건별 입상률 탐색 계약

입상마의 공통점에서 모델 입력 후보를 찾는다. 결과 계산 전에 조건·구간·기간을 고정한다. 입상마만 보고 점수를 역산하지 않으며 같은 모집단의 모든 비입상 출전도 분모로 유지한다. 관찰 연관·모델의 미반영 후보·미래 예측 개선을 구분한다. 이번 작업은 학습·재보정·운영 반영 없이 통계를 계산한다.

## 자료와 시점

기존 상대능력 연구의52,155출전·5,206경주,2017-01-13~2026-09-19를 그대로 사용한다. 현재 거리800·900·1000·1110·1200·1300·1400·1610m,6두 이상·완전 정상 착순·유효 전체시간 편성이라는 사후 선정 조건을 승계한다. 무이력·동일거리 기록 없음은 포함하며 별도 조건으로 표시한다.400m는 과거 이력에만 남긴다. 제외 말3005648을 복원하지 않는다.

2017~2023은 과거 탐색,2024~2025는 후기 비교,2026은9월19일까지 최근 비교다. 이 자료들은 기존 연구에서 이미 사용했으며 새로운 독립 검증이 아니다. 조건 경계는 이번 결과를 보고 조정하지 않는다.

T−2까지 관측한 과거 이력만 과거 조건에 사용한다. 최신 표시 마명·2026년 고정 나이를 과거 입력으로 사용하지 않는다. 나이·성별은 직전 관측 경주의 값이며 이번 나이와 같다고 단정하지 않는다. 이번 거리·등급·두수·번호·부담중량은 결과 원장에서 재구성한 선언 가정이다. 과거 최초 공개·정정 시각 및 실물 게이트 대응은 미확정이다. 현재 부담중량을 포함한 조건은 선언표 대조가 필요한 후보로 분리한다. 당일 함수율·실제 체중·실제 전개는 예측 조건으로 추가하지 않는다.

원천은 기존 품질 조회의 동결 파생표와 원천 스냅샷이다. DB·등록부·운영 모델과 기존 결과를 변경하지 않는다.

## 단일 조건과 고정 구간

각 조건은 결측을별도 범주로 유지하며 성능 좋은 행만 남기지 않는다.

번호 효과는 정확히10두·번호집합1~10인 경주에서만1~3/4~7/8~10으로 나누고 거리별로 계산한다. 대상 밖 행은 해당 조건의 분모에서만 제외한다. 과거 통과순위·주행중 위치를 번호로 대신하지 않는다.

조건 조합은 다음4개만 사전에 정한다. 상대 순위분율4구간×직전착순5구간,상대 순위×부담변화6구간,상대 순위×추세4구간,상대 순위×동일거리 유효시간4구간이다. 미확인도 보존한다. 모든 조합표를 보고하며 최적 구간을 재탐색하지 않는다.

## 분모와 비교

조건C마다 출전수·말수·경주수·경주일수·입상/비입상 수,입상마 중 해당 조건의 비율P(C|Top3),해당 조건 출전의 입상률P(Top3|C),전체 출전 중 해당 조건 비율을 함께 계산한다. 조건 구간 내 전체 말의 입상률을 모델 예측확률로 그대로 대입하지 않는다.

3/N은 각 편성의 균등 기준이다. 조건별 평균 입상률−해당 조건 출전의 평균3/N을 계산해 출전두수 차이를 분리한다. 이는 다른 능력·거리·등급·기수·배정 차이를 조정한 인과 효과가 아니다. 같은 경주에서 조건 해당·비해당 말이 모두 있는 경우 경주별 입상률 차이도 별도 표에 남긴다.

2024~2026은 기존 R1의 시간순 저장 Top3 확률을 연결해 조건별 관측−예측 차이를 계산한다.2026년 운영 공통467경주에서는 HY_R_FORM의 저장 주변확률도 연결한다. 서로 다른 모델의 서로 다른 모집단 잔차를 직접 비교하지 않고 공통 표본을 별도로 보고한다. 관측−예측 잔차가 남아도 새 입력의 추가 개선으로 확정하지 않는다.

2024~2025와2026의 각 조건별 균등기준 차이·R1잔차에 경주일 bootstrap2,000회·seed20261009의95% 점별 구간을 계산한다. 같은 말의 여러 날짜 반복을 별도 군집 조정하지 않는다. 많은 조건·조합을 보는 탐색이며 구간0배제를 다중비교 확증이나 채택 기준으로 사용하지 않는다. 최소100출전·50경주를 만족하지 않는 후기/최근 비교는 소표본으로 표시한다.

## 확인할 가설과 반례

최근 동일거리 기록 우위,최근 입상 반복,거리 경험과 최근성의 조건이 다음 입상률과 연결될 수 있다. 반례로 좋은 기록이 있어도 강한 상대를 만나거나 큰 증량·장기 공백이 있는 경우를 함께 본다. 최고·추세·편차의 연관을 이전 J1 묶음이 개선하지 못했다는 사실과 구분한다. 조건이 입상마에게 흔하다는 사실은 모델 추가 가치가 있다는 증거가 아니다.

출전 ID·직전 ID·최근 동일거리 실제 출전 ID를 남기며 전체 이력 날짜≤T−2,말ID일치,정답 교란 시 조건 불변,결측/경계/자기 제외를 확인한다. 결과와 코드를 날짜별 폴더 및 결론 모음에 보존한다.
