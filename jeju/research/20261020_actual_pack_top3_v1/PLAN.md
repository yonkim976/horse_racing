# 실제 통과조 세 그룹과 입상 결과

2026-10-20 사용자 정정 요청. 말의 과거 각질이 아니라 해당 경주의 실제 통과조 위치를 비교한다. 결과를 집계하기 전에 고정한다.

기존 품질 검증된 2017-01-13~2026-09-19 정상완주 완전편성52,155출전·5,206경주·2,813두의 고정 CSV와 통과조 원문 감사표를 읽는다. 현재8거리·원천7~13두·400m/제외말결과제외·2026부분연도이며 현재10월까지의 확장 집계가 아니다. DB개방/쓰기·외부수집·운영모델변경없음.

주지점은 S1F다. 1110/1610m는출발후210m,그외기본설명200m이며1300m는사용자지점순서2C→S1F를유지한다. 초반첫/둘째/셋째이후 통과조 묶음으로 세 그룹을 정한다. 첫묶음은‘선두’,두번째묶음은‘두번째/선입위치’,나머지묶음은‘뒤쪽’이다. 괄호내순서를개별순위로복원하지않으며,두번째묶음이항상전통선입을뜻하거나뒤쪽말이모두추입형/추입성공을뜻하지않는다. 혼동을줄이기위해 그룹번호와원문을함께보존한다.

원천통과조가품질보류이거나한말이라도분류되지않으면해당지점경주전체를주분모에서제외하고제외원장을남긴다. 보류를다른원문으로우회하지않는다. 기존피처의품질라벨과원문파싱·출전명단이정확히일치하는지검산한다. 세그룹중없는그룹은0두로보존하되입상률은NULL이다.
