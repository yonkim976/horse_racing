# S40 대 번호·초반성향 상호작용 G47 — 결과 전 단일 비교 계약

2026-10-25. 사용자가 승인한 연구의 조건을 후보 학습·확률·성과 확인 전에 고정한다. 실제 원천 조사·입력 생성·구현·학습·평가는 현재 세션 GPT-6 Luna xhigh가 담당하고, 메인은 지시·설계/코드 검토·독립 검산·채택 판단을 담당한다.

## 범위와 소유권

- 기준선 S40는 `20261022_tb_state_transfer_v1`의 봉인된 모델·원시 OOS 점수·PL 온도·경주 명단을 그대로 재사용한다. S의 새 학습/온도 최적화는 0회다.
- 후보 G47는 S40의 기존 입력 정의를 유지하고 아래 정확히 7개 수치 변수를 추가해 동일한 학습 규칙으로 새 말 점수를 학습한다. 기존 S의 개별 원시 점수 자체를 고정한 사후 보정 실험은 아니다. 기존 40개 입력·학습 조건 고정에 7개 입력 묶음만 추가하는 비교다. 공동분포 생성 방법은 바꾸지 않는다.
- 기존 E43의 부담중량·중량변화·번호 비율, 보류 축 선택기·앙상블·하위마 제외 및 다른 후보를 추가하지 않는다. 추가 변수 묶음의 증분 효과만 비교하며 각 변수의 독립 효과나 경합의 인과효과를 확정하지 않는다.
- audit/는 asset_audit, experiment/는 entry_experiment, review/는 entry_review, supervisor/와 최종 README/manifest는 메인이 소유한다. 기존 파일·원천·DB·더러브렛·운영 등록부·운영 모델을 수정하지 않는다. 외부 수집과 DB 변경은 없다.

## 재사용 원천과 시간

- 기존 `20261021_phase_pace_prediction_v1/outputs/features_and_targets.parquet`에서 `api_record_id` 및 정확한 대상 키로 연결한 **h10_s1f_0_mean, h10_s1f_0_n, h10_slots**만 수치 원천으로 읽는다. 현재 대상 경주의 y_*/obs_*·착순·사후 구간값·시장정보를 입력으로 읽지 않는다. 과거 원천 검산에는 별도로 동결된 관측/계보를 읽을 수 있다.
- h10은 동일 공식 말 ID의 경주일−730일 이상, 경주일−2일 이하(양 끝 포함)의 **최근 최대 10개 실제 출전 슬롯**이다. S1F 관측이 빠졌다고 더 이전 관측으로 10개를 채우지 않는다. m은 유효 슬롯에서 과거 S1F 첫 묶음 진입 indicator의 평균, n은 그 유효 관측 수다. n=0이면 m은 NULL이다. 원천의 첫 묶음은 단독 선두·물리적 경합·전술적 선행 유형과 같지 않다.
- 슬롯 원천은 2017년부터 시작하므로 초반의 730일 창이 왼쪽에서 잘릴 수 있다. n=0은 실제 과거 출전이 없었다거나 후미형이라는 뜻이 아니다. 슬롯 ID·날짜·원천 해시와 지원량을 보존한다.
- 이전 F의 학습된 OOS 예측은 2024~2026만 존재하므로 이를 과거 학습행에 섞지 않는다. 이번 최소 실험은 검증된 과거 이력 계산만 재사용하며 보조 모델을 추가로 학습하지 않는다. 같은 해 정답으로 보정한 값을 같은 해 입력으로 쓰지 않는다.
- 문서·관측의 최초 공개/정정 시각은 미확인이다. T−2는 사건 날짜 경계이며 실제 구매 시점 가용성의 증명으로 부르지 않는다.

## 정확한 입력 산식

대상 말 i의 출주번호를 b_i, 동일 S40 대상 명단을 R, 과거 첫 묶음 평균/관측 수를 m_i,n_i라 한다.

`q_i = (m_i*n_i + 1)/(n_i + 3)`; n_i=0일 때 분자는 1이며 q_i=1/3이다. 이는 기존 F 원천의 명시적 수축 성향값이다. **이번 경주에 보정된 선행 확률 또는 동시 진입 확률이라고 부르지 않는다.** 모수나 임계값을 결과에 따라 바꾸지 않는다.

| 모델 입력 | 고정 산식 |
|---|---|
| `pace_own_early_tendency` | q_i |
| `pace_own_label_support_fraction_max10` | n_i / 10; 최대10슬롯 대비 유효 S1F 라벨 지원량이며 실제 보유 슬롯 중 비율과 구분 |
| `pace_inner_interaction` | q_i × sum(q_j: j∈R, b_j < b_i) |
| `pace_outer_interaction` | q_i × sum(q_j: j∈R, b_j > b_i) |
| `pace_adjacent_inner_interaction` | q_i × sum(q_j: j∈R, b_j = b_i−1) |
| `pace_adjacent_outer_interaction` | q_i × sum(q_j: j∈R, b_j = b_i+1) |
| `pace_opponent_observed_fraction` | count(j∈R\{i}: n_j>0) / (\|R\|−1) |

- 각 집계에서 자기 말은 제외한다. 곱은 학습용 상호작용 수치이며 독립성에 근거한 동시 선행 사건 확률이 아니다. 실제 경합 여부·에너지 소모·진로는 직접 관측/예측한 결과가 아니다.
- 해당 측 또는 번호차이1의 상대가 없으면 빈 합은 0이다. 이는 존재하지 않는 상대의 기여 0이며, 이력이 없는 실제 상대는 q=1/3과 관측량으로 구분한다. n=0의 평균을 0이나 후미 성향으로 치환하지 않는다.
- 출주번호는 S와 동일한 명단의 번호 그대로다. 취소로 건너뛴 번호를 압축하지 않는다. 인접은 **정수 번호차이 1**이며 가장 가까운 남은 번호를 대신 쓰지 않는다. 실제 출발 칸·주로 물리 위치와의 대응은 미검증이다.
- phase 원천의 추가 487경주/4,463행을 현재 편성에 섞지 않는다. S40 대상 52,155행/5,206경주 전부가 원천에 1:1 연결됐고 대상 키/두수/거리/번호집합이 같다. 새 집계는 S40 명단에서 계산한다. 결측이나 품질 상태 때문에 경주 분모를 바꾸지 않는다.
- 얇은 입력은 위 7개 모델 열과 검산용 키·m/n/slots/q·선택 슬롯 ID/날짜·상대/인접 ID/번호/지원량·산식/원천 해시를 보존한다. 계보 열은 모델에 전달하지 않는다.

## 동일 학습·보정·평가

- supervised 5,206경주/52,155행 유지. Y=2024/2025/2026: 초기학습 2017..Y−3, 조기종료 Y−2, 선택 반복 수로 2017..Y−2 refit, 보정 Y−1, 평가 Y. 같은 경주의 말을 분할하지 않는다. 범주 어휘는 초기학습에서만 만든다.
- S40와 같은 binary Top3 LightGBM, 출전마 가중치 1/N, seed 20261008, learning_rate .04, num_leaves 15, min_data_in_leaf 100, lambda_l2 5, deterministic/force_col_wise, threads4, 최대800/early-stop25를 사용한다. 선택 반복 수 자체는 같은 규칙에서 달라질 수 있다.
- G만 초기+refit 총6회, 최종 모델3개, 연간 PL 온도3개를 생성한다. S는 재학습/재보정0회다. 추가 seed·후보·규제 탐색·평가 후 재학습을 하지 않는다.
- 양쪽 모두 같은 full-field sequential PL ordered Top3 공동분포와 온도 [0.35,4]를 쓴다. 온도는 전년도 보정 경주의 joint NLL로만 정한다. 모든 순열의 전체 분포에서 7승식을 계산하고 임의 상위 조합 재정규화를 하지 않는다.
- 평가기간 2024..2026-09-19, 1,779경주/17,412두/269일. 연승은 개시두수 미확인 실제7두 36경주 제외한1,743경주, 다른6승식은1,779경주다. 기존 봉인 승식 사건·동착/취소/비정상완주 적용 범위와 결과 기반 정상완주 명단의 한계를 유지한다.

## 결과 전 판정과 출력

- 유일 비교 G−S. 삼쌍승 joint NLL의 paired date bootstrap **양측95% 구간 상한<0**, 삼쌍승 Brier Δ<=0, 단승 NLL/Brier Δ<=0를 모두 만족해야 후속 연구 후보 기준 통과다. 단승 조건은 점추정 보호이며 통계적 비열등성 검정이 아니다.
- 기존 269일×2,000회 날짜 bootstrap 일정을 재사용한다. 새 일정을 고르지 않는다. 전체/연도별 7승식 NLL·Brier, 고정 확률구간별 실제 적중률, 최대확률1장, 축Top3, 복승/복연승 상위3장 및 적중 합집합/장수 분포를 같은 조건으로 보고한다. 축/복승3장/복연3장 차이의 날짜95% 구간을 보존한다.
- 사용자 사례를 코드 합성검사로 검증한다: 같은 자기 q에서 안쪽/바깥쪽 상대 교환, 번호4와 번호2의 차이(5번기준), 양쪽 인접, 자기 제외, 번호 결번, n=0/부분 관측. 이것은 예측 성과 검증과 구분한다. 임계값으로 유리한 결과 하위집단을 골라 성공으로 보고하지 않는다.
- 기존 여러 연구에서 사용한 기간이며 새로운 독립 검증기간이 아니다. 시장가격·배당·인기·ROI는 비교하지 않는다. 10% 개선이나 전개 변수의 인과효과, 실제 경합 예측 성공을 가정하지 않는다. 운영 승격은 없다.
