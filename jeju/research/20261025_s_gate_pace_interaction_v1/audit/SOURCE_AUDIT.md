# G47 입력 원천 감사

2026-10-25 결과 전 고정 입력 감사. `gate_pace_features.parquet`는 S40의 52,155두·5,206경주 전부를 보존하며, 기존 h10 첫 묶음 이력으로 정확히 7개 gate/성향 상호작용 변수를 만든 얇은 표다. 모델 학습·예측·성과 계산은 하지 않았다.

## 원천과 고정

생성기는 S40 키 집합을 `20261022_tb_state_transfer_v1/inputs/state_features.parquet`에서, 경주·말 번호 메타데이터를 10/10 F1_STYLE6 `features.parquet`에서 읽었다. 초반 성향은 10/21 phase `features_and_targets.parquet`에서 지정된 키와 `h10_slots`, `h10_s1f_0_mean`, `h10_s1f_0_n` 열만 읽었다. 선택 슬롯 ID와 경계는 `history_lineage.parquet`의 `h10_ids`, `cutoff`, `lower`를 읽고, 각 선택 ID의 날짜는 같은 phase 표의 메타데이터로 연결했다. 결과열(`y_*`, `obs_*`, 착순), 학습된 phase OOS 점수, DB 및 외부 자료는 입력으로 읽지 않았다.

## 시간 경계와 지원량

과거 슬롯은 같은 공식 말 ID의 대상일−730일 이상, 대상일−2일 이하로 제한했다. `h10_ids`의 슬롯 순서를 보존하고 ID별 날짜를 붙여 창 경계와 말 ID를 검사했다. 선택된 실제 출전 슬롯 수와 유효 S1F 첫 묶음 라벨 수는 다른 개념이다. 슬롯 0개인 행은 2,493두, 1–9개는 17,730두, 10개는 31,932두다. 유효 라벨 수가 0인 말은 2,511두, 3개 이상인 말은 45,058두다. n=0은 수축값 q=1/3과 관측 지원 0을 함께 보존하며 후미 성향으로 해석하지 않는다.

구현 산식은 q=(m·n+1)/(n+3), n=0이면 1/3이다. 번호가 더 작은 말 전체와 더 큰 말 전체를 각각 모으며, 인접은 번호 차이 1만 쓴다. 취소 번호를 압축하지 않고 자기 말은 제외한다. 상대가 실재하지만 과거 라벨이 없으면 q=1/3 및 support=false로 유지한다. 모든 집계는 같은 S40 경주 명단 안에서만 이루어진다.

공개·정정 시각이 검증되지 않아 T−2는 사건일 기준 경계이지 실제 사전 가용성 증명은 아니다. 첫 묶음 라벨은 단독 선두, 물리적 경합, 전술 유형과 다르며, 번호와 실제 게이트 위치의 일치도 확인하지 않았다. 따라서 q 및 상호작용은 모델 입력 공변량이며 현재 경주 선행 확률이나 동시 경합 사건 확률이 아니다.
