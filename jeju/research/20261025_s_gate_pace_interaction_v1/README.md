## 무엇을 경합 정보로 넣었나

같은 말의 T−730일..T−2일(포함) 최근 최대10개 실제 출전 슬롯에서, 확인된 S1F 첫 묶음 진입 빈도 m과 유효 관측수 n을 사용했다. `q=(m*n+1)/(n+3)`이며 n=0이면 명시 prior1/3이다. q는 과거 성향 수축값이며 이번 경주에 보정된 선행 확률이 아니다.

| 새 모델 변수 | 의미 |
|---|---|
| 자기 초반 성향 | q_i |
| 자기 관측 지원량 | n_i/10; 최대10슬롯 대비 유효 라벨수 |
| 안쪽 상호작용 | q_i × 안쪽 상대 q 합 |
| 바깥쪽 상호작용 | q_i × 바깥쪽 상대 q 합 |
| 바로 안쪽 상호작용 | q_i × 번호가 정확히1 작은 상대 q |
| 바로 바깥쪽 상호작용 | q_i × 번호가 정확히1 큰 상대 q |
| 상대 이력 지원 비율 | 자기 제외, 유효 관측이 있는 상대의 비율 |

5번 말 기준으로 상대가4번이면 안쪽·인접 안쪽에 모두 반영되고,2번이면 안쪽에만 반영된다.6번이면 바깥쪽·인접 바깥쪽에 반영된다. 번호가 비었으면 압축하지 않고 해당 인접 기여는0이다. 이력이 없는 실제 상대는 q=1/3과 관측 지원량으로 구분한다. 자기 말은 모든 상대 집계에서 제외했다. 곱은 학습용 상호작용 값이며 동시 선행 사건확률이 아니다.

**이 실험은 번호 배치와 과거 초반성향에 의한 경합 압박의 대용변수를 추가한 비교다.** 첫 묶음에는 여러 말이 들어올 수 있으며 실제 진로 충돌·기수 의도·속도·에너지 소모의 관측 정답은 제공하지 않는다. 실제 출발칸과 출주번호 대응도 미확인이다.

3개 G 모델 모두 새7개 변수를 실제 트리 분기에 사용했다. 인접 안쪽 변수는 연도별20/19/17회, 인접 바깥쪽은19/29/26회 분기에 사용됐다. 이 빈도/중요도를 개별 변수의 인과효과나 독립적인 성능 개선 증거로 해석하지 않는다.
