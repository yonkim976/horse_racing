# 제주 기수 특성 연구의 자료 지원과 비교 방법

기수의 성적, 좋은말 배정, 말의 과거능력을 고려한 추가 기여, 말과의 호흡, 전개 특성을 연구할 보유자료가 있다. 다만 **기수만의 순수 능력을 정확하게 분리한 점수는 현재 관측자료만으로 보장할 수 없다.** 이번 단계는 기수별 순위 산출이 아니라 자료 지원과 연구 설계를 확인했다.

이전 [각질·선행형 편성 연구](../20261009_style_leader_density_v1/README.md)는 현재 결론으로 보존하고 추후 재개한다. 기수 연구에 그 탐색결과를 확정 각질 보너스로 넣지 않는다.

## 확인한 보유자료

정상완주·전두수 선정 자료2017-01-13~2026-09-19의52,155출전·5,206경주·2,813두를 기존 중량 원천과 T−2 피처에 일대일 연결했다. 공식 기수ID가40명이며 해당 표본에서 결측·0ID가 없다.2026년 부분연도에는4,673출전·488경주·기수23명이 관측됐다. 현재 등록기수 전체 명단과는 다르다.

| 비교 지원 | 전체기간 | 2024~2025 | 2026년9월19일까지 |
| --- | ---: | ---: | ---: |
| 관측 기수 | 40 | 29 | 23 |
| 해당기간100출전 이상 기수 | 38 | 26 | 17 |
| 둘 이상 기수가 탄 말 | 2,317 | 960 | 588 |
| 말×기수5회 이상 조합 | 3,427 | 792 | 247 |
| 같은말·같은거리2~60일 비교쌍 | 31,320 | 7,696 | 2,487 |
| 이 중 기수가 달라진 비교쌍 | 13,533 | 3,201 | 974 |
| 부담차1kg·함수율차3%p 이내인 기수변경쌍 | 3,572 | 858 | 242 |

직전 비교는 **직전 같은거리의 분석 대상 관측**이며 다른거리 출전이나 선정 외 경주가 중간에 있을 수 있다. 임의의 두 기록을 모두 조합한 숫자가 아니다. 한 말이 여러 쌍에 반복되므로 독립 실험 횟수로 해석하지 않는다. 비슷한 부담·함수율은 같은 컨디션·편성·기수교체 이유를 뜻하지 않는다.

말×기수 연결망은 전체2,813두·40명이 하나의 연결 성분이다. 동일말을 매개로 기수 간 비교를 시도할 기반은 있지만 기승 배정의 무작위성·인과 식별이나 기수별 모든 거리의 충분한 표본을 보장하지 않는다. [기수별 출전 지원](audit01/jockey_support.csv), [기간별 지원](audit01/period_support.csv), [교체쌍 지원](audit01/pair_support.csv), [연결망](audit01/connectivity.json).

## 구분해서 확인할 다섯 가지

| 질문 | 비교할 데이터 | 해석 기준 |
| --- | --- | --- |
| 좋은 말을 많이 타는가 | 경주 전 말의 기록·반복성·등급·상대구성으로 예상 수행을 정하고 기수별 배정 분포를 비교 | 현재 입상한 말을 사후에 좋은말로 정의하지 않음 |
| 같은 수준 말에서 더 잘 타는가 | 실제 기록·경주 내 상대기록과 사전 예상의 차이, 같은말·거리 기수교체, 말·경주 조건을 함께 고려한 기수 효과 | 원시 승률과 기수의 추가 기여를 구분 |
| 어떤 전개에 강한가 | 말의 사전 위치 성향·초반속도,게이트,상대 선행 구성에 비해 실제 S1F 집단·위치와 후반 전진·구간기록이 어떻게 달라지는가 | 말의 원래 성향을 기수 취향으로 부르지 않음 |
| 어떤 조건에서 강한가 | 거리·주로·부담·사전 각질별 추가 기여 | 반복되는 조건만 제한해서 비교하고 작은 셀은 축소 추정 또는 보류 |
| 특정 말과 호흡이 좋은가 | 말 효과+기수 효과로 설명한 기대값에 말×기수 조합이 추가로 얼마나 기여하는가 | 조합의 높은 원시 입상률이 곧 호흡의 증거는 아님 |

## 첫 연구의 구체적 순서

1. **좋은말 배정부터 확인한다.** 말의 과거기록·반복성·최근변화·같은거리 수행·상대구성으로 기수 정보 없는 사전 기대치를 만든다. 강한 말·보통 말·약한 말의 기수별 배정 비율과 기대 수행 분포를 확인한다. 말의 과거기록에도 과거 기수 영향이 들어 있으므로 완전히 순수한 말 능력으로 이름 붙이지 않는다.
2. **기수의 추가 기여를 추정한다.** 현재 질문에 적합하게 기대기록 대비 실제기록 오차를 먼저 보고, 입상·승률 대비 초과 성과를 보조로 본다. 시간 단위 초와 입상률 단위%p를 섞지 않는다. 말·경주 또는 상대구성·거리·함수율·월·부담·최근수행·공백·가능하면 사건 당시 조교사 배정을 고려한다. 조교사ID 필드는 로컬 적재 코드에 존재하지만 이번 감사에서는 그 커버리지·연결을 새로 검증하지 않았으므로 다음 단계의 확인 항목이다.
3. **같은말 기수교체로 보강한다.** 같은거리·짧은 공백·비슷한 부담과 주로의 기수변경을 유지쌍과 함께 비교한다. 호전 말에 좋은 기수가 배정되거나 부진 말의 기수가 교체되는 선택 편향을 확인한다. 교체만으로 원인이 입증됐다고 하지 않는다.
4. **전개 특성과 조합을 분리한다.** 초반 위치 확보·앞선 유지·후반 전진·거리/각질 적합성의 조건별 결과를 보고 기수 주효과와 말×기수 추가 효과를 나눈다. 기승 수가 적은 셀은 평균으로 축소하고 불확실성을 표시한다. 미래 결과가 각질 분류에 들어가지 않게 T−2 이력을 유지한다.
5. **후속기간에서 확인한다.** 먼저 이전기간으로 기준과 추정치를 고정하고2024~2025 및2026 부분연도에 기록오차·확률 품질·기수 효과 방향이 유지되는지 비교한다. 이미 여러 번 쓴 자료이므로 후향 개발 비교라고 표시하고 새로운 독립검증으로 부르지 않는다.

최종 기수표의 후보 항목은 기승말 기대능력 분포·원시 성적·기대 대비 추가기록/입상 기여·조건별 강점·말×기수 호흡·최근 변화·출전수·군집구간이다. 한 줄 총점으로 배정·특성·능력을 합치지 않는다. 현재 화면이나 배당·인기·영상·새 외부수집을 필수로 요구하지 않는다.

## 확인할 수 없는 범위와 측정 한계

기수 배정은 무작위가 아니며, 건강·컨디션·조교 변화·교체 이유·지시·주행방해를 전부 관측하지 못한다. 기록을 고려한 추정치도 남은 차이가 모두 기수 때문이라고 보장하지 않는다. 특히 기수×말×조교사가 거의 고정된 영역에서는 분리가 약해진다.

통과조는 집단별 순위범위다. 같은집단 내외측 표기를 개별착순 또는 경주 전체 주행경로로 바꾸지 않는다. 영상 없이 안쪽 공략·진로 선택·막힘 회피·추진 동작·승부 의도를 확정할 수 없다. 여기서의 특성은 **조건을 고려한 관측 전개 성향**이다. G3F는막판600m 시간으로 취급하며 통과조가 아니다.1300m는 사용자 정정 출발→2C→S1F 계약을 유지한다.

현재 정상완주 표본은 완주 후 선정이며 취소·실격·주행중지·사고 대응 능력이나 안전 관련 특성을 평가할 모집단이 아니다. 그런 질문은 별도 자료와 선정 계약이 필요하다.2026년은9월19일까지이며 현역기수 전체를 대표하지 않는다.
