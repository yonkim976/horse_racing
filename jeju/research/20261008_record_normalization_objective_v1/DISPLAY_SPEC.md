# 제주 환산 기록의 표시 기준

사용자는 한 경주의 원기록과 조건별 조정 내역, 같은 거리의 기준 조건으로 환산한 시간을 함께 확인한다. 기본 기준은 건조·연중 평균 월 효과이며, 기준과 다른 목표 조건을 제공하면 그 조건을 명시한다.

## 표시 항목

| 항목 | 표시 내용 |
|---|---|
| 원기록 | 공식 전체 완주시간과 원천 경주 |
| 당시 조건 | 정확 거리·날짜·함수율 숫자와 상태 |
| 환산 기준 | 같은 거리·기준 함수율 조건·월 기준 |
| 함수율 조정 | 원기록에 실제 더하거나 빼는 초 |
| 월 조정 | 원기록에 실제 더하거나 빼는 초 |
| 환산기록 | 원기록에 두 조정을 더한 결과 |
| 추정 범위 | 합계 보정의 불확실성 구간. 개별 경기의 실제 반사실 시간 보장 범위와 구분 |
| 근거 | 경주수·경주일수·기간·계수 버전·제한표본 여부 |

## 가상 계산 예시

아래 수치는 표시 방식만 설명하며 실제 제주 추정값이나 채택값이 아니다. 같은 거리의 기준 조건보다 함수율은 0.30초 빠르게, 월은 0.10초 느리게 작용했다고 추정한 경우다.

| 항목 | 예시 |
|---|---:|
| 원기록 | 80.00초 |
| 함수율 조정 | +0.30초 |
| 월 조정 | −0.10초 |
| 기준 조건 환산 기록 | **80.20초** |

기준 조건으로 바꿔 비교하면 약 80.20초에 해당한다는 추정이다. 향후 해당 말의 기록이나 입상 확률을 뜻하지 않는다. 실제 표에는 가상 수치 대신 거리별 검증을 거친 값과 근거를 넣는다.

## 저장과 계산의 구분

원기록은 보존한다. 환경모형이 추정한 효과초와 축소 적용률, 실제 조정초를 별도 저장한다. 빠른 환경의 추정효과가 −0.30초이고 적용률100%라면 사용자에게 보여주는 조정은 +0.30초다. 적용률50%라면 실제 조정은 +0.15초다. 미추정 효과를 추정0초라고 표시하지 않는다.

계산은 반올림 전 정밀도로 합산하고, 화면의 표시 정밀도는 원천 기록의 분해능과 추정 불확실성에 맞춘다. 두 자리 소수의 가상 예시는 실제 정확도가 0.01초라는 주장이 아니다.
