# 제주 운영 모델과 새 기준선의 같은 경주 비교

현재 보존된 예측을 같은 467경주에 맞추면 운영 모델 HY_R_FORM이 J0와 R1보다 입상확률·상위 후보·6조합에서 앞선다. R1은 J0보다 확률 평가가 좋아진 연구 후보지만 운영 모델을 대체할 단계는 아니다. 운영 모델·등록 설정·DB를 변경하지 않았다.

## 비교 대상과 기간

2026년 1월 2일~9월 12일, 70경주일·467경주·4,475출전이다. 2026년은 부분연도다. 날짜·경주번호로 연결한 뒤 말ID 전체집합, 출발번호, 거리, 말별 Top3 정답까지 일치하는 경주만 사용했다. 일치 대상에서 말이나 경주를 성능에 따라 추가로 선별하지 않았다.

운영 모델의 기존 저장 평가 510경주 중 43경주는 새 기준선의 완전 정상 착순·유효 전체시간 조건에서 제외돼 공통 비교에 들어오지 않는다. 새 모델 488경주 중 나머지 21경주는 9월 17~19일로 운영 저장 평가 상한 이후다. 공통 기간의 말집합·정답·번호·거리 불일치 경주는 0이다. 이 표본은 실전의 모든 편성을 대표하지 않는 회고적 정상 편성 부분집합이다.

## 같은 467경주 결과

확률 손실은 경주마다 출전마의 평균을 구한 뒤 경주 균등 평균이다. 한 마리 입상은 최고점 1두의 Top3 적중, 상위5두 전부는 실제 입상마 3두가 상위5두 안에 모두 포함되는 경주 비율이다.

| 지표 | 운영 HY_R_FORM | J0 13열 | R1 21열 |
|---|---:|---:|---:|
| 입상확률 log loss ↓ | 0.555417 | 0.592488 | 0.584759 |
| 입상확률 Brier ↓ | 0.187645 | 0.202563 | 0.199224 |
| 한 마리 입상 | 285/467 · 61.03% | 236/467 · 50.54% | 254/467 · 54.39% |
| 상위3두 정확 집합 | 28/467 · 6.00% | 22/467 · 4.71% | 19/467 · 4.07% |
| 상위5두 입상마 포함 비율 | 75.02% | 65.38% | 67.02% |
| 상위5두 입상마 전부 포함 | 182/467 · 38.97% | 125/467 · 26.77% | 122/467 · 26.12% |
| 분포 상위6개 삼복승 조합 적중 | 144/467 · 30.84% | 100/467 · 21.41% | 100/467 · 21.41% |

상위6개 조합은 **각 모델이 보존한 세 마리 집합 확률 전체에서 확률이 높은 서로 다른 집합 최대6개를 선택한 비교용 재구성**이다. 상위5두 안으로 조합을 제한하지 않았다. 과거 운영 게시물에서 실제 추천한 6개 조합의 실적이나 수익률은 아니다. HY_R_FORM은 원래 PL 집합 분포를 사용하고 J0·R1은 원래 점수합 집합 분포를 유지했다. 새 공통 분포로 재보정하지 않았다. HY_R_FORM의 순서 모델은 집합 내 순서만 바꾸므로 이번 삼복승·Top3 주변확률 비교에는 영향을 주지 않는다.

## 차이의 불확실성

R1−운영 모델 차이, 70경주일 대응 bootstrap 5,000회·seed20261009, 95% 점별 구간이다. 여러 지표를 동시에 보정한 구간이나 새로운 독립 검증이 아니다.

| 지표 | R1−운영 | 95% 구간 |
|---|---:|---:|
| Brier | +0.011579 | +0.007978~+0.015120 |
| log loss | +0.029342 | +0.020507~+0.038013 |
| 한 마리 입상 %p | −6.64 | −10.84~−2.35 |
| 상위3두 정확 집합 %p | −1.93 | −4.56~+0.61 |

| 6조합 적중 %p | −9.42 | −13.97~−4.71 |

운영 모델 우위가 확률과 후보·6조합에서 관찰되며 해당 차이 구간은 0을 포함하지 않는다. 상위3두 단일 집합 차이는 구간이 0을 포함한다. 정확한 1·2·3위 순서는 J0·R1에 별도 순서 모델이 없어 비교하지 않았다.

## 모델의 범위와 해석

운영 모델은 선택 입력108열과 순서 입력68열을 가진 하이브리드다. 전체·거리별 Elo와 불확실성, 전체·구간 기록, 상대 능력과 선행 경쟁, 출발번호, 부담중량과 변화, 기수·조교사 및 말과 기수의 과거 성적, 조교·주행심사·과거 체중과 상태 등의 정보를 포함한다. 모든 입력이 각각 검증돼 성능을 높였다는 뜻은 아니다.

J0는 원기록의 최근 동일거리 수행·경력·출전간격·기본 조건 중심의13열, R1은 여기에 자기 제외 상대 기록·관측수·순위8열을 추가한21열이다. 현재의 상대 편성을 일부 고려하지만 운영 모델의 전개 경쟁·기수·현재 중량 등 전체 정보를 구현한 것은 아니다.

학습 분할도 다르다. 운영 모델은 2018-08-31~2025-06-28 학습, 2025-07-04~09-27 종료 선택, 2025-10-02~12-27 확률 보정이다. 새 모델은 2017~2023 최초 학습, 2024 종료 선택 및 합쳐 재학습, 2025 확률 보정이다. 따라서 현재 저장된 완성 모델 간 비교이며 입력 변수 하나의 순수 기여나 같은 학습 조건에서의 알고리즘 우위 실험이 아니다.

양쪽 모두 이전 경주 이력을 T−2까지 갱신하는 회고 평가다. 원천 스냅샷과 수집·정정 이력이 다르고 과거 출마표 최초 공개/수정 시각의 완전한 증빙은 없다. 이 비교를 수요일 실제 운영 성적이라고 부르지 않는다. 2026년은 기존 연구에서 이미 평가에 사용한 기간으로, 새 독립 평가라고 주장하지 않는다.

## 다음 개발에 적용할 기준

운영 HY_R_FORM을 비교 기준으로 계속 유지한다. J0·R1에는 부담중량, 기수, 거리별 게이트와 전개를 묶음별로 추가하고 바로 이전 기준선과 운영 모델을 함께 비교한다. 같은 학습·보정 분할에서도 비교해야 정보의 추가 기여를 구분할 수 있다. 환경 기록 보정은 별도 검증을 통과한 경우에만 더한다. 관찰 연관이나 예전 계수를 고정 가감으로 넣지 않는다.

이번 비교로 새 모델을 운영에 승격하지 않는다. 새 모델의 장점은 능력 평가표와 각 입력의 근거를 추적하며 쌓는 개발 구조에 있고, 현재 예측 성능이 운영 모델보다 좋다는 근거는 확보하지 못했다.
