# 제주마 편성 대비 상대능력 추가 비교

R1은 전체 확률 손실의 사전 유지 기준을 충족했다. 확률 평가의 연구 기준선 후보로 유지하고 J0는 후보·조합 성능의 대조군으로 함께 보존한다. 기존 J0와 동일한2024~2026년9월19일의1,779경주·17,412출전으로 비교했다. 2026년은 부분연도이며 이미 본 자료의 후향 개발 비교다.

이번 결과에서 전체 확률 손실은 개선됐지만 상위5두 전부 포함률과 6조합 적중률의 점추정은 낮아졌고 차이 구간은0을 포함했다. 후보·조합 개선으로 설명하지 않으며 모든 목표에 우월한 모델로 확정하지 않는다. 2024년에는 확률 손실도 나빠지는 점추정이었고2025·2026년에는 개선돼 연도별 차이가 남는다.

J0 13열에 자기 제외 상대 기록수·가용률·중앙값·기록 차이·빠른 상대 수·순위분율의8열을 추가한 R1 21열이다. 기록 없는 상대를 느린 말이나0초로 채우지 않았고 자기 기록이 없으면 능력 차이는NULL이다. 원기록 비교이며 환경 보정된 순수 능력이 아니다.

관측 출전 이력 0인 661출전에서 J0 Brier 0.222048 → R1 0.216954, 차이 -0.005095(날짜95% -0.009287~-0.001114)였다. 평균 예측은 26.31% → 29.49%, 실제 입상 비율은 31.62%다. 이는 runner 균등 하위군이며 전체 경주 균등 지표와 가중 방식이 다르다. 관측 이력 0은 공식 신마 판정이 아니다. 같은 무이력 집단의 기존 균등 확률 Brier는0.216334로, R1이 J0보다 개선됐어도 균등보다 낮은 오차를 확보한 것은 아니다. 무이력 평가가 해결됐다고 설명하지 않는다.
