# 출발조교 동일 중복 독립 재검산

검토일: 2026-10-01

사용자 지정 GPT-6 Luna xhigh 서브에이전트가 별도 계산으로 원문 출발조교 311페이지의 모든 item을 읽고 재검산했다. 전체 필드와 JSON 값의 형식·값을 보존하는 정렬 JSON 비교를 사용했다. 검토 중 파일·DB 변경과 API 호출은 하지 않았다.

주 에이전트의 [전수 감사 결과](audit_summary.json)와 다음 수치가 일치했다.

- 원문 295,471행, 완전 동일 그룹 4,205개, 모든 그룹 두 번 출현.
- 같은 페이지 안 4,199그룹, 서로 다른 페이지에 걸친 6그룹. 경계 6그룹은 모두 인접 페이지 마지막 item 1,000과 다음 페이지 첫 item 1에 있다.
- 비어 있지 않은 응답 페이지 전체 SHA 반복 0. 2002년부터 2006년까지의 정상 0행 응답은 같은 응답 해시를 가지며 데이터 행 중복으로 세지 않는다.
- 최신 프로필 4,617개 ID에 연결되는 말 4,476두. 동일 추가 반복 3,299행, 영향 제주마 1,536두. 전체 원문 중 영향 말 ID는 2,079개다.
- 말 ID와 날짜가 같은 반복 그룹은 7,291개, 추가행은 7,297행이다. 7,288그룹은 두 행, 3그룹은 네 행이다.
- 내용이 다른 말·날짜 조합 3,092개는 모두 서로 다른 내용 두 개씩이다. 차이 필드는 기승자명 2,678개, 기승자명과 비고 159개, 비고 230개, 조와 순번 24개, 조 1개다.

별도 훈련 회차인지, 정정 또는 재노출인지에 관한 원인은 이번 계산으로 확정하지 않았다. 원문 수량과 실제 시행 횟수를 구분하고 완전 동일 중복과 다른 내용을 가진 말·날짜 조합을 별도로 유지해야 한다는 결론이 일치했다.

서브에이전트의 검토 범위는 API22 출발조교다. 일별조교 API18에서 확인한 `hrNo='018570 '` 세 행은 이 독립 검토의 대상이 아니며, 주 에이전트 [별도 원장](invalid_raw_training_ids.jsonl)에 기록돼 있다.
