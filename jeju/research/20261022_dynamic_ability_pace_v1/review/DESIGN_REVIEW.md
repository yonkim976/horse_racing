# 독립 설계·구현 검토

검토일 2026-10-22. 최종 계약 [`supervisor/DESIGN_CONTRACT.md`](../supervisor/DESIGN_CONTRACT.md), 원천 감사 [`audit/SOURCE_REVIEW.md`](../audit/SOURCE_REVIEW.md)와 manifest, 이전 공동승식 기준선의 규칙·평가 계약을 검토했다. 새 모델 적합, 예측 생성, 결과 지표 계산은 하지 않았다. 이 문서는 코드 리뷰의 진행 기록이며, **현재 구현 승인이나 적합 승인 영수증이 아니다.**

## 설계 판정

최종 계약은 독립적인 원점수 비교 A−R와 동결 A에 대한 2상태 혼합 B−A를 분리하고, 결과 확인 뒤 후보·규제를 고르는 경로를 두지 않는다. 앞선 설계 검토에서 제기한 가장 큰 모집단 문제는 수정됐다. 이제 세 phase head의 학습·보정 라벨 표본이 A/B의 5,206개 정상·완전·고유순위 경주와 같고, 5,693개 starter 자료는 검증된 과거 phase 이력 공급에만 쓰인다. 따라서 B의 `q=P(Z=1|X)`와 관측 Z 조건부 전문가가 같은 선택 모집단을 대상으로 한다.

시간 분할도 코드가 그대로 구현한다면 논리적으로 적합하다. 빈티지 `c`의 학습 결과는 `c−2`년까지, 보정 라벨은 `c−1`년, 예측은 `c`년으로 분리한다. B 학습에 넣는 A/phase 출력은 각 행의 이전 빈티지 산출물이어야 하며, Y년 B 보정 입력의 A/phase 적합·보정도 계약의 `≤Y−3`·`Y−2` 경계를 따라야 한다. 같은 날짜 경주끼리 과거 업데이트를 주고받으면 안 된다. 저장된 날짜 컷오프는 공개 시각 증명이 아니며, 연구는 최종 실제 출전집합에 조건부인 후향적 순위 실험이다. 이 해석과 2024–2026-09-19 평가기간의 반복 사용 제한이 계약에 분명히 적혀 있다.

`Q_B=(1-q)PL(u(0)/T_B)+qPL(u(1)/T_B)`는 같은 전체 starter set의 정규화된 순차 Top3 분포 두 개의 볼록혼합이므로 자체 합은 1이다. 실제 평가 코드에서는 각 PL arm의 합, 혼합 Q의 합, runner WIN/Top2/Top3 주변합과 7승식 사건 합·연결관계를 독립 계산으로 확인해야 한다. 네 개 γ는 관측 학습 Z에 조건부한 full-field 순위 우도에서 적합하고, 예측에는 target Z 대신 별도 예측 q를 섞는다. 이는 `P(Z|X)P(Y|Z,X)`라는 예측 분해로 이해할 수 있으며 그 자체로 label leakage나 인과 매개효과 추정은 아니다. 계약이 밝힌 대로 초기팩 수는 관측 사건이고 인과적 페이스 압력은 아니며, 분산·지원량 요약도 베이지안 상태 불확실성을 나타내지 않는다.

다만 시간 경주 난도와 말의 절대 능력을 인과적으로 분리하지는 않는다. 경주 내 순위 PL likelihood는 모든 주자에게 같은 값을 더해도 변하지 않는다. 제안된 rank/margin 이력은 선택된 정상완주 자료의 축약 통계이며, `margin`도 같은 과거 경주 내 상대시간이지 거리·주로 효과를 제거한 물리 속도가 아니다. 최종 계약의 좁은 주장 범위는 이 점과 일치한다.

## 승식·확률·분모 계약의 계승

이 연구는 [`rules_contract/README.md`](../../20261022_joint_wager_baseline_v1/rules_contract/README.md)와 JSON 계약을 그대로 계승한다. 규칙 JSON SHA-256은 `20cd4b17274018a36efbb1b0cea64eb5d5c9809ed5f3481bea59c734f99fee83`이다. 현행 한국마사회법 시행규칙 제4조의 승식 사건·최소 출주수와 2024-06-21 시행일은 [직접 조문](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=122175), [현행 전체 규칙](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=263295)으로 고정된다. 해당 규칙 원문·연혁, 별표, KRA 안내의 접근 기록은 이전 규칙 계약에 있다. 공식 전수 완료·판매·정산을 이번 코호트가 재현했다는 뜻은 아니다.

사건 정의는 하나의 `Q(i,j,k)`에서 만든다. WIN은 1위, PLC는 발매 개시 5–7두면 Top2·8두 이상이면 Top3, QNL은 1·2위 무순위쌍, EXA는 정확한 1→2위, QPL은 Top3 안의 무순위쌍, TLA는 정확한 Top3 무순위 세트, TRI는 정확한 순서 1→2→3이다. PLC 분기 수가 미관측인 실제 7두 36경주는 PLC만 unknown으로 제외하며, 나머지 6승식은 포함한다. 따라서 primary 분모는 비-PLC 각 1,779, PLC 1,743이다. 실제 출주수 ≥8은 발매 개시 출주명단의 부분집합이라는 하한 전제일 뿐이며, 발매 개시 두수의 관측·판매/정산 증거로 확대하지 않는다. QPL은 5–7두 경주를 PLC 사유만으로 빼지 않는다.

단일 적중 티켓 공간 WIN/QNL/EXA/TLA/TRI에는 categorical NLL과 모든 티켓의 sum-Brier를, 복수 적중 가능 PLC/QPL에는 티켓별 binary log loss와 Brier를 경주 안에서 평균한 다음 경주 균등 평균을 적용한다. PLC 이벤트 확률 총합은 Top2일 때 2, Top3일 때 3이고 QPL 총합은 3이다. 이 이벤트들은 서로 배타적이지 않으므로 합을 1로 재정규화하지 않는다. 동일 Q에서 QNL/EXA, QPL/TLA, runner 주변합의 관계도 확인한다. 취소·불성립·동착·실격·주행중지 정산은 기존 원장 규칙대로 확인된 근거만 반영하고, 구조적 strict Top3 평가를 실제 마권 환급 시뮬레이션으로 부르지 않는다.

날짜 bootstrap은 고정 자산 [`date_bootstrap_schedule.npy`](../../20261011_pair_top3_direct_v1/outputs/date_bootstrap_schedule.npy), SHA-256 `d141b0c3f9a463cbfc9d1f4c61228b58757c31aee4ec74b79f41c5baeadaccbd` (2,000 × 269)를 사용한다. 실행 전 실제 파일 해시·날짜 정렬을 재검증해야 한다. 이 paired date interval은 고정된 학습·보정 예측 조건에서의 평가날짜 변동을 반영하며 학습·상태 추정 불확실성을 포함하지 않는다. 기존 기준 연구의 고정 `T=1.1837152381349905`는 별개다. 새 R은 계약대로 매 평가연도 직전년 raw OOS score로 보정한 **rolling-T 기준선**이고, 예전 COMMON-T 결과로 오인하거나 라벨을 바꾸지 않는다.

보조 축 지표의 1,023/1,779은 기존 `20261020_axis_selector_v1/README.md`에서 F1 raw-score 1위 말의 Top3 적중수다. 단일 PL 분포의 WIN 주변확률은 점수에 단조 증가하므로 이 수는 rolling-T R의 최대-P_WIN 말 선택과 일치해야 한다. 계약의 10%는 상대 개선이므로 같은 1,779 경주에서 최소 1,126회 적중이 필요하다. 최종 비교에서는 R의 실제 선택과 count를 다시 대조하고, 각 arm은 Q에서 얻은 P_WIN 최댓값을 선택해야 한다. 이는 보조지표이고 과거 기간의 점추정만으로 10% 참 개선을 주장할 수 없다.

법령 연혁도 과대 일반화하지 않는다. 기존 계약이 직접 확인한 1995년 역사본에서는 PLC 5–7/8+ 분기가 확인되며, 현재 규칙에는 2013·2020·2021 개정 이력이 표시된다. 모든 조문 세부가 모든 2019–2023 경주에서 동일하게 적용됐다는 판매·정산 증거는 아니다. 발매 시 출전마와 실제 출전마 불일치 관련 법 제10조 조항은 2023-03-28 시행이므로 앞선 연도에 소급 적용하지 않는다. 취소, 무효, 동착, 순위변경, DQ, 미완주는 공식 상태가 확인된 만큼만 반영하고 원시 상태값만으로 의미를 추정하지 않는다.

시장 비교는 이번 설계의 범위 밖이다. 최종 배당을 이용한 `pD−1`은 사후 가격의 기대 순수익 대용치일 뿐 실제 구매 전 ROI가 아니며, 이번 연구는 수익 분석을 하지 않는다. PLC/QPL처럼 티켓 사건이 서로 겹치는 승식은 배당 역수를 1로 정규화해도 결과 분포가 되지 않는다. 시장 비교를 재개한다면 같은 경주·사전 가격 시점·전체 티켓·동일 예산/조합 수를 맞춰야 한다.

## 구현 검토 상태

최종 코드와 입력의 정적 검토는 [최종 pre-fit review](FINAL_PREFIT_REVIEW.md)와 기계 판독 가능한 [review receipt](FINAL_PREFIT_REVIEW.json)에 기록했다. 현재 판정은 **PASS_PREFIT_STATIC_REVIEW**이며, source-preflight receipt는 최종 코드 bundle SHA를 고정하고 있다. 이는 구현 정적 검토만 통과했다는 뜻이다. 모델 적합 및 평가 실행 전에는 별도의 감독자 승인 영수증이 여전히 필요하다.
