# 제주 진료 공백 연도 및 dacom72 원문 감사

기준일: 2026-10-02. 이 검토는 API 공백 연도 재조회와 로컬 원문 보유 확인만 수행했다. 제주 DB나 다른 저장소 DB를 수정하지 않았고, TXT 행을 코어에 적재하지 않았다. 산출물은 `/private/tmp/jeju_medical_20261002/history_gap_review/`에 있다.

## 결론

- API16_1에서 기존 정상 0행이던 9개 연도를 다시 조회했다. 9개 모두 HTTP 200, `resultCode=00`, `totalCount=0`, 1페이지, 항목 0행이었다. 각 새 응답은 136바이트이고 SHA-256은 `640c1da4ea90e6ffd55e7d69b9fec7afe03bdbd1b82b8ed662db4442fd6e2e5d`다. 보유한 2026-09-29 응답과 9개 모두 바이트 단위로 일치한다. 재조회 자체가 과거 전체 자료 부재를 증명하지는 않는다.
- 로컬 `meet=2` dacom72에는 실제 날짜가 적힌 원문 행이 있다. API 공백 연도 중 2005–2007, 2009–2011은 본문 날짜 기준 원문 행이 확인돼 진료 이력 후보를 보완할 수 있다. 2002–2004는 파일과 본문 행이 없다.
- 이 TXT에는 공식 `hrNo` 필드가 없고, 전체 53,185행에서 공식 말 ID처럼 보이는 7자리 숫자 토큰도 발견하지 못했다. 따라서 코어 말과 직접 조인할 수 없다. 마명·날짜만으로 공식 ID를 만들어 연결하지 않는다.
- 이 단계에서 TXT는 적재하지 않는다. 원문 행의 위치와 해시는 추적할 수 있지만, 말 ID·품종·원래 공개 시각이 확인되지 않았다. Thoroughbred의 행 파서나 미확인 접두어 규칙도 적용하지 않았다.

## dacom72 보유 현황

보유 위치는 `data/raw/kra_text/dacom72/meet=2/`이며, 파일 이름은 `<YYYYMMDD>dacom72.rpt` 형태다. 기존 다운로드 원장에는 1,150개 파일이 모두 `downloaded`로 기록되고, 빈 응답과 HTML payload는 0개다. 파일 날짜 범위는 2005-11-03~2026-09-09다. 이 파일들은 Thoroughbred medical-v1 source parquet에 들어 있지 않다. 해당 처리 결과는 meet 1과 3만 포함하고 meet 2를 제외했다.

gap 연도별 파일 경로 연도 집계와, 파일 내용의 날짜 접두어를 별도로 집계했다. 행 수는 이벤트 횟수나 독립 진료 횟수로 해석하지 않는다.

전체 meet=2 파일은 1,150개, 53,185개 물리 행, 7,819,690바이트다. 원시 바이트에서 날짜 접두어 `YYYY.MM.DD`만 확인했으며 모든 행에서 유효한 날짜로 판독됐다. 전체 파일 CP949 엄격 디코딩 오류와 탭 행은 0건이다. 행의 바이트 길이는 145바이트 51,690개, 146바이트 1,495개였다.

파일 기준 날짜와 본문 이벤트 날짜는 다르다. 예를 들어 `20051103dacom72.rpt` 첫 행의 본문 날짜는 `2005.10.31`이고, `20060101dacom72.rpt`에는 본문 날짜 `2005.12.29`인 행이 있다. 파일이나 다운로드 시각을 사건일 또는 당시 공개 시각으로 간주할 수 없다.

원문 예시(공백 패딩을 포함한 전체 첫 행):

```text
2005.10.31 갈색추억          18 제주부속동물 봉와직염
```

이 샘플에서 날짜와 진료명처럼 보이는 텍스트는 확인된다. 가운데 숫자와 열 경계의 의미는 이번 검토에서 확정하지 않았다. 전체 파일은 탭 구분표가 아니며, 이 검토는 필드 위치 파서나 진단 사전을 적용하지 않았다.

## 코어 연결 및 사용 전제

TXT는 API의 `illName1`·`illName2` 두 칸과 달리 하나의 결합 텍스트 행을 보인다. 형식·필드 경계와 코드 의미를 별도 검증해야 한다. 말 ID는 원문에 없으므로 공식 ID 연결은 현 단계에서 불가능하다. 마명·날짜 비교는 후보 단서일 뿐이며, 코어 ID로 승격하려면 독립적인 공식 식별 근거가 필요하다. 원문 행을 보존한다면 파일 상대경로·전체 파일 SHA-256·물리 행 번호·원행 해시를 provenance로 유지하고 말 ID는 NULL로 둔다.

`meet=2`는 제주 경주장 조회 범위를 뜻하며 개별 말의 역사적 품종을 증명하지 않는다. 진료일과 실제 공개 시각은 구분되어야 하며, 본문에 날짜만 있는 행은 경주 예측 시점에서 이용 가능했는지 확인되지 않았다. API33 dictionary의 Thoroughbred phrase mapping, 과거 358개 접두어 문맥 규칙, Thoroughbred fixed-width offsets는 이 TXT에 적용하지 않았다.
