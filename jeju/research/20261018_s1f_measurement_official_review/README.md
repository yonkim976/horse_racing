# 제주 1110m S1F 공식 측정거리 확인

확인일: 2026-10-18 KST. **1110m 경주의 S1F는 출발 후 210m 지점이다.** 같은 예외가 1610m 경주에도 적용된다.

## 직접 확인한 공식 근거

한국마사회 [제주 경주성적표 용어해설](https://race.kra.co.kr/raceScore/scoretableLayerExplanation.do?meet=2)의 `구간별 통과순위` 설명:

> S1F : 출발지점에서 200m 지점(단, 1110m 경주와 1610m 경주에 한하여 210m 지점)

이 문구는 S1F 지점의 거리별 예외를 직접 명시한다. [제주 오늘의 경주 보는 법](https://race.kra.co.kr/down/pdf/raceView_jeju.pdf)의 ‘최초 200m’라는 일반 설명만으로 이 예외를 제외하지 않는다.

| 항목 | 해석 |
|---|---|
| 1110m·1610m 경주의 말별 S1F | 출발선 → 210m 지점 |
| 그 외 경주의 S1F | 공식 설명의 기본 출발 후 200m 지점 |
| 말별 G1F | 결승선 전 200m → 결승선 |
| 말별 G3F | 마지막 600m 구간 |
| 3C·4C | 코너 지점의 누적 기록·통과순위. 공식 해설은 결승선 전 **약** 600m·400m라고 설명하므로 정확한 거리로 치환하지 않는다. |

## API6 펄롱타임과의 구분

10월 17일 5R의 경주 단위 API6/홈페이지 펄롱타임 표는 `110·310·510·710·910·1110m`의 통과거리와 그 사이 시간을 제공한다. 첫 110m 기록은 말별 S1F 210m 기록과 별개다. 이 표의 선두마 통과시간을 각 말의 S1F 또는 말별 200m 구간시간으로 대입하지 않는다. [앞선 실제 적재 보고서](../20261018_oct17_section_load/README.md)를 함께 읽는다.

이번 확인은 **측정거리 해석과 문서의 정정**이다. 저장된 시간·순위·API 원문·모델·DB 파일은 변경하지 않았다. 210m 시간에 200/210을 곱하는 등 환산값을 원 측정값으로 대체하지 않는다.

## 근거 보관과 이전 설명 정정

- `raw/scoretableLayerExplanation_meet2.html`: 공식 HTTP 200 원문, EUC-KR로 해독.
- `collection.json`: 공식 URL·조회 UTC 시각·크기·원문 SHA-256. 원문 SHA는 `3e36455ff78e3f43bd1f19be820eb7292895b209c590f49935d67d5292cb3854`다.
- 샌드박스 최초 요청은 DNS 해석 실패였고, 승인 검토를 거친 공식 HTTPS 읽기로 같은 URL의 원문을 확보했다.
- 앞선 대화의 ‘1110m S1F 210m 여부 미확정’ 설명은 이 공식 제주 전용 예외 조항 확인으로 정정한다. 과거 연구의 S1F 미확정 문구는 당시의 조사 상태이며 이 후속 확인이 우선한다.
- 독립 검증은 `verification.json`에 기록한다.
