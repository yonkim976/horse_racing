# 연구모델 축과 확정 단승배당 최저마의 입상 비교

2026-10-20. **주 비교는 현재 유지 중인 연구모델 F1_STYLE6이며, 최근 구간 상대기록 추가 후보는 보조 비교다.** 모든 적중은 해당 말의 최종 3위 이내 입상이다.

직전 비교와 같은 900·1000·1110·1200m, 2024~2026-09-19의 1,503경주·14,714출전에서 출전마 전체의 API4 `winOdds`를 확인했다. 최저 표시배당이 유일한 1,477경주를 주 표본으로 썼다. 표시배당 공동최저 26경주는 실제 단독 인기 1위를 확정할 수 없어 주 표본에서 분리했다. 2026년은 부분연도다.

## 현재 연구모델 결과

아래 입상률은 실제 결과로 집계한 비율이다.

| 구분 | 경주 수 | 모델축 입상 | 단승 최저배당마 입상 |
|---|---:|---:|---:|
| 전체 비교 | 1,477 | 850/1,477, 57.55% | 972/1,477, 65.81% |
| 같은 말 선택 | 799, 54.10% | 551/799, 68.96% | 같은 말이므로 동일 |
| 다른 말 선택 | 678, 45.90% | 299/678, 44.10% | 421/678, 62.09% |

서로 다른 말을 고른 678경주는 두 말이 함께 입상할 수도 있으므로 네 사건으로 나눴다.

| 다른 말 선택의 결과 | 경주 수 | 678경주 중 비율 |
|---|---:|---:|
| 두 말 모두 입상 | 173 | 25.52% |
| 모델축만 입상 | 126 | 18.58% |
| 단승 최저배당마만 입상 | 248 | 36.58% |
| 두 말 모두 입상 실패 | 131 | 19.32% |

현재 표본에서는 모델과 시장의 최종 평가가 일치한 말의 입상률이 68.96%였고, 서로 달랐을 때는 단승 최저배당마의 입상률이 모델축보다 높았다. 이는 사후 표본의 조건부 기술통계다.

## 모델 예측확률과 실제 입상률의 구분

같은 말을 골랐을 때 그 말에게 모델이 부여한 평균 Top3 확률은 61.06%, 실제 입상률은 68.96%였다. 서로 다른 말을 골랐을 때 모델축의 평균 예측확률은 53.90%, 실제 입상률은 44.10%였다. 그때 단승 최저배당마에 모델이 부여한 평균 확률은 39.91%였지만 실제 입상률은 62.09%였다. 전체 표본의 모델축 평균 예측확률 57.77%와 실제 57.55%가 가깝다는 사실만으로 이러한 하위 집단 차이가 사라지는 것은 아니다.

단승배당의 역수를 Top3 확률로 해석하지 않았다. 시장 축의 '입상확률'은 관측된 입상률이며 시장이 직접 제시한 Top3 확률이 아니다.

## 구간 상대기록 추가 후보와 동률 민감도

보류 중인 구간 추가 후보도 동일 1,477경주로 비교했다. 모델축 입상은 854/1,477(57.82%)이며, 단승 최저배당마는 같은 972/1,477(65.81%)이다. 같은 말 선택은 789경주(53.42%), 그 말의 입상은 539/789(68.31%)다. 다른 688경주는 둘 다 입상 184, 후보축만 입상 131, 단승 최저배당마만 입상 249, 둘 다 실패 124경주다. 후보는 여전히 채택 보류이며 이번 비교로 모델을 변경하지 않았다.

26개 공동최저 경주에서 낮은 마번을 대표로 정하는 보조 규칙을 적용하면 전체 1,503경주의 현재 모델축 입상은 861/1,503(57.29%), 시장 대표마는 988/1,503(65.74%)다. 같은 말 선택은 808경주, 그 말의 입상은 556/808(68.81%)다. 이 대표마가 공식 단독 인기 1위였다는 뜻은 아니며, 주 분석과 분모를 섞지 않는다.

## 독립 확인과 한계

Luna가 별도로 원천·집계를 만들고, 감독자는 [독립 코드](independent_compare.py)로 직접 재구성했다. 원천 범위 14,714행 모두 JSON 수치형 양수 `winOdds`(1.0~195.6)를 갖고 있으며, 원문 payload SHA는 기존 동결 스냅샷과 전부 일치했다. 현재 DB의 해당 경주 전체 실제 출전마 집합도 모델 출전마와 일치했다. 출전 ID·공식 말 ID·날짜·마번과 실제 착순을 대조했고 최고 모델 점수 동률은 낮은 마번 순으로 선택했다. 모델·평가·DB·운영 등록부를 수정하거나 재학습하지 않았다.

단승배당은 사후 경주결과 API의 확정 표시값이다. 이 가격·인기 순위가 실제 구매 시점에 확보 가능했음을 입증한 비교가 아니며, 수익률이나 새 미래 기간의 전략 검증도 아니다.
