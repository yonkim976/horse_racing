# 제주 추가 조건·시퀀스 감사 — 사전 고정 계획

작성일: 2026-10-09. 상태: **root 사전검토 승인; 최종 입력 preflight 후 기술통계 실행 가능**. 이 문서는 분석 결과가 아니다. root가 고정한 경계·불확실 상태 정의를 반영했다. 계산해도 새 모델을 학습하지 않으며 중앙 결론 모음·DB·운영모델·등록부를 수정하지 않는다.

## 질문과 기존 결과 경계

현재 운영 모델 `HY_R_FORM`, 저장 기준선 R1, 기존 52,155출전·5,206경주 원천을 보존한다. 분석 모집단은 `jeju/research/20261009_field_relative_ability_v1/outputs/features.parquet`의 기존 완전 정상 편성 표본이며, 현재 800·900·1000·1110·1200·1300·1400·1610m, 정상 착순 1~N, 6두 이상, 전 출전 양수 완주시간, 완전순위·공식 ID 연결 조건을 그대로 승계한다. 2017-01-13~2026-09-19, 2026년 부분연도다. 무이력과 조건 미관측 출전도 분모에 남긴다. 작은곰 ID 3005648은 제외 상태를 유지한다.

현재 조건 연구는 단일조건 16군, 정확 10두의 번호 조건 및 4개 사전 조합을 포함한 21조건군·727조건기간 표를 이미 냈다. 기존 교차표는 `R1 상대순위 × 직전착순`, 부담변화, 추세, 동일거리 유효시간 수다. 직전 Top3/7위 이하와 R1의 잔차 차이는 관찰됐지만 직전 착순 변수의 독립 기여·추가 모델 성능을 분리하지 않았다. 2026 운영 공통 467경주에서는 HY_R_FORM이 R1보다 Top3 확률·후보·6조합 지표가 높았다. 따라서 현재 계획은 `직전 R1 상대순위 × 직전착순` 표를 다시 계산하지 않는다.

## 고정 모집단, 기간, 결과, 분모

- 각 행은 기존 정상 완전 편성의 말 1두 출전이다. 결과는 기존 `finish_position`의 Top3 여부다. 타깃 경주 착순·완주시간은 조건 산출에 사용하지 않고 라벨로만 사용한다.
- 기간은 `race_date` 기준 `2017–2023`, `2024–2025`, `2026-01-01–2026-09-19`로 고정한다. 2026은 부분연도다. 이전 기간은 이미 반복 사용한 개발자료이며 독립 미래검증이 아니다.
- 조건별로 출전 수, 공식 말 수, 경주 수, 경주일 수, Top3·비입상 수, `P(조건|Top3)`, `P(Top3|조건)`, 조건 점유율, 편성별 균등 `3/N`, `P(Top3|조건)−mean(3/N)`를 보존한다. 조건 안에 입상마만 골라 넣지 않는다.
- 같은 경주 안에서 조건이 다른 말이 함께 있는 비교 수와 평균 위험 차이를 별도 보존한다. 조건이 한 경주 내 모든 말에 같은 경우 그 조건의 평균 R1 잔차로 정보가치를 설명하지 않는다. 완전 편성의 Top3 합은 3이고 R1 Top3 확률 합도 3이기 때문이다.
- R1 저장 Top3 확률은 기존 2024–2026 평가 17,412출전·1,779경주에서만 연결한다. HY_R_FORM은 운영 비교의 공통 467경주·4,475출전에서만 연결한다. 이력 재계산이나 저장 예측 재산출은 하지 않는다.
- 2024–2025 및 2026의 조건별 `3/N` 차이와 저장 R1 잔차는 경주일 bootstrap 2,000회·seed 20261009의 95% 점별 구간으로 보존한다. 공통 467경주 HY 잔차는 그 표본에 한해 기술한다. 다중 비교 보정으로 오해하지 않게 점별 구간과 탐색 한계를 함께 표기한다.
- 조건 셀은 전부 보고한다. 100출전 미만 또는 50경주 미만은 `low_support` 표시를 붙이고 제거·병합·경계 재조정하지 않는다. 네 조건 가족 외 사후 구간 탐색은 하지 않는다.

## 네 개 사전 조건 정의

모든 날짜 비교는 한국 현지 `race_date`로 한다. 대상 경주의 과거창은 `history_cutoff = race_date − 2일`까지 포함(T−2 inclusive)한다. 원천 사건일은 공개시각을 증명하지 않는다. 현재 출주집합·거리·등급·번호·부담은 기존 결과 원장의 사후 재구성 가정이며 당시 선언표·수정시각을 재현한 것이 아니다.

| ID | 조건·고정 구간 | 산출 정의와 unknown 처리 |
|---|---|---|
| S1 | **장기 공백 뒤 복귀 순서**: 일반, 91일 이상 공백 뒤 첫 출전, 그 복귀 출전 다음의 두 번째 출전, unknown | 기존 원천 스냅샷의 같은 공식 말 ID `started` 이벤트를 날짜·출전 ID순으로 정렬하고 타깃 T−2까지 사용한다. 우선순위는 (1) 현재 직전 시작 간격 `currentgap ≥91`이면 첫 복귀, (2) 그 외 `currentgap ≤90`이고 과거 시작이 2회 이상이며 직전 시작 사이 간격이 `≥91`이면 두 번째 출전, (3) 과거 시작 0회 또는 과거 1회뿐이라 앞선 공백을 알 수 없으면 unknown, (4) 그 밖은 일반이다. 두 간격 중 하나에 시행 여부를 알 수 없는 비시작 원문 코드 `0/93/98`이 있으면 ID를 기록하고 unknown으로 censor한다. 코드는 새 시작으로 승격하지 않는다. `94/95/99`는 의미를 추정하지 않고 기존 non-start 처리로 둔다. 중간 시작을 건너뛰지 않는다. `started`에는 정상착순 외 원천상 시작한 DNF·실격 상태가 포함되며 실제 시행 횟수 완전성을 뜻하지 않는다. |
| S2 | **거리 변경 후 과거 경험 거리 복귀**: 직전 거리 동일/변경/unknown 3수준 × 관측된 같은 거리 과거 시작 수 0/1–2/3+/unknown 4수준 | 기존 T−2 feature의 `previous_start_id`, `distance_m`, `same_starts`를 사용한다. `same_starts`는 해당 거리의 과거 `started` 출전 수이며 유효시간 수와 다르다. 0은 **관측된 정확 거리 시작 0회**이지 공식 첫거리·평생 무경험 보증이 아니다. 원천에 거리가 NULL인 과거 시작은 별도 unknown 거리 사건일 수 있고, 이를 관측 0회에 더하지 않는다. 3+는 반복 관측 지원이 있다는 뜻이지 입증된 거리 적성이라는 뜻이 아니다. 3×4 고정 교차만 낸다. 기간·타깃 거리 분모를 따로 보인다. |
| S3 | **동일거리 관측 상대위치 변화**: 상대위치 개선 0.25 이상, 변화 폭 0.25 미만, 악화 0.25 이상, unknown | 현재 R1 `mean5_rank_fraction`에서 같은 말의 가장 최근 동일거리 과거 feature row 값(`race_date ≤ history_cutoff`)을 뺀다. 낮은 분율은 빠른 상대기록 위치다. 변화 `현재−과거 ≤−0.25`는 개선, `−0.25 < 변화 < +0.25`는 작은 변화, `≥+0.25`는 악화다. 0.25는 0~1 순위분율의 사전 고정 사분위 이동 폭이다. 현재·이전 feature가 모두 있어야 계산한다. 타깃 행에서 참조한 가장 최근 동일거리 원천 출전이 frozen feature에 없으면 더 오래된 feature로 건너뛰지 않고 unknown이다. 이는 관측한 상대 위치 변화이며 순수 편성강도 변화나 순수 말 능력 변화가 아니다. |
| S4 | **직전 출전의 T−2 상대기록 위치와 실제 착순분율 불일치**: 기대 상대위치보다 실제 착순이 0.25 이상 나쁨, 차이 절댓값 0.25 미만, 0.25 이상 좋음, unknown | 타깃의 정확한 `previous_start_id`가 frozen feature와 연결될 때, 그 과거 출전 행의 **당시 저장된** `mean5_rank_fraction`(그 과거 경주의 T−2 과거 평균시간으로 계산된 자기 제외 상대위치)과 그 출전의 실제 `finish_position` 분율 `(finish_position−1)/(field_n−1)`을 비교한다. `finish_fraction−past_mean5_rank_fraction ≥+0.25`는 사전 상대기록 위치보다 나쁜 착순, `≤−0.25`는 더 좋은 착순, 그 사이는 가까움이다. 해당 이전 행이 정상 완전편성이 아니거나 사전 상대위치가 없으면 unknown이다. 타깃 현재 출전의 착순·시간을 조건에 쓰지 않는다. 과거 R1 확률 잔차나 모델의 기대 순위로 부르지 않고, 시간 기반 상대기록 위치와 실제 상대착순의 후향 불일치로만 부른다. |

S3는 현재/이전 편성·관측수 변화도 포함한다. S4는 두 순위가 거의 같은 현재시간 순위 대 현재착순 순위를 다시 비교하는 설계가 아니다. 타깃 직전 경주 전에 저장된 과거 평균시간 상대순위와 그 직전 경주의 이후 실제 착순을 연결한다. 이 결과는 다음 경주 타깃의 T−2 정보다.

## 넓은 조건 후보 감사와 분류

상태는 데이터 구조를 확인한 현재 단계의 처리 우선순위다. `입력가능`은 frozen cohort와 T−2 이력으로 정의를 계산할 수 있음을 뜻하며 효과·지원 충분성·운영 게시 가능성을 뜻하지 않는다.

| 후보 | 상태 | 기존 결과·가용성·보류 이유 |
|---|---|---|
| 첫 거리/거리 복귀 × 직전 거리 변경 | **입력가능 (S2)** | 기존 이력에 관측된 정확 거리별 시작 수·직전 거리 ID가 있다. 원래 21군에는 직전 거리변경과 동일거리 경험수 단일군은 있으나 이들의 조합표는 없다. `0`을 공식 무경험으로 부르지 않는다. [R1 입력 계약](../20261009_field_relative_ability_v1/CONTRACT.md), [Top3 조건 계약](../20261009_top3_condition_profiles_v1/CONTRACT.md). |
| 장기 공백 첫 복귀/그 다음 출전 | **입력가능 (S1)** | 기존 이력의 최근 시작일과 상태 슬롯을 쓸 수 있다. 간격 단일 구간은 21군에 있다. 이벤트 횟수 완전성·공개시각을 보장하지 않아 관찰 시퀀스에 한정한다. [기초 이력 계산·검증](../20261008_horse_profile_baseline_v1/run.py), [조건 결과](../20261009_top3_condition_profiles_v1/README.md). |
| 이전·현재 편성 대비 상대수준 변화 | **입력가능 (S3)** | R1은 현재 편성 자기제외 동일거리 과거시간 상대위치(`mean5_rank_fraction`)와 관측수를 이미 저장했다. 이번은 동일 말의 정확 거리 이전 feature 값과 변화량이다. 절대 편성 강도라 부르지 않는다. 현재 선언집합 당시 공개시각은 미확정이다. [R1 입력 계약·결과](../20261009_field_relative_ability_v1/README.md). |
| 좋은 기록 위치와 직전 부진 착순의 불일치 | **입력가능 (S4)** | 직전 착순·과거 T−2 평균시간 기반 편성 내 상대위치가 연결된다. 기존 `current R1 rank × previous finish`와 정의가 다르며 그 교차표를 재생하지 않는다. [기존 4개 교차표 계약](../20261009_top3_condition_profiles_v1/CONTRACT.md). |
| 승급/강급 × 직전 좋은 성적 × 부담 증량 | **추가 검증 필요** | 과거·현재 원문 등급과 부담 필드는 있으나 공식 등급 순서·시대별 동등성, 실제 선언표·중량 가용 시각, 상호작용의 분모가 아직 고정되지 않았다. 기존 Top3 조건 보고서에서 3kg 이상 증량 원시 입상률은 높았어도 좋은 성적·배정·승급이 섞여 중량 이익으로 볼 수 없다고 보류했다. 중량 연구는 기록 손실 위험, Top3 조건 연구는 사후 정상 완전편성의 입상률로 결과목표·표본이 다르다. [Top3 조건 결과](../20261009_top3_condition_profiles_v1/README.md), [중량 연구](../research/conclusions/04_WEIGHT_SPEED.md). |
| 저경력 말의 개선폭 × 이력 관측수 | **추가 검증 필요** | 경력수와 과거 기록창은 저장돼 있고 무이력 661 평가 출전에서 R1 Brier 0.216954로 균등 기준 0.216334보다 높았다. 이력 0은 공식 신마가 아니며 최근 성적을 더하는 다른 작업과 중복된다. 곡선/지원 기준을 별도 고정해야 한다. |
| 기수 교체 × 같은 말의 기수 이력 | **추가 검증 필요** | 공식 기수 ID 연결·같은 말/거리 교체쌍은 존재한다. 이전 연구에서 기수 ID의 소폭 예측 개선은 보고됐지만 말×기수 상호작용은 추가 개선이 없어 미채택이다. 교체 비교의 대상은 상대기록·Top3이며 배정·교체 이유는 미관측이다. 이번 4조건 분석에는 미포함한다. [자료지원 계약](../20261009_jockey_research_feasibility_v1/README.md), [기수 효과](../20261009_jockey_effects_v1/README.md), [최신 기수 결론](../research/conclusions/08_JOCKEY_PROFILE.md). |

## 원천·구현 계약

- 대상행·과거 이벤트 ID는 `field_relative_ability_v1`의 frozen `features.parquet`와 `20261008_horse_profile_baseline_v1/outputs_v2/source_snapshot.parquet`에서 읽는다. 신규 추출시에는 읽기 전용 DB 연결만 허용한다. 연구 산출 전후 DB 파일은 쓰기 금지다.
- 공식 `api_record_id`, `horse_id`, `race_id`로만 붙인다. 이름·현재 소속·현재 프로필을 과거 키로 쓰지 않는다. 기존 최근 동일거리 이력 ID의 T−2 검증을 계승하고, 모든 신규 참조는 대상 `history_cutoff` 이전이고 말 ID가 같음을 확인한다.
- S1용 started history는 기존 source snapshot `started` 정의(착순 1~89, 91, 92)를 그대로 쓴다. 시행 여부를 확정할 수 없는 raw non-start 코드 0/93/98이 최근 두 간격 중 하나에 끼어 있으면 해당 대상 조건을 unknown으로 censor하고 원행 `api_record_id`·개수·대상 row ID를 별도 CSV와 출전 계보에 남긴다. 94/95/99는 원 뜻을 추정하지 않고 기존 non-start 처리로 둔다. 미완주·실격·중지 표기를 정상착순이나 입상으로 바꾸지 않는다. 모든 과거 source row가 history snapshot 범위 밖이면 unknown으로 남긴다.
- 타깃 결과의 착순·시간만 바꾸는 교란 검증에서 S1~S4 조건과 ID 계보가 불변이어야 한다. 과거 행의 실제 착순을 바꾸면 S4가 변해야 하며, 타깃 행 착순을 바꾸면 S4가 변하면 안 된다.
- 전체 행 수·말 수·경주 수·경주일 수·입상/비입상·기간·거리·unknown 표를 보존한다. 재표집은 날짜 군집 점별 95% 구간이며 같은 말의 장기 반복 군집은 조정하지 않은 한계를 쓴다.
- 계산 전 기존 파일들의 SHA-256과 해시목록을 저장한다. 계산 중 `.venv/bin/python`만 사용하고 새 파일은 이 연구 폴더에만 쓴다. DB·등록부·모델·과거 원본의 파일 해시/크기는 시작·종료에 대조한다. 기존 R1/HY 저장 예측과 이력 계보를 다시 만들거나 덮어쓰지 않는다.
- 조건별 결과표와 전체 4조건표를 모두 남긴다. 소표본·결측이 커 결과를 해석할 수 없으면 그 상태로 보고하고 더 유리한 경계나 조건을 추가 탐색하지 않는다.

## 연구 한계

모든 결과는 여러 차례 사용된 2017~2026-09-19 후향 자료의 설명·잔차 비교다. 당시 출전선언·취소·수정 시각은 완전히 재생하지 못했다. 2026은 부분연도다. 입력 조건과 다음 Top3의 연관은 인과효과가 아니며, 잔차는 변수의 고유 개선이나 고정 가점의 증거가 아니다. 표본 지원이 적거나 자료 정의가 맞지 않으면 후보를 보류한다. 독립 검증·새 학습·모델 개선·운영 반영으로 부르지 않는다.
