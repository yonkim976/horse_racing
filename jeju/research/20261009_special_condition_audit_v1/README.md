# 제주 추가 조건 감사: 시퀀스·상대조건

## 결론

네 조건은 고정된 2017-01-13~2026-09-19 제주 정상 완전편성 52,155출전·5,206경주에서 후향 기술 비교했다. 네 조건별 원 통계는 모두 보존했고, 별도 감독 승인 후 2024–2025와 2026 부분연도의 기존 F1 예측 잔차도 추가했다. 새 모형은 학습하지 않았고 DB·운영모델·등록부·중앙 결론은 수정하지 않았다. 이 결과는 인과효과, 연구효과의 독립 미래검증, 고유 변수 기여, 모델 개선 또는 운영 가점의 증거가 아니다.

현재 다음 연구 순서는 다음과 같다.

1. **장기 공백 첫 복귀(S1)**는 시행 여부 불확정 원행을 `unknown`으로 censor한 뒤 남은 관측 가능 이력에서 F1 입력 `days_since_start ≥91`과 같은 구간화다. first-return F1 잔차가 2024–2025와 2026 부분연도에 각각 +4.10%p와 +4.97%p였고 점별 95% 구간도 0 위였지만, 새 정보 발견이나 새 특징 필요를 뜻하지 않는다. 기존 공백 입력의 구간 보정·상호작용·오차분할 후보로만 남긴다.
2. **직전 시간상대위치와 실제 착순 불일치(S4)**는 R1 잔차에서 방향이 컸지만, 직전 착순 정보를 직접 받는 F1에서는 잔차가 작아지고 모든 구간이 0을 포함했다. F1 입력의 중복 가능성이 크므로 새 피처 효과로 해석하지 않는다. F1 이후에도 조건별 잔차가 재현되는지, 사전 고정한 후속 평가에서만 확인한다.
3. **거리 복귀(S2)**는 같은 거리의 관측 시작 수·직전 거리별 결과가 달랐지만, 여러 셀에서 F1 잔차 구간이 0을 포함했다. 현재 거리별로 나눠 본 진단 후보이며 “첫 거리”나 거리 적성으로 부르지 않는다.
4. **동일거리 상대위치 변화(S3)**는 원 Top3/3/N 비교에서 개선·악화 방향이 보였지만 F1 잔차는 작거나 기간 간 방향이 달라 추가조건 우선순위를 낮춘다.

|---|---:|---:|---:|---:|---:|---:|

원천 정답 분모는 정상 착순 1~N, 경주당 6두 이상, 모든 말의 양수 완주시간, 전체 순위 완성 및 공식 ID 연결 조건을 그대로 승계했다. 말 수는 기간별 고유 말 수이며 기간 간 중복될 수 있다. 2026은 부분연도다. 예전 기간은 반복 사용된 연구·학습자료라 연구효과의 독립 미래검증 자료가 아니다. R1 저장 예측은 2024년 이후 17,412출전·1,779경주에서만 연결했고, 2017–2023 잔차는 산출하지 않았다.

각 조건 셀에는 출전·말·경주·경주일·입상·비입상, Top3율, 편성별 균등 기준 `3/N` 대비 차이, 편성 내 비교, 저장 R1 잔차와 저지원 표시를 기록했다. R1 잔차·`3/N` 차이의 날짜 bootstrap 구간은 2024–2025와 2026 부분연도에 대해 2,000회, seed 20261009로 계산한 **점별** 95% 구간이다. 다중비교 보정과 반복 말 단위 추가 군집 보정은 없다.

원 통계 검증은 52,155출전·5,206경주, 경주별 Top3 합=3, 같은 경주 분모 일치, T−2 이전 계보 연결, 타깃 착순 교란 200행 불변을 통과했다. C가 별도로 원 575개 조건통계행과 301개 날짜 구간을 재계산해 일치시킨 [구현 독립 재계산 receipt](../20261009_finish_and_condition_review_v1/special_condition_independent_verification.json)도 PASS다. 이는 결과 계산의 재현성 확인이며, 연구효과의 독립 미래검증은 아니다. 보충 검증은 F1만 17,412출전·1,779경주와 공식 ID 1:1 연결, 라벨 일치, 경주별 F1 확률합=3(최대 오차 약 2.7×10⁻¹⁵), 타깃 출전의 착순·실제시간 교란 200행 불변을 통과했다. C가 원/F1 301개 보충 셀과 CI, 연결, 확률합, 수리 후 S2 312행 격자를 독립 재계산한 [F1 보충 구현 독립 재계산 receipt](../20261009_finish_and_condition_review_v1/f1_condition_supplement_independent_verification.json)도 PASS다. S4 구현은 과거 실제 착순 교란 시 S4만 바뀌는 검사도 통과했다. 입력 잠금 검증으로 원천·DB·운영모델·등록부 불변을 확인했으며, 보충은 기존 F1 확률만 읽고 학습·재보정하지 않았다.

## 네 조건과 최근 평가 잔차

`F1 잔차 = 실제 Top3 여부 − 저장된 F1 Top3 확률`이다. 양수는 해당 셀에서 F1이 실제 입상률을 평균적으로 낮게 예측한 상태, 음수는 높게 예측한 상태다. 아래 구간은 F1 잔차의 날짜 군집 bootstrap 점별 95% 구간이다. R1과 F1 잔차의 나란한 비교는 조건별 남은 오차의 기술이며 모델 간 paired 개선검정이나 조건의 독립 기여가 아니다. 수치는 %p다.

S1의 F1 양의 잔차는 days-since-start 입력의 구간별 미적합 가능성을 보여주는 사후 셀 분석이지 새 변수 효과가 아니다. S4에서 R1의 큰 양·음 잔차 대비 F1 잔차는 작고 구간이 0을 포함한다. F1이 직전 착순 상대순위·직전 Top3·이전 결과상태를 이미 입력받는 점과 양립하지만, 잔차 변화만으로 직전 착순 입력의 원인 역할을 입증할 수 없다. S2의 `same_starts=0`은 frozen 원천에서 관측된 해당 정확 거리 시작이 0회란 뜻이며 공식 첫 거리·평생 무경험을 보증하지 않는다.

## 지원·결측·한계

- S1 `unknown`은 출전 3,582건이다. 그중 66개 대상 출전에는 최근 공백구간 내 시행 여부 불확정 원문 코드가 있어 censor했고, 연결한 원행 ID는 별도 CSV에 남겼다. 이 행을 새 시작으로 재분류하지 않았다. 한 번 이하 과거 시작으로 앞선 공백을 알 수 없는 경우도 unknown이다.
- S2 전체 3×4 고정 격자는 [정정 지원표 v2](outputs_f1_supplement/S2_full_grid_support_v2.csv)에 저장했다. 기존 원 통계에 관측된 범주는 6개이며 전체 분석 기간·거리 scope마다 12개를 모두 행으로 보존했다. `prev_same × same_starts=0`은 정의상 불가능한 구조적 0이다. `same_starts` NULL은 frozen cohort에서 0건이어서 `unknown` 수치구간이 없는 것과 구분했다. `prev_unknown × 1–2/3+`는 개념상 가능하지만 해당 표본에서 0건이었다. 초기 보충 격자 [원본](outputs_f1_supplement/S2_full_grid_support.csv)은 잠금된 이력으로 보존했다. 그 `period=all` 6개 관측 셀에는 F1 평가기간 밖의 행을 집계하면서 `mean_p_F1`이 남는 표시 오류가 있어, [수리 코드](repair_grid_v2.py)와 [diff 검증 receipt](outputs_f1_supplement/S2_full_grid_v2_verification.json)가 그 6개 필드만 NULL로 바꾼 v2를 생성했다. 원 조건 통계·보충 통계·잠금 파일은 바뀌지 않았다.
- S3 `unknown` 15,763건, S4 `unknown` 12,281건은 과거 상대시간 위치나 연결된 정상 과거 feature 부족을 포함한다. 미관측·NULL을 좋은 신호나 불리 신호로 채우지 않았다.
- 원 표본과 모델 예측은 이미 반복 사용된 후향 자료다. 사건 날짜는 공개시각을 증명하지 않는다. 경주일 bootstrap은 날짜 내 상관을 묶지만 같은 말의 장기 반복 출전 군집을 추가 보정하지 않는다. 95% 구간은 점별이며 조건 다중비교 보정이 아니다.
- 당시 선언표·취소·수정 이력은 완전히 재생되지 않는다. 같은 경주에 공통인 환경·등급·상수 조건은 Top3 합이 3인 제약을 고려해야 한다. 비입상·unknown과 저지원 셀은 모두 분모에 남겼다.
