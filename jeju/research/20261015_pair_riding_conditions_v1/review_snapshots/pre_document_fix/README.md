# 제주 F1_STYLE6 pair 기승조건 증분 비교

**사전 지정 복합 게이트 판정: improvement not established; retain as unadopted research candidate.** 이 결과는 2024–2026 반복 개발 자료에서 저장 기수-ID pair 후보에 기승조건 묶음 하나를 추가한 비교다. 2026년 자료는 9월 19일까지의 부분연도이며 독립 미래 검증이 아니다.

말별 F1_STYLE6 점수, 기존 pair 선택 기준, 평가 roster와 평가 목표를 고정했다. 새 목표는 선택한 두 말이 공식 Top3에 함께 드는 사건이다. 정확한 1·2·3착 순서나 운영 HY_R_FORM의 직접 비교는 이번 실험 범위가 아니다.

## 사전 지정 게이트

| 비교 | 저장 기수-ID 기준 | 기승조건 후보 | 차이 | paired 날짜 95% CI (%p) |
| --- | --- | --- | --- | --- |
| 438/1,779 | 24.62% | 437/1,779 | 24.56% | -0.056%p | [-0.329, +0.170] |

후보가 바꾼 선택은 22경주다. 바뀐 조합에서 적중을 얻은 경주는 2, 기준 적중을 잃은 경주는 3, 결과가 같은 경주는 17였다. 기존 말 점수와 기수-ID 비교기 출력은 그대로 유지됐다.

선택 적중은 baseline 438회에서 후보 437회로 1회 줄었다(차이 -0.056%p, paired date 95% CI [-0.329, +0.170]); 따라서 선택 개선 gate는 미통과다. 한편 같은 baseline 선택 pair에 확률만 적용한 Brier 차이는 -0.0001264 (95% CI [-0.0002213, -0.0000348]), log loss 차이는 -0.0003726 (95% CI [-0.0006103, -0.0001450])로 둘 다 개선됐다. 전체 pair 경주균등 Brier 차이는 -0.0000256 (95% CI [-0.0000322, -0.0000188]), log loss 차이는 -0.0001701 (95% CI [-0.0001999, -0.0001402])다. 따라서 확률 점수에는 증분 신호가 보이지만 선택쌍 적중 개선을 입증하지 못해 사전 복합 gate는 실패하며, 후보를 미채택 연구 상태로 둔다. 이는 정확 착순 순서 개선의 증거도 아니다.

| Gate | 결과 | 기준 |
| --- | --- | --- |
| 선택 적중 개선 | 미통과 | candidate hit-rate lift > 0 and paired date CI lower bound > 0 |
| 기준 선택 pair 확률 개선 | PASS | both candidate-minus-baseline Brier and log loss <= 0; at least one paired date CI upper bound < 0 |
| 전체 pair 확률 guard | PASS | candidate-minus-baseline race-equal Brier and log loss both <= 0 |
| 복합 판정 | 미통과 | 세 gate 모두 PASS일 때만 복합 개선 |

세 gate 모두 PASS일 때만 사전 복합 개선으로 판정한다. 미통과는 효과가 없다는 증명이 아니며, 예측 개선이 확인되지 않은 후보는 미채택 상태로 둔다.

## 입력·평가 계약

- 저장 F1_STYLE6 점수와 기존 기수-ID pair 후보의 모든 54개 열을 동결했다. 새 runner 상태 10개를 unordered pair 양 끝 말에서 합산했다. H1에서 `horse_current_rider_history_unavailable_count`가 `previous_rider_unknown_count`와 정확히 중복되어 첫 열만 유지했고, fold별 활성 rider-condition 입력은 9개였다. 총 공동 입력은 각 fold 69열이다.
- 세 평가 fold는 2024년 637경주, 2025년 654경주, 2026년 488경주다. H1에서 fold별 1회 적합, H2에서 양의 기울기를 갖는 Platt 보정 1회, 총 3+3회만 수행했다. 추가 arm, 재시도, 튜닝은 하지 않았다.
- bootstrap은 기존 고정 269경주일·seed 20261011·2,000회 paired date schedule을 사용했다. 날짜를 독립 표본처럼 취급하지 않았다.
- rider history는 보유 started 기록이며 생애 전체 기승 자료라고 보장하지 않는다. 모든 feature cutoff는 대상 경주일 기준 T−2 포함이다. 기록 공개 timestamp가 없으므로 T−2는 실제 공개를 확인한 시각이 아니다.
- 승식 배당, 사후 배당, ROI는 입력이나 결과에 사용하지 않았다. 이번 모델은 pair 동시 Top3 분류기이며 정확 Top3 순서 예측기가 아니다.
