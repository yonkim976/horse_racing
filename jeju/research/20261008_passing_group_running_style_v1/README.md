# 제주마 통과조 기반 말별 각질 후보

통과조로 **초반 위치 성향과 후반 전진 성향을 나누어 표시하는 방식**이 적합하다. 최근 출전에서 전방을 반복하는 말과 후방을 반복하는 말을 구분할 수 있지만, 같은 집단 안의 순서와 전술 의도는 확정할 수 없다. 후미대기와 추입도 별도다. 이번 결과는 설명용 분류 후보이며 미래 경주 예측 성능이나 전통적 각질의 정답을 검증한 결과가 아니다.

2017-01-01~2026-09-19 정상 완주·완전 경주 **52,155출전·5,206경주·2,813두**를 분석했다. 2026년은 부분연도다. 2025·2026년에 대상 출전이 관측된 말은 1,198두이며 현재 등록·활동마 전체라는 뜻은 아니다. 비정상 종료 경주·일부 후보만 보유한 경주·6두 미만 경주 등은 기존 strict 계약에 따라 제외됐다. 현재 거리 8종만 사용하고 400m는 제외했다.

## 통과조를 읽는 기준

공식 용어해설을 대조한 [보유 의미 검토](../20261003_unresolved_section_review/semantic_review/README.md)에 따르면 괄호 안 마번은 같은 집단 안에서 내측부터 적힌 것이다. `(1,5,7)`을 1→5→7의 개별 순위로 해석하지 않는다. 앞선 말이 2두라면 세 말 모두 **3~5위 범위**로 계산한다. 집단 내부를 바꾸어도 결과는 같아야 한다.

출전두수를 반영해 이 범위 전체가 앞 1/3에 있으면 전방, 가운데 1/3이면 중단, 뒤 1/3이면 후방으로 센다. 범위가 경계를 걸치면 집단경계 불확실로 남긴다. 첫 집단 소속과 단독 선두는 별도 기록하며, 선두군 소속을 실제 단독 선행으로 바꾸지 않는다.

기본 위치는 S1F로만 분류한다. S1F가 없으면 다른 코너로 대신하지 않는다. 1300m는 S1F/2C 측정 정의가 미확정이므로 초반 각질 판정과 S1F→4C 전진 판정을 보류한다. 해당 거리의 관측 범위와 4C→G1F 전진은 별도 보존했다. 코너 표시 열을 모두 시간순으로 연결하지 않았고 G3F 막판시간을 통과조로 만들지 않았다.

## 말별 분류 규칙

말 전체 거리 통합과 정확거리별 프로필을 각각 만든다. **마지막 해당 대상 출전일 기준 730일 안의 최근 10회 대상 출전**을 쓴다. 오래된 유효 관측으로 결측을 채우지 않는다. 최소 5회 유효 S1F, 최근 정의 지원 출전의 유효율 60% 이상에서 다음 규칙을 적용한다. 통합표의 1300m는 초반 비율 분모에서 제외하고 제외 횟수를 표시한다.

| 후보 | 설명용 기준 |
|---|---|
| 선두군형 | 확실한 전방 60% 이상이고 첫 집단 소속 60% 이상 |
| 선입형 | 확실한 전방 60% 이상이며 선두군형 기준에는 미달 |
| 중단형 | 확실한 중단 60% 이상 |
| 후미대기형 | 확실한 후방 60% 이상 |
| 혼합 또는 집단경계 불확실 | 한 위치가 반복 기준에 미달. 실제 위치 변화와 집단 관측 불확실성을 함께 포함 |
| 자료부족·측정정의보류 | 유효 표본·커버리지 미달 또는 1300m 초반 의미 미확정 |

**60%·5회·730일·최근 10회는 이번에 먼저 정한 설명 규칙이다. 최적 기준이나 미래 각질 확률로 검증하지 않았다.** 불확실한 집단도 유효 관측 분모에 포함해 확실한 위치의 비율을 과장하지 않는다. 전체 비율의 분자·분모 및 단순 Wilson 점별 95% 구간은 상세 프로필에 있다. 이 구간은 반복 출전의 독립성을 가정하는 기술 구간이며 미래 확률의 신뢰구간이 아니다.

## 실제 말별 사례

| 말과 거리 | 유효 관측 | 전방 / 중단 / 후방 / 불확실 | 선두군 | 4C→G1F 확실 전진 | 분류 후보 |
|---|---|---|---|---|---|
| 흑룡시대 1110m | 10회 | 8 / 0 / 0 / 2 | 7/10 | 0/10 | 선두군형 후보 |
| 황룡강 1000m | 10회 | 7 / 0 / 0 / 3 | 5/10 | 0/10 | 선입형 후보 |
| 녹원매직 900m | 6회 | 0 / 4 / 2 / 0 | 0/6 | 1/6 | 중단형 후보 |
| 흥부시대 1000m | 10회 | 1 / 1 / 8 / 0 | 0/10 | 1/10 | 후미대기형 후보 |
| 삼다장군 1110m | 10회 | 0 / 0 / 10 / 0 | 0/10 | 6/10 | 후미대기형 후보 |

표의 관측 종료일은 흑룡시대·황룡강·흥부시대 2026-09-19, 녹원매직 09-04, 삼다장군 09-18이다. 거리별 최근 대상 출전으로 계산했다. 후반 확실 전진은 4C 순위범위 하한보다 G1F 상한이 2위 이상 앞선 경우다. 예를 들어 4C가 8~10위이고 G1F가 5~6위이면 적어도 2두를 앞선 것으로 센다. 범위가 겹치면 전진하지 않았다는 뜻이 아니라 전진을 확정하지 못한 것이다.

흥부시대 1000m와 삼다장군 1110m는 모두 후방을 반복하지만 후반 확실 전진은 각각 1/10회와 6/10회다. **후방 위치만으로 두 말을 같은 추입형으로 묶으면 이 차이가 사라진다.** 삼다장군 1110m에는 설명용 후반 전진 반복 태그를 붙였다. 순위 전진은 막판 속도·가속·입상·말의 능력과 같지 않다.

거리별표를 먼저 보는 편이 좋다. 예를 들어 흑룡시대 1000m는 최근 10회 전방 8회·선두군 3회로 선입형 후보,1110m는 전방 8회·선두군 7회로 선두군형 후보다. 두 거리의 관측 종료일도 각각 2025-08-08과 2026-09-19로 달라 순수한 거리 효과로 해석할 수 없다.

모든 연결은 공식 말 ID다. 최신 API42 마명과 2026년 고정 나이를 사용하며 과거 출전 당시 나이와 구분한다. 제외 말 3005648은 편입하지 않았다. 전체 31,236경주×지점 점검과 괄호 내부 순서 불변 검사를 수행했고, 별도로 보존 파서의 구간 및 모든 최근 프로필의 출전 ID·창·분자를 재대조했다. DB는 읽기 전용이며 실행 전후 SHA가 동일하다.

재실행은 새 출력 폴더를 지정한 후 계산·검증·출판 순서로 진행한다. 기존 run01은 덮어쓰지 않는다. 연구 관리 등록은 운영 모델 반영과 별개다. 미래 입력 채택 시 최소 T−2의 과거 이력으로만 프로필을 구성하고 후속 경주의 위치·전진을 별도로 검증해야 한다. 이번에는 같은 경주의 사후값을 사전 입력에 연결하지 않았고 DB·운영 모델·웹을 변경하지 않았다.
