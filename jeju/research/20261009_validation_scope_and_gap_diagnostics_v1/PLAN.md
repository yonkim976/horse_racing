# F1 공백 잔차 후향 분할 진단 — 계획 초안

상태: **root 고정 셀 승인 대기. 새 셀별 잔차·손실 계산은 아직 실행하지 않음.**

## 질문과 해석

기존 S1의 `first_return_91_plus`와 `general` 사이에 보인 F1 Top3 잔차가 거리, 기존 경력 버킷, 직전 Top3 상태별로 어떻게 분포하는지 기술한다. S1 첫 복귀는 불확정 시행 이력을 censor한 뒤 계산된 기존 `days_since_start ≥ 91`의 결정론적 구간이다. 독립 정보나 새 피처로 해석하지 않는다. 이 작업은 2017~2026-09-19 후향 개발자료의 추가 분할 비교다.

## 고정 표본·입력·셀

- `20261009_special_condition_audit_v1/outputs/condition_features.parquet`의 고정 S1 레이블과 `finish_history_ablation_v1/outputs/runner_predictions.parquet`의 저장 예측을 공식 `api_record_id`로 1:1 연결한다. `variant == F1`만 쓰며 `y`와 ID를 대조한다. 입력 해시와 upstream lock 검증은 `input_lock.json`에 기록한다.
- 기간은 저장 평가 표본 그대로 `2024_2025`와 `2026_partial`(2026-01-02~09-19)로 둔다. 2026은 부분연도다.
- 비교군은 S1의 `first_return_91_plus`와 `general`만이다. `second_after_return_le90` 및 S1 `unknown`은 대비 통계에 섞지 않으며, 해당 건수와 F1 연결 건수를 별도 coverage 행으로 남겨 분모 이탈을 숨기지 않는다.
- 분할은 한 번에 한 축만 적용한다(교차표·상호작용 없음). 축은 (a) 정확 거리 800/900/1000/1110/1200/1300/1400/1610m, (b) F1 기존 `observed_starts` 버킷 0/1–4/5+, (c) 기존 `previous_top3` 상태 top3/not_top3/unknown이다. 경계·범주를 다시 맞추지 않는다.
- 셀마다 평균 잔차 `mean(y − p_top3)`, 저장된 runner-level Brier 평균, 연결된 출전 수·경주 수·경주일 수를 낸다. `n_cohort`와 `n_F1`을 나누고, 확률·라벨 결측은 제외하지 말고 coverage로 표시한다. 완전 연결 기대치는 전체 F1 코호트 17,412출전·1,779경주다. 불일치 시 계산을 중단한다.
- `<100` 출전 또는 `<50` 경주 셀은 `low_support`로 표시하되 유지한다. `unknown` 직전 Top3 셀도 같은 지표·분모로 보존한다. 미지 경력은 0경력으로 바꾸지 않는다.
- 첫 복귀에는 직전 시작 이력이 필요하므로 `first_return_91_plus × observed_starts=0`은 구조적 0 셀로 행을 남기고 수치 지표는 정의 불가로 둔다.
- 잔차 CI는 기존 S1 방식과 같이 경주일 군집 bootstrap 2,000회, seed `20261009`, 점별 95% percentile 구간으로 계산한다. 셀 내 경주일이 10일 미만이거나 F1 행이 0이면 CI는 NA다. 날짜 수는 항상 보고하고 낮은 지원 셀을 제거하거나 결과에 따라 경계를 바꾸지 않는다. 다중비교 보정·유의성 선별은 하지 않는다.
- `first_return_91_plus − general` 차이는 별도 승격 기준 없이 필요 시 기술 비교로만 제시한다. 이를 독립 정보, 휴양의 원인 효과 또는 모델 개선으로 주장하지 않는다.

## 금지 범위와 승인 게이트

새 조건·임계값·교차축·모델 fitting·보정·가점은 추가하지 않는다. 이 문서가 root 승인되기 전에는 위 셀별 잔차·Brier를 계산하지 않는다. 승인 뒤에도 이미 잠긴 F1 예측을 집계만 하며 DB, 운영 모델, 등록부, 기존 연구 폴더, 중앙 결론을 쓰지 않는다.

## 미래 검증 프로토콜 초안

미래 평가 경주일은 계획·입력·모델 해시를 잠그고 예측 생성 시각을 사전 고정한 뒤에만 포함한다. 예측 생성 시각은 과거 이력 cutoff와 별도다. 모델 입력의 과거 이력 cutoff는 경주일 기준 KST T−2를 포함해 고정하고, 출전목록·조건은 각 경주에 대해 사전 고정된 실제 예측 생성 시각에 가용했던 스냅샷을 저장한다. 출전목록을 반드시 T−2에 확보해야 한다는 뜻은 아니다. 예측 생성 시각, 그때 확보된 입력 스냅샷, 예측 파일 해시는 결과 공개 전에 보존한다. 원천 사건 날짜만 있고 공개시각이 없으면 그 가용성은 확인된 사실로 취급하지 않고 별도 가정으로 표시한다. 예측 시각에도 확인할 수 없는 출전·조건 값은 unknown으로 둔다.

주 평가는 현재의 정상 완전 표본 계약만 승계한다: 공식 ID 연결, 6두 이상, 정상 착순 1..N, 전 출전 양수 완주시간, 전체 순위 완성. 따라서 추정 대상은 이 제한 표본이며 모든 출전 경주로 일반화하지 않는다. 취소·불성립, T−2 뒤 취소/출전변경, 미완주·실격·불완전 착순은 결과를 만들어 넣지 않고 제외 사유와 출전·경주 분모를 별도 집계한다. 제외·변경을 확정 예측 뒤 소급 삭제하거나 남은 확률을 재정규화하지 않는다. 무이력은 기존 관측 시작수 0 버킷으로, 결측 과거 Top3는 unknown으로 유지한다.

새 라벨을 보유하거나 일정에 등록하지 않는다. 현재 DB 상한은 2026-09-19이며, 위 절차는 향후 별도 사전고정 후에만 적용한다.
