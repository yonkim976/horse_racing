# 사용자 확인에 따른 제주 취소 경주 판정 반영

기준일: 2026-10-01. 사용자가 직접 확인해 제공한 취소 여부를 [확인 원문](user_assertions.jsonl)에 보존했다. 확인 출처는 `user_review`이며, 별도의 공식 취소 사유 문구를 만들어 붙이지 않았다. 날짜 전체 취소와 특정 경주 취소의 범위를 그대로 기록하고, 보유 API4_3 출전행과 읽기 전용으로 대조했다.

## 반영 결과

종전 미확정 7경주·30개 제주마 후보 출전행은 모두 **취소 확인, 사유 미표시**로 처리했다. 취소 여부 미확정은 0경주다. [갱신된 76경주 검토 원장](confirmed_76_review.jsonl)은 공식 홈페이지 취소 사유 명시 69경주·650행과 사용자 취소 확인 7경주·30행을 합친다. 2026-09-30 원장과 공식 HTML·TXT 원문은 이전 경로에 보존했다.

현재 전원 0초인 제주마 후보 147경주·1,393행의 취소·불성립 여부는 전부 확인됐다. 사유가 확인된 것은 140경주·1,363행이며, 나머지 7경주·30행은 취소됐지만 사유가 표시되지 않은 경우다. 사유 미표시를 취소 여부 미확정과 구분한다. 경주 결과 원천의 0값은 보존한다.

사용자가 알려준 9개 날짜의 취소 범위는 보유한 제주 전체 API에서 **67경주·613행**에 해당한다. 이 중 현재 제주마 후보에 포함된 것은 **7경주·30행**이다. [제주 전체 취소 확인 목록](user_confirmed_jeju_races.jsonl)은 후보에 없는 경주도 함께 보존한다. 모든 지정 경주의 API 완주시간은 전원 0으로, 사용자의 취소 판정과 양수 완주시간이 충돌하는 경주는 없었다.

| 날짜 | 사용자 확인 취소 범위 | 해당 제주 전체 API 경주 | 현재 제주마 후보 경주 | 제주마 후보 행 |
|---|---|---:|---|---:|
| 2002-07-06 | 전 경주 | 1~10R | 3R | 1 |
| 2002-08-31 | 전 경주 | 1~10R | 1R | 2 |
| 2002-12-07 | 전 경주 | 1~10R | 1R | 1 |
| 2003-02-23 | 전 경주 | 1~10R | 7R | 1 |
| 2004-05-15 | 1·2·6R | 1·2·6R | 없음 | 0 |
| 2004-05-16 | 2R 제외 전 경주 | 1·3~9R | 없음 | 0 |
| 2004-06-20 | 2·6·8·9R | 2·6·8·9R | 6R | 7 |
| 2004-06-26 | 1·4·6R | 1·4·6R | 4R | 10 |
| 2004-07-04 | 전 경주 | 1~9R | 7R | 8 |

표의 전 경주 번호는 현재 API 보유본에서 확인된 번호다. 날짜 전체 취소 확인은 별도 원문 범위로 보존했으며, API에 없는 경주번호를 만들어 추가하지 않았다.

## 제주 전체와 제주마 후보 목록이 다른 이유

기존 0초 원인 감사의 대상은 제주 경마장 전체가 아니라 `jeju_race_population_candidates`에 출전행이 있는 경주였다. 이 뷰는 `race_result_rows`의 `rank_class_candidate`, `api_cross_reference_candidate`, `program_rule_candidate` 행을 고른다. 경주 모집단 후보와 개별 말의 품종 확정은 동일한 상태가 아니다.

추가로 알려준 2004-05-15 1·2·6R은 API 등급 원문이 각각 `한3`, `한3`, `한4`이고 현재 제주마 후보 행이 없다. 당일 후보인 4R은 등급 원문 `제1`이며 9행 중 8행에 양수 완주시간이 있어 전 경주 취소 사례가 아니다. 2004-05-16은 2R에만 양수 완주시간이 있고, 나머지 취소 경주는 `한...` 또는 `래3` 등급 원문으로 현재 후보 행이 없다.

5월 두 날짜의 취소 출전행 98행·98개 말 ID를 API20_1과 직접 대조했다. 98행 모두 경주일 이전 또는 당일에 동일 말 ID의 `majong=한라` 또는 `한라(래)` 관측이 있고, 같은 조건의 `majong=제주` 관측은 0행이다. 이 두 날짜의 취소 자료는 API 원천에 있으나 제주마 후보 규칙에 포함되지 않은 경우다. 각 경주의 사전 API20 관측 여부도 [전체 취소 확인 목록](user_confirmed_jeju_races.jsonl)에 기록했다. 관측된 마종 라벨과 경주 당시 품종의 최종 확정은 구분한다.

2002~2003년과 2004-07-04는 등급 원문이 비어 있는 행도 많다. 이 날짜의 후보는 동일 말 ID의 API20_1 제주 품종 관측과 연결된 일부 출전행으로 구성된다. 따라서 후보 밖의 모든 경주·말을 한라마로 확정해서 제외했다고 해석하면 안 된다. 현재 필터에 포함되지 않은 상태와 품종이 비제주로 확정된 상태는 구분한다.

## 재현과 저장 범위

[판정 반영 코드](build_confirmed_review.py)는 사용자 확인 범위를 보유 API에 펼쳐 완주시간 충돌을 검사하고, 기존 76경주 원장에 새 판정 필드를 붙인 결과를 별도 파일로 만든다. [집계 결과](summary.json)에 날짜별 전체 API 경주와 제주마 후보 포함 여부를 기록했다. SQLite DB는 읽기 전용으로 열었으며 이번 작업은 검토 원장과 문서에 판정을 반영한 것이다.
