# 제주 능력 평가와 환경 조건의 현재 해석

2026년 10월 8일 사용자 요청으로 이전 연구의 해석을 보존한다. 말의 동일거리 반복 수행과 최근 상태를 평가 중심에 두되, 함수율·월·게이트는 기록을 해석하는 조건으로 함께 본다. 현재 고정 보정치를 확정하지 못했다는 사실을 환경 영향이 없다는 근거로 사용하지 않는다.

800m는 시간과 입상 양쪽에서 내측 연관성이 관찰됐다.900m는 입상 이점이 뚜렷하고 시간 환산은 불확실하다.1000~1200m는 일관된 내외측 차이의 방향·크기가 불확실하며,1300·1400m는 제한표본,1610m는 판단 부족이다.모두 정확10두 게이트 연구의 범위다.입상률 차이를 초 단위 보정치로 환산하지 않는다.

함수율과 계절·월에 따른 기록 차이는 관찰됐지만,고정 초 단위 환산과 기간 재현성은 아직 불확실하다.계절별 차이에 함수율·말 구성·성장·능력 변화가 섞일 수 있어 ‘주로 영향은 없고 계절 영향만 있다’고 나누지 않는다.순수 인과효과나 실제 반사실 환산 정답을 관측한 연구가 아니다.
