# 말별 평소 출전 주기 이탈과 적정 주기 후보

2026-10-15 사용자 요청. 각 말의 평소보다 짧거나 길게 출전했을 때의 수행 변화와, 말마다 다른 적정 출전주기를 찾을 수 있는지 확인한다. 결과 산출 전 설계를 고정한다.

## 평소 주기의 정의

앞선 `20261015_start_interval_v1`의 불변52,155출전 및 보유원장65,269관측출전을 재사용한다. 같은 공식말ID, 정상착순1~89 또는관측출전91/92,2002~2026이력·결과2017-01-13~2026-09-19,현재8거리·원천7~13두·400m/제외말결과미편입을상속한다. DB접속·외부수집·운영변경 없음.

각대상경주의 T−2까지 종료된 최근5개 출전간격(종료일이cutoff이전,최근730일)의 중앙값을 평소주기로 정한다. 최소3개 간격을 요구한다. 현재간격은 평소주기 계산에서 제외한다. 과거의긴공백도임의삭제하지않고중앙값으로영향을완화한다. 현재간격/평소주기의 비율을짧음(<0.75),평소범위(0.75~1.25포함),김(>1.25~2),매우김(>2)으로고정한다. 평균·중앙절대차이일수와비율,평소주기분포·말별이력지원·모든출전연결ID·시점을보존한다. 민감도는최근10개중앙값(같은730일·최소3개)이다.

## 평소보다 짧거나 길 때의 성적

기간별전체/2017~2023/2024~2025/2026 및거리별원시착순·직전대비변화·Top3·상대기록을표본과구간으로저장한다. 주비교는평소범위대비3군이다. 경주와말×정확거리고정효과,과거전체/동일거리착순·상대기록·이력수·직전성적,부담·체중·게이트·현재기수/조교사,로그평소간격·간격관측수·과거간격MAD비율을고려한다. **절대간격구간(이전연구8범주)도함께조건에포함**해단순히2주간격이유리한현상과자기평소주기이탈의추가연관을구분한다. 비교항은무벌점,표준화조건/결측표시/절대간격/관계자더미는ridge1이다. 민감도는절대간격통제제외(without_absolute)와최근10개평소주기(median10)이며새확정후보를추가하지않는다.

목표상대시간(빠름양수초),10두환산착순의질(상위양수),Top3(%p). 지원은각군/기준군100출전·30두·20일·같은말거리에서양군관측20두,모형30경주/30두/20일·잔여자유도>20·비교항식별이다. 날짜·말군집t95%를각각저장하고같은방향+날짜BH q<.05를지원기준으로한다. 전체거리의전체/최근2기간×3목표×지원비교는하나의BH가족,거리별은별도가족이다. 최근두기간반복은동일비교의양기간지원이다. 독립미래검증·인과효과로부르지않는다.

## 말별 적정 주기 후보와 이후 확인

평소자주나온주기와성적이좋았던주기를구분한다. 개인별정확한최적일수를강제로추정하지않고절대구간1~7/8~14/15~28/29~42/43~90/91일이상을비교한다. 발견표본은현재/이전관측을확인하고평소주기최소이력이있는선정출전이다.

2024년용후보는2017~2023년(2023-12-30까지),2026년갱신후보는2017~2025년(2025-12-30까지)만사용한다. 각발견표본에주기변수없는경주+말거리효과/과거수행·부담·체중·게이트·기수/조교사조정을적합한다. 그훈련표본잔차의빠른방향평균으로말별구간을비교한다. 총20출전이상·각5출전이상인구간2개이상인말만가장좋은관측구간후보를고른다. 같은자료에서최대값을고르므로발견차이는우세검증이아니다. 전체말의보류/후보·차선/차이·표본·훈련상한을남긴다.

**2024고정후보를변경하지않고**2024~2025년과2026년에같은후보구간에나왔을때다른구간보다좋았는지확인한다. 말능력·편성·절대간격을이미사용한연도고정H1의기대초과기록(`H1_time_adv`,빠름양수)을주확인목표로쓴다. 새H1은학습하지않는다. 개인별비교는절편+후보구간일치여부+정확거리/연도더미의OLS,총20출전·일치/비일치각5회·10일·잔여자유도>5·거리조건후식별을요구한다. 개인말한두만으로말군집구간을계산할수없으므로날짜군집t95%를사용한다. 양기간모든적격개인검정을한BH가족으로평가하고양기간양수지원인말만반복후보로표시한다. 관측한조건부개인차이이며관계자선택/컨디션인과식별은아니다.

2026갱신후보의2026년확인은별도사후탐색BH가족으로보관하고두기간반복주장을추가하지않는다. 전체말프로필에개인최적확정과단순과거후보를구분한다. 집단검증으로2024고정후보일치효과를같은말거리/경주와절대간격을고려한후속2기간에서별도비교하고날짜/말구간및2검정BH를제공한다. 이집단추가확인은기대초과기록을목표로하고적격30두·20일·각군100출전·양군관측20두를요구한다. 기존기간재사용의시간순서후향확인이지독립새미래검증은아니다.

## 검증과 저장

평소주기이력창은 말별 별도순회로 종료ID/일자와 중앙값을 전수재구성하고 현재/미래기록을 추가·변경해 현재주기가 변하지 않는지 확인한다. 모형계수·구간·지원/BH는 별도합동고정효과방정식으로 검증한다. 개인후보는cutoff이전잔차만으로 독립재선정하고 확인표본의ID·기간·계수/날짜분산·BH를 재계산한다. 원천해시·분모·코드·전체표·보류·채택상태·한계를 새날짜폴더에 저장하고, 출전주기결론문서/README/SOURCES/등록부/manifest를 갱신한다. 기존연구·DB·운영·기수전체/각질 재개대기 상태는 보존한다.
