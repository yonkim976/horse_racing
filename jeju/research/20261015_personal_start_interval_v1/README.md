# 제주마의 평소 출전 주기와 말별 적정 주기 후보

**평소보다 짧게 나왔다는 이유만으로 추가로 유리하다고 확정하지 못했다.** 실제 간격이 며칠인지까지 고려하면, 앞선 연구의8~14일 우세와 개인 평소주기 이탈의 추가 연관은 구분된다. 평소보다 긴 경우는 전체기간에서 성적이 낮은 연관이 있었지만 최근 두기간에 반복 확인되지는 않았다.

**말마다 과거에 성적이 좋았던 구간 후보는 찾을 수 있으나, 이후 성적까지 확인해 개인 적정 주기로 확정한 말은 없었다.** 자료가 충분하지 않은 말은 미확정으로 남겼다. 개인별 주기가 존재하지 않는다는 증명은 아니다.

## 말마다 평소 주기는 다르다

평소주기는각경주T−2까지끝난최근5개출전간격의중앙값이다. 종료일최근730일·최소3개이력을요구하고현재간격은계산에서뺐다. 2017-01-13~2026-09-19 원천52,155출전에서44,720출전·2,246두가이조건을충족했다. 직전간격미관측1,946건,간격은알지만평소주기이력이부족한5,489건은분리했다.2026년은09-19까지부분연도다.

2026년출전이관측됐고자료상한까지평소주기를계산할수있는809두의중앙평소주기는21일,사분위는15~31일,10~90백분위는14~55일이었다. 21일인말128두·14일118두·15일99두가관측됐지만,전체말에게21일을일괄대입하지않는다. 이최신프로필은2026-09-19까지끝난관측출전으로계산한기술정보이며,경주별T−2평소주기와시점이다르다.

## 말별로 과거에 좋았던 구간 후보

평소자주출전한간격과성적이좋았던간격은별도로관리했다.1~7/8~14/15~28/29~42/43~90/91일이상6구간으로나누고,훈련표본에서경주·말거리·과거수행·부담·체중·게이트·기수·조교사를고려한뒤남는빠른방향잔차를비교했다. 주기변수는이발견모형에넣지않았다. 총20출전이상·각5출전이상인구간2개이상인말만후보를골랐다. 같은훈련자료의최대값을선택하므로이단계의최고구간은확정우세가아니다.

- 2023-12-30까지자료로2024년전에고정한후보:532두.
- 2025-12-30까지자료로갱신한2026년용후보:708두. 이중2026년선정출전이관측된말은251두다.708두전체가현재활동마라는뜻은아니다.

2026갱신후보분포는8~14일295두,15~28일212두,29~42일57두,43~90일58두,91일이상43두,1~7일43두다. 이는서로다른구간지원조건을충족한과거성적후보의분포이며,모든말의확정적정주기분포가아니다.1~7일후보는과거자료에서고른것이고최근실제출전표본이없다.

2024고정후보가2026갱신후보와같은말은532두중452두였지만훈련자료가많이겹친다. 이를독립된적정주기재현성으로세지않았다.

## 이후 경주에서도 좋았는가

2024고정후보를바꾸지않고이후해당구간에출전했을때를확인했다. 목표는연도고정H1예상대비빠른기록(`H1_time_adv`)이다. H1은말능력·편성·절대간격등을이미고려하므로개인후보일치의추가수행을확인하는데사용했다. 새H1이나운영모형을학습하지않았다.

집단비교도경주·말거리·절대간격과현재과거수행조건을고려했다.2024~2025년말구간은+0.043~+0.339초,2검정BH q0.039로지원됐지만2026말구간−1.062~+0.982초,q0.928로반복되지않았다. 과거의잘맞던구간에다시나오는것이일관되게추가우세라는주장은보류한다.

개별말확인은같은말의후보구간일치/비일치에서H1기대초과기록을거리·연도로조정했다. 사전최소20출전·각5회·10일기준에서2024~2025년35두가적합됐으나BH양수지원은0두였다.2026고정후보의관측최대16회,갱신후보최대17회로개별주확인최소20회를충족한말은없었다. 이보류를효과0으로표시하지않았다.

[소표본 탐색 설계](SMALL_SAMPLE_PLAN.md)에따라최소10출전·각3회·8일로완화한별도탐색도저장했다.2024고정후보의2024~2025년96두/2026년11두,2026갱신후보의2026년31두를적합했으나별도BH를통과한양수사례는모두0개였다. 이사후지원완화로새확정후보를추가하지않았다.

## 범위와 해석
