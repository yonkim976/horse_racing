# 제주마 원기록 평가표와 Top3 기준선 비교

2026년 10월 8일. 효과 계산 전에 고정하는 제한된 후향 개발 비교다. J0는 최근 동일거리 원기록 중심의 최소 모델, J1은 J0에 최고·반복 수행·편차·변화와 관측수를 추가한다. 기존 제주 환경 파일럿의 현재 부담중량·상대능력 입력을 승계하지 않는다. 입력 수 자체가 목표는 아니다.

## 자료와 시점

로컬 DB `jeju/data/jeju_native_core.sqlite3`의 `jeju_race_postrace_sections_quality_2026`를 읽기 전용으로 조회한다. 자료 상한은 2026년 9월 19일, 학습 정답은 2017년부터다. 2002년부터 보유한 이전 출전은 warm-up이다. 공식 말 ID로 연결하고 제외 말은 편입하지 않는다. 최신 이름은 표시용이며 학습 입력이 아니다. 최신 프로필의 품종은 과거 사건일의 품종 확인을 뜻하지 않는다.

과거 이력은 한국 날짜 `history_date <= target_date - 2일` 전체를 포함한다. 정상 착순 1~89와 주행중지·실격 코드 91·92를 관측 출전으로 센다. 취소·미출주·불명 코드는 출전 경력에 포함하지 않는다. 자료 부재는 신마·평생 경력 0의 증명이 아니다. 현재 스냅샷의 정정 후 기록과 날짜 기준 가용성을 사용하며 당시 게시·정정 시각까지 재생하지 못한다.

이번 거리·원문 등급·편성은 결과 원장에서 재구성한 조건이다. T−2 당시 등록표 가용성과 실제 출주집합 변동은 확인되지 않았다. 따라서 이 실험은 실제 T−2 운영 성능 검증이 아니다. 당일 주로·체중·시간·착순·현재 사건 나이·성별·중량·출발번호는 모델 입력에서 제외한다. 현재 번호는 동점 정렬과 조합 식별에만 쓴다. 기수·심판·구간·조교·심사·배당·영상도 제외한다.

## 평가 모집단

현재 대상 800·900·1000·1110·1200·1300·1400·1610m를 함께 학습한다. 400m는 과거 이력 경력에만 남긴다. 경주별 6두 이상, DB 결과 원장 전체 행수와 후보 수 일치, 고유 말 ID·양수 번호, 전원 정상 숫자 착순·양수 전체시간, 착순 정확 1~N, 동일 거리·원문 등급을 요구한다. DNF·실격·동착·취소·부분 편성·불완결 경주는 경주 전체를 제외하고 사유를 남긴다. 이는 사후 선택 모집단이며 비정상 결과까지 포함하는 운영 전체에 일반화하지 않는다. 대상 경주 안에서는 이력 부재·저경력·기록 결측을 이유로 말 또는 경주를 추가 제외하지 않는다. 희소 거리는 합동 모델의 예측을 보존하되 별도 지원량과 결과를 표시한다.

## 말별 평가표

동일거리 실제 관측 출전 순서의 최근 5회 창을 사용한다. DNF·실격·시간 결측도 창의 한 자리를 유지하고 유효 시간을 NULL로 둔다. 예전의 ‘최근 유효 기록 5개’를 찾는 foundation·환경 파일럿과 다르므로 해당 결과를 덮어쓰지 않는다. 다른 거리 시간을 환산하거나 혼합하지 않는다. 시간이 작을수록 빠른 원기록이다.

| 항목 | 계산 |
|---|---|
| 최근 기록 | 동일거리 직전 출전 시간, 최근 5회 유효 시간 평균과 n |
| 최근 3회 | 최근 3회 창의 유효 시간 평균과 n |
| 최고 | 최근 5회 유효 시간 최솟값 |
| 반복 수행 | 최근 5회 빠른 시간 2개의 평균, 유효 n≥2 |
| 안정성 | 최근 5회 유효 시간 표본 표준편차 ddof=1, n≥3 |
| 이전 수행 | 동일거리 4~6번째 이전 출전 창의 유효 시간 평균과 n |
| 변화 | 최근 3회 평균 − 이전 3회 평균, 양쪽 n≥2. 음수는 빨라진 방향 |
| 경력·신뢰도 | 전체 관측 출전수, 동일거리 출전수·유효 시간수, 직전 출전 및 동일거리 출전 이후 일수 |
| 과거 상태 | 직전 실제 출전의 원문 사건 나이·성별. 결측이면 더 오래된 값으로 건너뛰지 않음 |

최고 기록 당시 날짜·거리·주로·등급·부담중량과 각 창의 원천 ID·NULL을 예시에 남긴다. 조건은 설명용이며 이번 J0/J1에서 보정에 사용하지 않는다. 임의 가중 종합 점수는 만들지 않는다.

J0 13열: 이번 거리·원문 등급·두수, 관측 출전수·출전 간격·직전 사건 나이·성별, 동일거리 출전수·유효 시간수·최근 동일거리 출전 이후 일수, 직전 동일거리 시간·최근5회 평균·유효 n5.

J1 추가 8열: 최근3회 평균·유효 n3, 최근5회 최고·빠른2회 평균·표준편차, 이전3회 평균·유효 n, 최근3회−이전3회 변화. J0의 모든 열을 유지하고 제거 열은 없다. 결측은 LightGBM의 결측 분기로 처리한다. 관측수 0과 시간 NULL을 구분한다. 원문 등급·직전 성별 범주는 초기 학습 구간의 어휘만 사용하고 미등록 범주는 결측으로 둔다.

## 학습과 확률

비교는 uniform·J0·J1뿐이며 결과를 본 추가 튜닝은 하지 않는다. J0/J1은 같은 합동 거리 LightGBM binary Top3 모델, 동일 하이퍼파라미터와 경주 균등 가중치를 쓴다. seed 20261008, learning_rate 0.04, num_leaves 15, min_data_in_leaf 100, lambda_l2 5, 최대 200회, 조기종료 25회, 스레드 4. 버전과 최종 트리 수를 저장한다.

평가 연도 Y=2024·2025·2026마다 초기 학습 2017~Y−3, 조기종료 Y−2, 결정된 트리 수로 2017~Y−2 재학습, 온도 보정 Y−1, 평가 Y로 분리한다. 전처리·어휘는 초기 학습만 사용한다. 평가 중 이미 발생한 T−2 이전 이력은 갱신하지만 모델·온도는 재학습하지 않는다. 2026년은 9월 19일까지의 부분연도다.

경주 내 순서 없는 3두 집합 S에 `P(S)=exp(sum(z_i for i in S)/tau)/sum_over_all_triples(exp(sum(z_i)/tau))`를 부여하고 주변 Top3 확률을 합산한다. tau는 전년도 경주 균등 집합 NLL을 [0.35,4]에서 최소화한다. 이는 말별 점수의 가산 집합 모형이며 동반입상 상호작용을 학습한 모형이 아니다. 확률 합 3·집합 확률 합 1을 검증한다. 점수 동점은 현재 출발번호 오름차순으로 고정하며 번호를 학습 입력으로 쓰는 효과와 구분한다. 동일 점수 집합의 부동소수점 덧셈 순서가 조합 우선순위를 바꾸지 않도록 정렬 후 합산한다.

## 지표와 유지 판단

주지표는 경주 균등 말별 Top3 binary log loss·Brier다. runner 균등도 따로 보존한다. 상위3·4·5·6두의 실제 입상마 포함 비율, 상위5두 전원 포함률, 최대6개 서로 다른 삼복승 조합 적중률·집합 NLL·확률 구간 보정을 저장한다. 적중률은 수익률이 아니다.

전체·연도·거리·원문 등급, 이력0·1~4·5+ 및 같은 거리 기록 부재를 나눠 본다. 포함률의 분모는 경주별 실제 입상마 3두다. 경주일 paired bootstrap 2,000회로 J1−J0 및 J0−uniform 95% 점별 구간을 계산한다. 하위군 구간은 탐색용이며 다중비교 확증에 사용하지 않는다.

J1의 연구 기준 유지 근거는 전체 두 확률 손실이 모두 낮아지고 적어도 하나의 개선 구간이 0을 제외하며, 다른 핵심 지표와 연도별 퇴행을 함께 확인하는 것이다. 이를 충족하지 못하면 J0와 J1을 후보로 보존하고 자동으로 다음 기준선에 합치지 않는다. 어느 경우에도 운영 승격하지 않는다. 이미 본 2024~2026년 결과는 독립 미래 검증이 아니다.

## 확인과 보존

학습 전 감사·제외 원장·평가표 사례·계산 검증을 저장하고 계약·코드·피처 해시를 고정한다. 독립적인 과거 이력 재계산, T−2 경계·무이력·비정상 출전 창 유지, 모델 재로딩, 경주별 확률·조합·지표 재계산을 검증한다. DB와 기존 운영 모델의 전후 해시를 비교한다. 코드·모델·예측·전체 표·한계는 이 새 폴더에 저장하고 연구 결론 모음에 연결한다.
