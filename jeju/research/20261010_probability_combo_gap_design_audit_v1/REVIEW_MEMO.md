# 조합 gap 진단 1차 원천·설계 검토 메모

검토일: 2026-10-10. 검토 목적은 `F1_STYLE6` 저장 점수의 조합 gap 진단에 앞서 원천·확률 구조·선행 연구와 해석 한계를 확인하는 것이다. 본 메모는 결과를 새로 계산하지 않았고 DB에 연결하지 않았다.

## 1차 판정

저장된 `F1` 및 `F1_STYLE6` 점수로 진단을 설계할 수 있다. 평가용 원시 점수는 말별 LightGBM raw score(logit)이며, 확률은 경주별 가능한 모든 3두 무순위 집합의 additive score를 온도 보정해 정규화한 분포에서 유도한다. 이를 ordered 1·2·3착 분포나 말별 정확 2·3착 확률로 부르면 안 된다.

새 분석의 후보 union과 배분 실패 분해는 `20261009_axis_companion_pairs_v1`의 후보군 포괄 상한과 문제의식이 겹친다. 다만 그 연구는 R1 점수 1위 축을 고정하고 축이 실제 Top3에 든 경주에서 상대 2두를 순위 2~7위 pool의 15쌍 가운데 6개로 선택한다. 새 진단은 축을 고정하지 않고 전체 실제 Top3 무순위 집합과 F1 계열의 공동 set 분포에서 상위 k개 티켓의 horse union을 만든다. 이 차이를 보고서에 밝혀야 한다.

## 확률·선택 구조

`20261010_style_history_ablation_v1/run.py`는 평가 경주별 raw score `z_h`를 저장한다. 앞선 F1의 `parts()`와 `evaluate()` 구현은 전체 `C(N,3)` 무순위 집합 `S`마다 `E(S)=Σ(h∈S) z_h`를 만들고 다음 분포를 사용한다.

`Qτ(S) = exp(E(S)/τ) / ΣT exp(E(T)/τ)`

말 `h`의 Top3 주변확률은 `pTop3(h)=ΣS:h∈S Qτ(S)`이다. 따라서 이 점수 구조는 Top3 집합 분포이며, 개별 말의 순서별 조건부 확률을 담지 않는다.

동점 재현 시에는 원 구현의 순서를 유지해야 한다. horse 행은 마번 오름차순이며, 삼두 raw score는 정렬 후 `(z₁+z₂)+z₃`로 합산한다. set 선택은 이 에너지를 내림차순 `stable` 정렬하고 조합 열거 순서를 동점 tie-break로 쓴다. 주변확률 horse 순위도 raw score 내림차순 `stable` 정렬이다.

F1/STYLE6 저장 meta의 연도별 τ는 다음과 같고 모두 양수다.

| 평가연도 | F1 τ | F1_STYLE6 τ |
|---|---:|---:|
| 2024 | 1.014653 | 1.100645 |
| 2025 | 1.095057 | 1.115658 |
| 2026 | 0.986406 | 0.971946 |

τ가 양수이면 같은 모델·같은 경주 안에서 `E(S)`와 `Qτ(S)`의 순위가 같다. 따라서 온도 보정은 각 티켓의 확률 질량은 바꾸지만, canonical 상위 k set의 순서와 선택 결과는 바꾸지 않는다. 말 주변확률도 원 점수 순서를 보존한다. `w_h=exp(z_h/τ)`라 하면 `pTop3(i)-pTop3(j)=(w_i-w_j)e₂(w_{−i,−j})/Z`이고 나머지 말이 2두 이상인 정상 출전집합에서 마지막 계수는 양수다. 동률은 원 구현의 stable 말 행 순서 및 조합 열거 순서가 처리한다. 따라서 F1과 STYLE6 사이의 순위·선택 차이는 후보 입력·학습 점수의 차이로 해석할 수 있지만, 한 모델에서 raw score 선택과 τ 적용 선택이 달라졌다는 결과는 구현 불일치 점검 대상이다.

이 set model에는 명시적 pair-specific joint interaction이 없다. 경주 안에서 서로 다른 i,j,k,l에 대해 `Qτ({i,j,k}) / Qτ({i,j,l}) = exp((z_k−z_l)/τ)`다. 제3말 교체 odds는 이미 포함한 i,j에 따라 추가로 달라지지 않는다. 다만 `z_h` 자체가 경주·편성 맥락 입력에 의존할 수 있고, 정확히 3두를 포함하는 고정 크기 집합은 서로 배타적인 결과 공간이므로 말별 주변 사건들은 의존한다. 이 모델을 독립 말별 확률의 곱이라고 부르면 안 된다. 이 구조 차이는 후속 pair-conditional 모델 가설의 근거가 될 수 있지만, 이번 진단만으로 실제 pair 효과나 성능 개선을 확인하지 않는다.

모델 간 raw logit 크기는 공통 단위가 아니다. `F1`과 `F1_STYLE6`의 raw 점수 차이를 능력 차이나 확률 차이로 직접 해석하지 않는다. 점수 순위와 티켓 집합 교체율은 모델별 경주 안에서 비교하고, 분포 질량·주변확률·실제 Top3 집합 NLL을 비교할 때는 해당 모델과 평가연도에 저장된 τ를 적용한다.

이번 진단에서 사전 고정한 티켓 수는 `k∈{1,3,6,10,20}`이다. 모델이 지정한 같은 경주에서 같은 수 k장의 삼복 조합을 산다고 둘 때, `Qτ`가 부여하는 hit 확률은 선택 집합의 `ΣQτ(S)`다. 그러므로 각 모델이 자기 `Qτ`에서 고른 상위 k개 티켓은 그 모델 분포 아래에서 기대 hit 확률을 최대화한다. 후보 horse union `U_k`도 F1과 STYLE6 각각의 선택 티켓으로 따로 만든다. 두 모델 티켓을 합친 pooled union은 사용하지 않는다. 이 성질은 실제 적중 보장이나 확률 보정의 증거가 아니다. k를 늘리면 보유 조합이 늘기 때문에 k가 다른 hit율은 모델 개선 비교가 아니다. k>6은 이번 진단에서 사전에 고정한 추가 민감도 진단으로 표시한다.

## 후보 포괄과 조합 배분

진단에서 각 k에 대해 선택한 티켓들의 마번 또는 horse ID 집합 합집합을 `U_k`, 실현된 Top3 무순위 집합을 `T`로 둘 수 있다. 결과를 다음 세 사건으로 상호 배타적으로 분류하면 후보 생성과 조합 배분을 나눈다.

1. 적중: `T`가 선택된 티켓 중 하나와 같다.
2. 배분 실패: `T ⊆ U_k`지만 `T` 자체는 선택 티켓에 없다.
3. 후보 union 실패: `T ⊄ U_k`.

완전한 Top3 집합 하나가 있는 평가 경주마다 정확히 하나의 분류가 되어야 하며, 각 k에서 세 비율 합이 1이어야 한다. 이 분해의 “후보”는 상위 k개 공동 티켓에 등장한 말의 union이다. 기존 축 연구의 R1 상대 6두 후보군과 섞어 부르면 안 된다.

이미 보고된 `Top5 capture`는 점수 상위 5두에 들어온 실제 Top3 말의 수 비율이고, `Top5 all3`는 실제 Top3 집합이 그 5두 안에 전부 들었는지의 사건이다. 이는 상위 6 joint ticket의 상한이 아니다. 실제 Top3 세 말이 상위 5두에 모두 있더라도 고정된 6개 canonical joint 티켓 중 하나에 그 조합이 없을 수 있고, joint 티켓의 union 크기와 말 순위 상위 5두의 집합은 다른 기준이다.

## 선행 axis-companion 연구와 중복 경계

`20261009_axis_companion_pairs_v1`은 축을 고정하고 `P(나머지 실제 Top3 두 마리 | 축이 Top3)`를 모든 상대 쌍에 대해 모델링한다. 주 정책은 R1 순위 2~7위의 15쌍에서 6개를 선택한다. 축이 Top3가 아닌 경주도 전체 six-hit 분모에는 남지만 상대 조건부 포착률 분모에는 들어가지 않는다. 저장된 조건부 확률은 축 탈락 사건의 전체 순서·집합 분포를 제공하지 않는다.

그 연구는 후보 pool 안에 실제 상대 두 마리가 들어오는 범위와 선택 실패/기존 적중 손실을 이미 보고했다. 따라서 일반적인 “후보군 miss와 티켓 배분 miss를 나누자”는 발상만으로 새로움을 주장하지 않는다. 새 연구가 더할 수 있는 점은 (a) 축 조건 없이 모든 평가 경주의 실현 Top3 집합을 대상으로 하고, (b) 후보를 저장된 전체 Q의 top-k 티켓 union에서 정하며, (c) 같은 1,779경주·17,412 출전의 F1 대 STYLE6 차이를 공동 집합 확률 구조 안에서 대조한다는 것이다.

## native PL과 additive set 모델의 비교 가능 범위

`HY_R_FORM`의 native Plackett–Luce(PL)는 순서 확률을 구성한 뒤 순서 없는 Top3 집합과 말별 Top3 주변확률을 유도한다. F1 계열 additive model은 세 말 점수의 합으로 unordered Top3 집합 Q를 직접 정규화한다. 같은 roster와 label의 점수가 두 모델 모두에 있을 때 Top3 주변확률 log loss/Brier, 실제 unordered Top3 집합 확률/NLL, 동일 티켓 수의 set hit를 비교할 수 있다. 현재 저장된 운영 직접대조는 공통 467경주에 한정된다. 기존 1,779경주 전부로 native PL을 대조하는 자료 범위는 확인되지 않았다. 또한 같은 입력·같은 학습 목표에서 확률 구조만 바꾼 통제 비교가 아니므로 차이를 구조의 인과 효과로 귀속할 수 없다.

PL은 순서 분포를 제공하지만 additive set Q는 이를 제공하지 않는다. 그러므로 F1 계열과 native PL의 정확 2착·3착 확률, `i→j→k` 삼쌍승, 승식 순서 확률을 이 진단만으로 비교할 수 없다. 기존 목표 문서에 있는 동착·취소·실격·미완주 규칙도 normal complete cohort 밖으로 자동 확장하지 않는다.

## 표본·시점·후속 학습 경계

원래 STYLE6 평가의 1,779경주·17,412 출전·269 경주일은 2024-01-05~2026-09-19 저장 평가 코호트이며 2026은 부분연도다. 코호트는 사후 정상 완주와 완전 출전집합을 기준으로 했고, 과거 당시 예측 대상 출전집합 및 공식 공개 시각을 복구하지 못했다. 날짜순 연도 분할은 당시 정보가 공개됐다는 증거가 아니며, 같은 과거 labels의 반복 사용은 fresh label이나 독립 미래 holdout을 만들지 않는다.

기존 결과에서 말별 Top3 log loss와 Brier는 개선됐지만 canonical 최대 6조합 hit의 날짜 paired 구간은 0을 포함했고, 2025·2026 six-hit 점추정은 F1보다 낮았다. 새 계산 없이 읽은 기존 보고서의 판정이다. 이번 진단이 확인할 수 있는 것은 저장 공동분포의 순위·질량·고정 k ticket 선택 및 실패 위치이며, 스타일 입력의 인과 효과나 새 확률모형의 일반화 성능은 아니다.

조건부 pair/조합 학습을 후속 제안하려면 새 시간순 OOF를 생성하고, 같은 출전집합·결과·학습시점에서 공정 대조를 고정하며, 양쪽의 조합 예산을 6장으로 맞춰야 한다. 이번 조합 gap 진단은 자동으로 그 학습을 시작하거나 운영 모델을 바꾸는 승인이 아니다.

## 근거 검토와 수행 범위

설계·원천 파일의 SHA-256과 검토 범위는 [README](README.md)의 표와 [source manifest](source_manifest.json)에 기록했다. 기존 `prepared_lock.json`은 기준선 replay 산출물과 원천 감사 문서·cache의 해시를 선언하며, `source_audit_reference.json`은 원천 감사 대상 및 고정 cache 해시를 적는다. 이번 검토에서는 소형 잠금·코드·문서·저장 점수 파일의 현재 SHA를 확인해 기재했고, 기존 대형 원천 cache 및 DB 전체는 다시 해시하지 않았다. 그 SHA는 기존 lock에 선언된 값으로 구분했다.

검토 중 DB query/open, 학습, τ 재최적화, 외부 수집, 결과 metric·bootstrap·새 분류 통계 계산은 하지 않았다. 이 메모는 분석 코드 구현의 보안 감사를 대신하지 않는다.
