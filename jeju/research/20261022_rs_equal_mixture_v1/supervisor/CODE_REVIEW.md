# 감독관 실행 전 검토

2026-10-22. 실데이터 E 평가 전에 출처 감사, 설계, 실행 경로와 서브에이전트 검토를 확인했다. 결론은 고정된 후보 1회의 확률 평가 실행 허용이다. 사용자에게 재승인을 받는 절차가 아니다.

- 기존 4개 세션 연구의 242개 파일과 운영 등록부·HY_R_FORM을 합쳐 244개 파일의 해시·크기가 시작 상태와 일치한다. DB는 열지 않는다.
- R/S 원시 점수와 각 연간 PL temperature는 해시가 고정된 기존 산출물이다. F1 meta의 별도 tau를 PL temperature로 잘못 사용하지 않는다. 전년도 보정 및 과거 학습 범위, T−2 포함 경계, 정확한 명단 결합을 감사 기록과 대조했다. 기존 S 모델·온도 재현은 직전 연구의 검산 결과를 참조하고 이번에는 다시 학습하지 않는다.
- 실제 계산 경로는 두 raw score/T 벡터로부터 full-field PL Q를 정확히 반반 혼합한다. 승식 사건은 그 전체 첫 3착 분포에서 합산하며 승식별·연도별 다른 가중치나 보정 경로가 없다. 점수 평균이나 저장 조합의 재정규화도 없다.
- 복승·복연승 상위 1/3쌍의 합집합과 적중수 PMF는 같은 Q의 모든 순열을 순회해 계산한다. 표 선정은 확률과 1e−12 동률 범위·마번 사전순을 사용한다. 정답은 평가에만 사용한다.
- 승식 정의·최소 출전두수·연승 36경주 격리를 유지한다. 결과 모집단은 전원 정상 완주·완전 착순의 회고 자료이며 실제 모든 발매 상황을 재구축한 자료가 아니다.
- Log loss/Brier의 경주 가중치와 고정 269일 bootstrap이 계약과 같다. 연승이 제외된 날짜도 전체 날짜 목록에서 count=0으로 처리해 재표집한다. 7승식의 확률 정확도와 축·표 선택 성과를 분리한다. 후보 채택은 E−S와 E−R의 고정 기준을 모두 요구한다.
- 소스·출력 경로는 연구 폴더에 고정돼 있고 기존 파일 쓰기·DB 쓰기·네트워크·pickle 로드가 없다. 재사용 모듈은 정해진 신뢰된 파일을 SHA-256 확인 후 bytecode 저장 없이 로드한다. Parquet은 필요한 E 열만 압축 저장하며 전체 Q는 저장하지 않는다. 이번에 만든 임시 Parquet만 작성 후 제거한다.
- 최초 fresh preflight 비교는 양쪽 timestamp 처리 불일치로 실행 차단 오류가 있었다. 결과 계산 전에 양쪽에서 timestamp를 제외하는 동일 비교로 수정했고, 최종 preflight와 재호출 일치를 작업자가 확인했다. 후보 수·평가 기준 변경은 아니다.
- 작업자 합성검사 8개 및 검토자 합성 단위검사가 통과했다. 감독관의 별도 공식은 5/7/8/12두 합성 편성에서 혼합·주변확률·정확한 복연 합집합을 검산했고 최대 오차는 9e−16 미만이다. 실제 E 결과는 아직 계산하지 않았다.

실행 후 감독관은 실데이터 모든 경주의 성분 R/S와 E 첫 3착 분포·7승식·표 선택·주변확률·확률 구간·bootstrap을 독립 검산한다. 혼합의 Jensen/Brier 항등식은 단일 성분보다 성능이 좋다는 증거로 사용하지 않는다. 재사용 개발기간·공개시각 미확인·시장 가격 미확보의 한계는 최종 보고에 남긴다.
