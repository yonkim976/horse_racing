# R/S 공동 착순 확률 50:50 혼합 — 결과 전 고정 계약

2026-10-22. 사용자의 앙상블 비교 실행 요청에 따른 단일 실험이다. 이 문서는 새 혼합 모델의 평가 결과를 계산하기 전에 고정한다. 기존 R/S 결과를 이미 확인했으므로 미관측 미래 검증이 아닌 재사용 개발기간의 비교다.

## 연구 질문과 후보

R은 F1_STYLE6 연구 기준선의 기존 원시 점수와 연간 PL temperature다. S는 직전 `20261022_tb_state_transfer_v1`의 상대 능력·거리 상태 10개를 추가한 연구 후보다. 운영 `HY_R_FORM`은 이 실험에 포함하지 않는다.

단 하나의 후보 E를 모든 경주·연도·승식에서 동일하게 `Q_E(i,j,k)=0.5 Q_R(i,j,k)+0.5 Q_S(i,j,k)`로 정의한다. 각 성분은 자신의 이미 고정된 연간 temperature를 먼저 적용한 full-field Plackett–Luce의 첫 3착 공동분포다. 원시 점수 평균, temperature 평균, 선택한 일부 조합 재정규화는 사용하지 않는다. 성분별 정규화된 전체 Q를 섞은 후 사건을 합산한다. 상위 3위 뒤의 전체 착순까지 추정했다고 부르지 않는다.

신규 GBM 학습 0회, 신규 보정 0회, 혼합 비율 탐색 0회. 50:50 이외 비율·연도별 가중치·승식별 가중치·추가 seed·입력·학습량 후보를 평가 결과를 본 뒤 추가하지 않는다. 결과가 불리하면 그대로 보고 보류한다.

## 원천·시점·모집단

F1_STYLE6의 기존 features.parquet를 라벨·키·전체 편성의 원천으로 경로와 SHA-256으로 참조한다. R의 연도별 evaluation_scores.parquet, S의 기존 candidate_oos_scores.parquet의 arm=S/role=evaluation 행, 양쪽의 기존 parameters.json을 재사용한다. 필요한 메타·코드·원장도 해시로 고정한다. 기존 DB 및 모델을 새로 조회·추론·복사하거나 변경할 필요가 없다.

Y=2024,2025,2026의 원시 점수 provider는 초기학습 2017..Y−3, early stopping Y−2, refit 2017..Y−2, 보정 Y−1, 평가 Y 계약을 따른다. R/S의 해당 provider별 보정값을 그대로 재사용하고 같은 해의 결과로 다시 맞추지 않는다. 이력은 기존 사건일 기준 T−2까지 포함한다. 실제 공개시각과 당시 최종 구매 가능 명단은 미확인이며 이번 혼합은 이 한계를 개선하지 않는다.

세 arm의 평가 집합은 2024~2026-09-19, 1,779경주·17,412두·269일로 동일하다. 연도별 637/654/488경주. 기존 전원 정상 완주·고유한 완전 착순 및 최종 기록 명단에 조건부인 회고 모집단을 유지한다. 기존 취소·비완주·동착 제외 계약을 완화하지 않는다.

승식 정의와 최소 출전두수는 기존 봉인 `20261022_joint_wager_baseline_v1/rules_contract/rules_contract.json`을 따른다. 실제 7두이고 발매 시작 명단 미확인인 36경주는 연승만 격리해 연승 1,743경주, 나머지 6승식 1,779경주다. 연승 적중 범위를 무조건 Top3로 두지 않는다. 동일한 규칙의 합성 소필드 검산과 예외 처리도 유지한다.

## 평가와 판정

주 비교 E−S, 기준선 보호 E−R이다. 각 비교에서 TRI(삼쌍승) Log loss 차이의 날짜 paired bootstrap 95% 상한<0, TRI Brier 차이<=0, WIN Log loss와 Brier 차이<=0를 모두 요구한다. 두 비교 모두 통과해야 E를 후속 연구 후보로 채택한다. 단승 보호는 점추정 기준이며 통계적 비열등성 증명으로 부르지 않는다. 실패하면 S 연구 후보와 F1_STYLE6 연구 기준선을 유지하고 E는 보류한다. 운영 등록부와 HY_R_FORM은 어떤 결과에도 자동 교체하지 않는다.

7승식 Log loss/Brier를 전체·연도별로 보고한다. WIN/QNL/EXA/TLA/TRI는 실제 배타적 사건의 categorical Log loss와 전체 표 Brier 합, PLC/QPL은 합법적인 표별 binary loss의 경주 내 평균을 구한 뒤 경주에 같은 가중치를 준다. 수치 안정화 EPS=1e−15. 확률 구간별 실제 적중률은 기존 16개 경계와 ticket-event pooled weighting을 유지하고 경주 평균 지표와 구분한다.

기존 2,000×269 날짜 bootstrap schedule과 전체 정렬 날짜 목록을 그대로 참조한다. 같은 날짜의 경주는 함께 재표집하며 선택적 거리·기간 제외나 bootstrap schedule 재선택을 하지 않는다.

선택은 승식별 최대확률 표 1장, max WIN 말의 Top3 입상, 복승·복연승 상위 1/3쌍으로 고정한다. 수치 동률 1e−12 및 마번 사전순으로 순차 선발한다. 모든 arm에서 경주·후보 수·구매 표수가 동일하다. 복연승 여러 표의 적중 합집합과 적중수 0..3 분포는 공동 Q에서 계산하며 주변확률의 단순합/독립곱으로 만들지 않는다. 선택 결과와 축 입상은 보조 지표로 성공 기준을 바꾸지 않는다. R 대비 상대 +10% 축 목표 1,126회는 참고하며 확률 평가의 대체물로 쓰지 않는다.

## 실행 검토와 독립 검산

asset_audit는 audit/, baseline_experiment는 experiment/, rules_contract는 review/, 감독관은 supervisor/와 루트 최종 문서·manifest를 소유한다. 실제 조사·구현·평가는 기존 세션 GPT-6 Luna xhigh 서브에이전트에 맡긴다. 중복 구현이나 새 채팅은 만들지 않는다. 감독관의 별도 구현은 독립 수치 검산에 한정한다.

실데이터 혼합 평가 전: 원천·정확한 명단·기존 temperature·시점 검토, 합성 확률 질량·주변확률·혼합 선형성·복연 합집합 검산, 코드의 고정 가중치 및 무학습 확인을 완료한다. 감독관이 코드·계약·preflight·원천 해시를 결합한 내부 승인 원장을 쓴 뒤 평가 1회를 실행한다. 사용자에게 재승인을 요청하는 절차가 아니다.

감독관은 실데이터 모든 경주의 E 공동분포와 7승식·선택·bootstrap을 독립 재계산한다. 기존 R/S 지표의 동일성, E 사건확률=성분 사건확률 평균, 질량·주변 일관성, Log loss의 Jensen 상한과 Brier의 정확한 혼합 항등식을 점검한다. 이 수학적 상한은 E가 더 좋은 단일 성분 S를 이긴다는 보장이 아니다.

## 저장과 해석 범위

이번 신규 영구 산출물 25,000,000B 이내, 기존 세션 54,709,908B와 합쳐 300,000,000B 이내로 설계한다. 전체 Q는 경주별 메모리 계산만 한다. 기존 R/S 전체 예측과 원장은 복사하지 않고 해시로 참조한다. 신규 E의 핵심 주변확률·표 선택·경주 지표·복연 적중수 원장만 필요한 열을 압축 Parquet로 저장한다. 모델·대형 스냅샷·DB·중복 환경을 새로 저장하지 않는다. 실제 분모·계산식·환경·입력 해시·실행 기록·독립 검산은 보존한다.

시장 배당이나 인기 입력, 구매 전 가격, 외부 자료 수집, DB 쓰기, ROI 평가는 이번에 없다. 따라서 시장 우위·실전 수익·미사용 미래기간 성능의 증거로 표현하지 않는다. 확정 배당으로 구매 전략을 사후 선정하지 않는다. 완료 시 이번/세션 신규 저장량·주요 파일 크기·남은 디스크 공간을 보고한다.
