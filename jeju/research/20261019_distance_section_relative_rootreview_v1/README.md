# 제주 거리별 구간 상대기록 후보: 감독자 검토

2026-10-19. Luna xhigh가 원천·피처·학습·평가를 담당하고, 감독자는 별도 구현으로 계산과 예측을 검산했다.

**결론: 기존 연구 말평가 F1_STYLE6를 유지한다. 구간 상대기록/관측 수 10열 후보는 사전 채택 기준을 통과하지 못했다.** 이번 비교는 이미 여러 번 확인한 과거 개발 기간의 후향 비교다. 새 독립 미래 검증이나 운영 승격이 아니다.

## 비교 범위

기존 30개 입력의 값·행 순서·정답을 보존하고 신규 10개 입력만 추가했다. 전체 학습 코호트는 기존 52,155출전·5,206경주다. 저장 기준선은 재학습하지 않았고, 후보는 기존 시간 분할·파라미터·seed·보정·조합 규칙으로 최종 3개 모델만 학습했다(초기/재학습 합계 LightGBM 6회, 확률 온도 보정 3회). 결과를 본 추가 학습·튜닝은 없다.

주 평가 표본은 900·1000·1110·1200m의 2024~2026-09-19 경주 1,503개·14,714출전이다. 2026년은 부분연도다. 비대상 거리는 새 10열 모두 NULL이며 전체 1,779경주 결과는 보조다.

## 신규 입력의 의미

같은 거리·같은 구간의 유효 말별 시간을 경주별 중앙값으로 만들고, 각 과거 출전 s의 날짜−2일까지 존재하는 경주별 중앙값을 같은 비중으로 누적 평균해 기준 B(s)를 계산했다. 유효 과거 경주가 20개 이상일 때만 기준을 제공한다. 상대기록은 `B(s)−실제 구간시간`으로 양수가 빠른 수행이다. 주로·등급·월별 효과를 분리한 보정계수를 추정한 실험은 아니다.

각 대상의 기존 동일거리 최근 5회 실제 출전 슬롯에서 유효 상대기록 평균과 관측 수를 구간별로 만들었다. 무효 슬롯은 유지하고 더 오래된 출전으로 채우지 않는다. 유효값이 없으면 평균 NULL/n=0, 비대상 거리는 평균/n 모두 NULL이다. 1110m S1F는 210m의 초 단위 원기록을 보존한다. 사용자 승인 명목거리는 표시·해석에 사용하며 시간 비율 환산을 하지 않았다.

## 원천·독립 검산

- 동결 기준 모집단은 55,860출전·5,668경주다. 이전 스냅샷에 빠진 현재 DB의 54개 행은 7개 초기 경주의 전체 출전마 지점 검사에만 반영했다. 품질 뷰에서 이 54개 행의 근거가 없어 해당 7개 경주의 구간을 차단했다. 대상·이력·동결 모집단을 삭제하지 않았다.
- 과거 135,855슬롯×5구간=679,275행을 보존했다. 유효 상대기록은 678,044행이다. 선택된 품질 값과 보류 상태를 사용했으며 DB·운영 모델·등록부는 변경하지 않았다. API 양수 미검토 값은 홈페이지 검증 완료와 구분한다. 사건 날짜/T−2는 당시 공개 시각을 증명하지 않는다.
- 감독자는 원천 구간 식·유효성·전체거리 합, 21,770개 source-event 기준값, 모든 슬롯 상대기록과 10개 최종 입력을 별도 코드로 재계산했다. 기준값 직접 평균과의 최대 차이는 5.33×10⁻¹⁴초였다.
- 저장/후보 각 17,412출전·1,779경주·10,674조합의 모델 점수와 확률을 재계산하고, 평가자의 예측·경주 지표·조합 및 주 지표 bootstrap 4,000개 값을 대조했다. 후보 예측과 bootstrap 값의 차이는 0이었다.
