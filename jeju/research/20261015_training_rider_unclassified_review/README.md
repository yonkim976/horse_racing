2026년 10월 15일 기준 제주 전용 SQLite DB를 읽기 전용으로 점검했다. 전체 908,316행 중 미분류는 298,875행(32.904%)이다. 미분류는 초기 자료와 2021년 12월 이후 자료에 집중된다. 원문 종류는 미분류 전부 `prGubun_raw='-'`이며, 분류 코드가 이미 제공된 행을 누락한 결과는 아니다.

## 집중 시기와 API 표기 변화

| 기간 | 미분류 | 기간 내 미분류 비율 | 전체 미분류에서 차지하는 비중 |
|---|---:|---:|---:|
| 2007~2012년 | 108,657 | 99.74% | 36.35% |
| 2013~2021년 | 5,643 | 1.36% | 1.89% |
| 2022~2026년 9월 28일 | 184,575 | 47.94% | 61.76% |

- 2012년 12월 1,981행은 모두 종류 `-`다. 2013년 1월에는 기수·조교사·조교보·조교승인 표기가 제공된다.
- API의 조교보·조교승인 마지막 관측일은 모두 2021-12-09다. 이날 228행에는 미분류가 없고, 다음날 211행 중 100행이 미분류다.
- 따라서 미분류 증가에는 원천의 종류 제공 방식 변화가 관련됐을 가능성이 있다. 변화의 행정적 이유나 해당 직책의 실제 전환을 확정한 것은 아니다. 사번으로 과거 역할을 소급 분류하지 않는다.
- 2017-01-01~2026-09-19 분석 범위에도 미분류 188,218행이 있다. 2017년 이전에만 있는 문제가 아니다.

## 홈페이지 보완 대상 범위

현재 말별 조교 페이지의 최근 6개월 안내를 기준으로 2026-04-15~09-28을 점검 후보로 삼았다. 이 범위의 미분류는 18,278행·836두이며 시각과 조교시간은 모두 유효하다. 실제 페이지에서 같은 사건을 찾을 수 있는지 별도 확인해야 한다. 18,278행은 홈페이지 보완 완료 수가 아니다. 미분류의 93.88%인 280,597행은 이 후보 기간보다 오래됐다.

종류 보완은 말 ID·조교일·입장시각·퇴장시각·조교시간이 모두 일치하고 홈페이지 표식이 명확한 개별 행에서만 가능하다. 홈페이지 `(관)`은 주로조교이고 `외`는 종류 미확정으로 둔다. 이름이나 동일 사번의 다른 날짜 표기로 과거 사건 전체를 재분류하지 않는다.

## 홈페이지 추가 조회 결과

미분류 최근 기록이 많은 말 8두를 골랐다. 기존에 확인한 32두는 제외했으며 표본은 544행이다. 이는 임의 표본이 아니라 보완 가능성을 확인하기 위한 대상 선정이므로 전체 미분류의 종류 비중으로 일반화하지 않는다.

- 최초 8개 요청은 실행환경의 DNS 오류로 실패했다. 원문을 받지 못한 544행은 대조 불가이며 홈페이지 기록 부재가 아니다. [최초 실패 원장](website/collection_manifest.json)을 보존했다.
- 허용된 네트워크 실행으로 재시도한 8개 페이지는 모두 HTTP 200이었다. [재시도 원장](website/retry_collection_manifest.json), [원행별 홈페이지 대조 근거](website/retry_website_event_evidence.json)를 보존했다.
- **534행은 같은 말 ID·날짜·입장·퇴장·분이 정확히 일치하고 홈페이지에 `(관)`으로 표시되어 주로조교로 추가 분류할 수 있다.** `외`·빈칸·모호한 연결은 이 표본의 정확일치 행에서 모두 0행이다.
- 나머지 10행은 2026-04-15 5행, 04-16 3행, 04-17 2행이며 정확히 대응하는 홈페이지 행을 찾지 못했다. 이 표본의 직접 일치는 04-18부터다. 최근 6개월 경계와 관련될 수 있지만 누락 원인은 확정하지 않는다.
- 루트 검증기는 원문 8개의 SHA와 말 ID를 다시 확인하고 별도 HTML 파서로 534행의 원문 표식·DB 사건키·현재 미분류 상태를 모두 검산했다. [독립 검증 결과](website_candidate_verification.json), [검증 코드](verify_website_candidates.py).

현재 홈페이지에서 최근 자료를 더 수집하면 미분류를 줄일 수 있다는 직접 근거를 확보했다. 18,278행 전체에서 같은 수준으로 분류할 수 있는지는 아직 확인하지 않았다. 홈페이지에 보이는 9월 28일 이후 새 조교 기록은 이번 기존 DB 미분류 대조에 포함하지 않았다. **추가 확인한 534행은 근거를 보관한 분류 후보이며 이번에 DB에 적용하지 않았다.**

기존 보관 32페이지의 안내·폼·스크립트도 다시 확인했다. 모두 최근 6개월 안내가 있고 해당 조교 화면에서 날짜 선택 input/select 또는 과거 날짜를 선택하는 조교 조회 파라미터는 찾지 못했다. 이는 확인한 화면에 한정한 결과이며 마사회 전체의 과거 자료 제공 가능성을 부정하는 결론은 아니다. [기존 화면 재검토](website/existing_page_ui_review.json), [홈페이지 담당 검토 보고](website/README.md).
