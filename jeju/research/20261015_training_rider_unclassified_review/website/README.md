# 제주 일별조교 미분류 홈페이지 추가 대조

조사일: 2026-10-15 (KST)

## 결과

최근 6개월 후보 중 기존 말 페이지 32개와 겹치지 않는 8두를 골라 공식 제주마 조교현황 페이지와 대조했다. 대상은 2026-04-15~2026-09-28의 미분류 API18 행 중 입·퇴장시각과 양수 조교시간이 있는 18,278행·836두다. 표본은 후보 행 수가 많은 순으로 고른 비무작위 8두이며, 그 8두에 속한 후보 행은 544개다.

공식 페이지의 같은 말 ID·조교일·입장시각·퇴장시각·조교 분이 모두 일치한 API18 원행은 **534행**이다. 이 534행의 홈페이지 기승자 표식은 전부 `(관)`으로, 페이지 범례에 따라 추가로 **주로조교 후보**로 확인된다. `(관)` 이외의 역할은 현재 직책이나 사번으로 추정하지 않았다. `외` 0행, 빈칸·`-` 0행, 서로 다른 사번/페이지 표식 충돌 0건이다.

나머지 10행은 정확 일치하지 않았다. 해당 말 페이지에 같은 날짜 행이 보이지 않았고, 모든 후보 날짜(4월 15~17일)가 해당 페이지에서 관측된 가장 이른 조교일보다 앞선다. 10행은 4월 15일 5행, 4월 16일 3행, 4월 17일 2행이다. 페이지의 6개월 안내 범위 가장자리와 맞닿아 있지만, 페이지가 그 날짜를 생략한 정확한 이유는 확인하지 못했다.

## 페이지 범위와 날짜 UI 재확인

기존 32페이지를 원문 SHA까지 다시 확인했고 모두 안내문 `최근 6개월간 조교자료입니다.`를 포함했다. 말별 조교현황 폼은 `Act`, `Sub`, `meet`, `hrNo`, `realRcDate`, `realRcNo` 숨김 필드만 갖고 날짜 입력 0개·선택 목록 0개였다. 요청 URL 쿼리는 `Act`, `Sub`, `hrNo`, `meet`뿐이다. `realRcDate`와 `realRcNo`는 경주일 결과표를 여는 `goScore`에서 쓰이고, `goPageTab`은 조교·심사·출발조교 탭을 전환한다. 이 화면에서 과거 날짜를 선택하거나 조교 페이지를 날짜별로 넘기는 UI는 확인하지 못했다. 이 판정은 저장된 말별 조교현황 페이지와 UI에만 한정한다.

## 실패와 재시도 기록

첫 요청은 8개 URL 모두 DNS 이름 확인 오류로 실패했다. 이때는 544행을 미일치로 보지 않고 **대조 불가**로 정정해 `website_event_evidence.json`에 기록했다. 오류 원문은 `collection_manifest.json`에 남겼다. 사용자 승인 범위 내에서 동일한 8개 고정 공식 URL을 제한된 HTTPS 수집기로 재시도했고 8/8 HTTP 200을 받았다. 재시도 원장·페이지 SHA는 `retry_collection_manifest.json`, HTML 응답 바이트는 `retry_raw_html/`에 있다.

## 판정·사용 한계

- 정확 일치가 확인된 534행만 직접 표식 `(관)`에 근거한 주로조교 후보로 센다. DB에 반영하지 않았다.
- 원 API18 `prGubun_raw='-'`를 보존한다. 동시대 페이지의 표식만 확인했으며 API 종류·사번·현재 직책/명부로 과거 역할을 추정하지 않았다.
- 동일 날짜만 맞거나 일부 시각만 맞는 근사 연결은 만들지 않았다. 10행은 그날 페이지 행이 없으므로 역할 후보를 부여하지 않았다.
- 8두는 최근 미분류행이 많은 말로 의도적으로 선택한 표본이다. 534/544 비율을 나머지 18,278행이나 전체 미분류 298,875행에 적용할 수 없다.
- DB는 SQLite `mode=ro`와 `PRAGMA query_only=ON`으로 읽었다. DB 및 분류 적용 테이블을 수정하지 않았다.

## 산출물

- `existing_page_ui_review.json`: 기존 32페이지 원문 SHA와 날짜 UI·안내문 검토.
- `collection_manifest.json`: 최초 요청 실패 원장.
- `website_event_evidence.json`: 최초 실패의 544행을 대조 불가로 기록한 정정 결과.
- `retry_collection_manifest.json`: 8개 성공 응답의 URL·상태·SHA·저장 경로.
- `retry_website_event_evidence.json`: 534개 직접 일치, 10개 미일치, 원행 연결 및 미일치 날짜 확인.
- `retry_raw_html/`: 추가 수집한 공식 KRA 원문 HTML.
- `run_website_review.py`, `retry_website_fetch.py`: 읽기 전용 조사·재시도 코드.
