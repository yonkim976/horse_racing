# F1_STYLE6 전체 출전마 연승 기대값 사후 평가

저장된 `F1_STYLE6`의 말별 Top3 주변확률과 최종 연승(PLC) 표시 배당을 결합해 고정 선택 규칙 8개의 과거 환급을 계산했다. 코호트는 2025년부터 2026-09-19까지 가격이 보유된 1,142경주·11,083출전행이다. 그중 Top2 확률이 없는 7두 이하 36경주·252출전행을 제외해 8두 이상 1,106경주·10,831출전행을 평가했다. 2025년은 650경주, 2026년 부분연도는 456경주다.

각 선택은 경주당 한 마리, 1,000원으로 계산했다. EV는 `저장된 p_top3 × 원문 PLC 배당 − 1`이다. 저장 확률은 개별 sigmoid가 아니라 F1_STYLE6의 native Top3 집합 주변확률이다. 확률 순위는 저장 모델 점수 내림차순으로 정하고, 점수가 같으면 낮은 마번을 앞에 뒀다. 지원 코호트에서 저장 확률의 미세한 표현 차이는 같은 점수 말 108두의 단순 p 정렬 순서를 바꿀 수 있었으므로 이 기준으로 묶었다. EV 동률이면 확률 순위, 마번 순으로 선택했다. EV가 양수인 후보가 없으면 해당 경주는 사지 않은 것으로 기록한다.

당첨은 공식 착순이 3위 이내인 경우다. 적중 총환급은 원금 포함 `1,000원 × 원문 배당`, 미적중 총환급은 0원이며 ROI는 `총환급 ÷ 실제 stake − 1`이다. 세전 가정이다. 269개 경주일·2,000회 고정 bootstrap을 재사용해 적중률과 ROI의 95% percentile 구간을 냈다. 요약표의 비율과 CI는 %이고, 0 stake bootstrap 표본은 ROI 정의 불가 횟수로 따로 표시했다. 민감도는 총환급이 가장 큰 적중 wager 1·3·5건을 통째로 제외해 해당 환급과 stake를 함께 뺀 ROI다. 추가 임계값 탐색이나 성과가 좋은 경계 추천은 하지 않았다.

전체 1,106경주 결과에서 고정 모델 순위 1·2·3위 정책의 ROI는 각각 -18.8%, -15.4%, -16.6%였다. 순위 3위의 평균 모델 EV는 +0.42%였지만 실제 순이익은 -183,300원이었다. `p×odds−1>0` 규칙도 이 자료에서 수익을 내지 못했다. 확률 1위만 EV가 양수일 때 고르면 258경주를 선택해 ROI -22.1%였고, 전체 출전마 최대 EV 후보를 선택하면 1,103경주에서 평균 모델 EV +126.0%와 실제 ROI -29.9%를 기록했다. 상위 3두 안에서 고른 정책은 ROI -16.8%, `p≥0.40`과 `p≥0.50` 정책은 각각 -17.3%, -23.5%였다. 전체 정책별 적중·환급·연도별 CI와 최대환급 1·3·5건 제외 민감도는 `summary.csv`에 있다.

`case_examples.csv`에는 확률 3위 선택의 적중 10건과 미적중 10건을 날짜 순으로 고르게 뽑고, 같은 경주의 확률 1위 값도 함께 실었다. 전체 정책의 매 경주 선택·미선택 내역은 `selected_rows.csv`에 저장했다. `REPORT.json`은 cohort와 검증·통계 결과를 기록하고 `source_hashes.json`은 입력·결과 해시를 고정한다.

가격 원문은 이전 source audit의 API301 runner별 전체 quote를 사용했다. 원문 가격 11,083개와 모든 출전말 가격의 coverage는 선행 감사와 root 독립 검토에서 PASS였으며, root의 직접 API JSON quote reference와도 `(race_id, horse_number)` 전체 11,083건의 가격 및 페이지 SHA가 일치했다. 공식 결과 17,412 runner는 모델 roster와 독립 검토에서 PASS였고, 이 분석의 지원 코호트에서도 official rank·마번·말 ID·field size를 다시 대조했다. root가 별도로 계산한 8개 정책·3개 기간 요약 24행 및 선택 bet 6,183건과 이 결과를 교차 대조해 일치 여부를 보고서에 기록했다.

결과는 같은 과거 개발자료에 대한 사후 기술통계다. 최종 표시 배당의 사전 공개 시각을 확인할 수 없어, 가격을 경주 전에 살 수 있었다고 가정하는 EV 선택은 실제 구매 전략의 성과 검증이 아니다. 2026년은 9월 19일까지의 부분연도다. 기존 모델 등록부나 운영 설정은 바꾸지 않았다.

최종 root 독립 검증은 [ROOT_VERIFICATION_RECEIPT.json](ROOT_VERIFICATION_RECEIPT.json)에 기록했다. 24개 요약행, 선택 wager 6,183건, 신뢰구간 96개를 독립 대조해 PASS했다. 최종 파일별 SHA-256은 [FINAL_ARTIFACT_MANIFEST.json](FINAL_ARTIFACT_MANIFEST.json)에 고정했다.
