# 두 말 동시입상 적중·미적중 경주의 배당 비교

기수 ID 효과까지 추가한 저장 후보의 선택을 그대로 사용했다. 적중은 선택한 두 말이 모두 Top3인 경우다. 전체 평가 1,779경주 중 배당이 보유된 2025-01-03~2026-09-19의 1,142경주를 비교했다. 적중 283경주, 미적중 859경주이며 두 집단 모두 해당 기간 배당 연결률은 100%다. 2024년 637경주는 조합 배당 원천이 없어 제외했다. 2026년은 부분연도다.

| 해당 경주의 실제 당첨배당 | 적중군 평균 | 미적중군 평균 | 적중군 중앙값 | 미적중군 중앙값 |
|---|---:|---:|---:|---:|
| 삼복승(TLA) | 20.106배 | 89.103배 | 12.9배 | 39.9배 |
| 복승(QNL) | 11.026배 | 30.811배 | 6.6배 | 14.4배 |

삼복승 평균 차이는 68.997배이며, 미적중군 평균이 적중군의 약 4.432배였다. 삼복승 90백분위는 각각 42.96배·202.84배다. 적중한 **선택 쌍 자체의 복연승(QPL)** 배당은 283건 평균 2.743배, 중앙값 2.3배, 90백분위 4.68배였다. 미적중 선택 쌍에는 당첨 배당을 부여하지 않았다.

적중 분류는 두 말 동시 Top3이며 삼복승 3두 적중이나 복승 Top2 적중이 아니다. 위 삼복·복승 배당은 그 경주의 실제 당첨조합 배당으로, 우리 조합의 실현 배당이나 수익률을 뜻하지 않는다. 배당은 사후 진단에만 사용했으며 모델 입력·말 평가·운영 기준은 변경하지 않았다. 반복 개발기간에 대한 기술통계다.

2025년 삼복승 평균은 적중 20.645배·미적중 90.013배, 2026년은 19.434배·87.855배였다. 연도별 상세 표와 경주별 연결은 아래 자료에 보존했다.

Luna xhigh가 공식 결과와 보관된 API301 최종배당 원문을 경주일·제주 코드·경주번호·당첨 마번으로 연결했다. 원문 SHA를 로컬 `source_documents`와 대조했고, 2026년 삼복승 488경주는 기존 당첨배당 CSV와 조합 키·배당액까지 일치했다. 전체 1,779경주의 Top3는 정확히 3두, Top2는 정확히 2두였으며 두 집합 안의 동착은 없었다.

감독 검토에서는 분석 코드를 사용하지 않고 공유 DB 결과로 당첨 키를 다시 만들고, 1,779경주의 라벨과 연결 배당을 행별 대조해 모두 일치함을 확인했다. 사용 원문 페이지 452개 해시도 별도로 확인했다. DB는 `mode=ro`·`query_only`로 열었으며 네트워크 호출·학습은 없다.
