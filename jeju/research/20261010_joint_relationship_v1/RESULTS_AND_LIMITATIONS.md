# F1_STYLE6 공동 관계 연구: 결과와 한계

**결과 상태:** 과거 개발 자료를 이용한 연구다. 사전 등록한 두 주 성능 게이트를 모두 통과하지 못했다. 이 결과는 채택·배포·운영 예측 변경·DB 기록·등록부 변경을 승인하지 않는다.

## 연구 질문과 비교 대상

고정된 질문은 기존 F1_STYLE6 말 점수와 말별 평가를 그대로 유지하면서 작은 관계항을 추가했을 때, 전체 정확 Top3 집합 후보 중 경주당 최대 6개 조합 선택의 성능이 달라지는지였다. 각 경주에서 전체 C(N,3) 무순서 조합의 확률을 함께 정규화하고, 확률이 높은 6개까지 선택했다.

주 대조군은 H2에서 온도를 맞춘 원시점수 전용 모델이다. 후보와 같은 저장 F1_STYLE6 원시점수를 사용하고 관계 계수는 0으로 두며, 후보와 같은 H2 날짜·라벨로 양쪽 온도를 각각 보정했다. 이 매칭 대조군이 사전 등록한 주 확률 비교다. 기존 F1_STYLE6 저장 말별 확률은 별도 참고값으로 보존했으며 주 대조군이 아니다. 기존 저장 확률과 말별 출력을 후보 결합분포에서 계산한 새 주변확률로 대체하지 않았다.

평가에는 2024-01-05~2026-09-19의 과거 1,779경주, 말 17,412행, 경주일 269일을 사용했다. 2026년 자료는 9월 19일까지의 부분 연도다. 이 경주와 라벨은 이전 개발 작업에서도 반복 사용했으므로 결과를 독립된 미래 검증으로 해석할 수 없다.

## 주 결과

표의 부호는 후보−매칭 대조군이다. 6조합 적중은 실제 순서와 무관한 정확 Top3 집합이 여섯 티켓 중 하나와 일치한 경주를 뜻한다. 결합 NLL은 해당 정확 Top3 집합에 준 확률의 음의 로그이며 낮을수록 좋다. 구간은 날짜를 클러스터로 묶은 사전 등록 paired bootstrap 2,000회, seed 20261008로 계산했다.

두 조건을 모두 만족해야 했다. 적중률 점추정은 양수지만 구간은 개선이 없을 가능성을 포함한다. 후보 결합 NLL은 평균상 조금 나쁘며, 구간 상한도 악화 0을 넘는다. 따라서 통합 연구 신호 게이트는 false다. 보조 지표나 하위집단 결과는 이 사전 규칙을 대체하지 않는다.

전체 결합 Brier 점수는 매칭 대조군 0.979484, 후보 0.979717로 후보가 조금 나빴다. 이 지표는 기술 통계이며 사전 게이트의 대체 조건이 아니다.

## 모형과 계수 해석

모형은 전체 원시점수 합에 고정된 11개 무순서 쌍 잔차 항을 더했다. pair residual은 unary 말 효과에 해당하는 부분을 투영해 제거했고, 경주 전체 C(N,3) 집합 분포를 함께 정규화했다. L2 lambda는 1.0으로 고정했다. 평가 연도별 H1 계수 학습은 한 번씩, 양쪽 모델의 H2 온도 보정은 각각 한 번씩 수행했다. 말 ID나 반복 쌍 ID는 사용하지 않았다.

고정 피처는 score 곱, score 절대차, 세 스타일 이력 요약(S1F 상대위치, S1F-to-C4 전진, C4-to-G1F 전진)의 절대차, 대응 관측·지원 수 세 열의 절대차, 그리고 세 이력 평균의 missing-either 지시자다. [fit_parameters.json](outputs/fit_parameters.json)의 fold별 계수는 다음과 같다. 정규화 및 투영이 적용된 계수이며 소수 셋째 자리까지 표시했다.

## 실행 이력과 검증 상태

저장된 fit에는 H1 관계 계수 최적화 3회와 H2 온도 최적화 6회가 있다. fit receipt는 기본 말 모델의 학습 또는 재로드가 없었고 학습 전후 원천 hash가 동일했다고 기록한다. receipt의 evaluation_outcome_metrics_computed=false는 학습 시점에 평가 결과를 아직 산출하지 않았다는 정확한 기록이다. 이후 저장된 학습 파라미터와 온도만 입력으로 사용해 별도 report 단계를 실행했다.

[all_triples.parquet](outputs/report/all_triples.parquet)에는 402,808행이 저장되어 있으며 후보와 매칭 대조군이 각각 201,404개 조합이다. report 내부 검사는 경주별 확률 합과 arm별 정답 집합 수를 확인한다. C의 독립 사후 검증은 원천 자료부터 세 개 전체 분포 arm을 재구성하고 저장 결과와 대조했으며, 재학습이나 온도 재최적화 없이 PASS했다. 정답 Top3 집합 확률, 티켓 parity, 세 arm 분포 정규화, 말별 주변확률 및 저장 report와의 전량 비교가 확인됐다. receipt는 39개 잠금 원천의 전후 hash가 같다고 기록한다. C 사후 검증 receipt는 `jeju/research/20261010_joint_relationship_review_v1/outputs/postfit_independent_validation/independent_postfit_validation.json`이며 SHA-256은 `276e94432acd34205c8005bfee5e0c4516353d6cac43406aa83c17de57f223bc`다. 구조 전용 C 독립 preflight도 PASS했으며 receipt SHA-256은 `8d2b7ad7d32fe31685906c5197ec486e9e0cc64200e08947b39d0e613436afde`다.

root 최종 검토도 PASS로 기록됐으며 파일은 [root_final_review.json](outputs/root_final_review.json), SHA-256은 `b91048fbd50a91a6e1c685aff7118e03f7d54b9511b34eed991c26a931ec76ee`다. root는 C 검증과 별도로 잠금 원천 39개의 hash 불변을 확인했다. 여기서 PASS는 검증 절차와 저장 결과 재현에 대한 판정이다. 성능 판정은 별개이며, 두 사전 등록 성능 게이트는 실패했다. 운영 승격은 승인되지 않았다.

## 해석 범위와 제한

- 평가에는 정상 완주 코호트와 사후 구성된 완전 roster를 사용했다. 따라서 비정상 종료·미완주 조건으로 확대 해석할 수 없고, 실제 경주 전 확정 출전 명단과 결장·취소 정보가 당시 어떻게 알려졌는지 재구성하지 않았다.
- 과거 예측의 실제 공표·게시 시각을 재구성하지 않았다. 이 연구의 시간 경계와 저장된 T−2 이력 계약 검사는 미래정보 사용을 제한하지만, 과거에 실제로 이용자에게 공개된 예측을 그대로 재연하는 검증은 아니다.
- 스타일 관측 이력은 과거 자료에서 만든 요약 피처를 관계 정보의 대리변수로 사용한다. 이 피처는 현재 경주에서 실제 주행 중 나타날 위치를 직접 예측하는 모델이 아니다.
- 같은 과거 경주와 라벨을 이전 연구에서 반복 사용했다. 이력을 더 포함해도 개발 표본 재사용 문제는 해소되지 않는다.
- 전체 적중률 구간이 0을 포함하고 정확 집합 NLL guardrail도 실패했다. 관측된 점추정만으로 개선이 입증됐다고 말할 수 없다.
- 연도별·거리별 지원은 제한적이고 방향이 다르다. 이 표들은 탐색적 기술 결과이며 여러 하위집단을 본 데 대한 보정이 없다.
- 2026년은 9월 19일까지의 부분 기간이다.
- 결합 모델이 선택 티켓과 파생 말별 주변확률을 바꿀 수 있어도, 기반 말 점수는 고정됐다. 주변확률 성능과 티켓 선택 성능은 서로 바꿔 읽을 수 없다.
- 계수는 특정 코호트, 피처 표준화, 보정 분할에 의존할 수 있다. 인과적 또는 다른 기간에 이식 가능한 궁합 효과로 해석하지 않는다.
- 운영 모델, 등록부, DB, 기존 저장 예측은 변경되지 않았다. 본 연구 결과를 채택 또는 운영 모델이라고 표현해서는 안 된다.
- C의 사후 독립 재구성과 root 최종 검토는 PASS했지만, 이는 성능 향상 검증이 아니라 데이터·계산 재현성 검증이다. 연구 신호 게이트는 실패했으며, 이 결과는 운영 승격이나 최종 중앙 출판을 뜻하지 않는다.
