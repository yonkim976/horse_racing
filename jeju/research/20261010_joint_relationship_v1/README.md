# F1_STYLE6 공동 관계 연구

**상태: 과거 자료를 이용한 연구 결과이며, 사전 등록한 두 주 성능 게이트를 모두 통과하지 못했다. 이 결과로 모델을 채택하거나 운영을 변경하지 않는다.**

이 연구는 저장된 F1_STYLE6 말 점수를 그대로 둔 채, 순서가 없는 말 쌍 관계항 하나를 전체 정확 Top3 조합 확률분포에 추가했다. 동일한 1,779경주(2024-01-05~2026-09-19)에서 경주당 최대 6개 조합을 비교했다. 이 경주와 라벨은 이전 개발 연구에서도 반복 사용했으므로 독립된 미래 홀드아웃이 아니다.

주 비교는 H2에서 온도를 맞춘 원시점수 전용 대조군과 후보 모델의 비교다. 저장된 기존 F1_STYLE6 말별 확률은 별도의 변경 없는 참고값이며, 주 비교의 대조군이 아니다. 원래 말 점수·말별 예측·저장 조합·운영 모델·DB·등록부는 변경하지 않았다. 관계 모델의 결합확률에서 합산해 얻은 말별 주변확률은 별도 파생 결과다.

따라서 두 조건을 함께 요구한 연구 신호 게이트는 실패했다. 적중률 점추정은 높아졌지만 구간에 개선 없음이 포함되고, 결합 NLL 보호 조건도 통과하지 못했다. 보조 지표나 일부 거리 구간의 결과는 이 결론을 바꾸지 않는다.

두 모델의 6개 조합 집합은 1,077경주에서 달랐고, 702경주에서는 순서를 무시한 조합 집합이 같았다. 양쪽 합계 10,674개 티켓 슬롯 중 9,259개는 유지됐다. 후보에서만 나타난 티켓과 대조군에서만 나타난 티켓은 각각 1,415개였다. 실제 정확 Top3 집합을 새로 포함한 경주는 50개, 기존에 포함했지만 후보에서 빠진 경주는 34개로, 적중 순증은 16경주였다. 자세한 목록 순위와 집합 비교는 [결과와 한계](RESULTS_AND_LIMITATIONS.md)를 참조한다.

고정된 11개 쌍 피처와 날짜 분리 H1 계수 학습·H2 온도 보정을 사용했다. 말 ID나 쌍 ID를 학습하지 않았다. 계수는 정규화된 관계 피처의 기술적 모수일 뿐, 인과 효과나 다른 기간에도 통하는 말 간 궁합의 증거가 아니다.

전체 방법은 [사전 계획](PLAN.md)에, 연도·거리 결과와 보정 비교·계수·실행 이력·제한은 [결과와 한계](RESULTS_AND_LIMITATIONS.md)에 기록했다. 기계 판독 결과는 [report_metrics.json](outputs/report/report_metrics.json), [race_metrics.csv](outputs/report/race_metrics.csv), [all_triples.parquet](outputs/report/all_triples.parquet)에 있으며, 실행 출처는 [fit_receipt.json](outputs/fit_receipt.json)과 [report_receipt.json](outputs/report/report_receipt.json)에 있다.

학습 단계 receipt에 기록된 evaluation_outcome_metrics_computed=false는 당시 평가 결과를 아직 계산하지 않았다는 뜻이다. 이후 저장된 학습 파라미터와 온도만 사용해 별도 report를 생성했다. C의 원천 자료 기반 독립 재구성과 root 최종 검토는 모두 검증 PASS다. 이는 계산·출처 재현이 확인됐다는 뜻이며 성능 신호 게이트가 통과했다는 뜻은 아니다. 두 주 성능 게이트는 실패했고, 승격이나 운영 변경은 없다.
