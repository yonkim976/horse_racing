# 감독 판정 보충: 순차 연구 후보 gate

2026-10-09. `CONTRACT.md`의 입력 열, 모집단, 파라미터, split, 지표 또는 2,000회 bootstrap 정의를 바꾸지 않고 판정 순서만 명시한다. 원 계약의 해시는 output lock에 보존한다.

1. F1은 R1과 비교한다. 전체 Top3 log loss와 Brier가 모두 낮고, 이 두 지표 중 적어도 하나의 경주일 paired 95% 구간이 0보다 낮으면 F1을 다음 연구의 연구 유지후보로 표시한다.
2. F1이 첫 gate를 통과한 경우에만 F2와 F1의 같은 gate를 다음 순서로 적용해 F2의 순차 연구후보 여부를 정한다. F1이 실패하면 F2−F1의 개선만으로 F2를 R1 대체 연구후보로 부르지 않는다.
3. F2−R1은 보조 수치로 보고하고 gate에 사용하지 않는다. 두 단계는 같은 후향 기간과 다수 지표를 재사용하므로 확증적 효과·최적해·독립 미래검증을 입증하지 않는다.
4. 사전 비교계약에 따라 결과와 무관하게 F1/F2 여섯 최종 모형을 모두 완성해 표와 검증 산출물을 보존한다. 어느 gate도 운영 모델·등록부 변경을 허가하지 않는다.

`previous_result_status`의 세 범주는 경주 전체 완결 상태만 나타낸다. 전체 경주가 불완전하지만 개별 말의 착순이 정상 범위 1..N이면 `previous_top3` 0/1을 직접 보존하고 상대순위는 NULL이다. 개별 말의 91/92 등 무효착순은 같은 불완전 범주에서 `previous_top3`와 상대순위를 NULL로 유지한다. 두 열의 결측을 0으로 치환하지 않는다. 원시 상태 코드는 숫자 그대로 보존하며 의미를 새로 추정하지 않는다.
