# 직전 착순·최근 입상 이력 입력 비교 계약

2026-10-09. 학습 전에 고정하는 연구 계약이다. 기존 R1(21열)을 저장 모형으로 재현하고, 직전 결과와 같은 거리의 최근 입상 이력 6열을 추가한 F1(24열)·F2(27열)만 비교한다. 이는 반복 사용된 과거 기간의 후향 개발 비교이며 독립 미래검증이나 운영 반영이 아니다. 이 문서와 `IMPLEMENTATION_PLAN.md`에 대한 root 검토·승인 전에는 어떤 후보 모형도 fit하지 않는다.

## 자료·모집단·보존

입력은 `20261009_field_relative_ability_v1/outputs/features.parquet`와 그 계약의 `20261008_horse_profile_baseline_v1/outputs_v2/source_snapshot.parquet`다. 첫 파일은 R1의 기존 21열, `previous_start_id`, `last5_same_source_ids`와 공식 출전 ID를 제공한다. 둘째 파일은 과거 실제 출전의 공식 `api_record_id`, `horse_id`, 날짜, 경주, 거리, `finish_position`, 기존 `started` 상태를 제공한다. 마명 문자열로 연결하지 않는다. 현재 말의 최신 표시 이름과 2026년 기준 나이 정책은 기존 입력 계약 그대로 둔다. 새 이름·나이 입력을 만들지 않는다.

R1과 같은 52,155출전·5,206경주, 2017-01-13~2026-09-19 및 2024~2026 평가 17,412출전·1,779경주를 사용한다. 거리·완전 정상 착순 등 모집단 선정 기준, 제외 말, J0 13열과 R1 상대능력 8열은 그대로 둔다. 당일 착순, 중량, 기수, 게이트, 계절 또는 새 외부자료는 입력하지 않는다. 과거 관측은 현재 경주일 T−2까지이며 경주일·말·공식 출전 ID 전체를 연결 확인한다.

DB, 운영 모델·등록부, 기존 연구 산출물은 읽기 전용이다. 이 날짜별 폴더 안에만 코드를 쓰고 신규 산출물을 만든다. 학습 전 DB·운영 등록부·현재 HY_R_FORM, R1/J0 보존 모형, feature/source 입력, 관련 기존 예측 파일 및 코드 해시를 고정하고 실행 뒤 불변 여부를 확인한다. 다른 모델 폴더 전체 해시 대신 위 연구에 사용되는 구체적 보호 대상만 잠근다.

## 과거 결과의 고정 정의

실제 출전자 수 N은 해당 과거 `race_id`의 `source_snapshot.parquet` 행 가운데 물려받은 `started=True`인 전체 수다. 참조 생성 규칙은 `finish_position` 1..89 또는 91/92를 started로 두며, 다른 원문 값의 의미를 이번 연구에서 재분류하지 않는다. 따라서 미분류/비시작 원문 값은 N에 추가하지 않으며, 취소 여부도 이 값 하나로 확정하지 않는다. 원천에서 실제 시작으로 지정된 모든 행을 포함하고 현재 연구의 정상 편성 필터를 과거 이력에 소급 적용하지 않는다.

어떤 말의 개별 착순은 정수값 `1 <= finish_position <= N`이고 그 경주에서 같은 horse ID의 started 행이 하나일 때만 이력 내 정상 착순으로 인정한다. 다른 값·NULL·91/92·중복 horse ID는 그 말의 착순이 무효/미관측인 상태로 유지한다. 한 경주의 결과가 정상적으로 완결됐다고 표시하려면 N≥2이고, started 행의 착순이 중복 없이 정확히 `1..N`이어야 한다. DNF·실격 등 started 비정상 상태가 섞이거나, 순위 집합이 불완전·중복·범위 밖이면 경주 상태는 `non_normal_or_incomplete`다. N=0/1에는 상대순위의 분모가 없으므로 상대순위는 NULL이고 경주 상태도 `non_normal_or_incomplete`다. 이 경주 수준의 완결성 조건은 F1 상대순위에만 적용한다. 개별 말의 유효 착순·Top3 관측 여부와 혼동하지 않는다. 중복 착순은 경주 상대순위를 막지만, 해당 말의 단일 행·단일 official horse ID에 정수 착순 1..N이 직접 있으면 말의 Top3 여부는 그 착순으로 보존한다.

직전 경주는 각 행의 `previous_start_id`로 연결한다. `previous_result_status`의 3범주는 **경주 전체의 착순 완결 상태**다. ID가 없으면 `unobserved`, 있으면 해당 과거 경주 전체가 위의 완전성 기준을 만족할 때 `normal`, 그 외에는 `non_normal_or_incomplete`다. 이 상태열은 말 자체의 착순 유효성을 별도 구분하지 않는다. `previous_finish_relative_rank`는 경주 전체가 `normal`일 때만 `(p-1)/(N-1)`로 계산한다. 다른 상태는 NULL이다. `previous_top3`는 직전 말의 개별 착순이 `1..N`으로 직접 유효하면 `1[p<=3]`로 계산한다. 따라서 그 경주의 다른 출전마 DNF 등으로 전체 순위가 불완전해도 직전 말의 유효 1~3위/4위 이상은 보존한다. 직전 말 착순이 invalid면 NULL이다. 과거 행이 없으면 Top3와 상대순위는 NULL이고 상태만 `unobserved`다.

F2는 `last5_same_source_ids`에 저장된 실제 동일거리 출전 슬롯을 시간 순서 그대로 쓴다. 각 실제 ID의 착순이 invalid면 해당 결과 값을 NULL로 남기고 창에서 행을 삭제하지 않는다. 창은 최대 직전 5회이며 각 ID를 공식 말 ID로 확인한다. `same_distance_last5_actual_n`은 ID가 있는 실제 출전 슬롯 수다. `same_distance_last5_normal_n`은 그 슬롯 중 해당 말의 착순이 각 경주 실제 started 수 N 대비 `1..N`인 정상 착순 수다. `same_distance_last5_top3_rate`는 정상 착순 결과 중 1~3위의 비율이다. 정상 착순 수가 0이면 비율은 NULL이다. 비정상·불완전 착순은 분자·분모에 임의의 최하위 순위를 넣지 않고 슬롯과 NULL로 보존한다. 경주 전체 순위가 불완전한 경우에도 해당 말의 `1..N` 착순이 직접 확인되면 F2의 개별 정상 결과로 셈한다. 이 분모는 같은 거리 최근5 실제출전 중 비정상 착순을 0으로 간주한 이전 조건탐색의 Top3 비율과 정의가 다르므로, 두 비율을 같은 값으로 비교하지 않는다.

## 모형·열

R1 입력 21열은 이전 R1 계약의 J0 13열+상대능력 8열을 정확히 그대로 사용한다. 제거 열은 없다. 범주 어휘는 각 초기 학습구간에서만 결정한다. 행 순서·출전 ID는 세 모형에서 일치해야 한다.

| 묶음 | 추가 입력 열 | 정의 |
|---|---|---|
| F1: R1+3 | `previous_finish_relative_rank` | 위의 완전 경주에서만 계산하는 느린 쪽 상대순위 `(p-1)/(N-1)`; 0은 1위, 1은 N위 |
| | `previous_top3` | 개별 직전 착순이 1..N으로 직접 유효할 때 Top3 여부 1/0; 그렇지 않으면 NULL |
| | `previous_result_status` | `normal`, `non_normal_or_incomplete`, `unobserved` 범주 |
| F2: F1+3 | `same_distance_last5_top3_rate` | 최근 최대5 실제 동일거리 출전 중 정상 개별 착순 결과를 분모로 한 Top3 비율; 정상 결과 0개면 NULL |
| | `same_distance_last5_actual_n` | 최근 최대5 실제 동일거리 출전 슬롯 수(0..5) |
| | `same_distance_last5_normal_n` | 창 중 개별 정상 착순이 직접 확인된 결과 수(0..actual_n) |

각 변형은 확정적으로 21/24/27열이다. 경주 집합 입상률·조건별 집계 입상률은 어떤 모형에도 입력하지 않는다. 신규 범주 어휘는 초기 학습 표본만으로 고정한다. 비정상 결과를 최하위 숫자로 바꾸지 않는다.

## 학습·평가·판정

R1 보존 대조군은 `20261009_field_relative_ability_v1/outputs/R1_2024`, `R1_2025`, `R1_2026`의 저장 모형·메타데이터를 재로딩해 기존 17,412개 점수/확률 및 지표를 재현한다. R1을 재학습하지 않는다. 후보 F1/F2만 세 평가연도별 최종 모형 총 6개를 만든다. 각 모형은 이전 계약대로 조기종료용 초기 학습과 그 결과 iteration까지의 refit을 거쳐 총 LightGBM train 호출 12회, 온도 보정 최적화 6회를 수행한다.

각 평가 Y=2024, 2025, 2026에 대해 초기 학습은 2017~Y−3, 조기종료는 Y−2, 결정된 iteration으로 Y−2까지 재학습, 온도 보정은 Y−1, 평가는 Y다. 기존 R1과 같은 LightGBM 설정·seed 20261008·경주 균등 가중치(출전 가중치 1/field_n)·최대 200회·조기종료 25회·범주 처리·온도 보정 범위 및 알고리즘을 쓴다. 평가연도별 모형과 온도는 고정하고 과거 이력만 T−2까지 갱신한다.

세트 분포·주변 Top3 확률은 R1의 기존 가산 집합 모형, 최대 6개 canonical sorted 조합, 각 3개 점수의 좌결합 float 덧셈·동점 규칙을 그대로 쓴다. 확률 합, 집합 분포 합, 말별 주변 합을 확인한다. 주지표는 경주 균등 Top3 log loss·Brier다. 보조지표는 보정, 상위5두 입상마 포함·전부 포함, 6조합 적중이다. 전체·연도·거리·관측경력·동일거리 이력·직전 정상착순/상태 하위군을 보존하고 표본 수와 잔차를 함께 낸다.

주 비교는 단계별 F1−R1, F2−F1이며 F2−R1은 보조다. 평가 전체 17,412출전에서 각 차이의 경주일 paired bootstrap 2,000회·95% 점별 구간을 계산한다. 말 단위 신뢰구간은 같은 말의 반복을 별도 군집 보정하지 않으며 탐색으로 표시한다. 각 단계의 연구 유지후보 gate는 전체 log loss와 Brier가 모두 낮아지고, 두 지표 중 적어도 하나의 차이 구간이 0보다 낮은 경우다. F1 gate는 F1−R1, F2 gate는 F2−F1에 적용한다. 하위군·다른 지표·후보/조합 퇴행과 소표본을 별도로 보고하며, 확률 유지후보와 후보/조합 개선은 분리한다. 두 단계·다수 지표가 같은 후향 표본을 반복 사용하므로 이 gate는 확증·최적 증명이나 독립 미래검증이 아니다. 어떤 결과도 운영 승격으로 해석하지 않는다.

2026년 운영 공통 비교는 기존 운영 비교에서 확정된 동일 467경주·4,475출전으로 고정한다. 운영 HY_R_FORM의 보존된 점수/확률/PL 집합분포와 F1/F2/R1의 동일 말집합 확률을 비교해 이전 운영 비교와 같은 지표(입상 확률 손실, 최고점 입상, 상위 집합/상위5 포함, 최대6조합)를 남긴다. 조합은 모델별 원래 집합 분포에서 최대6개를 고른 역사적 재구성이며 과거 게시표의 적중·수익으로 읽지 않는다. 같은 경주·기간의 반복 평가이므로 독립검증으로 부르지 않는다.

## 재현·검증 출력 계약

`verify.py`는 실행 가능한 독립 검증기로 준비 전후 보호/원천/모형/코드 해시, R1 저장 모형 재로딩 및 점수 재현, F1/F2 모든 이력 ID·공식 말 ID·거리·T−2 조건, 실제 started 수와 취소코드 제외, 정상순위 완결성, NULL·Top3·비율 산술, 경주별 확률합·좌결합 조합 순위, 저장 지표 및 bootstrap 산술을 확인한다. 전수 이력 검사 건수와 고정된 synthetic 반례 검사를 JSON으로 기록한다. 합격 전에는 최종 결과를 납품하지 않는다.

고정 산출물은 `outputs/` 안의 준비 잠금·피처 원장·결측/표본 지원표·모형 메타데이터와 저장 파일·말별 예측·경주 지표·상위조합·전체/하위군/보정표·paired 차이 구간·2026 운영 공통 표·verification JSON이다. `README.md`는 해석, 고정한 정의, 관측된 개선·퇴행·소표본 및 한계와 원천/코드/모형 해시를 연결한다. 중앙 conclusions는 이 담당 작업에서 수정하지 않는다.
