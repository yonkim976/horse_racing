# 제주마 최소 기준선과 실험 절차 v1

상태: 사전 설계. 아직 학습·확률 보정·성능 평가는 실행하지 않았다. 아래 입력은 후보이며 실제 학습 채택 목록은 시점·라벨 계약을 완료한 뒤 별도 manifest로 고정한다.

## 정답·모집단

초기 정답은 `y=1[최종 착순 1,2,3]`이다. 우승 y와 별도 저장한다. 취소·불성립은 정답 경주에서 제외한다. 출전취소·제외·주행중지·실격·동착을 숫자 착순이나 무조건 비입상으로 일괄 변환하지 않는다. 결과 코드별 의미와 T−2 등록 출전집합에서 실제 출주집합으로의 변화를 먼저 문서화한다.

`provisional_label_scope.json`의 5,365경주는 보수적인 **사후 점검 표본**이다. 모든 후보가 정상 숫자 착순·양수 시간을 가지고 1·2·3위가 각각 한 마리인 경주만 센 것이다. 정상 완주 말만 행 단위로 남겨 DNF 말이 없었던 편성을 만들지 않는다. 이 필터는 사전 예측 시점의 출전 선택 규칙이 아니며 배포 모집단과 다르다. 최종 학습 전에는 동착·출전집합·품종 유효시점·결과코드 계약을 적용하고 그 변경으로 생긴 제외 경주를 기록한다.

정답 후보 시작일은 2017-01-01, 실제 첫 경주일은 2017-01-13이다. 이전 기록은 해당 말의 T−2 이전 기본 성적 warm-up으로 사용할 수 있다. 시작 자료가 2002년이므로 평생 이력 완전성을 주장하지 않는다. 구간·통과순위의 초기 이력은 2017년 이후로 제한한다. 400m·장거리·희소 등급을 삭제하거나 다른 거리로 합치기 전에 지원 범위와 표본량을 따로 보고한다.

## 예측 시점과 사용 가능성

- 사건 날짜: `history_date <= race_date−2일`, 한국 날짜 c일 전체 포함.
- 공개시각: 확인되면 `available_at < race_date−1일 00:00 Asia/Seoul` 추가. 미확정은 플래그를 두고 회고 분석으로 한정한다.
- 현재 DB 정정값: 사후 품질 개선 자료다. 회고 교정 버전의 성능과 실제 당시 알려진 자료의 성능을 구분한다.
- 이번 출전표: 거리·등급·중량·마번·출전집합을 당시 공개된 자료에서 재생할 수 있어야 한다. 현재 결과 원장 재구성 예시만으로 가용성을 입증하지 않는다.
- 이번 당일 체중·주로·tempo: T−2 초기 모델에서 제외. 추후 별도의 예측시점 모델을 만들 때 과거 가용성을 확인한다.

## 최소 기준선 후보

먼저 정상적인 완전 편성 N에 균등 `p_top3=3/N`을 주는 참조선을 둔다. 이것도 유효 Top3가 정확히 3마리인 라벨 계약이 전제다. 다음으로 단순한 결측 처리 가능한 말별 분류기를 원기록 입력으로 비교한다. 알고리즘·튜닝 범위를 학습 전에 고정하며 시작부터 대규모 탐색을 하지 않는다.

| 묶음 | 정확한 입력 후보 | 현재 조건 |
|---|---|---|
| 이번 기본 조건 | `target_distance_m`, `target_grade_raw`, `target_carried_weight_kg`, `declared_field_size` | 거리·등급·중량·두수의 T−2 가용성 필요. 등급은 원문 범주 유지 |
| 관측 경력 | `observed_start_count`, `valid_time_count_all_distances`, `days_since_last_observed_start` | 관측 공백과 실제 신마를 구분 |
| 과거 기본 상태 | `last_observed_event_age`, `last_historical_body_weight_kg`, `last_historical_carried_weight_kg` | 과거 나이·체중으로 명시. 현재 고정 나이는 입력 제외 |
| 동일거리 전체기록 | `same_distance_last_time_s`, `same_distance_recent5_mean_s`, `same_distance_valid_time_count`, 최근 평균의 관측수, 마지막 동일거리 기록 이후 일수 | 동일거리 기록 없으면 시간 NULL, 관측수 0 |
| 결측 설명 | 위 입력의 결측 여부·지원 원천 상태 | 0으로 채워 능력 부족으로 표현하지 않음. 결측 처리는 학습 구간에서 결정 |

최근 편차·최고 기록·변화량은 평가표에 보존하되 첫 최소 입력과 분리해 전체기록 확장 묶음에서 효과를 본다. 입력12개·258개를 목표로 삼지 않는다. 식별자·최신 마명·원문 SHA는 연결과 감사에만 사용하고 예측 입력에서 제외한다. 이번 원천 체중·주로, 기수·기수 성향·심판기록·시장 배당·영상은 초기 입력에서 제외한다.

## 정보 묶음 추가 순서

| 실험 | 추가 후보 | 핵심 비교 |
|---|---|---|
| M0 | 위 최소 기준선 | 균등 확률 대비 전체기록의 효용 |
| M1 전체기록 확장 | 최근 편차, 변화, 365일 최고·두 번째 기록 차, 각각 n·최근성 | 평균·최고·안정성의 별도 기여 |
| M2 구간기록 | 정의가 지원되는 동일거리 S1F/G3F/G1F와 관측수 | 전체시간 보정과 구간 보정 구분 |
| M3 성적·상태 | 과거 입상 이력, 체중·중량 변화 | 최근 시간의 중복 설명인지 확인 |
| M4 상대 능력 | 이번 출전마 평가표의 순위·중앙값 차·지원수 | 동일 T−2 자료로 편성 집계 |
| M5 거리별 전개 | 개별 초반 위치·유지·진출 이력, 별도 예상 전개 | 과거 위치를 이번 확정 각질로 쓰지 않음 |
| M6 게이트 | 검증된 출발번호/실제 게이트와 거리·주행 특성 상호작용 | 번호·실제 게이트·주행 내외측 구분 |
| M7 주행심사 | 거리·시점 확인된 심사 기록과 관측수 | 저경력마 하위군 효과·결측 편향 |
| M8 동반입상 | 공동 Top3 집합 또는 조건부 조합 모델 | 말별 확률과 조합 사건 확률 구분 |

각 실험의 added/retained/removed 열, 원천·계산 코드 해시, 결측 처리, 거리 지원표, 경주 집합, 날짜 분할, seed, 튜닝 횟수를 manifest에 남긴다. 이전 묶음이 개선되지 않으면 다음 기준선에 자동 유지하지 않는다. 구간 보류 필드와 관련 파생값은 상태를 따라 차단한다. 알려진 충돌 행을 더 넓게 제외한 민감도 분석도 같은 평가 경주에서 비교한다.

## 제주 전용 주로 보정 연구

현재 확인한 동일거리·시대 중앙값 대비 잔차는 주로 보정 완료물이 아니다. 검증된 제주 경주 함수율 계수를 확인하지 못했으므로 M0는 원기록으로 보존한다. 더러브렛 계수와 공식 안내의 지수 환산 계수를 그대로 적용하지 않는다.

먼저 같은 거리·시대 안에서 함수율, 등급·연령 구성, 출전마 수준과 시간의 관계를 조사한다. 보정 함수는 과거 학습 구간만으로 적합하고 미래 기간에서 잔차 편향·안정성과 입상 예측을 각각 평가한다. 희소 거리의 계수 통합·축소는 검증할 가설이다. 0%·빈 함수율은 미확정이며 건조 0으로 쓰지 않는다. 같은 날 전체 경주 결과로 그날 사전 예측의 주로 변이를 계산하지 않는다. 과거 이력 보정도 보정함수 적합 시점과 사용 가능한 결과 시점을 명시한다.

전체시간 보정과 각 구간 보정을 별도 실험으로 둔다. 구간 계측 경계가 확인되지 않은 거리에서는 속도 환산·중반 차분을 보류한다. 보정 지원 밖의 말에는 원기록과 지원 부족 상태를 유지하고 추정값을 관측값으로 표기하지 않는다.

## 시간순 학습·보정·평가

경주일 전체를 같은 구간에 묶고 `학습 < 확률 보정 < 평가`를 지킨다. 전처리·등급 매핑·변수 선택·보정 함수·하이퍼파라미터는 해당 평가 구간 앞의 자료만 사용한다. 평가 구간 안에서도 이미 발생한 T−2 이전 경주 이력은 정해진 갱신 규칙으로 사용할 수 있으나 모델 재적합 여부는 미리 고정한다.

개발용 시간 분할 초안은 다음과 같다. 실제 모집단을 확정한 뒤 날짜와 행 수를 manifest에 동결한다.

| 개발 fold | 학습 | 확률 보정 | 평가 |
|---|---|---|---|
| D1 | 2017~2020 | 2021 | 2022 |
| D2 | 2017~2021 | 2022 | 2023 |
| D3 | 2017~2022 | 2023 | 2024 |

이 표는 재사용되는 **개발 평가**다. 기존 v13은 이미 2026-01-02~2026-09-12의 510경주를 평가했고 이후 실험도 같은 기간을 사용했다. 이번 예시는 2026-09-19까지 확인했다. 따라서 2025~2026년의 재사용 성능을 새로운 독립 검증으로 부르지 않는다. 진정한 최종 검증은 설계 동결 이후 아직 분석하지 않은 기간에서 해야 하며 현재 보유 상한 이후 자료는 이번에 수집하지 않았다.

## 지표와 조합

주지표는 말별 Top3 binary log loss와 Brier다. runner 평균과 race 균등 평균을 함께 보존하고, 확률 구간별 예측 평균·실제 비율·표본수로 보정을 본다. 상위 k 후보 포함률은 `실제 입상마∩상위k / 실제 입상마수`, k=3·4·5·6으로 고정한다. 실제 입상마 3두 전부 포함된 경주 비율은 별도로 표시한다. 경주일 단위 paired bootstrap 등으로 묶음 간 차이의 불확실성을 함께 본다.

신마 여부가 확인된 표본, **관측 이력 0·1~4·5개 이상** 표본을 구분한다. 저경력 기준은 이번 개발 분석용 정의이며 신마를 뜻하지 않는다. 거리·등급·연도별 결과와 분모를 함께 보고 희소군의 우연한 개선을 일반화하지 않는다.

삼복승은 순서를 무시한 3두 집합이다. 경주당 최대 6개의 서로 다른 조합을 동일 정책으로 선택하고 실제 유효 입상 집합을 포함하는지 집계한다. 선택 정책은 개발/보정 구간에서 정하고 평가 결과를 보고 바꾸지 않는다. `p_i × p_j × p_k`는 동반입상 확률이 아니다. 초기 주변확률만으로 조합 순위를 만들 경우 그 점수는 순위용 휴리스틱으로 표시하고, 공동확률이라고 설명하지 않는다. 공동 집합 모델은 M8에서 별도 검증한다. 조합 수·지원 경주·제외 사유를 모두 남기고 적중률을 수익률로 표현하지 않는다.

## 학습으로 넘어가기 전 완료 조건

1. T−2 출전집합·조건의 재생 가능성과 사후 정정 버전의 사용 범위를 명시한다.
2. 출전취소·DNF·실격·동착·품종의 라벨 계약을 적용해 경주별 포함/제외 원장을 만든다.
3. 위 분할·입력·결측·최소 모델·비교 지표를 고정한다.
4. 현재 평가표 예시의 의미와 계산 검증을 유지한 채 원기록 M0를 학습한다.

이 조건은 추가 승인 요청이 아니라 연구의 데이터·실험 준비 순서다. 현재 첫 작업은 완료했으며 운영 모델과 DB를 바꿀 필요 없이 제주 폴더 안에서 이어갈 수 있다.
