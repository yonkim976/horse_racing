# 말별 평가표 v1 계산 계약

상태: 일부 항목을 실제 계산한 연구 초안. 평가표는 종합점수나 예측확률이 아니다. 최근 평균·최고·편차·표본량을 별도 열로 유지한다. 전체시간·구간시간 모두 현재는 **원기록**이다.

## 이력 집합과 시간

대상 경주일을 한국 날짜 T, 절단일을 c=T−2로 둔다. 과거 기록은 `race_date <= c`로 선택한다. 날짜만 있으므로 c일 전체를 포함하고 T−1·T당일은 제외한다. 예시의 T=2026-09-19, c=2026-09-17이다. 최종 운영에는 공개시각까지 확인해 `available_at < T−1 00:00 Asia/Seoul` 조건을 추가해야 한다. 현재 정정·검토값을 과거에 알려진 값으로 소급했다고 주장하지 않는다.

H는 같은 공식 말 ID의 관측 이력, S는 H 중 정상 숫자 착순 1~89 또는 원천 결과코드 91/92인 관측 출전이다. 코드 91/92를 일반 착순이나 유효 시간으로 쓰지 않는다. V는 H 중 정상 숫자 착순·양수 전체시간·양수 거리를 모두 만족하는 기록이다. D는 V 중 이번 거리와 **정확히 같은 거리**다. 시간순 정렬 후 R은 D의 최근 최대 5개, W는 D 중 `[c−364일,c]`이다. 출전수는 관측수이며 평생 경력이나 신마 여부의 확정값이 아니다.

## 계산한 항목

| 항목 / JSON 열 | 식 | 근거와 제한 |
|---|---|---|
| 관측 출전수 / `observed_start_count` | \|S\| | 자료에 없으면 관측수 0. 실제 경력 0과 구분 |
| 출전 간격 / `days_since_last_observed_start` | T−max(S 날짜) | 관측 출전 없으면 NULL |
| 유효 전체기록수 / `valid_time_count_all_distances` | \|V\| | 다른 거리 시간의 평균을 내지 않음 |
| 동일거리 기록수 / `same_distance_valid_time_count` | \|D\| | 동일거리 무관측과 경주 전체 무관측을 구분 |
| 직전 동일거리 시간 / `same_distance_last_time_s` | 마지막 D의 시간 | 직전 출전이 다른 거리면 전체 직전 출전과 다를 수 있음 |
| 최근 평균 / `same_distance_recent5_mean_s` | ΣR시간/\|R\| | 최대 5개. 고정 가중치 없음 |
| 최근 편차 / `same_distance_recent5_std_s` | √[Σ(t−평균)²/\|R\|] | 모집단 표준편차, n<2이면 NULL. 동일조건 능력의 확정치 아님 |
| 최근 변화 / `same_distance_latest_minus_prior3_mean_s` | 최근 시간−그 직전 최대 3개 평균 | 음수는 원기록 단축. 이전 기록 없으면 NULL |
| 최근 최고 / `same_distance_best365_s` | min(W시간) | 시간·당시 날짜·거리·등급·중량·체중·주로를 함께 보존 |
| 최고와 두 번째 기록 차 / `same_distance_second_best_gap365_s` | 두 번째로 작은 W시간−최소 W시간 | 반복 출전은 각각 한 관측. n<2 NULL. 작은 차가 재현 능력을 보장하지 않음 |
| 과거 체중 / `last_historical_body_weight_kg` | S 중 마지막 유효 체중 | 이번 당일 체중과 구분 |
| 과거 체중 변화 / `last_minus_previous_body_weight_kg` | 최근 유효 체중−직전 유효 체중 | 원문 괄호 증감과 별도 계산. 출전 누락 가능성 존재 |
| 과거 부담중량 / `last_historical_carried_weight_kg` | S 중 마지막 양수 중량 | 이번 중량과 분리 |
| 과거 나이 / `last_observed_event_age` | S 중 마지막 유효 `age_at_race_raw` | 대상 경주 당시 나이와 같다고 단정하지 않음 |
| 구간 평균 / `s1f/g3f/g1f_recent5_mean_s` | 2017년 이후 D에서 해당 구간 유효값 최근 최대 5개 평균 | 구간별 관측 집합이 다름. 원천 양수 또는 홈페이지 정정 상태만, 알려진 내부 충돌이 있는 행은 보수적으로 제외 |
| 초반 위치 / `early_rank_fraction_recent5` | 평균[(S1F순위−1)/(해당 경주 관측 출주두수−1)] | 0이 앞쪽. 2017년 이후 D, 유효 개별 순위 최근 최대 5개. 부분 후보 경주·N≤1 제외 |
| 위치 변화 / `early_to_g1f_order_gain_recent5` | 평균(S1F순위−G1F순위) | 위 초반 관측 중 G1F도 유효한 것. 양수는 순위 진출이며 가속도·주행거리·내외측 위치가 아님 |

`metric`에는 `value`, `n`, `unit`, `formula`, `source_api_record_ids`를 둔다. `n`은 해당 계산에 사용한 관측수다. 최고값의 n은 W 전체 기록수, 두 번째 기록 차의 n은 선택된 2개다. 표준편차가 NULL이어도 n=1일 수 있다. 각 계산은 서로 다른 근거 행을 가질 수 있다. 모든 과거 행의 키와 payload SHA는 `history_lineage`에 남긴다.

마명은 최신 프로필명, 표시 나이는 사용자 지정대로 **2026−최신 프로필 출생연도**다. `display_age_2026_current_profile`은 표시 전용이며 과거 학습 행의 나이로 쓰지 않는다. 원천 나이의 알려진 충돌은 유지하고 과거 나이 해석은 별도 검증한다.

## 설계했지만 아직 계산·채택하지 않은 항목

| 평가 묶음 | 후속 계산 후보 | 확인할 조건 |
|---|---|---|
| 좋은 기록의 반복 | 과거에만 적합한 동일거리·시대 기준값 이하 기록 비율, 분자·분모 | 좋은 기록의 기준은 개발 자료에서 확정. 최고 한 번과 반복을 분리 |
| 유사거리 적성 | 거리별 원기록·잔차·n 벡터, 거리 간 전이계수 | 평균속도로 모든 거리를 합치지 않음. 거리군·환산은 제주 검증 후 |
| 중반 특성 | 확인된 경계 사이의 누적시간 차 | 계측 순서·경계 미확정인 S1F/2C 차는 계산하지 않음 |
| 앞선 유지 | 유효 개별 순위 지점 간 유지·진출 비율 | 통과조에서 개별 순위를 복원하지 않음. 각질 임계값 미정 |
| 이번 중량 변화 | 이번 확인된 부담중량−과거 마지막 부담중량 | 이번 값의 T−2 공개 근거 필요 |
| 나이·성별 | 과거 원천 나이, 시점 일치 프로필 성별 | 현재 프로필로 당시 상태를 덮지 않음 |
| 신뢰도 | n, 마지막 유효 기록 이후 일수, 결측 사유, 원천 검토 상태 | 하나의 임의 가중 신뢰도 점수로 합산하지 않음 |
| 심사 | 최신 관측일·유효 시간·거리 확인 상태·심사 횟수 | 지금은 관측 사실만 별도 표시. 경주시간과 합치지 않음 |

## 말 자체와 이번 편성

평가표는 과거 관측값이다. 이번 거리·등급·상대 기록 분포·예상 앞선 경쟁·출발번호·이번 부담중량은 다음 결합 단계의 문맥이다. 이번 예상 각질과 과거 초반 위치는 별도 열로 둔다. 상대 말 집계는 이번의 확인된 전체 출전집합에서 각 말의 T−2 평가표만 사용한다.

현재 예시의 이번 거리·등급·부담중량·마번·편성 두수는 결과 원장에서 재구성했다. `target_context_reconstructed_not_verified_at_T_minus_2`라는 이름으로 공개 가능성 미확정을 표시했다. 이를 그대로 사전 예측에 사용할 수 있는 스냅샷이라고 부르지 않는다. 이번 최종 착순·전체시간·구간시간·사후 주로·당일 체중은 평가표 계산에 들어가지 않는다.

## 검증

실제 코드에서 대상 경주의 착순·시간·체중·주로를 바꿔도 평가표가 같음을 확인했다. T−1 가상 기록은 제외, T−2 기록은 포함했다. 다른 거리의 기록만 있을 때 동일거리 능력값이 NULL임을 확인했다. 원문 체중 `0()`과 빈 증감은 0kg·변화 없음으로 처리하지 않았다. 상세 결과는 `verification.json`에 보존했다.
