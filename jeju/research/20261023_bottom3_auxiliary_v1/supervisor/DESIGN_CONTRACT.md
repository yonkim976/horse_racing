# 하위 3두 전용 보조 모델 — 결과 전 계약

2026-10-23. 사용자가 승인한 첫 비교다. 새 하위 3두 성과를 계산하거나 모델을 학습하기 전에 이 계약을 고정한다. 기존 S는 연구 후보, F1_STYLE6는 연구 비교 기준선, 운영 모델은 운영 등록부로 구분한다. 이번은 하위 3두 보조 예측을 평가하는 실험이며 기존 상위 공동분포·7승식 확률을 변경하거나 운영에 적용하지 않는다.

## 한 가지 연구 질문

S의 동일한 40개 입력·전처리·시간 분할·LightGBM 설정을 유지하면서 정답만 Top3에서 Bottom3로 바꾸면, 기존 S의 가장 낮은 점수 3두보다 하위 3두의 확률과 선택이 좋아지는가? 별도의 입력 추가, 다른 seed, 학습량 탐색, 앙상블, 가중치 탐색은 하지 않는다.

정상 완주하고 순위가 정확히 1..N인 경주에서 `y_bottom3=1[finish_position >= field_n-2]`다. 10두 편성에서는 8~10위이며 비입상 4~10위와 다르다. 비완주·실격·동착·취소를 임의로 마지막 순위에 넣지 않는다. 기존 전원 정상 완주·완전 명단의 회고 코호트를 유지한다.

## 비교군과 시간

- L(S_LOW3): 직전 S의 저장된 provider별 원시 점수를 재사용하고 `u_L=-raw_score_S`로 하위 위험 순서를 정한다. 가장 낮은 S 점수 3두를 선택하는 기준선이다. 기존 S가 직접 학습한 Bottom3 확률이라고 부르지 않는다.
- B: 같은 40개 입력으로 Bottom3 binary 목적을 새로 학습한 단 하나의 후보. 원시 점수 `u_B=raw_score_B`가 클수록 하위 3두 쪽이다.

Y=2024,2025,2026: 초기학습 2017..Y−3, early stopping Y−2, 선택한 반복 수로 2017..Y−2 재학습, 보정 Y−1, 평가 Y. 범주 어휘는 초기학습에서만 만들며 refit에도 고정한다. candidate B 최종 모델 3개, 초기학습+refit 총 6회. S 저장 점수도 같은 provider Y의 calibration/evaluation 역할을 정확히 나눠 사용한다. 서로 다른 provider가 같은 경주를 예측한 행을 섞지 않는다.

LightGBM binary/binary_logloss, lr .04, leaves 15, min_data_in_leaf 100, lambda_l2 5, seed 20261008, deterministic/force_col_wise true, 4 threads, max 800, early stopping 25, 각 말의 학습 가중치 1/N로 경주 합계 1. 이 설정과 40개 입력 이름·범주 어휘를 직전 S metadata와 대조한다. 모델 점수는 raw_score=True로 저장한다.

F1 frozen features.parquet의 52,155행·5,206경주와 직전 S state_features.parquet의 10개 상태를 키로 1:1 결합한다. 기존 입력·상태를 복사하거나 다시 생성하지 않는다. S raw score 테이블의 `year`는 provider의 평가연도이며 calibration 행의 실제 race_date 연도는 Y−1이어야 한다. fit/earlystop/cal/eval 경주를 혼합하지 않는다. 동일 경주 말들은 한 분할에 속한다.

기존 사건일 기준 T−2 포함 경계를 유지한다. 실제 공개시각 및 당시 구매 가능 명단은 미확인이다. 평가 2024-01-05~2026-09-19의 1,779경주·17,412두·269일, 연도별 637/654/488경주를 그대로 쓴다. 새 평가기간 또는 미래 독립 검증이라고 부르지 않는다. 전체 라벨 합계 15,618개, 평가 5,337개이며 각 경주에는 정확히 3개 양성이 있어야 한다.

## 두 arm에 같은 하위 3두 집합 확률

순서 없는 정확히 3두 집합 A에 대해 `P(A|u,T)=exp(sum_{i in A} u_i/T) / sum_{C:|C|=3} exp(sum_{j in C} u_j/T)`를 사용한다. 계산은 log-sum-exp로 안정화한다. 두 arm 모두 같은 변환을 써 학습 목표만 비교한다. 이는 새로 명시한 Bottom3 집합 분포이며 기존 S의 상위 3착 PL 분포의 단순 역수나 보수가 아니다.

말별 Bottom3 확률은 그 말을 포함하는 모든 집합의 확률 합이다. 전체 집합 확률 합=1, 모든 말의 Bottom3 주변확률 합=3, 각 확률은 [0,1]이어야 한다. 주변확률을 곱해 집합 확률을 만들지 않는다. Top3 확률을 `1-P(Bottom3)`로 계산하지 않는다. 이 보조 집합 분포는 중간 순위나 상위 3착 순서를 정의하지 않으므로 7승식 확률을 출력하는 대체 모델로 사용하지 않는다.

L/B 각각의 연간 T는 provider Y의 Y−1 OOS 원시 점수와 실제 Bottom3 집합으로 집합 categorical NLL을 경주 동일 가중 최소화한다. T 범위 [.35,4], scipy bounded xatol 1e−12와 양 끝점의 목적값을 비교하여 최소값을 사용한다. 보정 6개만 허용한다. 기존 S의 Top3 PL temperature를 재사용하지 않으며, Y 평가 정답으로 T나 설정을 바꾸지 않는다. 온도 목적은 순서 없는 Bottom3 집합이며 마지막 3두의 정확한 역순을 추가 목표로 쓰지 않는다.

## 선택·확률 지표와 고정 판정

각 arm은 하위 위험 raw utility 상위 3두를 선택한다. 순차 선발에서 현재 최대 u−1e−12 이상을 동률로 보고 마번 사전순으로 고른다. L은 S raw score 최저 3두라는 기준을 그대로 보존한다. 후보 수·선택 방식·평가 경주는 동일하다.

확률 주 지표는 Bottom3 집합 categorical Log loss다. 전체 집합 one-hot Brier 합, 말별 Bottom3 binary Log loss와 Brier의 경주 내 평균도 보고한다. 수치 EPS=1e−15, 확률 구간은 기존 16개 경계 [0,.00001,.00005,.0001,.00025,.0005,.001,.0025,.005,.01,.025,.05,.1,.25,.5,.75,1]를 유지한다. 집합 확률과 말별 확률의 구간표를 별도로 저장하고 전체·연도별 ticket-event/runner-event 수 가중임을 표시한다. proper loss는 경주 동일 가중이다.

선택 지표는 경주당 실제 Bottom3 포착 수(0..3), precision@3=recall@3=포착수/3, 실제 Bottom3 집합 완전 일치, 선택한 3두 중 실제 Top3 포함 수(0..3), 한 마리라도 Top3를 잘못 제외한 비율, 실제 우승마 제외 비율이다. `모든 실제 Top3 보존=1−Top3 한 마리 이상 제외`를 함께 보고한다. N−3마리를 남기는 정책이며 3두를 제외한 뒤 확률을 0으로 만들거나 조합을 재정규화하지 않는다. 모든 동일 경주를 포함하고 유리한 거리/연도/출전두수만 사후 선택하지 않는다.

단일 비교 B−L에 대해 다음을 미리 구분한다.

1. **하위 3두 예측의 후속 연구 후보:** 집합 Log loss 날짜 paired bootstrap 95% 상한<0, 집합 Brier 차이<=0, 말별 binary Log loss 및 Brier 차이<=0를 모두 충족해야 한다.
2. **제외 보조 활용의 후속 연구 후보:** 위 기준을 통과하고, Top3 한 마리 이상 잘못 제외 비율과 우승마 제외 비율의 점추정이 각각 L보다 높지 않아야 한다.

두 번째 보호 조건은 점추정이며 통계적 비열등성이나 안전한 실전 제외를 입증하는 기준이 아니다. 각 지표의 날짜 구간을 함께 보고한다. 조건을 미리 나눴으므로 하위 정확도가 좋아져도 제외 성능이 나빠지면 두 판정을 다르게 기록한다. 어느 경우에도 바로 운영·승식 예측에 편입하지 않는다. 승식 적중률 +10%나 시장 우위를 이번 실험의 성공으로 주장하지 않는다.

기존 2,000×269 날짜 bootstrap schedule과 정렬 날짜 목록을 참조한다. 같은 날짜 경주를 함께 재표집하고 경주 수로 정규화한다. 전체·연도별·출전두수별 분모와 진단을 보존하되 주 판단은 고정된 전체 집합에서만 한다. 주 지표 외 구간은 기술적 비교이며 다중 비교 보정과 모델 재학습 불확실성을 포함하지 않는다.

## 역할·검토·저장

기존 세션의 GPT-6 Luna xhigh: asset_audit는 audit/, baseline_experiment는 experiment/, rules_contract는 review/를 소유한다. 감독관은 supervisor/와 루트 최종 보고·manifest를 소유하고 설계·시점·코드 검토, 별도 수식·모델 재생·결과 검산을 수행한다. 파일 구현을 중복하지 않는다.

학습 전에 원천 해시·정확한 경주/키·라벨·분할·범주 어휘·입력 목록·합성 확률 검산·코드 검토를 통과하고, 감독관이 최종 코드/계약/입력 해시를 결합한 내부 실행 승인 원장을 쓴다. 사용자 재승인은 필요 없다. 승인 전에는 B fit, 새로운 L/B Bottom3 성과 계산을 하지 않는다. 합성 검사와 label/분모/시점 구조 확인은 가능하다.

감독관은 3개 저장 모델의 cal/eval raw score를 재생하고 T의 목적·stationarity/경계 부호를 독립 확인한다. 모든 경주의 전체 Bottom3 집합을 별도 공식으로 재구성해 주변확률·7개 선택/보호 지표·proper loss·구간 빈도·bootstrap·채택 판정을 검산한다. 추가 모델 학습은 하지 않는다.

신규 저장 예산 30,000,000B, 이전 세션 57,799,506B를 포함해 총 300,000,000B 이내다. 신규 DB/대형 스냅샷/feature 복사/중복 환경은 만들지 않는다. 기존 source·state·모델·S score·bootstrap은 경로와 SHA-256으로 참조한다. 새 B 모델 3개 text, B cal/eval raw score, L/B 말별 핵심 확률, 경주 지표·선택 원장·집계·계수·환경·입력 해시만 압축 Parquet/JSON으로 보존한다. 전체 경주의 모든 집합 확률을 펼쳐 파일로 저장하지 않고 경주별 계산한다. 이번에 만든 재생성 가능한 임시파일만 정리할 수 있다.

원천/DB/기존 연구/더러브렛/운영 등록부는 변경하지 않는다. 외부 수집과 사후 배당 기반 구매 전략을 추가하지 않는다. 모델·예측·새로운 기간의 성과·시장 가치와 수익 성과를 구분하며, 미확인 공개시각과 정상 완주 표본의 선택 제한을 최종 보고에 포함한다.
