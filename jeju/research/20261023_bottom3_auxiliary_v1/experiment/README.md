# 제주 Bottom3 보조 분류 실험

이 실험은 같은 40개 S 입력, 전처리, 시기 분할, LightGBM 설정에서 학습 목표만 정상 완주 순위의 Bottom3 지시변수로 바꿨을 때, 저장된 S 원점수를 뒤집은 기준선보다 하위 3두의 집합 확률과 선택이 개선되는지 평가했다. Bottom3 집합 확률은 모든 `C(N,3)` 조합으로 정규화한 별도의 분포다. Top3 확률이나 제주 7승식 확률로 해석하지 않는다.

고정 코호트는 완주마 52,155두, 5,206경주이며 평가 범위는 2024년부터 2026-09-19까지 1,779경주, 17,412두, 269경주일이다. 비교군 L은 동일 provider vintage의 저장 S raw score에 부호를 바꾸고, 후보 B는 동일 입력으로 Bottom3 분류기를 학습했다. 연도별 학습·조기종료·refit·보정·평가 분리와 모든 입력 해시는 `outputs/parameters.json`, `outputs/fit_run_receipt.json`, `outputs/source_preflight.json`에 보존했다.

승인된 한 번의 실행은 6회 LightGBM 학습 호출과 6회 연간 온도 보정으로 끝났다. B 모델의 best iteration은 2024년 312, 2025년 160, 2026년 203이었다. L의 Bottom3 집합 온도는 각각 1.224969, 1.172648, 1.116850이고 B는 1.131145, 1.102727, 1.066382였다.

B−L의 전체 평균 차이는 Bottom3 집합 NLL −0.060336, 집합 Brier 합 −0.001576, 말별 이진 log loss −0.006659, 말별 Brier −0.002800이었다. NLL의 고정 날짜 bootstrap 95% 구간은 [−0.083043, −0.039072]였고, 나머지 세 proper-loss 조건도 모두 0 이하라서 **prediction research gate는 통과**했다. 이 판정은 동일 코호트의 연구 후보이며 미래 표본에서의 독립 검증이나 운영 승격을 뜻하지 않는다.

하위 3두 선택은 경주당 평균 포착 수가 1.382799에서 1.403035로 0.020236 증가했지만, 그 차이의 bootstrap 구간 [−0.008586, 0.048126]은 0을 포함했고 정확한 3두 집합 일치율 차이도 +0.001686에 그쳤다. 동시에 B는 실제 Top3 말을 하나 이상 잘못 제외한 비율이 0.424958에서 0.477234로 0.052277 증가했고, 실제 우승마 제외율도 0.128724에서 0.168634로 0.039910 증가했다. 두 증가의 bootstrap 구간은 각각 [0.032240, 0.071711], [0.025655, 0.054617]로 양수였다. 따라서 **exclusion auxiliary gate는 통과하지 못했다**. Bottom3 확률 손실의 개선은 Top3 또는 우승마를 안전하게 제외하는 성능을 보이지 않는다.

재현과 독립 검산에 필요한 모든 산출물 및 모델 해시는 `outputs/fit_run_receipt.json`에 있다. 실험 전체 설계와 정확한 지표 정의는 `PLAN.md`와 `../supervisor/DESIGN_CONTRACT.md`를 참조한다. 이 연구는 Bottom3 보조 과제만 시험했으며 Top3 착순·7승식 모델을 대체하지 않는다.
