# Bottom3 실험 결과·receipt 검토

**검토 판정: 통과 (`passed: true`).** 저장 결과, 단회 실행 receipt, 사전 고정 게이트와 supervisor 독립 검산이 서로 일치한다. 여기서 `passed`는 결과 기록과 주장의 검토가 통과했다는 뜻이다. 후보 gate는 별도다. Bottom3 확률 연구 gate는 통과했지만, 제외 보조 gate는 실패했다.

계약된 실행은 한 번만 수행되었다. receipt는 `COMPLETED_RESEARCH_ONLY`, `run_count=1`, 6회 LightGBM 학습 호출, 6회 온도 적합을 기록하고, 승인 해시와 사전검사·코드·원천 해시를 연결한다. 실행 claim도 1회 claim으로 일치한다. receipt의 11개 결과/모델 artifact 경로가 모두 존재하고 파일 크기와 SHA-256이 receipt와 일치함을 확인했다. 전체 연구 크기는 receipt 기록상 약 2.77 MB로 30 MB 한도 이하다.

주 분모는 두 arm 각각 1,779경주·17,412두·269일이며, 평가 Bottom3 정답은 arm당 5,337개다. 연도별 경주는 2024년 637, 2025년 654, 2026년 488개다. 전체 입력 코호트 52,155두·5,206경주·15,618개 label도 계약과 일치한다. 표본은 완전 명단과 정확한 1..N 순위의 정상 완주 경주로 제한되어 있다.

Supervisor의 독립 검증은 PASS다. 저장된 3개 B 모델 및 3개 기존 S 모델의 calibration/evaluation 원점수 재생, 6개 온도 최적점과 양 끝점, 402,808개 Bottom3 집합 사건, 3,558개 경주 행, 34,824개 말별 주변확률, 256개 신뢰도 bin, 24,000개 paired bootstrap draw를 재구성해 저장 결과와 일치시켰다. 별도 계산 코드를 다시 실행하거나 모델을 재학습하지 않았다. 결과 summary/receipt의 gate 값과 독립 검증 gate 값이 모두 일치하며, artifact 해시 점검에서 누락 또는 불일치가 없었다.

`B−L` Bottom3 집합 NLL 차이는 `−0.060336`이며 날짜 bootstrap 95% 구간은 `[−0.083043, −0.039072]`다. 집합 Brier 합 차이 `−0.001576`, runner binary log loss 차이 `−0.006659`, runner Brier 차이 `−0.002800`도 모두 0 이하라서 사전 고정된 **prediction research gate는 통과**했다. 이는 같은 회고 평가 코호트에서의 Bottom3 집합/주변확률 개선 결과다.

선택 결과는 보호 gate와 다르다. Bottom3 포착 수는 L의 2,460/5,337에서 B의 2,496/5,337로 늘었지만 평균 차이의 구간은 `[-0.008586, 0.048126]`을 포함하고, 정확한 Bottom3 3두 집합 일치율도 83/1,779에서 86/1,779로만 바뀌었다. 반면 하나 이상 실제 Top3 말을 잘못 제외한 경주는 756/1,779에서 849/1,779로 증가했다. 차이는 `+5.23%p`, bootstrap 구간 `[+3.22,+7.17]%p`다. 실제 우승마를 제외한 경주도 229/1,779에서 300/1,779로 증가해 `+3.99%p`이며 구간은 `[+2.57,+5.46]%p`다. 따라서 **exclusion auxiliary gate는 실패**했다. 이 실패는 사전 gate 기준상 명확하지만, gate 자체를 넘어 실전 제외 정책의 통계적 비열등성이나 안전성을 입증하는 연구는 아니다.

해석은 Bottom3 보조 확률 과제에 한정한다. 2024–2026 자료는 이 연구에서 재사용된 회고 평가 구간이며 독립 미래 검증이 아니다. 공개시각·실제 구매 시점의 정보 가용성은 확인되지 않았다. 시장/ROI를 평가하지 않았고, Top3 착순분포나 제주 7승식 확률을 출력하지 않는다. Bottom3 proper-loss 개선은 승식 적중률·시장 우위·우승마 또는 Top3 말을 안전하게 제외하는 능력으로 일반화할 수 없다. 운영 모델·등록부 변경이나 운영 승격도 없다.

결론은 **B를 동일한 Bottom3 확률 연구의 후속 후보로만 기록하고, 실제 말 제외 기능으로는 보류**하는 것이다. 이는 운영 채택 승인이 아니다.
