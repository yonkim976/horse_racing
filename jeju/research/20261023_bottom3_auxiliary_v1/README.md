# 제주 하위 3두 전용 보조 모델 비교

2026-10-23 완료. **하위 3두 확률 정확도는 개선됐지만, 제외용 활용은 보류한다.** 새 B는 사전 고정한 하위 확률 연구 후보 기준을 통과했다. 그러나 실제 Top3와 우승마를 잘못 제외하는 비율이 모두 높아져 제외 보조 기준은 통과하지 못했다. B는 후속 확률 연구용 산출물로 보존하며 기존 S의 상위 착순·승식 확률과 운영 모델은 변경하지 않았다.

## 만든 것과 재사용한 것

- **L — 기존 S 최저 점수 3두:** 저장된 provider별 S 원시 점수의 부호를 뒤집은 하위 위험 순서다. S가 직접 학습한 Bottom3 확률이라는 뜻은 아니다.
- **B — Bottom3 전용 모델:** S와 같은 40개 입력, 범주 어휘·전처리·학습행 순서·시간 분할·LightGBM 설정·경주 가중치를 사용하고 학습 정답만 `finish_position >= field_n-2`로 바꿨다. 2024/2025/2026 평가용 최종 모델 3개를 만들었고 초기학습 및 refit을 합쳐 6회만 실행했다.
- 두 arm은 동일한 **정확히 3두인 순서 없는 집합 분포**를 사용한다. `P(A) ∝ exp(sum(u_i/T), i∈A)`를 모든 `C(N,3)` 집합에 걸쳐 정규화했다. 각 말의 하위 확률은 그 말을 포함한 집합의 확률 합이다. 전체 집합 확률 합은 1, 말별 주변확률 합은 3이다.
- T는 각 provider Y의 직전 연도 Y−1 OOS 자료에서 집합 Log loss를 최소화해 L/B별로 정했다. 보정은 총 6회다. 기존 S의 Top3 온도는 재사용하지 않았다.
- F1 동결 입력, S의 상태 입력·원시 점수·기존 검산 증거, 날짜 bootstrap 표는 경로와 SHA-256으로 참조했다. 원천/DB/feature table 사본을 만들지 않았다.

이 분포는 하위 3두 집합만 정의한다. `1-P(Bottom3)`를 Top3 확률로 해석하지 않으며, 상위 순서와 7승식 확률을 출력하는 공동 착순 모델의 대체물이 아니다.

## 고정 비교 조건

정상 완주하고 전원 순위가 정확히 1..N인 기존 코호트를 썼다. 전체 2017–2026 자료는 52,155행·5,206경주이며, 각 연도 모델의 실제 학습 분모는 별도로 저장했다. 비완주·실격·동착·취소를 임의로 하위 순위에 배치하지 않았다.

평가는 2024-01-05부터 2026-09-19까지 **1,779경주·17,412두·269일**, 연도별 637/654/488경주다. 실제 하위 3두 라벨은 5,337건이다. 두 arm 모두 매 경주 3두를 고르고 N−3두를 남기는 동일 규칙을 평가했다. 유리한 거리·연도·출전두수만 골라 판정하지 않았다.

Y년 모델은 2017..Y−3 초기학습, Y−2 early stopping, 2017..Y−2 refit, Y−1 보정, Y 평가 순서다. 범주 어휘는 초기학습 기간에서만 만들었다. 과거 이력은 사건일 기준 T−2 포함 경계를 유지했다. 같은 평가연도 정답으로 학습 반복 수나 T를 선택하지 않았다. 전체 기간은 앞선 연구에서 사용한 자료이므로 새로운 독립 검증기간이 아니다.

조건과 판정 기준은 [DESIGN_CONTRACT.md](supervisor/DESIGN_CONTRACT.md)에 결과 전에 고정했고, [EXECUTION_APPROVAL.json](supervisor/EXECUTION_APPROVAL.json)이 최종 코드·입력·사전 검토 해시를 결합한다. 학습 전에 발견한 streaming 집계·원장 경로·코호트 명칭·JSON 키 일관성 문제를 고친 후 한 번 실행했다. 결과를 본 뒤 모델이나 선택 규칙을 조정하지 않았다.

## 확률 정확성

모든 proper loss는 경주 동일 가중이며 낮을수록 좋다. 집합 Brier는 경주 내 모든 집합의 one-hot 오차 제곱 합이고, 말별 지표는 경주 내 말 평균이다. 구간은 기존 2,000회 날짜 paired bootstrap의 B−L 95% 구간이다.

| 지표 | L: 기존 S 최저점수 기준 | B: 하위 3두 전용 | B−L | 날짜 95% 구간 |
|---|---:|---:|---:|---:|
| **하위 3두 집합 Log loss — 주 지표** | 4.342293 | 4.281958 | −0.060336 | [−0.083043, −0.039072] |
| 하위 3두 집합 Brier | 0.982184 | 0.980607 | −0.001576 | [−0.002552, −0.000623] |
| 말별 하위 3두 binary Log loss | 0.574421 | 0.567762 | −0.006659 | [−0.009227, −0.004195] |
| 말별 하위 3두 binary Brier | 0.195202 | 0.192402 | −0.002800 | [−0.003915, −0.001751] |

주 지표의 구간 상한이 0보다 작고 나머지 proper loss 점추정도 개선되어 **하위 확률 후속 연구 후보 기준은 PASS**다. 주 지표 이외 구간은 기술적 비교이며 다중 비교 보정·모델 재학습 불확실성을 포함하지 않는다.

집합 사건과 말별 사건의 전체·연도별 16구간 빈도표를 각각 보존했다. 아래는 B의 말별 예측확률 구간이며, 표는 말 수 가중이고 위 손실은 경주 동일 가중이라는 차이가 있다.

| B의 말별 하위 확률 구간 | 말 수 | 평균 예측확률 | 실제 하위 3두 비율 |
|---|---:|---:|---:|
| 2.5–5% | 70 | 4.37% | 2.86% |
| 5–10% | 800 | 7.96% | 8.63% |
| 10–25% | 5,958 | 18.08% | 17.94% |
| 25–50% | 8,592 | 35.41% | 35.45% |
| 50–75% | 1,970 | 57.53% | 57.51% |
| 75–100% | 22 | 76.92% | 81.82% |

일반 구간은 대체로 실제 빈도와 가깝지만, 양끝 구간의 작은 표본과 반복 사용한 평가기간의 한계가 있다. 이 표만으로 미래 보정을 보장하지 않는다.

## 3두 선택과 입상마 보호

| 같은 1,779경주의 선택 결과 | L | B | 변화 |
|---|---:|---:|---:|
| 실제 하위 3두 포착 / 5,337두 | 2,460두 (46.09%) | 2,496두 (46.77%) | +36두, +0.67%p |
| 하위 3두 집합 완전 일치 | 83경주 (4.67%) | 86경주 (4.83%) | +3경주 |
| **실제 Top3를 한 마리 이상 잘못 제외** | **756경주 (42.50%)** | **849경주 (47.72%)** | **+93경주, +5.23%p** |
| 실제 우승마를 잘못 제외 | 229경주 (12.87%) | 300경주 (16.86%) | +71경주, +3.99%p |
| 실제 Top3 세 마리를 모두 보존 | 1,023경주 (57.50%) | 930경주 (52.28%) | −93경주 |

포착률 변화 +0.67%p의 날짜 95% 구간은 **−0.29~+1.60%p**다. 포착률 개선을 확정할 근거는 부족하다. Top3 오제외 변화의 구간은 +3.22~+7.17%p, 우승마 오제외 변화는 +2.57~+5.46%p다. 사전 고정한 두 제외 보호 점추정 조건을 모두 위반하여 **제외 보조 후속 후보 기준은 FAIL**이다.

여기서 Top3 전원 보존은 ‘3두를 제외하고 남은 N−3두 안에 실제 Top3가 모두 있는가’다. 기존 축 한 마리의 Top3 입상률이나 승식 적중률과 다른 지표다. 기준선 L 자체도 실전 제외 전략으로 승인된 것은 아니다.

## 확인한 사실과 해석

확인한 사실은 B가 이 반복 평가 코호트에서 하위 집합·말별 proper loss를 개선했지만 Top3 및 우승마 오제외를 악화했다는 것이다. 따라서 B로 말을 제외해 상위 승식 적중률이 오를 것이라는 가설은 이번 비교에서 지지되지 않았다.

학습 목표에서 10두 경주의 1위와 4위는 모두 ‘하위 3두가 아님’이라는 정답이다. 하위 8~10위를 더 잘 맞히는 목표만으로 입상마를 보호하는 별도 목적까지 충족되지는 않는다. 이 목적 차이는 관측된 결과를 해석하는 근거이며, 특정 입력이 악화를 일으켰다는 인과 진단은 아니다.

다음 연구가 필요하다면 ‘실제 입상마 오제외를 줄이는 목적과 기존 상위 확률의 일관성’을 먼저 설계해야 한다. 이번 결과를 본 뒤 가중치·제외 두수·거리 제한을 바꾸어 재시험하지 않았다. 운영은 HY_R_FORM 등록부 기준을 유지하고, F1_STYLE6 연구 비교 기준선과 기존 S 연구 후보도 보존했다.

## 범위와 저장
