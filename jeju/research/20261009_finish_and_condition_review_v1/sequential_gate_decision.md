# 순차 모델 유지 판단: 사전 해석

결정 시점: 2026-10-09, 후보 출력 확인 전.

이 연구는 기존 후향 평가 구간을 재사용하므로 아래 기준은 탐색적 유지후보 선별에만 쓰며 독립 미래검증이나 운영 승격 근거가 아니다.

1. 먼저 F1−R1의 확률 개선 gate를 평가한다. 전체 평가 모집단에서 log loss와 Brier가 모두 낮아지고, 둘 중 적어도 하나의 날짜 paired bootstrap 95% 점별 구간이 0 아래에 있을 때만 F1 gate 통과다.
2. F1 gate가 통과한 경우에만 F2−F1에 같은 gate를 적용한다. 두 단계 gate가 모두 통과할 때만 F2를 다음 순차 연구의 후보로 부른다.
3. F1 gate가 통과하지 못하면 F2−F1의 개선만으로 F2가 R1보다 낫거나 R1을 대체한다고 주장하지 않는다. F2 모형은 사전 계획대로 학습하고 결과를 보고하되, 이 단계의 순차 유지 gate는 실패로 남긴다.
4. F2−R1은 보조 비교다. 이것만으로 앞 단계 gate를 우회하지 않는다.
5. 확률 개선 gate와 상위 말·조합 지표 개선은 분리해 판정한다. 어떤 단계의 확률 gate가 통과해도 후보 또는 조합 퇴행과 운영 공통 467경주 결과를 따로 함께 보고한다.

이 명확화는 사용자 권한 아래 root 감독관이 내린 사전 해석이다. 잠금된 연구 계약이나 모델 실행 코드는 변경하지 않는다.
