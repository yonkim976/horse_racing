# Top-5 set selector: pre-outcome independent review

Status: independent review completed. Frozen-Q reconstruction, hash-locked choices, and the post-approval 1,779-race outcome report have all been independently checked. The new q-max policy underperformed the fixed F1_STYLE6 Top5 rule on the prespecified primary cohort; the success gate failed.

## Mathematical result

The Top-5 event is `actual unordered Top3 ⊆ selected set`. For any normalized distribution `P(T)` over exact unordered Top3 sets, the probability that a 5-set `S` succeeds is

`q(S) = sum_{T subset S, |T|=3} P(T)`.

The selector must maximize this quantity over all `C(N,5)` five-horse sets. If `N < 5`, selecting all available horses is the only feasible policy; if `N = 5`, the event is certain. The frozen evaluation cohort has runner counts at least 7, so neither edge case occurs in the primary analysis.

A selector built from individual runner weights alone is mathematically degenerate for this objective. For sequential Plackett–Luce, use independent latent variables `E_i ~ Exponential(1)` and clocks `X_i = E_i / w_i`; their order has the PL distribution. Let `a` be selected and `b` unselected, with `w_b ≥ w_a`, and let `E_S` denote the event that the first three clocks all belong to `S`. First compare `E_S` under the original rates `(w_a,w_b)` with `E_S` under swapped rates `(w_b,w_a)`, using the same latent variables. In the swapped-rate version, `X_a` can only decrease and the excluded runner's `X_b` can only increase, while all other clocks remain fixed. The first-three-all-in-`S` event is monotone under those two changes, so its probability cannot decrease. By exchanging the labels of the identically distributed latent variables `E_a` and `E_b`, `E_S` under swapped rates has the same probability as `E_{S-a+b}` under the original rates. Thus exchanging a selected lower-weight runner for an unselected higher-weight runner cannot reduce the Top3-in-set probability. Repeated exchanges show that a set containing the five largest weights maximizes `q(S)`; tied weights can produce multiple equally optimal sets.

The result also applies to the additive exact-set softmax used by the matched F1_STYLE6 baseline. With `w_i = exp(score_i / temperature)`, its triple mass is proportional to `w_i w_j w_k`; therefore `q(S)` is proportional to the third elementary symmetric polynomial of the five selected weights. Replacing selected weight `w_a` with unselected `w_b ≥ w_a` changes the numerator by `(w_b - w_a) * e2(S \\ {a}) ≥ 0`. A single-runner-score top-5 is therefore already optimal under both the PL model and the unary additive joint-set model, independent of positive temperature. A distinct selector can arise only from a non-unary joint distribution, such as the frozen pair-residual candidate below.

## Cohort and independent review contract

The compatible source study reports 1,779 complete normal-finish evaluation races, 17,412 runner rows, and 269 race dates from 2024-01-05 through 2026-09-19. The fixed primary distance cohort is 900, 1,000, 1,110, and 1,200 metres: 251 + 508 + 482 + 262 = 1,503 races. The remaining 276 races (800, 1,300, 1,400, and 1,610 metres) are outside this primary cohort and must not be added after seeing results. Each included race has a complete runner roster and one unique actual unordered Top3 set. The existing research independently reconstructed the old joint probabilities from locked sources and reported all 39 source hashes unchanged.

The independently rebuilt Q must be compared race-by-race with the frozen candidate distribution, not just with stored six-ticket rankings. For each race the review will check: the complete `C(N,3)` roster; finite nonnegative masses summing to one; agreement of `probability` with stable softmax of `total_energy / temperature`; one exact true set; and candidate probabilities agreeing with the root rebuild within its declared numeric tolerance. The review implementation will not import functions from the source model or root's selector.

For choice verification, all `C(N,5)` sets were independently enumerated per race from the locked probability source. Triple probabilities were accumulated in canonical sorted horse-number tuple order with `math.fsum`. Among sets within absolute `1e-12` of the maximum `q`, the predeclared tie rule is greatest overlap with the baseline raw-score top-5, then lexicographically smallest sorted horse-number tuple. The independent implementation reproduced all 1,779 locked candidate choices and verified that matched unary-Q reproduces raw-score top-5 in every race. Reversing probability-row insertion order did not change selected-set utilities. The independent receipt is `INDEPENDENT_CHOICE_AUDIT.json`; it records selection SHA-256 `1f3d40769939b82afe4f6278f92bf5f13af85329355a4a03ddc036391d55322d`, source selector SHA-256 `9bbd0556236dde13697f62dec70e7a81928bab1f57de0ab267008b429e94c4e2`, 386 changed candidate choices, maximum q gap `2.78e-17`, and zero utility replay difference. The primary observed outcome is whether all three actual Top3 horses are inside the chosen five. This is a retrospective result, not an independent future holdout or evidence for operational adoption.

## Limitations and controls

The new selector is outcome-blind once the objective, distances, baseline, tolerance, overlap rule, and bootstrap schedule are frozen. Nonetheless, it is evaluated on a repeatedly inspected historical period. It cannot be called an untouched holdout or evidence of future performance. The old F1_STYLE6 model scores and frozen pair parameters are not to be refit or recalibrated for this selector. Existing model registry, operating model, database, and full source/model assets remain outside the review scope. Source artifacts are referenced by path and SHA-256 only.

Reviewer visibility disclosure: during a schema check, this reviewer loaded `baseline_runner_predictions.parquet` with the default full-column read and printed its first three rows. That exposed the first race's three `y`, `log_loss`, and `brier` values before the new selector choices were computed. Those values were not aggregated, used to choose the policy, or used to change any rule. This reviewer is not described as label-blind. The root's Q reconstruction and main selector were run without reading `y`; the selector artifact is separately hashed before the report stage opens labels. The audit distinguishes this limited reviewer exposure from the later independent recomputation of outcomes.
