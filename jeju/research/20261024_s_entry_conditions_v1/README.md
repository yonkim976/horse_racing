# S 출전조건 3변수 비교 — E43 보류, 기존 S40 유지

2026-10-24 완료. 기존 S40에 **현재 선언 부담중량, T−2 이전 마지막 유효 실제 부담중량 대비 변화, 출주번호 비율**만 추가했다. 전체 기간의 7승식 NLL·Brier 점추정은 모두 낮아졌지만, 사전 지정 삼쌍승 NLL 신뢰구간이 0을 포함하여 연구 채택 기준을 통과하지 못했다. 2026년에는 7승식 NLL·Brier 점추정이 모두 악화했다. **E43는 보류한다. S40 연구 비교 기준과 HY_R_FORM 운영 모델은 그대로다.**

실제 조사·구현·학습·평가는 현재 세션 GPT-6 Luna xhigh 서브에이전트가 수행했다. 메인은 조건 고정, 원천·시간·코드 검토, 해시 결합 실행 승인, 독립 검산과 최종 판단을 담당했다. F1_STYLE6는 원래 말 평가 연구 기준이며 S40 또는 운영 모델과 혼동하지 않는다.

## 동일 비교 조건

- 기존 S40의 40개 입력·저장 모델·OOS 원시 점수·연도별 온도·경주 명단·bootstrap 일정을 읽기 전용으로 재사용했다. S의 추가 fit/온도 최적화는 0회다.
- E43만 2024/2025/2026용 최종 모델 3개를 생성했다. 초기학습+refit 총 6회와 과거 보정기간 온도 3회가 전부이며 후보 추가·재탐색은 없었다.
- Y별 초기학습 2017..Y−3, 조기종료 Y−2, refit 2017..Y−2, 보정 Y−1, 평가 Y. seed 20261008, binary Top3 LightGBM, 출전마 가중치 1/N, 규제·학습률·범주 어휘·최대 800회/조기종료 25회 규칙을 S와 일치시켰다. 선택된 반복 수 자체는 같은 규칙에서 달라질 수 있다.
- supervised 5,206경주/52,155행, 평가 2024..2026-09-19 1,779경주/17,412두/269일. 연승만 개시두수 미확인 실제7두 36경주를 기존 계약대로 제외해 1,743경주다. 그 외 승식은 모두 1,779경주다.
- full-field sequential PL의 순서 있는 Top3 공동분포에서 7승식을 계산했다. 말별 입상확률을 곱하지 않았으며 전체 조합은 스트리밍 계산하고 저장하지 않았다.

## 승식별 확률 정확성

## 원천 정의와 한계

- 현재 부담중량은 `dacom01` 출전선언 kg다. 현재 경주의 사후 결과 부담중량으로 대체하지 않았다. 선언문서 날짜<=T−2 조건을 지켰으나 최초 공개/정정 시각은 미확인이다. **실제 구매 시점 가용성을 입증한 실험은 아니다.**
- 변화량은 현재 선언 부담 − 동일 공식 말 ID의 경주일<=T−2에서 가장 최근인 유효 실제 부담이다. 반드시 바로 직전 출발과 같다고 보장할 수 없어 `burden_change_vs_last_valid_kg`로 명명했다. 18개 특수코드 관측은 양의 실제 전체시간을 확인했고, 출발 여부가 불명확한 24개는 제외했다. 더 앞선 유효 관측으로 넘어간 15행은 표시했다.
- 출주번호는 `(번호−1)/(동일 선언 명단 최대번호−1)`로 넣었다. 취소 후 번호를 압축하지 않았으며 물리적 게이트와 같다고 주장하지 않는다. S의 결과 기반 정상완주 명단이라는 기존 제한도 남는다.
- 현재 부담/번호는 각각 51,917행, 차이는 49,988행이다. 별표 접두 정확 연결 135행만 원문 검증 후 보완했다. 이름 충돌 40행과 자료 상한 198행은 결측으로 유지했고 전체 분모를 보존했다. 결측을 0으로 바꾸지 않았다.
- 과거 실제 부담은 해시 고정 read-only SQLite payload를 재사용했다. DB에 기록된 원문 JSONL 12개는 현재 실물이 없어 당시 기록된 경로/해시와 DB payload를 보존했으며 직접 실물 재확인을 주장하지 않는다. DB 상한은 2026-09-12이며 이를 넘는 198행의 과거 이력 완전성을 주장하지 않는다.
- 평가기간은 이미 여러 연구에 사용된 개발기간이다. 신규 독립 검증, 시장 가격 대비 우위, ROI, 동시 7승식 우위의 증거는 없다. 당시 구매 전 가격이 없어 수익 비교를 하지 않았다.
- 이번 비교는 3개 변수 묶음의 효과만 보여준다. 각 변수의 기여나 부담중량의 인과효과를 분리해 밝힌 실험이 아니다.

- 감독관은 새 experiment 모듈을 import하거나 재학습하지 않고 6개 저장 모델의 73,314개 원시 점수를 정확히 재현했다. 온도 목적값/최적조건, 2,416,848개 순서 있는 Top3 확률, 24,834개 승식 점수, 34,824개 주변확률, 14,232개 조합선택 행, 896개 신뢰도 행, 2,000개 주 bootstrap을 검산했다. 확률 점수 최대 오차 1.78×10⁻¹⁵, 주 bootstrap 최대 오차 6.77×10⁻¹⁷이었다.

## 판단과 다음 연구 질문
