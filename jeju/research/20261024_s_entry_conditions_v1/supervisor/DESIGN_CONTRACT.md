# S 출전조건 3변수 단일 비교 — 감독관 사전 계약

2026-10-24. 후보 결과 확인 전 고정한다. 사용자 요청에 따라 실제 원천 조사·구현·학습·평가는 현재 세션 GPT-6 Luna xhigh가 수행하고 감독관은 지시·검토·독립 검산·판정을 수행한다.

## 범위와 소유권

- 기준선 S는 봉인된 `20261022_tb_state_transfer_v1`의 S40이다. 기존 저장 모델·OOS 점수·온도·명단을 읽기 전용 재사용한다.
- 후보 E는 같은 S40에 현재 부담중량, 직전 부담중량 대비 변화, 출주번호 비율의 정확히 3개 수치 입력을 추가한 S43이다. 다른 변수·목표·모델군·seed·후처리·앙상블·하위마 제외를 추가하지 않는다.
- audit/는 asset_audit, experiment/는 entry_experiment, review/는 독립 검토 담당, supervisor/와 최종 README/manifest는 메인 소유다. 기존 DB·원천·운영 등록부·모델·더러브렛·기존 연구는 수정하지 않는다. 외부 수집은 하지 않는다.

## 원천과 시간

- 현재 부담중량은 kg다. 원천이 과거 출전선언인지 사후 결과표인지 분리해 기록한다. 사후 결과표를 선언 자료로 명명하지 않는다. 실제 공개시각 미확인은 사전 가용성 가정으로 표시한다.
- 원천 조사에서 기존 H3의 dated dacom01 선언표를 확인했으므로 이번 실행의 현재 부담중량은 이 선언값만 사용한다. 누락은 NULL이며 현재 경주의 결과표 값으로 fallback하지 않는다. 문서 날짜 기반 가용성과 실제 최초 공개·정정 시각 입증은 구분한다. 후자는 미확인으로 `pre_race_availability_verified=false`다. 결과를 보고 원천/표본을 선택하지 않는다.
- H3의 135개 매칭 누락은 원문 마명이 정확히 `★` + 기존 과거 마명인 사례다. 동일 날짜/경주번호/마번/공식 말 ID와 과거 마명/거리/원문 줄을 확인한 이 경우만 새 입력에서 보완한다. 단일 접두 기호를 제거한 정확 일치만 허용하고 기호의 의미는 추정하지 않는다. 기존 H3 자료는 수정하지 않고 보완 원문·줄 해시·상태를 별도 기록한다. 다른 이름 충돌이 있는 2019년4경주40행과 선언표 없는 2026년후반21경주198행은 임의 연결/결과값 fallback 없이 결측 유지한다.
- 직전 값은 동일 공식 말 ID의 기록된 경주일 <= T−2일에서 가장 최근의 유효 부담중량이다. 유효의 정의와 미완주·취소 처리, 동률 이벤트 처리, 불명확한 값은 학습 전 원천 계약에 고정한다. 결측을 0kg 또는 능력 부족으로 해석하지 않는다.
- 직전 값은 과거 선언값이 아니라 실제 출전 결과 원천의 kg다. 정상1..89 및 특수91/92 중 raw rcTime>0와 normalized finish_time_ms>0로 실제 주행 관측이 확인된 행만 허용한다. 현재 원천의 특수코드18행은 양의 전체 시간으로 포함하고, 전체시간0인24행은 출발 여부 미확정으로 보류한다. 서로 다른 API/TXT의 상태 코드 의미를 전이하거나91을 실격으로 확정하지 않는다. 취소/철회/미출전은 제외한다. 따라서 마지막 유효 관측이 마지막 출발과 같다는 보장은 없다. 동결 과거 DB 상한은2026-09-12이며, 이를 넘는 T−2 구간의 완전성은 주장하지 않는다. 해당198행은 현재 선언값도 결측이므로 중량 변화 역시 결측이다.
- 출주번호 비율은 `(번호−1)/(해당 명단 최대 번호−1)`이다. 물리적 게이트로 해석하지 않는다. 취소로 번호가 건너뛰는 경우 압축 재번호하지 않는다. 당시 개시 명단이 미확인일 때 기존 S의 결과 기반 정상완주 명단이라는 제한을 유지한다.
- 분모의 명단은 S와 동일한 현재 평가/학습 대상 경주 명단이고, 그 안에서 원문으로 확인된 선언번호의 최대값을 쓴다. H3 개별 카드 선택/부담중량 누락으로 확인 가능한 최대번호까지 버려 번호 척도를 축소하지 않는다. 전체 선언표에서 같은 명단의 최대번호를 확인해 계보를 보존한다. 번호 또는 분모 미확인, 최대값<=1이면 결측이다. 원래 선언표 전체 명단과 차이, 일부 선언 누락 및 원문 확인 여부는 원천 감사에 기록한다. 이 구체화는 후보 학습·평가 전에 고정한다.
- 출전키 1:1 연결과 전체 경주 분모를 보존한다. 결측 때문에 유리한 경주만 제거하지 않는다. 계보·공개시각·라벨은 검증 열이며 학습에 들어가지 않는다.

## 동일 학습·보정·평가

- 기존 S supervised 5,206경주/52,155행과 연도별 분할을 유지한다. Y=2024,2025,2026: 초기학습 2017..Y−3, 조기종료 Y−2, 선택 반복으로 Y−2까지 refit, 보정 Y−1, 평가 Y. 초기학습 범주 어휘를 고정한다.
- 기존 S와 동일 binary Top3 LightGBM, 출전마 가중치 1/N, seed 20261008, learning_rate .04, num_leaves 15, min_data_in_leaf 100, lambda_l2 5, deterministic/force_col_wise, threads4, 최대800/early-stop25. 후보의 반복 수는 같은 선택 규칙으로 정하되 S와 숫자 자체를 강제 일치시키지 않는다.
- 후보만 초기+refit 6회, 최종 모델3개, Y−1 OOS PL 온도3개. S는 fit/온도최적화0회. 후보 탐색·추가 seed·평가 후 튜닝은 하지 않는다.
- 두 arm 모두 동일 full-field sequential Plackett–Luce Top3 공동분포와 승식 사건 계약을 사용한다. 온도는 [0.35,4]에서 보정기간 joint NLL로만 선택한다.
- 평가 2024..2026-09-19, 1,779경주/17,412두/269일. 연승은 개시두수 불명인 실제7두 36경주 제외 1,743경주. 나머지6승식은1,779경주. 이미 사용한 개발기간이며 신규 독립 검증기간이 아니다.

## 결과 전 판정

- 유일 주 비교 E−S: 삼쌍승(ordered Top3 joint) NLL의 paired date bootstrap95% 상한<0, 같은 Brier 차이<=0, 단승 NLL/Brier 차이<=0를 모두 만족해야 연구 후속 후보 기준 통과다. 단승 보호는 점추정 조건이며 통계적 비열등성 검정이 아니다.
- 고정2,000회 날짜 bootstrap schedule을 재사용한다. 전체/연도별7승식 NLL·Brier와 기존 고정구간 신뢰도표를 모두 보고한다. 유리한 승식만 선택해 성공을 선언하지 않는다.
- 동일 최대확률1장, 축Top3, 복승/복연승 상위3장 선택과 정확한 사건 합집합을 보조로 보고한다. 표수·규칙·분모를 바꾸지 않는다. 축/복승3장/복연3장 차이의 날짜95% 구간을 함께 보존한다.
- 시장 가격·수익은 이번 비교에 없다. 10% 적중 개선, 인과효과, 시장 우위, 새로운 기간 일반화는 별도 증거 없이는 주장하지 않는다. 운영 자동 교체는 없다.

## 검토·보존

- 학습 전 원천 감사, 코드 검토, 구조/합성 검사를 완료하고 감독관의 코드·입력 해시 결합 승인 후1회 실행한다. 감독관은 재학습 없이 입력의 원천계보, 저장 모델 점수, 온도 목적값/최적조건, 확률 합/주변확률/승식 점수와 주요 bootstrap을 독립 검산한다.
- 신규 연구 저장 예산40,000,000B, 세션 전체300,000,000B 이내. 원천/DB/feature/model 사본 금지. 얇은 입력·계보와 후보 모델·OOS 점수·선택 원장·핵심 집계만 저장한다. 전체 조합 확률은 경주별 계산하고 저장하지 않는다.
- 시작/종료 파일 크기·SHA·남은 디스크 공간·환경·fit 수를 기록한다. 기존 파일을 정리하지 않는다.
