# 학습 전 감독관 검토

2026-10-24. 후보의 점수·확률·성과를 확인하기 전에 검토했다. 이 문서는 연구 실행 검토이며 운영 승격 승인이 아니다.

- 연구 질문은 S40 + 현재 부담중량/직전 유효 실제 부담 대비 변화/출주번호 비율의 단일 E43 비교로 고정했다. 최종 모델 3개, 초기+refit 6회, 과거 보정기간 온도 3개만 허용한다. S는 재학습·재보정하지 않는다.
- 감독관 `verify_inputs.py`는 새 원천 생성 모듈을 import하지 않았다. 원문 449문서의 실제 SHA 및 51,917개 선언 줄, 별표 정확 연결 135개, 전체 번호 명단 5,181경주를 직접 검증했다. 독립 SQL과 pandas as-of 연결로 52,155행 모두의 최신 유효 과거 부담중량·출처 행·날짜·차이를 대조했다. 실제 DB 전체 SHA도 재검증했다. `INPUT_VERIFICATION.json` PASS다.
- 현재/번호 51,917행, 과거 실제 50,203행, 차이 49,988행이다. 이름 충돌 40행과 자료 상한 198행을 포함해 전체 52,155행/5,206경주를 그대로 유지한다. 결측을 0으로 바꾸지 않는다.
- 문서 날짜<=T−2는 가용성 가정이다. 실제 최초 공개/정정 시각은 입증되지 않았다. 과거 원문 JSONL 일부는 실물이 없어 pinned DB에 보존된 payload와 source metadata를 근거로 한다. 원문 파일을 직접 재해시했다고 주장하지 않는다. 특수 91/92 중 양의 전체 주행시간이 확인된 18개 관측만 포함하며 불명확 24개는 제외하고 앞선 유효값 fallback을 기록한다.
- 신규 입력에 실격·당일 결과·인기·배당·원천 계보가 학습 변수로 섞이지 않는 것을 확인했다. 현재 결과 기반 명단이라는 S의 기존 제한은 유지된다. 새로운 독립 평가기간이라는 주장은 하지 않는다.
- 학습·조기종료·refit·보정·평가 연도, 1/N 가중치, 범주 어휘, seed/규제/반복선택 규칙을 S와 같게 고정했다. OOS 원장의 year는 모델 vintage이며 보정 경주 연도는 별도 race_date로 구분한다.
- 순서 있는 Top3 공동분포를 모두 계산하고 7개 승식으로 집계한다. 평가 1,779경주/17,412두/269일, 연승만 개시두수 미확인 실제7두 36경주 제외한 1,743경주다. 선택 표수와 날짜 bootstrap 일정을 고정했다.
- 구조 preflight는 PASS이며 fit/후보 확률/성과/온도 최적화 모두 false다. 저장량 보수 추정 27,087,541B로 40,000,000B 예산 안이다.
- 입력의 `unconfirmed` 상태 표시는 값/문서ID/문서날짜/SHA가 NULL인 것과 일관된다. 이를 허용하도록 검증기만 수정했으며 입력 값과 계약은 바꾸지 않았다.
- 외부 PL 수학 엔진의 SHA `706b2e94a6b311e5bd9b3706da7df4f6a08117e917d22171fbde63a4d1a3210c`를 S parameters 기대값과 직접 대조했다. 이는 초기 봉인된 이전 연구 manifest와 `preservation.py`의 325개 보호파일에도 포함된다. 실행 승인 직전 및 독립 결과검산/완료 시 감독관이 재검증한다. 새로운 pipeline 내부 pin과 구분해 감독관이 시행하는 전후 무결성 검사로 기록한다.

최종 승인 JSON은 이 검토, 독립 입력검산, 서브에이전트 검토, preflight, 코드/입력/기존 엔진의 해시를 결합한다. E 성과를 보고 후보·변수·규제·명단·구매 규칙을 변경하지 않는다.
