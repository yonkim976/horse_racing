# 모델 예측축과 단승 최저표시배당마 비교 계획

## 질문과 비교 대상

동일한 동결 주행별 예측 모집단에서 F1_STYLE6의 score 1위 말이 공식 Top3에 든 비율과, API4 최종 원문 `winOdds`가 가장 낮은 말의 공식 Top3 비율을 비교한다. 주 비교는 전체 출전마의 승식 가격이 모두 유효하고 표시 최저 단승배당이 유일한 경주다. 동률 최저 경주는 별도 집계하고, 최소 마번을 대표로 선택한 전체 모집단 민감도를 함께 둔다. 표시배당 동률은 반올림으로 발생할 수 있어 확정 공동인기 1위로 부르지 않는다.

## 고정 범위와 원천

- 주 평가기간·거리: 2024~2026-09-19, 900·1000·1110·1200m; 기존 evaluation lock의 1,503경주·14,714마 행 키를 유지한다.
- 메인 모델: frozen F1_STYLE6 baseline runner predictions. 보조 모델: 이미 저장된 F1_STYLE6_DISTANCE_SECTION_RELATIVE10 candidate predictions. 두 모델은 같은 eligible race key에서 별도로 비교한다.
- Top3 label은 고정 prediction parquet의 `y`를 사용한다. 예측축은 경주별 score 내림차순, 동점은 낮은 마번 우선이다. 같은 말 비교는 축 1위와 favorite 선택 말의 horse ID·마번이 같은 경우로 정의한다.
- 단승배당은 읽기 전용 제주 DB의 API4 `race_result_rows`→`api_records.payload_json.winOdds` 원문 값이다. 출전마 전체 가격을 검증하며 당첨마 가격만으로 favorite를 정하지 않는다. 원문 값 누락·0·비양수·비수치·9999.9가 하나라도 있으면 경주 전체를 가격 불완전으로 분리하고 대체값을 넣지 않는다.
- 주 비교는 표시 최저배당이 정확히 한 말인 경주다. 동일 최저가 여러 말인 경주는 별도 결과표에서 최저가 전체 집합과 축 1위 포함 여부를 보고한다. 비교 가능한 단일 favorite가 아닌 만큼 메인 집계에 섞지 않는다.

## 산출 항목과 제한

전체 및 연도·거리별 축/단승 favorite Top3 실제율, 모델 Top3 확률 평균, 선택 동일률과 동일 선택 말의 Top3율, 다른 선택 경주의 축/favorite 각 적중 교차 4분할을 보고한다. `selected_rows.csv`에 경주별 선택 horse ID·마번·착순·전체 field odds 검증·각 선택 말의 모델 확률·동점 상태를 보존한다. 실제 Top3 비율과 평균 모델 확률을 분리한다.

최종 표시 배당의 사전 공개시각은 확인되지 않았으므로 후향 기술 비교다. 단승배당 역수는 우승 확률의 단순한 대체값으로 해석하지 않으며, Top3 정확도나 모델 개선·실제 구매 시점의 전략 성능을 뜻하지 않는다. 결과를 본 뒤 임계값 선택, 모델 재학습·재예측, DB 쓰기, 외부 자료 수집은 하지 않는다.
