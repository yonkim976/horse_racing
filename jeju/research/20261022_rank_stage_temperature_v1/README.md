# 제주 공동 착순 분포 개선 검토 — 단계별 보정 후보 보류

2026-10-22. **같은 F1_STYLE6 말 평가를 보존한 채 착순 단계마다 보정 강도를 달리하면 삼쌍승 확률 손실이 줄어드는 신호를 확인했다. 그러나 미리 정한 단승 보호 조건을 통과하지 못해 후보는 보류한다.** 2024–2026 자료는 이미 여러 번 사용한 개발 자료다. 이번 결과는 새 기간의 일반화나 시장 우위를 입증하지 않는다.

조사·구현·적합·평가는 현재 세션의 GPT-6 Luna xhigh 서브에이전트가 맡았다. 감독관은 원천·시간·수식·코드를 검토하고 승인된 한 번의 실험을 독립 계산으로 재검증했다. 파일 소유권은 `audit/`, `design_review/`, `experiment/`, `supervisor/`로 나눴다. 운영 모델 HY_R_FORM, 연구 말 평가 F1_STYLE6, 10/20 보류 축 선택기를 구분하며 운영 등록부를 변경하지 않았다.

## 실제로 만든 것과 재사용한 것

기존 [공동 승식 기준선](../20261022_joint_wager_baseline_v1/README.md)의 F1_STYLE6 원점수, feature table, 라벨·승식 계약, 공통 temperature, 날짜 bootstrap 일정과 참조 손실을 경로·SHA-256으로 재사용했다. 말 평가를 재학습하지 않았고 같은 해 정답으로 맞춘 기존 provider tau를 입력에 적용하지 않았다. 원천·모델·DB 사본을 만들지 않았다.

새로 만든 것은 세 단계 temperature를 사용하는 공동분포 구현, 후보 손실·말별 주변확률·확률구간 집계·선택 원장, 방법 감사와 독립 검산이다. 전체 순열을 파일로 펼치지 않고 경주별 계산 후 필요한 결과만 보존했다. [방법 비교 감사](audit/README.md)는 기존 집합 보존 순서 모형·관계항·direct pair 실험의 중복과 한계를 구분한다. [방법론 원문 확인](audit/method_sources.md)의 고전 순차 선택 모형은 구조 근거이며, 단계별 temperature의 제주 성능을 입증하는 자료는 아니다.

## 결과 전에 고정한 단일 비교

말 점수 `s`와 전체 출전집합 `R`에 대해 다음을 계산한다.

`Q(i,j,k) = softmax_R(s/T1)[i] × softmax_(R−i)(s/T2)[j] × softmax_(R−i−j)(s/T3)[k]`

각 단계는 앞서 선택한 말을 제외한 **전체 남은 출전마**를 분모로 삼는다. 사전에 고른 Top3 집합 안에서 세 개 온도를 맞추는 방법과 다르다. 모든 7승식 확률은 이 Q에서 합산한다. 부분 조합을 전체 분포로 간주하거나 별도로 재정규화하지 않는다.

| 항목 | 사전 고정 조건 |
|---|---|
| 주 비교 기준 COMMON | 기존 공통 T=1.1837152381349905, 다시 적합하지 않음 |
| 단승 보호 기준 RAW | 세 단계 T=1인 원점수 PL |
| 새 후보 | T1·T2·T3 전역 3개, 각 [0.35, 4.0], 추가 규제·후보 탐색 없음 |
| 보정 적합 | 2019–2023 OOS 원점수 2,492경주·25,278출전, 단계별 관측 경로 NLL 최소화 |
| 평가 | 2024-01-05–2026-09-19, 1,779경주·17,412출전·269일 |
| 연승 분모 | 개시두수 분기가 불명확한 실제 7두 36경주를 별도 원장으로 유지, 평가 1,743경주 |
| 선택 진단 | 각 승식 최고확률 1조합; p≥pmax−1e−12 중 마번 사전순; 모든 비교군에 동일 적용 |
| 게이트 | TRI NLL 차이 날짜 bootstrap 95% 상한<0, TRI Brier 차이≤0, WIN NLL·Brier가 각각 RAW보다 나쁘지 않음 |

T−2 날짜 경계와 공개시각 미확정 상태는 기존 계약을 승계한다. 연승의 실제 8두 이상 경주는 발매 개시 후 추가 출전이 없다는 전제에서 Top3 분기를 사용한다. 과거 경주별 발매 개시두수·실제 승식 제공·정산의 전수 확인을 완료한 자료는 아니다. 동착·취소·미완주 등 기존 제외·보류 계약도 그대로다. 이 조건은 [기존 승식 계약](../20261022_joint_wager_baseline_v1/rules_contract/README.md)과 [기존 경주 원장](../20261022_joint_wager_baseline_v1/experiment/outputs/race_contract_ledger.parquet)에서 추적한다.

전체 계획과 실행 전 근거는 [감독관 설계](supervisor/DESIGN_DECISION.md), [실험 계획](experiment/PLAN.md), [코드 검토](supervisor/CODE_REVIEW.md), [해시 기반 실행 승인](supervisor/RANK_STAGE_EXECUTION_APPROVAL.json)에 있다. 실제 적합은 scalar optimizer 3회로 한 후보를 구성했고 평가 실행은 한 번이다.

## 동일 조건의 결과

적합값은 **T1=0.9648521157, T2=1.2410594885, T3=1.5195802928**이다. 세 값 모두 내부 최적점이며, 보정 표본의 단계별 목적값·역온도 미분·볼록성을 독립 확인했다. 이는 평가 성능 보장과 다르다.

아래 차이는 모두 **후보−COMMON**이며 작을수록 좋다. 단승·복승·쌍승·삼복승·삼쌍승은 경주 균등 categorical Log loss와 sum-Brier, 연승·복연승은 경주 안 티켓별 binary 손실 평균 후 경주 균등 평균이다. 서로 다른 승식의 손실 크기는 직접 비교하지 않는다.

## 개선이 발생한 부분과 아직 부족한 부분

같은 공동분포에는 `TRI NLL = TLA NLL + 상위 3두 집합이 주어졌을 때 순서 NLL`이 성립한다. 독립 확인한 평가 평균을 이 식으로 분해하면 집합 NLL 차이는 **+0.000727839**, 조건부 순서 NLL 차이는 **−0.010862536**이다. 따라서 이번 삼쌍승 개선은 집합 확률의 개선을 뜻하지 않는다. 이 분해는 관측된 정답 집합에 대한 진단이며, 예측 때 정답 집합을 입력했다는 의미가 아니다.

순차 경로로 분해한 첫 단계, 둘째 단계, 셋째 단계의 NLL 차이는 각각 −0.002684570, +0.000240890, −0.007691016이다. 둘째·셋째 수치는 실제 앞선 착순에 조건부인 경로 손실이며 정확한 2착·3착 주변확률의 손실과 다르다. 계산식과 원값은 [감독관 판단 기록](supervisor/DECISION.json)에 보존했다.

확률구간별 적중률은 사전 고정 16개 구간을 모두 저장했다. 후보 단승 50–75% 구간은 69티켓에서 평균 예측 57.80%, 실제 44.93%이고, 후보 삼쌍승 2.5–5% 구간은 394티켓에서 평균 예측 3.10%, 실제 1.78%다. 이는 남은 보정 문제를 보여주는 기술적 진단이며, 같은 경주 티켓 간 의존과 작은 고확률 표본 때문에 이 구간만 골라 새 보정값을 맞추지 않았다. 모든 112개 구간 행과 빈 구간을 포함한 [후보 reliability 집계](experiment/outputs/candidate_reliability_bins.parquet), [기존 기준선 집계](../20261022_joint_wager_baseline_v1/experiment/outputs/reliability_bins.parquet)를 함께 보존한다. 집계 가중은 ticket-event이며 주 지표의 경주 균등 가중과 구분한다.

동일 수치 동점 규칙으로 다시 계산한 최고확률 1조합은 후보·COMMON·RAW 사이 **7승식 모두 변경 0건**이다. 적중 수는 단승 487/1779, 연승 998/1743, 복승 203/1779, 쌍승 118/1779, 복연승 429/1779, 삼복승 107/1779, 삼쌍승 26/1779로 같다. 확률 손실 개선과 선택 적중률 개선을 구분한다. 이전 실험의 정확 부동소수점 argmax 선택 수와 섞지 않으며, 이번 [선택 원장](experiment/outputs/selection_ledger.parquet)의 동일 규칙 비교를 따른다. 이 선택 진단에는 배당이나 구매 예산을 넣지 않았으므로 구매 전략의 수익 검증이 아니다.

## 다음 개선 방향의 우선순위

1. **단승 확률을 고정하고 2·3착 조건부 분포만 개선한다.** 우선 가설은 첫 단계 T1=1을 고정하고 후속 단계만 과거 OOS 자료에서 보정하는 것이다. 이렇게 하면 RAW 단승 확률의 보존은 구조적으로 확인할 수 있다. 삼쌍승·다른 승식의 개선 여부는 별도 검증해야 한다. 이번 실패를 본 뒤 세운 후속 가설이므로 이번 연구에서 T1만 바꿔 재채점하거나 성공으로 재분류하지 않았다.
2. **집합 확률과 집합 내 순서의 손실을 따로 통제한다.** 기존 10/17 집합 보존 순서 모형을 재사용할 수 있지만 이미 수행한 연구이고 운영 HY_R_FORM 대비 우위는 확인되지 않았다. 전체 Q에서 유도한 7승식 비교와 집합 손실 보호 조건을 사전에 고정해야 한다. 집합을 보존한다고 단승까지 보존되는 것은 아니므로 첫 번째 방법과 혼동하지 않는다.
3. **후속 설계 선택을 과거 시간순 구간 안에서 끝낸다.** 과거 OOS 점수에서 보정·모형 선택 시점을 분리한 rolling 검증을 먼저 고정하고, 2024–2026의 반복 개발 자료로 성공을 선언하지 않는다. 최종 일반화 판단에는 아직 사용하지 않은 이후 기간이 필요하다. 구매 전 동일 시점 가격이 확보되지 않은 현재 자료로 시장 우위나 실제 기대수익을 주장할 수 없다.

말 평가와 조합 구조를 동시에 바꾸거나 이미 실패한 축 선택기·direct pair·관계항을 다시 채택하는 방향은 이번 우선 후보로 두지 않았다. 새 피처를 포함하는 큰 모델 변경은 별도 원천·공개시각 감사와 비교 조건을 먼저 갖춰야 한다. 위 세 항목은 다음 연구 순서이며 추가 실험의 성과가 아니다.

## 검산·재현·저장

감독관의 [독립 검산](supervisor/RESULT_REVIEW.json)은 실험 모듈을 가져오지 않은 수식 구현으로 3,625,272개 착순 삼중항을 재계산했다. 후보 손실 12,417행, 말별 확률 17,412행, 선택 원장 37,251행, 참조 손실 24,834행, 확률구간·연도별 요약·bootstrap·최적점 미분이 일치했다. 공통 T로의 환원, 확률 합, 주변확률 일관성, 점수 이동 불변성과 3착 보정이 앞 두 단계 주변확률을 바꾸지 않는 성질도 확인했다. 계산 검산 PASS와 채택 게이트 실패는 별개다.

저장된 결과를 변경하지 않는 재현 명령은 프로젝트 루트에서 다음과 같다.

```sh
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python jeju/research/20261022_rank_stage_temperature_v1/supervisor/verify_results.py --check-only
```

봉인된 실험 폴더에서 `--source-preflight`나 적합을 다시 실행하지 않는다. 후속 후보는 새 연구 폴더에서 계획·승인을 별도로 남긴다. 코드·실행 환경·입력 해시는 [실험 보고 JSON](experiment/outputs/report.json), [적합 영수증](experiment/outputs/fit_receipt.json), [원천 검토](supervisor/SOURCE_REVIEW.json)에 있다. 문서·구현·산출물의 최종 파일별 SHA-256과 정확한 저장량·남은 디스크 공간은 [최종 manifest](FINAL_MANIFEST.json)에 기록한다.

신규 연구 폴더는 약 3 MB이며, 큰 파일은 선택 원장 1,376,935 bytes, 후보 말별 주변확률 820,574 bytes, 경주 손실 481,811 bytes다. 신규 목표 20 MB 및 앞선 연구와 합산 300 MB 한도 안이다. 기존 자료를 복사하지 않았고 DB·원천·모델·운영 등록부를 이 작업에서 수정하지 않았다.
