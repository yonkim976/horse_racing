# 기존 번호 연구의 내·중·외측 대조 요약

2026-10-08. 사용자의 거리별 게이트/내외측 유불리 질문에 답하기 위한 사후 설명 분석이다. 기존 연구를 덮어쓰거나 보정률·운영 판단을 변경하지 않는다.

- 대상은 기존 연구가 추정한1000·1110m, 정확10두/마번1~10의 완전 정상결과 경주. 주 기간2019~2025, 최근2024~2025 민감도. 2026은 원 연구의 계수 학습 밖이라 이 요약에 추가하지 않는다.
- 출발번호순 내측1~3, 중간4~7, 외측8~10을 결과 계산 전에 고정한다. 실제 물리 게이트 대응이나 경주 중 주행위치의 확인은 아니다.
- 기존10번호 회귀의 계수와 공분산으로 묶음별 번호 평균, 내−중/외−중/외−내를 계산한다. 번호별 임의 선택 없음. 묶음 회귀를 새로 최적화하지 않는다. 기존 모형을 재계산해2019~2025의 번호별 추정치가 저장표와 일치하는지 검사한다.
- 과거 동일거리 기록·경력·간격·나이·중량·성별 및 경주 고정효과 통제는 기존 gatefit 그대로. 시간(초)과 Top3 선형확률(%p)은 별개다.
- 날짜 cluster95%구간을 주 보고, 반복말 cluster 구간을 민감도로 보존. 각 기간에서 두거리×세대조×두정답12개 대비의 BH q를 사후 탐색으로 보고한다. 표본 선택/미측정 능력에 따른 관찰 연관성이며 인과효과·입상 예측 개선으로 부르지 않는다.
- 기존 감사 source_rows.csv/history_ids.json 및 번호표/코드/계약 해시를 남긴다. DB는 재조회/변경하지 않고 기존 추출본만 사용한다. 모든 출력은 이 새 폴더에 독점 생성한다.
