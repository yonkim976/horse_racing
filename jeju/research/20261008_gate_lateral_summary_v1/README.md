# 제주 거리별 출발번호 내·중·외측 유불리 요약

2026-10-08. 기존 연구의 번호별 결과를 묶어 설명한 사후 탐색 분석이다. **Top3 관찰 연관성은1000·1110m 모두 내측>외측 방향이며, 시간 차이는 불확실하다.** 기존 기록보정 보류 판단과 운영모델은 변경하지 않는다.

대상은 정확10두·마번1~10·정상 완전순위인 경주다. 내측1~3, 중간4~7, 외측8~10으로 결과 계산 전에 정의했다. 실제 물리 게이트 대응이나 경주 중 레일/주행위치를 확인한 것은 아니다. 기존10번호 회귀에서 그룹별 번호 효과를 동일비중 평균했다. 과거 동일거리 기록·나이·중량·성별·관측경력·간격과 경주 고정효과를 통제했다. 다른거리·다른두수는 이 표로 판단하지 않는다.

## 주 기간2019~2025

Top3의 중간 번호 대비 차이, 단위 %p. 절대입상확률이 아니라 번호효과의 조정 추정치다.

| 거리 | 경주 / 경주일 | 내측1~3 | 중간4~7 | 외측8~10 | 내측−외측 및 점별95%구간 |
| --- | --- | --- | --- | --- | --- |
| 1000m | 920 / 508 | +2.82 | 0.00 | +0.18 | +2.64 [ +0.17, +5.11 ] |
| 1110m | 574 / 375 | +1.83 | 0.00 | −2.80 | +4.63 [ +1.39, +7.87 ] |

1000m에서는 내측이 높은 방향이며 중간·외측은 서로 비슷하다.1110m에서는 내측>중간>외측 순의 점추정이지만 내−중과 중−외는 각각 불확실하다. 두 거리 모두 개별 번호를 최고의 번호로 확정한 순위표가 아니다.

전체시간의 외측−내측 차이는1000m +0.058초(95% −0.024~+0.140),1110m +0.029초(−0.065~+0.122)다. 양수는 외측이 느린 방향이며 둘 다0을 포함한다. Top3 %p를 이 시간 차이로 환산하지 않는다.

## 불확실성과 적용 판단

날짜 cluster 점별95%구간을 제시했다. 각 기간 두거리×세대조×시간/Top3의12개 비교에 BH를 적용하면 내측−외측 Top3의 q는 주 기간1000m0.143/1110m0.061, 최근 기간은 각각0.054/0.054다. 이 탐색 다중비교 기준q<0.05를 통과한 대조는 없다. 여러 결과 중 유리한 대비만 골라 확정 우위라고 표시하지 않는다. 반복말 cluster 구간도 `lateral_contrasts.csv`에 보존했다.

**관찰상 내측 번호의 입상 우세 후보는 있으나, 초 단위 기록 보정이나 실제 예측 확률에 고정 가산할 근거는 아직 부족하다.** 이 그룹 요약은 예측 입력 추가의 미래 성능을 검사하지 않았다. 기존 연구의 번호 초 성분도 사전 시간 예측 진단을 통과하지 못해 적용하지 않았다. 원천은 사후 정상완주 선택 모집단이며 미측정 능력·번호 배정·출전 선택의 영향이 남는다.

900·1200·800m와 희소 장거리의 조정 유불리는 이번 연구에서 미추정이다.1000/1110 계수로 채우지 않는다. 실제 주행 내외측 효과는 별도 질문이며 이번 출발번호 결과와 독립적으로 더하지 않는다.
