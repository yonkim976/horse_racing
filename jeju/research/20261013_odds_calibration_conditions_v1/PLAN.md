# 최종 QPL 배당 구간별 보정 및 오차 조건 사후 진단 계획

## 질문과 해석

고정된 선택쌍과 저장 확률의 사후 보정 상태를 최종 QPL 표시배당 및 예측 전에 확보된 고정 경주·말 이력 조건별로 기술한다. 사전 배당 자료가 없으므로 최종배당은 사후 조건이다. 이 결과는 실행 가능한 사전 전략, 인과 효과, 수익성 또는 배당에 따른 확률 감점 규칙의 근거가 아니다. 현재 말평가와 선택된 pair 정책은 고정한다.

## 표본과 고정 입력

- 연구 대상은 기존 반복 평가 기간의 2025년 654경주와 2026년 부분연도 488경주, 총 1,142경주다. 2026년 상한은 2026-09-19다. 2024년은 QPL 가격 자료가 없어 제외한다.
- 주 분석은 `selected_jockey_id_candidate == 1`과 `jockey_id_candidate_calibrated_probability`; 보조 비교는 `selected_jockey_basic_candidate == 1`과 `candidate_calibrated_probability`다. 선택쌍 선택 규칙은 재계산하지 않는다.
- 최종 가격·환급·적중·공식 출처는 독립 원문검증 PASS를 받은 `20261013_postrace_ev_exploration_v1/race_rows.csv`를 그대로 연결한다. 조건 분석은 유효 최종 가격 행만 대상으로 하며, 제외 사유와 유효 표본 수를 보존한다.
- 평가 사건은 선택한 두 말이 함께 Top3에 든 QPL pair event다. QNL 확률이나 말별 Top3 확률을 대입하지 않는다.
- 말별 F1_STYLE6 점수 순위는 2025·2026 평가 점수를 공식 `api_record_id`로 말 이력 표에 연결해 산출한다. `horse_number`는 경주 안의 마번 연결키이고 `horse_id`는 말 개체 ID이며 서로 대체하지 않는다. `finish_position`은 실제 결과 진단에만 사용한다.
- 역사 특성은 고정 `features.parquet`의 예측시점 `history_cutoff`를 따른다. 거리·등급·출전두수·선택 두 말의 경력 및 휴식·전개 이력은 이미 관측된 평가 행에서만 가져온다. 말평가 점수, 모델, calibration 또는 pair 선택은 수정하지 않는다.
- 입력 고정 SHA-256은 예측 pair `0d41ee66149edfae79f2b422ba588c422686a328aad0122071183ee9db6768d6`, 기존 검증 race rows `4fc2e924dcf4f987c22962977d42dd83a786bebc2f70606bc565bd97d2869198`, frozen feature `036939bd6d518a9e53d458a2f4eb2bf30bfecfa4bb80e21c78edd1f7f44f028f`, 2025 점수 `45247f00f286197067957d25ee46e0594f2ef0d26089c6b6081592272651eb12`, 2026 점수 `0ccae2475fc1ea87ddf62b054572961ab32fed26b332070907853ebbd412989a`, 날짜 schedule `d141b0c3f9a463cbfc9d1f4c61228b58757c31aee4ec74b79f41c5baeadaccbd`다. 상위 원문 출처·페이지 검증의 hash chain은 기존 `SOURCE_HASHES.json`과 `ROOT_REVIEW.json`으로 연결한다.

## 고정 구간과 지표

- 최종배당 구간은 `[1,2)`, `[2,3)`, `[3,5)`, `[5,10)`, `[10,∞)`로 고정한다. 하한 포함·상한 제외이며 관측 가격 범위, 결측·비양수·9999.9 제외 건수를 확인한다.
- 확률 구간 교차표는 `[0,.15)`, `[.15,.20)`, `[.20,.30)`, `[.30,.40)`, `[.40,1]`로 고정한다. 마지막 구간만 1을 포함한다.
- 각 선택기·전체/2025/2026 기간 및 최종배당 구간마다 `n`, 적중 수, 평균 확률, 경험 적중률, 보정 차이 `100 × (평균확률 − 적중률)` %p, O/E `적중 수 / 확률 합`, Brier, log loss를 기록한다. Log loss는 계산 시 확률을 `[1e-15, 1−1e-15]`로 clip한다. 과대평가는 양수 gap, 과소평가는 음수 gap이다.
- 날짜 불확실성은 전체 평가 parquet의 ISO 정렬 269개 경주일에 대한 고정 2,000×269 재표집 schedule을 그대로 사용한다. 연도·조건 마스크를 고정 schedule에 적용하고, 해당 반복에서 유효 분모가 0이면 제외해 반복 수를 기록한다. Gap의 percentile 95% CI를 제공한다. 교차 세부표에는 CI를 만들지 않는다.

## 사전 고정 오차 조건 가족 8개

각 조건은 선택된 말 중 요약값 하나로 정하고 현재 확률·결과를 사용해 경계나 그룹을 조정하지 않는다.

1. 경주 거리: 실제 `distance_m` 값 그대로 사용하고 각 거리의 지원 수와 소표본 표시를 함께 제공한다.
2. 원래 등급 범주: `grade_raw` 값을 합치거나 순서형 숫자로 바꾸지 않는다.
3. 출전 두수: `<=8`, `9`, `10`, `>=11`. 이는 평가 원천의 정상완주 완전 편성 출전두수이며, 예측 당시 편성 공개 시각은 복구되지 않았으므로 실전 가용 조건으로 확정하지 않는다.
4. 선택 두 말의 최소 `observed_starts`: `0`, `1–2`, `3–9`, `10+`.
5. 선택 두 말의 최소 `same_valid_times`: `0`, `1–2`, `3+`.
6. 선택 두 말 중 최대 `days_since_start`: `<=14`, `15–35`, `36–60`, `61+`; 어느 한 말이라도 값이 없으면 `unknown`.
7. 두 F1_STYLE6 점수 차이 절댓값: `[0,.5)`, `[.5,1)`, `[1,∞)`; 이는 원 F1_STYLE6 모델 출력 점수 단위이며 초나 확률로 해석하지 않는다.
8. 과거 초반 위치 중복: 두 말의 `hist_s1f_relpos_mean5`가 모두 관측되고 모두 `<=.33`이면 `both_low`; 둘 다 관측됐으나 조건을 충족하지 않으면 `observed_other`; 어느 한쪽이라도 결측이면 `missing`. 이는 선행 전개가 확정됐다는 뜻이 아니다.

점수상 약한 말의 경주 내 순위와 두 말의 착순은 context와 pair 실패 진단에만 남긴다. 특정 조건의 결과를 성공 원인 또는 예측오류의 단독 원인으로 단정하지 않는다.

## 결과 해석 및 반복개발 제한

- 조건별 전체 보정 차이와 같은 조건 내부의 최종배당층별 잔차를 나란히 보존해, 조건 차이가 배당 구성과 함께 움직이는지 살핀다.
- 개별 미적중은 확률 오류의 증거로 확정하지 않는다. 두 선택마 모두 Top3, 하나만 Top3, 둘 다 미입상의 세 결과를 실제 착순 진단으로 제공한다.
- 기존 사후 EV 그룹 `posthoc_score >= 0` (기존 주 분석 326경주), `p >= .30 AND posthoc_score >= .10` (52경주), `.20` (39경주)은 이미 살펴본 집단이다. 동일 그룹을 보조 진단으로 보존하며 독립 검증으로 부르지 않는다.
- 전체·연도 방향, 표본 수, 날짜 bootstrap 구간, 소표본을 분리한다. 여러 고정 조건을 함께 살피는 탐색이며 유의성 선택·인과 설명을 하지 않는다.
- 경계와 조건은 이번 진단 결과를 산출하기 전 코드·계획에서 고정한다. 이는 새 평가기간에 대한 사전등록이나 독립 검증을 뜻하지 않는다.
- 입력은 로컬의 읽기 전용 파일만 사용한다. 새 네트워크/수집·학습·재보정·재예측·DB 조회 또는 쓰기는 하지 않으며 이 새 연구 폴더 안에만 산출물을 저장한다.
