# 거리별 구간 상대기록 원천 번들

이 폴더는 900·1000·1110·1200m의 최근 5회 동일거리 실제 출전 이력에 대해, 구간 기록과 과거 기준 잔차를 재현할 원천 자료를 고정한다. 자료 동결만 수행했으며 모델 학습·점수 계산은 하지 않았다. 파일별 행 수와 SHA-256은 [source_audit.json](source_audit.json)과 [artifact_manifest.json](artifact_manifest.json)에 기록했다. 이 README는 동결 manifest 이후 추가한 설명 파일이며, 별도 SHA-256은 작업 회신에 보고한다.

입력 모집단은 저장된 F1_STYLE6 52,155행 전체다. 거리 대상 38,193행을 별도 추출했지만 전체 원본 특징 파일도 그대로 보존했다. 저장된 `last5_same_distance_start` 연결을 그대로 따라 135,855개 슬롯을 만들었고, T−2까지의 이력 시점과 무효 기록을 유지했다. 슬롯을 다시 고르거나 더 오래된 이력으로 빈자리를 채우지 않았다. 이 원천 자료는 기존 1000m 평균+n 실험 결과를 다시 평가하거나 그 실패 원인을 설명하지 않는다.

구간 초는 품질 선택된 누적 시각의 차이로 계산했다. 3C·4C는 누적 통과 시각이며, G1F는 마지막 200m 구간시간이므로 G1F 통과시각은 `T − G1F`다. 구간 산식은 S1F, C3−S1F, C4−C3, T−G1F−C4, G1F다. 거리별 명목 길이는 사용자 승인 가정으로 [nominal_segment_contract.csv](nominal_segment_contract.csv)에 저장했다. 1110m의 S1F는 210m, 1610m는 이번 대상에 포함되지 않는다. 명목 길이는 구간 평균속도를 나눠볼 때만 사용할 수 있으며 실제 주로 궤적이나 순간 속도를 뜻하지 않는다. 원시 초 값은 길이에 맞춰 보정하지 않았다.

각 슬롯·구간의 기준은 해당 경주의 거리와 같은 과거 적격 경주별 구간 중앙값을 한 경주당 같은 가중치로 평균한 값이다. 기준 경주일은 이력 경주일에서 이틀을 뺀 날짜까지 포함하며, 최소 20개의 서로 다른 과거 경주가 있어야 기준이 성립한다. 상대기록은 `과거 기준 − 실제 구간 초`라서 양수면 기준보다 빠르다. 기준 모집단은 2002-07-06~2026-09-19의 동결 원천 스냅샷에서 제주 2경주·해당 거리의 실제 출전마이며, 해당 경주 안에서 품질 게이트를 통과한 출주마들의 중앙값을 썼다. 따라서 상대기록은 같은 거리·구간의 역사적 기준 비교이며, 같은 경주 안에서 다른 말보다 앞섰는지를 나타내는 상대순위와 별개다.

구간 기록에는 선택된 API4 시간값이 양수이고 허용 상태(`api_positive_unreviewed`, `website_corrected`)이며 누적 차이가 유한 양수여야 한다. 또한 `valid_time`과 상속된 전체 경주 지점 품질 게이트를 적용했다. 전체 지점 게이트는 현재 DB의 실제 출전마 명단을 분모로 사용해 API4 순서 ID·말 ID·마번의 완전 일치, API303 경주 내 선택 일관성, 지점 레코드와 품질 뷰의 상태·출처 일치를 확인하며 누락·보류·미해결 상태는 차단한다. API6 리더 구간기록은 사용하지 않았다.

동결 스냅샷에는 과거 7개 경주에서 실제 출전마 일부만 들어 있다. 현재 DB와 대조한 결과 현재 DB 전용 출전마 54행에는 품질 뷰 원천이 없다. 이 54행은 전체 경주 지점 게이트 분모에 남겨 두고, 기록 대체값으로 메우지 않았다. 따라서 해당 7개 경주의 네 지점 마스크는 모두 실패하며 그 경주에 속한 냉동 기준 출전마도 구간 적격 기록과 경주 중앙값을 만들지 않는다. 기준 모집단의 나머지 행과 대상·이력 행은 그대로 유지했다. 알려진 제외마 3005648은 저장된 F1 모집단과 동결 기준 모집단에 이미 없으며 추가 제외 조건은 적용하지 않았다.

주요 파일은 `target_f1_style6_features.parquet`(전체 특징), `target_distance_roster.parquet`와 `target_last5_lineage.parquet`(대상·정확한 이력 연결), `benchmark_reference_roster.parquet`, `api4_quality_source_snapshot.parquet`, `source_race_point_quality_masks.parquet`, `reference_section_intervals.parquet`, `reference_race_segment_medians.parquet`, `source_event_benchmark_stats.parquet`, `target_last5_relative_history.parquet`다. `candidate_race_roster_reconciliation.parquet`, `mask_only_current_db_rows.parquet`, 지점별 순서·그룹 증거 파일과 `source_fingerprint_before_after.parquet`는 포함 범위와 품질 판단을 추적하기 위한 자료다. SQLite는 `mode=ro`와 `query_only`로 열었고, 전체 DB 파일 해시를 변경 불변의 증거로 주장하지 않았다. 지정된 논리 행 지문은 읽기 전후 일치했다.
