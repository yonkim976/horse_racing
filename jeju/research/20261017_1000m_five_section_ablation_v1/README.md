# 제주 1000m 다섯 구간시간 ablation

**결론: 다섯 구간의 최근 평균과 관측 수 10개를 더한 후보는 사전 기준을 통과하지 못했습니다. 현재 저장된 `F1_STYLE6` 30열 기준선을 유지하고, 후보를 운영에 적용하지 않습니다.** 1000m 주 평가에서 말별 Top3 log loss와 Brier가 모두 조금 나빠졌고, 보조 지표도 서로 엇갈렸습니다. 결과는 이 피처 묶음과 평가 코호트에 대한 후향 비교이며, 구간 정보 전반이 쓸모없다는 뜻은 아닙니다.

## 비교 설계

비교 대상은 저장된 30열 `F1_STYLE6`와 그 저장 모델·점수, 그리고 동일한 30열에 아래 평균/n 입력 10개만 더한 40열 후보입니다. 후보의 학습 코호트는 기존 전체 거리 52,155출전·5,206경주와 같게 유지했습니다. 1000m 대상에서만 새 값이 계산되고, 다른 거리는 10개 입력이 모두 NULL입니다. 저장 기준선은 재학습하지 않고 세 저장 모델을 다시 불러와 17,412출전·1,779경주 점수를 재현했습니다.

각 대상 출전의 예측 입력은 경주일 T−2일까지의 기존 F1 동일거리 최근 최대 5회 실제 출전만 사용합니다. 유효 슬롯 값의 산술평균과 유효 개수(0–5)를 구간별로 만들었습니다. 무효 슬롯은 남겨 두고 더 오래된 출전으로 채우지 않았습니다. 1000m 대상에서 유효 슬롯이 없으면 평균 NULL/n=0이고, 비1000m 대상은 평균과 n 모두 NULL입니다.

| 입력 구간 | 초 단위 계산 |
|---|---|
| 0–200m | `S1F` |
| 200–약400m | `C3 − S1F` |
| 약400–약600m | `C4 − C3` |
| 약600–800m | `finish_time − G1F − C4` |
| 800–1000m | `G1F` |

각 구간에는 최근 유효 기록 평균과 관측 수가 각각 하나씩 있습니다. 공식 경마장 설명에서 S1F는 200m, C3와 C4는 결승선 약 600m 전·약 400m 전, G1F는 마지막 200m 지점으로 안내됩니다. 따라서 C3/C4가 들어간 구간의 거리는 근사 표기이며, 정확한 센서 위치라고 해석하지 않습니다. [KRA 경주기록 용어 설명](https://race.kra.co.kr/raceScore/scoretableLayerExplanation.do?meet=2)

구간별 끝점 시간 상태와 경주 내 전체 출전마의 point-status 검사를 적용하고, 해당 과거 F1 슬롯의 `valid_time=True`를 요구했습니다. 다섯 분할의 합은 원천 finish time과 일치합니다. G3F는 `finish − C3 − G3F` 별도 일관성 진단으로만 사용했으며 모델 입력에는 넣지 않았습니다.

모델은 기존 F1_STYLE6 설정·범주 처리·Top3 보정 절차를 사용했습니다. 평가연도별로 학습, 조기종료, 보정, 테스트 경계를 기존과 동일하게 적용해 후보 3개를 학습했습니다(총 LightGBM 학습 호출 6회, 온도 보정 최적화 3회). 결과를 본 뒤 추가 학습이나 피처 튜닝은 하지 않았습니다.

## 1000m 주 평가 결과

주 평가 코호트는 2024–2026년 508경주·5,013출전입니다(2026년은 9월 19일까지). 주지표는 말별 Top3 이진 log loss와 Brier를 경주 안에서 평균한 뒤 경주별 동일 가중치로 평균합니다. 차이는 후보 − 저장 기준선이며 음수가 개선입니다. 신뢰구간은 미리 고정된 2,000회×269경주일 paired bootstrap을 사용했습니다.

| 지표 | 저장 F1_STYLE6 | 40열 후보 | 차이 (95% 경주일 CI) |
|---|---:|---:|---:|
| 말별 Top3 binary log loss | 0.563635 | 0.564610 | +0.000974 `[−0.000043, +0.001969]` |
| 말별 Top3 Brier | 0.190325 | 0.190717 | +0.000391 `[−0.000028, +0.000816]` |
| 예측 1순위 마의 3위 이내 입상 | 294/508 (57.87%) | 285/508 (56.10%) | −9경주 |
| 실제 입상마 평균 포착 수 / 3 (상위 5두 안) | 69.03% | 69.09% | +0.07%p |
| 실제 입상마 3두 모두 상위 5두 안 | 155/508 (30.51%) | 152/508 (29.92%) | −3경주 |
| 최대 6개 예측 조합에 실제 입상 3두 포함 | 116/508 | 111/508 | −5경주 |
| 실제 입상 3두 집합 NLL (전체 3두 집합 분포, 보조) | 4.293008 | 4.301935 | +0.008927 `[+0.000164, +0.017799]` |

사전 유지 기준은 두 주지표 점추정치가 모두 개선되고, 적어도 하나의 paired 95% 구간 상한이 0 미만인 경우였습니다. 두 점추정치 모두 기준선보다 높아 기준을 통과하지 못했습니다. 주지표 CI는 0을 포함하므로 이 비교만으로 통계적으로 확정된 악화라고 결론내리지 않습니다. 상위 5두 포착률은 상위 5두 안에 실제 입상마 3두 중 평균 몇 두가 포함됐는지를 3으로 나눈 값입니다. 소폭 올랐지만, 다른 적중 지표와 주지표의 하락을 상쇄하지 않습니다.

전체 1,779경주 보조 집계에서도 후보의 log loss는 0.568159→0.568789, Brier는 0.192256→0.192497로 높아졌습니다. 이는 1000m 밖의 성능 확대를 주장하는 자료가 아니라 기존 전체 거리 코호트에 같은 피처 열을 추가했을 때의 보조 결과입니다.

## 구간 데이터 지원량

과거 슬롯의 품질 조건을 통과해 실제 feature 값으로 사용된 행은 총 53,828개 저장 슬롯 중 구간별 아래와 같습니다. 대상 출전 수는 14,457입니다.

| 구간 | 유효 과거 슬롯 | 유효 과거 기록이 1개 이상인 대상 | 5개 모두 유효한 대상 |
|---|---:|---:|---:|
| 0–200m | 53,743 | 13,060 | 8,628 |
| 200–약400m | 53,743 | 13,060 | 8,628 |
| 약400–약600m | 53,781 | 13,057 | 8,668 |
| 약600–800m | 53,745 | 13,056 | 8,638 |
| 800–1000m | 53,779 | 13,059 | 8,657 |

모든 14,457개 1000m 대상의 구간별 평균, n, cutoff, 과거 출전 ID와 날짜는 [상세 profile parquet](outputs/all_1000m_profiles.parquet)에 있습니다. 예를 들어 2026-09-19 제주 3경주 9번 독차지(target API ID 186332)는 T−2 cutoff인 9월 17일까지 과거 동일거리 출전 3회(IDs 181856/181391/191618, 2025-08-16/2025-09-06/2026-01-09)를 사용했습니다. 해당 다섯 구간 평균은 순서대로 17.633/17.367/16.800/16.267/17.567초이며 각 n=3입니다. 이 예시는 결과에 따른 선택이 아니라 독립 검증자가 고정한 사례입니다. [사전 고정된 20개 예시](outputs/profile_examples.csv)는 interval과 지원량 구간(n=0, n=1, n=2–4, n=5)마다 평가일·경주·마번 키 순으로 처음 나오는 행을 선택했으며, 결과를 보고 골라내지 않았습니다. 슬롯별 원천 시간·상태·분할 계산·유효성 사유는 [계산 원장](outputs/historical_section_slot_ledger.parquet)에서 확인할 수 있습니다.

## 범위와 한계

이 결과는 과거 실제 출전으로 검증한 후향 ablation입니다. 원천 데이터는 대상 경주일보다 이른 날짜(T−2)의 기록을 확인하지만 API 값 또는 나중의 웹사이트 수정사항이 실제 예측 시점에 언제 공개됐는지는 증명하지 않습니다. 따라서 이 연구는 실시간 당시 가용성 기준의 전향 검증이 아닙니다. 2026년은 부분연도이고, 비교는 2024–2026의 선택된 경주들에 한정됩니다. 10개 열을 한 묶음으로 시험했으므로 개별 구간의 독립 효과를 분리하지 않았습니다.

학습·평가 코드는 한 번만 실행했고 기준선은 재학습하지 않았습니다. 데이터베이스·운영 모델·등록부를 변경하지 않았으며, 기존 착순 모델이나 pair 모델의 학습·적용도 변경하지 않았습니다. 독립 검토자는 두 모델의 전체 17,412 평가출전, 1,779경주, canonical 최대 6개 조합 10,674행과 14,457개 profile을 대조했습니다. 보고 검토 결과는 [ROOT_REPORT_REVIEW.json](../20261017_1000m_five_section_rootreview_v1/ROOT_REPORT_REVIEW.json)에서 확인할 수 있습니다.
