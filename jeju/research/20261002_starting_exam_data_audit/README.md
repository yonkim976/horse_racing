# 제주 출발심사 API21 데이터 감사

**수치 시점:** 아래 전수 감사 본문은 작은곰 삭제 전 스냅샷이다. 이후 사용자 지시에 따라 작은곰을 삭제했으며 현재 활성 후보는 **10,664행·4,636두**, 기승자 미제공은 **5,795행**이다. 삭제 및 현행 검증은 [삭제 보고서](../../maintenance/small_bear_removal_20261002/README.md)를 따른다.

기준일: 2026-10-02. 수집 대상은 **한국마사회 출발심사 결과 API21**이며, 출발조교 API22 및 주행심사 API20과 구분한다. 원천은 `../20261001_starting_exam_api_collection/`의 성공 완료한 연도별 응답이다. 이번 작업은 검증이며 DB 적재·원문 수정·삭제·모델 입력 추가를 하지 않았다.

## 검증 범위와 결과

API21의 제주 경마장 전체 응답 2000~2026년, 27개 연도·37페이지·25,614행을 검사했다. 원문에서 관측된 날짜는 2000-01-07~2026-09-30이다. 성공 원문에 기록된 SHA-256, 행 수, 연도 및 경마장 구분을 root가 다시 확인했다. 날짜 달력 해석 25,614행과 후보의 원문 위치·전체 payload 10,666행이 모두 일치했다. 전체 내용 동일 중복행 및 날짜·회차·말 ID 중복 키는 각각 0개다. 실패·중단된 과거 attempt는 성공 수집 행 수에 포함하지 않았다. 수집 기간의 페이지 완전성 검증은 공식 원천에 모든 역사적 사건이 존재한다는 보장은 아니다.

제주마 후보는 **10,666행·4,637두**다. 공식 말 ID로 현재 API42 프로필의 `breed='제주마'`를 확인한 범위다. `meet=2`나 ID 접두·말 이름은 품종 확정 근거로 사용하지 않았다. 나머지 14,948행·10,769개 ID는 품종 미확정 상태로 이 후보에서 제외했다. API21의 `name='한국'`은 품종 필드가 아니다. 현재 품종 확인과 과거 심사일의 품종 근거는 구분한다.

Root 전수 재계산은 [root_source_verification.json](root_source_verification.json), 프로필·의미 비교는 [root_verification.json](root_verification.json), 예외 원문 위치는 [exceptions.json](exceptions.json)에 기록했다. GPT-6 Luna xhigh가 작성한 전수 감사 코드를 root가 검토·수정·실행한 결과는 [integrity/summary.json](integrity/summary.json)에 보존했다. 서브 감사에서도 원문 페이지 37개 해시·byte 수, 헤더·페이지 번호·총건수와 후보 JSONL 전체 재구성이 통과했다. 감사기의 선언 경로는 각각의 기준 디렉터리에서 해석한 실제 경로로 비교하며, 기승자명을 ID로 취급하지 않는다.

## 이름·나이·성별 해석

- 말 ID 연결 후보의 마명은 10,666행 모두 현재 API42 마명과 일치했다. ID 3107458은 보유 경주 원문의 동방라오와 API21의 무명전설이 연결된다. API21 마명을 당시의 변경 불가능한 역사적 이름으로 단정하지 않는다. 분석 표시명은 사용자 지정 최신 이름 정책을 따른다.
- API21 나이는 10,666행 모두 **심사일 기준 생일을 지난 횟수(만나이)**와 일치했다. `심사연도−현재 프로필 출생연도`보다 1 낮은 2,757행은 심사일이 생일 전인 것으로 설명된다. 이는 이 데이터의 관측 결과이며 모든 KRA 자료의 공식 마령 규칙을 확정하는 설명은 아니다. 홈페이지와 API의 나이는 일부 다르므로 원문 나이를 서로 덮어쓰지 않는다. 분석용 나이는 계속 **2026−최신 API42 출생연도**를 사용한다.
- 성별은 1,307행·622두에서 과거 `수`와 현재 `거`가 다르다. 거세에 따른 변화와 양립하지만 개별 거세일을 검증한 것은 아니다. 과거 성별과 현재 프로필 성별을 따로 유지한다.
- **토종등극(3005897)**은 2002-11-15 1회 API21 성별이 `수`, 현재 API42는 `암`이다. 기존 경주·주행심사 감사의 알려진 충돌에 추가 근거로 기록했다. 사용자의 현행 기록 유지 결정에 따라 자동 수정하지 않았다.

높은 원문 나이도 별도로 검사했다. 검토 기준을 `API21 age >=16`으로 잡아 17~31세의 11행·9두를 추출했다. 이 기준은 공식 연령 상한이 아니다. 과거 홈페이지 11페이지를 조회해 9행·8두가 같은 높은 연령을 표시하는 것을 확인했다(그중 생일 전 2행은 홈페이지가 API보다 1 높음). 작은곰(3005648)의 2002-07-05·12 31세 두 행은 요청한 홈페이지에 해당 말 행이 없어 대조하지 못했다. API42 출생일은 1971-04-01이며 보유 API20 주행심사 두 행도 31세다. 여러 원천의 일치는 원천 생년월일 자체의 정확성을 보장하지 않으므로 고령 관측을 검토 표시로 남긴다. 다른 8두는 은빛천사·검문도·한국돌풍·샛별요정·행복두배·제주의별·여왕국·왕비상자다. [추가 대조 및 DB 맥락](extreme_age_crosscheck/context_report.json)에 말 ID·생년월일·홈페이지 원문·보유 경주 및 주행심사 연결을 기록했다. 현재 현역 여부나 생존을 추론하지 않았다.

## 적재 및 분석 시 적용할 기준

같은 말·날짜가 2개 회차에 있는 제주마 관측은 **779그룹·1,558행**이다. 모두 서로 다른 `trainNo`이며 같은 날짜·말 ID만으로 유일화하면 기록이 사라진다. 2026-09-30 타이산(3107923)은 2회 `1차합격`, 3회 `불합격`; 수사대(3017464)와 사상최강(3018494)은 2회 `1차합격`, 4회 `합격`이다. 보유 공식 홈페이지 원문에서도 이 6행이 확인됐다. 다른 날짜에 동일한 다두 편성이 통째로 반복된 후보는 발견되지 않았다. 단독 1두 편성 반복을 원천 오류로 간주하지 않는다.

공식 Swagger의 `daySerial`은 **심사차수**, `trainNo`는 **경주번호**, `chulNo`는 **마번(출주번호)**다. `daySerial`은 2017-04-30과 2017-05-03에 38이 관측되어 연도 안의 날짜 고유키로 사용할 수 없다. 번호 의미를 임의로 보정하지 않는다. `rider`는 기승자 문자열이며 ID 필드가 아니다.

원문 보존 시 예외 행도 삭제하지 않는다. 판정 미제공 4행은 원천 결측 상태로 보존하고 합불 분석에서 제외한다. 취소·제외·검사취소 등 판정은 각각 원래 라벨로 남기며, `1차합격` 651행을 최종 합격으로 자동 통합하지 않는다. `reason`은 심사 신청사유이며 `nopassReason`의 결측을 채우는 값이 아니다. 기승자·순번 결측을 0이나 다른 필드로 채우지 않는다.

제주 DB의 SHA-256은 기존 값 `fbc21f5229aa654ea3442141c3f3e7044f41bf7069c8f77e6f3c9f0af562f0b3`와 일치했다. 이번 감사는 DB 적재 승인 또는 전체 자료의 무결점 판정을 뜻하지 않는다. 원문 구조와 연결은 통과했고 위의 결측·출처 충돌을 보존해야 한다. 예측용 공개시각 및 당일 가용성 검증은 별도이며, 이번 감사로 모델 입력을 채택하지 않았다.

## 2026-10-02 사용자 확인 및 적재 지침

- 기승자 미제공 5,797행은 `rider` 키가 없는 행이다. 명시적 JSON null·빈 문자열·`-`는 각각 0행이며 나머지 4,869행에는 기승자 값이 있다. 조회 시 결측은 NULL로 표현하고 미기승으로 해석하지 않는다.
- 사용자의 외부마 표기 유지 지시에 따라 천아오름 해당 행의 조교사 표시명은 **외부마**로 적재한다. 원문 `trName='외부마'`와 `trNo='0BBBBB'`는 그대로 보존하고 정규 조교사 ID 연결은 NULL로 둔다. 이 표기는 조교사 칸의 원문 값이며, 말의 제주마 품종·말 ID·마명을 바꾸거나 해당 심사 행을 제외하는 지시가 아니다.
- 작은곰(3005648)은 최초 사용자 확인 대기였다가, 후속 삭제 지시에 따라 **로컬 DB와 활성 후보에서 삭제 완료**로 변경됐다. 프로필 1행·주행심사 2행·출발심사 후보 2행 및 관련 DB 근거를 삭제했다. 현재 입력과 재수집 후보에서 제외하며, 과거 감사·원문은 이력으로 보존한다.

외부마 지침은 후속 2026-10-02 출발심사 DB 적재에 적용 완료했다. `외부마`·`0BBBBB` 원문은 보존하고 정규 조교사 ID는 NULL이다. 최초 지침 반영은 문서와 사용자 결정 기록에 한정했고, 이후 사용자 승인으로 적재했다. [적재·검증 보고서](../20261002_starting_exam_db_load/README.md)를 따른다.

## 기승자 누락 기간 재확인

GPT-6 Luna xhigh 조사와 root 재계산에서 누락이 날짜 구간으로 분리됨을 확인했다. 2021-10-24까지의 후보는 원문에 `rider` 키가 없고, 최초 값 제공 관측일인 2021-10-27부터 2026-09-30까지는 기승자 미제공 예외가 0행이다. 원문 2021-10-24 동백미인(3019049)은 해당 키가 없고, 같은 연도 응답의 2021-10-27 삼관우승(3018985)은 `김홍권(소속기수)`가 있다. 따라서 후보 생성 파서가 값을 버린 현상이 아니다. 홈페이지에 값이 있는 과거 심사 사례도 있으므로 미기승을 의미하지 않는다.

공식 Swagger는 현재 `rider`를 기승자로 설명하지만 이전 기간 미제공 사유 또는 필드 변경 시점을 입증하는 이력은 확인하지 못했다. 2021-10-27을 공식 API 개편일로 확정하지 않는다. 삭제 후 최신 기간별 수치는 [rider_absence_periods_20261002.json](rider_absence_periods_20261002.json)에 있다.

2026-10-02 사용자는 기승자 미제공 사실을 문서에 남기고 다음 단계로 넘어가도록 지시했다. 현행 후보의 미제공 5,795행은 **API 원천 미제공 / NULL**로 적재하며, 기승자가 없었던 사건으로 해석하지 않는다. 이 단계의 추가 기승자 수집이나 추정 보정은 진행하지 않는다.

후속 단계인 **출발심사 API21 제주 DB 적재를 2026-10-02 완료**했다. 추가 21두 프로필을 먼저 반영하고 10,664행·4,636두를 공식 말 ID와 원문 위치로 연결했다. 기승자 미제공 5,795행은 NULL이며, 판정 미제공·취소·제외·1차합격과 같은 날 다른 회차를 유지했다. 분석 상한 2026-09-19까지의 조회는 10,620행이다. 원문·프로필·건수·기존 모든 행 불변·FK·SQLite 무결성·재실행 추가 0행이 통과했다. [적재·검증 보고서](../20261002_starting_exam_db_load/README.md)에 현행 테이블·입력 계약·증거를 기록했다. 위의 최초 감사 본문은 당시 스냅샷으로 유지한다.
