# 제주 pair Top3 복연승(QPL) 등액 실현수익

고정 예측 파일의 아홉 선택 방식 각각에서 경주당 한 조합에 10,000원을 매수했다고 두고, 실현 환급과 손익을 계산했다. 배당이 검증된 2025년 654경주와 2026-09-19까지의 488경주, 총 1,142경주를 모든 방식에 같은 분모로 적용했다. 2024년 637경주는 검증된 QPL 원천이 없어 제외했다.

| 선택 방식 | 적중/경주 | 적중률 | 적중 시 평균 QPL | 총환급 | ROI |
|---|---:|---:|---:|---:|---:|
| 현재 기수 ID 후보 | 283/1,142 | 24.78% | 2.743배 | 7,764,000원 | -32.01% |
| 직전 기수 기본 후보 | 276/1,142 | 24.17% | 2.743배 | 7,572,000원 | -33.70% |
| 확장 후보 | 274/1,142 | 23.99% | 2.895배 | 7,932,000원 | -30.54% |
| 이전 직접 쌍 | 272/1,142 | 23.82% | 2.877배 | 7,826,000원 | -31.47% |
| 원점수 Top2 | 274/1,142 | 23.99% | 2.794배 | 7,656,000원 | -32.96% |
| 저장 F1 Top2 | 274/1,142 | 23.99% | 2.794배 | 7,656,000원 | -32.96% |
| 공동 주변확률 Top2 | 280/1,142 | 24.52% | 2.820배 | 7,895,000원 | -30.87% |
| 후보 공동 최대쌍 | 277/1,142 | 24.26% | 2.821배 | 7,815,000원 | -31.57% |
| 매칭 공동 최대쌍 | 274/1,142 | 23.99% | 2.794배 | 7,656,000원 | -32.96% |

각 방식의 총투입은 11,420,000원이다. 환급은 적중한 조합의 최종 QPL 배당에만 계산했고 미적중 조합의 QPL 표시는 지급액으로 세지 않았다. ROI는 `(총환급−총투입)/총투입`이다. 2026년은 부분연도이며 이 후향 등액 계산은 미래 수익을 보장하거나 새 베팅 정책을 제안하지 않는다.

현재 선택은 직전 기본 방식보다 적중이 7회 많고 환급이 192,000원 더 컸다. 확장 후보와는 선택이 다른 86경주에서 현재 환급이 168,000원 적었고, 공동 주변확률 Top2와는 105경주에서 131,000원 적었다. 확장 후보와 다른 대표 경주인 **2025-07-25 제주 1R**에서 현재 3-6은 2.3배, 확장 후보 2-6은 31.5배를 받았다. 31.5배는 DB QPL 값과 공식 API301 원문이 일치하며, 원문 페이지 SHA-256은 `2efdbfeb927b2e29c8f70dcf58d1bcb46ff6a0bbcbe70387815c7fb654d5ace3`이다. 선택 변경 경주의 손익 차이와 최대 기여 경주 3건은 `comparison_diagnostics.csv`에 있다.

`race_returns.csv`는 경주·방식별 선택쌍, 공식 Top3 적중, DB QPL 인용배당, 실제 지급배당, 환급·손익 및 적중 QPL 원문 페이지 해시를 담는다. `summary.csv`는 전체·2025·2026 부분연도별 수치다. `SOURCE_HASHES.json`에는 고정 입력·감사 자료·관련 DB 추출·생성 CSV의 해시를 기록했다.

계산은 `.venv/bin/python -B jeju/research/20261013_pair_qpl_roi_v1/analyze.py`로 재현한다. 기존 API301 감사 코드의 고정 SHA를 확인한 뒤 읽기 전용 원문 helper를 호출한다. SQLite는 `mode=ro`와 `query_only`로 열었고, 예측 라벨은 공식 착순과, 모든 적중 QPL은 API301 원문과 DB 배당 간 전수 대조했다. 네트워크 요청·DB 쓰기·학습은 없었다.

Luna xhigh 분석 후 감독 독립 검산은 아홉 방식의 10,278개 경주별 선택·환급과 27개 전체/연도별 집계를 모두 재계산해 일치함을 확인했다. 당첨 배당의 원문 197페이지도 별도 JSON 파싱·해시 검증을 수행했다. [독립 검산 코드](verify.py), [검토 결과](ROOT_REVIEW.json), [원문 페이지 경로·ID·해시](SOURCE_PAGE_INDEX.json)에 보존했다. 위 비교는 연구용 F1_STYLE6 기반 저장 방식들 사이의 비교이며 운영 HY_R_FORM과의 비교는 아니다. 공식 배당을 그대로 적용한 단순 환급 계산으로 구매에 따른 시장 배당 변화는 가정하지 않았다.
