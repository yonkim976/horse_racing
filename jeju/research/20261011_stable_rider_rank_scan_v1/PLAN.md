# 전체 마방 착순 상승 사례 확인

2026-10-11 사용자 질문: 앞서 제시한 두 마방 외에도 기수 교체 뒤 순위 상승 사례가 있는가?

기존 착순 변화 연구의 불변 전체표 3,119행을 재사용한다. 2026년 교체 20건 이상인 모든 조합을 빠짐없이 제시하고, 2024~2025년에도 20건 이상인 조합의 평균 상승 방향을 비교한다. 두 기간 원시·10두 환산 평균 모두 양수이면 기술적 반복 후보로 표시한다. 인과·유의성·승부 의도 확정 규칙은 아니다. 20건은 설명용 소표본 필터이며 검정력 보장이 아니다. 기존 두 마방(이준호·이태용) 밖의 조합도 별도 제공한다.

선택 표본·거리·원천·입력 계약·구간 방법은 앞선 연구를 상속한다. 현재/이전 공식 API ID 연결은 앞선 전수 검증을 참조하고, 이번에는 전체 3,119행의 건수·평균·상승/동일/하락과 공식 ID/표시명 연결을 기존 43,024쌍에서 다시 확인한다. 새로 전체를 훑고 높은 수치를 설명하는 사후 탐색이며 다중검정 보정에 따른 우세 확정은 하지 않는다. 기존 연구·기수/각질 재개 대기 상태·DB·운영은 보존한다.
