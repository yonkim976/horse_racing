**2026-10-01 후속 확인:** 사용자가 남은 7경주 전부의 취소를 확인했다. 현재 취소 여부 미확정은 0경주이며, 7경주·30행은 **취소 확인·사유 미표시**로 반영했다. 갱신된 판정과 추가로 알려준 2004년 5월 취소 범위는 [사용자 확인 반영 기록](../20261001_user_cancellation_confirmation/README.md)과 [새 76경주 원장](../20261001_user_cancellation_confirmation/confirmed_76_review.jsonl)을 참조한다. 아래 내용과 기존 원장은 2026-09-30 조사 당시의 근거·판정을 보존한다.

기준일: 2026-09-30. 아래 분류는 **삭제 전** 제주 전용 core DB의 `jeju_race_population_candidates`에 있던 전원 완주시간 0인 162경주·1,535행과, 완주시간은 양수이나 말별 통과착순과 API303 경주 자료가 없는 2026-07-07 4경주·40행을 감사한 결과다. 경주일·경주번호를 기준으로 경주를 중복 없이 집계했다. 결과 API4_3, 코너 API303, 심판리포트 API215의 보존 원문을 대조했다. 이상 행은 [API4_3 보존 응답](../20260929_core_collection_inventory/raw/2026/attempts/20260929T132618.518555Z/source_pages/page_0001.json) 자체에 들어 있으므로 로컬 파서가 생성한 오류는 아니다. 해당 원문 파일의 SHA-256은 `8f60ee195eff36cb2f4bd0620fd4db0e30ac2b17618c0b7bbfc1b144a2eb4006`이다.

**후속 처리:** 사용자 요청으로 7월 7일 4경주·40행과 8월 25~26일 15경주·142행을 `race_result_rows`에서 삭제했다. 현재 후보는 9,494경주·92,513행이며, 전원 0초인 후보는 147경주·1,393행이다. [삭제 기록과 검증 결과](../../maintenance/zero_time_cleanup_20260930/README.md)를 참조한다. 아래 표의 162경주 수치는 삭제 전 원인 조사 모집단을 뜻한다.

## 2026-07-07 4경주의 원인

2026-07-07 제주 1~4R의 40행은 2026-04-11 제주 1~4R의 `(경주번호, 마번, 말 ID, 착순, 완주시간)`과 **40행 모두 일치**한다. 양쪽 API4_3 원문을 행별로 비교하면 7월 7일 행에서는 `rcDate`, 요일, 통과순위·구간시간, 배당률, 일부 조교사·마주 등이 달라진다. 따라서 원문 전체가 동일한 단순 복사본은 아니지만, 4월 11일의 결과·출전집합이 다른 날짜에 재노출된 것은 명백하다. 4월 11일 1~4R은 API303 기록이 있고, 7월 7일 1~4R에는 없다. [2026년 제주 경마 시행계획](https://race.kra.co.kr/down/raceplan2026_jeju.pdf)에도 화요일인 7월 7일 시행은 없다.

따라서 7월 7일의 양수 완주시간을 별개의 실경주 성적으로 계산하면 4월 11일 성적을 중복 집계하게 된다. 통과착순이 전부 0인 것은 이 재노출 자료에 구간값이 채워지지 않은 양상으로 설명된다. API4_3 제공 시스템 안에서 왜 이 날짜와 값이 생성됐는지는 원문만으로 확인할 수 없다.

2026-09-30에 한국마사회 [제주 경주성적표](https://race.kra.co.kr/raceScore/ScoretableScoreList.do?Act=10&Sub=1&meet=2)의 [기간별 검색](https://race.kra.co.kr/raceScore/scoretablePeriodSearch.do)에서 대상 49일을 조회했다. 76경주 중 명시적 취소 사유가 있는 69경주의 내역은 **짙은 안개 64경주·605행, 태풍 나리 2경주·17행, 주로 상태 불량 1경주·8행, 출발불성립 1경주·10행, 출발대 고장 1경주·10행**이다. 원문 문구의 공백·표기 차이는 판정표와 원장에 그대로 보존했다. 화면의 날짜 조건은 URL에 남지 않으므로 요청 필드, 응답 HTML, 경주 상세 제목과 SHA-256을 함께 기록했다.

종전에 확인한 2015~2017년 및 2021년 14경주는 13경주·126행이 안개, 2016-04-16 3R 1경주·10행이 출발대 고장이다. `dacom11` 제목을 다시 추출해 14경주 모두 대상 경주가 빠져 있고 뒤 경주 결과는 있는 것도 확인했다. 이 11개 날짜의 보존 파일은 KRA `race.kra.co.kr/dbdata/fileDownLoad.do` 다운로드 기록이 HTTP 200이며, 파일 SHA-256이 수집 이력과 일치한다. 2021-01-22 1R의 [당일 성적표](../../../data/raw/kra_text/dacom11/meet=2/year=2021/month=01/day=22/20210122dacom11.rpt)와 체중표는 2R부터 시작한다.

이번에 추가 확인한 2005~2008년 19경주 중 17경주는 안개, 2007-09-16 제주 3R·5R은 태풍 나리다. 2009~2014년 36경주는 안개 34경주, 2012-10-27 8R 주로 상태 불량, 2014-05-09 6R 출발불성립이다. **2002-07-06 3R, 2002-08-31 1R, 2002-12-07 1R, 2003-02-23 7R, 2004-06-20 6R, 2004-06-26 4R, 2004-07-04 7R은 사유 미확정**이다. 이 7경주의 공식 상세 칸은 비어 있다. 공식 TXT 중 2004-06-20은 1·3·4·5·7R만, 2004-06-26은 2·3·5·7·8·9R만 결과 제목이 있어 각각 6R과 4R의 결과가 빠졌다. 반면 2002~2003년 4일의 TXT는 5바이트 개행뿐이고 2004-07-04 TXT는 0바이트다. 특히 2004-07-04 화면 응답은 1~9R 모두 사유가 없는 빨간 상세 표시를 보여 주므로, 그 표시 자체를 취소 증거로 해석하지 않았다.

76경주 전체의 API4_3 착순 원문에는 `ord=99`가 있다. 그중 2010-02-26 6R과 2010-03-06 6R은 한 마리씩 `ord=95`도 있다. API303은 63경주에서 코너값이 `-` 또는 `X`, 구간시간이 `0:00.0`인 자리표시자이고 13경주는 행이 없다. 이 패턴과 날씨 필드만으로 안개·기상악화 등 정확한 사유를 붙이지 않았다. API215는 2002~2016년 제주 연도 조회가 0행이고, 보존된 2017년·2021년 응답에는 대상 날짜의 심판사항이 없다.

[경주별상세성적표 API227](https://www.data.go.kr/data/15089492/openapi.do)도 확인했으나 현재 서비스 키의 해당 서비스 조회가 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`(HTTP 403)로 거절되어 교차 조회하지 못했다. 공식 제공 필드 설명에도 별도의 취소 사유 항목은 제시되지 않는다. 공식 상세가 공백인 7경주의 정확한 사유를 추정하지 않으며, 그중 TXT까지 빈 5경주의 취소 여부도 단정하지 않는다. 원문 0값을 임의로 보정하지 않는다.

## 데이터 처리 상태와 남은 확인

재노출된 19경주·182행은 후보 DB 결과층에서 삭제했다. 기존에 취소·불성립이 확인된 71경주·713행에 홈페이지에서 사유를 추가 확인한 69경주·650행을 더하면, 현재 전원 0초 후보 중 **사유 확인 140경주·1,363행**, **사유 미확정 7경주·30행**이다. 미확정 7경주 중 2경주는 공식 TXT의 결과 누락을 확인했고 5경주는 취소 여부도 미확정이다. 모두 유효한 완주 성적으로 쓰지 않는다. 원문 0값을 다른 날짜의 결과로 채워 넣지 않는다. API 제공 시스템이 이전 날짜의 기록을 재노출한 내부 원인은 확인되지 않았다.

API 원문 경로는 [API303 연결 감사](../20260929_api_detail_sources/API303_CORNER_RANK_INTEGRATION_2026-09-30.md), [API215 보존본 인벤토리](../20260929_api_detail_sources/README.md)에 있다. API215의 공식 명칭은 [한국마사회_심판리포트정보](https://www.data.go.kr/data/15063980/openapi.do)이며, 경주일·경주번호·`judgement`를 제공한다.
