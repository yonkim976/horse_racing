# 제주 조교 기승자 미분류: 기간 분포와 홈페이지 보완 재확인

후속 실제 적용: 사용자 승인 후 [최근 6개월 홈페이지 전수 대조·DB 반영](../20261017_training_rider_website_completion/README.md)을 완료했다. 19,885행을 주로조교로 보완했고 전체 미분류는 281,483행이다. 아래는 적용 전 조사 기록이며 당시의 후보·미적용 표시는 보존한다.

조사일: 2026-10-17 KST. 대상은 제주 전용 `jeju/data/jeju_native_core.sqlite3`의 **일별조교 기승자 종류**다. 출발조교·출발심사와 합산하지 않았다. DB는 읽기 전용으로 조회했고 분류값을 변경하지 않았다.

현재 자료는 2007-10-01~2026-10-15의 912,913행이다. 미분류는 **301,368행(33.01%)**이다. 이전 10월 15일 보고서의 298,875행은 갱신 전 수치다. 집계 단위는 조교 원행이며 인원 수나 실제 시행 횟수가 아니다.

## 어디에 몰렸나

| 기간 | 전체 기록 | 미분류 | 기간 내 미분류 비율 | 전체 미분류의 비중 |
|---|---:|---:|---:|---:|
| 2007~2012 | 108,940 | 108,657 | 99.74% | 36.05% |
| 2013~2021 | 414,392 | 5,643 | 1.36% | 1.87% |
| 2022~2026-10-15 | 389,581 | 187,068 | 48.02% | 62.07% |

2026년만 보면 66,900행 중 34,256행(51.20%)이다. 2017년 이후에도 667,332행 중 191,160행(28.65%)이 미분류이므로 초기 자료에만 있는 문제가 아니다.

미분류의 API18 원문 `prGubun_raw`는 전부 `-`다. 사번은 257,960행에서 제공되고 43,408행은 미제공이다. 이름 참조가 있더라도 사건 당시 종류 근거가 없으면 미분류다. 분류 검토 누락·원문 변경에 따른 강제 미분류는 이번 비교에서 없었다. `training_current`와 `daily_training_rider_types`는 912,913개 행 ID 및 종류·상태가 같았다.

기존 [전환일 대조](../20261015_training_rider_unclassified_review/README.md)에서는 2013년 초 종류 제공이 늘고, 조교보·조교승인 마지막 관측일인 2021-12-09 다음 날부터 미분류가 증가했다. 원문 제공 방식 변화와 관련될 가능성은 있으나 행정적 원인이나 직책 전환을 확정하지 않는다.

## 홈페이지로 더 구분할 수 있나

**최근 기록은 추가 구분 가능함을 직접 확인했다.** 공식 [제주 말별 조교현황](https://race.kra.co.kr/racehorse/profileTrainState.do?Act=02&Sub=1&hrNo=3104724&meet=2)의 범례는 `관:주로조교`다. 표본 8두 모두 최근 6개월 안내가 있고 해당 조교 조회용 과거 날짜 선택 필드는 확인하지 못했다. 현재 페이지의 제공 범위를 마사회 전체 과거 자료의 제공 한계로 일반화하지 않는다.

오늘 기준 6개월 후보 창인 **2026-04-17~10-15**에는 미분류 **20,408행·913두**가 있다. 이는 전체 미분류의 6.77%이며 나머지 280,960행은 이 창보다 오래됐다. 이 20,408행은 조회 후보 수이고 보완 완료 수가 아니다. 실제 HTML 제공 경계는 말과 날짜별로 확인해야 한다.

최근 미분류가 많은 8두를 조회했고 HTTP 200 원문에서 **587행**의 말 ID·날짜·입장·퇴장·조교시간이 모두 일치했다. 전부 `이름(관)`으로 표시되어 **주로조교 분류 후보**로 확인했다. 별도 BeautifulSoup 파서로 원문 SHA·공식 말 ID·587개의 사건키·현재 DB 미분류 상태를 검산했고 오류·모호한 연결은 0건이었다. 전체 모집단의 종류 비중을 추정하는 표본은 아니다.

| 말 | 공식 ID | 정확 일치 미분류 행 |
|---|---|---:|
| 힐링대륙 | 3104724 | 76 |
| 태흥신공 | 3104752 | 76 |
| 대보 | 3104139 | 74 |
| 비천도해 | 3018749 | 73 |
| 한라왕자 | 3019081 | 73 |
| 남조로 | 3103871 | 71 |
| 기찬 | 3104794 | 72 |
| 가온파워 | 3105269 | 72 |

예: 힐링대륙 2026-10-07 07:14~07:34, 20분은 API 종류 `-`·사번 `005285`, 홈페이지 `부찬현(관)`이다. 당시 행의 직접 표식으로 주로조교를 구분할 수 있다. `(관)`을 관리사 직책으로 바꾸거나 같은 사번의 다른 날짜 전체에 소급 적용하지 않는다.

이전 10월 15일 확인한 534행과 이번 587행은 337행이 겹친다. 이번 새 근거는 250행, 두 조사에서 확인한 후보의 합집합은 784행이다. 534+587로 합산하지 않는다. **이 후보들은 DB 분류에 아직 적용하지 않았다.**

## 후속 작업 범위

최근 후보 913두의 홈페이지를 수집해 정확 사건키와 명확한 범례 표식으로 종류를 보완할 수 있다. `외`·공란·일치하지 않는 기록은 미분류로 유지한다. 최근 창보다 오래된 280,960행은 현재 말별 페이지 외의 당시 공식 원문이 확보될 때만 보완한다. 이름·현재 직책·사번 접두로 추정하지 않는다.
