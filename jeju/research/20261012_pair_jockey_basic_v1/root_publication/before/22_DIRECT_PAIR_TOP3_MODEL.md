# 두 말 동시 Top3 직접 pair 모형 평가

저장된 F1_STYLE6 말 점수와 여섯 style 입력을 유지한 채, 과거 OOS 학습 점수로 H1 경주 수만 늘려 직접 pair 모형을 다시 비교했다. 평가 코호트와 말별 F1_STYLE6 평가는 그대로 유지했다. 평가는 2024-01-05~2026-09-19의 1,779경주·269경주일·76,848개 무순서 pair이며, 매 경주 한 쌍을 선택했다. 2026년은 9월까지의 부분연도다.

## 최신 결과

| 방식 | 적중 | 경주 | 적중률 |
|---|---:|---:|---:|
| 확장 H1 직접 pair 모형 | 427 | 1,779 | 24.00% |
| 이전 직접 pair 모형 | 426 | 1,779 | 23.95% |
| Raw F1_STYLE6 점수 상위 2두 | 429 | 1,779 | 24.11% |
| 저장된 F1_STYLE6 P(Top3) 상위 2두 | 429 | 1,779 | 24.11% |
| 기존 joint 주변확률 상위 2두 | 434 | 1,779 | 24.40% |
| 기존 joint 최대 pair | 422 | 1,779 | 23.72% |
| 기존 matched 최대 pair | 429 | 1,779 | 24.11% |

사전 지정 primary 비교에서 확장 직접모형은 raw 점수 상위 2두보다 **-0.112423 퍼센트포인트**였고, 동일 날짜 bootstrap 95% 신뢰구간은 **[-0.340716, +0.056917] 퍼센트포인트**였다. 점추정과 구간 하한이 모두 0보다 커야 하는 gate를 통과하지 못했다. 따라서 이 연구에서도 적중 개선이나 채택 근거를 확인하지 못했다.

학습창 확대 효과를 보는 별도 사전 지정 대비에서는 확장 모형이 이전 직접모형보다 1회 더 적중했다. 이전 모형과 선택한 쌍이 달라진 24경주에서 5회 개선·4회 손실·15회 동률이었고, 전체 차이는 **+0.056211 퍼센트포인트**, 동일 날짜 bootstrap 95% 신뢰구간은 **[-0.280426, +0.390865] 퍼센트포인트**였다. 이 대비는 primary 성공 gate를 대체하지 않는다.

H1 경주 수는 평가연도 순으로 이전 **312/326/329경주**에서 확장 **2,147/2,818/3,458경주**가 됐다. 연도별 선택 적중은 확장 **153/150/124회**, 이전 직접모형 **154/148/124회**였다. 역사 OOS 점수의 재현과 최종 pair 산출은 독립 검토에서 통과했다.

## 해석 범위

확장은 표본 수와 함께 과거 달력 구간·점수 모델 vintage 및 편성 구성을 바꿨으므로, 관측 차이를 학습 경주 수만의 인과효과로 해석할 수 없다. 2024~2026 라벨은 앞선 개발 평가에서 사용한 역사 자료로, 독립 미래 holdout이 아니다. 고정 날짜 bootstrap은 이미 적합한 rolling model을 조건으로 하며 H1 학습 라벨을 재표집하거나 모델을 다시 적합하지 않는다.

이번 결과로 표본 부족을 원인이라고 단정할 수 없다. 다음 비교는 모델 구조와 제약을 분리해 사전 지정해야 하며, feature·loss·λ를 함께 조정하지 않는다. 말별 F1_STYLE6 평가와 운영 모형은 변경하지 않았고, 직접 pair 모형도 운영에 반영하지 않았다.
