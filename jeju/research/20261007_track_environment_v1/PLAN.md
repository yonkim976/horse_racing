# 제주 주로환경 보정 연구 적용 검토

2026-10-07. 참조 채팅 `더러브랫- 주로환경 보정 연구`와 실제 보존 보고서·계산 계약을 읽고, 제주 데이터의 지원 범위를 점검한다. 이번 산출물은 적용 설계와 자료 지원 감사다. 보정계수·적용률·예측모델을 확정하거나 DB에 보정값을 적재하지 않는다.

## 이번 질문

1. 더러브렛 연구에서 환경 차이 관찰, 과거 기록 보정의 검증, 운영 적용 중 실제 완료한 것은 무엇인가?
2. 제주 거리×함수율×월에 충분한 관측과 공통 비교 조건이 있는가?
3. 제주 마번·출전두수 분포와 등급 표기가 같은 설계를 지원하는가?
4. 향후 전체시간 보정부터 시작할 때 사용할 원천·시점·계산·평가 계약은 무엇인가?

## 제주 지원 감사의 사전 정의

- 공유 SQLite는 `mode=ro`, `query_only=ON`. `jeju_race_postrace_sections_quality_2026`의 기본 결과만 읽는다. 현재 경주 자체의 사후 구간값·주로빠르기·기수·심판기록은 분석 입력에 넣지 않는다.
- 과거 기본 기록은 보유 하한부터 조회하되 지원 집계 대상은 2017-01-01~2026-09-19다. 관측 후보와 확정 학습 모집단을 구분한다. 현재 프로필로 확인한 제주 후보가 당시 품종까지 확정됨을 뜻하지 않는다.
- 전체시간 연구용 점검 경주: 후보 6두 이상, 모든 후보 정상 숫자 착순·양수 시간·거리, 최종 순위가 정확히 1~N, 고유 말ID·마번, DB 결과 원장 대비 부분 후보가 아닌 경주. 경주 내 거리·원문 등급·주로값이 일치해야 한다. 이 조건은 사후 선택 모집단이며 실제 T−2 출전집합을 재현한 것이 아니다.
- 숫자 함수율은 원문의 괄호 %에서 추출한다. 1~5·6~9·10~14·15~19·20 이상을 더러브렛과 비교 가능한 후보 구간으로 분류하고, 제주 원문 상태 라벨과의 일치 여부를 별도 검사한다. 0·키 미제공·이상형식은 unknown이다. 구간 경계의 제주 적용은 일치 검사와 후속 검증을 전제로 한다.
- 계절은 겨울12/1/2, 봄3/4/5, 여름6/7/8, 가을9/10/11. 완결연도 2017~2025와 최근 완결 2024~2025를 구분한다. 2026년을 완결 연간 주기로 취급하지 않는다.
- 거리×함수율 및 건조 각각 20경주일 기준은 **자료 지원 점검용 잠정 기준**이다. 더러브렛 수치가 제주 통계적 충분성을 보장하지 않으며 효과 채택 기준은 아니다.
- 말별 과거 능력 비교의 가용성은 T−2까지 동일거리 정상 기록 최근 최대3개로 점검한다. 최소 1개가 있는 말이 4두 이상인 경주 수를 센다. 이 단순 평균은 학습된 기대시간이나 환경 중립 능력값이 아니고, 보정계수 추정에 바로 사용하지 않는다.
- 계절 공통 지원은 정확 거리×연도×원문 등급×숫자 함수율 안에서 여름·겨울 모두 관측된 층을 센다. 실제 계절 효과 추정에는 말 구성·과거 능력·중량·나이 추가 통제가 필요하다.
- 마번은 출발번호 대용값이다. 실제 물리 게이트와 같다고 확정하지 않는다. 숫자 마번·N·마번순 상대 위치를 따로 보존한다. 번호 결번은 가상 출전마로 채우지 않는다.
- 예측 개선·인과효과·보정 초의 결론을 이번 지원 집계에서 도출하지 않는다. 더러브렛 코드의 속도범위·MAD 바닥·80/90% 적용률·12두 번호별 규칙을 제주에 이식하지 않는다.

## 보존과 검증

DB 전후 SHA-256·크기·수정시각, 키 유일성, 경주 완결성, T−2 과거 이력 경계, 집계 총합을 검사한다. 참조 보고서·계산 계획의 해시를 남긴다. 신규 결과만 이 폴더에 생성하고 기존 제주 연구·더러브렛 연구·운영 자산은 수정하지 않는다.
