# 제주 기록 보정의 첫 실험 설계

2026-10-07. 더러브렛의 개발 절차를 제주 원천·거리·표본에 맞게 옮기는 설계다. 현재 계수나 적용률을 채택한 문서는 아니다. 기존 [제주 기초 연구](/Users/kimyongjin/Desktop/horse_racing/jeju/research/20261007_foundation_v1/README.md)의 말별 평가표와 Top3 목표를 유지한다.

## 1. 무엇을 가져오고 다시 추정하는가

| 대상 | 가져올 구조 | 제주에서 새로 정할 것 |
|---|---|---|
| 함수율 | 사전 능력 대비 잔차 → 경주 단위 집계 → 거리별 환경 차이 → 과거 기록 보정 → 재학습 | 계수, 축소 강도, 지원 조건, 적용률 |

| 게이트 | 같은 경주 안에서 사전 능력 차이를 통제한 비교 | 제주 출전두수별 번호 효과, 초 단위 효과, 물리 게이트 대응 |

서울80%·부산90%는 제주 보정률이 아니다. 더러브렛의 10~20m/s 유효범위, MAD 바닥값, 12두 번호별 설계, S1F 경계, 최근창·반감기·%p 상한도 제주 기본값으로 복제하지 않는다. 숫자 함수율의 다섯 구간은 제주 원문과 이번 표본에서 전부 일치했으므로 비교용 후보 정의로 사용할 수 있다. 연속 함수율 반응은 별도 대안이며 1%마다 일정한 초를 더한다고 가정하지 않는다.

## 2. 대상과 기간

첫 파일럿은 **1000m·1110m의 전체시간**으로 한다. 2019년 이후에는 현행 형식의 등급 표기가 관측되고 최근2024년 이후에도 다섯 함수율 구간의 잠정 지원이 있다. 두 거리는 합쳐 하나의 초 보정표를 만들지 않고 정확 거리 범주와 상호작용을 둔다. 900·1200m, 과거800m로 확장하되 최근 희소 함수율은 따로 표시한다.

2017년을 원래 모델 정답 후보 시작으로 검토하는 방침은 유지한다. 다만 환경계수의 첫 주 분석은 **2019년 이후**, 2017~2018년은 원문 등급의 별도 시대층·warm-up·민감도 자료로 둔다. 이번 점검에서 `제1` 마지막 관측은2018-08-25, `제1등급`~`제6등급` 첫 관측은2018-08-31 이후였다. 이는 표기 관측 경계이며 실제 제도 개편일이나 동등 등급 판정이 아니다. `제1`을 현재 `제1등급`으로 정규화하지 않는다. OPEN 표기도 근거 확인 전 별도 보존한다.

400m는 보유 기간이2017~2018이고 건조 기준이1경주일뿐이다. 1300·1400·1610m는 젖은 조건 또는 건조 참조가 부족하다. 다른 거리의 계수를 넣어 빈칸을 채우지 않는다. 계층적 축소를 실험하더라도 지원 부족을 명시하고 그 거리의 검증 결과가 없으면 보정 채택으로 부르지 않는다.

초기 점검의 정상·완전 순위5332경주는 사후 선택 모집단이다. 취소·실격·주행중지·동착 등의 제외가 환경·번호에 따라 달라질 수 있다. 향후 계수 추정에서 이 모집단을 쓸 경우 제외율과 결과코드 분포를 같이 보고하고, 정상 시간 관측을 더 넓게 보존한 민감도를 둔다. 잘 알려진 구간 오류 때문에 전체시간 기록을 임의 삭제하지 않는다.

## 3. 함수율: 기대시간과 실제시간의 차이

각 말의 과거 T−2 이력과 이번 기록의 거리·원문 등급·당시 나이·부담중량·성별·출전 간격을 이용한 최소 기대시간 모형을 먼저 만든다. 이번 경주의 실제 함수율·구간·착순은 **환경을 제외한 기대시간**의 입력에서 뺀다. 기수·기수 성향·심판기록은 초기 제외한다. 현재 프로필 고정 나이를 과거 나이로 쓰지 않는다. 과거 동일거리 최근 기록도 원기록부터 시작한다.

기대시간은 대상 연도보다 이전 자료로 적합해 연도 외부 잔차 `r_i = 실제시간_i − 기대시간_i`를 만든다. 기대시간 학습과 잔차를 만들 경주를 분리한다. 잔차를 같은 경주의 중앙값으로 집계할 때 적격 말 수와 과거 이력 결측률을 보존하고, 경주당 총가중치를1로 둔다. 단순한 말별 평균 때문에 두수가 큰 경주를 더 많이 세지 않는다.

그다음 경주 잔차에 정확 거리·함수율 구간·달력월·연도/시대·등급 구성·경주번호 등을 조정한 환경모형을 적합한다. 거리×함수율의 수축 모형과 거리별 독립 모형을 구분해 비교한다. 말 능력 변화가 잔차에 남을 수 있으므로 다른 기대시간 사양과 원문 등급 시대 분리의 민감도를 확인한다. 주로빠르기 `tempo`는 초기 제외한다.

극단 잔차 제거는 데이터 오류 판정과 다르다. 우선 무절단/경주 중앙값의 강건 기준을 보존하고, 학습 구간 안에서만 정한 MAD 방식 등을 민감도로 비교한다. 제주 분포를 보지 않고 더러브렛의 초 단위 바닥값을 복제하지 않는다. 빠르거나 느린 평가 정답을 보정 후보에 유리하도록 삭제하지 않는다.

여기서 **경주 고정효과를 넣으면 함수율·월처럼 경주 내 동일한 변수는 흡수되어 추정할 수 없다.** 함수율·월의 경주 간 비교와 아래 게이트의 경주 내 비교는 다른 추정 단계다.

## 4. 계절·월: 함수율과 중복되지 않는 성분

먼저 정확 거리×연도×원문 등급×숫자 함수율 안의 공통 관측만 비교한다. 관측 지원과 인구 구성 통제가 다르므로 원시 차이, 조건 일치 차이, 과거 능력·당시 나이·중량·성별 구성까지 조정한 차이를 나눠 보고한다. 2017~2025와2019~2025, 최근 완결2024~2025를 구분한다. 2026년은1~9월 자료이며 겨울·연간 비교를 완결연도처럼 다루지 않는다.

처음부터144개 거리×월 셀을 독립 추정하기보다 연중 평균0을 기준으로 한 완만한 순환 곡선 후보를 둔다. 월별 범주 모형은 설명용 비교로 보존한다. 월은 기온·관리·편성·말의 성장 등 여러 변화가 섞인 지표이며 순수 기온의 인과효과가 아니다. 풍향·풍속 등 새 외부 자료 연결은 이번 첫 범위에 추가하지 않는다.

함수율과 월을 하나의 환경모형에서 추정하거나, 이전 자료에서 추정한 함수율 성분을 제거한 뒤 남은 월 성분만 추정한다. 전체 월 평균 차이를 기존 함수율 보정에 그대로 더하면 같은 효과를 두 번 제거할 수 있다.

예를 들어 환경모형의 예측값을 `f(d,m,q,x)`라 하자. d=정확 거리, m=함수율 조건, q=월, x=같이 유지할 통제 조건이다. 같은 월의 건조를 함수율 참조로 하고, 건조의 연중 평균을 월 참조로 두면 다음처럼 분리할 수 있다.

```
함수율 성분 Δm = f(d,m,q,x) − f(d,건조,q,x)
월 성분 Δq = f(d,건조,q,x) − mean_k f(d,건조,k,x)
```

이때 평균은12개월 같은 비중을 기본 후보로 두되 월별 관측 지원과 외삽을 확인한다. 지원 없는 월의 값을 곡선으로 만들었다고 검증된 값으로 표시하지 않는다. 두 성분의 합은 해당 환경과 공통 참조의 차이가 되어 중복 가산을 피한다. 이 식은 설계 예시이고 제주 추정값은 아직 없다.

## 5. 게이트: 먼저 초 단위 효과를 따로 추정

마번, 관측 출전두수 N, 마번순 상대 위치 `(번호순위−1)/(N−1)`를 따로 둔다. 번호가 이어진 경주에서도 물리 출발대 배치와 같다고 독립 확인한 것은 아니다. 이번 완전 순위 표본은10두가 중심이고 최근2024년 이후에는1548/1779경주가10두다. 따라서 번호별 주 분석은 **정확히10두·마번1~10**으로 시작하고 다른 두수는 별도 연구한다. 더러브렛의12두 규칙을 적용하지 않는다.

초 단위 게이트 추정은 같은 경주의 전체시간 차이를 종속변수로 하고 경주 고정효과, 각 말의 사전 능력과 당시 나이·중량·경력·간격 차이를 조정한다. 정확 거리×출전두수별 효과를 허용한다. 동시에 Top3 차이는 별도 종속변수로 분석한다. `%p`와 `초`를 변환하지 않는다.

주 분석에서 **현재 경주의 실제 S1F 순위나 관측 내외측 위치를 통제하지 않는다.** 출발번호가 전개를 통해 영향을 주는 경로를 제거하면 질문이 바뀐다. 실제 위치를 사용하는 분석은 사후 기전 연구로 분리하고 보정 초를 독립적으로 더하지 않는다. 제주 통과조는 품질 보류·지점 대응·압축 표기 계약을 먼저 통과해야 하며 레일 거리나 추가 주행거리를 제공하지 않는다.

같은 경주 내 시간·입상 비교에서도 배정·말 구성·미관측 조건의 영향이 남는다. 원인으로 확정하지 않고, 이후 기록 평가와 예측에 유용한지 검증한다. 결과코드·출전집합의 선택 편향과 번호별 제외율도 점검한다.

## 6. 보정 기록과 저장 구조

```
보정시간 = 원기록 − a_m·Δm − a_q·Δq − a_g·Δg
```

Δ는 해당 조건이 공통 참조보다 더한 추정 시간(초)이다. 빠른 환경이면 음수이므로 그 이점을 제거할 때 원기록에 시간을 더한다. 반대면 시간을 뺀다. a는 검증할 적용률이다. 원기록 자체에80% 등을 곱하는 식이 아니다.

함수율 적용률의 첫 비교 범위는0·25·50·75·100%, 월·게이트는 초 단위 추정과 지원 점검 후0·25·50% 같은 작은 후보부터 시작하는 안이다. **이 값들은 후보 격자이며 권장 보정률이 아니다.** 선택 기간에서 차이가 작은 후보 중 보정이 작은 것을 고르되 더러브렛의0.002초 허용오차를 자동 이식하지 않는다. 제주 개발 자료에서 평가 변동과 실무 목적을 보고 선택 규칙을 사전에 고정한다.

| 저장 필드 | 의미 |
|---|---|
| 경주키·말ID·원천 ID·payload SHA | 정확한 연결·근거 |
| 원기록 초 | 공식 선택값, 보존 |
| 함수율·월·게이트의 추정 효과 초 | 미추정이면 NULL |
| 성분별 적용률·실제 적용 초 | 지원·선택 규칙을 따라 계산 |
| 보정시간 초 | 실제 적용분만 반영한 별도 열 |
| 추정 자료 종료일·계수 버전 | 과거 시점 검증 |
| 지원 경주수·경주일수·불확실성 | 효과 크기와 신뢰도를 구분 |
| 상태 | 적용, 미추정, 지원 부족, 원기록 유지, 참조조건 등 |

미추정 성분은 효과가0으로 확인된 것이 아니다. 원기록을 유지할 때 실제 적용 초는0일 수 있지만 `estimated_effect=NULL`, `status=unsupported_raw_fallback`처럼 구분한다. 마체중·부담중량·나이·성별은 환경 추정의 통제나 말 평가 정보이며 이번 환경 보정에서 모두 제거하지 않는다.

## 7. 과거 시점과 시간순 검증

말별 이력은 한국 날짜 T−2까지 포함한다. 사건 날짜와 당시 공개시각은 별개이며 현재 DB는 사후 검토 버전이다. 이번 원천으로 얻는 첫 성능은 이 가정을 표시한 회고 개발 분석이다.

각 과거 기록 h의 계수는 **h보다 이전 연도까지로 고정**하는 방식을 첫 비교로 사용한다. 2025년까지 적합한 표를2019년 기록에 일괄 적용하지 않는다. 계수 지원이 없는 초기 기록은 원기록과 미지원 상태를 보존하며 평가 행을 후보마다 바꾸지 않는다. 이후 대상 T−2 시점에 과거 전체를 재평가하는 대안은 별도 버전과 누수 검증이 필요하다.

초기2019년 이후 자료는 기대시간·환경계수의 seed 역할을 하고, 최초 과거계수를 만들 수 있는 연도는 실제 이력·지원 집계로 정한다. 그 전 기록을 보정 완료로 소급하지 않는다. 같은 경주일의 전체 기록을 이용해 그 경주의 사전 주로 편차를 만들지 않는다.

파일럿에서 다음을 같은 학습행·평가행·모델 복잡도·seed로 비교한다.

1. R0 원기록 평가표.
2. R1 함수율 보정 이력으로 재학습.
3. R2 함수율+월의 중복 없는 보정 이력으로 재학습.
4. R3 초 단위 검증이 된 게이트 성분 추가.

먼저 환경 모형의 잔차·계수 안정성·거리/기간별 방향을 확인한다. 다음으로 다음 동일거리 출전의 원시 전체시간 MAE를 보조 검증하고, **최종 판단은 말별 Top3 log loss·Brier·보정도와 후보 포함률·최대6조합 적중률**에 둔다. 시간 오차 개선이 입상 개선을 뜻하지 않는다. 조합 확률은 주변확률 곱으로 주장하지 않는다.

2019~2026년은 이미 여러 번 관찰한 개발 자료다. 예를 들어2022~2023을 적용률 선택,2024~2025를 후향 평가,2026년을 부분연도 점검으로 쓸 수 있지만 이는 새로운 독립 평가가 아니다. 실제 분할과 최소 모델은 첫 추정 전에 고정한다. 최종 미관측 검증은 규칙 동결 이후 별도 기간에서 수행한다.

표본 지원과 불확실성은 날짜를 단위로 집계·재표집한다. 월·거리의 다수 대비는 다중 탐색임을 표시하고 일부만 골라 일반화하지 않는다. 같은 말의 반복 출전과 계수 추정오차에 대한 민감도도 남긴다. 효과가 불확실하거나 예측이 개선되지 않으면 원기록 기준선을 유지한다.

## 8. 구간 보정은 다음 단계

제주의 S1F·코너 경계,1110·1610m 거리 대응,1300m S1F/2C 측정 순서는 아직 미확정이다. 전체시간 보정계수로 구간시간을 비례 보정하거나 초반·막판·중간에 같은 초를 가산하지 않는다. 이번 첫 연구는 전체시간으로 시작할 수 있지만 구간 보정의 준비가 완료된 것은 아니다.
