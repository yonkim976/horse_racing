**전용 선택 모델 3개를 실제 학습했지만 기존 점수 Top5 대비 개선은 확인되지 않았다.** 기존 F1_STYLE6 말 평가와 원점수는 그대로 유지한다. Luna xhigh가 실행했고, root가 학습 목적함수·전처리·최종 gradient·선택·원천 정답 연결·집계와 신뢰구간을 검토했다.

주 지표는 정확히 고른 5두 안에 실제 입상마 3두가 **전부** 들어간 비율이다. 주 평가에서 새로 포함한 경주 31개, 반대로 놓친 경주 35개였다. 고정 날짜 bootstrap 2,000회의 차이 95% 구간은 **−1.34~+0.78%p**다. 전체 거리는 38개 새로 포함·37개 누락, 보조 구간 −0.90~+1.01%p다. 사전 성공 기준을 통과하지 못했으므로 선택기를 채택하지 않는다.

## 실제로 학습한 내용

각 경주의 모든 가능한 5두 집합을 열거하고, 실제 Top3가 전부 포함된 집합들을 정답 측으로 묶어 그 집합들에 학습 분포의 질량을 주는 목적함수를 사용했다. 기존 말 점수의 경주 내 표준화 값을 고정 prior로 두고, 경력·동일거리 지원수·상대 기록 순위·과거 구간 위치 및 전이·그 지원수 11개 기존 입력의 합에 작은 선형 보조계수를 학습했다. 원천 F1 점수와 말별 확률은 변경하지 않았다.

2024년 선택 모델은 2019~2023년 2,492경주, 2025년 모델은 2019~2024년 3,129경주, 2026년 모델은 2019~2025년 3,783경주로 학습했다. 매 경주의 원점수도 해당 결과를 학습하기 전에 생성한 과거 OOS 점수만 사용했다. 전처리는 각 학습기간의 유효 runner 관측에서만 정했고, T−2 날짜와 provider refit 시점을 검증했다. λ=1·영벡터 시작·한 번의 최적화로 fold당 1회씩만 학습했고 탐색·재시작·사후 규칙 변경은 없었다.

이 모델은 입상 3두 전원 포함이라는 사건을 학습하는 **가법 선택 보조모델**이다. 말 간 상호작용 항은 없다. 무작위 5두 선택 분포의 정답 집합 질량을 학습한 것이므로 그 질량을 실제로 고른 5두의 보정된 적중확률이라고 해석하지 않는다. 최종 판정은 실제 선택한 5두의 포함률로만 했다.
