# 제주마 편성 대비 상대능력 입력 비교

2026년 10월 9일. 성능 계산 전에 고정한다. 원기록 최소 모델 J0에 이번 상대 말들의 T−2 이전 동일거리 수행을 비교하는 8열을 추가한 R1을 검증한다. J1의 최고·편차·추세 묶음은 승계하지 않는다. 기수·부담중량·게이트·전개·환경은 이번 비교에 추가하지 않는다.

## 자료와 모집단 및 시점

이전 `20261008_horse_profile_baseline_v1/outputs_v2/features.parquet`의 52,155출전·5,206경주를 재사용한다. 이전 동결 해시와 현재 DB 해시를 확인한다. 원천은 품질 조회 `jeju_race_postrace_sections_quality_2026`, 상한 2026년 9월 19일이다. 공식 말 ID로 연결하며 제외 말 3005648을 유지한다. 원장 DB·운영 등록부·HY_R_FORM을 변경하지 않는다. 기존 산출물은 읽기 전용 참조로 남긴다.

2017년부터 학습하고 2002년부터의 관측 이력을 warm-up으로 사용한 기존 계약을 유지한다. 한국 날짜 T−2까지 포함하며 T−1·당일 이력은 제외한다. 동일거리 최근 실제 관측 출전 5회 창의 정상 양수 시간을 평균한다. DNF·실격·시간 결측은 자리와 NULL을 유지한다. 다른 거리 시간을 환산하지 않는다. 상대 말의 동일거리 이력도 같은 대상 경주 날짜의 T−2까지다.

현재 800·900·1000·1110·1200·1300·1400·1610m, 정상 완전 착순1~N·6두 이상·저장 원장과 같은 전체 편성을 사용한다. DNF·실격·동착·부분편성 경주는 전체 제외된 사후 모집단이다. 이력이 없는 말은 포함한다. 400m는 현재 학습 대상에서 제외한 기존 범위를 유지한다. 희소 거리 학습 지원의 한계도 승계한다.

이번 출주집합·거리·등급·두수는 결과 원장에서 재구성한 가정이다. 당시 T−2 선언표·취소·게시·정정 시각을 재생하지 못했다. 현재 프로필 품종·표시 마명도 사건 당시 전체 품종·평생 경력을 입증하지 않는다. 이 실험은 정상 완전 편성에 대한 후향 개발 비교이며 실제 운영 전체 성능이나 독립 미래 검증이 아니다.

## 추가 열과 계산

각 말 i의 J0 입력 `mean5_s`를 x_i라 한다. 현재 경주의 다른 말 중 x가 유효한 말만 O_i에 포함하고 n_i=|O_i|로 센다. 자신을 반드시 제외한다. 작은 시간이 빠른 방향이다. 모든 상대가 같은 현재 목표 거리의 과거 기록을 사용한다. 경주 ID·말 ID는 연결과 자기 제외에만 사용한다.

| 추가 열 | 정의 | 결측과 관측수 |
|---|---|---|
| `opp_mean5_valid_n` | n_i | 관측 없음은 0 |
| `opp_mean5_valid_fraction` | n_i / (이번 두수−1) | 미관측을 0초로 변환하지 않음 |
| `opp_mean5_median_s` | O_i 시간의 중앙값 | n_i=0이면 NULL. 자기 기록이 없어도 상대 수준은 보존 |
| `mean5_minus_opp_mean_s` | x_i − mean(O_i) | 자기 또는 상대 평균 없음이면 NULL |
| `mean5_minus_opp_median_s` | x_i − median(O_i) | 자기 또는 상대 중앙값 없음이면 NULL |
| `mean5_minus_opp_fast2mean_s` | x_i − 상대의 빠른 시간 2개 평균 | 자기 없음 또는 n_i<2면 NULL |
| `opp_mean5_faster_n` | O_i 중 x_j < x_i인 말 수 | 자기 없음 또는 n_i=0이면 NULL. 비교 가능할 때 빠른 상대가 없으면 0 |
| `mean5_rank_fraction` | (빠른 상대 수 + 0.5×동일 시간 상대 수) / n_i | 자기 없음 또는 n_i=0이면 NULL. 0=상대보다 빠름, 1=상대보다 느림 |

원기록 차이는 조건 보정된 순수 능력 차이가 아니다. 이력의 주로·등급·부담·최근성 차이가 남는다. 동률은 저장된 평균값의 정확한 동률로 정의하고 현재 출발번호를 이용해 임의 순위를 만들지 않는다. 상대별 기록수로 가중 평균하지 않는다. 미관측 상대가 있는 경우 계산 가능한 상대만의 비교이며 가용률과 n을 함께 제공한다.

J0는 기존 13열을 그대로 유지한다. R1은 J0 13열+위 8열=21열이며 제거 열은 없다. 이번 실제 착순·시간·체중·함수율·기수·마번·구간측정과 미래 성적을 추가 계산에 쓰지 않는다. 무이력 말도 상대 가용률·수·중앙값을 받을 수 있지만 자기 능력 차이는 NULL로 남긴다. 상대능력이 필요한 행을 제거하지 않는다.

## 학습과 평가 계약

J0와 R1 두 모형만 같은 표본에서 비교하고 결과 확인 후 열·모수·경계를 변경하지 않는다. 기존 J0와 동일한 LightGBM 설정·seed20261008·경주 균등 가중치다. 각 평가 Y=2024·2025·2026에서 초기 학습2017~Y−3, 조기종료Y−2, 결정된 회수로 Y−2까지 재학습, 온도 보정Y−1, 평가Y다. 모형과 온도는 평가 연도 내 고정하고 T−2 과거 이력만 갱신한다. 최대200회·조기종료25회, 나머지 설정도 이전 그대로다. 원문 범주는 초기 학습 어휘만 사용한다. 결측은 결측 분기를 사용한다.

J0를 새 폴더에서 재학습해 이전 동결 점수·확률·경주지표와 일치를 확인한다. 순서 없는 3두 집합의 말별 점수 합을 softmax로 정규화하고 주변 Top3 확률을 계산하는 기존 가산 집합 모형을 유지한다. 집합 합1·주변 합3, 온도 범위[0.35,4], 전년도 집합 NLL 보정, 번호 동점 정렬도 유지한다. 동반입상 상호작용을 별도 학습하지 않는다. 부동소수점 검산은 정렬된 세 항의 좌결합 덧셈을 사용한다.

평가 1,779경주·17,412출전을 그대로 사용한다. 2026년은 9월19일까지 부분연도다. 주지표는 경주 균등 Top3 log loss와 Brier, 보조는 상위5두 실제 입상마 포함률·3두 전부 포함률·최대6조합 적중률·집합 NLL이다. 연도·거리·등급·무이력/저경력 포함 편성, 말별 관측 경력0·1~4·5+ 및 동일거리 이력0·1~4·5+를 분리한다. 확률 구간별 보정·학습거리 지원도 남긴다.

R1−J0의 경주일 paired bootstrap 2,000회·95% 점별 구간을 계산한다. 말별 하위군은 같은 말의 두 모형 오차차를 날짜별 합/수로 집계한 runner 균등 차이다. 같은 말의 장기 반복에 대한 별도 군집 추론은 하지 않는다. 하위군은 탐색이며 다중비교 확증으로 사용하지 않는다. 적중률은 수익률이 아니다.

전체 log loss·Brier가 모두 낮아지고 적어도 하나의 개선 구간이 0을 제외해야 R1을 다음 연구 기준선 후보로 유지한다. 다른 핵심 지표·연도별·무이력 퇴행도 함께 보고한다. 기준 미충족이면 J0 유지·R1 후보 보존이다. 어느 경우에도 운영에 자동 적용하지 않는다.

## 학습 전과 후 검증

모든 상대값을 독립적인 계산으로 다시 구하고 자기 제외·NULL·동률·순서 불변·현재 사후 관측 교란 불변을 확인한다. 상대 말의 입력을 바꿨을 때 자신에게 계산된 상대 수준은 변하지만 그 상대 자신의 상대 중앙값에는 자기 변화가 들어가지 않는지 검사한다. 실제 편성 사례와 출전 ID·상대 ID를 보존한다. 모든 과거 원천 날짜가 T−2 이내인지 이전 계보와 연결한다.

학습 전 코드·계약·입력과 보호 파일 해시를 고정하고, 학습 후 모델 재로딩·온도·확률·순위·6조합·지표·주구간을 재계산한다. 이전 J0 재현과 DB·기존 모델·등록부 해시 불변을 확인한다. 날짜별 새 연구 폴더와 중앙 결론 모음에 결과·한계·파일 크기를 보존한다.
