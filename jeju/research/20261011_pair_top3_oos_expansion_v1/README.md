# 제주 Top3 pair H1 확장 모델 평가

F1_STYLE6 평가와 30개 말 입력은 고정하고, recipe-valid 과거 OOS 원시 점수를 H1에 추가해 direct pair 모형을 다시 비교했다. 기존 direct 모형과 원시 점수 Top2를 포함한 모든 비교는 같은 2024~2026 평가 경주에서 수행했다. 평가기간은 2024-01-05~2026-09-19이며, 2026년은 9월까지의 부분연도다. 이 평가는 반복 개발 표본이며 새 holdout은 아니다. 예측 pair 확률은 공동 Top3 분포가 아니므로 경주별 모든 pair 확률의 합이 3으로 보장되지 않는다.

평가 코호트는 1,779경주, 269경주일, 76,848개 무순서 pair다. 각 경주에서 각 방식은 pair 하나를 선택했다.

## H1 학습창 확장 대비

확장 direct는 427/1,779(24.00%), 기존 direct는 426/1,779(23.95%)였다. 변경 pair 24경주 중 +5승, -4패, 15동률이며, 차이는 +0.0562%p, 동일 날짜 bootstrap 95% CI는 -0.2804%p ~ +0.3909%p다. 이 비교는 학습창 확대와 역사 구간 구성이 함께 바뀌는 별도 사전 지정 대비이며 primary 성공 gate를 대체하지 않는다.

H1은 2024년 312→2,147경주, 2025년 326→2,818경주, 2026년 329→3,458경주로 늘었다. 연도별 확장 direct 적중은 153/150/124, 기존 direct는 154/148/124였다. H2와 평가 코호트는 그대로 유지했다. Primary gate는 raw Top2 대비 427/1,779 대 429/1,779, 차이 -0.1124%p와 95% CI -0.3407%p~+0.0569%p로 미통과다. H1 확장은 경주 수와 함께 과거 달력 구간 및 점수 모델 vintage도 바꾸므로 학습량만의 인과효과로 해석할 수 없다. 2024~2026 평가 코호트는 반복 개발 라벨을 재사용하며 독립 holdout이 아니다. 고정 날짜 bootstrap은 적합된 rolling model을 조건으로 하며 H1 학습 라벨을 재표집하거나 재학습하지 않는다.

다음 비교에서는 표본 부족을 단정하지 않고 구조 효과와 학습 제약을 분리해 검토한다. 학습량 비교와 동시에 λ 또는 loss를 튜닝하지 않는다.
