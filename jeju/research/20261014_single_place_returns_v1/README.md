# 제주마: 경주당 연승 축 한 마리의 확률과 사후 수익

GPT-6 Luna xhigh가 저장된 F1_STYLE6 말 평가를 유지해 집계했고 감독이 모든 선택·확률·배당·요약·신뢰구간을 독립 검산했다. **매 경주 1,000원씩 산 사후 수익률은 −18.99%였다. 확률이 높은 경주만 고른 사전 고정 임계값에서도 수익은 마이너스였다.**

말 평가는 재학습·보정하지 않았다. 기존 말별 Top3 확률은 저장 점수와 연도별 기존 온도로 만든 무순서 Top3 집합 분포의 주변확률이다. 각 경주의 최고 점수 한 마리를 선택하고 정확한 점수 동률은 작은 마번으로 정했다. 이 분포에서 점수 최대 말은 수학적으로 Top3 확률 최대 말과 같다. 계산상 1 ULP 차이로 동률 선택이 바뀌지 않게 했으며 선택한 말의 확률은 저장값을 그대로 사용했다. 두 말 동시입상 확률을 단일 말 확률로 변환하지 않았다.

전체 평가는 2024-01-05~2026-09-19의 1,779경주·269일·17,412출전이다. 이미 여러 연구에서 사용한 과거 개발 자료이며 2026년은 부분연도다. 수익률은 사후 연승 배당이 있는 2025년 654경주와 2026년 488경주, 총 1,142경주에서 계산했다. 2024년 637경주는 가격이 없어 수익 계산에 넣지 않았다.

연승 기준은 8두 이상이면 Top3, 7두 이하면 Top2다. 현재 모델에 Top2 확률이 없어 7두 36경주는 동일한 최고 점수 축으로 실제 Top2 적중·수익만 계산하고 연승 예측확률을 NULL로 남겼다. 확률 구간에는 전체 1,743경주, 가격 보유기간에는 1,106경주가 포함된다. [마사회 연승 안내](https://park.kra.co.kr/race_guide_.pdf), [배당 확정과 환급 절차](https://race.kra.co.kr/raceguide/RaceProcessGetService.do).

## 전체 손익과 해석

- 1,142경주에서 654회 적중: 실제 연승 적중률 57.27%.
- 총 투입 1,142,000원, 총환급 925,100원, 손익 −216,900원. 수익률 −18.99%, 날짜 95% 구간 −23.57~−14.59%.
- 평균 적중배당 1.4145배. 같은 평균 적중배당에서 손익분기 적중률은 70.70%다. 실제 57.27%와 차이가 크다.
- 실제 적중률을 고정하면 손익분기 평균 적중배당은 1.7462배다. 두 손익분기 수치는 사후 기술통계이며 구매 전 배당 기준이 아니다.
- 연도별 수익률은 2025년 −17.54%, 2026년 −20.94%. 7두 경주만 보면 18/36 적중, 수익률 −25.28%(구간 −48.49~+5.72%).

전체 확률 지원 1,743경주의 평균 예측확률은 58.12%, 실제 적중률 57.26%이며 차이(실제−예측)는 −0.86%p, 날짜 95% 구간 −3.18~+1.33%p다. 가격 보유 확률 지원 1,106경주는 평균 예측 57.88%, 실제 57.50%다. 전체 확률 평균이 가까운 것과 수익이 나는 것은 별개이며, 이번 자료에서는 높은 확률에 낮은 적중배당이 함께 나타났다. 70~80% 구간은 73.39%를 맞혔지만 평균 적중배당 1.2077배로 수익률 −11.37%였다.

이번 결과는 높은 입상확률만으로 연승 구매를 결정할 근거를 제공하지 않는다. 현재 말 평가는 유지하며 고확률 구간 자체가 수익성을 보장한다고 해석하지 않는다. 후속 연구는 한 마리 연승 사건에 대한 시간순 확률 검증, 7두 Top2 확률 지원과 실제 사전 배당 가용성을 구분해야 한다. 사전 배당이 없는 현재 자료로 실행 가능한 가격 필터 성능을 주장하지 않는다.

## 원천·검증·계산 계약

API301 PLC 원문에서 최신 완전 run의 506개 페이지를 확인해 1,142경주 모든 11,083두의 가격을 확보했다. 원문 표시배당을 원금 포함 환급배수로 사용해 적중 시 1,000원×배당, 미적중 시 0원으로 계산한 사후 표시배당 기준 수익이다. 미적중마에도 quote가 존재하지만 그 가격을 지급 환급으로 합산하지 않았다. 추가 공제 전 계산이며 원문에는 개인별 실제 지급액·공식 최초 가격 공표시각이 없다. 동착·취소·불완전 편성은 고정 정상 완주 cohort에 없으므로 예외 정산 계약을 검증했다고 주장하지 않는다.

감독은 저장 점수·기존 온도로 17,412개 확률을 재현하고, 공식 말 ID·마번·착순·실제 출전두수를 읽기 전용 DB와 대조했다. 직접 원문 JSON 추출 가격과 계산 코드의 입력·출력을 독립 대조해 1,779개 선택, 49개 요약과 392개 CI 경계를 재계산했다. 날짜 bootstrap은 기존 2,000×269 일정의 표본 날짜 ID를 날짜 빈도 가중치로 변환해 사용했다. 구간/임계값의 빈 집단과 분모 0인 반복도 보존했다. DB·운영 등록부·기존 모델을 수정하지 않았고 새 학습·보정은 없다.
