# 첫 출전 말 주행심사 정보 비교

2026-10-18 사전등록 연구다. 저장된 제주 F1_STYLE6 30입력 기준선을 보존하고, 기준선 이력에서 `observed_starts == 0`인 말에 주행심사 정보 4개를 한 묶음으로 추가한 후보 1개를 같은 경주에서 비교했다. 이는 저장된 말 평가 모델끼리의 후향 비교이며 운영 모델, 등록부, DB를 바꾸지 않았다.

정확한 피처·분할·지표·통과 기준은 [CONTRACT.md](CONTRACT.md), 입력 재현은 [preflight](outputs/preflight_verification.json), 실행 고정값은 [prepared lock](outputs/prepared_lock.json), 결과 고정값과 모든 결과 파일 SHA는 [evaluation source lock](outputs/evaluation_source_lock.json) 및 [최종 manifest](outputs/FINAL_MANIFEST.json)에 있다.

## 코호트와 자료

저장 F1_STYLE6 코호트는 52,155출전·5,206경주이며 2017-01-13–2026-09-19 자료다. 평가 코호트는 17,412출전·1,779경주·269경주일이고 실제 첫 평가일은 2024-01-05, 마지막은 2026-09-19다. 사전 대상인 `observed_starts == 0`은 저장된 과거 이력에서 출전 기록이 관측되지 않았다는 뜻이지 평생 첫 출전을 보증하지 않는다. 평가 대상은 661출전·252경주다. 2024년 224출전/90경주, 2025년 246/89, 2026년 191/73이며 주평가는 거리를 제한하지 않았다.

주행심사 입력은 API20 주행심사 응답만 사용했다. 감사된 전체 명시 제주 자료는 15,831행이며 2002-06-12–2026-10-15 범위다. 이 대상 말과 연결한 T−2까지 기록은 3,500행, 말 1,946두 모두에 한 건 이상이며 연결 이벤트는 961개다. 원천 감사와 피어 roster는 [source audit](../20261018_debut_trial_source_audit_v1/README.md)에 있다. API20에서 심사 거리는 확인되지 않아 서로 다른 이벤트의 원시 초를 합치거나 실전 기록과 섞지 않았다.

## 후보 입력과 검증

기존 30개 입력의 값, 순서, 라벨, 학습·평가 경계는 그대로다. 다음 네 입력을 관측 출전 0인 행에만 붙였다. 관측 출전이 있는 말은 네 값 모두 NULL이다.

| 입력 | 정의 |
|---|---|
| `trial_peer_relative_time_mean3` | T−2까지 최근 등록 이벤트 세 개 중 자격이 있는 `(말 심사시간 − 같은 이벤트 다른 유효 제주 말들의 중앙값) / 중앙값` 평균 |
| `trial_peer_relative_time_n3` | 위 상대시간의 유효 개수, 0–3 |
| `trial_days_since_latest_event_pre` | T−2까지 최근 등록 심사 이벤트 날짜부터 경주일까지 일수. 취소·무효 기록도 최근 기록과 개수에 포함 |
| `trial_event_count_pre` | T−2까지 등록 말-이벤트 기록 수. 실제 시행 횟수라는 뜻은 아님 |

시간 신호는 양수 유한 `rcTime`, 정수 `ord` 1–89, 감사된 완료 판정 allowlist, 그리고 target 외 동일 이벤트의 유효 제주 말 두 마리 이상을 모두 요구한다. 무효/취소 슬롯은 최신 세 기록 창에 남기며 과거 기록으로 대체하지 않는다. API21 출발심사, 출발조교·일별 조교, 현재 프로필은 사용하지 않았다. 심사일은 공개 시각이 아니므로 T−2 시점에 정보가 실제로 공개됐는지는 확인되지 않았다.

기준 저장 모델 3개는 재적합 없이 재생했고 17,412행·1,779경주 예측과 저장 출력을 일치시켰다. raw score, 말별 확률·손실, 경주별 손실, 최대 6조합의 최대 절대오차는 0이었다. 별도 root 구현과 1,946두의 네 피처가 행별로 일치했고, 기존 30열은 정확히 보존됐다. 후보는 root 승인 후 단 한 번만 적합했다: 연도별 3개 모델, LightGBM 6회, temperature 보정 3회. 다른 피처 묶음·하이퍼파라미터 탐색·재적합은 없었다.

## 결과

주평가 손실은 먼저 각 경주에서 무이력 말들의 runner-binary Top3 손실을 평균하고, 그 뒤 252경주를 동일 가중했다. 차이는 후보 − 저장 F1_STYLE6이며, 정해진 2,000×269 날짜 bootstrap을 그대로 썼다. 무이력 말이 없는 날짜도 표본에서 제외하거나 날짜 인덱스를 다시 만들지 않고 손실 합과 경주 수 모두 0으로 처리했다.

| 지표 | 저장 F1_STYLE6 | 4입력 후보 | 후보 − 기준선 | 고정 날짜 paired 95% CI |
|---|---:|---:|---:|---:|
| Top3 log loss | 0.629980 | 0.524203 | −0.105777 | [−0.133520, −0.079095] |
| Brier | 0.219313 | 0.173344 | −0.045969 | [−0.058128, −0.034093] |

두 점추정치 모두 개선됐고 두 신뢰구간 상한도 0보다 낮아 사전 gate를 통과했다. 2,000회 모두 유효했다. 결과는 하나의 4열 묶음에 대한 것이며 개별 심사 피처의 독립 기여나 인과효과를 분리하지 않는다.

연도별 주평가도 같은 정의로 계산했다.

| 평가연도 | 경주 수 | 기존 → 후보 log loss | 기존 → 후보 Brier |
|---|---:|---:|---:|
| 2024 | 90 | 0.638601 → 0.539296 | 0.223246 → 0.180798 |
| 2025 | 89 | 0.609900 → 0.500795 | 0.210404 → 0.162629 |
| 2026 | 73 | 0.643833 → 0.534132 | 0.225326 → 0.177219 |

같은 경주에서 Top3 양성/음성 무이력 말 쌍을 비교한 raw-score concordance는 118경주·398쌍에서 0.500000에서 0.752828로 올랐다. 정확한 raw-score 동률은 0.5로 계산했다. 이 진단은 보조값이며 통과 기준은 아니다.

전체 1,779경주에서 runner log loss는 0.568159→0.564087, Brier는 0.192256→0.190565였다. 경력마 보조 비교에서도 log loss 0.565444→0.564665, Brier 0.191127→0.190851이었다. 네 추가 열이 경력마에서 NULL이어도 새 후보의 pooled refit으로 경력마 raw score가 모두 달라졌다(16,751행, 평균 절대 변화 0.045090, 최대 0.383796). 따라서 경력마 점수나 가중치가 고정됐다고 해석하지 않는다.

주요 경주 보조 지표의 1,779경주 동일 평균은 최고 점수 말의 3위 이내 입상률 57.50%→58.46%, Top5 포착률 69.10%→69.66%, canonical 6조합 적중률 22.88%→24.68%(407→439경주)였다. Top5, 축(최고 점수 말), 삼복 계열 요약은 판별 보조값이다. 6조합도 두 말 평가 모델에 같은 기존 F1_STYLE6 점수 기반 생성 규칙을 적용한 비교이며, 별도 pair/order 헤드 모델을 재적합한 결과가 아니다.

첫 출전마가 포함된 동일 252경주만 보면, 같은 최대 6조합 규칙의 적중은 50/252(19.84%)에서 74/252(29.37%)로 24경주 늘었다. 이는 말 평가의 기본 조합 생성 규칙 비교이며 별도 pair/order 헤드를 재학습한 결과가 아니다.

## 결과 신뢰성과 한계

최종 평가기는 처음 실행 때 공유 merge-key를 suffix 열로 잘못 참조해 경주 보조표 단계에서 `KeyError`를 냈다. 그 시도는 후보 점수와 손실을 메모리에서 계산했지만 보고 파일을 쓰거나 결과값을 내보내지 않았다. 원인은 경주 비교표의 `year`/`distance_m` 공통 열 이름을 잘못 가정한 코드 오류였다. 실패 당시 lock/hash와 오류를 [실패 시도 감사기록](outputs/evaluation_failed_attempt_audit.json)에 보존했고, 수정은 보조표 그룹화 열 이름만 바꿨다. 피처, 점수, 지표, 모델, 파라미터, gate는 바꾸지 않았다. 수정된 고정 평가기는 한 번 완료했고 영수증 및 결과 SHA는 [evaluation report receipt](outputs/evaluation_report_receipt.json)에 있다.

이 비교는 saved F1_STYLE6 말 평가 기준선과의 후향 개발 코호트 비교다. 운영 모델인 HY_R_FORM과의 비교가 아니며 운영모델이나 DB는 수정·승격하지 않았다. observed_starts=0은 평생 첫 출전을 확인하지 않는다. 역사적 주행심사 정보의 T−2 시점 공개 여부는 알 수 없다. 따라서 결과는 미래 성능, 현장 가용성, 운영 적합성을 증명하지 않는다.

Root의 독립 검산은 17개 보호 아티팩트 불변, 기준·후보 각 17,412 runner/1,779 경주/10,674 canonical ticket의 수치 일치, 3,240 최근 심사 슬롯, 주평가·concordance·고정 예시를 확인했다. 추가 검산은 20개 runner scope, 144개 경주 진단, 4,000개 bootstrap 값과 12개 결과 해시를 재확인했다. 상세 내용은 [ROOT_REPORT_REVIEW.json](../20261018_debut_trial_rootreview_v1/ROOT_REPORT_REVIEW.json)과 [ROOT_REPORT_NUMERIC_ADDENDUM.json](../20261018_debut_trial_rootreview_v1/ROOT_REPORT_NUMERIC_ADDENDUM.json)에 있다.
