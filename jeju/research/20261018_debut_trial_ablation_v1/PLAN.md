# 첫 실전 전 주행심사 정보 추가 비교 계획

2026-10-18 사전 계획. 기준선은 `jeju/research/20261010_style_history_ablation_v1`의 저장된 `F1_STYLE6` 30입력 모델 세 개와 점수다. 첫 출전/관측 무이력 집단을 대상으로 주행심사 정보 한 묶음만 추가해 같은 경주에서 비교한다. 새 후보 학습은 원천 감사, 코드·입력 잠금 및 root의 명시적 fit 승인 전까지 실행하지 않는다.

## 모집단과 기준선

- 저장 F1_STYLE6 학습 코호트: 2017-01-13~2026-09-19, 52,155 출전·5,206경주.
- 평가 코호트: 2024~2026년 17,412 출전·1,779경주·269경주일. 2026년은 9월 19일까지의 부분연도다.
- `observed_starts == 0` 집단: 1,946 출전·1,946두·641경주 전체; 평가 구간은 661 출전·252경주 (2024: 224/90, 2025: 246/89, 2026: 191/73).
- 평가 집단의 거리 분포: 800m 415출전/135경주, 900m 238/110, 1000m 8/7. 첫 출전 비교를 1000m로 한정하지 않는다.
- 30개 기존 입력의 이름·값·행 순서·정답·연도별 train/early-stop/refit/calibration 경계는 F1_STYLE6 저장 자료와 정확히 맞춘다. 기존 세 모델은 재학습하지 않고 저장 가중치·meta·top3 결과·calibration/evaluation scores를 재현한다.
- 학습 코호트의 첫 출전 행도 새 입력을 받는다. 다만 모델 입력은 모든 `observed_starts > 0` 말에서 추가 열 전부 NULL이어야 한다. 무이력 말의 주행심사 기록이 없거나 유효 관측이 없으면 요약 평균은 NULL, 관측 수는 0이다.

## 사전 원천 확인과 피처 후보

API20 `ridingTestResult_1` 주행심사만 검토한다. API21 출발심사, 출발조교·일별조교, 현재 프로필 열은 입력에서 제외한다. 말 연결은 공식 `horse_id`만 허용하며 이름·마번으로 연결하지 않는다. 원천 감사가 확인할 이벤트 키, 같은 이벤트 roster, 중복 행, 유효 시간과 공식 제주 라벨 처리를 잠금 전에 고정한다.

기존 자료 요약은 API20 `rcTime`의 양수값이 초 단위이고, 저장된 명시 거리 `rcDist`는 0행이라고 보고한다. 따라서 원시 trial seconds의 평균이나 최솟값을 거리 불명 자료끼리 합치거나 실전시간에 보정해 넣지 않는다. 최종 후보는 같은 주행심사 이벤트 안에서만 계산한 상대시간 한 묶음으로 제한한다. 원천 감사자는 실제 이벤트 자연키 `(trainDate, meet=2, trainNo)`와 `daySerial` 불변성을 확인했으며, 전체 동일 이벤트 roster에서 정확한 제주 라벨·말 ID를 사용한다. 이벤트 정렬은 날짜·`trainNo`·source API row ID 순으로 잠그며 공개시각이나 당일 순서를 뜻한다고 해석하지 않는다.

잠정 계산안은 한 말의 가장 최근 실제 주행심사 이벤트 최대 3개에서, 각 이벤트 내 그 말의 양수 `rcTime`을 본인을 제외한 명시 `majong=제주` peer들의 양수 `rcTime` 중앙값과 비교한 단위 없는 상대값 `(horse_time − peer_median) / peer_median`을 계산하는 방식이다. 이벤트마다 비교 peer가 두 말 이상 있어야 해당 값이 유효하다. 최근 최대 3개 실제 이벤트 슬롯에 무효 항목이 있으면 그보다 오래된 이벤트로 대체하지 않는다. 추가 열은 다음 네 개를 검토한다.

| 잠정 입력 열 | 정의 |
|---|---|
| `trial_peer_relative_time_mean3` | 최대 3개 고정 최근 이벤트 슬롯 중 유효한 상대시간의 산술평균. 음수는 해당 이벤트 peer 중앙값보다 빠름. 유효 n=0이면 NULL |
| `trial_peer_relative_time_n3` | 평균에 포함된 이벤트 수, 0..3 |
| `trial_days_since_latest_event_pre` | T−2까지 등록된 가장 최근 주행심사 출주기록 날짜부터 경주일까지의 일수. 취소·무효 기록도 최신 기록으로 포함 |
| `trial_event_count_pre` | 검증된 공식 이벤트 키 기준 T−2까지의 주행심사 출주기록 수. 취소·무효 기록도 포함하며, 동일 말·이벤트 중복이 0건으로 확인된 자료에서 기록 수와 이벤트 수가 일치 |

네 열은 하나의 사전 고정 묶음이며 추가 변형·개별 열 선택·거리별 raw-time 후보를 만들지 않는다. 시간 신호는 유한 양수 `rcTime`, 정수 `ord` 1..89, 원천 감사가 고정한 공식 완료 판정이 모두 충족될 때만 유효하다. 93 등의 특수 순위는 제외하고, `ord`/`passFlag` 원문을 합격·불합격 서열로 해석하지 않는다. 87개가량의 취소·무효/시간부적격 기록은 최근 3개 등록기록 슬롯 및 기록 수·최신기록일에서 유지하고 유효시간 n에서만 제외한다. 원천 감사가 이벤트 키·동일 이벤트 peer roster·판정 상태를 검증하지 못하면 이 후보를 잠그지 않고 사유를 기록한다. `observed_starts > 0`에서는 네 열 모두 NULL이며, 주행심사 기록이 없거나 최근 3개 슬롯에서 유효 peer 신호가 없으면 평균 NULL·n=0이다.

## 시점·가용성

각 target 경주일의 T−2 한국 날짜까지 같은 날짜의 주행심사 사건을 포함하고 이후 날짜는 제외한다. 사건일은 공개시각이 아니다. 주행심사의 최초 공개·게시시각은 미확정이며 해당 날짜 컷오프만으로 당시 예측 시점 가용성을 입증하지 못한다. 결과는 이 제한을 가진 후향 개발 비교다. 원천 peer 기준은 API20 내 동일 trial event의 공식 제주 라벨·공식 ID로 한정하고, 경주 결과·현재 프로필·다른 API 종류를 보조 연결에 사용하지 않는다.

## 비교·평가 사전 고정

- 저장 F1_STYLE6 세 모델의 exact replay만 기준선으로 쓰며 재학습하지 않는다. 후보는 기존 30열과 위 네 열만 포함한 34열 단일 변형이다.
- 연도별 날짜·행·정답을 기준선 그대로 유지한다. 후보 fit은 2024/2025/2026 세 fold로 제한하며 기존 F1_STYLE6의 학습 설정·범주 처리·경주당 `1/field_n` 가중치·Top3 보정·additive Top3 확률 계산을 그대로 따른다. 최대 6 LightGBM train 호출과 3 temperature 최적화만 허용한다.
- 주평가 집단은 평가기간 `observed_starts == 0`의 252경주다. trial coverage가 없거나 유효 입력이 없는 무이력 출전도 주평가에서 제외하지 않는다. 각 경주에서 그 경주 내 무이력 말의 runner-binary Top3 log loss와 Brier를 평균한 뒤 252경주를 동일 가중한다. 차이는 `후보 − 저장 F1_STYLE6`이다.
- 공통 269일의 고정 bootstrap schedule `jeju/research/20261011_pair_top3_direct_v1/outputs/date_bootstrap_schedule.npy` (2,000×269, SHA-256 `d141b0c3f9a463cbfc9d1f4c61228b58757c31aee4ec74b79f41c5baeadaccbd`)를 유지한다. 해당 날짜에 무이력 평가 경주가 없으면 그 날짜는 분자·경주 수에 모두 0으로 기여한다.
- 17,412출전/1,779경주의 full cohort 손실은 보조 결과다. 축·Top5·삼복 최대 6조합도 보조 결과로 두며 사전 gate를 바꾸지 않는다. 연도/거리별 결과, 무이력 말의 심사 지원량과 무관측 사유를 함께 보고한다.
- 후보는 주평가 무이력 집단에서 두 손실의 점추정치가 모두 기준선보다 낮고, 적어도 하나의 날짜 paired 95% bootstrap 구간 상한이 0 미만일 때만 사전 gate를 통과한다. 전체 코호트와 `observed_starts > 0` 경험마만 따로 본 결과는 보조 진단이며 gate나 자동 승격 사유가 아니다. 후보 재적합은 경험마의 추가 열이 NULL이어도 모델 구조·파라미터를 바꾸므로 경험마 점수가 기준선과 동일하다고 주장하지 않는다.
- 사전 고정 보조 진단으로 경주 내 무이력마 간 raw-score concordance를 보고한다. Top3 정답 양성·음성 쌍에서 raw score가 높으면 1, 같으면 0.5, 낮으면 0을 주고 쌍 평균 후 eligible race를 동일 가중한다. 최소 한 양성·한 음성 무이력마가 있는 118경주·398쌍이 대상이며, 기준선 동점 concordance는 0.5다. 이 진단은 gate나 별도 적합을 추가하지 않는다.
- 사용한 기간은 과거 연구와 겹치는 개발 자료다. bootstrap 불확실성은 독립 미래 검증을 뜻하지 않는다. 임의 승격은 하지 않는다.
