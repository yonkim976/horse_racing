# 제주마 분석을 데이터부터 다시 시작하는 계획

기준일은 2026-09-28이다. 이번 작업은 기존 최종 후보 `HY_R_FORM`을 보존하면서 제주 자료를 사람이 검토할 수 있는 새 작업 공간으로 정리하는 단계다. 새 모델을 맞추거나 운영 모델을 바꾸지 않는다.

## 목표

새 연구 목표는 [우승축·착순·동반 후보 예측 목표](JEJU_PREDICTION_OBJECTIVES_2026-09-28.md)를 따른다. 우승축을 입상 안정마와 구분하고, 출전마 전체의 우승·Top2·Top3 및 정확한 2·3착 확률, 조건부 동반 후보와 공동 착순 분포 기반 승식 확률을 다룬다. 추천 5두에 실제 상위 3두가 포함되는 집합 목표도 포함한다.

기존 HY_R_FORM의 A(한 마리 입상 선택), B(상위 3두 집합), C(상위 3두 순서)는 기존 모델을 비교하는 평가 지표로 유지한다. 이를 새 목표와 동일시하지 않는다. HY_R_FORM의 내부 구조·확률 계산 및 저장 출력은 입력 감사에서 확인한 사실을 보존하며, 새 목표를 이미 구현했다고 간주하지 않는다. 기존 기준 가중치·점수·보정값과 운영 등록부는 변경하지 않는다.

## 지금까지 확정된 기준

- 선택 모델은 선언 변수 108개, 순서 모델은 68개를 받도록 설계됐다. 68개는 108개의 앞부분과 같다.
- 원입력에서 전처리된 차원은 각각 154열(99수치, 53결측표시, 시대 2열)과 83열(59수치, 22결측표시, 시대 2열)이다.
- 두 모델은 각각 8개 원입력을 학습 표본에서 상수여서 제외했다. 입력 선언 수, 변환 열 수, 실제 트리 분기 사용 수는 서로 다른 값이다. 상수 제외는 원천 값이 모두에게 실제로 같다는 뜻이 아니다.
- 최고 기준 가중치 파일은 `HY_R_FORM`이며 SHA-256은 `f1b9531e068cab51dff906961d56f51c7c4b0e5a86f378c9aa1f03f159ec9706`이다. 상세 목록은 [모델 입력 감사](JEJU_FINAL_MODEL_INPUT_AUDIT_AND_REBUILD_PLAN_2026-09-28.md)를 본다.
- 기존 2026-01-02~09-12 평가 510경주는 이미 확인된 기간이다. 같은 경주와 경주일은 재분석하더라도 새 독립 검증이 되지 않는다.
- 새 자료 수집은 요구하지 않는다. 현재 분석 상한은 2026-09-12다. 시장 배당·인기 입력, 영상 및 당일 정보 연결은 현재 범위 밖이다. 새 목표 평가에는 목표별 말 확률과 공동 착순 분포가 필요하다.

## 데이터 우선 진행

1. **평가 계약 고정:** 우승·Top2·Top3, 정확한 착순, 동반/조합 사건, 동착, 출전집합, 경주 단위, 시점·T−2 정책을 명시한다. 기존 A/B/C는 비교 지표로 별도 둔다.
2. **원천 목록과 품질 확인:** 각 출처의 범위·단위·말/경주 키·공개시각·적재시각을 확인한다. 종별 혼합, 오연결, 시간 역전, 중복, 누락과 격리 이유를 기록한다.
3. **저장 입력 재현:** `HY_R_FORM`의 108/68 입력을 원천까지 추적한다. 이름·단위·집계 기준과 피처 생성 시점이 맞는지 검토한다. 모델이 받은 과거값과 신규 분석 자료를 하나로 덮어쓰지 않는다.
4. **가설별 자료표 작성:** 같은 거리 기록, 구간 측정 지점·거리, 초반 경쟁과 종반 수행, 주로·편성, 부담중량·과거 체중, 조교·진료·심판 사건을 표본 수와 결측 상태부터 본다.
5. **반례와 불확실성 제시:** 직접 관측, 대용치, 해석, 가설, 현재 데이터로 알 수 없는 것을 분리한다. 단일 변수의 연관성을 원인이나 예측 개선이라고 단정하지 않는다.
6. **제한된 비교:** 자료 정의·가용 시점 감사 후에만 피처 묶음의 추가 정보를 새 목표별로 비교한다. 기존 A/B/C와 기준 모델 비교 결과도 보존한다.

기존 자료의 기간을 여러 연구에서 사용했으므로 결과는 후향 개발 분석이다. 시간 분할을 달리하거나 새 변수 설명을 붙였다는 이유로 독립 검증 표본이 생기지 않는다. 새로운 독립 검증이 필요한 경우에도 과거 자료 분석을 위해 새 데이터나 서비스 연결을 필수 조건으로 만들지 않는다.

## 분석·학습 진행 전 게이트

- 대상 경주일보다 뒤에 게시되거나 정정된 정보를 입력으로 사용하지 않았음을 근거로 확인한다. 날짜만 있고 게시 시각이 없으면 가용성을 가정으로 표시한다.
- 말 ID와 경주·출전 ID를 교차 확인한다. 이름 유사 일치와 현재 소속을 과거에 소급하지 않는다.
- 수치 변수는 원천 단위, 환산식, 기준집단을 확인한다. S1F 200m, S1F210, 주파시간을 같은 종류의 시간으로 혼합하지 않는다.
- 학습·보정·평가는 경주일 단위 시간 순서로 나누고 같은 경주의 출전마를 분리하지 않는다. 테스트 기간을 본 뒤 피처·경계·모델을 조정하면 개발 자료로 분류한다.
- 여러 번 확인한 기간에서는 단일 최고값 대신 경기일 단위 불확실성, 우승·Top2·Top3 확률 품질, 우승축·동반 후보·추천 5두 집합·조합 평가, 기존 A/B/C 비교, 연도별 변화 및 반례를 보고한다.
- 모델 학습은 자료 감사의 질문에 답하는 최소한의 사전 비교만 수행한다. 이 기록만으로 운영 모델을 자동 교체하지 않는다.
