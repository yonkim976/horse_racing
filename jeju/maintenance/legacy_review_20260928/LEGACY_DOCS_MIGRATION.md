# 제주 구형 연구 문서 정리 안내

구형 제주 실험 보고서와 복제 연구 증거는 현재 `jeju/` 작업공간 정리에서 제거한다. 운영 추론 기준은 `scripts/predict_jeju_live_hy_r_form.py`, `config/prediction_model_registry.json`, 그리고 HY_R_FORM 동결 번들이다. 선택 모델 및 입력 감사 자료는 `jeju/docs/JEJU_FINAL_MODEL_INPUT_AUDIT_AND_REBUILD_PLAN_2026-09-28.md`와 `jeju/docs/JEJU_HUMAN_ANALYSIS_FRAMEWORK_2026-09-28.md`에서 시작한다.

원천 수집·ID 연결·자료 계보 기록과 현재 평가 register는 root `docs/JEJU_*.md`에 남겼다. hash로 확인한 제거 내역은 `deletion_receipt.json`에, 남은 정리 후보와 보존 자산은 `approved_remaining_v3.json`에 기록했다.
