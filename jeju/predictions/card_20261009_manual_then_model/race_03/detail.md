- 모든 기록행은 부담중량·기수초과·과거 체중·주로·당시 기수·필드 수와 출처를 보존했다. API section time의 `api_positive_unreviewed`는 홈페이지 검증 완료가 아니며 추정 보정도 하지 않았다. 충돌/보류는 NULL+상태, 미사용 구간의 0은 결측. 통과조 괄호 안 순서를 개별 순위로 변환하지 않았다.
