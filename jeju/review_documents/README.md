# 제주마 DB 통합 점검 문서함

2026-10-20 자동 갱신 설치 완료: **[매일 22시 Mac launchd 설치·실제 실행 검증](../research/20261020_launchd_install/README.md)**. 설치된 서비스를 실행해 종료 코드 0을 확인했고 API 142페이지·홈페이지 14페이지와 기존 42개 테이블·2,827,050행의 보존을 검증했다. 일별조교 314행·진료 23행·프로필 관측 12행을 추가했다. 기존 Codex 예약은 삭제했으며 새 갱신은 로컬 스크립트로 실행한다.

2026-10-18 측정 정의 후속 확인: **[제주 1110m S1F는 210m](../research/20261018_s1f_measurement_official_review/README.md)**. 공식 제주 경주성적표 용어해설이 1110m·1610m의 S1F를 출발 후 210m로 명시한다. API6 첫 110m 펄롱타임과 별개이며, 이전의 ‘210m 미확정’ 설명을 정정했다. 이 확인은 DB 시간·순위 변경이 아니다.

2026-10-18 최신 구간 실제 반영은 **[10월 17일 구간상세·통과조 적재 및 5R 거리 정정](../research/20261018_oct17_section_load/README.md)**이다. API6·API303 각 7경주와 홈페이지 거리 검토 6칸을 추가했다. API 원문을 보존하고 새 `api6_section_points_current`에서 5R의 홈페이지 거리 110~1110m를 조회한다. 실제 경주거리 1110m와 API6 마지막 거리 칸 1100m는 서로 다른 필드다. 다른 기존 1110m 18경주는 API 원값을 유지하며 [과거 이력 감사](../research/20261018_oct17_section_load/history_audit/README.md)에 범위·건수를 구분했다. 앞선 읽기 전용 조사와 실제 적용 원장을 구분한다.

2026-10-18 후속 확인: **[고정 기준 DB 삭제·복구 가능성 및 10월 17일 구간 검토](../research/20261018_baseline_recovery_review/README.md)**. 고정 기준 파일은 10월 17일 저장공간 정리 원장에 명시된 삭제이며, 최근 롤링 백업은 정상이나 옛 고정 원본과 다른 시점이다. 휴지통 접근 제한 등 복구 조사 한계를 기록했다. 10월 17일 7경주·69두의 홈페이지 구간상세·통과조가 확인됐고 API6·API303도 10월 18일 재조회에서 각 7행을 제공한다. 5경주(1110m)의 API6 거리 6칸은 홈페이지보다 각각 10m 작아 출처 차이 후보로 보존했다. 이 검토는 DB 복원·정정·추가 적재를 실행하지 않았다.

조교 분류의 최신 실제 반영·검증은 **[2026-10-17 과거 일별조교 기승자 전수 보완 완료](../research/20261017_older_training_rider_completion/README.md)**다. 먼저 확인한 609행과 전수 대조의 추가 185,819행을 합쳐 주로조교 186,333행·교육생 95행을 반영했다. 공식 4,122일 전부 수집·독립 검증 완료이며, 과거 미분류 94,532행과 최근 대상 523행을 포함해 전체 미분류는 95,055행이다. 41개 테이블 보존·재실행 검증도 완료했다. 아래 수치는 각 단계 당시의 스냅샷이다.

과거 미분류의 후속 원천 조사는 **[2026-10-17 과거 일별조교 공식 보완 원천](../research/20261017_older_training_rider_sources/README.md)**에 있다. 날짜별 전체 상세의 과거 조회를 실제 확인했고 표본 609행의 주로조교 근거를 검증했다. 이 조사는 DB 적재와 구분하며 구형 미정 약어와 시간 결측의 한계를 기록했다.

최신 실제 반영은 **[2026-10-17 조교 기승자 홈페이지 보완·DB 반영](../research/20261017_training_rider_website_completion/README.md)**이다. 최근 미분류 20,408행·913두를 대조해 19,885행을 주로조교로 보완했고, 확인되지 않은 523행은 미분류로 유지했다. 전체 미분류는 281,483행이다. 이전 조사·초기 분류 보고서의 수치는 당시 스냅샷이다.

최신 미분류 원인·보완 범위는 **[2026-10-17 기승자 미분류 기간·홈페이지 재확인](../research/20261017_training_rider_unclassified/README.md)**에 있다. 최신 DB 301,368행의 미분류 분포와 홈페이지 8두·587행 직접 대조를 담았다. 추가 확인은 DB 분류 적용과 구분하며 [10월 15일 조사](../research/20261015_training_rider_unclassified_review/README.md)도 보존한다.
