# 제주 일별조교 사번의 공식 홈페이지 이름 대조

조사일: 2026-10-15 (KST)

## 결과

공식 KRA 말별 조교 페이지에서 제주 API18 원행과 말 ID·조교일·입장시각·퇴장시각·조교시간(분)이 모두 일치하는 관측을 확보했다. 이 exact-event 연결은 API18의 `prNo_raw`를 홈페이지 `기승자` 셀의 실명과 연결하는 근거다. API18 원래 구분값은 모두 `-`였으며 그대로 보존했다. 이 결과만으로 `-`를 기수·조교사·관리사 역할로 재분류하지 않는다.

- 최근 6개월 범위의 미연결 대상은 56개 사번, 19,514개 완전시각 API18 행, 851개 말이었다. 대상 정의는 `prGubun_raw='-'`이고, 보유 제주 기수 API307·조교사 API308 ID와 정확히 같지 않은 사번이다.
- 말 프로필 32페이지를 수집했고 32페이지 모두 HTTP 200, 응답 원문 SHA-256 확인, 페이지 상단 말 ID·마명 및 조교표 확인에 성공했다. 페이지 제한은 100개였고 병렬 요청은 최대 3개였다.
- 1,259개 API18 원행 관측이 말·날짜·시각·분 단위 조교시간까지 정확히 일치했다. 그중 1,236행은 이름이 있는 관측이며 50개 사번 각각 서로 다른 말/날짜에서 2회 이상 같은 이름으로 확인됐다. 이름이 여러 개인 사번이나 정확한 이벤트 키가 여러 사번과 충돌한 건은 없었다.
- 5개 사번(`006045`, `006077`, `006078`, `006079`, `006080`)의 23개 정확일치 관측은 홈페이지 기승자 칸에 `외`만 표시했다. 이를 사람 이름이나 역할 코드로 해석하지 않았고, 이름 미제공 관측으로 보존했다.
- `005319`는 대상 범위에 API18 완전시각 행이 한 건뿐이고 그 날짜가 2026-04-15다. 대응 말 페이지에서 정확일치를 찾지 못해 미확정으로 남겼다. 최근 6개월 경계와 관련 있을 수 있으나 원인이라고 단정하지 않는다.
- 별도 `조교보` 21개 사번 47,620행과 `조교승인` 41개 사번 84,580행은 최종 관측일이 모두 2021-12-09다. 현재 말별 홈페이지가 최근 6개월 자료만 제공해 이 오래된 행들은 이번 대조에서 이름을 확인하지 못했다.

## 공식 페이지와 확인한 범위

페이지 주소 형식:

`https://race.kra.co.kr/racehorse/profileTrainState.do?Act=02&Sub=1&hrNo=<말ID>&meet=2`

페이지는 말 ID와 현재 마명을 표시하고 `조교일자`, `기승자`, `입장시간`, `퇴장시간`, `조교시간` 표를 제공한다. 화면 안내는 최근 6개월 자료로 범위를 제한한다. 표시된 범례는 `이름`을 기수명, `조`를 조교사, `관`을 주로조교, `생`을 교육생으로 설명하며 `이름(트)`는 기수 트랙라이더로 표시한다. 이름 뒤의 `(관)` 등은 원문에 보존하고 person name과 코드로 분리했다. 범례에서 의미를 확인하지 못한 `외`는 원문 토큰만 보존했다.

조회 URL에서 별도 날짜 필터나 과거 페이지 탐색 파라미터는 확인하지 못했다. 2026-04-15 이전 기록, 페이지가 공개하지 않는 사람 이름, `외` 토큰의 뜻은 이 자료로 확정할 수 없다. 홈페이지의 날짜만으로 API18 행에 연결하지 않았으며, 날짜와 시각만 일치하는 근사 연결도 만들지 않았다. 홈페이지 시각에서 종료-시작이 표시 조교시간과 같고 API18의 `duration_seconds`가 그 분값의 60배인 경우에만 증거로 채택했다.

대표 세 행은 다음과 같이 원행과 일치한다.

| 사번 | 말 ID | 날짜 | 홈페이지 기승자 원문 | 이름 | API18 입장–퇴장 | 홈페이지 시각·분 |
|---|---:|---|---|---|---|---|
| `005002` | `3104703` | 2026-09-28 | `김경태(관)` | 김경태 | 06:30:00–06:43:00 | 06:30–06:43, 13분 |
| `005003` | `3104301` | 2026-09-28 | `한태경(관)` | 한태경 | 06:41:00–06:47:00 | 06:41–06:47, 6분 |
| `005027` | `3104105` | 2026-09-27 | `이유근(관)` | 이유근 | 07:40:00–07:58:00 | 07:40–07:58, 18분 |

세 행 모두 API18 원래 구분 `-`를 보존한다. `(관)`은 홈페이지가 설명하는 주로조교 코드이므로 이 관측은 기수 경기 출전이나 기수 역할을 뜻하지 않는다.

## 보유 API 원천과 한계

- [KRA 기수 정보 API307](https://www.data.go.kr/data/15056828/openapi.do), API endpoint `/B551015/API307/jockeyInfo`: 보유 원문 및 수집 기록은 `data/research/jockey_roster_20261008/`에 있다. 제주 기수 ID/이름 명부 대조에 사용했다.
- [KRA 조교사 정보 API308](https://www.data.go.kr/data/15130588/openapi.do), API endpoint `/B551015/API308/trainerInfo`: 보유 원문은 `data/raw/kra_trainer_affiliations/2026-09-29/meet_{1,2,3}.json`에 있다. 조교사 번호·이름·소속/기간 정보를 대조했다.
- [기수 일일조교일자 API234](https://www.data.go.kr/data/15089697/openapi.do), API endpoint `/B551015/jktrdate/getjktrdate`: 일자별 기수 조교 집계·기수명을 제공하지만 이 조사에서 확인한 명세상 말별 행에 등장하는 직원 사번 전체의 이름 명부는 아니다.

이번 공식 카탈로그 검토에서 관리사·조교보 등 일별조교 직원 사번 전체를 이름에 연결하는 별도 공개 직원명부 API는 찾지 못했다. API307/API308 ID와 다른 사번은 그 차이만으로 역할을 단정할 수 없다. 말별 페이지 대조는 해당 ID가 정확히 일치하는 시점에 홈페이지에 표시된 이름을 증명할 뿐, API18의 `-` 구분을 소급해 해석하지 않는다.

## 산출물과 재검증

- `collect_kra_training_html.py`: 기본 실행은 읽기 전용 DB에서 수집 계획만 만든다. `--fetch`는 고정된 `race.kra.co.kr` 말 프로필 주소만 조회하고, `--parse-only`는 저장한 원문을 재파싱한다. 인증키를 사용하지 않는다.
- `collection_plan.json`, `profile_collection_plan.csv`, `unlinked_recent_id_scope.csv`: 56개 ID 범위와 32개 페이지 선택 계획.
- `http_collection_manifest.json`: 각 HTTP 응답의 URL·상태·크기·SHA-256·저장 경로 및 실패 기록. 이번 실행은 성공 32, 실패 0.
- `raw_html/`: 응답 바이트 그대로 보관한 공식 KRA HTML. 본문 SHA-256을 manifest와 대조했다.
- `staff_website_identity_evidence.json`: 정확일치 행 전체, ID별 이름 미확정 상태, role-token-only 관측과 페이지별 원문 provenance. `start_time_local`/`end_time_local`은 DB 원행의 전체 시각이고 `website_start_time_local`/`website_end_time_local`은 홈페이지의 시계 표시다. `person_name`이 없는 정확일치도 증거 배열에 남고 별도 `unresolved_observations`에도 분리된다.

다시 계획을 만들 때:

```sh
python3 jeju/research/20261015_training_rider_identity/source_review/collect_kra_training_html.py
```

저장된 원문으로 다시 검증할 때:

```sh
python3 jeju/research/20261015_training_rider_identity/source_review/collect_kra_training_html.py --parse-only
```
