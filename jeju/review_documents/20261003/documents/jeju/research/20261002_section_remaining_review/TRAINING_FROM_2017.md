# 제주 2017년 이후 학습 구간 품질 검토

2026년 10월 2일 확인 결과, 남은 항목이 모두 2017년 이전 자료에 있는 것은 아니다. 2017-01-01부터 정답 학습 표본을 구성하면 2002년 결측·구형 표기·API303 지점 대응 문제는 정답 표본에서 제외되지만, 2017년 이후 통과순위 충돌·API6 누락은 남는다. 홈페이지 순위 정정 14개는 10월 3일 DB에 반영했다. 알려진 충돌 필드를 차단하고 확인된 정정값·결측 처리 계약을 적용하면 학습 자료를 구성할 수 있다는 데이터 품질 판단이다. 모델을 학습하거나 성능 영향의 허용 한계를 측정한 결론은 아니다.

## 분모와 크기

현재 제주 후보 원장의 2017-01-01~2026-09-19 구간은 5,901경주·59,042출전행이다. 유효 착순 1~89와 양수 완주시간이 있는 후보가 최소 하나 있는 경주는 5,828개이며, 그 조건을 만족하는 출전행은 57,850개다. 실제 학습 모집단은 출전집합·마종 유효시점·동착·예외 결과 계약을 적용한 뒤 확정해야 한다.

- 미확정 순위 충돌 18경주 / 5,828경주 = **0.309%**.
- API6 누락 6경주 / 5,828경주 = **0.103%**.
- 순위 충돌 18경주의 전체 후보 행은 177행으로, 후보 59,042행의 **0.300%**다. 그중 유효 완주행은 176행이다. 이것은 해당 필드를 차단할 범위의 크기를 보여주며 경주 전체 삭제가 필요하다는 뜻은 아니다.
- 순위 충돌 18경주·홈페이지 순위를 정정한 2경주·API6 누락 6경주의 합집합은 26경주·253행이다. 이는 최초 관측 범위이며 현재 미정정 오류 개수가 아니다. 광해청명 미확정 시간은 이 집합 안에 있다. 이미 정정한 2024-03-02 시간 사례와 측정 정의 미확정 666관측 등은 이 집계에 추가하지 않았다.

이 수치는 이미 발견한 항목의 비중이다. 전체 DB의 실제 오류율이나 모델 성능 저하의 상한이 아니다. 과거값이 이후 여러 피처에 재사용되면 원문 1필드의 영향이 여러 학습행으로 퍼질 수 있다. 연도·거리·등급·말별 집중도와 파생값 영향은 별도다.

## 최종 착순 정답과 구간 피처의 구분

2017년 이후 위 26경주의 전체 출전표 253행을 공식 홈페이지와 추가 대조했다. 홈페이지의 최종 숫자 착순 252행은 API와 모두 일치했고, 253행의 1~3위 여부에도 차이가 없었다. 나머지 1행은 2025-11-01 5R 2번(3018812)으로 API 결과코드 92·홈페이지 최종 착순칸 공란이다. 공란을 숫자 착순으로 만들지 않는다. 이 검사는 해당 경주의 기본 정답 후보를 보존할 근거이며, 전체 기간의 정답 검증이나 동착·출전집합 계약을 완료했다는 뜻은 아니다.

## 학습 자료 구성 판단

1. **최종 결과가 확인된 경주의 기본 학습 정답은 유지할 수 있다.** 취소·불성립, 동착·특수결과, 완전한 출전집합은 별도 계약을 적용한다. 최종 정답이 틀린 것으로 확인되면 정정 또는 경주 단위 제외가 필요하다.
2. **확인된 홈페이지 정정값을 사용한다.** 기존 시간 3건의 정정과 광해청명 G1F NULL은 유지한다. 순위 14개는 DB에 반영했으므로 `jeju_race_postrace_sections_reviewed_2026`의 선택된 순위와 상태를 사용한다. 원문 순위로 정정을 우회하지 않는다. [실제 적용·검증 내역](<../20261002_section_order_website_load/README.md>).
3. **정답 미확정 구간 필드만 결측으로 차단한다.** 2026-10-03 전체 미해결 19경주의 순위 70개·통과조 20지점을 품질 조회에서 NULL로 반영했다. 그중 2017년 이후는 18경주다. 현재 `jeju_race_postrace_sections_quality_2026`를 사용하며 광해청명 G1F 시간도 NULL이다. 개별 순위와 그룹 중 어느 쪽이 맞는지 선택하지 않는다. 관련 시간·상대 순위·경쟁마 집계도 해당 지점의 일관성이 확인되기 전 제한한다. [보류 반영·검증](<../20261003_unresolved_section_review/README.md>).
4. **API6 미제공은 경주 전체 상세 구간만 결측 처리한다.** 별도로 확인된 API4 말별 기록까지 일괄 폐기하지 않는다. 0초·평균 추정값으로 보충하지 않는다.
5. **측정 의미가 미확정인 항목은 의미를 가정한 파생식에서 제외한다.** 특히 1300m S1F/2C 표시 순서를 실제 주행 순서로 단정하지 않는다.
6. **같은 경주의 사후 기록을 그 경주의 사전 피처로 넣지 않는다.** 과거 이력도 대상 예측시점 이전 공개 자료로 제한한다. 전처리·변수선택은 학습 구간에서 정한다. [scikit-learn 누수 안내](https://scikit-learn.org/stable/common_pitfalls.html#data-leakage).

결측을 처리하는 학습기로 모델을 구성할 수 있지만, 이는 잘못된 양수값을 그대로 사용해도 된다는 뜻은 아니다. 예를 들어 [HistGradientBoosting 결측 지원](https://scikit-learn.org/stable/modules/ensemble.html#missing-values-support)은 NaN 처리 방식을 제공한다. 사용자 데이터에서 성능 손실이 허용 가능한지는 별도 검증이 필요하다.

## 2017년 이전 과거 이력을 사용할 때

정답 학습 시작일과 이력 조회 시작일은 다르다. 2017년부터 학습하더라도 2016년 이전 경주를 최근 기록·평균·Elo 등에 연결하면 과거의 잘못된 값이 들어올 수 있다. 따라서 기본 결과 이력과 구간·통과조 이력을 따로 검사해야 한다.

구형 상세 기록을 사용할 필요가 없다면 초기 구성에서는 상세 구간 이력을 2017년 이후 검증 자료로 제한할 수 있다. 과거 이력이 관측되지 않은 말을 신마 또는 출전 0회로 만들지 않는다. [2017년 코호트 이력 연결 검토](<../../docs/JEJU_2017_COHORT_PREHISTORY_LINKAGE_2026-09-29.md>)는 이전 원천 기반의 가용성 검토이며 현재 API 원장의 학습 모집단을 확정하는 결과가 아니다.

## 성능 영향 확인 방법과 남은 한계

학습을 별도로 진행할 때는 동일한 경주일 단위 시간 분할·동일 평가 경주에서 다음을 비교한다.

- 기본 성적·조건만 사용한 기준선.
- 확인된 정정값과 미확정 필드 결측 처리를 적용한 구간 이력 추가.
- 위 방식에 더해 알려진 충돌 경주를 학습 이력에서 제외한 민감도 비교. 평가 경주를 임의로 바꿔 점수를 높이지 않는다.

우승·Top2·Top3의 log loss·Brier·확률 보정 및 연도·거리별 변화, 경주일 단위 불확실성을 비교한다. 시간 자료는 미래 구간에 대한 평가가 필요하다. [scikit-learn 시계열 평가 안내](https://scikit-learn.org/stable/modules/cross_validation.html#cross-validation-of-time-series-data).

현재는 실제 모델 학습·피처 재생성·성능 비교를 실행하지 않았다. 따라서 **2017년부터 학습하는 설계는 가능하지만, 발견된 오류를 그대로 허용해도 성능이 괜찮다는 검증은 아직 없다.** 이번에는 읽기 전용 집계와 문서화만 수행했고 DB·운영 모델·학습 기간 설정을 변경하지 않았다.
