# 출발심사 공식 홈페이지 역사조회 조사

## 결과

공식 출발심사 결과 페이지는 날짜별 결과 목록을 과거 방향으로 넘길 수 있다. 저장한 첫 두 목록 페이지는 각각 10개 결과일을 담고, 2026-09-30부터 2026-07-19까지 20개 결과일과 상세 차수 링크 44개를 보여준다. 상세표는 날짜와 차수마다 별도 POST로 열며, 말 ID는 상세표 행의 `javascript:goPage1('<말ID>', ...)` 링크에 있다.

캡처한 목록 HTML의 검색 폼에는 연도·월·일 조건이 없고 `pageIndex` 페이지만 있다. 페이지는 최근 기록부터 이어지는 것으로 확인했지만, 마지막 페이지, 최초 보존 연도, 2002년까지의 실제 연결 여부는 확인하지 않았다. 따라서 2002~현재 전수 목록 완결성을 주장할 수 없다.

두 페이지 표본의 빈도를 2002년부터 현재까지 외삽하면, 10개 결과일/목록 페이지 기준 목록 약 250회, 페이지당 약 22개 차수 상세 기준 상세 약 5,500회 요청이 필요하다. 이 값은 2026년 여름 표본에 근거한 규모 추정이며 과거 시행빈도·홈페이지 보존 하한·호출 실패율은 반영하지 않는다. 이 조사에서는 역사 상세를 1건(차수 한 개)만 표본 보존했고 나머지 상세 호출은 진행하지 않았다.

이 경로는 API21_1 권한이 복구될 때까지의 임시 검증·보완 후보이다. API21_1은 동일한 서비스 키에서 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`(HTTP 403, 코드 30)를 반환했고, API42는 정상이라는 기존 진단과 일치한다. 홈페이지 표본으로 API 원천의 실패를 대체하거나 API 권한 문제를 해결했다고 보지 않는다. DB 쓰기는 없었다.

## 보존물

- `raw/list_pages/page_0001.html`: 기존 공식 홈페이지 검증 폴더의 목록 원문을 바이트 그대로 복사.
- `raw/list_pages/page_0002.html`: 공식 목록의 `pageIndex=2` 응답 원문.
- `raw/detail_pages/20260823_1.html`: 2026-08-23 결과표 1차 상세 원문 표본.
- `derived/listing_rows.jsonl`, `derived/detail_rows.jsonl`: 원문 행 위치, 말 ID 링크, 원문 필드 및 원문 크기·SHA-256을 연결한 파싱 결과.
- `derived/parse_summary.json`: 로컬 파서 집계.
- `manifest.json`: 조회 조건, 아티팩트 해시, 요청량 추정, 중단 지점과 최근 66행 교차검증 참조.
- `build_probe_records.py`: 네트워크를 사용하지 않고 보존된 원문만 다시 파싱하는 재현 스크립트.

원문 상세에서 보존한 필드는 날짜, 차수, HTML 표 행 위치, 말 ID 및 그 ID 링크의 `href`/`onclick`, 마번, 마명, 심사 사유, 성별, 나이, 기수, 조교사, 마주, 판정, 불합격 사유다. 파싱되지 않는 행은 버리지 않고 원문 HTML에 남긴다.

## 최근 66행 대조

기존 `../website_validation/` 검증은 2026-09-13~09-30 5개 날짜의 66행과 공식 목록·상세 원문 14개를 보존했다. 14개 SHA-256이 확인됐고, 각 날짜의 상세 행 수가 목록 출전 두수와 일치했다. 66행 모두 공식 말 ID 링크가 있으며 고유 ID는 40개다. 판정은 합격 39, 불합격 15, 1차합격 12였다. 최초 검증 당시 기존 프로필에 연결된 36행 외에 30행이 로컬 프로필 미연결로 표시됐지만, 후속 API42 직접조회에서 해당 30행에 해당하는 신규 말 ID 21개가 모두 정확한 프로필과 `제주마` 품종으로 확인됐다. 이에 따라 현행 말 프로필 제주마 근거는 66/66행이며, 과거 심사 당시 마종 확정과 DB 적재를 뜻하지 않는다. 상세의 목록 수와 합격 수는 `1차합격`을 합격 수에 넣지 않는다는 점도 검증 보고서에 기록돼 있다. 이 결과는 홈페이지와 API21_1의 동일성 검증이 아니라 홈페이지 파서·목록 링크 및 말 ID의 API42 대조이며, `website_validation` 원문은 수정하지 않았다.

## 재개 기준

현재 완료 체크포인트는 목록 2쪽이다. 다음 목록 후보는 `pageIndex=3`이며, 목록 페이지마다 요청 1건과 상세 차수마다 요청 1건을 예상한다. 재개할 때는 고정된 `https://race.kra.co.kr` 공식 호스트만 사용하고, 각 응답 바이트를 페이지별로 즉시 보존한 뒤 SHA-256·수집시각·요청 파라미터·행 위치를 manifest에 기록한다. 목록 원장을 먼저 끝내야 최초 게시일과 총 요청량을 계산할 수 있다. 목록 원장 전체를 확인하기 전에는 상세 전수를 시작하지 않는다.

지금 표본에서는 20개 결과일 44차수 중 상세 1차수만 보존했으므로, 표본 목록에서 대기 중인 차수는 43개다. 앞으로 상세를 재개하는 경우 `(date, round)`로 이미 수집된 항목을 건너뛰고, 매 요청 후 manifest 체크포인트를 갱신해야 한다.
