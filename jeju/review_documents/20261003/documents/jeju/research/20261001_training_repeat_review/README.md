# 제주 조교 반복 기록 추가 검토

2026년 10월 1일 보유 원문을 다시 분류하고, 공식 제주 출발조교 날짜별 전체 표를 표본 대조했다. API22에 조교장소가 없어 서로 다른 400M·800M 출발지점 기록이 같은 내용으로 나타나는 사례가 확인됐다. 원문 전체의 오류 중복 여부를 확정한 결과는 아니다. 원천 삭제와 DB 변경은 하지 않았다.

## 원문 전수 분류

일별조교 API18 1,444,319행에는 동일 말 ID·날짜 반복이 없다. 출발조교 API22 295,471행에는 완전 동일 내용 4,205그룹이 있고 각 그룹은 두 item이다. 이 중 보유 제주마 ID에 연결되는 그룹은 3,299개이며, 사용자가 확인한 백두명성 ID 3107491을 제외하면 3,298개다. 이 수는 오류 중복 건수나 실제 시행 횟수가 아니다.

백두명성을 제외한 보유 제주마의 서로 다른 내용이 있는 말·날짜 그룹은 2,559개다.

| 달라지는 필드 | 그룹 수 |
|---|---:|
| 기승자만 | 2,221 |
| 비고만 | 186 |
| 기승자와 비고 | 128 |
| 소속조와 조번 | 24 |

같은 말·날짜 네 행 사례 세 그룹은 위 분류와 동일 내용 그룹 양쪽에 포함되므로 분류 수를 단순 합산하지 않는다. 그 외 같은 말·날짜 반복은 두 행이다. 제주마 동일 내용 그룹 중 기승자 부재 4, 마명 부재 28, 소속조·조번 부재 9그룹이 있으며 부재를 채우거나 자동 합치지 않는다.

## 공식 홈페이지 추가 대조

공식 표는 소속조, 조번, 마명, 기승자, 조교장소, 비고를 제공한다. API22에는 조교장소가 없다. 홈페이지의 마명만으로 과거 말 ID를 자동 연결하지 않고, 이번 대조는 날짜·당시 마명·소속조·조번·기승자·비고를 함께 확인한 표본 검증이다.

API의 페이지 경계에서 동일 내용이 반복된 여섯 그룹 모두 홈페이지에 두 행이 있고 조교장소가 400M·800M으로 달랐다.

| 날짜 | 당시 마명 | 말 ID |
|---|---|---|
| 2016-12-14 | 천문조 | 3016391 |
| 2019-10-16 | 대지비상 | 3018188 |
| 2021-01-06 | 대천대세 | 3017821 |
| 2023-03-15 | 청마대전 | 3102278 |
| 2023-02-08 | 기탄 | 3102296 |
| 2026-08-12 | 위하여 | 3107304 |

2014-12-24 해파랑(ID 3014942)의 동일 내용 두 item도 홈페이지의 800M·400M 기록과 대응한다. API 비고 '-'는 홈페이지 공란이며 양호로 변환하지 않는다.

2026-09-16 백두명성은 홈페이지 800M·400M 두 행이다. 동백천하와 수사대도 각각 두 행이며 기승자와 조교장소가 함께 다르다. 따라서 같은 날 반복과 내용 일치를 오류 중복으로 단정할 수 없다.

## 네 행과 두 행이 불일치한 사례

| 날짜 | 당시 마명 | 말 ID | 보유 API item 수 | 홈페이지 행 수 |
|---|---|---|---:|---:|
| 2024-01-17 | 별마로 | 3103304 | 4 | 2 |
| 2024-01-17 | 서부검객 | 3102101 | 4 | 2 |
| 2024-01-17 | 아연로 | 3103797 | 4 | 2 |

각 말의 API는 소속조·조번이 있는 두 item과 해당 필드가 없는 두 item이다. 홈페이지는 각각 400M·800M 두 행이다. 보유 API와 현재 홈페이지의 행 수 불일치를 확인했지만, 필드 부재 item이 생긴 원인과 각 item의 사건 대응은 미확정이다. 네 행을 네 차례 시행으로 집계하지 않고 원천 이상 후보로 표시한다. 원문은 모두 보존한다.

## 확인 범위와 다음 검증

원문 반복 분류는 전수, 공식 홈페이지 대조는 위 사례의 표본이다. 나머지 모든 동일 내용 그룹을 공식 홈페이지에서 확인한 것은 아니다. 현재 기록 수를 실제 출발조교 횟수로 입력하거나 동일 내용 그룹을 일괄 삭제하지 않는다. API를 기본 수집원천으로 유지하며 홈페이지는 별도 대조 근거로만 사용한다. API330은 이번에 호출하지 않았다. 조교자료는 기존 DB에 적재하지 않았다.

[API 입력 계약](<../../docs/JEJU_TRAINING_API_INPUT_CONTRACT_2026-10-01.md>)과 [기존 전수 감사](<../20261001_training_audit/README.md>)의 원문 보존 기준을 유지한다. 공식 홈페이지 대조 행과 조회 URL은 동봉 JSON에, 조회 HTML은 UTF-8로 디코딩한 사본에 보존했다. 최초 응답 바이트 SHA와 디코딩 사본 SHA는 서로 다른 해시다.
