# 마령 계산 방식 재검토 — 2026-10-01

## 현재 API42 나이

프로필 4,617두 모두 API42 `age = 2026 − birthYr`이다. 한국식 세는나이의 `+1`을 하지 않으며 생일 도래 여부를 계산하는 만 나이도 아니다. 경마에서 사용하는 마령이다. 예를 들어 2023년생은 2026년 마령 3세이고 한국식 세는나이는 4세이며, 생일 전 만 나이는 2세가 될 수 있다.

[한국마사회 2026년 제주 경마시행계획](https://race.kra.co.kr/down/raceplan2026_jeju.pdf)의 부담중량 운영 → 마령중량 절은 연령 기산시점을 **1월 1일**로 명시한다. 로컬 PDF 10번째 페이지에 해당 문구가 있다. 원본은 `raceplan2026_jeju.pdf`, 추출 문구는 `raceplan2026_jeju.pdf.excerpts.json`, 조회시각·해시는 `fetch_manifest.json`에 보존했다. 2018년 공식 제주 계획에도 1월 1일 문구를 확인했다. 이 자료만으로 2007~2014년 규칙이나 변경 시행일을 확정하지 않는다.

## 과거 후보 출전행 92,513행

| 비교식 | 원천 경주 나이와 일치 |
| --- | ---: |
| 경주연도 − 현재 프로필 출생연도 | 91,494 |
| 위 연도차 + 1, 한국식 세는나이 | 0 |
| 생일 도래를 반영한 만 나이 | 66,829 |
| 상반기 출생은 1월 1일, 하반기 출생은 7월 1일 증가 가정 | 91,444 |

위 비교식은 일치 행이 서로 중복되는 전체 기간 비교다. 전체 기간에 하나의 식을 강제로 적용하지 않는다.

연도차와 다른 1,019행·86두는 모두 2007~2014년이고 나이가 1세 작다. 그중 **992행은 하반기 출생마가 상반기에 출전한 경우로, 7월 1일 증가 가정과 정확히 일치**한다. 같은 말의 같은 해 상반기→하반기 출전에서 나이가 1세 올라간 인접 관측도 **112쌍·67두** 확인했다. 모두 2007~2014년이다.

예: `3008298` 무한야성, 현재 생일 `2000-07-16`:

- 2007-06-17 API4_3: 6세.
- 2007-07-01 API4_3: 7세.
- 실제 생일 7월 16일 이전에 나이가 증가하므로 이 사례는 생일 기준 만 나이로 설명되지 않는다.

보유 자료에서 2002~2006년과 2015~2026년은 연도차와 전부 일치한다. **데이터상 계산 방식이 달라진 구간은 확인했지만, 당시 공식 규정과 시행일은 미확정**이다. 과거 공식 계획으로 추정한 URL에서는 오류 안내 HTML이 반환되어 PDF로 인정하지 않았다. 따라서 992행을 입력 오류로 판정하거나 원천을 수정하지 않는다.
