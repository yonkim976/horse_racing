# 제주마 예측 목표 재정의 — 우승축·착순·동반 후보

결정일: 2026-09-28. 상태: 새 제주 연구의 목표 정의. 구현·학습·성능 검증 완료를 뜻하지 않는다.

제주 보유 자료로 데이터 분석을 먼저 진행한 뒤 아래 목표에 맞춰 모델과 출력 방식을 비교한다. 신규 자료 수집을 연구의 선행 조건으로 삼지 않는다. 현재 운영 기준 모델 `HY_R_FORM`은 비교 기준으로 보존한다.

## 1. 용어와 의도

- **축마**는 1등할 것으로 예상하는 말(우승 예상마)이다. 선행마나 단순 입상 안정마를 뜻하지 않는다.
- 선행마는 초반 주행 위치·전개 특성이고 우승 예상 여부와 별개다.
- 동반 후보는 선택한 축마의 뒤를 이을 2·3착 후보 또는 해당 승식에서 함께 적중할 후보다. 어떤 조건을 말하는지 표시한다.
- ‘정확히 2착/3착’과 ‘2착 이내/3착 이내’를 구분한다.
- 축마를 지정하는 것은 예측 분포에서 조건을 보는 것이며 실제 경주를 바꾸는 개입이 아니다.
- ‘쌍축’이라는 말만으로 두 말의 동시 우승을 가정하지 않는다. 출력에서는 **우승 후보 두 마리 중 하나가 우승**, **두 말이 1·2위 동반**, **두 말이 3위 이내 동반**, **1→2위 고정**을 구분한다. UI 용어는 구현 전에 정한다.

## 2. 모든 출전마의 필수 확률

추천 말만이 아니라 완전한 출전마 집합 전체에 다음을 제공하는 것을 목표로 한다.

| 항목 | 정의 | 용도 |
|---|---|---|
| 우승 확률 | P(착순=1) | 우승축 후보 |
| 2위 이내 확률 | P(착순≤2) | 1·2위권 평가 |
| 3위 이내 확률 | P(착순≤3) | 입상 후보 평가 |
| 정확히 2위 확률 | P(착순≤2) − P(착순=1) | 2착 후보 |
| 정확히 3위 확률 | P(착순≤3) − P(착순≤2) | 3착 후보 |

기본 출력에는 우승·Top2·Top3 확률을, 상세 출력에는 정확히 2·3위 확률을 포함한다. 확률은 모델 추정치이며 실제 적중 빈도와의 일치 여부를 별도로 검증한다.

## 3. 공동 착순 분포와 조합 확률

설계 목표는 서로 다른 말 `i, j, k`의 `Q(i,j,k)=P(1위=i, 2위=j, 3위=k)`를 구성하고 필요한 경우를 합산해 말별·승식별 확률을 얻는 것이다. 단일 학습기를 쓸지는 정하지 않는다. 우승·Top2·Top3 점수를 별도로 학습하는 방식도 비교할 수 있지만 최종 확률의 일관성을 확인해야 한다.

동착이 없고 정상적으로 상위 3위가 확정되는 경주에서는 다음을 만족해야 한다.

- Q는 음수가 아니고 전체 합은 1이다.
- 말별 우승 확률 ≤ Top2 확률 ≤ Top3 확률이다.
- 전체 출전마의 우승 확률 합은 1, Top2 확률 합은 2, Top3 확률 합은 3이다.
- 말별 확률을 단순히 곱해 동반 입상 확률을 만들지 않는다.
- 동착·실격·미완주·출전취소의 학습 및 정산 규칙은 별도 데이터 계약으로 정한다. 엄격한 순열 계약을 예외 경주에 그대로 적용하지 않는다.

| 승식 | 필요한 사건 |
|---|---|
| 복승 | 지정 두 말이 순서 없이 1·2위 |
| 쌍승 | 지정 두 말이 순서대로 1→2위 |
| 복연승 | 지정 두 말이 모두 3위 이내 |
| 삼복승 | 지정 세 말이 순서 없이 1·2·3위 |
| 삼쌍승 | 지정 세 말이 순서대로 1→2→3위 |

## 4. 우승축 선택 뒤 동반 후보

우승축 A를 지정하면 다음을 구분한다.

1. A 자체의 우승 확률.
2. A가 우승한다는 조건에서 B가 2위일 확률, C가 3위일 확률, B·C가 함께 2·3위를 차지할 확률.
3. 조건을 적용하지 않은 실제 조합 확률: A→B 쌍승, A→B→C 삼쌍승 등.
4. 복승·복연승·삼복승처럼 A의 우승을 요구하지 않는 승식의 전체 적중 확률.

예를 들어 A의 우승 확률이 30%이고 A 우승 조건에서 B가 2위일 확률이 40%라면 A→B 쌍승 확률은 12%다. 40% 조건부 확률을 실제 적중 확률처럼 표시하지 않는다. 이는 조건부 확률의 계산이며 두 말의 독립성을 가정하지 않는다.

축마에 따라 조건부 후보 순위가 달라질 수 있다. 전개·편성의 상호작용을 반영하는 것은 연구 가설이지, 현재 모델이 검증해 구현했다는 뜻은 아니다. 조건 사건의 확률이 0이면 조건부 확률은 미정으로 두고, 매우 작으면 안정성 정보를 함께 표시한다.

## 5. 추천 5두와 조합 구성

추천 5두에는 우승 후보·2착 후보·3착 후보·순서 없는 입상 후보 등의 역할을 표시한다. 핵심 집합 평가는 **선정한 5두 안에 실제 1·2·3위가 모두 포함되는가**다. 말별 Top3 확률 상위 5두를 기준선으로 두고 공동 분포를 활용한 선택과 비교한다. 이는 ‘정확히 5위 안에 들 말을 예측하는 문제’와 다르다.

축마를 고정하지 않은 상위 3두 포함 확률과, 우승축이 우승하고 나머지 두 말이 동반 후보에 포함될 확률을 구분한다. 앞의 사건은 뒤의 성공을 보장하지 않는다. 우승축이 불확실한 경주도 표시한다.

같은 추천 수라도 조합 수가 다르다. 삼복승 전체 5두 조합은 10개, 1두 고정+4두 동반은 6개, 2두 고정+3두 동반은 3개다. 추천 수 확대 자체를 성능 개선으로 보지 않고 같은 조합 수 또는 비용 조건에서 비교한다. 여러 조합 중 하나 이상 적중할 확률은 사건의 합집합으로 계산한다. 복연승처럼 여러 조합이 함께 적중할 수 있으면 확률을 단순 합산하지 않는다.

## 6. 평가와 진행 순서

| 층위 | 평가 내용 |
|---|---|
| 말별 확률 | 우승·Top2·Top3별 Brier/log loss, 보정 상태, 확률 구간별 실제 적중 빈도 |
| 선택 결과 | 우승축 적중률, 조건을 명시한 동반 후보 적중률, 추천 5두의 실제 상위 3두 포함률 |
| 조합 | 다섯 승식의 확률 정확성 및 고정 조합 수에서의 적중률 |
| 실용성 | 배당·비용 기반 평가는 확률 정확성과 분리. 현재 제주 범위에서는 배당·시장 인기 입력과 수익성 평가를 진행하지 않음 |

기간·거리·편성 크기별 표본 수와 불확실성을 함께 보고한다. 최고 적중률 하나만으로 모델을 결정하지 않는다. 지표 우선순위와 후보 수·채택 기준은 실험 전에 고정한다. 평가 결과를 본 뒤 유리하게 바꾸지 않는다.

보유 자료를 시간순으로 나누고 과거 자료만으로 학습·변수 선택·확률 보정을 수행한다. 이미 여러 번 살펴본 기간은 새로 분할해도 독립적인 미관측 테스트가 아니다. 최신 최종 가중치로 과거 학습 구간을 재예측한 값을 공정한 과거 성능으로 쓰지 않는다. 현재 자료 상한은 2026-09-12이며, 사전 공개 시점이 확인되지 않는 입력은 가용성을 가정으로 표시한다.

다음 순서는 데이터 품질·시점 계약 → 기록·환경·게이트·전개 분석 → 소수 변수 기준선 및 기존 구조 비교 → 변수 묶음 비교 → 확률·조합 출력과 평가 확장이다. 상세 데이터 우선 절차는 [재시작 계획](<RESTART_PLAN_20260928.md>)을 따른다.

## 7. 기존 모델 및 목표와의 관계

기존 HY_R_FORM의 A(한 마리 입상 선택), B(상위 3두 집합), C(상위 3두 정확한 순서) 평가는 과거 결과 및 기준선 비교를 위해 유지한다. 새 목표는 이를 **우승축, 착순 확률, 조건부 동반 후보와 승식별 공동 확률**로 확장한다. 기존 A/B/C 지표를 새 목표와 같은 것으로 간주하지 않는다.

기준 모델의 저장 구조나 확률 출력을 확인하기 전에는 기존 출력들을 하나의 새 목표 분포로 간주하지 않는다. 기존 `HY_R_FORM`의 가중치와 운영 등록부는 변경하지 않으며, 새 목표의 구현·학습·검증·운영 승격은 별도 후속 작업이다.
