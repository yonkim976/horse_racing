# 복합 진료 원문의 병명별 분리와 개별 검토 등급

2026-10-15. 독립 연구 43의 사전·엑셀 표시 후속 개정. 기존 연구와 원본 엑셀은 보존한다. 운영 모델·DB·의학적 중증도 기준은 변경하지 않았다.

사용자 질문은 엑셀에서 두 병명이 한 원문에 묶여 있을 때 각각 판별할 수 있는지다. 이전 파일은 정확한 관측 원문을 보존해 복합문구에 대표 등급을 표시했다. 이번에는 별도의 항목별 표와 원문 연결표를 추가했다. 복합 원문의 대표 등급을 각 구성요소에 복제하지 않고, 각 정확한 사전 항목의 기존 개별 등급과 근거를 사용한다.

## 범위와 결과

- 입력: 이전 카탈로그의 정확한 원문·사전 제목 12,908개, 공식 사전 제목 3,500개, 기존 검토 구성요소. 추가 수집·회귀·실제 진료 사건 연결은 0개다.
- 복합 원문 8,826개를 분리했다. 기존 검토 구성요소가 있는 3,716개와, 문구 전체가 공식 사전 제목들의 유일한 조합으로 소비되는 5,110개 후보를 구분한다. 후자는 사람이 새로 임상 검토한 결과가 아니다.
- 공식 제목 그대로 유지 3,500개, 기존 검토 단일 대응 180개, 보류 402개다. 보류는 기존 문맥·파서·제외 369개와 분리 불명확 33개이며, 빈 구성요소와 U로 연결표에 남긴다.
- 중복 제거한 개별 사전 항목은 3,500개다. A587/B384/C1335/T68/U1126. 연결표는 보류 원문을 포함해 21,738행, 실제 원문→항목 연결 21,336개다. 이 수치는 방문 횟수·마필 수가 아니다.
- 쉼표가 포함된 공식 사전 제목 49개는 제목 전체를 유지한다. 예: `좌제2,3중수골골간인대염좌/파열`. 공식 제목 자체에 복합 증후군 표현이 있는 경우도 사전 제목 단위로 유지하므로, 3,500개를 전부 병리학적으로 독립된 질병이라고 해석하지 않는다.

## 분리 기준

공식 제목 자체와 정확히 일치하면 우선 보존한다. 그 외에는 기존 검토 구성요소를 사용한다. 검토가 없는 원문은 괄호 밖 쉼표 경계에서 사전 제목과 정확히 일치하는 전체 문구 분해를 찾는다. 경계의 ASCII 공백만 제거하며, 일부 문자열·유사어·부위 접두사 추측은 하지 않는다. 전체 분해 경로가 정확히 하나일 때만 사전 일치 후보로 채택한다. 문맥 검토가 필요하거나 파서 전용인 기존 보류 원문은 자동 분해 대상에서 제외한다.

순서와 원문 SHA-256을 보존한다. 단독 원문 관측 주·두수는 각 항목 자체의 기존 정확 일치 관측 수만 사용한다. 복합 원문의 관측 빈도를 자식 항목에 더하지 않는다. `연결된 원문 수`는 서로 다른 원문 문구 수이고 별개의 열이다.

## 엑셀 읽는 방법

새 파일 `outputs/medical_individual_terms.xlsx`는 원래 `요약과 기준`, `전체 항목` 시트를 보존하고 다음 두 시트를 추가한다. 요약에는 새 시트 안내 두 행만 추가했다.

| 시트 | 용도 |
|---|---|
| 단일 항목 판별 | 중복 제거한 사전 항목별 등급·개별 근거·분류 통계·단독 관측 수 |
| 원문별 분리 내역 | 원문→구성요소, 순서, 개별 등급과 기존 원문 대표 등급, 분리 근거, 원문 식별 해시 |

예를 들어 `각막염,우전굴건염`은 이전 원문 대표 등급 A였지만 구성요소별로는 각막염 B, 우전굴건염 A다. `원문별 분리 내역`에서 원문 필터로 검색하면 두 행을 함께 볼 수 있다.

## 해석 한계

A/B/C/T/U는 기존 연구의 검토 우선순위 후보이며 임상 중증도·현재 위험 확률·기록 감점 수치가 아니다. C는 저위험 판정이 아니다. 출전 지연과 복귀 첫째·둘째·셋째 성적은 기존 2024~2025년 33분류 통계의 참고 표시다. 개별 병명별 직접 효과를 새로 추정하지 않았고, 복합 원문을 나눴다는 이유로 개별 병명이 성적 저하의 원인이라고 판정할 수 없다. 실제 사건 수준에서 병명별 효과를 분리 추정하려면 복합 진료 동시 발생과 과거 능력 등을 반영한 별도 재분석이 필요하다.

## 검증과 산출물

`verify_terms.py`는 모든 원문·구성요소 순서·원문 해시, 개별 등급과 단독 관측 수의 자체 출처 일치, 공식 쉼표 제목 보존, 엑셀 전 셀과 기존 셀·수식·행높이·너비·고정창·필터·조건부 서식을 확인한다. 기존 참조 40파일의 바이트와 SHA-256을 보존한다. 변경한 요약과 새 두 시트는 렌더링해 시각 검토했다. 검증 결과는 `outputs/verification.json`, 입력 보존 목록은 `outputs/baseline.json`, 정확한 파일 용량은 `outputs/artifact_inventory.json`에 있다.

주요 재현 코드: `split_terms.py`, `build_workbook.mjs`, `verify_terms.py`. 전체 분리 판정·연결표·개별 표를 parquet와 CSV로 보관했다. 게시용 요약은 `PUBLICATION.md`, 출처는 `SOURCES.md`다.
