# 연구58C: 동적 상태와 조건부 공동착순 모델

2026-10-22. 사용자 승인에 따른 구현·학습·개발 비교. 운영 반영 없음.

## 고정할 비교와 예산

- 서울·부산, 기존 178,497행·16,435경주 프레임. 학습 2017년부터, 상태 필터의 이력은 2010년부터 허용.
- 2024/2025/2026 각 지역 6분할. 초기 학습 2017..Y−3, 조기중단 검증 Y−2, 재학습 2017..Y−2, 확률 보정 Y−1, 개발 평가 Y. 경주 전체를 한 분할로 묶는다.
- 기존 EL89·F103과 같은 4,799경주·50,754출전마, 축 1두, 복승/복연 1·3조합. 정답을 사용한 경주 선별 없음.
- 새로운 후보는 state_gbm, state_joint 두 계열. 별도로 EL89의 학습 상한만 늘린 strong89 대조군. 각 6개 최종 모델, 초기+재학습 각 1회. 랜덤시드 1개, 성적 확인 뒤 추가 탐색 없음.
- strong89/state_gbm은 기존 학습 설정을 유지하고 최대 800회·조기중단 25회. state_joint는 32차원, 2-head attention 한 층, 2개 잠재 시나리오와 1→2→3착 조건부 decoder. AdamW, 최대 64 epoch, patience 10, batch 128, lr .001, weight_decay .01, dropout .1, gradient clip 1. CPU 2 threads. 검증 평균 공동착순 NLL로 epoch 선택 후 동일 epoch 재학습.
- 두 후보 입력은 EL89 + 동적 상태로 같게 한다. 기존 유효한 과거 요약을 버리는 효과와 새 구조 효과를 혼동하지 않는다. state_gbm 대비 state_joint는 학습 목적·함수 계열도 바뀌므로 attention 하나만의 인과적 효과로 해석하지 않는다.

## 동적 상태

원시 DB는 읽기 전용. 검증된 과거 관측 파일의 보정 기록·초반·종반600m와 DB의 정상 착순·불완주 상태를 사용한다. 겹치는 종반200m를 별도 독립 관측으로 더하지 않는다. 주로빠르기·배당·조교·진료·심사·당일 체중은 추가하지 않는다.

1. 순위: 당시 출전마들의 사전 상태를 이용한 pairwise logistic 근사 Bayesian 갱신. 말별 2차원 능력·거리 반응, 공분산을 보존한다. 정상 완주마끼리만 순위 갱신하며 비완주를 임의의 시간·정확한 꼴찌로 바꾸지 않는다. 같은 경주 갱신은 동시 수행한다.
2. 기록: 기존 함수율 보정 표준 기록지수에 local-linear Kalman filter를 적용한다. 수준·추세·불확실성, 큰 잔차 clipping. 예측 이후 미래 smoothing 없음.
3. 초반/종반: 과거 같은 편성의 구간 중앙값 대비 수행과 당시 상대 상태를 사용한 scalar filter. 두 통계 채널을 독립 확률처럼 곱하지 않는다.
4. 휴양 중 불확실성 증가, 약한 평균회귀, 적은 이력은 공통 사전분포로 완화한다. 불완주율은 관측 여부와 함께 Beta prior로 완화한다. 이 값들은 근사 필터의 불확실성이며 보정된 사실 확률로 주장하지 않는다.
5. 모든 경주 입력은 기존 cutoff_date(T−2일) 이하 관측만 사용. 같은 날 미래 경주·현재 착순과 구간은 입력 금지. 필터 관측의 과거 출전 roster에 있는 상대는 해당 과거 시점 상태만 사용한다.

## 출력과 판정

- GBM은 기존 삼두 집합 분포와 순서 보정 방식을 유지. Neural은 두 잠재 성분의 조건부 1→2→3착 분포를 합한다. 잠재 성분을 실제 빠른/느린 전개로 식별했다고 주장하지 않는다.
- 한 말 중복 선택 금지, 모든 공동착순 질량합 1. 축·복승·복연은 하나의 공동분포를 주변화한다. 복연 3조합은 기존대로 개별확률 상위 3쌍이며 합집합 적중확률은 정확 합산한다.
- 주지표 복승3, 보조 축/복승1/복연1/복연3/복연적중수, logloss/Brier. 전체·연도·지역, 날짜 단위 paired bootstrap 2,000회와 상대변화 95%구간을 보고한다.
- +10%는 EL89 대비 상대 개선(10%p 아님). 강한 기준 F103 및 strong89도 함께 비교한다. 개선된 지표만 골라 전체 향상이라고 표현하지 않는다. 후보 유지 조건: 복승3 차이의 95%구간 하한>0, 축/복연3 차이 하한>−1%p, ordered NLL 악화 없음. +10% 점추정과 그 하한을 별도로 표시한다. 운영 자동 승격 없음.
- 2024~2026은 반복 사용한 개발 자료로서 새 미래검증이 아니다. 후기 fold의 과거 연도가 학습/검증에 들어가는 rolling 방식이며 전체 설계를 미래에 봉인한 prospective 시험이 아니다. 공시시각·당시 출전명단·부담중량 한계 유지.

## 검증·보관

코드/계획/입력 해시를 학습·새 평가 전에 고정. 합법적인 구동 오류는 수정 내역·구해시·신해시를 남기고 의미 변경 없이 재실행한다. 합성 자료의 cutoff/future perturbation/불확실성 증가, 순열 equivariance, masking, 직접열거 확률합, 모델 재로드·예측 재현, 티켓 채점 대조. 검증 실패는 결과와 구분한다.

새 연구 폴더에만 모델·작은 상태표·예측·보고서를 저장. 기존 세 연구 신규 보관 합계 53,756,748 bytes와 합쳐 300,000,000 bytes 미만. DB/기존 전체특징/이전 모델 복제 금지. 가상환경 의존성은 보관 산출물에서 제외하고 버전을 기록한다. 완료 시 중앙 결론·출처·용량 기록 갱신.
