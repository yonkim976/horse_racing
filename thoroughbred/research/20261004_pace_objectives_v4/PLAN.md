# 전개 v4: 보유 자료로 주행심사·직접 목표·초반 부진 위험 비교

사용자 승인: 심판기록은 보류하고 보유 데이터만 사용한다. 웹 수집과 운영 모델 변경은 하지 않는다.

## 계산 전 고정한 범위

- 원천: core_api_2010_20260929_v1의 읽기 전용 DuckDB, v3의 보존 입력과 jockey 후보 예측.
- 2010–2016은 이력 준비, 지도학습은 2017년부터. 기록시간은 2017년 이후만 사용한다. 이력은 T−2까지, 같은 날 다른 경주도 제외.
- 서울/부산 별도. 평가 2024, 2025, 2026. 연도 Y의 조기종료: 2017..Y−3 학습, Y−2 검증; Y−2까지 재학습, Y−1 확률보정, Y 평가. 기존 비교기간 재사용이므로 독립 미래 검증으로 부르지 않는다.
- 기준은 v3 jockey를 정확하게 재사용. 주행심사를 더한 순위 회귀(trial)를 S1F/G3F에서 비교한다.
- S1F 선두 직접 이진학습을 기존 입력(leader)과 주행심사 추가 입력(leader_trial)에서 각각 비교한다. 초반 3위 이내 직접 이진학습(front3_trial)도 비교한다.
- S1F 선두 확률 및 상위3두 확률은 순차적 무복원 분포로 구성하고 이전 연도에서 보정한다. 통과순위 MAE는 기존 회귀값과 비교 가능한 회귀 후보끼리만 해석한다. 모든 후보의 점수 순위를 비교하는 rank_position_mae도 별도 제공한다.
- 회귀 후보는 기존과 같은0.02..1.0 온도 범위와 동일 학습 seed를 유지한다. 이진 logit 점수는 척도가 달라0.02..8.0 범위를 사용한다.
- 초반 부진 위험: 직전 실제출전3전 모두 유효한 2017+ S1F 시간이 있을 때 그 평균보다 실제 S1F가 0.4초 초과 느린지. 발주대 반응시간이나 공식 늦발의 정답이 아니다. 없는 이력은 미상이며 정상으로 넣지 않는다.
- 위험 모델은 같은 연도 분할로 학습하고 Y−1에서 sigmoid 보정한다. leader_trial의 점수에 log(1−위험) 가중치를 적용하는 후보(leader_risk)는 가중치/선두 온도를 Y−1에서만 선택한다. 평가 결과로 조정하지 않는다. 미상 위험은 점수 보정하지 않는다.
- 주행심사: 공식 horse ID의 검토된 연결만 사용. venue override가 있으면 반영하고 나머지는 원천 서울/영남 지역값을 쓴다. T−2 이전 최근 기록, 관측 수, 최근3회 초반시간 및 세션 상대시간/순위, 합격 여부, 경주 기록과 차이를 사용한다. 전체 주파시간은 거리와 훈련 목적 차이가 있어 넣지 않는다. 2010–2016 시간도 넣지 않는다.
- 세션 상대순위는 실제 완료자들의 S1F 순위가 1..N 완전 순열일 때만 사용. 연습/불합격도 유효 완료시간이 있으면 관측으로 포함하고 합격여부를 별도 표시한다. 취소·제외의 유효 시간 처리 기준을 점검한다.

## 판정

- 같은 경주에서 선두 적중률, 초반3두 정확 적중, 앞선 재현율, Brier/NLL, 큰 오차 비율을 함께 본다. 날짜 단위 bootstrap 구간과 연도별 결과, 이력0/1–4/5+ 구분을 제공한다.
- 위험은 상수 확률 기준 대비 Brier/logloss, AUROC, 상위10% 경보의 실제 부진 비율과 전체 발생률을 평가한다. 경보 대상은 이력이 충분한 말에 한정한다.
- 개선을 보장하지 않는다. 부족한 지표는 그대로 보고하고 자동 승격하지 않는다. 이번 단계는 전개 비교이며 입상 모델 연결 및 삼복승 검증은 별도 단계다.
- 모델 파일 재현, T−2 연결, 주행심사 표본 직접 재계산, 시간 라벨 표본 재계산, 같은 평가 키 및 확률합, 원천/운영 등록부 해시 보존을 확인한다.
