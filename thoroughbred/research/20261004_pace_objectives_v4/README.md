# 전개 v4: 보유 자료로 개선한 결과

심판기록은 사용자 요청대로 보류했다. 웹 수집 없이 보유 DuckDB의 주행심사·경주 기록과 v3 입력을 사용했다. [계산 전 계획](PLAN.md), [코드](run.py), [설정](config.json), [전체 보고서](outputs/REPORT.md), [검증](outputs/verification.json)을 보존한다.

**이번 비교에서 가장 일관된 개선은 주행심사 추가였다. 특히 경주 이력이 없는 말의 초반 위치 오차를 줄였다.** 선두 직접 학습은 부산 선두 선택에 도움이 됐지만 초반3두 동시 포착은 악화할 수 있었다. 목표마다 후보를 구분해서 남긴다.

평가2024–2026-09-20, S1F 서울2,756·부산1,946경주를 같은 출전마로 비교했다. 학습2017+, 2010–2016은 이력 준비, 이력T−2. 기존 연구에서 이미 여러 번 살펴본 후향 기간이며 독립 미래 검증은 아니다. 운영 등록부와 원천 DB, 기존 실험을 바꾸지 않았다.

## 주행심사 추가

| 장소 | 지점 | 기존 기수 v3 평균 위치 MAE | 주행심사 추가 | 차이의 날짜 bootstrap95% 구간 |
|---|---|---:|---:|---|
| 서울 | S1F 초반200m | 1.8686두 | 1.8431두 | −0.0298~−0.0211두 |
| 부산 | S1F 초반200m | 1.9342두 | 1.9038두 | −0.0359~−0.0242두 |
| 서울 | G3F 잔여600m 진입 | 1.9703두 | 1.9524두 | −0.0217~−0.0140두 |
| 부산 | G3F 잔여600m 진입 | 2.0071두 | 1.9836두 | −0.0287~−0.0185두 |

서울·부산의 각3개 평가연도에서 두 지점의 평균 위치 오차가 모두 감소했다. 전체 경주 동일가중 지표이며 최종 착순 오차가 아니다. 예상 평균 위치와 실제 통과위치 차이가3두 이상인 비율도 S1F 서울19.48%→18.58%, 부산21.00%→20.08%로 줄었다.

**경주 이력0인 말**의 S1F 말 동일가중 오차는 서울1,631두에서2.5830→2.2486두, 부산1,251두에서2.5964→2.2464두였다. 큰 오차 비율은 서울41.26%→28.69%, 부산39.81%→28.62%. 전체보다 큰 개선이 있지만 아직 경력마 수준으로 정확해졌다고 주장하지 않는다. [경력별 수치](outputs/regression_experience_diagnostics.csv)는 같은 말끼리 비교한 사후 민감도 분석이다.

입력은 과거 주행심사의 초반시간·세션 상대시간·통과순위·최근3회/관측 수·합격 여부·경과일·실전 과거기록과 차이·이번 편성 내 상대 비교다. 공식 말ID의 검토된 연결과 기존 물리지역 예외를 사용했다. 완료시간이 있는 연습·불합격도 관측으로 포함하되 상태를 따로 표시한다. 취소·제외는 사용하지 않는다. 전체 주파시간은 미확인 거리·훈련 목적 차이가 있어 넣지 않았고2010–2016 원시시간도 넣지 않았다.

## 선두 선택과 앞선3두 포착

| 장소 | 후보 | S1F 선두 적중 | S1F 초반3두 정확 적중 |
|---|---|---:|---:|
| 서울 | 기존 기수 v3 | 43.25% | 16.36% |
| 서울 | +주행심사 회귀 | 44.27% | 17.31% |
| 서울 | 선두 직접+심사 | 44.05% | 16.69% |
| 서울 | 초반3두 직접+심사 | 43.61% | 17.74% |
| 부산 | 기존 기수 v3 | 40.90% | 17.47% |
| 부산 | +주행심사 회귀 | 41.68% | 17.06% |
| 부산 | 선두 직접+심사 | 43.32% | 16.55% |
| 부산 | 초반3두 직접+심사 | 41.83% | 16.91% |

서울 주행심사 회귀의 선두 개선은+1.02%p(95% 구간+0.11~+1.89), 초반3두 개선은+0.94%p(+0.14~+1.79)였다. 부산 선두 직접+심사는+2.42%p(+0.98~+3.82)이고3개 연도 모두 선두 선택이 개선됐다. 반면 부산의 초반3두 정확 적중은0.92%p 낮아졌으며 구간은0을 포함했다. 서울 초반3두 직접 후보의+1.38%p 구간은+0.50~+2.28이지만 부산에서는 같은 효과를 확인하지 못했다. 이 구간은 여러 후보를 살펴본 선택효과를 보정하지 않는다.

**통과 상위3두 적중은 최종 입상이나 삼복승 적중이 아니다.** 선두 하나를 더 잘 찾는 모델로 부산의 전체 전개 후보를 일괄 대체하지 않는다. 후보의 확률은 무복원 순차분포로 계산하며 선두 합1·상위3두 합3을 확인했다. 직접 분류 점수는 예상 평균 순위가 아니므로 순위 회귀 MAE처럼 읽지 않는다.

## 초반 부진 위험

위험 정답은 직전 실제출전3전 모두 유효한2017+ S1F 기록이 있을 때 평균보다0.4초 초과 느려졌는지다. 중간의 결측 출전을 건너뛰지 않는다. 발주대 반응시간이나 공식 늦발의 정답이 아니다. 이력이 부족하면 이 위험은 미상으로 남긴다.

| 장소 | 정답 비교 가능한 말 | 전체 부진 발생률 | 위험 상위10% 말의 부진 발생률 | 전체 부진 중 포착 |
|---|---:|---:|---:|---:|
| 서울 | 23,770 | 14.86% | 47.73% | 32.13% |
| 부산 | 17,536 | 10.97% | 23.42% | 21.36% |

상위10%는 각 평가연도에서 예측 위험순으로 고른 사후 평가 지표이며 현장 고정 경보 기준을 검증한 것은 아니다. 상수 확률 대비 Brier/logloss는 양 지역3개 연도 모두 개선됐다. AUC는 서울0.730~0.756, 부산0.642~0.666. 과거 기록 대비 초반 부진을 어느 정도 구분했지만 발생률에는 환경·거리·기수 조절 차이가 남는다.

위험으로 선두 점수를 낮춘 후보는 부산43.63%, 서울43.83%였다. 선두 직접+심사 대비 추가 변화는 부산+0.31%p(구간−0.25~+0.88), 서울−0.22%p(−0.58~+0.18)로 확실하지 않았다. **위험을 별도 참고값으로 보존하고 무조건 감점하는 방식을 기본으로 채택하지 않는다.** [위험 및 보조 비교](outputs/secondary_differences.csv), [후보별 대안 선두](outputs/leader_risk_scenarios.csv)는 인과적 경합 시나리오가 아니다.

## 다음 연구에 남길 후보

- S1F·G3F 평균 위치: 서울·부산 모두 주행심사 추가 회귀를 다음 입상 연결 후보로 남긴다.
- 선두 선택: 부산 선두 직접+심사를 별도 보조 후보로 남긴다. 서울은 주행심사 회귀를 우선한다.
- 초반3두: 서울 직접학습 후보는 비교 대상으로 남기고, 부산은 기존 기수 v3의 앞선3두 후보를 보존한다. 여러 후보의 확률을 임의로 혼합하지 않는다.
- 초반 부진 위험은 별도 확률·미상 여부로 남긴다. 입상 모델에 넣을 때에는 학습 경주에도 시간순 외부 예측을 만들어야 한다.

운영 승격과 최종 입상/삼복승 연결은 하지 않았다. 초반 페이스 시간 모델은 이번 변경 대상이 아니며, 실제 주행 내외측·기수 의도·당일 사고를 확인한 모델도 아니다. 현재 편성·기수·게이트는 기존 결과표 기반 대리값이므로 당시 출전표 공개/변경 시점까지 확인한 사전 운영 검증은 다음 단계다.

## 재현과 검증

프로젝트 루트에서:

```bash
.venv/bin/python thoroughbred/research/20261004_pace_objectives_v4/run.py prepare
.venv/bin/python thoroughbred/research/20261004_pace_objectives_v4/run.py train
.venv/bin/python thoroughbred/research/20261004_pace_objectives_v4/verify.py
.venv/bin/python thoroughbred/research/20261004_pace_objectives_v4/diagnostics.py
.venv/bin/python thoroughbred/research/20261004_pace_objectives_v4/verify_secondary.py
.venv/bin/python -m unittest discover -s thoroughbred/research/20261004_pace_objectives_v4 -p test_v4.py
```

prepare는 기존 출력 덮어쓰기를 거부한다. train은 해시가 맞는 완료된 연도 묶음만 재사용하며 불완전 묶음은 복구 없이 덮어쓰지 않는다. 이번 결과의36개 모델 파일을 보존했다.

단위검증7개 통과. 본 검증6,502개·보조 집계검증51개 통과/0실패, 모델 재현 최대 오차0. 과거3전·주행심사 표본 직접 재계산, 세션 순열, T−2, 기존 입력·정답·기준 확률 동일성, 평가 키·확률합·전체 집계, 모델 재현·연도분할, DB·운영 등록부 해시를 점검했다.

첫 시도의 미완료 출력은 outputs_before_nullable_fix에 보존했다. 결측 통과순위의 정수변환은 완료된 지점 학습 대상 밖에서만False로 채웠으며 결측 경주를 학습에 넣지 않았다. 최종 집계의 해당 없는 회귀 MAE는 엄격한 JSON을 위해null로 저장했다. 이 직렬화 수정 전 코드·감사와 완성된 모델 해시를 outputs/serialization_repair.json에 보존하고 모델·입력 불변을 검증했다. 보조 진단은 모델 선택이나 재학습 없이 저장된 예측을 집계하며 별도 secondary_audit.json을 가진다.
