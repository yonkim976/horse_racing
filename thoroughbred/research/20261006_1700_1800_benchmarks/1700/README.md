## 자료와 제외

원천 감사 거리 선택9,480행 → 기존 정상·완전 착순 모집단9,077행 → 넓은 구간 품질 제외2행 → 최종 **9,075행**이다. 최근2024년 이후 참조는 **2,310행**이며 종료일은서울2026-09-20다.

## 추정 방법과 개발 표본

지역별 Ridge alpha10으로 등급·상태·연도·월·성별·연령·부담중량·rating·엄격한 과거 착순과 초반 위치 이력을 통제했다. 이전 날짜의 최근5회 이력만 쓰며 다른 거리도 포함한다. 독립 구간 모형의 경주별 총 가중치를 같게 했다. 개발2021~2023에서0/0.3/1/3 후보 중 조합 평균 오차 최소값+0.01초 안의 가장 단순한 강도를 선택했다. 선택은{'서울': 0.0}다. 평가기간 결과를 보고 후보를 재선택하지 않았다.

최근 같은 등급 기록에서 자기 상태 효과를 빼고 목표 상태 효과를 더한 분포다. 상태별 분산·꼬리 변화까지 추정한 모형은 아니다. 건조 대비 전체시간 차이의 국5 예시:

양수는 느린 방향, 음수는 빠른 방향이다. 상태를 단조관계로 강제하지 않았다. 각 거리에서 새로 추정했으며1200/1300/1400/1600m의 초 단위 효과를 입력하지 않았다. 기존 전체시간 보정 결정이나 구간보정 채택 보류를 개정한 것은 아니다.
