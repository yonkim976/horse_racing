# 서울 1800m 계측선 명세 공개 탐색과 문의 준비

2026-10-20. 연구57D. **확인한 공식 공개 자료와 검색 범위에서 일반 서울 1800m의 실제 코너별 계측거리 명세를 확보하지 못했다.** 문서가 존재하지 않거나 비공개라고 확인한 것은 아니다. 코너 4지점과 인접 6구간의 미터 길이는 연구57C와 같이 미확정이다.

일반 해설의 1C 결승 전 1680m를 1800m에 대입하면 출발 후 120m가 된다. S1F 출발 후 200m보다 앞서므로 실제 일반군의 시간 순서와 충돌한다. 따라서 일반 해설을 거리별 측량표로 대신하지 않는다. 공식 해설 수치를 삭제하거나 비공식 거리로 교체하지도 않았다.

## 이번 추가 검색의 범위와 한계

마사회 도메인 중심으로 ‘서울 1800m 코너 계측 거리’, ‘계측선 배치도’, ‘경주기록 계측시스템’, ‘측정거리’, ‘판정장비’, ‘과업지시서’ 등을 조합해 검색했다. 공식 주로 안내, 용어해설, 실제 성적표, 시행계획, 기업 홈페이지의 고객 문의·정보공개 안내, 전자조달 홈페이지·공고 목록·이용 전환 공지를 읽었다.

2026-03-25 등록된 [전자조달 전환 공지](https://ebid.kra.co.kr/cus/notice/view.do?n=618)는 2026-03-31부터 입찰·계약 업무를 차세대 나라장터로 전환한다고 설명한다. 따라서 구 전자조달만으로 최근 자료까지 전부 확인했다고 할 수 없다. 공고 첨부파일과 나라장터 전체 기록, 내부 보유 도면을 전수 확인한 조사도 아니다. 검색 결과 없음은 보유 문서 부존재의 근거로 쓰지 않는다.

공공데이터 포털의 경주결과 서비스 메타데이터도 탐색했으나 그것이 보유 구간 필드의 정확한 제공 서비스인지까지 확정하지 않았다. 이를 근거로 계측 명세 제공 여부나 담당 부서를 단정하지 않았다.

## 무엇을 받아야 분석을 이어갈 수 있나

최소한 **현행 일반 서울 1800m의 START·S1F·1C·2C·3C·G3F·4C·G1F·FIN 누적거리표 + 기준 주행선 정의 + 주행경로 + 적용기간 + 문서 근거**가 필요하다. 시간 계측선과 통과순위 판정선이 같다는 확인도 필요하다.

과거 기록 분석을 위해 2010년 이후 변경 이력과 예외 경주 식별 방법을 추가로 요청한다. 다른 서울 거리도 보유 범위에서 요청하되 1800m를 우선한다. S1F=1C 정상480건/47개 경주는 관측 분류로만 유지하며, 출발점 변경으로 이미 확인됐다고 표현하지 않는다.

## 사용자가 문의할 공식 경로

- 기술 해석·담당 부서 안내: [고객의 소리](https://www.kra.co.kr/voc/voiceList.do?menuId=skr03_skr038_skr0382). 공식 페이지는 문답 조회에 로그인을 안내한다.
- 기존 보유 도면·명세·변경 이력: [마사회 정보공개 청구 안내](https://www.kra.co.kr/in/cl/01/incl0101.do?menuId=skr01_skr013_skr0131)에서 [정보공개포털](https://www.open.go.kr/)로 연결된다. 보유 문서와 해당 부분을 요청하는 문안을 별도로 마련했다.

정확한 내부 담당 부서명은 확인하지 못했으므로 문의 문안은 기능을 기준으로 전달을 요청한다. 이번 작업에서 게시·문의·전화·정보공개 청구는 하지 않았다.
