# 103→122 축 변경의 연도별 손익 진단

2026-10-12. 연구47의 결과를 이미 본 뒤 시작하는 후향적 진단이다. 새 모형·보정·문턱값을 선택하거나 운영에 반영하지 않는다.

질문: 2025년 순손실13경주와 2026년 순이익20경주가 어느 조건에서 생겼는가?

고정 비교: baseline103 대 combined122, 같은 4,799경주. 축은 raw_score 내림차순/마번 오름차순의 첫 말, 입상은 실제 1–3위. 축이 바뀐 경주를 새 적중/적중 상실/둘 다 적중/둘 다 실패로 나눈다. 순이익의 분모는 전체 경주, 조건별 성공률의 분모는 축 변경 경주로 구분한다.

2024·2025 전체연도와 2026-09-20까지를 보존하고, 2025·2026을 각각 01-01~09-20으로 맞춘다. 지역·정확거리·거리대(≤1300/1400–1600/≥1700)·등급·두수(≤9/10–11/≥12)·신마 포함·기존 축 입상확률/두 후보 확률차·승격 말의 기존 순위·내외측·앞선 확률·과거 종반 유지 관측량/부호를 비교한다. 문턱은 이 계획에 정한 해석용 구간이며 적중률 최적화에 쓰지 않는다. 종반 관측량은 0/1/≥2, 앞선 확률은 <.3/.3–.6/≥.6, 기존 입상확률은 <.6/.6–.7/≥.7, 기존 1·2위 확률차는 <.03/.03–.08/≥.08로 고정한다.

모든 축 변경 유형을 포함해 공변량·결측률·승격/강등 말의 차이를 보관한다. 조건별 표에는 전체경주/변경경주/득실을 모두 표시한다. 지역×거리대, 지역×등급의 공통층 표준화와 구성·층내 변화 분해를 사용한다. 경주일 군집 부트스트랩2,000회로 합산·동기간 순차이의95%구간을 계산한다. 여러 하위집단을 본 탐색 결과이며 유의성·원인을 확정하지 않는다.

고정 모델12개(두 후보×2지역×3연도)를 재추론해 저장 점수와 일치시킨다. 각 모델 안에서 승격 말−강등 말의 SHAP 묶음 기여를 계산해 선택 이유를 설명하되, SHAP을 실제 착순의 원인이나 새 변수만의 독립효과로 해석하지 않는다. 전체 학습이 달라져 공통 입력의 기여도 바뀐다.

현재 경주의 실제 초반·G3F·G1F 상대기록은 별도 사후 진단으로만 붙인다. 결과를 보고 입력을 다시 만들지 않는다. 과거 기록 지수는 높을수록 좋은 기록, 상대구간 초는 양수일수록 다른 말보다 빠름. G3F/G1F는 겹치는 구간이라 합산하지 않는다.
