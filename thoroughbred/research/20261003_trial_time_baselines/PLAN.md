# 서울 부산 주행심사 시간 기준점 조사 계획

2026년 10월 3일. 스키마·판정 코드·구간 제공 여부와 공식 규정 확인 후, 분포 통계 계산 전에 고정했다. 목적은 주행심사 합격 기준과 실제 기록 분포를 공식 연구 이력으로 보존하는 것이다. 현재 단계에서 실전 경주의 거리별 표준시간이나 최적 페이스를 확정하지 않는다.

## 원천과 범위

읽기 전용 코어 DB의 `trial_participants_venue_reviewed`를 사용한다. 서울·부산경남 요청 코드1·3의 보존 자료2010~2026년을 집계한다. 최근 주표는2024년 이후 신마 사유 `주행미합(신)`의 실제 판정 `합격`이다. 이는 최초 시도만을 뜻하지 않는다. 전체 합격·신마 불합격·신마 외 합격·연습 판정도 분리한다. 전체기간·2017년 이후·2024년 이후를 보존한다.

API에 거리 필드가 없으므로1000m는 주행심사 시행규정에 따른 거리다. 2026-09-17 코드3의48행은 기존 공식 계획 기반 부산경남·1000m 검토를 따른다. 이전 날짜 코드3는 기존 주행심사 원천 범위의 부산경남으로 집계하되, 모든 과거 날짜의 장소·거리 규정을 독립 재검증했다는 뜻은 아니다.

공식2026 시행계획의 연령별66/65초 기준과 주행상태 심사 항목을 확인한다. 합격 시간 상한과 실제 최단 관측값을 구분한다. 기록만으로 원 판정을 다시 결정하지 않는다.

## 시간과 품질 기준

원시 초 단위 `rcTime`(전체), `rcTimeS1f`(출발200m), `rcTimeG3f`(마지막600m), `rcTimeG1f`(마지막200m)를 사용한다. `passtime_*`나 순위 필드를 개별 말 구간시간으로 사용하지 않는다.0·결측은 미관측으로 취급한다. 원문 판정은 보존한다.

전체50~100초, S1F10~30초, G3F25~60초, G1F8~25초 범위와 합산 정합성을 주표 기준으로 삼는다. 전체−G3F−S1F로 얻는200~400m는8~30초, G3F−G1F의400~800m는16~50초여야 한다. 반올림 오차를 제외한 양수·순서 조건을 요구한다. 이 제외는 기준분포용 넓은 물리 범위이지 원문 오류의 확정 판정이 아니다. 양끝1%·5%를 추가로 잘라내지 않는다.

주표는 네 원시 시간이 함께 적격인 같은 출전행으로 계산한다. 개별 구간 결측·제외 수와 전체시간만 적격인 합격마 분포도 별도 보존한다. 부산G400은 원문 `rcTimeG400`을 보조 표로 제공하고8~50초 및 G1F<G400<G3F를 확인한다. 서울의 미제공G400은 추정해서 채우지 않는다.

## 통계

평균·표준편차·중앙값·P10/P25/P75/P90·관측 최솟값/최댓값·출전행/말/회차/날짜 수를 제시한다. 중앙80%는P10~P90, 중앙50%는P25~P75이며 신뢰구간이나 합격 범위가 아니다. 최소값은 원문을 재대조한 보존표본 관측값으로만 표시한다. 반복 출전마의 심사행마다 같은 가중치를 주고, 날짜별 평균을 동일가중한 평균도 보존한다.

신마 합격·그 밖의 합격·불합격·연습을 분리하고, 최근기간의 연도/2026상·하반기·연령·숫자 함수율 구간별 분포를 별도로 보존한다.2026하반기3세 이상과2세를 섞은 합격률·평균 해석을 피한다. 함수율·게이트·주행위치 보정을 이번 기초분포에 적용하지 않는다.

## Timeform 연결

사용자가 제시한 글의 `FS%=100×마지막 구간거리×전체시간/(마지막 구간시간×전체거리)`를 설명하고, 원시200/600m 및 부산400m 비율 분포를 보조 집계한다. 같은 말의 원시 전체·구간시간으로 계산하며 서로 다른 말의 평균을 대입하지 않는다.200m는1000m의20%, 600m는60%여서 글이 언급한 종반25~33% 지점과 일치하지 않는다. 부산400m도40%다. 평균/중앙값FS를 최적 par로 채택하지 않는다.

## 보존과 검증

새 연구 폴더에 코드·계획·원천 해시·품질 원장·통계·최단 관측행·보고서를 보존한다. DB와 과거 연구·운영 모델은 수정하지 않는다. 저장 표본과 원문JSON, 보관 API 응답을 재대조하고 별도 DuckDB 집계로 주표의 수량·평균·분위수를 재현한다. 구간 합산과FS 산식,0값 처리, 집계 키의 중복, 읽기 전용DB 해시를 확인한다. 결론 모음에 이번 연구의 별도 결론을 추가한다.
