# 경기장 거리별 환경 보정과 상대 주행위치 특성

2026-10-08. 새 정량 결과를 계산하기 전에 범위를 고정한다.

## 합산 보정

검증된 전체·구간 시험표를 하나의 조회 구조로 통합한다. 각 경기장·거리·두수·게이트 번호/그룹·함수율 상태·월·전체/최근 계수 기간에 대해 보정초=함수율+월+게이트다. 전체와 출발200m·마지막600m·마지막200m는 직접 목표다. 중간1=전체−출발200−마지막600, 중간2=마지막600−마지막200으로만 계산하고 독립 추정이라고 표현하지 않는다. 실제 내외측은 합산하지 않는다.

전체 함수율 서울80%·부산90%, 기존 구간 후보율과 게이트30% 기본+15% 상태 차이·수축·상한을 보존한다. 기존 채택 여부와 연구용 가용성을 별도 표시한다. 기존에 지원된1000/2000m 함수율 참조도 탐색 표로 제공하되 공식 채택 범위를 넓혔다고 표현하지 않는다. 지원하지 않는 상태·거리는0으로 추정하지 않고 빈값/미지원으로 표시한다. 기본 전체 모형의 월표는 기존값을 보존한다. 최근 전체 월과 누락된 전체 월은 아래 동일 설계 민감도 모형의 연간 곡선×30%×n/(n+100),12개월 평균0,0.12초 상한으로만 보충하고 출처를 표시한다. 구간 월과 모든 게이트는 기존 전체/최근 시험표를 보존한다.

기존4MAD 표본과 이탈 후미 제외 표본에서 정확 함수율·월·게이트를 함께 통제하는 말 고정효과 모형을4목표에 다시 적합한다. 전체·2024년 이후 두 기간, 지원14지역거리, 두 표본을 비교한다. 이는 기존 모형과 보정표를 덮어쓰지 않는 민감도 근거다. 상태별 숫자 함수율 혼합은 각 기간의 제거 전4MAD 경주 동일가중 분포로 고정한다. 원래 경주 명단·두수·게이트 범위는 유지한다.

대표 범위는 관측 출전 조건의 경주 동일가중 평균·중앙값·10~90%범위와 조건 격자의 최소/최대를 구분한다. 연도·분기별 요약은 노출 조건의 구성 변화이며 해당 연도 효과를 새로 추정한 결과가 아니다. 모든 게이트와 월을 평균해0에 가까워지는 값을 단일 거리 보정으로 사용하지 않는다.

표시 기준은 보정초 절댓값의 작은/큰 문턱을 전체0.05/0.20초,출발200·마지막200 0.01/0.04초,마지막600 0.02/0.08초로 고정한다. 문턱 미만0,중간+/−,큰값++/−−. 양수는 기록에 시간을 더하는 방향이다. 통계적 유의성 등급이 아니다. 중간구간에는 부호와 초만 제공한다.

## 상대 내측 중간 외측

같은 마군 내 상대 위치를 원 정의대로 사용한다. 레일 거리·실제 주행 경로가 아니다. 마군 중 하나라도4MAD/후미 조건에서 빠지면 마군 전체를 빼 원래 비교를 보존한다. 단독마는 비교에서 제외한다.

지역×계측지점×정확거리 및 전체거리 통합,전체/2024년 이후,기존4MAD/후미 제외 표본에서 말×거리+마군 고정효과를 적용한다. 함수율 상태마다2두 외측−내측,3두 이상 중간−내측/외측−내측/외측−중간을 같은 모형의 상태 상호작용으로 추정한다. 게이트·말 상태 통제를 유지한다. 가용 지점에서만 남은 시간도 비교한다. 서울4C 잔여시간은1200m·2024년 이후 계측 표본에 한정한다.

지원은 각 비교 위치100행·50마군·30경주·20날짜 이상,모형100마군·50경주·20날짜·30마필 이상,잔여자유도>5로 고정한다. 미식별/미지원은 표시한다. 말·날짜 군집 보수 분산과 기간×표본×지표×마군별 BH를 제공한다. 전후 차이·기간 차이 자체의 유의성이나 인과효과는 주장하지 않는다. 연도/분기×거리×함수율의 같은 마군 단순 차이도 별도 기술표로 제공하고 조정 모형과 구분한다.
