# 더러브렛 정식 경주 구간기록 API 적재

2010-01-01~2026-09-29 범위의 서울·부산경남·영천 정식 경주에서, **계획과 양수 완주 증거가 함께 있는 29,710경주**의 출전행만 구간기록 대상으로 삼았다. 마사회 `API4_3/raceResult_3` 원문은 이미 [날짜 조사 원장](../20260929_calendar_api_v1/README.md)의 `raw/race_execution_probe/`에 저장돼 있으며, 이 빌더는 네트워크 요청이나 운영 DB 읽기 없이 해당 응답을 직접 다시 읽는다. 대상의 실제 최신 경주일은 2026-09-20이다.

산출물은 [section_api_2010_20260929_v1](../../data/section_api_2010_20260929_v1)에 있다.

| 파일 | 행 | 의미 |
|---|---:|---|
| `runner_section_coverage.parquet` | 330,465 | 확정 시행 경주의 모든 말별 결과행. 구간값이 없어도 1행을 남김 |
| `section_measurements.parquet` | 4,380,065 | 원문 필드별 양수 구간시간·통과착순. 한 말에 여러 지점/시간종류가 있을 수 있음 |
| `section_parse_issues.parquet` | 0 | 숫자 해석 실패·음수 등의 오류 보존용 원장 |
| `manifest.json` | — | 출전 기준 CSV와 API 압축 원문의 SHA-256, 건수, 검증 결과 |

시간 2,617,940행은 누적시간 1,767,463, 구간시간 448,092, 결승 전 구간시간 402,385로 분리한다. 말별 통과착순 1,762,125행은 시간과 다른 종류의 측정으로 남겼다. 부산경남·영천의 `bu*` 필드를 같은 뜻의 서울 `se*` 필드로 임의 대체하지 않는다. 각 측정행에 원문 필드명·원문 값·원천 파일·항목 인덱스를 남겼다. `0`과 빈 칸은 측정값 없음으로 처리하고, 마사회 특수 착순 `99`는 통과착순으로 세지 않는다. 원본 값은 API 응답에 그대로 있다.

말별 출전행 330,465개 중 325,595개에 양수 구간시간 또는 통과착순이 있고, 4,870개에는 없다. 모든 확정 시행 경주 29,710개에는 적어도 한 말의 구간자료가 있다. 완주 증거가 있으나 구간값이 전부 빈 말은 서울 2010-07-04 6경주 10번 용왕성, 서울 2012-10-06 9경주 9번 동촌 **2행**이다. 이 둘은 보간하지 않았다.

[두 말의 결측 검토 원장](missing_finisher_section_review.csv)에 사용자가 제공한 경주 후 문구를 원문으로 연결했다. 용왕성은 `특이경주 / 실격 미처분`, 동촌은 `출주정지 2개월(2012.10.07~2012.12.06) / 양 앞다리 질병(양전 제염)`이다. 이 기록이 API 구간값 결측의 직접 원인이라는 근거는 아직 없어 `section_missing_cause_status=unverified`로 둔다. 두 말의 완주 기록과 구간 결측 상태는 그대로 유지한다.

보관된 해당 날짜의 `dacom12` RPT에는 두 말의 출전번호·마명·마체중 행이 있으나, 문서가 마체중/출전 속보라 **말별 구간시간·통과착순 열은 없다**. 보관 `dacom11` 심판 RPT는 2015년부터라 이 두 과거 날짜의 사유 문구를 확인하지 못했다. 따라서 제공된 문구의 출처는 현재 `user_provided_2026-09-30`으로 남기고 RPT를 구간값 보충 원천으로 사용하지 않았다.

기존 [구간 원천 스냅샷](../20260929_section_passing_raw/README.md)의 부산경남 API 유래 구간시간 1,433,221행과 동일 경주·말·원문 필드로 대조한 결과, 시간값 **1,433,221행 모두 일치**했다. [대조 결과](crosscheck_existing.json)와 [재현 스크립트](crosscheck_existing.py)에 남겼다. 이 대조는 공유된 API 값의 재현성 검사이며 원천의 물리적 정확도를 보증하지 않는다. 기존 스냅샷은 이 빌드의 입력이 아니다.

구간기록의 시간 종류는 API 필드의 역할을 보존한다. `se*AccTime`, `bu*AccTime`은 누적시간, 부산경남·영천의 `buS1fTime` 및 중간 `_...Time`은 구간시간, `bu_3fGTime`·`bu_2fGTime`·`bu_1fGTime`은 결승 전 구간시간으로 구분했다. `sj*Ord`와 `bu*Ord`는 **말별 통과착순**이다. 경주 단위 통과조는 이 표에 넣지 않았다. 측정값은 모두 사후 결과이므로 해당 경주의 예측 시점 피처로 사용하지 않는다.
