# 같은 함수율 상태에서 계절별 기록 경향 확인

2026-10-07 사용자 요청: 기존 거리별 기준 기록에 계절 경향이 있는지, 여름의 젖은 주로 비중과 분리해 같은 주로상태로 비교한다.

서울·부산의 완료된11거리 실전 모집단을 읽기 전용으로 합친다.1000m 주행심사·영천·제주·주로빠르기는 제외한다. 기존 거리별 품질 범위와 원시기록을 유지하고 이전 보고서·DB·운영 모델을 변경하지 않는다.

1. 겨울12/1/2월, 봄3/4/5월, 여름6/7/8월, 가을9/10/11월로 나누고 상태 비중·원관측 평균/분포를 보존한다. 여름이 더 젖어 있다는 가정은 실제 비중으로 먼저 확인한다.
2. 같은 지역·거리·연도·경주등급·상태와, 더 엄격한 같은 함수율 숫자의 계절쌍 관측 평균 차이를 각각 계산한다. 양쪽 관측 경주가 있는 비교층만 사용하고 조화 표본 가중치를 적용한다.
3. 경주별 평균에 같은 가중치를 주고 연도×등급×함수율 숫자의 고정효과를 제거한 월별 회귀를 적합한다. 연령·부담중량·rating·엄격한 이전 날짜의 이력·출전두수·성별 구성·결측 비중을 추가 통제한다. 한 비교층에서 두 달 이상 관측된 자료만 사용한다.
4. 계절은 각3개월의 월효과를 같은 비중으로 평균하고 겨울 대비 차이를 계산한다. 상태별 회귀도 따로 수행한다. 식별 불가능한 대조는 null이며0이나 다른 거리 값으로 채우지 않는다.
5. 날짜를 연도 안에서200회 재표집하고 고정효과 평균 및 계수를 다시 맞춘다. 유효180회 미만의95% 구간은 비운다. 점별 구간과 다중 탐색의 한계를 표시한다. 표본 조건과 불확실성 지원을 구분한다.
6. 연도별 정확 함수율 매칭 차이와 완결된2024/2025년 민감도 분석으로 기간별 방향을 확인한다.2026년은 아직 완결된 연간 주기가 아니므로 최근 민감도에서 제외한다.
7. 원자료·독립 집계·별도 고정효과 더미 회귀·재표집 분위수를 검증한다. 중앙 결론·게시 요약/JSON·과학 그림·전체 산출물 용량을 보존한다. 이번 연구는 계절적 연관의 설명이며 새 계절 보정이나 기존 기준표 개정, 우승 예측 개선을 채택하는 작업이 아니다.
