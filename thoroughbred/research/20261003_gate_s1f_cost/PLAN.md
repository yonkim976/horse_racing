# 게이트별 S1F 시간 차이 분석 계획

2026-10-03 계산 전에 고정. 날짜별 주행 위치 연구와 별도 폴더에서 수행하며 그 연구의 실행 및 파일은 변경하지 않는다.

- 기존 quality_filtered 게이트 연구의 서울·부산 2018년부터 2026-09-20까지 정상 완주 경주를 재사용한다. 숫자 함수율만 사용하며 주로빠르기와 최종배당은 사용하지 않는다. 등록 마번은 출발 위치의 대리변수이며 별도 물리적 출발칸 좌표를 확인한 것은 아니다.
- API S1F 누적시간을 초 단위로 일대일 결합하고 마번 일치를 검사한다. 주 분석은 전 출전마의 S1F가 유한하고 0보다 크며 완주시간보다 작은 완전 경주만 사용한다. 극단적으로 늦은 출발도 주 분석에서는 보존한다.
- 과거 초반 능력은 전체 API S1F 기록의 경주 중앙값 대비 차이를 이용한다. 말별 최근 5회 평균과 동일 경기장·거리 최근 5회 평균을 만들며 반드시 해당 경주일보다 이전 기록만 사용한다. 역사 기록의 극단 지연 영향은 10~25초 범위 기록만으로 과거 특징을 만드는 고정 규칙으로 제한한다. 범위 밖 기록을 오류라고 단정하지 않는다.
- 주 분석은 경기장·정확한 거리별 경주 고정효과 회귀다. 경주당 가중치합 1. 외측−내측 및 중간−내측 S1F 시간차를 추정한다. 기존 게이트 3등분 정의를 유지한다. 양수는 외측이 느리다는 뜻이다.
- 조정 변수는 기존 사전 능력·연령·부담중량·과거 착순과 전개·경력·휴양 간격 및 두 과거 S1F 평균과 결측 여부다. 당일 통과조와 S1F 위치는 주 모형의 설명 변수로 넣지 않는다. 주 추론은 경주일 군집 95% 구간, 전체 지원 거리의 외측 대비에 BH 다중비교 보정. 지원 기준은 50경주·20일이다.
- 보조 분석은 2024년 이후, 극단 지연 제외(전마 10~25초), 경주 내 S1F 중앙값 ±max(0.8초, 4×1.4826×MAD) 밖의 말이 있는 경주 전체 제외, 전마 과거 S1F 3회 이상, 말 고정효과를 추가한 동일 말 비교다. 마지막은 경주와 말의 두 고정효과를 가중 최소제곱으로 제거하며 일별 군집을 유지한다. 최초 반복 중심화의 느린 수렴으로 수치 해법만 희소 LSMR로 변경했다. 분석 대상과 비교 모형은 동일하다.
- 과거 전개 평균 prior_early≤0.20이고 S1F 이력 3회 이상인 말을 선행 성향으로 정의한다. 전마 이력 3회 이상인 경주에서 해당 말 수 0~1, 2, 3 이상에 따라 거리별 외측−내측 효과를 비교한다. 이 기준은 실제 선행 경쟁을 확정하는 기준이 아니다. 그룹 간 효과차도 같은 회귀의 상호작용으로 직접 검정하고 별도 BH 처리한다.
- S1F 통과조의 단독선두·선두조·선입·중간·후미와 출발 게이트를 결합한 기술 표도 제공한다. 같은 마군 내 상대 내외측만 알 수 있으므로 실제 안쪽 레일 진입 완료를 판정하지 않는다. 결과로 정해지는 전개별 표는 사후 설명이며 인과·사전 예측 성능으로 해석하지 않는다.
- 기록으로 관찰한 초반 시간차를 대각선 이동 거리로 직접 환산하지 않는다. 출발 반응·가속·진입 경쟁·경로의 영향을 분리하지 못한다. 현재는 후향적 관계 연구이며 운영 보정이나 실전 예측 모델을 변경하지 않는다.
- 새 폴더에만 코드·결과·보고서를 저장한다. 원본과 선행 연구의 SHA256을 검증하고 별도 최소제곱 해법으로 주 효과를 검산한다.
