# 구간·회복·상대 편성의 복승/축마 추가 가치 — 계산 전 계획

2026-10-09. 현재 선택 월·게이트·부중22를 고정 비교군으로 보존한다. 연구/운영 파일을 덮어쓰거나 DB·웹·운영 등록을 변경하지 않는다. 기수/조교사 식별자·성향·교체, 실제 내외측 주행, 당일 실제 전개/구간/함수율·배당을 새 입력에 사용하지 않는다.

## 고정 비교

서울/부산, 기존178,497행, 학습2017년부터, 2010~2016은 실제 출전 슬롯 warm-up. 평가2024/2025/2026부분. 같은 학습기/seed/연도 분할을 유지한다. 구간·통과조 원천은2018년부터라 이전/미지원 슬롯은 결측이다. 새 자료가 없는 말·경주도 평가에서 제외하지 않는다.

- baseline22: 선택된 모델 정확 재현.
- raw_sections: baseline22 + 초반200/마지막600/마지막200의 직전·최근3평균·최근5최고·최근5유효수 + 직전거리·최근5동거리 수.
- adjusted_sections: 같은 열/학습 설정에서 세 구간을 연도별 과거 자료로 보정한다. 미지원 보정은 원초를 유지하며 지원 여부를 별도 원장에 기록한다.
- style_history: adjusted_sections + 최근5실제슬롯의 통과조4분류 빈도/유효수, 단독마군/평균위치, 중간/후반400/막판200 순위이동 평균/유효수, 회복·앞선후퇴 빈도/유효수.
- field_context: style_history + 현재 게이트/상대위치, 자기 제외 전체 상대의 초반/막판 기록·선행/회복 빈도·관측 지원·빠른 상대 수. 안팎 상세 변수는 추가하지 않는다.
- pace_stack: field_context + 시간순 외부 생성 초반4확률/회복확률/후퇴확률/지원 표식. 이 연구의 직접 입력으로 별도 보조모형을 학습하며 기존157/297입력 모형 그대로의 연결이라고 부르지 않는다.

최근5전은 실제 출전 슬롯, T−2,730일을 유지한다. 유효기록을 찾느라 부진/결측 출전을 건너뛰지 않는다. S1F는 통과조의 첫 마군 전체/선입/중단/후미, 후반 이동은 공식 상대순위다. 원천 내측 배열을 앞뒤 착순으로 읽지 않는다. recovery/fade는 관측 사건으로 생리적 능력·작전 의도가 아니다. 과거 최종착순은 회복/후퇴 사건 계산에 간접 사용되나 과거 착순 원값이나 막판우수 비입상 보너스를 추가하지 않는다.

## 구간 환경 시험 후보

2020~2026 각 기록연도에 전년까지의 원자료/이전 전체기록4MAD 마스크만 사용한다. 기존 구간 연구의 같은 말 월모형·같은 경주/같은 말 게이트모형을 재추정한다. 월30%·표본수축100·구간 상한, 게이트 기본30%/상태15%·수축100·구간 상한을 유지한다. 함수율은 같은 월 설계에서 건조 숫자 혼합 대비 상태 대조를 새로 계산하고 기존 구간 후보율(서울200m60%/600m40%,부산200m40%/600m30%)을 적용한다. 이는 고정2026조회표의 정확 복제가 아닌 시간순 시험 버전이다.2018/2019·희소거리·미식별 조건은 원초 유지. 전체기록22개는 불변이다. 전체4MAD 마스크는 해당 연도 이전 자료로 이미 재추정된 것만 읽는다. 후미 제외로 말을 지우지 않는다. 마지막600/200은 겹치는 별도 설명변수이며 합산 점수를 만들지 않는다. 부산400m는 공통 보정/초반 모델에서 직접 지원되지 않아 이번 공통 실험은600/200에 한정한다.

## 학습/평가

우선 기존3위이내 목표를 고정해 입력 효과를 비교하고, 같은 여섯 입력 묶음으로2위이내 목표를 별도 학습한다. Y시험, Y−1조합온도교정, Y−2조기종료 후2017~Y−2재학습. LightGBM설정은 기존22와 같다. 보조 전개모형은2020~2026 각 행의 연도 이전만 학습(180회 고정), 이전 연도는 미관측이다. 주모형 학습행에도 자기 연도 결과로 학습한 보조예측을 넣지 않는다.

주 지표: 상위2두 복승1조합, 1순위축2위이내, 축+2/3/4순위 복승3조합. 보조: 축3위이내, 상위4두복승6조합, 목표확률Brier/로그손실.3위모형에서 복승 확률을 발명하지 않고 순위 선택 실적으로만 비교한다.2위모형은 모든 비순서2두 조합의 합점수 softmax/전년온도 및 말별 주변확률을 계산한다. 동률은 원마번 오름차순. 운영 모델은 같은마번/마필ID/숫자결과가 일치하는1,258경주에서 기존 입상 순위와2위이내확률 순위를 각각 대조한다. 최고 공동복승확률 조합이나 수익률 비교로 부르지 않는다.

평가 연도/지역/거리/이력 지원과 날짜 단위 paired bootstrap2,000회95%구간을 보존한다. 여러 탐색 비교/반복 사용한2024~2026은 새 독립 미래 검증이 아니다. 조합 적중·축마 차이와 확률 품질을 구분하고 점추정 최고를 자동 승격하지 않는다. 현재 부담중량은 결과DB의 회고값이며 사전 공개시각 미감사 한계를 유지한다.
