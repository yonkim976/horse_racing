관측 회복/후퇴는 추입 의도·체력 붕괴를 확정하지 않으며 선행밀집/막판우수에 고정 확률 보너스를 주지 않았다. 신마/자료부족 결측, 현재 출전명단/중량의 사전 공개시각 미감사, 반복 사용한 후향 평가/다중비교, 부분2026의 한계를 유지한다. 적중률은 수익률이 아니다.
