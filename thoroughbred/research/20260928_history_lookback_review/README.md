2026-09-28. **권고: 기본 경주·출전 이력은 2010-01-01부터 연결하고, 2010~2016은 이력 준비 구간, 2017년 이후는 정밀 분석·첫 기준 모델의 정답 학습 구간으로 구분한다.** 기존 2010년 이전 자료를 삭제하거나 모든 항목의 수집 시작일을 2010년으로 강제하는 결정은 아니다. 새 수집이나 DB 구축·모델 학습은 실행하지 않았다.

## 실제 보유 이력 추적

기존 2026-09-18 통합 산출물 `entry_result.parquet`에서 서울·부산, 결과 상태 finished/did_not_finish/disqualified를 사용했다. 고유 말 ID로 경마장 이동을 포함해 연결했다. 수록 마지막 경주일은 2026-09-13이다. 분석 코드와 출처 해시는 `analyze.py`, `evidence.json`에 있다.

## 구축 범위

### 2010~2016: 기본 경주 이력과 과거 상태

경주키, 말 ID, 당시 출전명단, 거리·등급·날짜·경마장, 착순·완주기록·결과상태, 기수·부담중량 등을 먼저 연결한다. 마체중·주로·구간·심사·조교·진료는 확보된 범위와 원천 의미를 따로 점검해 이용한다. 모든 상세 항목이 2010년부터 완전할 것이라고 가정하거나 없는 값을 생성하지 않는다.

2017년 이후에도 뛴 말만 과거 자료에서 추출해 최종 경주 표를 만들면 상대마와 편성 정보가 사라진다. 따라서 기본 구축은 서울·부산 해당 기간의 전체 경주·출전마를 유지한다. 이번 대상마 추적은 기간 필요량을 살피기 위한 후향적 감사이며, 미래 참가 여부를 피처로 쓰거나 과거 모집단을 선별하는 규칙이 아니다.

2010년 전 자료는 보존한다. 오래된 기수·조교사 통계, 상대마의 생애 이력, Elo 초기 상태, 혈통 연구 또는 전체기간 학습 비교에 필요할 수 있다. 2010년 시작은 2017년 이후 대상마의 관측 경력 연결을 위한 기본 범위이며 모든 통계의 완전한 초기화를 보장하지 않는다.

### 2017년 이후: 정밀 구간과 새 모델 연구

정정된 구간시간·통과착순·통과조를 기본 경주 이력과 연결한다. 누적/막판/구간의 의미, 거리별 지점, 원천별 누락·정정 여부를 확인한다. 2017년 이후 경주를 첫 기준 모델의 정답으로 학습하고, 2010~2016년 자료는 각 예측일 이전 말 이력을 만드는 데 사용한다. 학습기간 최종 선택은 [앞선 검토](../20260928_training_start_review/README.md)의 전체기간 비교와 별개로 수행한다.

서울의 2016년 주로 변경 이전 기록은 같은 거리라도 원시 초를 그대로 섞지 않는다. 시기별 출처·주로를 구분하고, 시간순으로 계산한 보정이나 상대 기록을 검증한다. 과거 경력 보존과 과거 환경을 현재와 동일하게 가정하는 것은 다르다.

## 완성도 판정

특정 연도부터 수집했다는 사실만으로 완전한 데이터셋이라 부르지 않는다. 다음을 확인한다.

1. 공식 국내 경력 또는 신뢰할 수 있는 원천과 관측 출전 목록을 대조해, 실제 데뷔와 수집 시작에 따른 이력 절단을 구분한다. 과거 시점의 공시 횟수를 확보할 수 있을 때만 해당 시점과 비교한다.
2. 말 ID·개명·경마장 이동 연결, 경주별 출전명단과 결과상태, 날짜 중복·누락을 검사한다.
3. 생애 이력 전체와 최근 5경주/최근 1년/동일 거리 이력의 충실도를 각각 기록한다. 이력 미확보를 0회 또는 신마로 표시하지 않는다.
4. 외국 도입마의 해외 경력과 국내 경력을 구분한다. 국내 최초 관측을 실제 생애 데뷔로 간주하지 않는다.
5. 2010년 이전의 국내 경력이나 식별 예외가 확인되면 해당 말과 필요한 경주를 더 거슬러 보완한다.

기본 경주 자료는 이미 더 오래된 기간까지 보유하고 있으므로 전 기간을 새로 다운로드할 필요부터 가정하지 않는다. 먼저 기존 자료를 연결하고 누락 목록을 만든 뒤, 확인된 공백만 추가 수집한다. 정밀 구간·심사 등 세부 항목은 기본 경력의 시작연도와 별도의 가용성 기준을 둔다.
