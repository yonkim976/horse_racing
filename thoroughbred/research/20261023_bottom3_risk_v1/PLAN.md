# 연구58F: 하위 3두 독립 예측과 축 선택 보조

2026-10-23. 사용자의 하위 3두 모델 제안을 제한된 비교 실험으로 구현한다. 기준 모델은 연구58C state_gbm이며 운영 모델이 아니다. 서울·부산을 따로 학습하고 동일한 2024~2026년 4,799경주 전체를 평가한다. 이미 여러 연구에 사용한 개발 자료이며 새 독립 검증 구간이 아니다.

## 정답과 비교 기준

정답은 정상 완주마 중 마지막 세 자리다. 불완주·실격·특수결과를 임의의 꼴찌로 만들지 않는다. 이들은 학습 손실에서 제외하지만 예측 명단에는 유지하며, 평가에서 정상 하위 3두 적중으로 인정하지 않는다. 해당 말이 하위권으로 지목된 빈도는 별도로 집계한다. 정상 완주마가 최소 6두임을 확인했다. 마지막 세 자리의 경계에 동착이 있으면 남은 자리 수를 동착마 수로 나눈 분수 정답을 사용한다. 예: 두 자리는 확정이고 다음 두 말이 동착이면 각각 0.5점. 이런 경주는 학습·조기중단·온도 보정에서 제외하고 평가의 말별 적중은 분수 처리한다. 세 두 모두 적중은 경계가 유일한 경주만 분모로 쓴다. 경주 또는 말을 사후 삭제해 축 성적을 올리지 않는다.

기준은 기존 입상 모델의 하위 3순위(입상확률이 가장 낮은 세 말), 무작위 기준은 경주별 3/두수다. 새 모델도 정확히 세 말을 지목한다. 주 지표는 세 지목 중 실제 정상 하위 3두 비율, 2두 이상/3두 모두 적중, 실제 입상마·우승마를 잘못 지목한 비율이다. 무작위 기준과 기존 모델을 반드시 함께 보고한다. 하위 3두는 비입상마 전체와 다르다.

## 한 모델 계열과 시간 분할

기존 118개 입력(과거 능력·구간·전개89 + 동적 상태29)을 그대로 사용한다. 현재 착순·실제 구간·배당·정상완주 여부는 입력에 넣지 않는다. 정상 하위 3두 여부를 학습하는 LightGBM binary 한 계열, 장소1/3 × 평가연도2024/2025/2026의 최종 6개와 조기중단용 6개를 적합한다. 2017~Y−3 학습, Y−2 조기중단, 2017~Y−2 재적합, Y−1 온도 보정·축 정책 선택, Y 평가. 원래 GBM과 같은 학습률.04·15잎·최소150·L2=5·seed20261004·4threads·최대800회·조기중단25회. 행 가중치 1/출전두수. 범주 사전은 최초 학습 구간에서만 만든다. 평가 후 모델·변수·시드 탐색 없음.

하위 세 말의 부분집합 확률은 exp(세 원점수 합/온도)를 모든 3두 조합에 걸쳐 정규화한다. 장소·연도별 전년도에서 온도 .35~4를 한 번 추정한다. 비교 기준도 기존 원점수를 음수로 뒤집어 같은 보정을 한다. 주변확률 합은 3이다. 이것은 기존 상위 3두 분포와 별도인 하위 3두 분포이며 양쪽의 통합 공동분포라고 주장하지 않는다. 이 주변확률의 Brier와 유일 정답 경주의 set NLL도 보고한다.

## 축 개선 여부를 별도 평가

축은 항상 한 두, 경주 선택률100%, 복승·복연1/3쌍 및 기존 공동확률은 유지한다. 첫 정책은 새 하위 3두를 제외하고 기존 점수 최상위를 축으로 고르는 고정 규칙이다. 둘째 정책은 기존 원점수 − λ×하위 원점수가 가장 큰 말을 축으로 고른다. λ는 {0,.25,.5,1}로 미리 제한하며 장소별 전년도 축 적중 수가 최대인 값을 고른다. 동률이면 작은 λ(기준 λ=0 우선). 이는 축 추천 효용점수이며 새 입상확률이 아니다. 선택된 말의 기존 주변확률만 표시한다. 온도는 축 정책 선택에 사용하지 않는다. 전년도에서 정책을 고른 뒤 해당 연도 정답을 읽기 전에 저장한다. 새 정책을 보고 다시 문턱을 조정하지 않는다.
