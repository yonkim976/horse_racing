# 전개 v5 — 이번 거리·편성에서 예상되는 전개

사용자가 거리별 각질과 이번 편성에 맞춰 학습하도록 승인했다. **같은 거리/거리구간의 말 이력을 따로 입력해 학습했고, 평균 통과위치 오차는 작지만 일관되게 줄었다.** 부산 선두 직접 학습의 전체 문맥 후보도 개선됐다. 다만 초반3두 정확 포착은 일관되게 좋아지지 않았다.

[계산 전 계획](PLAN.md), [설정](config.json), [전체 결과](outputs/REPORT.md), [독립 검증](outputs/verification.json)을 보존한다. 심판기록과 웹 수집은 사용하지 않았다. 기존 모델/원천 DB/운영 등록부는 보존했고 신규 후보를 운영에 승격하지 않았다.

## 바뀐 학습 입력

- 말×지역×같은 거리, 말×지역×거리구간(≤1300/1400–1600/≥1700)의 최근5회 S1F·G3F 상대순위, 선두/앞선비율, 두 지점 간 이동,200m 시간과 관측 수·최근일을 각각 집계했다.
- 관측이 적으면3관측의 가중치로 전체 과거5전 이력과 연결한다. 같은 거리 평균은 다시 거리구간 값에 연결한다. 표본이 없으면 기존 이력으로 대체하며0관측을 표시한다. 미상 각질을 앞선0순위로 채우지 않는다.
- 이번 거리에서 완화된 성향·시간을 출전마끼리 비교하고, 자신보다 빠르거나 비슷한 말의 수, 게이트×그 거리의 앞선 성향도 입력했다.
- 전체 문맥 후보는 기수의3개 거리구간별 과거 기대잔차와 표본 수, 직전 등급·등급 증감, 과거 거리 연장/단축/동일 조건에서의 위치 변화와 앞선 상실률을 추가했다.

거리별 이력만 추가한 distance, 위 추가 문맥까지 더한 context를 비교했다. 선두 직접 학습도 leader_distance/leader_context를 따로 만들었다. 같은 말이라도 이번 거리·편성과 관측 이력에 따라 입력과 예측이 달라지는 구조이며 고정된 각질 라벨을 붙이는 방식은 아니다. S1F/G3F별 예측이고 전체 주행경로·기수 의도를 직접 예측한 정답은 아니다.

평균 위치 MAE는 경주 동일가중 통과순위 오차이며 최종 착순 오차가 아니다. 두 지역의3개 평가연도 모두 S1F·G3F 평균 위치 오차가 감소했다. S1F 감소 폭은 서울 약0.54%, 부산 약0.41%로 작은 개선이다.

전체 문맥을 더한 회귀의 S1F는 서울1.8332, 부산1.8966두였다. 거리별 이력만보다 추가로 좋아졌다고 볼 근거는 없고 서울 G3F는1.9462두로 조금 악화했다. 위치 예측용 후속 후보는 더 단순한 distance를 우선 보존한다.

## 거리·등급·거리 변경

| 거리 구간 | 서울 S1F v4→거리별 이력 | 부산 S1F v4→거리별 이력 |
|---|---:|---:|
| ≤1300m | 1.9070→1.8988두 | 1.9341→1.9247두 |
| 1400–1600m | 1.8141→1.8018두 | 1.9261→1.9217두 |
| ≥1700m | 1.7523→1.7415두 | 1.7826→1.7713두 |

이번 거리별 이력의 점추정은 세 구간 모두 줄었다. 부산1700m 이상 선두 직접+전체 문맥은 기존 선두 직접+심사52.15→54.15%였지만 이는349경주의 사후 세부 결과이며 확정된 거리별 운영 선택으로 부르지 않는다. [거리별 표](outputs/distance_band_race_metrics.csv)와 [등급별 표](outputs/grade_race_metrics.csv)에 전체 지표를 남겼다. 숫자 등급 표는 국·혼을 묶은 요약이며 OPEN은 등급 미상값으로 별도다.

거리 연장 집단은 아직 해결되지 않았다. S1F 말 동일가중 오차에서 서울 연장 말8,321두는1.8862→1.8812두로 작게 줄었지만 부산6,347두는1.9610→1.9642두로 조금 악화했다. 같은 거리/단축 집단과 구분해야 한다. 전체 문맥 후보도 부산 연장 오차1.9662두였다. 이는 기수의 의도적 조절을 직접 관측하지 않은 한계가 남아 있음을 보여주는 성능 진단이며 원인을 확정한 증거는 아니다. [거리 변경 표](outputs/context_direction_runner_metrics.csv)를 보존한다.

신마의 추가 효과도 작다. S1F 서울2.2486→2.2429두, 부산2.2464→2.2447두로 v4 주행심사의 큰 신마 보완 뒤에 추가한 거리별 경험은 대부분 경력마에 관한 정보다. 신마는 미상 거리 이력과 주행심사 정보를 유지한다.

## 보존할 후속 후보

- 평균 위치: 서울/부산의 S1F·G3F에 거리별 이력 distance 후보를 다음 연결 실험용으로 보존한다.
- 부산 선두 선택: leader_context를 별도 후속 후보로 보존한다. 서울 선두와 초반3두에는 기존 후보도 유지한다.
- 전체 문맥 회귀는 거리별 이력 회귀보다 추가 이점이 뚜렷하지 않아 우선 후보로 채택하지 않는다.
- 위험 모델 정답/감점 방식은 이번 단계에서 바꾸지 않았다. 입상 연결과 삼복승 비교는 [후속 연결 연구](../20261004_pace_finish_stack_v1/README.md)에서 완료했고, 새 날짜의 독립 확인은 아직 남아 있다.

기존 출전 편성·기수·게이트는 결과표 기반 대리값이고 당시 사전 공개·변경 시점까지 증명한 운영 검증은 아니다. 거리 변경 이력의 앞선 상실도 최종 추입형이나 실제 작전의 라벨이 아니다. 서로 다른 후보의 확률을 임의로 섞지 않는다.

## 데이터와 검증

평가기간 출전마의 같은 거리구간 관측률은 약83~87%, 동일거리 약74~82%였다. 과거326,327행의 거리·등급을 읽기 전용 원천 DB에서 연결했다. 부산2010-03-12의 거리 결측10행은 거리 미상으로 유지하고 거리별 집계에서 제외했다. 다른 warm-up 이력은 유지했다.

단위검증7개 통과. 독립검증5,972개 통과/0실패,36개 모델 재현 최대 오차0. 동일거리·거리구간·완화 평균·기수 구간·거리변경의 과거 이력을 표본 직접 조회하고 T−2, 원시시간 범위, 기존 특징/정답/확률/키의 동일성, 확률합, 전체 집계·보정/학습 연도, 원천·운영 등록부 해시를 점검했다. 세부 그룹 표 검증418개도 통과/0실패였으며 [세부 검증](outputs/details_verification.json)에 남긴다.

프로젝트 루트에서 재현:

```bash
.venv/bin/python thoroughbred/research/20261004_pace_context_v5/run.py prepare
.venv/bin/python thoroughbred/research/20261004_pace_context_v5/run.py train
.venv/bin/python thoroughbred/research/20261004_pace_context_v5/verify.py
.venv/bin/python thoroughbred/research/20261004_pace_context_v5/verify_details.py
.venv/bin/python -m unittest discover -s thoroughbred/research/20261004_pace_context_v5 -p test_v5.py
```

prepare는 기존 출력 덮어쓰기를 거부하고 train은 해시가 맞는 완료된 묶음만 재사용한다. 모델 파일은 outputs/models의 지역·연도·후보별 폴더에 있다.
