# 게이트 번호별 유불리와 게이트만 사용한 시간순 후속 검증

2026년 10월 8일. 새로운 결과 계산 전에 고정했다. 기존 게이트·내외측 결과와 10월7일 거리 간 비교는 이미 관찰한 후향 자료다.

## 질문과 자료

게이트 번호별 차이가 출전두수·거리·시기별로 어떻게 나타나는지, 실제 현재 주행위치 없이 게이트 정보만으로 Top3 예측을 개선할 수 있는지 확인한다. 기존 `20261002_gate_lateral_bias/outputs/runners.parquet`의 정상 순위 완결·6두 이상·2018년 이후 모집단을 그대로 재사용한다. 서울 종료일2026-09-20·부산2026-09-18이다. 새 이상치 제거·원시 DB 조회/변경·운영 반영은 하지 않는다. 풍향·풍속·주로빠르기는 제외한다.

게이트는 마번의 대용값이다. 취소 후 물리적 발주기 위치를 별도 확인하지 않았다. 실제 현재 주행위치·구간 기록·최종 배당·현재 기록은 입력하지 않는다. 레이팅·나이·부담중량·이전 날짜까지의 최근5회 상대착순/Top3/초반위치·출전수/간격을 사용한다. 현재 레이팅 등 원천 필드의 공표 시각을 별도 검증한 실시간 재현은 아니다. 결과가 정상 완결된 경주만의 선택 모집단이라는 한계를 유지한다.

## 번호별 관찰 분석

- 정확히 마번1~10인10두와1~12인12두를 따로 분석한다. 지역×정확거리×두수×전체기간/2024년 이후를 구분한다. 다른 두수·번호 누락·13번 이상으로 복사하지 않는다.
- 경주 고정효과·경주 동일가중과 기존 능력 통제를 유지한다. 번호별 더미를 함께 적합하고 같은 두수의 모든 게이트 평균을0으로 둔 대비를 계산한다. 1번이 최상이라는 가정은 하지 않는다.
- 각 모형50경주·20일 이상을 지원 기준으로 한다. 각 번호 대비의 경주일 군집 t95% 구간·p와 전체기간/최근별 지원 대비 전체를 합친 BH q를 제공한다. 큰 점추정치와 다중비교 후 남은 차이를 구분한다. 표본 부족 셀은 상태로 남긴다.
- 12두 번호별 원 연구와 같은 표본의 대비를 재현한다. 시간순 예측 계수로 이 후향 번호표를 소급 사용하지 않는다.

## 실제 위치를 사용하지 않는 시간순 비교

- 연도2020~2026의 각 기준은2018년부터 직전연도까지로 학습한다. 같은 경주 안 평균을 제거한 선형 Top3 모형이며 경주당 총가중치1이다.
- M0는 능력값만으로 다시 적합한다. M1은 기존 기간별 연구에 저장된 게이트 전용 기준14개를 재사용한다. M1에는 내측/중간/외측 게이트와 거리·함수율 구간·달력월·두수 상호작용 및 능력값이 있고 현재 실제 주행위치는 없다. M0와 M1은 게이트 추가에 따른 재학습 절차의 비교다.
- 현재 경기장·거리의 과거50경주·20일과 과거 관측 조건 수준을 모두 충족한 경주를 공통 주 평가로 한다. 모든 출전마의 확률을 함께 계산하고 같은 경주에서3두가 입상하는 조건에 맞춰 합3, 각0.001~0.999가 되도록 제곱오차 최소 투영한다. 현재 결과는 정답 평가와 이후 날짜 업데이트에만 사용한다. 실제 개별 확률의 보정·운영 모델 승격은 아니다.
- M2는 M1에 이전84일의 같은 경기장·정확거리 게이트 잔차 편차만 추가한다. 중간/외측 두 변수의 경주별 중심값을 사용하며 각 경주일은 끝난 뒤 다음 날짜부터 반영한다. 현재 날짜는 학습에 넣지 않는다.
- 최근84일 잔차는 해당 평가 연도의 고정 기준으로 다시 계산한다. 이전연도 말의 잔차에는 해당 고정 기준의 학습표본이 포함될 수 있으나 현재 평가 날짜 이후의 정보는 없다. 과거 잔차 자체를 당시의 사전 예측이라고 표현하지 않는다.
- 반감기14/28/56일×과거 기준 강도40/80/120경주의9후보를 비교한다. 과거 게이트 설계 Gram의 경주당 평균을 ridge prior로 사용한다. 최근 내측0·중간·외측 추가효과의 최대−최소가5%p를 넘으면 함께 축소한다. 기본 게이트 효과 전체의 상한이 아니다.
- M0·M1·M2의9설정으로 총11후보다. 2022~2023년의 경주 동일가중 Bernoulli log loss로 경기장별 선택한다. 최소값+0.0001 안이면 M0→M1→더 큰 prior 강도→더 긴 반감기 순으로 선택한다. 선택과 무관하게 M0 대 M1 결과를 보존한다.
- 2024년 이후에는 선택을 고정하고 log loss·Brier·상위3두 적중수 비율을 같은 경주로 비교한다. 확률의 합3은 실제 입상자3명을 확정한다는 뜻이 아니다. 지표의 독립 단위는 경주이며 불확실성은 경주일 전체500회 재표집의 짝지은 손실 차이95% 구간으로 제공한다. 거리별·연도별 결과는 보조 표다. 이미 관찰한 후향 검증이며 새 미래 테스트나 수익 검증이 아니다.
- 자료 종료 다음날인2026-09-21 기준의 최근 게이트 편차를 저장한다. 2026-10-08 현재 당일 편향이라고 표현하지 않는다. 선택 후보가 M0/M1이면 최근 추가 보정은 선택하지 않은 것으로 보고한다.

## 검증과 보존

입력 해시·현재 실제 위치 미사용·과거 이력 날짜·연도별 학습 종료·당일 제외·투영 확률 범위/합·선택기간 분리·최근 상한·손실 집계를 검증한다. M0 별도 최소제곱·M1 저장 계수 적용·번호별 회귀와 원12두 대비·최근 ridge 풀이를 독립 경로로 확인한다. 결과·실패·지원 부족과 산출물 용량을 원 폴더와 중앙 결론에 보존한다. 기존 연구 수33개의 게이트 후속으로 연결하며 새 초 단위 보정·운영 반영은 별도 결정이다.
