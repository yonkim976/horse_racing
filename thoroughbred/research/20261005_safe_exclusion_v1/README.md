# 안전한 제외·후보6/7두·삼복6조합 실험

2026-10-05 완료. **비입상 제외 모델6개를 추가 학습하고 기존 후순위·동반입상 모델과 연결했지만, 최대6조합의 안정적 적중 개선은 확인하지 못했다. 운영 모델은 유지한다.**

사용자가 승인한 후순위 포착·동반입상 관계·후보6~7두와 최대6조합 연구를 이어 진행했다. 먼저 완료한 [후순위·동반입상 연구](../20261004_outsider_joint_v1/README.md)의 가중치를 재사용하고, 직전 논의인 입상마를 잘못 제외하는 비용과 제외의 실제 안전성을 별도 학습·검증했다. 후순위·관계 모델을 이번에 새로 학습한 것으로 집계하지 않는다.

## 학습과 예측 구성

- 서울·부산 각각2024/2025/2026용 비입상 head: 총6개. 심판기록·웹 추가 자료 없이 기존DB 피처261개를 사용했다.
- 이력2010–2016은 warm-up, 학습 정답2017년 이후, 이력T−2. 평가연도Y에 대해 초기학습2017..Y−3, 조기종료Y−2, 최종재학습은Y−2까지, 보정Y−1, 평가Y다. 예를 들어2026용 신규head는2024-12-29까지 학습하고2025년에서 보정했다.
- 비입상(착순>3)을 학습하되 실제 입상마를 비입상으로 오분류하는 손실 가중치8배를 고정했다. 단순히 기존 입상확률을 뒤집은 모델과 구별되는 실험이다. 가중치는 실제 확률이나 제외 안전률을 뜻하지 않는다.
- head의 뒤집은 원점수로 전체 삼복조합 공동분포를 만들고 이전 연도 삼복NLL로 온도를 보정했다. 부모 joint와 이 분포를 고정0.5/0.5 기하평균한 뒤 추가 온도를 보정한 것이 `fusion`이다. 두 독립 증거의 곱으로 해석하지 않는다.
- 낮은 입상확률 순으로 제외할 때 **제외한 말이 모두 비입상할 공동확률≥95%**인 최대 집합만 지우며 최소5두를 남긴다. 제외0두도 허용한다.95%는 모델의 조건으로, 실제 안전의 보장이 아니다.
- 최종 guarded 정책은 이전 연도 제외가능 경주≥100, 날짜 단위bootstrap2,000회의 한쪽95% 안전률 하한≥95%를 만족할 때만 제외를 활성화한다. 기존context 상위5두 중 제외되지 않은 말을 보존한 뒤fusion 순으로 최대7두를 채우고, 확률순으로6조합을 고른다.

온도·제외 안전 조건·선별 기준 모두 같은 이전 보정연도를 사용한다. 이 보정연도는 별도의 독립 안전 검증기간이 아니다. 결과 평가연도에는 다시 맞추지 않았지만2024–2026은 이미 여러 연구에서 사용한 후향 기간이다.

## 제외의 안전성과 실제 한계

이전 연도 안전 하한에 따라 서울은 세 평가연도 모두 제외를 껐다. 부산은2024·2025만 켰고2026은 껐다. 아무 말도 지우지 않을 수 있도록 만든 안전 조건이 실제로 작동했다.

| 제외 방식 | 서울 제외 경주 / 오제외 / 실제 안전률 | 부산 제외 경주 / 오제외 / 실제 안전률 |
|---|---:|---:|
| 신규head95%, guard 없이 적용 | 1,015 / 36 / 96.45% | 633 / 21 / 96.68% |
| 최종 guarded 정책 | 0 / 0 / 해당없음 | 463 / 15 / 96.76% |
| 부모 joint95%, guard 없이 적용 | 568 / 14 / 97.54% | 340 / 9 / 97.35% |

오제외는 **제외 집합에 실제1~3착 말이 한두라도 있었던 경주수**다. 안전률은 제외를 실행한 경주만의 비율이며, 전체 경주 적중률과 다르다. 신규head의 제외 실행 경주에서 평균 제외두수는 서울1.03두·부산1.01두 정도로 제한적이다. 실제 입상마를 전혀 지우지 않는 방식은 아니었다.

이전 연도 안전 확인은 서울375/360/352경주에서 실제안전96.53/96.11/96.59%였지만bootstrap하한94.88/94.55/94.85%로 미통과했다. 부산237/184/267경주에서는98.73/97.28/97.00%, 하한97.38/95.16/94.74%로 마지막만 미통과했다. 이력은 [guards.json](outputs/guards.json)에 보존했다.

신규95% 제외+상위7두가 제외 없이 상위7두를 고른 정책보다 적중수도 높지 않았다. 이미 확률이 낮아6조합에 잘 포함되지 않던 말을 지우는 경우가 많다. **같은 공동분포에서 후보를 줄이면 확률 상위6조합의 원래 확률합을 늘릴 수 없다.** 다른 모델로 분포를 더 정확하게 바꾸어야 제외가 조합 개선으로 연결될 여지가 있다.

## 남은 실패는 어디서 생겼나

최종 guarded 정책 기준:

| 결과/실패 원인 | 서울 | 부산 | 전체 |
|---|---:|---:|---:|
| 적중 | 853 | 529 | 1,382 |
| 실제 입상마 hard exclusion | 0 | 15 | 15 |
| hard exclusion 없이 후보군 밖 입상마 발생 | 979 | 721 | 1,700 |
| 실제 입상3두는 후보군 안, 정답6조합 누락 | 1,006 | 696 | 1,702 |

각 경주는 한 행에만 집계한다. 실패3,417경주의 약49.8%씩이 후보군 누락과 후보군 안 조합 누락이다. 제외 오류는0.44%다. 제외가 좋은지 여부와 별도로 **후순위 포착과 동반입상 조합 정확도를 둘 다 개선해야 한다**는 결론이다.

신규 혼합 상위6두 안에 실제 입상3두가 모두 들어간 비율은49.55%, 상위7두64.20%, 최종7두64.26%다. 후보7두 포함률64%는6조합 적중률64%가 아니다.7두의 삼복은35조합이며 그 중6조합만 선택한다.

## 경주 선별과 확률 품질

이전 보정연도의6조합 원래 확률합 중앙값 이상인 경주만 남기는 규칙을 고정했다. 최종 정책은4,799경주 중2,449경주(51.03%)를 남겼고, 그 안에서904경주 적중(36.91%)했다. 전체 적중1,382건 중478건을 함께 포기했다. 부모 역시2,453경주에서903적중(36.81%)이었다. 선별 효과를 신규head만의 성과로 해석할 수 없다. 배당·구매액을 평가하지 않아 수익률 결과가 아니다.

선택한6조합의 확률은 전체 분포의 원래 확률을 더했다. 제외나 후보군 축소 후 재정규화해 확신을 부풀리지 않았다. 확률 구간별 실적은 [trio6_calibration.csv](outputs/trio6_calibration.csv), 선별의 날짜bootstrap구간은 [supplement_summary.json](outputs/supplement_summary.json)에 있다.

전체 삼복NLL은 부모→혼합 서울4.13602→4.13039, 부산4.29683→4.29228로 소폭 감소했다. 서울NLL 차이−0.00563의95%구간은−0.00944~−0.00199로0을 포함하지 않지만, 부산NLL과 두 지역Top3Brier 차이는0을 포함했다. 이는6조합의 안정적 적중 개선이나 운영 우월성의 증거가 아니다.

## 등록된 운영 모델과 별도 비교

운영 `thoroughbred-main-20260919-v1`의 기존 재추론 결과와2026년 경주를 비교했다. 경주ID 외에 **마번·말ID·모든 숫자 착순**까지 일치하는1,258경주(서울733·부산525)만 사용했다. 운영NaN과API91/92는 숫자 착순 없음으로 비교할 때만0으로 통일했다. 실제 입상 정답은 바꾸지 않았다.

| 최대6조합 | 적중률 |
|---|---:|
| 운영 | 30.52% |
| 직전 연구 부모 joint | 30.92% |
| 이번 신규 혼합 전체 | 29.57% |
| 이번 최종 guarded·최대7두 | 29.49% |

운영 대비 최종 정책−1.03%p, 날짜bootstrap95%구간−3.08~+1.06%p. 직전 부모+0.40%p 역시−1.77~+2.53%p로 불확실하다. 운영 모델보다 좋다는 근거가 없다.2024–2026 전체 연구 비교표와 이2026 운영 비교표는 서로 다른 평가 집합이므로 섞어 비교하지 않는다.

## 검증·재현·결정

정책 단위테스트5개 통과. 별도 계산 [verify.py](verify.py)에서 신규head6개와 부모runner50,754행을 재추론하고 전체8정책4,799경주를 검증했다.783,042개 체크 통과, 최대 수치오차4.00e−15. 출전마·입상정답·제외집합·후보집합·6조합·확률합·실패분류·이전연도 보정 및안전 조건을 확인했다. 독립 검증은 같은 모델의 계산을 별도로 재현했다는 의미이고 새로운 독립 평가기간을 뜻하지 않는다.

원천DB·운영등록부·부모피처/가중치/예측·동결설정·코드57파일의hash가 그대로다. 완결 산출물은 `summary.json`, 검증은 `verification.json`, 추가 운영 비교 입력hash는 `supplement_summary.json`에 보존했다. 원천DB·기존연구·운영등록부를 수정하지 않았다.

```sh
.venv/bin/python -m unittest discover -s thoroughbred/research/20261005_safe_exclusion_v1 -p test_policy.py
.venv/bin/python thoroughbred/research/20261005_safe_exclusion_v1/verify.py
```

초기 재현 절차는 `run.py prepare`, `run.py train`, `supplement.py` 순이다. 완결폴더 위에 재학습/추가평가를 덮어쓰지 않는다. [PLAN.md](PLAN.md)와[config.json](config.json)은 학습 전에 고정했다.

**이번 후보 미채택, 운영 유지.** 제외 기준이나 가중치를 평가결과에 맞춰 다시 고르지 않는다. 이후 연구의 우선순위는 실패의 절반씩을 차지한 후보군 밖 입상 신호와 후보군 안 조합 순위다. 제외의 안전성을 높이는 연구만으로 현재 적중 문제를 해결했다고 볼 수 없다.
