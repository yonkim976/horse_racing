# 일별조교 기승자 번호와 이름 연결 검토

> 후속 작업: 사용자 승인으로 [일별조교 기승자 이름 적재](../20261015_daily_training_rider_links_v1/README.md)를 완료했다. 1,599,487행에 이름을 연결하고 송당스카이 충돌1행은 미확정으로 유지했다. 아래는 실제 적재 전 조사 결과다.

2026-10-15 확인 결과, **API18_1의 `prNo`는 공식 설명상 기승자 사번이며, 기수 기록에서는 공식 기수 번호와 직접 일치하는 경우가 많다. 이름 연결은 가능하다.** 다만 번호 미기재·조교보 등 기준정보 미대응·원천 충돌이 있어 전체 조교 기록을 자동 확정할 수 없다. 이번 단계는 조사와 검증이며 연구DB의 이름·ID 연결을 추가하지 않았다.

## 공식 정의와 직접 확인

[한국마사회 일별훈련 상세정보](https://www.data.go.kr/data/15058782/openapi.do)는 기승자구분·기승자사번을 제공한다고 설명한다. [기수일일조교일자 API234](https://www.data.go.kr/data/15089697/openapi.do)는 기수번호 `jkno`와 기수명 `jkname`을 함께 제공하며 명세 예시는 `080014`·김귀배다. 보유 API307 기수 프로필에서도 같은 번호·이름이 확인된다.

공식 일별조교의 조별 목록에서 제공하는 전체선택 기능으로 2026-09-28 서울·영남 상세를 직접 조회했다. 화면에는 말 공식 ID를 가진 링크, 입장·퇴장 시각, 기승자 표시가 있다. 같은 말·날짜·시각의 API행과 대조한 예시는 다음과 같다.

| 지역·말 | 조교 시각 | API `prNo` | 공식 화면 기승자 |
| --- | --- | --- | --- |
| 서울 무빙볼케이노 | 06:55~07:06 | `080405` | 김용근 |
| 서울 선돌풍 | 07:39~07:52 | `080434` | 김철호 |

`prNo`를 일률적으로 다른 체계의 번호라고 보거나, 모든 행에서 공식 기수 ID라고 보는 해석은 모두 피해야 한다. `prGubun` 원문 구분과 공식 인물 자료를 함께 대조한다. 조교사명 `trName`은 기승자명으로 대체하지 않는다.

## 전체 보유 기록의 연결 가능 범위

보유 일별조교는 2010-01-02~2026-09-28에 실제 행이 있는5,173,033관측이며, 연구 적재 범위 상한은2026-09-29다. 공식 ID의 앞자리0과영문자를 유지해 비교했다.

| 현재 상태 | 행 수 | 해석 |
| --- | ---: | --- |
| `prNo`와 보유 기수 프로필 ID 정확 일치 | 1,599,488 | 282개 번호에 이름 후보 연결 가능. 개별 과거 사건의 확정 연결 완료 수가 아님 |
| `prNo`는 있지만 프로필 ID 미대응 | 190,375 | 70개 번호. 조교보 등 포함, 이름 추정 금지 |
| `prNo='-'` | 3,383,170 | 번호 미기재. 조교사명이나 다른 날의 기승자로 채우지 않음 |

번호가 있는1,789,863행의 고유 번호352개는 모두6자리 문자열이다. 그중36개는`08A...` 형태이므로 숫자로 변환하지 않는다. 원문 구분이`기수`인 행 가운데 프로필 ID가 일치하는 것은1,306,077행이다. 동일 인물 번호가 서로 다른 시기의`기수`·`조교승인`·`조교보` 등 구분에 나타나므로, 이름이 연결되더라도 당일 역할은 원문 구분을 유지한다.

## 홈페이지 표본 대조와 예외

서울647행·영남601행, 합1,248행을 새로 조회했다. 지역·날짜·말 공식ID·입장·퇴장 표시시각이 유일하게 대응하는1,247행을 API와 연결했다. 홈페이지 시간은 분 단위이므로 원문 초를 보존하고 후보가 하나인 경우만 대조했다.

- 기승자 이름은399행에 표시됐다. 프로필 이름과 완전 일치347행, 이름 뒤의`(트)` 표시만 다른51행, 실제 이름 충돌1행이다. `(트)` 원문은 유지하며 표기의 의미나 당일 자격을 임의로 확정하지 않았다.
- 나머지 대응848행은`관`829행·`조`19행처럼 역할만 표시된다. 이 표시만으로 개인 이름을 얻을 수 없다.
- **이름 충돌1행:** 2026-09-28 서울 송당스카이,06:10~06:22. API`prNo=080608`는 보유 프로필의오수철과 연결되지만 홈페이지는유승완으로 표시한다. 어느 원천이 잘못됐거나 정정됐는지 확인되지 않았다. 원문 API 우선 원칙을 유지하고 두 근거와 충돌을 보존한다. 최종 기승자 이름 확정은 보류한다.
- 조번 표기 차이4행은 같은 공식 말ID·시각의 기록이지만 API와 홈페이지 조번이 다르다. 변경 원인은 미확정이며 조번으로 사람을 추정하지 않는다.
- 홈페이지 라온유나이트(ID`0056215`)1행은 같은 날짜의 보유API에 해당 말ID 기록이 없다. 같은 조교 시각의API에는 다른 말 내게로와줘(ID`0052115`)가 있으나 서로 다른 말이므로 연결하지 않았다.

## 이름을 추가할 때의 기준

1. 원문`prNo`·`prGubun`·`trName`은 유지한다.
2. 기수 프로필의 동일 공식 번호를 통해 검토용 이름 후보와 출처를 별도 열 또는 연결 원장에 기록한다. 인물 번호만으로 과거 당일 역할을 바꾸지 않는다.
3. 사건별 공식 화면이나 공식 기수 조교 자료로 대조한 기록에 검증 상태를 붙인다. 출처가 충돌하는 기록은 확정 연결에서 제외한다.
4. 프로필 미대응 번호·번호 없는 행은 미확정으로 남긴다. 이름만 같은 인물의 ID를 붙이지 않는다.
5. 과거 기승자 이름은 해당 조교 사건의 관찰값이고,2026년 프로필의 소속·성적·상태를 과거 모델 입력으로 소급하지 않는다.

기수 이름을 확인하는 보조 API234는 날짜별 기수·번호·조교두수 집계이므로 이것만으로 특정 말의 기승을 확정할 수 없다. API18 행의 공식 번호 및 사건별 근거와 함께 사용할 수 있는 보조 원천이다. 조교보·관리사 전체의 사번→이름 사전은 이번 조사에서 확보하지 못했다. 홈페이지는 최근1개월 조회를 안내하므로 과거 전체를 같은 화면에서 보완할 수 있다고 가정하지 않는다.
