# 더러브렛 전개 예측 v1

2026-10-03 사용자 요청으로 첫 전개 예측기를 개발한다. 기존 기준모델과 운영·제주 모델은 보존한다. 2010~2016년은 warm-up(이력 준비), 학습 정답은2017년 이후라는 합의를 유지한다.

## 무엇을 예측하는가

- **S1F:** 출발200m에서의 발표 통과순위. 예상 상대 위치와 통과순위1위/상위3위 확률.
- **G3F:** 마지막600m에 진입하는 지점의 발표 통과순위. 막판600m 소요시간이나 최종 착순과 구분한다.
- **위치 변화:** 두 지점의 예상 상대순위 차이. 서로 다른 지점의 주변 예측을 비교한 지수이며 전체 경로의 공동확률이 아니다.
- **초반 페이스:** 가장 빠른3두의 출발200m 평균시간. 이전 보정연도의 같은 경마장·거리 분포 하위25%는 빠름, 상위25%는 느림, 가운데는 보통이다. 전체 경주의 속도나 코너 경합 강도를 이 값 하나로 확정하지 않는다.

주 지표는 S1F 상대순위 MAE. leader/top3 NLL과 실제1위 선택, 상위3두 포함, G3F·위치 변화·초반시간 MAE를 함께 비교한다. 전개 예측 성공과 입상/수익 개선은 별도의 질문이다.

## 원천·누출 방지

현재 코어의 `confirmed_runners`, `section_measurements_api`를 읽기 전용으로 조회한다. 전개 첫 모델의 대상 편성은 이전 기준모델의 고정 경주·출발마를 그대로 사용하며, 지점별 모든 출발마의 순위1~N이 중복 없이 완성된 경주에만 해당 지점 정답을 부여한다. 일부 순위가 없다고 후보를 제거하거나 미완주를 후미로 임의 라벨링하지 않는다. 첫 기준모델의 상위 동착 등 제외는 그대로 상속한다.

과거 지점 순위는 실제 출발이력 전체에서 T−2 이하로 집계한다. 2010~2016년 상대 통과순위는 warm-up에 활용하고, 원시 초반시간은 주로 변경 이전 값을 섞지 않도록2017년부터 사용한다. 두 지점의 최근1/3/5/10회 상대순위·선두/전방 빈도·위치 변화·관측 수를 만든다. 괄호 통과조를 평탄화하거나 내외측 상대 위치를 물리적 거리로 변환하지 않는다. 이번 버전은 개별 말의 발표 통과순위만 사용하며 같은 통과조의 실제 공동 선두를 예측한 것으로 해석하지 않는다.

현재 편성에서 과거 초반 능력의 상대 순서·빠른 경쟁마 수·0.2초 이내 경쟁마 수·관측 부족 수를 추가한다. 마번은 표시/동률 정렬에만 쓰고 게이트 효과로 넣지 않는다. 기수 의도·당일 주로·실제 현재 전개는 입력하지 않는다. 순위·시간·최종 착순 정답은 별도 라벨 파일에 저장한다.

모든 현재 편성은 확정 출발마를 결과에서 재구성한 후향 조건이다. 사전 출마표 변경시각·과거 공개시각까지 입증된 실전 검증이 아니다. 2010년부터 관측했다는 사실만으로 해외·생애 이력이 완전하다고 표시하지 않는다.

## 모델·평가

`past_style`은 최근3회 상대 통과순위/시간을 이번 편성에 적용하는 단순 기준이다. `field_model`은 과거 기록66변수에 전개 성향과 상대 경쟁 변수를 추가한 작은 회귀 모델이다. S1F/G3F 상대순위와 경주별 초반시간을 각각 학습하며 서울·부산을 구분한다.

각 평가연도Y에서2017~Y−3 학습, Y−2 조기종료 선택 후2017~Y−2 재학습, Y−1에서 확률/초반시간 보정과 페이스 기준을 고정한다. Y년에 가중치·보정·기준을 갱신하지 않는다. 순위 점수의 남은 후보 softmax로 상위3착 분포를 만들며 보정연도의 실제 지점 상위3순위만으로 temperature를 선택한다. 다른 지점이나 최종 착순 분포와 결합하지 않는다.

초반시간 예측은 보정연도의 평균 잔차로 편향을 보정한다. 보정연도 거리별 분위수와 그 모델의 전체 잔차 경험분포로 빠름/보통/느림 확률을 계산한다. 같은 거리40경주 미만이면 페이스 분류는 미정이다. 이를 선행 경합 확률로 부르지 않는다. 이미 여러 연구에서 본2024~2026년 후향 평가다.

최종 입상 모델에 연결할 때는 해당 학습 경주보다 이전 자료만으로 생성한 **시간순 외부 예측**을 사용한다. 이번 버전은 전개기 자체의 평가이며 전개기 훈련 출력이나 실제 전개 라벨을 기존 입상 모델에 넣지 않는다.

## 실행

```bash
.venv/bin/python thoroughbred/research/20261003_pace_v1/run.py prepare
.venv/bin/python thoroughbred/research/20261003_pace_v1/run.py train
.venv/bin/python thoroughbred/research/20261003_pace_v1/verify.py
.venv/bin/python -m pytest -q thoroughbred/research/20261003_pace_v1/test_pace.py
```

입력·설정·코드·참조 기준모델 해시와 대상/제외 원장, 가중치·예측·평가를 새 `outputs/`에 저장한다. 기존 파일은 덮어쓰지 않는다.

G3F 위치·초반시간 오차도 개선됐다. 그러나 S1F 상위3두를 모두 맞힌 비율은 서울13.9%·부산16.2%이며, 단일 전개를 확정하기에는 불확실성이 크다. 순위 기대값과 선두/전방 확률을 함께 본다. 선행 경합·뒤에서 올라오는 실제 경로·최종 입상 개선이 검증된 모델은 아니다.

추가 진단으로 `diagnose_tempo.py`를 실행해 항상 ‘보통’으로 분류한 기준도 비교했다([CSV](outputs/tempo_normal_baseline.csv)). 서울2026년 빠름/보통/느림 분류는모델56.7%·항상보통58.6%로, 분류 기준을 이기지 못했다. 부산2024년도둘다52.3%였다. 나머지4개 경마장/연도는모델이 높았다. 이 추가 비교는 결과 확인 뒤의 진단이며 사전에 고정한 주 지표를 바꾸거나 모델을 재선택하지 않았다. 시간 MAE 개선과 페이스 범주 선택의 개선을 구분한다.

관련 테스트16개 통과, 원천·기준모델·등록부 보존/시간순 모델/100개 과거 이력/모델 재추론/확률 합·순서 등을 검증한114개 통과·실패0개. 표본 모델 재추론의 최대 차이는0이다. 다음은 시간순 외부 전개 예측을 착순 모델에 연결한 증분 비교다.
