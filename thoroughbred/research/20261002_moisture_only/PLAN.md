# 함수율 기반 주로환경 후속 연구 계획

2026-10-02, 결과를 보기 전에 고정한 1차 분석 계약.

- 대상: 서울·부산, 2018-01-01~2026-09-20. 새 API 코어 DB를 대조해 저장한 `20261002_track_source_reconciliation/results/api_study_population.parquet`를 입력으로 사용한다. 원천과 이전 연구를 수정하지 않는다.
- **주로빠르기/tempo_raw는 입력·보정·검증 어디에도 사용하지 않는다.** 상태는 숫자 함수율로 유도한다: 1~5 건조, 6~9 양호, 10~14 다습, 15~19 포화, 20 이상 불량. 숫자 20이 실제 정밀값인지 상한 표기인지는 미확정이다.
- 주 분석 `quality_filtered`: 상태·숫자 충돌 70경주와 양쪽 유효시간이 다른 서울 12경주를 합집합으로 제외한다. 민감도 `all_api`: 이 경주들도 원문 숫자·API 시간으로 포함한다. 불리하거나 유리한 결과를 보고 포함 여부를 선택하지 않는다.
- 기대시간: 기존 연구의 최근 동일 경기장·정확한 거리 직전 1·2회 기록, 1~365일 간격, 등급, 월, 부담중량, 마번 대용 게이트를 사용한 Ridge alpha=20. 전처리와 회귀 학습은 평가연도 이전 자료만 쓴다. 기대시간에 해당 경주의 함수율·실제시간·착순·주로빠르기를 넣지 않는다. 2020년부터 연도 외부 예측 잔차를 만든다.
- 공통 변동: 기대시간이 있는 말 4두 이상인 경주의 잔차 중앙값. 경주마다 같은 비중을 둔다. 출발200·마지막200·마지막600·전체시간을 따로 평가하고 겹치는 구간을 합산하지 않는다.
- 설명용 관찰 추정: 거리·연도·월·경주번호를 조정한 상태별 차이(건조 기준)와 정수 %별 차이(4% 기준). 경기장별·1200m 및 거리별 표본을 보존한다. 경주일 군집 95% 근사구간을 사용하고 상태/정수 값의 경주일이 20일 미만이면 근거 부족으로 표시한다. 원인 식별이나 개별 말 확정 보정은 아니다.
- 공통 잔차 예측: Ridge alpha=25; `함수율 없음 / 선형 % / 5구간 / 5구간+정수 %` 비교. 거리·월·연도추세·경주번호는 모든 후보에 동일하게 사용한다. 2024·2025·2026년을 이전 연도까지만 학습해 평가한다. 기본 판단은 MAE 차이와 경주일 대응 부트스트랩 95% 구간(1,000회, seed=20261002).
- 과거 기록의 환경효과는 **그 과거 경주 연도보다 이전 연도 자료로만 학습한 모형**에서 산출한다. 따라서 그 경주가 자기 조건 보정계수 학습에 들어가지 않는다. 당일 보정은 해당 경주를 뺀 다른 완료 경주 3개 이상에서 경주번호 간격 가중치 exp(-gap/3)와 수축 분모 +4를 사용한다. 과거 경주일 전체가 끝난 뒤 다음 날짜의 경주를 평가하므로 당일 후속 경주 결과 사용은 과거 해석에 한정한다.
- 다음 경주: 바로 직전 동일 거리의 유효 기록을 연결하며, 직전 경주가 기대시간 적격행이 아니면 건너뛰고 다른 과거 경주를 직전 경주로 바꾸지 않는다. `사전 기대시간만 / 직전 잔차 그대로 / 구간 보정 / 정수 % 보정 / 구간+다른 경주 당일 잔차`를 비교한다. 잔차 반영률 0.5 고정 비교가 기본이다. 각 후보별 반영률 {0,.25,.5,.75,1} 선택은 이전 평가연도만으로 하고 2024~2026년 결과로 선택하지 않는다.
- 다음 경주 평가를 `직전 경주가 이전 연도인 제한 표본`과 `직전 경주가 이전 날짜인 전체 표본`으로 나눈다. 전자는 기존 연구의 엄격한 범위와 유사하고, 후자는 실용적 범위를 넓힌 참고 결과다. 같은 연도라 해도 직전 경주 효과계수는 직전 연도까지로 고정된다.
- 원천 변경 효과와 다른 연구설계 변경이 섞이므로 기존 최종 보고서와 MAE 숫자만 직접 비교해 개선을 주장하지 않는다. 이번 설정은 상태 유도·품질 제외·보정계수 추정 시점·직전 경주 연결을 명확히 고친 후속 연구다.
- 2024~2026년은 이미 관찰한 후향 평가 기간이다. 새로운 독립 미관측 테스트라고 부르지 않는다. 운영 채택·등록부 변경·DB 발행·개별 말 원시기록 덮어쓰기는 수행하지 않는다.
