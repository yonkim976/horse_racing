# 이 세션의 작업 완료와 산출물 용량 기록

2026-10-04 사용자의 지속 지시. 이 주로·전개·구간 연구 세션에서 앞으로 지시받은 작업을 완료할 때마다 새 산출물의 파일 수와 크기를 기록하고 최종 답변에 보고한다. 프로젝트의 다른 세션에 적용할 지시는 아니다.

- 작업을 시작할 때 해당 경로의 기존 파일 목록·크기를 확인한다.
- 완료 후 새로 보관한 원천·분석 데이터·결과표·그림·코드·보고서·검증 결과·용량 기록 파일을 모두 집계한다. 파일별 상대경로와 정확한 바이트를 연구별 `outputs/artifact_inventory.json`에 기록한다.
- 신규 파일의 총용량과, 기존 파일을 수정했다면 수정 파일의 최종용량·순증감량을 구분한다. 기존 DB와 참조 자료의 크기를 새 산출물로 중복 계상하지 않는다.
- 임시 작업 파일·OS/브라우저 캐시·가상환경·메모리상 도구 응답은 보관 산출물이 아니므로 제외한다. 보관한 중간 실행 결과가 있으면 포함한다.
- 용량은 파일 내용의 논리적 크기 기준이다. 정확한 바이트와 MiB(1MiB=1,048,576바이트)를 병기한다. 디스크 할당량과는 다를 수 있다.
- [작업별 용량 기록](ARTIFACT_SIZE_LOG.md)에 날짜·작업·신규 파일 수·신규 총용량·수정 파일 수·순증감량·상세 명세 링크를 남긴다. 최종 답변에도 신규 총용량과 주요 구성 또는 가장 큰 파일을 보고한다.
- 완료 기록 자체의 크기도 집계한다. 최종 집계 후 파일을 수정했다면 용량 명세를 다시 갱신한다.

이번 지시 이전 작업의 크기를 소급 측정한 기록은 아니다. 첫 적용 작업은 서울·부산·영천1200m 등급별 구간 연구다.

2026-10-04 추가 지시: 연구로 새로 알게 된 내용은 [지속 정리·게시 정책](RESEARCH_PUBLICATION_POLICY.md)에 따라 연구 원본과 중앙 결론에 정리하고 웹사이트 게시용 요약을 준비한다. 이 용량 기록 의무도 함께 유지한다.
