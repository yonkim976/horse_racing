# 말별 심판 문구 저장 결과

마사회 홈페이지에 실제로 배치된 문구를 공식 마번과 과거 경주에 연결해 저장했다. 상황 분류와 가해/피해 판정은 수행하지 않았다.

- 홈페이지 수집: 2,981개 출전표, 미확보 페이지 0개.
- 보유 심판자료의 대상 12,546두 전부 홈페이지 표 행에서 확인.
- 표 원행 71,188행과 문구 73,801관측 보존.
- 같은 말·과거 경주·문구의 반복 관측을 출처 목록으로 묶은 기본 조회: 48,130문구, 9,196두.
- 대상 말 중 9,192두에서 문구를 확보했고, 3,354두는 이번에 조회한 홈페이지 행에 문구가 없었다. 함께 조회된 다른 말 4두의 문구도 공식 과거 명부와 연결해 보존했다. 문구가 없는 경우를 정상 주행·사고 없음으로 판정하지 않는다.
- 빈 문구 표 행 12,142행 보존. 날짜는 있지만 문구가 빈 18페이지도 재판독했으며 처음 보류한 이력과 HTML을 유지했다.
- HTML 별도 파서 대조 71,188행, 저장 문구 문자 구간·말·과거 경주·출처 대조 73,801관측. 7가지 저장 무결성 검사 위반 0건. 본문 자기 말 번호가 명시된 34,901관측은 과거 출전번호와 일치했고, 나머지 38,900관측은 홈페이지 행의 공식 마번 링크로 확인했다.
- 현재 출전번호 충돌·과거 명부 미확인·본문 자기 번호 충돌로 보류한 문구: 0건.
- API 문단 연결 원행 149,008행도 별도 보존. 홈페이지 문구를 아직 확보하지 못한 경주·말의 API 문단 89,140행은 기본 조회와 분리한 대조 자료다.
- 원천 연구 코어는 읽기 전용으로 사용했고 작업 전후 SHA256이 동일하다.
- 식별·빈칸·동명마·문자 위치 관련 테스트 12개와 Ruff 검사 통과.

## 저장 위치

- DB: `outputs/horse_steward_phrases.duckdb`
- 기본 뷰: `horse_steward_phrases`
- 홈페이지 원문 행: `website_card_rows`
- 홈페이지 문구 관측: `website_phrase_observations`
- 대조 보고서: `outputs/comparison_report.html`
- 전수 검사: `outputs/verification.json`
- 수집 원장: `collection_ledger.jsonl`
- 원본 HTML: `website_raw/`

## 범위

선택한 출전표별 최근 1년 이력을 모은 결과다. 각 말의 생애 전체나 모든 과거 경주의 홈페이지 문구를 전량 확보한 결과는 아니다. 서울·부산경남·영천 출전표를 조회했고 이번에 확보한 실제 과거 문구의 대상 경주는 서울·부산경남이다. 제주 자료는 포함하지 않았다. 홈페이지 표 행을 확보했다는 사실과 그 말의 모든 과거 문구를 확보했다는 사실을 구분한다.

저장된 실제 과거 경주 범위는 서울 2017-09-30~2026-09-13, 부산경남 2017-09-22~2026-09-04다. 과거 경주가 조회 출전표 날짜 이상이거나 366일보다 오래된 문구 행은 모두 0건이었다. 수집 시각은 과거 공개 시각으로 사용하지 않는다.
