# 심판리포트 제공 기간 확인

말별 저장 문구의 실제 날짜 범위와 원천 제공 방식의 변경을 구분했다. `availability.json`에 연도별 저장 수·API 원문 범위·원문 공백·공식 원천 URL과 HTML/HWP의 해시를 보존한다.

- 말별 저장분: 서울 2017-09-30~2026-09-13, 부산경남 2017-09-22~2026-09-04. 이 기간의 모든 경주 처리 완료를 뜻하지 않는다.
- 기존 API 수집 기록: 2010~2016년 정상 0행 응답. 서울 첫 원문 2017-10-14, 부산경남 2017-10-13.
- 공식 안내: 2017년 10월부터 웹페이지 방식 도입, 기존 PDF 공개는 2017년 12월까지 운영, 2018년 1월부터 중지.
- 서울 구게시판의 2004-05-02 글은 개별 기수 재결 설명이다. 2004년부터 모든 경주의 일별 리포트가 갖춰졌다는 근거로 해석하지 않는다.
- 부산 구게시판의 2005-09-30 제1일차 리포트 게시물과 HWP 첨부파일을 실제 확보했다. 게시일은 2005-10-02다.
- 2020-12-19 공식 공지에는 무고객 경마기간 리포트 미게재 방침이 있다.

2017년 이전 자료가 전부 없다는 결론은 잘못이다. 과거 게시글·첨부파일을 별도로 수집·판독해야 하며, 이전 자료의 전체 경주별 완전성은 아직 미확인이다. 이번 확인은 자료 제공 기간 점검이며 원천/말별 DB를 변경하지 않았다.
