# 구간기록의 함수율·월·게이트 시험 보정 v1

2026-10-08, 새 효과 계산 전에 고정. 사용자가 구간기록에 적용할 대략의 값을 요청했다. 기록 비교용 시험값을 만들고 운영 모델·DB·웹 배포·다음 경주 예측 평가는 변경하지 않는다. 풍향·풍속·주로빠르기·실제 주행위치 효과는 제외한다.

## 자료와 직접 분석 구간

기존151,074출전 품질 모집단과149,624출전 이상치 원장을 연결한다. 같은 표본을 유지하는 전체4MAD와최근2024년 이후4MAD를 사용한다. 기존 전체시간 잔차 이상치 규칙이며 구간별 이상치를 추가 제거한 결과로 표시하지 않는다. 기본 모형 최소100경주·30날짜·100마필,14개 지역×거리에서 가능한 기간만 적합한다.

직접 목표는 출발200m early, 마지막600m last600, 마지막200m late다. 세 구간은 겹치며 독립 합계 구간이 아니다. 기존 원천에서 검증된 계측/누적차만 사용한다. middle1=finish−early−last600(출발200m 이후부터 결승600m 전까지, 길이D−800m), middle2=last600−late(결승600m 전부터200m 전까지400m)를 구분한다. 서울4C530m·부산 관측 last400는 이번 신규 보정의 대상이 아니다.

## 추정

게이트 기본은 같은 경주+같은 마필 고정효과, 상태×게이트는 같은 경주+같은 마필 고정효과의 상호작용 모형이다. 기존 게이트/상태 설계와 통제·경주 동일가중을 그대로 사용해3목표를 동시에 풀고 같은 표본·설계에서 계수를 비교한다. 현재 실제 주행위치를 넣지 않는다. 효과는 관측 전개 선택을 포함한 조건부 차이이며 경로손실·인과 효과와 구분한다.

월은 기존 전체시간 연구와 같은 마필 고정효과·등급×연도·정확 숫자 함수율·두수·성별조건·마번·나이·중량·체중·레이팅·과거 이력 통제, 연간1·2차 sin/cos 곡선으로 직접 추정한다. 말·날짜 이원 군집의 더 큰 표준오차와 점별95% 구간·BH를 보존하되 유의성은 적용 스위치가 아니다. 월곡선은 연간12월 평균0 기준이며 0인 건조 기준 함수율과 기준이 다르다.

## 잠정 반영 강도

게이트 기본0.30×n/(n+100)×e, 상태 추가0.15×n_s/(n_s+100)×(e_s−e)를 사용한다. 각 실제 두수에서 평균0으로 중심화한 뒤 벡터 전체 수축으로 상한을 지킨다. 기본 상한 early0.05초/last600 0.08초/late0.04초, 상태 추가 상한0.02/0.03/0.02초다. 미식별 기본은 중립0, 미관측/미식별 상태는 기본만 유지하며 사유를 남긴다. 번호와 그룹은 중복하지 않는다. 전체시간 게이트 v1 수치는 수정하지 않는다.

월은0.30×n_month/(n_month+100)×월추정곡선이며12월 평균0으로 다시 중심화한다. 상한은early0.03초/last6000.06초/late0.03초이고 연간벡터 전체를 같은 비율로 축소한다. 기간 모형 자체가 없거나 월곡선이 식별되지 않으면0과 사유를 남긴다. 이 비율·상한·100출전은 정책적인 시험 시작값이며 최적화나 베이지안 추정 결과가 아니다.

함수율은 기존2025년까지 학습된 구간별 reference_seconds의지원 여부와후보량 add_seconds_retain80을 그대로 재사용한다. 서울 early/late60%,last60040%;부산 early/late40%,last60030%의기존 구간 후보이며 전체시간 서울80%·부산90%를복제하지 않는다. 미지원은null이다.

## 전체시간과 일치하는 중간 잔여값

직접 구간 보정 A_early,A_last600,A_late를 계산한다. 기존 전체시간 v1의 보정 A_finish를 그대로 사용하고 A_middle1=A_finish−A_early−A_last600, A_middle2=A_last600−A_late로 계산한다. 함수율·월·게이트 성분별로 같은 항등식을 적용한다. 이는 전체시간과 일치시키는 잔여 환산값이며 중간 독립 실증 추정이나 원인 분해가 아니다. 잔여값은 직접 구간에 설정한 상한을 공유하지 않는다.

early+middle1+middle2+late가finish이고 middle2+late가last600임을 원시·보정 양쪽에서 검증한다. last600와late를 전체시간에 함께 가산하지 않는다. 직접 구간 중 미지원이 있으면 해당 구간은null, 전체와 필요한 직접 항이 모두 지원된 경우에만 중간 잔여값을 계산한다. 전체 보정은 있어도 완결된 구간 보정이 없을 수 있다.

## 적용과 검증

기존 전체시간 적용 함수에 의존하는 읽기 전용 구간 적용 함수와 출전별 후향 원장, 상세 표·예시·게시 JSON·중앙 결론을 만든다. 기본은 월 끔, 게이트 v1전체; 강도0/0.5/1 선택 가능하다. 구간 함수율 자체도 후보이며 전체시간 채택과 구분한다. 자료 종료일서울2026-09-20·부산2026-09-18, 파일 사용 가능일2026-10-08 이전as_of를거부한다. 과거 예측 검증은 당시 이전 자료로 재적합해야 한다.

독립 명시적 희소 고정효과 풀이로1200/1600m 전체기간의3모형3목표를 확인한다. 수축·상한·중심화·이전기준 보존·원시/보정 항등식·개별과일괄적용·잘못된입력·입력해시·문서표 일치를 검증하고 용량을 기록한다.
