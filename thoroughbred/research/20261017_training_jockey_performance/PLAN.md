# 조교 기수 기승 확인과 경주 성적

2026-10-17 결과 계산 전 설정. 서울·부산의 기존2018~2026 출전 신원/과거 이력159,014행을 사용한다. 이전151,074 정상 기록 모집단보다 넓은 신원 원장을 쓰며 정상착순만 성적률에 포함한다. 경주 당일은 제외하고 직전14일을 기본,28일을 민감도로 한다. 일별 일반조교만 사용하고 출발조교·수영조교는 섞지 않는다.

기승자 구분은API 원문을 사용한다. 기수 프로필 이름이 연결됐다는 이유만으로 당시 역할을 기수로 바꾸지 않는다. 기수표기1회 이상이면기수기승확인,조교가있고구분이모두명시적비기수이면기수기승없음확인,기수표기가없고미상구분이있으면미확인이다. 조교 자체가 없는 행은 별도다. 조교승인·조교보를관리사/트랙라이더로임의변환하지 않는다. 기수 표기에 기수트랙라이더가 포함됐을 가능성은 사건별 홈페이지 확인이 없는 역사자료의 한계로 남긴다.

분류가 충분히 남은2018~2020은‘확인된 기수 기승 있음/없음’ 비교다.2024~2025와2026부분연도는‘기수 기승 확인/기수표기 미확인(역할미상 포함)’ 비교로 분리하고 실제 미기승 대조군이라고 부르지 않는다. 기간별 결과를 합쳐 하나의 효과로 만들지 않는다. 원천 날짜 수집이전체14/28일 지원되고 해당 말의 조교가1일 이상인 출전만 모형에 넣는다. 미수집을조교0회로 채우지 않는다.

기수 번호가 공식ID로 연결되고 실제 출전 기수ID와 같은 경우는‘출전 기수 조교기승 확인’으로 분리한다. 다른 기수만 확인된 경우와도 비교하되,최근 미상 조교일에 출전 기수가 탔을 가능성까지 배제한 것은 아니다. 이름만으로 ID미연결31행을 출전 기수와 매칭하지 않는다. 사건별충돌보류는 current-match에 사용하지 않는다.

평가항목은 우승률·3위이내입상률·상대착순(낮을수록좋음)·우승마와시간차(낮을수록좋음)다. 원시율,같은경주+같은말 고정효과,출전기수×연도·조교사 고정효과와직전/최근성적·연령·rating·중량·체중·게이트·공백·거리/등급변화·조교일수/시간/구보/습보를 통제한 관측차이를 구분한다. 조교량 통제를 뺀14일 민감도도 보존한다. 실제 조교 기승은 무작위가 아니며 작전·준비상태·선택판단이 남으므로 인과효과나 승부의지로 단정하지 않는다.

14/28일·기간별·지역별에 기수표기유무 단일항과출전기수/다른기수 두항의대비를 계산한다. 마필/날짜 이원·단일 군집분산의 대비별 최대를 사용한다. 기간×창길이×조교량통제 여부 내 지역·결과·대비 전체에BH q를 계산한다. 예측 모델의 추가 성능 검증은 이번 범위가 아니며 보정 상수·운영 적용도 하지 않는다.

선택한완전수집원천만연결하고observation_id의중복·역할·기수ID·경주전날짜범위·수집지원·행별분류를 검증한다. 원시집계와대표모형은독립계산으로대조한다. 연구DB는읽기전용이며원표식·운영DB·기존연구를수정하지않는다. 결과·검증·원천해시·게시요약·중앙결론·용량명세를 남긴다.
