# 함수율과 구간 전개: 주행심사1000m·실전1200m

2026-10-03. 결과 계산 전에 정한 분석 범위. 운영모형·DB·기존 보정 결정은 변경하지 않는다. 주로빠르기는 사용하지 않는다.

1. 주행심사: 검증된 참가자 원천 중 신마 사유의 합격·불합격, 유효 구간기록. 합격마만 제한하면 전체시간 통과 기준이 초반과 막판 관계를 만들어낼 수 있어 두 판정을 함께 본다. 합격마만의 표도 민감도로 제공한다. 과거2010–2023부터 학습하고 최근2024–2026을 해석한다. 초반·중반 페이스가 의도적인 조절인지 기록만으로 단정하지 않는다.
2. 실전1200m: 기존 원천 일치 검증의 구간기록과 게이트 연구의 정상 완주 집단·과거 이력을 일대일 연결한다. 사고·완주순위 불완전 경주와 기존82개 품질 제외 경주를 재포함하지 않는다. 2018–2023부터 학습하고 최근2024–2026을 해석한다. 등급별 원시 표도 보존한다.
3. 서로 겹치지 않는 구간: 1000m는 출발200, 다음200=T−G3F−S1F, 다음400=G3F−G1F, 마지막200. 1200m는 출발200, 다음400=T−G3F−S1F, 다음400=G3F−G1F, 마지막200. 전개 분류의 중반은 마지막200을 제외한 두 중간 구간의 합이다. 출발 가속 때문에 출발200과 마지막200의 초를 직접 비교하지 않는다.
4. 부산의 직접 관측 마지막400(2F_G)을 별도 연결한다. 서울은 코너 통과시간으로 마지막400을 임의 생성하지 않는다. 막판600은 앞 구간과 겹치므로 초중반 대 막판200 분류에 중복 투입하지 않는다.
5. 함수율 건조1–5·양호6–9·다습10–14·포화15–19·불량20이상. 최근 표는 전체·각 독립 구간·막판600·부산400의 평균·중앙값·P10–P90, 표본·날짜 수를 제공한다. 상하위 분위 기록은 임의 삭제하지 않는다. 1200m의 물리적 검증 범위는 T60–110초, S1F10–25, 다음400 각각16–45, G1F8–25, 부산40016–50이며 구간 순서도 확인한다. 주행심사는 이전 연구 valid_core를 그대로 승계한다.
6. 매 평가 연도보다 이전 자료만으로 Ridge(alpha=10) 구간별 조건부 중심값을 학습한다. 두 지역·두 모집단은 분리한다. 공통: 함수율 구간·월·성별·나이·부담중량. 실전 추가: 등급·rating·직전 경주까지의 prior_finish/prior_top3/prior_early·log_starts/log_gap. 당일 순위·배당·합격여부·전체시간은 설명변수로 사용하지 않는다. 미관측 성능을 보장하는 최적 par가 아니라 동일 조건의 경험적 기준이다.
7. 빠름/보통/느림은 학습기간의 해당 구간 잔차 P25/P75를 고정해 평가한다. 초반과 중반의 3×3 집단에서 막판 잔차·빠른막판 비율을 계산한다. 전체시간 또는 막판속도 비율로 집단을 나눠 자기상관을 만들지 않는다. 각 집단의 날짜 단위 재표집2000회 신뢰구간을 기록하며 날짜20개 미만은 소표본으로 표시한다. 신뢰구간은 학습한 기준의 추정오차를 포함하지 않는 조건부 구간이다.
8. 막판200 모델에 실제 초반·중반 구간시간을 더한 경우와 기본 조건만 사용한 경우의 과거 연도 분리 MAE를 비교한다. 막판잔차도 두 기준을 함께 남겨, 쉬운 초중반 덕분의 빠른 막판과 해당 전개에서 예상보다 빠른 막판을 구별한다. 실제 구간시간을 사용하므로 사후 기록 해석이며 출전 전 예측 검증이 아니다.
9. 함수율별 집단과 연도별, 합격마만/실전국6 등급 민감도를 보존한다. 관계가 지역·연도에 따라 바뀌면 함께 보고한다. 많은 탐색 비교의 유의성으로 인과효과나 새 보정치를 채택하지 않는다. 이상치 품질 원장·입력 SHA-256·분할/합계/독립 집계 검증을 보존한다.

품질 검증 보완: 검증에서2017년 신마7행의 함수율0/미확정을 발견했다. 다섯 함수율 구간에 넣을 수 없어 주 분석에서 제외하고 품질 원장에 별도 기록한다. 결과 개선을 위한 선택이나 조정은 하지 않는다.
