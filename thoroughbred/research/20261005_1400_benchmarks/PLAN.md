# 1400m 연구 범위와 실행 계약

2026-10-05 사용자 요청: 다음 거리1400m의 서울·부산 등급·주로상태별 기록 기준을 만든다. 기존 세션의 거리별 평가·지속 정리·용량 보고 정책을 따른다.

- 영천·제주와 주로빠르기를 제외하고 고정 스냅샷의1400m를 별도 추출한다. 코어DB는 읽기 전용이며 완료된 이전 연구를 덮어쓰지 않는다.
- 구간은200+600+400+200m로 정의하고 개별 말 원API 시간을 직접 대조한다. 결측·넓은 품질 범위 제외 원장을 남긴다.
- 평균·중앙·P10/P20/P80/P90·꼬리 평균과 인원, 실제 착순 상위3/하위3, 전체시간 선정 집단의 구간 평균, 두 기록점수를 보존한다.
- 2021~2023 개발평가로 상태효과 완화 강도를 선택하고2024~2026은 각 평가연도 이전 학습·직전3년 참조로 평가한다. 숨긴 셀 복원과200회 날짜 재표집을 함께 수행한다.
- 관측/추정·등급 참조/등급×상태의 표본을 구분한다. OPEN과 상위등급의 적은 날짜를 표시하며 기존 거리의 효과를 복사하지 않는다.
- 새 연구 폴더와 중앙 결론에 정리하고 게시용 Markdown/JSON을 준비한다. 실제 웹 배포·운영 보정 반영은 별도 작업이다. 모든 보관 산출물의 파일별 크기·총량·수정 순증감을 보고한다.

표본 확인 결과 두 지역에서10개 등급 모두 최근 참조가 있어100조합650행을 추정했다. 다만14조합의 최근 원관측은 없고69조합은 최근 상태 표본이 작다. 전체 등급 참조가 충분하다는 것과 모든 상태의 관측 근거가 충분하다는 것은 다르다.
