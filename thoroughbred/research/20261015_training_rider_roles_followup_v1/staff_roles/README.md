# 일별조교 기승자 구분과 조교보 사번 조사

조사일: 2026-10-15. 목적은 일별조교 API의 원문 구분, KRA 홈페이지 범례, `090xxx`/`091xxx` 번호의 이름 공개 자료를 구별해 확인하는 것이다. 운영 SQLite·Supabase는 조회하지 않았고, 이름을 새로 연결하거나 DB를 수정하지 않았다.

## 핵심 결과

1. **KRA 홈페이지 표시 범례는 공개되어 있다.** 말 프로필 조교현황 범례는 `이름=기수명`, `조=조교사`, `관=주로조교`, `생=교육생`, `이름(트)=기수트랙라이더`라고 직접 정의한다. 금주조교현황은 `후=기수후보생`도 정의한다. 따라서 `(트)`는 track rider를 가리킨다는 공식 근거가 있다. 반면 `관`은 사람 이름이나 관리사 신원이 아니라 화면의 `주로조교` 표시이고, `조`는 조교사 표시다. 각 화면별 범례 그대로 해석해야 한다.
2. **일별조교 API는 기승자사번과 기승자구분을 제공하지만, 사번→조교보/관리사 이름 기준표를 공개하지 않는다.** data.go.kr의 API18 설명은 필드명 수준으로만 `기승자구분`, `기승자사번`을 열거한다. 공개 기수 일일조교 API234는 `기수번호`·`기수명`을 제공하며, 기수 중심 집계다. 공식 공개 데이터 카탈로그를 검색했을 때 조교보/말관리사 사번-이름 사전 또는 명부 API/파일은 찾지 못했다. 이 결론은 공개목록 검색 결과에 한정되며, 내부 명부의 부재를 뜻하지 않는다.
3. **조교보는 규정상 기수와 별도 인력 범주로 취급된다.** KRA 경마시행규정 시행세칙(2014 공개본)은 조교사 면허 응시 경력 요건에 `조교보 자격`, `조교보로 근무`, `마필관리사`를 각각 명시한다. 따라서 조교보/관리사를 기수번호 계열의 사람으로 간주해서는 안 된다.
4. **로컬 텍스트 원문에서 exact token으로 검색했으나 ID+이름 짝은 발견하지 못했다.** `unmatched_rider_ids.csv`에서 별도 담당인 `080626`을 제외한 090/091 계열 69개 ID를 `data/raw`, `data/research`, `docs/research_archive/source`, `thoroughbred/research`의 JSON/JSONL/CSV/TXT/HTML/XML 대상으로 문자열 경계 포함 검색했다. 링크 조사 산출물 및 직전 리뷰 산출물은 검색에서 제외했다. 정확 토큰 매칭은 0행이었다. `data/raw`에는 `.gitkeep` 외 원문이 없었다.

## 해석상 제한

- API 원문 구분 `기수`, `조교승인`, `조교보`, `조교사`, `기수후보생`, `-`를 홈페이지 범례 `이름`, `(트)`, `관`, `조`, `생`, `후`와 자동 1:1 대응시키는 공식 코드표는 이번 검색에서 확인하지 못했다. 홈페이지 범례는 표현을 정의하지만 API `prGubun`의 완전한 값 사전을 제공하지 않는다.
- 보유 기수 프로필과 일별조교 `prNo`가 완전 일치하지 않는 조교보 번호는 ID 숫자 모양이나 이름 유사성만으로 개인 이름에 연결할 수 없다.
- 공개 API 목록과 최근 화면에서 과거 서울 2010~2021 조교보 명부를 대체할 별도 원천을 확인하지 못했다. 추가 연결에는 KRA의 역사적 사번-이름 대응자료가 필요하다.

## 공식 근거

- [data.go.kr: 한국마사회 일별훈련 상세정보 API18](https://www.data.go.kr/data/15058782/openapi.do) — 설명은 기승자구분·기승자사번을 제공한다고 열거한다.
- [data.go.kr: 한국마사회 기수일일조교일자 API234](https://www.data.go.kr/data/15089697/openapi.do) — 기수번호·기수명을 제공하는 일별 기수 조교 집계.
- [data.go.kr: 한국마사회 현역조교사 API235](https://www.data.go.kr/data/15089698/openapi.do) — 현역 조교사 이름·조·경주 통계를 제공하지만 조교보 사번은 제공하지 않는다.
- [KRA: 2022 경마시행계획 PDF](https://race.kra.co.kr/down/raceplan_2022.pdf) — 트랙라이더를 기존 말관리사와 구분되는 조교전문계층으로 정의한다.
- [KRA: 경주마 프로필 조교현황](https://race.kra.co.kr/racehorse/profileTrainState.do?Act=02&Sub=1&hrNo=015520&meet=2) — 이름/(트)/조/관/생 범례; 최근 6개월 화면.
- [KRA: 금주조교현황](https://race.kra.co.kr/trainer/thisWeekProfileTraineState.do) — 이름/조/관/후 범례; 현재 주간 화면.
- [KRA: 2014 경마시행규정 시행세칙 PDF](https://race.kra.co.kr/down/company/file_bylaw02.pdf) — 조교사 면허 경력 요건에서 조교보, 마필관리사 범주를 구분.

## 로컬 검색 재현 범위

대상 목록은 `../../20261015_daily_training_rider_links_v1/reports/unmatched_rider_ids.csv`의 090/091 계열 69개 ID다. 별도 확인 대상인 `080626`은 제외했다. ripgrep `--hidden --no-ignore`로 대상 폴더의 숨김/무시 파일도 포함하고, 대상 ID 각각에 exact token 경계식 `(?![A-Za-z0-9])`/`(?<![A-Za-z0-9])`를 적용했다. 0매칭은 원문 ID가 local text source에 있다는 근거가 발견되지 않았다는 뜻이며, 검색하지 않은 외부/내부 KRA 원천의 부재를 입증하지 않는다.
