# 일별조교 기승자 추가 확인

확인일: 2026-10-15. 연구 DB만 읽기 전용으로 조회했다. 이번 조사는 이름 확인과 분류 검증이며 DB 적재·수정은 하지 않았다.

## 1. API `080626` 기록의 표시 이름

**2026-09-04~09-10 영남 일별조교 31행은 마사회 공식 상세조교 화면에서 모두 `다비드`로 표시된다.** 날짜·meet·공식 마번·입장 시각·퇴장 시각으로 유일 대응을 확인했고 마명도 일치했다. 홈페이지 시각은 분 단위이므로 API 원문의 초 단위 값은 그대로 보존했다.

| 날짜 | API 080626 행 | 동일 사건 홈페이지 이름 |
|---|---:|---|
| 2026-09-04 | 6 | 다비드 전부 일치 |
| 2026-09-05 | 7 | 다비드 전부 일치 |
| 2026-09-06 | 6 | 다비드 전부 일치 |
| 2026-09-09 | 6 | 다비드 전부 일치 |
| 2026-09-10 | 6 | 다비드 전부 일치 |

예: 2026-09-04 오늘이순간(0047505) 06:12~06:26, 골드포켓(0053082) 06:32~06:46.

다만 **번호 관계는 아직 미확정**이다. `jkNo=080626` 공식 프로필 요청은 인적사항과 반환 숨김 jkNo가 공란이다. 정상 대조군 `080405`는 김용근과 같은 번호를 반환했다. 다비드의 공식 프로필은 `080584`로 조회되며 성명 다비드, 생년월일 1989-05-17, 데뷔일 2017-12-01을 반환했다. 따라서 API의 080626을 오기입이라고 단정하거나 080584의 공식 별칭으로 병합할 수는 없다. 동일 사건의 표시 이름 근거는 확인된 상태다.

- [공식 상세조교 화면](https://race.kra.co.kr/trainer/dailyAllTrainDetail.do): 날짜/meet 선택 또는 POST 양식 필요. 요청 양식과 응답 원본·SHA256은 official_web/capture_manifest.jsonl에 보존했다.
- [다비드 공식 기수 프로필](https://race.kra.co.kr/jockey/ProfilePersonItem.do?meet=3&jkNo=080584): 이번 확인에서는 POST 양식으로 정상 조회했다.
- 재현: `.venv/bin/python thoroughbred/research/20261015_training_rider_roles_followup_v1/verify_080626_events.py`
- 전수 대응 근거: `080626_exact_event_evidence.jsonl` / 집계·프로필 검증: `080626_verification.json`.

## 2. 나머지 090/091 계열 69개 번호

미연결 목록의 69개 번호는 서울 2010~2021 자료의 조교보·구분없음 기록에 나타난다. 이번에 조사한 KRA·공공데이터포털 공개 목록에서 과거 사번→조교보/말관리사 이름 명부를 찾지 못했다. 지정한 로컬 텍스트 원천 검색에서도 정확한 ID+이름 근거를 찾지 못했다. 사번 모양이나 조교사 이름으로 개인을 추정 연결하지 않았다.

69개 중 `조교보` 표기가 있는 번호는 62개, `-` 표기가 있는 번호는 52개이며 두 집합은 겹친다. 미연결 원래 목록은 이전 단계 reports/unmatched_rider_ids.csv에 있다. 이번 검색 범위와 제한은 [상세 조사](staff_roles/README.md), [로컬 검색 기록](staff_roles/local_search.json)에 남겼다. 공개 자료를 찾지 못했다는 결과이며 내부 명부가 없다는 뜻은 아니다.

## 3. 연구 DB에서 실제 관측한 API 구분

API 원문 prGubun은 다음 6종이다. `-`는 분류를 알 수 없는 원문 값이다.

| 원문 구분 | 행 수 |
|---|---:|
| - | 1,911,604 |
| 조교승인 | 1,552,997 |
| 기수 | 1,306,151 |
| 조교보 | 318,906 |
| 조교사 | 80,539 |
| 기수후보생 | 2,836 |

`트랙라이더`, `관리사`라는 독립 API 값은 현재 적재 자료에서 관측되지 않았다. 특히 `조교승인`을 곧바로 트랙라이더나 관리사로 바꾸는 공식 대응표는 확인하지 못했다.

## 4. 홈페이지 표시와 인력 종류

[마사회 말 프로필 조교현황 범례](https://race.kra.co.kr/racehorse/profileTrainState.do?Act=02&Sub=1&hrNo=015520&meet=2)와 [금주조교현황](https://race.kra.co.kr/trainer/thisWeekProfileTraineState.do)을 대조했다. 범례를 읽은 제주 화면은 공통 표시 확인에만 사용했으며 제주 데이터 적재는 하지 않았다.

| 홈페이지 표시 | 공식 범례 |
|---|---|
| 사람 이름 | 기수명 |
| 이름(트) | 기수트랙라이더 |
| 조 | 조교사 |
| 관 | 주로조교 |
| 생 | 교육생 |
| 후 | 기수후보생 |

`관`은 공식 범례상 **주로조교**다. 관리사 개인 이름이나 신원 확인 근거로 쓸 수 없다. API의 조교보·조교승인과 이 홈페이지 표시를 자동 1:1 변환할 근거도 확인되지 않았다.

기수·트랙라이더·조교사·조교보·말관리사·기수후보생/교육생 같은 인력 범주와 API 기록 분류는 구분해 관리해야 한다. [2022 경마시행계획](https://race.kra.co.kr/down/raceplan_2022.pdf)은 트랙라이더를 조교를 전담하는 전문 인력으로 설명하고 기존 말관리사와 구분한다. 해당 계획은 당시 정의의 근거이며 모든 시기의 자격·제도가 같다고 가정하지 않는다.

## 검증 및 보존

- 080626의 API 원문 파일 SHA256 및 공식 응답 8개 파일 SHA256 확인.
- 동일 사건 31행 유일 대응, 마명 일치, 다비드 표시 31/31.
- 원천 API 번호, 기승자 구분, 기존 이름 연결과 송당스카이 충돌 보류는 이번 조사에서 수정하지 않음.
- 조회에는 읽기 전용 DuckDB 연결만 사용. 운영 DB 조회·쓰기 없음.
