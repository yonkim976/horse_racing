# 출처와 변경 범위

2026-10-08. 외부 사이트를 새로 조회하거나 DB를 갱신하지 않았다. 프로젝트의 동결 실전기록과 기존 연구 코드를 재사용했다.

- 기준 모델: [기본 말별 평가표19](../20261008_horse_profile_model_v1/README.md). 입력 프레임178,497출전, 기존6개 평가표19모델과 동일 경주 결과를 대조군으로 보존.
- 기존 보정기록: [함수율·게이트 대리변수 연구](../20261003_pace_gate_moisture_v2/README.md)의 adjusted_records.parquet.326,327실전 이력, 원시시간·관측연도 이전 함수율 보정초·기존 지수.
- 추정 모집단: [성별별 경기력 연구](../20261007_sex_ability_gap/README.md)의 population.parquet.151,074행 중 환경추정에 필요한 과거 공변량만 사용. 전체기간에서 만든 common_recent_score·상대구간 백분위·당일 착순·배당은 읽지 않는다. 성별 연구의 보정량을 추가한 것은 아니다.
- 출발대 편성: [게이트·내외측 원천 연구](../20261002_gate_lateral_bias/README.md)의 runners.parquet. 실제 출전마번·원래 두수·상대3그룹으로 연결하고 연구자료의 품질 제외 뒤에 두수를 다시 줄이지 않는다.
- 월 추정·지원 규칙: [완주시간 월·게이트 공동 연구](../20261008_record_normalization_seconds/README.md). 같은 말 FE, 공변량 통제, 다섯 민감도·BH·보수적 후보. 고정2024년 최근창은 당시 이용 가능한 과거3/2완결연도로 변경.
- 게이트 추정: [초 단위 게이트 연구](../20261008_gate_lateral_seconds/README.md), [함수율별 게이트 연구](../20261008_moisture_gate_seconds/README.md). 실제 주행위치 자료는 사용하지 않고 게이트 기본/상태 모형 함수만 재사용.
- 게이트 수축·평균0·상한·fallback: [게이트 모델 후보v1](../20261008_gate_model_candidate_v1/README.md). 기존2026년 전체자료 결과표와 원장은 읽거나 과거 검증에 적용하지 않았다.

실제로 읽은 원천과 재사용 코드는[SHA256 명세](outputs/input_manifest.json)에 고정했다. 원천 DB·완료 연구 산출물·웹 평가표·운영 registry를 변경하지 않았다. 이 연구 폴더의 결과·문서·검증과 연구 목록의 소개만 추가한다.
