## 비교한 범위

- 서울·부산2024-01-05~2026-09-20의 같은4,799경주·50,754출전.2026년은 일부 기간이다.
- 기존 최소 기본모델의19개 입력을 그대로 유지한다. 원시 완주시간에 기존 함수율 보정, 후보 월 보정, 후보 게이트 보정을 더한 뒤 과거 지역×거리 중앙값/MAD 지수를 다시 만들고 최근 능력·변화·신뢰도를 계산했다. 입력 수를 늘리거나 주행심사·구간기록·기수·새 부담중량·새 성별 파생변수를 추가하지 않았다.
- 과거 기록 당시 게이트에 따른 영향을 완화하는 실험이다. 이번 경주의 게이트 유불리·실제 주행 내외측·예상 전개를 직접 입력하는 실험은 아니다. 실제 경주후 내외측 주행위치를 사용하지 않는다.
- 원시기록과 기존 함수율 보정초는 보존했다. 추가 보정은 기존 함수율 보정이 지원되는 유효 기록에서만 사용한다. 지원비율 입력도 기존 함수율 지원 정의를 유지한다.
- 학습 정답은2017년부터,2010–2016은 이력warm-up, 말의 이력은T−2. 평가연도Y에서2017..Y−3 초기학습/Y−2 조기종료/~Y−2 재학습/Y−1 삼복temperature/Y 평가를 유지했다. 동일 seed·하이퍼파라미터·1/두수 가중치로 신규18개Top3 head를 학습했다. 기본19의 기존6개 모델·검증 결과를 재사용했다.
- 말별Top3 raw score3개 합의softmax로 삼복확률을 만들고 전체 조합 중 최대6개를 선택했다. 새 우승 head·비가산 동반입상 모형·경주 선별·배당/수익률은 이번 범위에 없다.

## 시간 경계를 지킨 보정

2026년 자료까지 사용한 기존 연구표를 과거 검증에 그대로 넣지 않았다. 기록 관측 연도마다2018년부터 그 전년도까지의 자료로 계수·이상치 기준·지원 여부를 다시 추정했다. 두 개 과거 연도가 확보되는2020년부터 적용하고 이전 기록은 기존 보정을 유지했다. 보정 학습의 마지막 자료일과 기록 표준화 참조일이 적용 기록보다 최소 이틀 앞서는 것을 확인했다. 말 이력도 대상 경주T−2까지만 읽는다.

월은 서울1200/1300/1400/1800m, 부산1200/1400m의 기존 연구 가설 범위다. 같은 말 고정효과와 정확 함수율·등급×연도·두수·중량·체중·레이팅·과거 성적 등을 통제했다. 원시/MAD4/양끝5%/최근3완결연도/최근2완결연도 민감도, 지원·방향 일치, 전체/최근BH q<.05를 요구한다. 두95%구간의0에 가까운 끝 중 작은 값의 절반,±.30초 상한·.01초0방향 버림을 적용한다. 기존 연구의 고정2024년 최근창을 각 시점의 과거 완결연도 창으로 바꾸었다. 초기 연도에서는 창들이 겹치므로 독립 반복검증이 아니다.

게이트는 기존 후보v1의 말+경주 고정효과, 함수율 상태별 효과를 다시 추정했다. 기본30%·상태차15%와n/(n+100) 수축, 실제 두수별 평균0, 기본±.15초·상태추가±.05초를 유지한다. 정확1..N마번10/12두는 번호별, 나머지는 원래 마번 상대서열3그룹을 사용한다. 모든 대비가 식별되지 않으면 중립0, 상태 벡터만 없으면 기본만 사용한다. 이는 기존 엄격한 유의성 채택 규칙을 통과한 보정이라는 뜻이 아니라 작은 탐색적 수축 후보다.

전체353개 환경모형을 다시 적합했다. 월 후보의 비제로 셀은2020~2026년에 각각14/9/2/6/10/23/32개였다. 관측 연도별 근거가 달라 적용 범위와 크기도 달라진다. 평가기간의 실제 추가초 범위는 서울 월−.15~+.11초/게이트−.0623~+.0554초, 부산 월−.06~+.08초/게이트−.1121~+.0738초였다. 이전 답변의2026년 전체자료 기준 후보표와 계수의 학습기간이 다르다.
