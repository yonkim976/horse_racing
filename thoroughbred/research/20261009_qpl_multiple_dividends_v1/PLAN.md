# 복연 다중 적중과 실제 당첨 배당

2026-10-09. 이전 연구의 복연 선택 결과에서0/1/2/3개 적중 경주를 분리한다. 앞서 제시한 적중률은 하나 이상 맞은 경주 비율이며, 당첨 조합 수와 환급을 구분한다.

평균 배당은 로컬 운영 SQLite를 mode=ro/query_only/읽기 트랜잭션으로 조회한다. 서울·부산(마사회지역1/3), 2026-01-01~2026-10-09 중 완료 경주와 실제1·2·3착이 정확히 한 두씩인 경주를 사용한다. 실제 당첨2두조합3개에 해당하는 QPL 배당만 사용한다. 미당첨 모든 조합의 예상 배당을 평균내지 않는다. 동일 조합 관측은 observed_at_ms/id 마지막 행을 사용하고 양수/유한/9999.9미만만 정상값으로 취급한다.3개 모두 정상 배당이 있는 경주를 주 표본으로 삼으며 누락/특수값 수를 별도 보존한다.

전체 평균·중앙값·상하위1% 제외 평균(주 극단값제외 통계)·상하위5% 제외 평균(민감도), 지역별 수치와 실제자료 종료일을 보고한다. 배당행 단위 산술평균이며3개씩 완전한 경주만 사용하여 경주별 평균의 평균과도 일치한다.3개 배당을 더한 값은 평균 한 조합 배당과 구분한다.

모델 예측과 실제 배당 연결은2026년 동결 연구 출전명단/마번/말ID/정상화착순 전체가 로컬DB와 일치하는 경주만 사용한다. 현재말의 과거예측을 수정하지 않는다. 모든 선택 조합에1단위씩 동일 투입, 미당첨0, 다중 당첨은 실제 표시배당을 전부 합산한다. 합산 표시환급/투입조합수는 세금/절사/환급예외 미적용의 단순 총환급비율이며 실제 최종 순수익으로 표현하지 않는다. 전체 당첨 배당 평균과 모델이 맞힌 조합의 평균은 따로 제시한다. 이는 추가 사용 허가를 요청하는 단계가 아니라 요청한 복연 평가의 설명을 구체화하는 계산이다.

원천은 로컬 서울/부산 행만 동결 추출하고 해시를 보관한다. Supabase/제주/운영DB 쓰기/새 학습/선택 변경은 하지 않는다. 독립 원천 SQL 대조와 파생 데이터 재계산, 기존 다중 적중 수 재현, 선택 예산, 실제 정답 조합, 두 번/세 번 적중 합산을 검증한다. 중앙 결론·보고서·게시요약·용량을 기록한다.
