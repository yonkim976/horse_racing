# 전개 v2: 게이트와 함수율 보정 비교

사용자가 요청한 네 가지 비교를 구현했다. 결과와 연도별 수치는 [보고서](outputs/REPORT.md), [전체 지표](outputs/metrics.csv), [동일 경주 차이·구간](outputs/paired_differences.json)에 보존한다. 결과 계산 전 정의는 [PLAN.md](PLAN.md), 설정은 [config.json](config.json)이다.

## 결과와 다음 후보

2024년부터2026-09-20까지 S1F 관측이 완전한 서울2,756·부산1,946경주를 동일하게 비교했다. 아래 통과1위는 출발200m 발표순위1위이며 최종 우승이나 삼복승 적중이 아니다. 오차는 경주별 말 평균을 다시 경주 동일가중으로 평균했다.

| 입력 | 서울 S1F 순위 MAE ↓ | 서울 통과1위 선택 | 부산 S1F 순위 MAE ↓ | 부산 통과1위 선택 |
|---|---:|---:|---:|---:|
| 기존 v1 | 1.939두 | 38.72% | 1.983두 | 40.80% |
| 게이트 추가 | 1.880두 | 42.82% | 1.952두 | 41.62% |
| 전체기록 함수율 보정 | 1.939두 | 38.24% | 1.983두 | 40.96% |
| 둘 다 | 1.880두 | 43.14% | 1.952두 | 41.57% |

게이트 추가는 두 지역 모두3개 연도의 S1F·G3F 평균 순위오차를 줄였다. S1F 전체 순위오차의 게이트−기존 차이는 서울−0.05885두(날짜 bootstrap95% 구간−0.06622~−0.05128), 부산−0.03056두(−0.03686~−0.02451). G3F 평균오차는 서울2.005→1.980, 부산2.061→2.033두다. 확률 Brier도 두 지점에서 개선됐다.

통과1위 선택 개선은 서울에서 +4.10%p, 보조 구간+2.52~+5.65%p였다. 부산은 +0.82%p이나 구간−0.72~+2.28%p여서 확정적인 개선 근거가 약하다. **부산2026 S1F 통과1위는 기존39.17%→게이트38.61%→둘 다37.66%로 악화**됐다. 거리별 말 가중 순위오차도 부산1000m·1600m에서 게이트 추가 시 악화했다. 모든 조건에서 좋아진 모델이 아니다.

함수율 보정만 추가하거나 게이트 모델에 더해도 S1F 순위오차 차이는 매우 작고 날짜 구간이0을 포함했다. 서울의 함수율 단독 통과1위 선택은 오히려−0.47%p였다. 둘 다−게이트의 통과1위 차이도 양쪽 구간이0을 포함했다. 초반시간 MAE 변화 역시 대부분0.001초 미만이며 서울2026 분류 적중은56.75%→56.46%로 낮아졌다. v1의 보통 고정 기준58.64%보다도 낮아 이 분류 성능을 채택 근거로 삼지 않는다.

따라서 **게이트 추가를 다음 입상모델 연결 실험의 우선 후보로 유지하고, 함수율의 전개 추가 효과는 채택하지 않는다.** 전체기록을 건조 기준으로 비교하기로 한 기존 연구 합의는 유지한다. 그 환산이 기록 비교에 유용한지와 전개 예측력을 추가로 높이는지는 서로 다른 질문이다. 실제 주행 내외측·구간별 함수율·현재 주로 정보의 효과를 검증한 결과로 확대 해석하지 않는다.

관련 단위검증21개 통과. 독립검증411개 통과/0실패, 보존 모델별 예측 재현 최대오차0. 원천 DB·기존 v1·운영 등록부 해시 보존 확인. [검증 원장](outputs/verification.json).

## 입력과 범위

- 기존 v1 / 게이트 추가 / 전체 주파기록 함수율 보정 / 둘 다. 기존 모델은 재학습하지 않고 실제 보존 예측을 그대로 기준으로 사용한다. 변경 후보는 같은 학습·검증·보정연도, 같은 경주 및 동일 모델 설정으로 재학습한다.
- 서울·부산 별도. 2010–2016은 이력 준비, 정답 학습2017년 이후. 평가2024–2026년 보존자료. 원천 DB는 읽기 전용이며 운영 등록부와 기존 모델은 유지한다.
- 게이트는 출발 마번 대리변수와 전체 결과 카드 최대 번호 기준 상대 위치, 내/외 표시 및 과거 전개 성향과의 상호작용이다. 취소를 제거해 번호를 다시 붙이지 않는다. 경주 입력에는 빠른3두의 상대 게이트 평균과 과거 초반시간의 게이트별 분포를 더한다. 실제 횡방향 위치를 넣은 모델은 아니다.
- 과거 전체 주파기록은 서울80%·부산90%로 건조 기준 환산. 기존 horse_mad4 환경 추정 자산의 **전체시간 잔차만** 사용하며, 각 기록 연도 이전 자료로 거리×함수율 환경모형을 다시 적합한다. 원천 숫자 함수율만 사용하며 주로빠르기는 사용하지 않는다.
- 기존 환경 잔차가2020년부터 있어 최초계수는2021년이다. 합의한 거리 범위와 거리별 함수율 조건·건조 각각20경주일 이상을 충족하는 경우에 적용한다. 계수 없음·표본 부족·거리 범위 밖은 원기록을 유지하고 지원 원장에 구분한다. 불확실한 효과를0초로 확정하지 않는다.
- 환산값에서 기록지수의 과거 거리별 기준과 직전/최근3·5·10전, 같은 거리 기록 피처를 재생성한다. S1F·마지막200·600m는 원기록 유지. 환산 전체시간에서 막판 구간을 다시 역산하지 않는다. 기록과 통과순위 이력은 T−2일까지 사용한다.
- 초반시간 branch의 입력에는 원래 전체 주파기록 피처가 없어 함수율만 추가하면 기존과 동일하다. 게이트 및 둘 다의 초반시간 예측도 공유한다. 과거 보정과 현재 주로 예측은 구분하며 현재 함수율은 입력하지 않는다.

## 검증과 해석

1차 지표는 S1F 상대순위 MAE. 통과순위 MAE·통과1위·상위3두·Brier/NLL 및 G3F·초반시간을 함께 보고한다. 날짜 bootstrap1000회로 동일 경주 차이를 비교한다. 연도별, 거리별, 출발번호 내/중/외 구간별 오차도 보존한다. 구간별 표는 말의 출발 구간에 따른 순위오차이며 구간별 경주 적중률이 아니다.

이미 본 과거자료의 후향 비교다. 80/90 강도도 이전 연구 결과를 보고 정한 기준으로 독립 미래 평가라고 주장하지 않는다. 계수의 연도 분리와 이력 시점 제한을 지켰더라도 사전 출전표 공개·취소·물리적 게이트 자료 시점은 아직 확인하지 않았으므로 결과 편성에 조건부인 연구 성능이다. 확정 주행경로·선행경합 인과효과·삼복승 적중 개선을 뜻하지 않는다.

[verify.py](verify.py)는 기존 입력과 출력 보존, 피처 변경 범위, 시간 제한, 환경계수의 별도 Ridge 재현, 전 경주 순위 MAE 재집계, 키·확률합·모델별 수치 재현을 확인한다. [test_v2.py](test_v2.py)는 취소번호 간격, 전체시간 보정 부호/구간 보존, 미래 계수·미래 기록 영향 배제, 현재 통과정답 입력 배제를 검증한다.

## 삼복승 모델 연결 조건

이번 후보를 바로 최종 입상확률에 가산하지 않는다. 입상모델 학습행에도 그 경주 이전 자료만으로 만든 외부 전개 예측을 만들어야 한다. 현 분할 방식으로는 최초2020년 외부 예측을 만들 수 있고, 그 이전2017–2019 학습행은 전개 예측 결측과 가용 여부를 명시한다. 학습 경주 자체를 포함해 학습한 전개 모델의 출력이나 실제 현재 통과순위를 사용할 수 없다.

그다음 같은 시간 분할과 편성에서 기존 입상모델/외부 전개 추가 모델을 비교하고, 우승·Top3·조건부 동반 확률과 삼복승 상위6조합 적중을 따로 측정한다. 단위비용·동일 조합 수·취소 환급 기준을 맞춘 수익 검증 전에는 전개 개선을 수익 개선으로 해석하지 않는다. 미래 출전표와 게이트의 정확한 사전 시점을 확인하는 작업도 필요하다.

## 실행과 파일

프로젝트 루트에서 `.venv/bin/python thoroughbred/research/20261003_pace_gate_moisture_v2/run.py prepare`, `train`, 같은 폴더의 `verify.py` 순서로 실행한다. 준비·학습은 기존 출력 덮어쓰기를 거부한다. 출력은 기존 연구 폴더 정책에 따라 Git에서 제외한다.

`effects.parquet`·`environment_fits.json`: 계수·이전연도·지원 원장. `adjusted_records.parquet`·`record_references.csv`: 원기록/환산/지수 기준. `correction_coverage.csv`·`feature_changes.csv`: 적용 범위와 피처 변경. `runner_predictions.parquet`·`point_metrics.csv`·`tempo_predictions.csv`: 네 가지 비교 원출력. `models/`: 학습 모델·피처 계약·보정계수·입력/모델 해시. `verification.json`: 독립검증 결과.
