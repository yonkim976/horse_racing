# 편성 안의 초반 위치와 후반 움직임: 계산 전 계획

2026-10-08. 각질 연구28·28A·28B의 후속28C다. 서울·부산 실전2018~2026-09-20/09-18, 명단159,014행·통과조155,387행과 기존 정상 구간기록151,074행을 읽기 전용 재사용한다. 원자료18파일에서 출전 당시 기수/조교사 식별자와연령만 추가 대조한다. 제주·영천·심사·주로빠르기 제외. 기존 결과·DB·운영 모델·웹 배포 변경 없음.

## 질문과 구분

1. 과거 위치 성향만으로 하는 예상에 S1F·마지막600/200m 기록, 상대마의 과거 초반 능력, 게이트와기수/조교사 성향을 더하면 다음 실제 초반 위치가 더 잘 맞는가?
2. 상위등급 말의 성향과다음 위치 반복이 더 뚜렷한가? 이력량·거리 구성 차이와구분한다.
3. 후반 순위 회복과앞선 후퇴를 출전 전 변수로 구별할 수 있는가? 막판 시간의 빠름/느림도 별도로 저장한다.
4. 기수/조교사 과거 성향의 추가 정보는 있는가? 직접 관측된 전술 의도나 시도 여부로 해석하지 않는다.

## 누수 방지와 대상

- 실제 출전 명단 전체를 유지한다. 신마/결측 이력이 있는 상대마도 편성에서 제거하지 않는다. 예측 대상 경주의 S1F·G3F·G1F·착순·시간·함수율·체중·rating·배당은 입력하지 않는다. 현재 메타정보는 지역·거리·등급·게이트·두수·연령·출전 기수/조교사로 한정한다. 사후 정정/기수 변경의 실제 사전 공표시각까지는 감사하지 못하므로 실제 사전 발행의 검증과구분한다.
- 말의 최근5/10전은 원 명단의 실제 슬롯이며 각 경주T−2까지·730일 이내다. 결측을 건너뛰어 관측5전을 만들지 않는다. 부분 관측 평균과유효수/결측 표식,원래 슬롯 수를 함께 쓴다. 기존28A의유효5전 지원 조건도 저장하여 같은24,613행의별도비교를 한다.
- 기수/조교사 성향은 해당 경주T−2까지 직전365일의 관측 위치와,그 경주 전 말의 선행빈도 대비 앞선 진입 편차를 집계한다. 동일 날짜·전날 결과를 사용하지 않는다. 빈도는20회 강도로0.25에,조건부 편차는0에 축소한다. 미관측 식별자는결측 처리한다.
- 모든 모델·결측 대체·환경 정규화는 평가연도 이전 자료만 학습한다. 2024/2025는모델 고정 시간순 평가,2026은최종 사례 작성과프로필용이며 주 검증에포함하지 않는다. 선택적예시를 전체성능으로해석하지 않는다.

## 구간과 성향 입력

- 과거 정상기록의 S1F·마지막600m·마지막200m 원초와같은경주의 상대시간을 따로 저장한다. 매년 전년까지의 지역×정확거리·월·정확함수율 ridge10 환경모형으로 구간 기준 잔차를 계산한다. 등급을빼서등급간속도차이를자동소거하지않고현재/과거등급을다른입력으로보존한다. 2018년은환경잔차미관측으로두고원초/경주상대값만사용한다.
- 별도 마지막200m 조건부 모형은 환경·등급·rating·연령·부담중량과실제초반/중간을추가한다. 과거 경주를 설명하는 잔차이며 현재경주 실제초중반을입력하지 않는다. 이를정확한반응시간·에너지·피로기전·최적구간점수로부르지않는다.
- 최근5/10전 위치분포·상대위치평균/분산·선두1두율·과거 순위회복/후퇴,구간평균/유효수,최근거리/등급변화,이력수/경과일을 사용한다. S1F는반응+가속+추진이합쳐진200m확보력이지독립반응시간이아니다. G3F와G1F는겹쳐가산하지않는다.
- 편성 입력은다른말만의과거S1F잔차/원초순위와차이,선행/선입성향합,강한앞선후보수,정보지원비중,내측상대앞선성향이다. 상대마의현재실제초반이나착순은사용하지 않는다. 계산한후보밀집도를실제경합·압박의확률로표현하지않는다.

## 모델과 평가

- 첫마군 전체=선행,첫마군밖 상대위치≤1/3=선입,≤2/3=중단,그밖=후미의4범주를유지한다. 한경주여러말이선행범주일수있으므로선행확률합을1로강제하지않는다. 각말4확률합은1이다.
- 대조군: 기존지역×거리×두수 빈도와최근5전빈도의3회축소. 추가모형은동일한LightGBM(고정180나무·학습률0.04·15잎·최소잎150·L2=10·seed42·단일스레드)에서 (P)메타+위치이력 → (S)자기구간이력 → (F)편성비교 → (J)기수/조교사이력을순차추가한다. 평가자료로튜닝하거나나무수를선택하지않는다. 범주메타는고정one-hot이며말ID자체는입력하지않는다.
- 주비교는J 대 S의통합4범주Brier 차이. F 대 S, S 대 P, J 대 F는보조로같이보고한다. 정확도·로그손실·선행범주확률교정·최고선행확률마의실제첫마군포함률·지점별지원수도보존한다. 전체와기존5전지원공통표본을구분한다. 말/실제날짜/교집합군집의최대분산95%구간을사용하고4대비의BH도표시한다.
- 후반 회복 목표: G3F상대순위≥0.5이고그지점에서결승까지상대순위0.25이상회복. 앞선후퇴 목표: S1F선행/선입이면서결승상대위치가초반마군평균보다0.30이상뒤. 정상착순/해당순위가유효한행만목표를관측하며미완주를0으로바꾸지않는다. 육체적붕괴나의도적인추입전술의정답이아니다. 느린마무리/빠른마무리시간표식은보조로병기한다.
- 두후반목표도P와J로출전전확률을학습·평가한다. 실제현재초반위치로표본을사전선별하거나목표경주의구간을입력하지않는다. 각목표Brier·AUC·확률상하위20%발생률·교정과모형차이군집구간을보고한다.

## 등급과 사례

- 등급별현재관측·5전반복·분포집중도·예측오차를국6/국5/국4·혼4/국3·혼3/2/1/OPEN으로보존한다. 높은등급의원시정확도가높다는것만으로성향이더명확하다고주장하지않는다.
- 별도관찰대비: 상위1·2등급 대 국5·국6,지역×정확거리×평가연도×과거출전수(5~9/10~19/20+)×연령(2~3/4+)의공통셀에서각집단20출전이상인셀만비교한다. 조화표본수로가중한강한과거성향(4/5)비율과다음최빈각질반복률차이·말/날짜군집구간·2대비BH를보존한다. 승급원인·연령인과효과와구분한다.
- 최종 사례는2025년 말까지 학습한2026동결모형으로 자료 마지막 실제 경주를 계산한다. 사례 경주의 결과를 학습하거나 입력하지 않는다. 2026년은 주 성능집계에서 제외한다. 실제 전개도 병기하되 당시 사전 발행이나 미정 미래편성 예측으로 표현하지 않는다.
