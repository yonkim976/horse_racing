# 서울 1800m 기록의 구분 기준

2026-10-19 사용자 결정. 서울 1800m 기록을 **S1F·1C 동일 기록**과 **일반 비중복 기록**으로 구분해 문서와 후속 연구에서 사용한다. 이는 관측시간의 분류이며 실제 출발지점 변경을 확정한 분류가 아니다. 이번 결정은 문서 정리이고 DB·모델 입력·운영 보정을 변경하지 않았다.

## 대상과 두 기록군

기준 자료는 보유 서울 1800m의 2010-01-09~2026-09-20 결과다. 아래 건수는 **착순 1~30이고 완주시간이 양수인 정상 완주 18,014개 출전 기록** 기준이다. 경주 수와 말별 출전 기록 수를 구분한다.

| 기록군 | 판정 기준 | 기록 수 | 상세 시간 분할 |
| --- | --- | ---: | --- |
| **S1F·1C 동일 기록군** | 두 누적시간이 모두 양수이고 S1F=1C | **480건, 47개 경주** | 중복 1C 경계를 제거한 **7구간** |
| **일반 비중복 기록군** | 두 누적시간이 모두 양수이고 1C>S1F | **17,533건** | 서로 다른 S1F·1C를 유지한 **8구간** |
| 역순 예외 — 두 기록군에 넣지 않음 | 두 시간은 있으나 1C<S1F | **1건** | 원문 보존, 해당 코너 구간 평가 제외 |

480+17,533+1=18,014건이다. 일반군 17,533건 중 **17,532건은 전체 8구간이 정상 순서**이고, 나머지 1건은 다른 계측지점의 순서 문제로 완전한 8구간 평가에서 제외한다. 기록군 분류와 전체 구간의 유효성 검사는 별개다.

## 구간을 나누는 방식

**동일 기록군 — 7구간**

`출발 → S1F(1C 중복) → 2C → 3C → G3F → 4C → G1F → 결승`

S1F→1C의 0초 구간은 독립 구간이나 능력 점수로 만들지 않는다. 첫 200m를 두 번 합산하지 않는다.

**일반 비중복 기록군 — 8구간**

`출발 → S1F → 1C → 2C → 3C → G3F → 4C → G1F → 결승`

두 기록군의 초중반 기준치를 무조건 섞지 않고 구분해 비교한다. 코너 사이 정확한 미터 길이는 별도 검증 전까지 미확정으로 둔다. 두 기록군 공통의 확정길이 분할은 `출발→S1F 200m / S1F→G3F 1000m / G3F→G1F 400m / G1F→결승 200m`다. 같은 명목 길이가 같은 코스·난도라는 뜻은 아니다.

## 예외·결측·분모 관리

- 역순 1건은 **2010-07-17 서울 10경주 6번 아리새**, S1F 15.8초·1C 15.7초다. 동일군 또는 일반군에 강제로 넣거나 시간을 고치지 않는다.
- 전체 원천 18,376행을 볼 때는 비정상 착순 등도 포함되어 동일값이 481행이다. 그중 비정상 원문착순 91인 1행을 제외한 **정상 480건**을 이 문서의 동일군으로 사용한다.
- 전체 원천에서 둘 중 한 시간 이상 미제공인 281행은 별도 결측으로 둔다. 원문 0=0은 유효한 동일 기록이 아니다. 정상 완주 18,014건에는 이 결측이 없다.
- 동일군이 나왔던 날짜·야간 여부만으로 다른 기록을 동일군에 넣지 않는다. 개별 출전의 실제 누적시간으로 판정한다.
- 47개 경주의 실제 출발지점 변경은 개별 직접 근거가 확보되지 않아 미확정이다. 기록군 이름을 ‘출발점 변경 확정군’으로 바꾸지 않는다.

기존 1800m 기준표는 별도 선택·이상치·등급 필터를 사용하므로 위 원천 분류 건수와 표본 수가 다르다. 이번 문서 결정으로 기존 기준표를 재산출하거나 모델에 적용한 것은 아니다.
