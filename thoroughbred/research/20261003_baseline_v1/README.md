# 더러브렛 재개발 기준모델 v1

2026-10-03 사용자 승인에 따라 연구와 학습을 시작한다. 서울·부산만 대상으로 하며 제주·영천과 운영 DB·모델 등록부는 변경하지 않는다.

## 고정 질문과 비교

과거 성적 기준모델에 완주·구간 기록을 추가하면 우승·Top2·Top3 및 동반입상 확률이 개선되는가? `config.json`을 학습 전에 고정한다. 균등 착순 분포, `history`, `history_records`를 같은 경주에서 비교한다. 주 지표는 경주별 실제 상위 3착 순서의 negative log likelihood이며, 말별 Brier/log loss·확률 보정·복승/복연/삼복·고정 6조합·상위 5두 포함률을 함께 보고한다. 평가 결과에 따라 운영 모델을 자동 선택하지 않는다.

## 데이터·시점 계약

- 입력: 현재 208객체 코어 DB를 읽기 전용으로 조회한다. 이번 검증은 사용하는 경주·출전·구간 테이블 범위이며 전체 DB 재검증을 대신하지 않는다. 추출 Parquet와 DB·manifest·설정·코드 해시를 남긴다.
- 2010년 이후 실제 출발 이력(정상 착순, 실격91, 주행중지92)을 사용한다. 93/94/95는 비출발로 분리한다. 동일 말·일자 중복은 거부한다. 실격·주행중지는 입상 실패로 보존하고 해당 기록은 시간 피처에서 제외한다.
- **2010~2016년은 warm-up(이력 준비 구간), 2017년부터 정답 학습 구간**이라는 기존 기준을 유지한다([근거](../20260928_history_lookback_review/README.md)). 이전 기간은 출발 횟수·성적·과거 상태를 채운다. 서울 주로 변경 전 원시 시간을 섞지 않기 위해 이번 첫 기준선의 시간·구간 피처와 기록 기준 통계는 두 경마장 모두 2017년 이후로 제한한다. 이전 기록의 시기별 보정은 후속 후보이며 원천을 삭제하지 않는다.
- 현재 입력은 계획표의 거리·등급, 월, **확정 실제 출발마로 재구성한 편성**이다. 실전 사전 출마표·출전변경 시각의 완전성이 입증되지 않은 조건부 후향 기준선이다. 말 ID는 이력 연결에만 쓰며 모델 입력에 넣지 않는다. 마번은 표시·동률 정렬에만 쓴다.
- 말별 과거 이력은 경주일 T−2 이하만 포함한다. 현재 경주의 착순·기록·함수율·날씨·체중·부담중량·기수·조교사·배당은 입력하지 않는다. 상태 피처는 마지막 과거 출전의 나이·마체중·부담중량이다. T−2는 날짜 기반 사용 제한이며 역사적 공개시각이나 이후 정정 여부까지 증명하지 않는다.
- `history_count=0`은 보유 국내 자료에서 이전 출발을 관측하지 못했다는 뜻이다. 공식 신마·해외 무경력이나 완전한 생애 이력이라고 해석하지 않는다.
- 정상 상위 1/2/3위가 각각 한 두이며 출발마가 5두 이상인 경주를 학습·평가한다. 상위 동착·상위 착순 누락·알 수 없는 상태·중복 등은 경주 전체를 보류하고 제외 원장을 남긴다. 그 경주의 확정 과거 출발 이력은 이후 경주에 사용할 수 있다. 완주마만 골라 편성을 줄이지 않는다.
- 기록은 원시 값과 유효성 상태를 보존한다. 시간 피처 범위: 완주 평균속도 10~20m/s, 출발200m 10~30초, 마지막200m 8~30초, 마지막600m 28~90초 및 전체·구간 순서 정합성. 이상값은 피처만 결측 처리하고 평가 정답을 제거하지 않는다.
- `data_audit.json`의 `invalid_section_features`는 워밍업 시간의 의도적 미사용과 비완주·물리 범위 검사까지 합친 피처 제외 수다. 원천 품질오류 수로 해석하지 않는다. 학습연도별 실제 피처 가용성은 `feature_missingness.csv`에서 확인한다.
- S1F는 누적 출발200m, 막판 기록은 부산 직접 closing을 우선하고 없으면 완주시간−G1F/G3F 누적시간으로 계산한다. 구간 이상값 처리 수와 연도·경마장별 결측을 저장한다.
- 기록 지수는 해당 기록의 **이전 연도까지** 같은 경마장·거리의 정상 유효시간으로 만든 중앙값과 robust SD로 표준화한다(최소50표본, SD 하한0.5초). 이는 함수율 보정이 아니다. 함수율 환산·게이트·예상 전개는 다음 증분 실험의 후보로 남긴다.

## 학습·확률 구조

서울·부산을 각각 학습한다. 세 개의 작은 트리 모델은 1위, 실제 1위 제외 후 2위, 실제 1/2위 제외 후 3위 점수를 학습한다. 탈락시킬 정답은 학습 위험집합과 손실 계산에만 쓰며 피처에 넣지 않는다. 각 경주의 가중치 합은 단계별1이다.

추론은 모든 가능한 앞선 착순에 대해 남은 말의 점수를 softmax로 정규화한다. `Q(i,j,k)=P(i 1위)×P(j 2위|i 1위)×P(k 3위|i,j 앞선 착순)`에서 주변·승식 확률을 합산한다. 첫 기준선은 제거된 말의 정체성에 따른 별도 상호작용을 학습하지 않으며, 남은 후보의 분모만 바뀐다. 전개를 설명하는 완성 모델로 해석하지 않는다.

평가연도 Y마다:

1. 2017~Y−3년 학습, Y−2년으로 tree 수 조기종료 선택.
2. 선택한 tree 수로 2017~Y−2년 재학습.
3. Y−1년에서 단계별 temperature를 정해 실제 착순의 조건부 NLL 보정.
4. Y년만 평가. 해당 연도의 이전 날짜 결과는 이후 경주의 과거 이력으로 쓸 수 있지만 가중치·보정은 연중 고정한다.

범주 사전은 첫 학습기간에서만 만든다. 같은 경주·일자를 다른 분할에 나누지 않는다. 이미 관찰한 2024~2026년의 시간순 후향 검증이며 독립 미래 검증으로 부르지 않는다. 신규 모델은 새 원천·목표·표본이므로 기존 운영 모델 보고서의 숫자와 직접 우열을 주장하지 않는다.

## 실행·산출물

프로젝트 루트에서:

```bash
.venv/bin/python thoroughbred/research/20261003_baseline_v1/run.py prepare
.venv/bin/python thoroughbred/research/20261003_baseline_v1/run.py train
.venv/bin/python thoroughbred/research/20261003_baseline_v1/verify.py
.venv/bin/python -m pytest -q thoroughbred/research/20261003_baseline_v1/test_baseline.py
```

기존 출력은 덮어쓰지 않는다. 재실행은 새 연구 버전으로 진행한다. `outputs/`의 feature/label/split/race ledgers, 말별 예측, 경주별 평가, 보정표, 모델 metadata와 `REPORT.md`를 보존한다. 대용량 피처·가중치는 Git 제외다. 배당에 따른 선택·ROI는 이번 단계에서 평가하지 않는다. 현행 모델과 같은 표본·같은 시점 입력의 비교 및 미래 예측 저장은 후속 작업이다.

## 첫 실행 결과

[상세 보고서](outputs/REPORT.md), [평가 요약](outputs/summary.json), [검증 결과](outputs/verification.json)를 생성했다. 2017년 이후 프레임은 16,435경주·178,497출발마이며, 실제 평가 구간은 2024~2026년 서울2,838·부산1,961경주다. 서울 최신2026-09-20, 부산최신2026-09-18까지다.

| 경마장 | 비교 | 삼복 상위6조합 | 상위5두 실제 입상마 포함 |
|---|---|---:|---:|
| 서울 | 성적 중심 → 기록 추가 | 27.8% → 29.5% | 33.8% → 35.9% |
| 부산 | 성적 중심 → 기록 추가 | 23.6% → 25.9% | 28.1% → 30.4% |

기록 추가는 두 경마장·세 평가연도에서 주 지표인 착순 NLL을 줄였다. 우승·Top2·Top3 Brier도 전체 기간에서 개선됐다. 다만 서울2025년 우승축 적중률은31.1%→28.8%로 하락했으므로 모든 선택 지표가 매년 좋아진 결과로 해석하지 않는다. 평균 개선과 연도별 변화·경주일 bootstrap 구간을 함께 보고한다.

시점/워밍업/결과 상태/자료형/공통 확률 테스트6개 통과. 원천·등록부 보존, 입력·가중치 해시, 시간순 분할, 전체 예측 키, 확률 합·순서, 독립 원천 이력100표본과 가중치 재추론·별도 순열 계산을 포함한 검증146개 통과·실패0개. 별도 계산의 최대 확률 차이는8.88e−16이다. 이번 새 기준선과 기존 운영 모델의 직접 우열·수익성은 미평가다.
