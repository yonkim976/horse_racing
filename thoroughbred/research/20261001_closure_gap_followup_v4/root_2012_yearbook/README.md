# 2012년 마사연감 추가 첨부 확인

이전 조사에서 시설·사업 부속 파일만 확보했던 공식 게시물의 나머지 세 PDF를 추가 확인했다. 다운로드 요청 값과 HTTP 응답·파일 해시는 `capture_manifest.json`에 보존한다.

- `2012_masa_01.pdf`: 13쪽.
- `2012_masa_03.pdf`: 11쪽.
- `2012_masa_04.pdf`: 276쪽. 정기 휴장 전체 일정표는 찾지 못했다.

본문의 경주 미시행 표는 물리 21쪽/인쇄 18쪽(서울), 물리 70쪽/인쇄 67쪽(부산경남)을 전체 화면으로 확인했다. 서울 2010-08-21 4경주, 2011-01-23 7경주 이후, 2011-07-03 7경주, 2012-06-30 전 경주와 부산경남 2010-03-14 추모, 2012-12-07 폭설 미시행은 기존 판정 원장과 일치한다. 부산경남 2012-12-07은 12-14에 1개 보전경주를 시행했다고 적혀 있다. 기존 116경주 판정을 바꾸거나 정기 휴장 구간으로 중복 적재하지 않았다. 제주 장은 대상에서 제외했다.
