# 전개 예측 → 입상 모델 연결 비교

2026-10-04 사용자 승인으로 실제 연결 학습을 완료했다. **전개·게이트·기수·주행심사 등의 이력을 직접 넣은 후보는 입상 확률을 개선했지만, 그 위에 전개 예측값을 전달하는 추가 효과는 확인하지 못했다.** 부산의 이력 직접 입력은 삼복 확률 상위6조합도 개선했다. 서울의6조합 개선은 불확실하다. 운영 모델/등록부/원천 DB는 변경하지 않았다.

[계산 전 계획](PLAN.md), [고정 설정](config.json), [전체 결과](outputs/REPORT.md), [쌍차이와 구간](outputs/paired_differences.json), [독립 검증](outputs/verification.json), [세부 검증](outputs/details_verification.json)을 보존한다. 심판기록과 웹 수집은 사용하지 않았다.

## 실제로 연결한 구조

| 후보 | 입력 | 비교 목적 |
|---|---|---|
| records | 기존 재개발 v1의 기록 포함 입력 | 같은 기준선 유지 |
| context | v5의 base+distance+context 이력을 직접 입력 | 이력·게이트·기수·주행심사 등 관련 입력 묶음의 추가 효과 |
| context_pace | context + 시간순 외부 S1F/G3F distance 모델 예측 | 별도 전개 모델을 거친 예측값의 추가 효과 |
| context_pace_leader | 부산만 위 후보 + leader_context 선두 예측 | 부산 선두 직접 예측의 추가 효과 |

context−records는 거리 특징 하나의 효과가 아니다. gate/jockey/trial 등을 포함한 입력 묶음을 추가했다. 순수 연결 효과는 context_pace−context다. 추가 선두 확률을 기존 회귀 확률과 평균내지 않고 별도 열로 전달했다.

전개 전달값은 각 지점의 상대위치·예상 위치·선두/앞선3두 확률, 선두 확률의 편성 엔트로피와 상대 우위, 두 지점의 예상 상대위치 변화다. 엔트로피는 선두 확률의 퍼짐이며 실제 위치오차나 작전 의도의 정답은 아니다. 전체 주행경로의 공동 확률을 만든 결과도 아니다.

입상 모델은 기존과 같은1·2·3착 단계별 점수와 조건부 정규화 구조를 유지했다. 같은 입력 차이만으로 비교하며, 선행이면 감점한다는 임의 규칙을 추가하지 않았다.

## 시점과 표본

- 2010–2016은 warm-up, 입상 정답 학습은2017+로 유지했다. 전체 프레임178,497출발마·16,435경주.
- 전개 모델 연도Y:2017~Y−3 학습/Y−2 조기종료, ~Y−2 재학습, Y−1 확률보정, Y만 외부 예측.2020–2023의20개 head를 추가 학습하고2024–2026의15개 head는 v5에서 재사용했다.
- 외부 전개 예측117,501행.2017–2019에는 전개 예측값을 비워 두고 가용성0으로 표시했다. 실제 통과순위나 학습내 예측으로 메우지 않았으며 초기 학습 행도 삭제하지 않았다. 초기/후기 입력 가용성 차이는 남아 있는 한계다.
- 과거 이력과 전개 모델/보정의 최대 사용일은 예측 경주의T−2 이내다. 이력 시점 제한은 역사적 공개·정정 시각의 완전성을 증명하지 않는다.
- 입상 학습·보정도 v1과 같은 연도 분할. 평가2024–2026은 서울2,838·부산1,961경주, 총4,799경주이며2026년은9월 일부까지다. 현재 구간 정답이 누락된 경주도 입상 평가에는 포함했다.
- 새 입상 모델45개 head와 재사용 기준선18개 head를 보존했다. 모든 후보는 지역별 동일 평가 경주·출전마로 비교했다.

## 삼복 확률 상위6조합

| 지역 | 기록 기준 | 이력 직접 추가 | 전개 예측도 추가 | 선두 직접 예측도 추가 |
|---|---:|---:|---:|---:|
| 서울 | 29.53% (838/2838) | 29.81% (846/2838) | 29.81% (846/2838) | 미실험 |
| 부산 | 25.91% (508/1961) | 27.74% (544/1961) | 27.49% (539/1961) | 27.54% (540/1961) |

각 경주의 조합 확률 순으로6개를 선택한 결과다. 축마 고정6조합과 구분한다. [추천 조합](outputs/recommendations.parquet)에 실제6개 조합·확률·적중 여부를 남겼다. 새로운 실전 예측이나 DB 게시가 아니다.

기록→이력 직접 입력의 변화는 서울+0.28%p(날짜bootstrap95% 구간−0.78~+1.35), 부산+1.84%p(+0.67~+3.03)다. 부산은 삼복NLL도 개선되어 사전 계획의 두 목표 공동 개선 조건을 만족했다. 서울은 확률 지표의 개선이 있어도6조합 개선을 확정하지 않는다.

이력 직접→전개 예측 추가는 서울0.00%p(−0.67~+0.67), 부산−0.25%p(−1.07~+0.46)였다. 부산 선두 직접 추가 역시+0.05%p(−0.46~+0.61)로 뚜렷하지 않다.

전개 예측 추가는 서울 삼복NLL을+0.00410(구간+0.00081~+0.00782) 악화시켰다. 부산+0.00151(−0.00257~+0.00565)은 불확실하다. 축 후보1두의 적중률 상승과 함께 들어올3두 조합의 개선을 같은 효과로 취급하지 않는다. 확률 보정표와6조합 예상 합계/실제 적중은 [보정표](outputs/calibration.csv), [6조합 보정](outputs/trio6_calibration.csv)에 있다.

이력 직접→전개 예측 추가의 입상확률1순위 말 적중은 서울+0.78%p(구간+0.10~+1.44), 부산+1.07%p(+0.20~+1.91)였다.1두 선택만 보면 개선 신호가 있지만 이번 주목표인 삼복6조합의 추가 개선은 아니다. 부산의 이력 직접 입력도 축 고정6조합은+1.17%p(−0.10~+2.45)로 개선이 불확실하므로 확률 상위6조합의 결론과 구분한다.

## 이번 판단과 제한

- 부산 context는 다음 연구의 우선 입상 후보로 보존한다. 서울 context는 확률 개선 후보로 보존하되 기록 후보도 유지한다.
- 전개 예측값 연결과 부산 선두 직접 확률의 추가는 삼복 목적의 우선 후보로 채택하지 않는다. 기존 전개 모델은 전개 분석용으로 보존한다.
- 전개 예측은 같은 과거 입력에서 만든 요약이다. 이번 입상 구조에서 추가 정보가 부족했을 가능성이 있지만 실패 원인을 확정한 증거는 아니다. 공유 전개 시나리오에 따른 동반입상 관계는 이번 단계에서 학습하지 않았다.
- 반복 사용한2024–2026 기간의 연구 결과이며 독립 미래 검증이 아니다. 표본·후보 반복 비교의 구간을 미래 성능 보장으로 읽지 않는다. 결과표 기반 확정 출발 편성·기수·게이트 대리값이므로 사전 출마표/출전변경 시점까지 검증한 실전 성능이 아니다.
- 배당/ROI를 평가하지 않았다.6조합 적중 개선을 수익성 개선으로 바꾸어 읽지 않는다. 운영 승격·DB 게시도 수행하지 않았다.

## 검증과 재현

단위테스트7개 통과. 독립검증1,912개와 세부검증860개 모두 통과/0실패였고 최대 수치차는9.33e−15였다. 원천/등록부/부모 모델·피처 해시, 초기 결측과 전수 키·확률합, 전개35개 head와 입상63개 head 재추론, 별도 순열 확률·6조합 계산, 시간순 분할·모델 입력 허용 열, 세부집계·확률 보정·쌍차이와bootstrap을 확인했다.

표시용 전개 모델 ledger의 온도 값은 pandas JSON의 소수10자리 출력이다. 재현에는 해시로 연결된 모델 metadata.json의 원문 정밀도를 사용한다. 검증 산식은 거의 확실한 선두에서 소수 손실이 생기지 않도록 남은 항을 직접 합산한다. 학습 모델·예측 결과를 바꾼 수리가 아니다.

기준선의 말별 예측과 주요 경주 지표는 그대로 보존됐다. CSV 재저장 시 확률합 오차 진단 두 열에만 최대3.95e−31의 읽기/쓰기 소수 차이가 있어1e−30 이내로 확인했다. 주요 지표에는 동일한 완화 기준을 적용하지 않았다.
