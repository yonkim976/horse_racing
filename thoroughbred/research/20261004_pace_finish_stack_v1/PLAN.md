# 전개 예측 → 입상 모델 연결: 계산 전 고정 계획

사용자가 2026-10-04 연결 학습과 기존 대비 우열 확인을 승인했다. DB 및 운영 등록부는 변경하지 않고 기존 결과도 덮어쓰지 않는다. 심판기록·웹 수집은 사용하지 않는다.

## 질문과 후보

같은 출전마·학습연도·분할·입상 확률 구조에서 전개 이력과 시간순 외부 전개 예측을 추가하면 실제 입상과 삼복 상위6조합이 좋아지는가?

1. records: 새 재개발 기준모델 v1 history_records를 그대로 재현/보존.
2. context: v5의 기록 포함 base+distance+context 입력을 입상 모델에 직접 넣는다.
3. context_pace: context + 별도로 학습한 S1F/G3F distance 전개 예측.
4. context_pace_leader: 부산만 context_pace + leader_context 선두 확률. 서울에 이 후보를 만들지 않는다.

전체 context에는 게이트·기수·주행심사 등 과거 증분 입력이 함께 포함된다. context−records를 거리 특징 하나의 효과로 해석하지 않는다. context_pace−context가 예측값 전달 자체의 효과다. 후보·하이퍼파라미터를 결과 후 탐색하지 않는다.

## 이력과 외부 예측

2010–2016 warm-up, 정답 학습2017+, 과거 자료 T−2. 기존178,497행 전체 프레임과 정답을 사용하며 현재 S1F/G3F 누락 경주도 입상 평가에서 제거하지 않는다.

전개 예측연도2020–2026마다 2017~Y−3 학습/Y−2 조기종료, ~Y−2 재학습, Y−1 확률보정, Y 예측. 2024–2026은 v5의 검증된 모델을 재사용하고2020–2023은 같은 고정 설정으로 추가 학습한다. 모든 학습용 전개 값은 자기 연도 이전 자료로 만들어진 외부 예측이며 학습내 예측/현재 실제 통과순위를 대체값으로 넣지 않는다. 2017–2019는 예측 결측+가용성0이며 입상 학습 행은 그대로 보존한다. 해당 초기 구간 때문에 연결 모델의 입력 가용성이 시간에 따라 달라지는 한계도 명시한다.

전개 모델 입력은 v5 계약의 허용 열만 사용한다. 현재 기록/착순/통과순위/말·기수ID를 넣지 않는다. 각 예측은 사용 모델과 training/calibration 날짜를 기록한다. 모든 전개 모델/보정의 최대 날짜가 예측 경주의 T−2 이내인지 검사한다. 확률은 완전한 이번 편성에서 계산하며 현재 구간 정답의 유무로 예측을 걸러내지 않는다.

전달값: 가용성, 각 지점의 상대위치/예상 위치/선두 확률/앞선3두 확률, 편성의 선두확률 엔트로피, 다른 말 최고 선두확률과 차이, 두 지점의 예상 상대위치 변화. 엔트로피는 확률의 퍼짐이며 전체 위치 오차나 실제 기수 의도의 정답은 아니다. 부산 추가 선두 확률은 기존 회귀 확률과 섞지 않고 별도 열로 전달한다.

## 입상 학습·판정

서울·부산 별도, 평가2024/2025/2026 부분연도. 기준모델 v1과 같은 3단계 입상 점수/위험집합/softmax/temperature/하이퍼파라미터/연도 분할. 동일 경주에서 기록 후보의 저장 결과와 새 후보를 비교한다. 삼복 상위6조합은 조합 확률 순으로 선택하고 상위5두 축 고정6조합은 별도로 보고한다. 배당/ROI는 이번 목표가 아니다.

확률 주 지표는 ordered_top3_nll 및 trio_nll, 실제 선택은 top6_trio_hit. Top3 Brier/보정, 입상1순위/상위5두 포함, 복승·복연을 보조 지표로 보고한다. records/context/context_pace 및 부산 선두 후보의 사전 지정 쌍 비교를 경주일 cluster bootstrap1000회로 수행한다. 전체·연도·거리·등급·신마 관측 포함·거리 연장 포함 경주를 함께 보존한다. 확률개선과6조합 개선이 서로 다르면 둘을 구분한다. 수익성 향상으로 바꾸어 읽지 않는다.

주 비교에서 삼복 NLL 차이의95% 구간이 음수이고6조합 적중률 차이의95% 구간이 양수인 경우에만 두 목표의 명확한 공동 개선으로 분류한다. 한쪽만 개선되거나 구간이0을 포함하면 부분 개선/불확실로 남기고 운영을 자동 교체하지 않는다. 반복 사용한2024–2026 연구 기간이므로 독립 미래 확인이 아니다.

## 검증·보존

원천/등록부/부모 피처·모델 해시를 고정한다. 기존 기록 피처/정답/예측 키를 보존하고 동일 편성·연도별 완전성을 검사한다. 전개 모델 전체 재추론, 시간순 학습·보정 기간·현재 정답 비사용·초기 결측, 입상 모델 전체 재추론, 별도 순열 계산의 조합·주변확률 및6개 선택, 세부집계·쌍차이 재계산을 검증한다. 완료된 모델 묶음만 해시가 맞으면 재사용하고 미완료 묶음은 덮어쓰지 않는다.
