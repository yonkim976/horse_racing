# 말별 평가표 v1 설계

2026-10-07. **말 자체의 과거 능력을 먼저 설명하고, 이번 편성·게이트·당일 조건을 다음 단계에서 결합한다.** 현재 문서는 계산 및 표시 기준을 정한 설계이며, 새 평가표 계산·학습·성능 검증·운영 반영은 아직 하지 않았다. 기존 [258개 입력 사전](../20261006_feature_inventory_v1/README.md)과 [12개 학습 기준선](../20261006_feature_inventory_v1/baseline_contract.json)은 보존한다. 평가표의 모든 항목을 모델 입력으로 자동 채택하지 않는다.

## 평가 단위와 정보 시점

- 하나의 평가표는 `horse_id + target_meet + target_race_date + cutoff_date + profile_version`으로 식별한다. 같은 말도 예측 날짜에 따라 갱신된다. 이름만으로 연결하지 않는다.
- 경주별 표는 이 평가표에 `race_key + target_distance_m`을 연결한다. 동일거리 적합성은 이 단계의 조건부 항목이다. 편성 상대순위는 기본 말별 평가표에 넣지 않는다.
- 이력 종료일은 목표 경주일T−2. 해당 종료일까지 실제 확보된 자료만 사용한다. 원천 공개/수집시각이 없다면 날짜 기준 후향 평가라는 한계를 표시한다. 예측용 당일 정보는 별도 공개시각 검증 대상이다.
- 실전 출전수 등 경력은2010년 이후 이력, 전체·구간 시간 능력은2017년 이후 유효 기록을 사용한다. 모델 학습 정답 시작2017년과 구분한다.
- 최근 창은 **실제 출전 순서의 최근3/5/10전**이다. 결측 기록을 건너뛰어 더 오래된 출전을 끌어와 창을 채우지 않는다. 각 통계의 유효 관측수와 원천 날짜를 보존한다.
- v1의 전체 능력 요약은 경마장 이동 이력을 포함한 해당 말의 최근 실전을 쓰되 지역·거리별 표준화 지수를 사용하고, 혼합 경마장/거리 여부를 표시한다. 동일거리 및 구간 비교는 목표 경마장·거리로 제한한다. 다른 지역의 실측 시간을 직접 평균하지 않는다.

## 기록의 공통 단위

`q`는 기존 연구의 **건조환산 전체시간 기록지수**다. 클수록 해당 지역·거리 기준보다 빠르다. 해당 기록 연도 이전 자료로 만든 지역·거리 중앙값 및 MAD 척도, 지원되는 과거 함수율 보정 자산을 사용한다. 공식 rating·확률·등급을 맞춘 능력점수가 아니다.

보정 지원이 없는 기록은 기존 계산처럼 원기록 기반 지수를 유지하되 `correction_supported=false`를 함께 표시한다. 지원 부재를 보정효과0이라고 판정하지 않는다. 새 거리별par, 월·계절·시대·성별·연령 보정은 자동 연결하지 않는다. 과거 부담중량 및 기수 영향을 제거한 기록지수도 아니다.

## 평가 항목

최고기록과 최근 평균의 차이는 설명용 파생값으로 추가할 수 있으나 v1 필수값으로 늘리지 않는다. 최근3/5/10전·최소 관측수 기준은 설계상의 초기값으로, 예측 개선이 검증된 임계값은 아니다.

## 평가 신뢰도 표시

각 숫자에 `값 / 단위 / 유효수 / 출전창 / 최신 원천일 / 보정 여부 / 결측 사유`를 붙인다. 하나의 신뢰확률이나A/B/C 등급으로 합치지 않는다.

- 경력0회: 실전 능력 **평가 불가**.0점으로 입력하지 않는다. 주행심사를 별도 보조표로 연결할 수 있다.
- 통계창 유효1회: **단일 관측**. 최고값은 표시할 수 있지만 반복 능력·안정성은 보류한다.
- 최소조건 미충족: **표본 부족**. 원천 값과 횟수는 보존하고 해당 파생값은 비운다.
- 유효수가 충분해도 공백이 길거나 경마장·거리가 섞였으면 해당 날짜·혼합 표시를 함께 읽는다. 유효수만으로 확신도를 보장하지 않는다.
- 기록 결측, 참조 기준 부재, 동일거리 이력 부재, 보정 미지원은 서로 다른 사유로 남긴다.

## 기본 평가표 밖에서 결합할 정보

이번 등급·출전두수·상대들의 능력·상대 선행 압력·게이트와 예상 전개는 경주별 결합 단계에 둔다. 이번 부담중량·당일 마체중·당일 함수율은 확보시각이 확인된 별도 입력으로 둔다. 당일 체중이 없으면 직전 체중을 당일 체중처럼 채우지 않는다.

기수 관련 명시적 변수는 앞서 정한 대로 제외한다. 통과조·실제 내외측 주행·심판기록도 이번 설계에 추가하지 않는다. 주행심사는 실전과 합산하지 않고 심사일·S1F기록·세션 대비 값·관측수를 갖는 별도 보조표로 보존한다.

## 사람이 읽는 요약

한 말에 대해 최근/최고/반복가능성/변화/거리경험/구간/전개/자료부족을 각각 요약한다. 수치에서 확인한 사실만 서술한다. 예: “최근 평균보다 최고기록은 높지만 유효1회라 반복 능력은 미확인”이라는 구조로 표현하며, 실제 말에 적용하기 전에는 수치와 말 이름을 생성하지 않는다.

종합100점·가중치 합계·확정 각질·입상 확률을 수동으로 만들지 않는다. 말별 평가 항목과 원천을 보존한 뒤 어떤 묶음이 예측에 도움이 되는지 학습으로 검증한다.

## 구현·검증 순서

1. 첫 구현은1–4번 능력표와8번 경력·신뢰도 표시부터 만든다. 확장된 평가표와 기존12개 학습 계약을 구분한다.
2. 실제 과거 경주에서 경력0회/1회/충분한 말, 미완주, 장기 공백, 경마장 이동 사례를 읽어 정의를 검토한다.
3. 5번 거리 조건을 연결하고,6–7번 구간·전개를 차례로 추가한다. 이력 없는 조건을 다른조건으로 채우는 방식은 별도 검증한다.
4. 말별 항목의 원천일≤T−2, 보정 참조의 시간순, 결측/관측수, 실제 출전창, 상위2평균≤최고, std 최소조건을 확인한다. 해당 경주 및 미래 착순·시간을 바꿔도 평가표는 같아야 한다.
5. 이후 정보 묶음별 학습에서 기존 동일 평가 경주에 대한 삼복6조합 적중, NLL/Brier, 상위5두의 입상3두 포함, 지역·연도·경력별 변화를 비교한다. 평가표가 설명하기 쉬워지는 것과 예측 성능 개선은 별도 결론이다.
