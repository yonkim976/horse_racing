# 더러브랫 축 고정 후보 범위 확대 추가 검증

2026-10-09 완료. **현재 선택22개에서 축+상대4두6개 23.80% → 상대6두에서 점수합 최고6개 25.09%(+1.29%p, 날짜95% +0.57~+2.07%p). 53개 연구후보는 24.96%→27.01%다. 선택 규칙의 후향 개선 신호이며 새 학습·운영 승격은 없다. 후속 검증할 조합 선택 규칙 후보로 보존한다.** 제주 자료·코드·문서는 이번 작업에서 읽거나 변경하지 않았다. 기본 모델을 다시 학습하거나 확률을 보정한 횟수는0이다.

## 무엇을 고정하고 비교했나

현재 선택 기준선은 월+게이트+부담중량22개이며53개는 연구후보다. 기존 각 말 점수·온도·모형1위 축·전체 출전집합·구매6개·경주 수를 고정했다. `axis_pool5`는 축+모형2~5위의 모든6개, 주 정책 `axis_pool7`은 축+모형2~7위의15개에서 기존 로짓합 최고6개다. 전체15개를 샀다는 뜻이 아니다. `axis_pool6`·전체 상대·축 강제 없는 전체최고6개는 사전 고정 진단이며 결과를 보고 주 정책으로 바꾸지 않았다.

## 과거 시기 민감도

이전 연구에서2020~2023년마다 당시 이전 자료만으로 생성한53개 OOF 5,971경주에 같은 규칙을 적용했다. 24.95%→26.21%, 차이 +1.26%p [날짜95% +0.61~+1.87]다. 각 연도의 점추정도 양수였다. 이 기간은 앞 동반모델 학습과 피처 개발에 관련된 자료이므로 새로운 독립 미관측 검증이 아니다.22개2020~2023 OOF는 이번에 새 학습하지 않았다.

## 남은 실패의 위치

현재22개 확대 규칙의 실패 3,595경주:

- 축 자체가3위 밖: 1,937경주, 실패의 53.88%.
- 축은 입상했지만 상대 두 마리 중 적어도 하나가 모형2~7위 밖: 891경주.
- 축도 입상하고 상대 두 마리도 후보6두 안이지만,15개 중 선택6개에 정답 쌍이 없음: 767경주.

따라서 후보 범위 확대만으로 축 탈락을 해결할 수 없고, 후보군 안의 관계 선택에도 개선 여지가 남는다. 실제 선행 붕괴·당일 컨디션 등이 원인이라고 이번 결과만으로 확정하지 않는다. [실패 분해](outputs/failure_decomposition.csv),[신규 적중·손실 경주 전체](outputs/capture_events.csv),[실제 입상마 모형순위별 포착](outputs/capture_by_rank.csv).

## 운영 모델과 같은 경주 비교

전체 말ID·원래 마번·정상착순까지 일치한1,258경주에서22개 확대 규칙은 27.50%,53개 확대 규칙은 29.41%,기존 운영의 원래6조합은 30.52%다.22개−운영 차이는 -3.02%p [날짜95% -5.55~-0.46],53개−운영은 -1.11%p [-3.45~+1.31]다.

운영보다 개선됐다는 근거는 없다. 운영과 연구는 축·입력·학습·분포 구조가 다른 완성 방식이므로 조합 선택 변수 하나의 순수 기여로 비교하지 않는다. 실제 게시 구매나 배당·수익률 평가도 아니다. [운영 대응 비교](outputs/operating_comparisons.csv),[일치 장부](outputs/operating_alignment.json).

## 재현·제한·결정

이전2017+ 학습·T−2/730일 과거 입력을 유지했다. 평가12개 모형과 과거OOF8개를 재로딩해 모든 점수를 재현했고, 원래22개 전체최고6개와 앞53개 축고정 결과도 재현했다. 별도 코드로 모든 삼복 조합·확률·티켓·정답·bootstrap 구간을 다시 계산했다. 현재 정답 제거/교란·행 순서 변경에도 선택이 같다. 등록부·원천·모형 SHA 불변. [검증](outputs/verification.json),[사전 계약](PLAN.md),[출처 동결](outputs/source_lock.json).

기존2024~2026 개발 자료의 반복 평가이고 과거 실제 출마표 최초 게시·취소·정정 시각까지 재현한 것은 아니다. 부담중량 사전 공개 시각의 원천 한계와 과거 피처의 결측·지원량 한계도 승계한다. 이번 검증으로 운영 모델·선택 기준22개·웹·DB를 바꾸지 않는다. 후속 검증할 조합 선택 규칙 후보로 보존한다. 이후 기간의 독립 검증과 축 선정 개선을 분리해 진행할 필요가 있다.
