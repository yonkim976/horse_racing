# 서울 1600m의 게이트 차이를 다른 거리와 직접 비교

2026년 10월 7일, 새 거리 간 대비를 계산하기 전에 고정했다. 기존 게이트 연구의 서울 1600m 내측 우위 10.06%p는 이미 관찰한 결과다. 이번은 그 수치의 재현과 거리 간 차이의 후향 탐색이며 새로운 미래 검증이 아니다.

- 기존 `20261002_gate_lateral_bias/outputs/runners.parquet`의 품질 완료 모집단만 재사용한다. 서울, 2018~2026-09-20, 정상 순위 완결·6두 이상이다. 새로운 이상치 제거는 하지 않는다.
- 게이트는 취소마 제외 후 상대 마번순 3등분의 내측·중간·외측이다. 물리적 출발대 이동과 실제 주행 경로는 관측하지 않는다. 12두는 1~4·5~8·9~12다.
- 결과는 최종 Top3 여부다. 기존과 같은 경주 고정효과·경주당 가중치합 1, 레이팅·나이·부담중량·과거 상대착순/Top3/초반위치·출전수/간격 통제를 거리별로 적합한다. 현재 실제 주행위치·최종 배당·주로빠르기·풍향·풍속을 넣지 않는다.
- 1000·1200·1300·1400·1600·1700·1800·2000m를 비교한다. 1900·2300m는 원 연구의 50경주·20일 지원 미달로 정식 비교에서 제외한다. 모든 조건에서 같은 최소 지원을 적용한다.
- 주 분석은 전체기간의 `내측−외측 Top3 차이`다. 1600m 값에서 각 다른 거리 값을 빼는 7개 대비를 직접 계산한다. 양수이면 1600m 내측 우위가 더 크다. 7개 양측 검정에 Holm과 BH를 각각 제공하고 주 판단은 Holm<0.05다. 효과의 크기 순위와 차이의 검정 결과를 구분한다.
- 거리별 추정량의 경주일 영향값을 같은 날짜에 정렬해 공분산을 포함한다. 각 거리의 원 연구와 같은 유한표본 보정계수의 제곱근을 영향값에 적용해 원래 분산과 일치시킨다. 차이의 t근사 자유도는 두 거리 중 작은 경주일 수−1을 사용한다. 단순 독립 표본으로 가정하지 않는다.
- 민감도는 2024년 이후, 서울 1600m가 실제 관측된 날짜의 다른 거리, 정확히 마번 1~12가 있는 12두 경주다. 각 조건에서 최대 7개 대비를 별도 가족으로 보정한다. 주 결과를 본 뒤 유리한 조건을 선택하지 않는다. 민감도는 독립 검증이 아니다.
- 연도별 1600m 경주 수와 원시 위치별 Top3율, 중간 대비 내측·외측 차이를 함께 보존한다. 1600m가 더 강하더라도 인과적 주로 효과·개별 말 확률 가산·초 단위 보정으로 채택하지 않는다.
- 입력 해시와 원 연구 계수를 대조한다. 별도 최소제곱 솔버로 계수를 확인하고 날짜별 영향값으로 계산한 거리 간 분산을 다른 산술 경로로 확인한다. 원천 DB·운영·기존 연구 파일을 변경하지 않는다. 결과와 용량을 결론 폴더에 연결한다.

## 출전두수 확인 후 보조 분석 추가

첫 계산 뒤 서울 1600m 표본은 7~10두이며 12두 경주가 0건임을 확인했다. 사전에 정한 12두 민감도로는 1600m를 비교할 수 없다. 그래서 정확히 마번 1~10을 갖춘 10두 경주끼리의 비교를 사후 보조 분석으로 추가한다. 10두에서는 게이트가 1~3·4~7·8~10으로 같아진다. 원래 주 분석·민감도의 수치나 판단 기준은 바꾸지 않으며, 이 추가 결과를 독립 확인이나 사전 지정 주 분석으로 표현하지 않는다.
