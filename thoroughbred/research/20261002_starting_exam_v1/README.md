# 출발심사 API21_1 연구 DB 적재

## 범위와 결과

2026-10-02, 공식 [한국마사회 출발심사 성적정보 API](https://www.data.go.kr/data/15057405/openapi.do)를 연구 DB에 추가했다. 대상은 2010-01-01~2026-09-29, 서울(1)·영남(3)이며 제주(2)는 제외했다. 연구·모델 개발의 2017년 이후 기준은 유지한다. 운영 DB와 운영 서비스에는 접근하지 않았다.

| 항목 | 서울 | 영남 | 합계 |
|---|---:|---:|---:|
| API 원문 행 | 29,540 | 22,821 | 52,361 |
| 기준일 이내 적재 행 | 29,516 | 22,809 | 52,325 |
| 기준일 이후 제외 행 | 24 | 12 | 36 |
| 기록이 있는 날짜 | 1,840 | 1,698 | 3,538 |

적재 기록의 실제 날짜는 서울 2010-01-06~2026-09-18, 영남 2010-01-06~2026-09-19다. 요청 범위 전체 34개 연도×지역 조합의 API 응답 총건수와 원문 행 수가 일치했다. 날짜×지역 12,232칸은 정상 응답에 기록이 있는 경우와 없는 경우를 구분한다. API 응답에 행이 없다는 사실만으로 휴장·취소·미시행을 확정하지 않는다.

API21_1 출발심사 결과는 API22_1 출발조교 기록 및 API20_1 주행심사와 별도 자료다. 심사일·차수·번호·출전번호, 말·기승자·조교사·마주 원문, 판정·심사 사유·불합격 사유를 보존한다. 원문 일부 행은 선택 필드가 생략되어 있으며 날짜·차수·번호 일부는 JSON 숫자형이다. 필드의 존재 여부와 원래 자료형을 그대로 남겼다.

## 식별자와 검토 내역

| 역할 | 기존 공식 ID 연결 | ID 없음 | 기준정보에 없는 ID | 대체 표기 |
|---|---:|---:|---:|---:|
| 말 | 51,553 | 42 | 730 | 0 |
| 조교사 | 52,270 | 49 | 0 | 6 |
| 마주 | 52,236 | 65 | 24 | 0 |

말 미연결 730행은 공식 ID 507개에 해당하며, 이번 연구 DB의 말 기준정보에 해당 ID가 없다는 의미다. 원문 ID를 유지한다. ID 없는 42행도 원문·날짜·출전번호·출처를 보존하고 추정 ID를 넣지 않았다. 조교사의 `휴양마` 등 대체 표기는 실제 사람 ID 연결로 취급하지 않는다. 마주의 미연결 24행은 공식 ID 9개다. 역할별 예외 916건은 [연결 예외 원장](link_exceptions.json)에 원문과 페이지·행번호·해시를 남겼다.

기승자는 API의 `rider` 원문만 제공되므로 이름만으로 기수 ID를 생성하지 않는다. 심사 원문에는 조교승인자 등의 표기도 있어 기승자를 모두 기수로 간주하지 않는다.

### API와 보조 원문 차이

[보조 대조 요약](rpt_review/api21_comparison_summary.json)과 [차이 원장](rpt_review/api21_comparison_mismatches.csv)을 추가했다. 로컬 원문 파일이 있는 날짜·지역에서 API 36,786행과 RPT 후보 36,806행을 대조했다. 원문 파일이 없는 날짜의 API 15,539행은 RPT 누락 판정에서 제외했다.

- 날짜·지역·차수·심사번호·출전번호가 같은 키 중 단일 API 행의 마명 일치 36,576건, 마명 불일치 156건이다. ID 없는 API 42행은 API 마명도 모두 비어 있다. 그중 39행의 키에는 RPT 마명이 보이며 3행은 로컬 파일 날짜 범위 밖이다. RPT 후보 이름은 보조 원장에만 남겼으며 확정 이름·ID로 대체하지 않았다.
- 키와 마명이 같은 36,576건의 판정 비교는 일치 36,311·표기 차이 265건이다. 차이 중 RPT 판정란 공백 35건을 포함한다. 대표 공백 행의 실제 원문을 주 에이전트가 확인했다. 이는 API가 합격인 서울/영남 기록을 RPT의 공백으로 지우는 근거가 아니다. 두 원천의 갱신 시점·표기 변경 원인은 이번 조사에서 확정하지 않았다.
- RPT에만 있는 키 30개, API에만 있는 키 5개가 있다. 예를 들어 2018-05-10 서울 차수 35의 `킹리`는 API 출전번호 22, RPT 26으로 표기되어 양쪽 키가 각각 달라진다. 따라서 키 부재를 곧바로 실제 심사 또는 말의 누락으로 해석하지 않는다. API의 모든 수집 페이지가 총건수와 일치한다는 사실과 원천 간 키 차이는 별도로 관리한다.

사용자가 합의한 API 우선 기준에 따라 원문 행·판정·공식 ID를 유지했다. 차이 원장에는 양쪽 파일·페이지/행번호·해시를 기록했고, API에 없는 RPT 행을 임의로 추가하지 않았다. 차이의 원인까지 모두 해소된 상태는 아니다.

자연키가 동일하고 원문도 동일한 8개 키·16행은 모두 보존했다. 한 행으로 집계할 경우의 초과 관측은 8행이다. 자연키가 같은데 원문이 다른 사례는 없었다. 자연키 필드가 부족한 128행도 별도 QA 표시를 남겼다. 반복행을 모델의 횟수·합격률로 사용할 때는 후속 집계 규칙이 필요하다.

판정 원문은 합격 40,142·불합격 9,882·출전취소 1,381·출주취소 731·`-` 180·심사취소 6·출전제외 1·경주취소 1·합격유보 1행이다. 서로 다른 판정을 하나로 합치거나 `-`의 의미를 추정하지 않았다.

## 저장 구조

연구 DB: `thoroughbred/data/core_api_2010_20260929_v1/thoroughbred_core.duckdb`.

| 객체 | 행 수 | 내용 |
|---|---:|---|
| `starting_exam_observations` | 52,325 | 원문 관측, 공식 ID, 연결 상태, 출처, QA |
| `starting_exam_source_files` | 34 | 선택한 원문 페이지와 해시·수집 시각 |
| `starting_exam_partition_coverage` | 34 | 연도·지역별 정상 응답과 총건수 |
| `starting_exam_results` | 52,325 | 원문 필드와 역할별 연결 상태 |
| `starting_exam_sessions` | 3,538 | 날짜·지역·차수·번호 원문 그룹 |
| `starting_exam_qa` | 52,325 | 반복·키 누락·식별자 QA |
| `starting_exam_date_coverage` | 12,232 | 날짜·지역별 API 관측 상태 |
| `starting_exam_entity_links` | 156,975 | 말·조교사·마주의 역할별 연결 |

차수와 번호는 출발심사의 원문 그룹이다. 일반 경주의 키로 합치지 않았다. API에는 출발심사 거리 정보가 없어 1,000m 등의 값을 추가하지 않았다. 영남 원문은 API 권역을 유지하고 실제 부산·영천 장소를 임의로 구분하지 않는다.

원문과 Parquet에는 수집 시각을 기록했다. 과거 경기 전 공개 시각은 검증되지 않았으므로 후향 관측이며, 현재 시각을 과거 공개 시각으로 사용하지 않는다. DB 전체의 최종 동결·누출 검증 완료를 의미하지 않는다.

- 기존 DB와 명세는 `backups/20261002_before_starting_exam/`에 함께 보관한다. 적재 전 DB SHA-256은 `5c9fa0e4d53a776a643d045440717727c5a9299b158f43ea93109eb53e770ec7`, 적재 후는 `828942c5b59f4632998c12f142c4e18e4ee2e6316a0e5a56f826f37a68c726a6`이다.

초기 접속 환경에서 HTTP 오류가 발생한 29개 요청의 원문·실패 명세는 별도 캡처 디렉터리에 보존했다. 접속 환경을 바꾼 성공 캡처 34개만 적재에 선택했다. 실패 요청을 정상 0건으로 분류하지 않았다.
