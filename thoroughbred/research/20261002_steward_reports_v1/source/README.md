# KRA API215/API180_1 steward and sanction source capture

This package stores exact response-body bytes from the official read-only KRA OpenAPI endpoints `API215/JudgeReport` and `API180_1/sanctionHistory_1`. It requests annual `rc_year` + `meet` partitions for 2010–2025 meets 1/3 and 2026 meets 1/3/4, with 1,000 rows per page and at least 0.5 seconds between requests. The service key is read from project settings in memory only; source parameters, redacted URLs, raw response bytes, logs, and manifests do not contain it.

`api_observations.parquet` keeps one source-item occurrence and all original fields in `raw_item_json`; `api_exclusions.parquet` repeats out-of-scope occurrences with reasons. `api_page_ledger.parquet` records every request, including zero-row receipts, public parameters, timestamps, response metadata, exact body size/hash, and raw-page path. `raw_page_sha256_manifest.json` independently lists each exact response. The collector verifies page numbers/lengths and a stable partition `totalCount` before marking a partition complete.

API215 contains race-level narrative (`judgement`, `addJudgement`) and race locator fields, but no structured horse ID/entry number in observed rows. Horse numbers/names in prose are retained verbatim and are not automatically parsed into horse links. API180_1 uses `gubun` to identify the sanction subject: observed `말` records carry a horse ID in `prNo`, horse name in `prName`, and `chulNo`; `기수` rows carry a jockey ID in `prNo`. `kind`, `reason`, `fine`, `spDate`, and `stDate` remain source values; `etlTime` is preserved as an opaque source field, not treated as a publication timestamp.

## Captured coverage and review

The capture completed 70/70 annual meet partitions and 102 pages. It retained 61,439 source-item occurrences: 14,867 API215 reports and 46,572 API180_1 sanctions. Ten API180_1 items dated 2026-10-02 are preserved as excluded rows because they fall after the inclusive 2026-09-29 research cutoff; they remain in the raw page and `api_exclusions.parquet`.

API215 returned normal zero-count receipts for all 14 Seoul/Busan partitions in 2010–2016. Its first available row in this capture is 2017-10-13 and its last is 2026-09-20. Of 14,867 API215 race keys, 14,853 match the frozen 29,710-key confirmed-race export, while 14 keys match adjudicated nonexecution records. There are 14,857 confirmed-race keys without an API215 row. Annual response counts also differ from confirmed-race counts in years after 2017, so a successful API response does not establish complete report coverage. For example, API215 rows are below confirmed-race counts in both Seoul and Busan for 2020 and 2021. Some annual API counts are slightly higher than confirmed-race counts and can include cancelled or otherwise nonexecuted races; counts alone do not show which interpretation applies.

API180_1 returned positive counts for all requested annual partitions. It contains 46,562 in-scope occurrences across 21,431 distinct race keys: 31,978 `gubun=말` horse-target rows and 14,584 `gubun=기수` jockey-target rows. Horse sanctions are directly queryable by the string `horse_id` (source `prNo`, including leading zeros) and race key/date; the source item also supplies `prName` and `chulNo`. There are 67 extra occurrences across 57 repeated candidate sanction-event keys (exact repeated source rows); no occurrences were removed. The API supplies no event ID, and its repeated rows are preserved for later review. A race having no sanction rows is expected and is not a coverage failure.

These counts measure what the APIs returned during this capture. They do not establish how long each response has been published, whether all historical records remain available, or whether every expected report/sanction is represented. In a separate read-only review of KRA's official referee website, an older-report board route was found (board 69, 142 listed pages, with December 2017 posts and a 2017-12-27 notice about a change in report-publication method). That proves a historical web archive path exists, but the older attachments' contents, earliest date, and race-by-race completeness have not been verified or added to these API source files. See the sibling `official_web/README.md` and saved HTML/metadata for the inspected pages. Do not interpret API215's zero receipts as proof of no historical report.

`api_year_meet_coverage.json` contains every partition's requested count, pages, and returned race-date bounds. `core_race_comparison_summary.json`, `core_race_source_comparison.csv`, `api215_missing_confirmed_race_keys.csv`, and `source_race_keys_not_in_confirmed_core.csv` compare source race keys with frozen local research exports; they do not access the operational database. No production database or service was modified or loaded.
