# 심판리포트 적재 이상 여부 재점검

2026-10-02 적재 후 연구 DB와 고정 원문을 읽기 전용으로 다시 확인했다. 이번 검증 범위에서 저장·연결 무결성 위반은 0건이었다. 원문 공백과 표기 불일치는 남아 있으므로 전체 역사 자료가 완전하거나 모든 문장의 의미를 확정했다는 판정은 아니다.

## 저장 및 연결 검증

- 연구 DB 해시는 적재 직후 검증본과 동일했다. 기존 자료 보존 검증을 받은 DB에서 추가 변경은 확인되지 않았다.
- 고정 입력 38개와 공식 API 원문 102페이지의 해시·파일 크기가 모두 일치했다.
- 말별 원문 문단 연결 149,008행이 대상 경주·출전번호·공식 마번·명부의 마명과 일치했다. 동일 문단·말의 중복 연결은 0건이었다.
- 연결된 문단·말 언급의 참조, 원문 위치, 추가사항의 대상 경주, 중복 정리한 이력의 전체 출처 위치를 확인했다. 잘못되거나 누락된 참조는 0건이었다.
- 범위 안 제재 46,562행의 공식 대상 ID·출전번호 연결이 모두 검증된 상태였다.
- 과거 공개 시각을 확정한 것으로 잘못 표시한 행은 0건이었다. 실제 공개 시각은 계속 미확정으로 둔다.

15가지 검사의 상세 결과는 [재점검 원장](recheck_integrity.json)에 기록했다. 이 검사는 원문 표현의 의미를 전부 사람이 검토했다는 뜻은 아니다.

## 독립 연결 규칙 재검토

GPT-6 Luna xhigh 서브에이전트가 원문과 연구 DB를 읽기 전용으로 점검했다. 승인된 연결의 오연결 증거는 발견하지 못했다.

- 이름만 재사용한 언급 3,249건의 근거가 모두 같은 원문 필드·대상 경주·출전번호·공식 말 ID에 속한 유효한 번호·마명 언급이었다. 일부 근거는 문서상 뒤에 등장한다. 문서 설명의 ‘앞서’ 표현을 실제 규칙에 맞게 수정했으며 데이터와 연결 규칙은 바꾸지 않았다.
- 추가사항 문단 4,136개가 저장된 대상 경주 판정과 일치했다. 연결 2,769행의 대상 경주도 일치했다. 미래 대상 연결은 0건이었다.
- 요일 불일치 33문단 관측과 서로 다른 경주가 함께 적힌 42문단 관측은 모두 연결되지 않았다. 숫자는 하루의 여러 경주에 반복되는 원문 관측을 포함한다.
- 불완전한 인용부호 때문에 `와`가 이름 후보로 잡힌 사례가 있었다. 실제 말로 연결되지 않았으며, 미확정 후보에는 이런 파싱 잡음도 포함된다. 6,162행을 모두 말이나 원천 오류의 수로 해석하지 않는다.
- 추가사항의 경주장은 API 경주장을 따른다. 문장 내부의 경주장을 독립 판정하는 기능은 없으므로 일반적 한계로 남긴다. 주 에이전트가 승인 연결된 추가사항에서 경주장 명칭이 포함된 서로 다른 문단 2개를 추가 확인했으며 다른 경주장의 대상을 잘못 연결한 증거는 없었다.
- 추가사항을 대상 경주·말·문단만으로 묶으면 371개 그룹이며, 현재 조회 뷰는 부모 보고일도 보존해 373행이다. 부모 보고일이 다른 2건까지 동일 사건으로 합치는 판정은 하지 않았다. 일반 문단을 포함한 146,612행을 고유한 사고 횟수로 사용하지 않는다.

현재 DB는 출처와 보류 항목을 유지한 연구 자료로 사용할 수 있다. 전체 기간의 리포트 완전성, 미확정 문장 연결, 모델의 정보 이용 시점 검증은 완료 전이다.
