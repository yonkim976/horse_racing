# 연구58D: 동적 상태의 원인 분해와 공동확률 보정

2026-10-22. 연구58C 뒤 사용자가 후속 진행·보고를 승인했다. 서울·부산의 원인 분해 3개 후보와 확률 보정 1개 계열로 제한한다. 운영 변경 없음.

## 질문과 비교

기준은 58C의 state_gbm(118변수), strong89, 과거 EL89/F103 및 state_joint다. 같은 4,799경주·50,754출전마, 축1두·복승/복연1·3쌍. 확정된 모델/점수/상태를 참조하며 복제하지 않는다.

새 학습은 세 가지뿐이다.

1. rank_only: EL89 + 순위 상태 9변수(능력·거리반응의 평균과 불확실성, 현재거리 점수/불확실성, 이력수, 편성 내 차이/순위). 상대를 고려하는 순위 상태 묶음이 전체 개선을 설명하는지 본다.
2. no_rank: EL89 + 나머지 상태 20변수. 기록 수준/추세, 초반·종반, 불완주 위험, 지원량·휴양 및 편성 상대 상태. 순위 상태가 없을 때도 개선되는지 본다.
3. simple_rank: EL89 + 동일 이력·cutoff의 단순 과거 착순 요약 9변수. 정상 완주마의 편성 내 승률(이긴 상대 비율, 동착 .5), 직전·최근3/5평균·최근5표준편차·전체평균·전체수·최근5수, 전체평균의 편성 차이/순위. 상대 신원·그 상대의 능력 추정은 쓰지 않는다. 미관측/비완주를 꼴찌로 채우지 않으며 최근5는 출전 슬롯을 유지한다.

rank_only 대 simple_rank는 입력 차원이 같지만 표현/학습정보가 다르므로 동적 갱신 하나의 인과효과로 해석하지 않는다. no_rank에도 상대 구간 상태가 들어 있으므로 모든 상대정보를 제거한 대조군은 아니다. 불확실성 하나의 독립 효과를 주장하지 않는다.

## 학습과 결과 판정

지역 2 × 연도 2024/2025/2026 = 6분할. 2017..Y−3 초기학습, Y−2 조기중단, 2017..Y−2 재학습, Y−1 보정, Y 개발평가. 58C와 같은 LightGBM 설정·시드20261004·최대800·조기중단25. 신규 최종18모델/초기+재학습36회, 추가 시드·모델·평가 후 튜닝 없음.

주지표 복승3. 축/복승1/복연1/3/개수와 전체분포 NLL/Brier를 함께 보고한다. 전체·연도·지역, 날짜 paired bootstrap 2,000회. 상대10%는 EL89/F103/strong89/state_gbm 각각의 분모를 명시하며 10%p와 구분한다. 점추정과 구간 하한은 별개다. 후보 유지 조건은 state_gbm 대비 복승3 차이의 95% 하한>0, 축·복연3 하한>−1%p, ordered NLL 악화 없음. 단순화 후보는 동등성 입증 없이 더 간단하다고 자동 채택하지 않는다.

## 확률 보정 한 계열

58C state_gbm의 추천을 고정한다. 1축/복승3/복연3 사건의 진위 패턴 8개에 대한 공동확률에 지수 가중치를 학습한다. 각 사건의 지시자와 지시자×기존 사건확률의 logit, 총6계수다. 기존 공동확률 q를 q'∝q exp(β·φ)로 바꿔 중복착순 금지와 모든 주변확률의 일관성을 보존한다. 독립적인 주변확률별 보정은 하지 않는다. 추천은 원래 정책 그대로여서 적중률·참여율·추천 수가 바뀌지 않는다.

보정계수는 평가 전년도 앞 6개월에 한 번 적합(평균 공동 NLL + .01/2×계수제곱, 계수 ±2)한다. 이 사전 시험의 기반 온도도 상반기로만 재추정한다. 뒤 6개월은 시간순 보정검증으로만 사용한다. 세 선택사건 평균 Brier가 감소하고 ordered NLL이 악화하지 않으면 해당 분할에서 보정을 채택하고, 아니면 항등변환을 선택한다. 선택 후 전년도 전체에서 기존 기반 온도를 재사용해 최종 보정계수를 한 번 재적합한다. 각6분할에서 사전시험+최종재적합, 총12회 작은 보정 적합. 평가 정답은 선택에 사용하지 않는다. 후보 원형과 이 과거검증 선택 정책 모두 보존·보고한다. 최종 Y년 비교가 시간순 평가다.

선택정책의 평가 주지표는 같은 세 추천사건 평균 Brier. paired 95% 상한<0이고 ordered NLL 차이<=0일 때 보정 개선 확인. 원형/선택정책의 Brier·고정10구간 ECE·평균확률/실제적중 모두 보존. 단순 ECE 감소만으로 채택하지 않는다.
