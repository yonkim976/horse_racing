# 예측 목표·정답·확률 계약

이 문서는 연구 확률 API의 의미를 고정한다. 2024–2026 결과는 이미 반복 사용된 후향 자료이며 운영 추론, 신규 미사용 시험, 실제 구매 추천으로 표시하지 않는다.

`P(a,b,c)`는 1·2·3위가 서로 다른 세 말인 순서의 확률이다. `q({a,b,c})`는 그 순서 6개의 합이다. LightGBM의 Top3 raw score와 확률을 구분하며, 말별 확률의 곱이나 점수합 자체를 조합 확률로 반환하지 않는다. 점수합은 정규화·이전 연도 교정·평가를 거친 집합 분포의 energy로만 사용한다.

| 대상 | 정답 | 확률/API | 이번 평가 |
|---|---|---|---|
| 축 1두 | 선택 말의 공식 착순이 1·2·3위 중 하나 | `marginals()['top3'][i]` | 주 목표. 최대 1두, 마번 동률 규칙 |
| 단승 | 말 i가 공식 1위 | `win[i] = Σ P(i,b,c)` | 구조 제공. 성능 채택 판단은 하지 않음 |
| 연승 | 해당 경주의 **공식 연승 인정순위/정산규칙**에 i 포함 | 공식 인정순위가 {1,2}면 `top2[i]`, {1,2,3}이면 `top3[i]` | 공식 계약이 확인되지 않으면 출력/채점 보류. Top3 축을 연승으로 부르지 않음 |
| 복승 | 비순서 {i,j}가 공식 1·2위 | `quinella[i,j] = Σ_c(P(i,j,c)+P(j,i,c))` | 상위 1쌍, 상위 3쌍의 경주 적중률 |
| 복연승 | i,j 모두 공식 Top3 | `qpl[i,j] = Σ_{T⊃{i,j}} q(T)` | 1쌍·3쌍 경주 적중률, 3쌍 중 적중수와 분포 |
| 쌍승 | i가 1위, j가 2위 | `exacta[i,j] = Σ_c P(i,j,c)` | 구조 제공, 별도 순서 성능 검증 필요 |
| 삼복승 | 비순서 {i,j,k}가 공식 Top3 | `trio_distribution()` | 전체 집합 NLL 및 교정에 사용 |
| 삼쌍승 | i→j→k가 정확한 1→2→3위 | `ordered_distribution()` | 공통 분포 구성. 별도 추천 평가 필요 |

현재 출력은 `runner_probabilities.parquet`의 우승/Top2/Top3와 `tickets.parquet`의 복승·복연 각 상위 3쌍이다. 나머지 승식은 같은 분포에서 계산 가능한 연구 구조이며, 모두 검증을 마쳤다는 뜻이 아니다. 특히 최소 출전두수·취소 후 인정순위·동착 정산은 공식 경주별 규칙을 별도 입력해야 한다. 소수두수 34경주를 포함한 이번 표에서 Top3를 임의로 연승 확률로 표시하지 않았다. 다른 종의 구현을 더러브렛 공식 규칙의 근거로 사용하지 않았다.

## 추천 수와 합집합

모든 후보에서 같은 실제 출발마 명단의 전 조합을 대상으로 각 pool 상위 1쌍/3쌍을 선택한다. 같은 쌍을 중복 추천하지 않는다. 마번 오름차순 조합 열거 후, 소수12자리로 반올림한 값이 같으면 동률로 처리한다(선택 비교에만 반올림; 저장 확률은 원값). 기존 full103의 축+차순위 3두 복승 정책은 별도 `legacy_quinella_*` 대조다.

복승 3쌍은 동시에 둘 이상 적중할 수 없으므로 합집합 확률이 세 확률 합이다. 복연 3쌍은 한 경주에서 여러 쌍이 적중하므로 합집합을 `P(a,b,c)`에서 직접 합산한다. 복연 세 확률 합은 **예상 적중조합 수**이고 ‘하나 이상 적중확률’이 아니다. 예를 들어 테스트의 세 확률 합1.8과 합집합0.9를 별도로 검증했다.

## 정답 모집단

주 결과는 서울·부산의 지원된 4,799경주·50,754 실제 출발행이다. 완주 50,608행과 DNF140/DQ3은 유지한다. 미해결 special_result 3행은 기존 라벨92→Top3=0을 그대로 이어받은 한계이며, 이 2경주를 뺀 4,797경주 결과도 별도 제공한다. 같은 경주의 취소·경주제외·출발제외 697행은 실제 출발자가 아니어서 후보 슬롯에 없다. 취소마를 비입상으로 붙여 분모를 늘리지 않는다.

평가기간의 별도 28경주는 상위 3위 동착 때문에 저장 모델 모집단에서 제외되어 있다. 이 경우 승리 집합이 정확히 3두가 아닐 수 있으므로 현재 분포가 공식 정산을 나타내지 못한다. 기존 누락 경주에 결과를 추정해 넣지 않으며, 동착 지원은 별도 정답·분포 설계가 필요하다. 낮은 착순의 동착도 원천에 남기되 유일한 1·2·3위 조건을 검증한다.

정상완주 조건부 민감도는 원래 공동분포에서 비정상완주 말을 포함한 순서를 제거한 뒤 재정규화한다. 모델 입력을 사후 완주마 기준으로 재생성하거나 재학습하지 않는다. 이 민감도는 결과를 안 뒤 출발마를 제거하므로 실전 성능이 아니다. 완주 시간 결측/비양수와 상태 불명은 정상완주로 간주하지 않는다.

## 평가와 확률 검증

경주마다 말Top3 Brier, 전체 복승쌍 Brier, 전체 복연쌍 Brier를 먼저 평균한 뒤 경주 동일가중한다. 후보 수가 많은 경주의 쌍이 전체를 더 크게 지배하지 않는다. 선택축/1쌍/3쌍 합집합의 Brier와 10개 고정 구간 보정표도 제공한다. 연도·지역·거리·원문등급별 경주 수와 결과, 날짜 단위 같은 경주 paired bootstrap 2,000회 95% 구간을 함께 본다.

말Top3 합3, 복승 합1, 복연 합3 같은 합계는 구성상 항상 맞는다. 따라서 전체 평균 예측과 전체 평균 빈도의 일치만으로 좋은 보정이라고 주장하지 않는다. 확률 구간·선택 추천의 예측/실제 차이와 proper score가 판단 근거다. 회귀로 계산한 보정 절편/기울기는 평가 진단으로만 남기며 평가자료에 다시 맞춰 예측을 수정하지 않는다.

입력 시점은 과거 이력 cutoff와 보정/보조모델의 연도 이전 학습을 검사한다. 이번 거리·등급·게이트·부담중량 등 출마 조건은 경기 결과 타깃이 아니지만, 저장 원천의 실제 공개 timestamp는 모두 입증되어 있지 않다. 현재 부담중량과 최종 출발명단의 시점 한계를 포함한 후향 비교이며, 경기 전 봉인 카드의 전향 성능으로 확대하지 않는다.
