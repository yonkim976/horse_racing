# 새로운 모델 설계와 복연 선택 목표 진단

2026-10-22. 질문: 기존 연구 모델 설계에서 벗어나 연구 DB를 어떻게 활용하면 적중률의 상대 10% 이상 개선을 노릴 수 있는가?

신규 모델 학습은 하지 않는다. 자료와 선행 방법을 읽고 새로운 구조를 설계한다. 별도로 아래 **단 하나의 사전 고정 정책 진단**을 수행한다. 이 정책은 새 예측 모델이 아니라 기존 확률에서 추천 세 쌍을 고르는 의사결정 방식이다.

- 비교 확률: 연구58 additive89(EL89)의 기존 6개 지역·연도 모형과 고정 온도. 확률을 재적합·혼합하지 않는다.
- 모집단: 같은 서울·부산 2024-01-05~2026-09-20 4,799경주·50,754출발행. 비완주 포함, 기존 동착 제외 계약 유지.
- 기본선: 개별 복연 확률 상위 3쌍.
- 유일한 후보: 전체 가능한 서로 다른 3쌍 묶음 중, 적어도 하나가 맞을 **모델상 합집합 확률**이 최대인 묶음. 삼복 집합 확률을 정확히 합산한다. 12자리 반올림 동률은 마번 쌍의 사전식 순서로 해소한다.
- 세 쌍이 맞는 사건은 서로 겹친다. 포함·배제식으로 모든 후보 묶음의 합집합 확률을 계산한다. 근사 탐색이나 평가 정답을 이용한 선택은 없다.
- 주 지표: 복연 3조합 하나 이상 적중률. 보조: 0/1/2/3개 적중 분포, 총 적중 조합 수/경주, 예측 합집합 확률, 선택 합집합 Brier.
- 단독 1조합·축·복승의 추천은 원래 정책 그대로다. 새 3조합은 단독 1조합을 반드시 포함하도록 제한하지 않으며, 그 포함 여부도 기록한다.
- 날짜 단위 paired bootstrap 2,000회, seed 20261022. 95% 차이 구간과 상대 향상 구간을 제시한다. 연도·지역별도 모두 보고한다. 좋은 조건만 선택하지 않는다.
- 검증: 독립 직접 열거로 작은 필드 모든 후보 묶음의 포함·배제식 확인; 전체 기본선 확률·적중 재현; 모든 추천의 직접 사건 합산; 모델 확률상 최적값 비악화; 실제 정답은 선택 이후 채점에만 사용.
- 결과가 좋든 나쁘든 이 한 정책으로 진단 종료. 모델의 예측력 향상이나 신규 독립 시험 결과로 표현하지 않는다. 평균 적중 조합 수 감소 가능성을 함께 보고한다.

기존 자료를 반복 사용한 후향 탐색이다. 현재 결과로 미래 10% 향상·수익을 약속하거나 운영을 교체하지 않는다. 연구 DB는 읽기 전용, 새 원천 수집·기존 파일 복사·DB 쓰기·발행·배포 없음. 신규 보관 목표 5MB 미만, 이전 두 연구와 합계 300MB 이내.
