# 기본19·월게이트19에 부담중량3개를 추가한 결과

2026-10-08 완료. **부담중량 정보 추가로 확률 오차가 줄었고, 입상마 포착·삼복6조합은 개선 방향이나 그 증가분은 아직 불확실하다.** 기본19→중량22의 삼복6조합25.26→25.90%(순31경주 증가), 상위5두 입상3두 포착29.88→30.69%(39경주 증가)다. 월+게이트19→월+게이트+중량22는25.23→25.59%, 포착30.24→30.71%였다. 완료 당시 중량22를 추천했으며 이후 사용자 선택에 따라 **월+게이트+중량22를 다음 연구 기준선으로 지정**했다. 기존 모델·결과는 보존하며 운영 모델·웹 평가표는 변경하지 않았다.

## 무엇을 추가했나

기존19개 입력과 기록 보정·최근 능력 평가를 그대로 유지하고 다음3개만 추가했다. 단위는 모두kg다.

| 입력 | 정의 |
|---|---|
|`previous_carried_weight`|대상 경주T−2까지의 마지막 실전 출전 당시 부담중량|
|`current_carried_weight`|이번 경주 당시 DB에 기재된 부담중량|
|`current_vs_previous_carried_weight`|이번 부담중량−직전 부담중량|

예를 들어 직전54kg·이번56kg이면54/56/+2를 입력한다. 기존 넓은 연구 프레임의`carried_weight_change`는 직전 출전과 그 이전 출전의 차이였으므로 이번 새 입력과 구분한다. 이력 없는 말은 직전과 차이를 결측으로 두고 이번 중량은 사용한다.40~70kg 밖은 결측으로 처리하며 해당 원천에서는 범위 밖 값이 없었다. 세 열은 두 중량값과 차이이므로 독립 원천3종이 아니다.

**1kg·1000m당0.03초를 빼는 고정 기록 보정은 적용하지 않았다.** 중량에 따른 순수 인과효과를 가정하지 않고, 기존 거리·등급·나이·성별·기록 평가와 함께 모델이 조건부 예측에 활용하게 했다. 체중·중량비·추가 중량 이력창·명시적 기수·새 성별 파생변수는 추가하지 않았다. 부담중량에 감량 기수 등의 영향이 간접적으로 포함될 수 있으며 이번 실험이 그런 영향을 제거한 것은 아니다.

## 원천과 시점

동결 DuckDB의`confirmed_runners.carried_weight_raw`를읽기 전용으로 가져왔다.330,346원천행에서 기존 실전 이력326,327행을 키로 연결해 출전 순서를 보존하고, T−2의 마지막 출전을 다시 찾아 이전 중량을 계산했다. 무효 시간·미완주를 건너뛰어 더 이전 중량으로 채우지 않는다. 결과 착순·배당·당일 체중·기수 등은 새 입력 추출 SQL에서 읽지 않았다.

이번 부담중량은 **결과 DB에 남은 경주 당시 기재값**이다. 사전 출마표의 공개시각·변경 이력까지 복원한 자료가 아니므로, 당시 사전 예측에서 같은 값을 쓸 수 있었는지 확인하는 point-in-time 검증은 미완료다. 과거 중량의T−2 경계와 이번 중량의 공표시각 한계는 구분한다. 기존 모델도 출전표·취소 등의 완전한 사전 공개시각 복원은 하지 않은 후향 연구다.

학습178,497출전에서 이번 중량 결측0, 직전/차이 결측11,468행이다. 평가50,754출전에서는 이번 중량 결측0, 직전/차이 결측2,958행이다. 결측을0kg이나0kg 변화로 채우지 않았다. [연도·지역별 원천 범위](outputs/coverage.csv).

## 같은 경주·같은 학습 설정

- 기본19와 월+게이트19의 기존12개 모델 및 결과를 고정 대조군으로 재사용했다. 신규12개Top3 head는 서울/부산×평가2024/2025/2026×2후보다. 기존19개 열의 값은 모두 불변이다.
- 정답 학습2017년부터,2010–2016은 이력warm-up, 말 이력T−2. 평가연도Y에서2017..Y−3 초기학습/Y−2 조기종료/~Y−2 재학습/Y−1 temperature/Y평가를 유지했다. seed20261004·학습 설정·1/두수 가중치가 기존과 같다. 결과에 맞춰 추가 하이퍼파라미터 탐색은 하지 않았다.
- 평가는2024-01-05~2026-09-20의 같은4,799경주50,754출전이다.2026년은 일부 기간이다.
- 삼복은 모든3두 조합의 말별raw Top3점수 합을 이전연도temperature로 환산해 확률 상위6개를 고른다. 우승 head·별도 동반입상 관계·축마 규칙·경주 선별·배당/수익률은 추가하지 않았다.
- 월/게이트 후보는 앞선 실험에서 관측연도 이전 자료로 만든 기록 평가를 그대로 재사용했다. 환경계수·이상치·기록 표준화 참조를 이번 결과에 맞춰 다시 조정하지 않았다.

기본 비교는 새로 적중179경주/기존 적중 누락148경주로 순31경주 증가다. 월게이트 비교는179/162로 순17경주 증가다. 적중·포착 증가분의 구간은 모두0을 포함하므로 확정 개선으로 표현하지 않는다.

서울·부산 각각에서도 두 후보의NLL·Brier 차이 구간이 모두0보다 작았다. 월·게이트 보정만 시험했을 때보다 추가 정보의 확률 예측 가치가 분명한 방향이다. 다만 이미 반복 검토한 후향기간의 탐색 결과이며 다중비교 보정과 독립 미래 검증은 하지 않았다.

## 검증과 다음 기준선

[verify.py](verify.py)의 **1,924,953개 수치 비교 통과**, 최대오차3.55e−15:

- 기존19개 입력 전체 불변, 직전 중량178,497행을 별도searchsorted 방식으로 재구성, 원천키·T−2·신마 결측·증감 산식 확인.
- 원시DB24행을 별도 파라미터 SQL로 대조하고 원천DB·완료 연구·운영 registry 해시 불변 확인.
- 신규12개 저장모델 재추론, 학습/조기종료/보정 연도·카테고리 vocabulary·tree수·temperature 미분조건 확인.
- 후보9,598경주의 전체삼복·말별주변확률·6조합·정답·집계 독립 재계산. 삼복합1/말별입상합3, 동일 경주·정답 확인.
- 날짜bootstrap24개 비교 재현. Ruff 통과. 날짜 비교 검증에서ns/us 저장 정밀도 차이를 동일 단위로 맞췄으며 실제 날짜 불일치0행, 학습 입력·모델은 변경하지 않았다.

세 신규 입력 모두 학습에서 사용됐다. 두 후보의6개fold 평균 학습gain 비중은 이번 중량 약7.2%, 직전 약2.3%, 차이 약0.5~0.6%였다. 이는 학습분할 사용량의 기술통계이며 각 열의 독립적인 개선량이나 인과적 중요도가 아니다. [학습 gain](outputs/weight_feature_training_gain.csv).
