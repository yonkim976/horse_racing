# 축 붕괴 사전 예측 연구

대상은 더러브랫 서울·부산, 현재 선택된 month_gate_weight22 연구 기준선이다. 축은 해당 연도 동결 모델 점수 1위(동점은 마번 순)이며 붕괴는 실제 3위 밖이다. 선행마의 전개 실패와 구분한다. 제주·DB·운영 모델·연구 기준선 선택은 변경하지 않는다.

2020–2023년 축은 2017년 이후 자료로 새 시간순 OOF 예측을 만들고 2024–2026년 축은 기존 동결 예측을 재사용한다. 각 Y년 기본 모델은 Y−2년까지 학습하고 Y−1년으로 온도를 보정한다. 위험 모형도 2020–Y−3 학습, Y−2 조기종료, Y−2까지 재학습, Y−1 확률보정, Y년 평가한다. 기수·조교사·현재 경주 통과조·착순은 입력하지 않는다. 기존 T−2 이력과 보정기록을 그대로 참조한다.

위험 점수는 (1) 기존 공동 삼복분포에서 1−축입상확률, (2) 이것의 전년도 Platt 보정, (3) 모델 점수/경합도 위험 학습, (4) 축의 53개 과거 프로필과 자기 제외 상대마 정보 추가 학습을 비교한다. 위험 학습은 지역을 합쳐 표본을 확보한다. 후보당 연도별 한 모형이며 결과에 따른 재튜닝은 하지 않는다.

정책은 모두 6조합이다. 기준은 축+상대6두 중 점수합6개와 축 자유 전체6개다. 각 새 위험 점수로 ① 전년도 위험분포 상위30% 기준을 넘을 때만 축자유6개, ② 같은 위험 신호에 원축을 제외한6개, ③ 기존 공동분포의 축포함/미포함 질량만 새 위험확률로 재배분한 전체6개를 비교한다. 원축을 반드시 빼는 정책의 오판 비용도 집계한다. 현재 결과를 본 뒤 경주를 선택하지 않는다.

주 비교는 추가 이력 위험 모형의 Brier/logloss와 원래 위험 점수, 재배분6개와 기존 축자유6개다. 보조 비교는 위험시 고정 해제/원축 제외와 축고정6개다. 같은 날짜 군집 2,000회 paired bootstrap 95% 구간, 연도/지역, 위험구간, 구조된 실패와 새로 놓친 적중을 보고한다. 기존 연구에서 이미 검토한 2024–2026년 재사용 후향 평가이며 새 독립 검증 기간이 아니다. 배당·수익률은 평가하지 않는다.

독립 검증은 저장 모델 재예측, 시간 경계, 전년도 보정/문턱, 실제 조합 전수 재구성, 입력에서 결과 제거/변조 불변성, 원본 해시 보존, 6개 예산, 기준선 재현을 확인한다. 완료 후 원 보고서·중앙 결론·게시 요약·파일 용량 명세를 저장한다.
