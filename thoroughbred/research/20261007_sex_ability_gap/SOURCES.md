# 원천·기간·방법과 해석 범위

2026-10-07. 추가 API 조회나 DB 변경 없이 보관 파일만 사용했다. 시작 시 관련 기존 파일 목록·크기·해시는 [baseline_inventory.json](outputs/baseline_inventory.json), 실제 분석 입력과 18개 원문 파일의 SHA-256은 [source_audit.json](outputs/source_audit.json)에 있다. 적용 경로와 상위 경로에서 AGENTS.md는 발견되지 않았다. 요청된 연구 목록·중앙 결론·출처 목록·용량/게시/거리 기준 정책과 계절·시대·거리별 분석 코드 및 검증 문서를 읽었다. 보안 스킬의 고정 경로·읽기 전용 원칙을 적용했다.

## 모집단과 출전 시점 분류

[계절 연구](../20261007_seasonal_same_moisture/README.md)의 최종 151,074행·13,928경주·12,435두를 그대로 재사용했다. 원문 성별은 각 결과 행의 `sex`, ID는 `hrNo`, 성별 제한 원문은 `sexCond`, 마체중은 `wgHr`, 부담중량은 `wgBudam`, 착순은 `ord`다. 11개 거리별 입력의 원문 위치/index를 복원하고 날짜·거리·ID·착순·전체·구간시간과 다시 대조했다. 최신 마필정보를 과거에 적용하지 않았다. API 결과가 사후 수정될 가능성 및 수술 당일/실시간 과거 카드 상태까지는 검증하지 않았다. 관찰된 수→거 변경은 거세 전후의 인과효과를 뜻하지 않는다.

원문은 [기존 일정 수집](../20260929_calendar_api_v1/README.md)의 한국마사회 `API4_3/raceResult_3`, `raw/race_execution_probe/YYYY/meet_N.json.gz`에 있다. [공식 성적표](https://race.kra.co.kr/raceScore/scoretablePeriodSearch.do)는 기존 시행키 검증의 출처이며 이번에 새로 재조회하지 않았다. 영천·제주·주행심사는 제외했다. 주로빠르기는 입력·모형·점수 어디에도 사용하지 않았다.

출전 시 분류 암/수/거에는 결측이 없고, 현재 마체중에도 결측이 없다. rating 0 이하는 기존 정의대로 결측이다. 이력은 이전 날짜만 사용한 최근 최대5회 상대착순·3위 이내·초반위치, 로컬 누적출전수, 마지막 출전 이후 공백이다. 기록이 없다는 것은 국내 보관 이력 부재일 수 있으며 생애 무출전으로 단정하지 않는다. 원자료 결측은 null을 유지하고 통제행렬에서만 관측 중앙값+결측 지시자를 썼다. 전부 미관측인 통제는 제거했다. 완전관측 표본 결과도 별도로 제공한다.

서울 전체 종료일 2026-09-20, 부산 2026-09-18이다. 거리별 실제 시작·종료일은 [표본표](outputs/venue_distance_sex.csv)에 있다. 부산1400은 2026-09-11, 부산1900은 2020-07-19처럼 종료일이 다르다. 2024년 이후 공통 점수 참조는 49,004행이다. 2026년은 부분 연도다.

## 기존 품질 선택과 추가 민감도

기존 [정상 경주 선택](../20261002_moisture_position/analyze.py)은 취소/제외 코드93·94·95를 뺀 뒤 6두 이상, 정상 양수 완주기록, 동착/착순 누락 없는 완전한 순위, 유효 마번·함수율을 요구했다. 거리별 기존 전체·구간 물리 범위도 계승했다. 이번 연구는 정상적인 꼬리 기록을 추가 절사하지 않았다. 확정 시행키의 더 넓은 API 감사 모집단 158,528행을 선택 원장으로 비교했다. 그 원장에 이미 결측 처리된 비정상 전체시간5개는 새로 복구하지 않았다.

[선택 원장](outputs/selection_ledger.parquet)의 `finish_ms`는 기존 감사 입력의 밀리초이며, [분석 모집단](outputs/population.parquet)과 시간 결과표는 초다. 사유별·성별·거리별 원수와 비율은 [선택표](outputs/selection_by_sex.csv)에 있다. 모집단 밖 양수 완주마를 포함한 전체시간 민감도 및 같은 시행키의 원래 비제외 출전자 전체를 복원한 우승/3위 이내 민감도를 계산했다. 원래 출전자 민감도는 취소/미시행 또는 잘못된 API 전용 경주까지 포함한 전수 성적이 아니다. 비완주 코드에 임의의 시간을 부여하지 않았다.

성별 제한 원문 `암`과 공란/오픈 등을 구분했다. 공란은 법적 제한 미상이다. 실제 원래 출전자 중 두 분류 이상이 있는지를 별도로 계산했다. 수+거만 있는 편성도 두 분류 경쟁에 해당하며 암말과 경쟁한 경주로 부르지 않는다. 같은 경주 비교에는 해당 두 분류가 실제 함께 나온 경주만 사용했다. 암말 제한 경주를 혼합 경쟁으로 세지 않았다. 관측 평균 부담중량 차이를 규정상 감량량으로 해석하지 않았고, 연도별 감량 규정을 확인하지 않은 채 특정 kg 규정을 주장하지 않았다.

## 모형·단위·불확실성

각 지역·거리에서 암−수, 거−수, 암−거를 별도 적합했다. 원시 차이와 연도×월×정확 연령×정확 함수율 고정효과, 등급 추가, 부담중량·마체중(각 제곱항 포함), rating(제곱항 포함)·과거 성적 추가를 나눈다. 등급 공통 표본에서 원시/등급 없는 단계도 다시 계산한다. 해당 층에 양쪽 분류가 있어야 하며, 암말끼리만 있는 층에서 수말 효과를 외삽하지 않는다. 각 쌍의 공통 표본이 다르므로 암−수와 거−수를 빼서 암−거를 만들 수 없다.

개별 출전 동일 가중 OLS다. 통제 없는 층별 비교는 `n1*n0/(n1+n0)` 가중 평균차와 같다. 같은 경주 고정효과도 동일 경주당 단순 평균차가 아닌 양쪽 출전자 수에 따른 겹침 가중 비교다. 추가 통제가 있는 계수는 선형/제곱항 모형의 조건부 연관이며 층 간 평균효과나 원인 분해가 아니다. 말 고정효과는 넣지 않았다. 기존 성별 보정 잔차·기록예측 모형을 이용하지 않았다.

마필과 지역별 날짜의 두 군집 score 분산을 합하고 교집합 분산을 뺐다. 같은 경주는 같은 날짜 군집에 포함된다. 자유도는 출전수−층수−층 내 설계행렬 rank, 군집 소표본 보정과 t 자유도 min(마필군집, 날짜군집)−1을 썼다. 작은 음의 이원 분산 가능성을 피하기 위해 이원/말 단독/날짜 단독 중 최대 분산을 사용했다. 이는 점별 근사95%구간이며 무작위 표본이나 생물학적 인과성을 보장하지 않는다. [공식 statsmodels 이원 군집 공분산 문서](https://www.statsmodels.org/stable/generated/statsmodels.stats.sandwich_covariance.cov_cluster_2groups.html)를 방법 참고로 확인했으며 실제 구현은 NumPy이고 별도 SciPy 희소 더미/잔차 회귀와 score 합으로 대조했다.

양쪽 각각100행·30두·20날짜·공통20층 및 대비 식별을 주 구간 제공 조건으로 사전 정의했다. 미달 시 점추정은 잠정으로 보존하고95%구간은 null이다. 원시 비교는 층수 요건이 없다. 시기 변화는 두 기간 각각 양쪽100행과20날짜도 요구했다. 조건을 통과해도 OPEN처럼 모형/중량이 복잡하고 표본 불균형이 큰 곳은 해석이 불안정할 수 있다. 주 거리별 같은등급 전체시간 대비에 BH q값을 제공했지만, 전체 탐색표의 동시 신뢰구간이나 다중비교 조정 완료를 주장하지 않는다. CSV의 `horse_variance/date_variance/intersection_variance/two_way_variance`는 원래 종속변수 단위의 분산이며, 비율 결과의 difference/se/CI는100배 해 %p로 표시했다.

전체 및 독립 구간 시간 단위는 초, 상대속도 대비는 %p다. `early_relative_pct=100*(200/early)/(distance/finish)`이며 `late_relative_pct`도 같은 정의다. 절대시간과 자기 전체 평균속도 대비 비율은 다르다. 중간1은 200m 이후부터 마지막600m 전까지(거리−800m), 중간2는 그 뒤400m, 마지막200m다. 네 구간 거리·시간 합을 검증했다. 마지막600은 겹치는 보조구간이며 중복 합산하지 않는다. 서울 막판400이나4C 이후 시간을 새로 만들지 않았다. 기존 서울4C 명목530m 연구의 범위를 확장하지 않았다.

공통 점수는 성별을 합친2024년 이후 같은 지역×거리×등급×함수율 **상태** 경험분포의 자신보다 느린 기록 비율(동률 절반)이다. 각 성별을 따로50점으로 맞추지 않았다. 상태 안의 정확 함수율과 월을 맞춘 점수는 아니며 기존 거리별 추정 기준표를 개정한 것도 아니다. 미관측 최근 등급/상태 참조는 null이고 참조수가 함께 있다. 이 보조점수는 후향 설명용이며 우승확률·공식 rating·종합능력·운영 보정이 아니다.

시기 분석은 모든 해1~8월,2018~2023 대2024~2026의 성별×최근시기 상호작용이다. 연도 고정효과를 유지하고 다른 통제의 기울기는 시기별로 달라질 수 있게 했다. 연도 제외 같은 연령·등급·월·정확 함수율 조건이 양 시기에 관측된 층만 남겼다. 완결2024~2025 및 가까운2021~2023 비교는 같은 자료의 민감도이며 미래 검증이 아니다.
