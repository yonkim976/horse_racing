# 부산 거리별 게이트 차이와 강한 우위의 확인

2026년 10월 7일, 거리 간 직접 대비 계산 전에 고정했다. 기존 부산 거리별 계수는 이미 관찰한 값이며 이번은 후향 후속 분석이다.

- 기존 게이트 연구의 품질 완료 `runners.parquet`를 재사용한다. 부산, 2018~2026-09-20 자료 계약에서 실제 부산 종료일까지, 정상 순위 완결·6두 이상이다. 새 이상치 제거와 DB 조회·변경은 하지 않는다.
- 1000·1200·1300·1400·1600·1800·2000m를 비교한다. 관측이 없는 부산1700m 등을 만들어 넣지 않는다. 게이트는 상대 마번순 3등분이다.
- 기존과 같은 경주 고정효과·경주당 가중치합1, 레이팅·나이·부담중량·이전 날짜까지의 최근 성적·초반위치·경험·간격을 조정한다. 결과는 Top3다. 현재 실제 위치·배당·주로빠르기·풍향·풍속은 제외한다.
- 내측−외측의 부호 있는 효과를 주 기준으로 한다. 양수는 내측, 음수는 외측 우위다. 절댓값 순위를 유의한 차이로 표현하지 않는다.
- 전체기간에서 7거리의 모든 21쌍을 직접 비교하고 동일 날짜의 영향값 공분산을 포함한다. 각 쌍은 왼쪽 거리의 내측 우위−오른쪽 거리의 내측 우위다. 21개 양측 검정에 Holm을 주 기준으로, BH를 보조로 제공한다. 반대 방향의 차이와 같은 방향에서 더 강하다는 차이를 구분한다.
- 민감도는 2024년 이후와 정확히 마번1~12를 갖춘12두 경주다. 지원되는 모든 거리 쌍을 기간별로 별도 보정한다. 최소50경주·20일을 유지한다.
- 기존 서울 후속에서 검증한 추정 함수를 재사용하고, 부산의 전체·최근 계수를 원 연구와 대조한다. 별도 부분회귀로 계수·날짜 영향값을 검증하고 쌍별 분산·p·Holm·BH를 대조한다. 입력 해시를 전후 확인한다.
- 내측·중간·외측, 최근기간 방향, 표본·지원 여부를 함께 보고한다. 초 단위 보정·개별 말 확률 가산·운영 변경으로 채택하지 않는다. 기존 게이트 연구의 후속으로 결론과 용량을 보존한다.
