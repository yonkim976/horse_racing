# 제3의 말을 포함한 전체 출전마 축 선택

2026-10-14. 연구53. 기존 2024~2026 결과를 이미 본 뒤 정한 반복 후향 연구다. 아래 방법과 후보를 이번 성적 계산 전에 고정한다. 서울·부산만 사용하고 운영·선택22·기존 미래계약·DB·제주는 변경하지 않는다.

## 질문과 비교

기존103/122의 입상점수1위 두 말 밖에서 축을 찾으면 입상과 복승이 나아지는가? 축은 우승확률1위가 아닌 Top3 점수로 선택하는 입상축이다. 기존 능력모델을 동결하고 연구51의 2020~2026 시간외 말별 예측을 재사용한다. 2020~2023은 기존16모델의 OOF, 2024~2026은 기존12모델의 평가 예측이다. 정답 학습2017+, 이전warm-up, T−2/730일 실제슬롯 조건을 승계한다.

각 경주의 122축을 기준말로 삼고, 나머지 모든 말을 대안으로 만든다. 후보나 경주를 실제 착순으로 거르지 않는다. 라벨은 후보만Top3=득(+1), 기준말만Top3=실(−1), 둘다입상/둘다실패=중립(0). 같은 경주의 대안들 가중치 합이1이 되도록 1/(실제두수−1)을 쓴다. 각 평가연도Y의 선택학습은2020~Y−1뿐이며 현재연도는 전처리·튜닝·조기종료에 쓰지 않는다.

주후보 gain_logit: 다항로지스틱 L2 C=.1, lbfgs, max_iter2000. 분리대조 gain_tree: multiclass LightGBM leaves4/minleaf150/L2=20/lr.03/80rounds/seed20261014. 각3개, 신규6모델. 결과 후 모델·문턱·후보범위를 변경하지 않는다.

동일하게 학습한 각 모형에 두 선택 범위를 적용한다. two는103/122축만, all은전체출전마. 기준122축의 기대득실은 정확히0, 나머지는P득−P실. 최댓값을 축으로 선택하며 정확동점이면122축 우선, 그다음122순위/마번으로 결정한다. 제3의 말은 두 원래 축 모두와 다른 말이라는 뜻이며 원래모델3위 말만 뜻하지 않는다. 나머지 말 순서는122순위 그대로여서 후보축 확대와 동반마 재정렬을 섞지 않는다. 기본 능력점수·말별확률은 수정하지 않는다. 선택확률은 조건부 교체결과이며 말별 입상확률이 아니다.

## 입력

기준/후보/차이: 빠른초반 뒤G3F/G1F/공동관측수/동시유지율, 최근3전보정지수/유효수/추세/편성평균대비지수, 예상첫조확률/상대게이트/경력/출전간격12×3=36. 거리·등급·두수3, 각103/122모형의 기준/후보확률/차이6와 기준/후보순위4, G3F/G1F×관측비율 또는최근상대기록의기준/후보/차이12: 숫자61+지역/국혼범주2=원입력63개. 학습중앙값+결측표시+학습평균/표준편차+학습어휘만 쓴다. 실제 착순은 입력 생성과 선택 API가 거부한다. G1F와G3F는 겹치므로 합산능력점수를 만들지 않는다. 기수/조교사/배당/당일실측구간 추가 없음.
