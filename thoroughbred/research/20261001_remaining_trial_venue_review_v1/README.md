2026-09-17의 네 회차와 48개 참가행 모두 `physical_venue_unresolved`로 유지한다. API 라벨, `meet=3` 또는 RPT 저장 경로를 영천/부산경남으로 치환하지 않는다. 마필·기수·조교사 소속도 장소 추정에 사용하지 않는다. 결과목록의 `부산경남경마` 이미지 대체문구와 `영남경마` 본문 경로명이 엇갈리므로 이 UI 자체도 어느 한쪽을 확정하는 근거로 취급하지 않는다.

## 장소를 확정하려면 필요한 근거

다음 중 날짜와 장소를 한 자료 안에서 직접 연결하는 한국마사회 원문이 필요하다.

- 2026-09-17을 명시한 시행 공지·편성 안내·장소 변경 공지
- `렛츠런파크 영천` 또는 `렛츠런파크 부산경남`을 본문에 적은 날짜별 심사표/RPT
- 장소가 명시된 공식 심사 영상 또는 영상 설명·메타데이터

회차·참가두수만 일치하는 결과표, meet 코드, 파일 경로, 마필·기수·조교사 연고는 장소 확정 근거가 아니다. 이런 직접 근거를 새로 확보하기 전에는 장소 컬럼을 채우지 않는다.
