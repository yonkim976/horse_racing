# 남은 거리 기록 기준 연구 계획

2026-10-06 사용자 요청: 나머지 거리도 같은 등급·상태·구간 방식으로 이어 분석한다. 동결한 실전 모집단에서 미완료 거리1000·1900·2000·2200·2300m를 대상으로 한다.1000·1900·2000은 서울/부산,2200은 부산,2300은 서울이다. 공식 현재 편성 거리 전체를 새로 조사한 결과가 아니다. 앞선1000m 주행심사와 실전1000m를 구분한다.

- 동결 DB·Parquet·원API를 읽기 전용으로 사용하고 원천 식별·거리·전체·구간기록을 개별 대조한다. 완료된 이전 거리 연구는 재실행하거나 수정하지 않는다. 영천·제주·주로빠르기는 제외한다.
- 함수율 숫자의5상태로 나누고 최근2024년 이후 같은 등급의 기록을 참조한다. 독립 구간은200+(거리−800)+400+200m다. 겹치는 막판600과 부산 직접 마지막400을 분리한다. 서울 직접 마지막400은 만들지 않는다.
- 평균·중앙·P10/P20/P80/P90, 시간 빠른20/중간60/느린20의 인원·평균, 실제 착순 집단과 시간 집단의 구간을 보존한다. 같은등급/전체등급 기록점수를 각각 제공한다.
- 정상 기록의 꼬리를 일정 비율로 자르지 않고 넓은 품질 범위와 제외 원장을 남긴다. 품질 경계를 최적선이나 원천 오류 판정으로 해석하지 않는다.
- 지역별 Ridge alpha10, 경주별 동일 총 가중치, 이전 날짜 최근5회 이력으로 상태 효과를 추정한다. 개발2021~2023 후보0/.3/1/3 중 최소 오차+.01초 내 가장 단순한 값을 선택한다. 미관측 등급 및 이전 상태 지원 없는 개발평가를 제외한다. 개발표본 없으면0 기본값이며 검증된 최적값으로 부르지 않는다.
- 시간순2024~2026 비교는 이전3년 같은 등급 참조와 이전 상태 지원이 있는 평가행만 모든 방법에 공통 사용한다. 평가20일 또는10조합 미만이면 희소 검증,0행이면 검증 불가로 표시한다. 낮은 오차만으로 보정 개선을 확정하지 않는다.
- 최근 등급 참조가 없거나 해당 지역·거리에서 전기간 함수율 상태 지원이 없으면 시간 null이다. 관측 표본과 추정 참조를 구분하며 추정으로 표본 수가 늘어나는 것으로 표현하지 않는다.
- 날짜 군집200회 재표집, 유효180회 미만 신뢰구간은 비운다. 유효 반복을 충족해도 원참조 한두 날짜는 잠정이다. 숨긴 조합 복원은100기록/10일과 평가5일 지원을 요구한다.
- 원본 보고서·중앙 결론·게시Markdown/JSON을 보존한다. 웹 배포·운영 모델·기존 보정 결정은 변경하지 않는다. 전체 보관 파일과 수정분의 용량 명세를 자체 포함해 기록/보고한다.
