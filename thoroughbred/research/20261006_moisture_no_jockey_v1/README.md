# 보정 기록 유지·기수 입력 제외

2026-10-06 완료. **사용자 요청대로 기수 관련26개를 제외하고 보정 기록을 유지한258개 입력으로6개head를 재학습했다. 삼복6조합 적중은서울소폭증가·부산감소,부산확률품질은악화했다. 요청한구성은연구후보에반영하고운영은유지한다.**

[현재입력결정](INPUT_DECISION.md), [계획](PLAN.md), [설정](config.json), [계약·제외목록](outputs/feature_contract.json)을보존했다. 직전[보정기록연결연구](../20261005_moisture_finish_v1/README.md)의augment/augment_joint를고정비교대상으로사용했다.

## 제거한 입력과 유지한 정보

기수초반성향·180일최근성향·외측출발성향·거리별성향·진출성향·관측수·기수교체·교체성향차이·말×기수이력·기수×게이트·기수×말각질·편성상대기수성향을제거했다. 기수이름/ID는모델입력이아니며조립된신규학습프레임에서도기수관련열을제거한다.26개전체목록은계약에있다. 과거말의실제기록에서과거기수의영향을인과적으로분리한결과는아니다.

원기록261개와보정추가23개중명시적기수26개제거로284→258개다. 원기록·최근기록·최고기록·편성상대기록·거리별통과순위이력·주행심사이력·게이트×말각질은유지한다. 보정은기존전체시간건조환산서울80%·부산90%를그대로쓴다. 과거기록연도이전계수/지원조건/이력T−2를유지하며현재함수율·주로빠르기·구간보정·새par는추가하지않았다.

## 게이트가 전개 모델과 같은가

**현재단일말게이트6개입력은전개v2/v5에서만들었던동일한입력을공유한다.**

| 입력 | 계산 |
|---|---|
| gate_number_proxy | 출발마번을게이트번호대리값으로사용 |
| gate_fraction_proxy | (마번−1)/(결과카드최대마번−1),내측0~외측1 |
| gate_inner_proxy / gate_outer_proxy | 상대위치1/3미만내측,2/3이상외측 |
| gate_style_interaction | 상대게이트×과거최근3전S1F상대순위 |
| conditioned_gate_style | 상대게이트×거리조건을고려한과거S1F앞선3두성향 |

기수×게이트는제거했다. 이표의내/외는**출발번호의위치**로통과조에서읽는실제주행내외측이아니다. 실제횡방향주행위치·통과조마군과간격은계속보류한다. 게이트유불리보정계수나거리손실초를입상점수에별도로가산한모델도아니다.

입상head에별도전개예측값(stack_예상위치/선두확률등)을넣지않았으므로현재는전개예측을경유한게이트효과와직접게이트가산점을두번더하는구조가아니다. 동일원천입력을공유하는것과독립정보가늘어나는것을구분한다.

joint는3두간12개비가산관계를추가로학습하며그중`gate_front_pair`·`gate_style_distance`2개는게이트와각질의**말간관계**다. 단일말게이트열이나별도전개모델출력과동일한열은아니다. 이번에는기수제거만의효과를보기위해이관계구조도유지했다.
