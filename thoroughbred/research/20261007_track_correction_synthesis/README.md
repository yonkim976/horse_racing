# 주로 환경을 종합한 기록 보정의 적용 범위

2026년 10월 7일. 기존 연구의 종합과 후속 설계이며 새로운 계수 추정이나 보정 채택은 아니다.

**각 출전 기록에 적용할 하나의 종합 보정초는 만들 수 있다. 다만 지금까지 나온 함수율·월별·게이트·내외측 수치를 그대로 더해서 완성할 수는 없다.** 현재 전체시간 보정으로 채택한 것은 함수율이며, 나머지는 척도·비교 기준·검증 범위를 맞춘 공동 추정이 필요하다. 모든 경기장과 거리에서 같은 초를 더하는 하나의 상수는 적절하지 않다.

## 현재 사용할 수 있는 값

`건조 기준 환산시간 = 원시 완주시간 + 함수율 보정초`

서울은 추정 함수율 효과의 80%, 부산은 90%를 사용한다. 이는 원시시간의 80%·90%를 조정한다는 뜻이 아니다. 거리·상태별 값이 다르고, 건조와 해당 상태가 각각 과거 20경주일 이상인 셀에 한해 참고표를 채택했다. 아래는 1200m 예시다.

| 경기장 | 건조 | 양호 | 다습 | 포화 | 불량 |
|---|---:|---:|---:|---:|---:|
| 서울 | 0.00 | −0.10 | −0.01 | +0.39 | +1.03 |
| 부산 | 0.00 | −0.11 | −0.07 | +0.58 | +0.87 |

단위는 초다. 서울 1200m 불량에서 72.00초는 약 73.03초로 환산한다. 빠른 환경의 이점을 제거하려고 시간을 더하는 방향이다. 현재 참고표는 2025년까지 추정한 값이므로 과거 예측 평가에는 당시 이전 자료로 추정한 계수를 따로 사용한다. 미지원 거리·상태는 0초로 확정하지 않고 미지원으로 표시한다. [채택 결정과 전체 거리표](../conclusions/01_TRACK_MOISTURE.md)

## 항목별 종합 가능성

| 항목 | 확인된 결과와 단위 | 종합 보정에서의 처리 |
|---|---|---|
| 함수율 | 건조 대비 전체시간 차이, 초 | 현재 채택 범위에서 사용 |
| 달력월 | 같은 함수율에서도 지역·거리별 기록 차이, 초 | 연간 공통 기준으로 재중심화하고 함수율과 공동 추정한 후 후보 검증 |
| 출발 게이트 | 지역·거리·시기별 최종 Top3 차이, %p | 전체시간에 대한 조건부 효과를 새로 추정해야 초 단위로 합칠 수 있음 |
| 실제 마군 내 내측·중간·외측 | 지점·마군 크기에 따른 Top3 차이, %p | 전개 해석용으로 보존. 능력을 포함한 경주 진행 결과여서 기록 보정의 자동 차감 항으로 쓰지 않음 |
| 날짜·주말·최근 편차 | 작은 표본과 기간별 방향 변화 | 서로 겹치는 기간값을 합산하지 않고 과거 자료의 최근 편차 하나로 완화 |

서울 건조 1200m 8월은 겨울 월평균 대비 약 −0.61초, 부산은 약 −0.65초였지만, 이것은 채택된 월별 보정초가 아니다. 건조의 월별 값을 포화·불량에 복사할 근거도 부족하다. 기존 기준 회귀의 월 통제와 중복될 수 있어 이미 조건을 맞춘 기준표에 다시 더하지 않는다. [월별 연구](../conclusions/23_MONTHLY_SAME_MOISTURE.md)

서울 1200m 게이트의 내측 +1.97%p·외측 −1.82%p는 중간 대비 Top3 차이다. 이를 +0.0197초 또는 일정한 배율의 초로 바꾸지 않는다. 부산 1600m에서는 외측 방향이 관찰되어 내측에 모든 거리 공통 가산을 줄 수도 없다. [게이트 연구](../conclusions/03_GATE_POSITION.md)

내외측은 절대 레일부터의 거리나 실제 추가 주행거리가 아니다. 같은 마군에서 맨 안쪽·양끝 사이·맨 바깥쪽이라는 상대 위치다. 2두에는 중간이 없고 단독에는 상대 내외측이 없다. 특히 막판 외측의 높은 입상률에는 남은 힘·추월·진로 선택이 포함될 수 있다. 게이트와 실제 위치는 관련되어 있으므로 각 연구값을 독립 보정처럼 두 번 더하지 않는다. [공동 연구](../conclusions/04_JOINT_CORRECTION.md)

## 후속 종합 보정의 설계

출발점은 원시 전체시간이며, 목표 기준은 **같은 경기장·거리에서 건조, 학습기간의 연간 기준 환경, 평균적인 출발 조건**이다. 여기서 평균적인 출발 조건은 학습자료의 게이트 분포에 대해 효과가 평균 0이 되도록 정한 비교 기준이며, 특정 마번을 이상적 게이트로 정하지 않는다.

`보정시간 = 원시시간 + Δ종합`

`Δ종합 = −공동모형이 추정한 관측 조건과 기준 조건의 시간 차이`

함수율·계절 곡선·게이트의 주효과와 지원되는 상호작용을 같은 전체시간 모형에서 추정하고, 각 항의 강도를 시간순 검증으로 선택한다. 단순 가법 모형이면 각 항의 초를 합할 수 있지만 상호작용을 포함하면 기준 조건에서 전체 모형을 다시 계산해 한 번만 차감한다. 현재 채택 계수와 새 공동 계수를 섞어 쓰거나 기존 입상률 계수를 초로 변환하지 않는다. 새 공동모형은 기존 함수율 보정과 별도로 비교한다.

계절 곡선은 12월과 1월이 이어지고 월 경계에서 값이 급변하지 않도록 설계한다. 계절과 동반되는 말의 성장·등급·출전 구성 변화가 모두 주로 효과로 흡수되지 않도록 당시 정보와 과거 능력 이력을 고려한다. 그래도 추정값은 조건부 기록 정규화이며 물리적 주로 효과만의 인과 추정으로 표현하지 않는다.

최근 편차는 당일 경주를 제외한 이전 관측만으로 계산하고 장기 기준 쪽으로 완화한다. 기존 연구의 서울 반감기 14일·부산 56일·40경주 상당 강도·최근 84일·조합 간 추가효과 범위 5%p는 **Top3 조건부 연구의 설정**이다. 전체시간 보정의 초 단위 설정으로 확정하지 않고 필요하면 후보로 재검증한다.

실제 주행위치는 우선 별도 전개 지표로 둔다. 이를 넣은 후향 분석은 위치를 확보한 능력까지 제거할 수 있으므로 능력 보정과 구분한다. 후속 검증에서 추가 가치가 확인되더라도 사전 예측에는 과거 이력으로 추정한 예상 위치·마군 크기만 사용할 수 있다. S1F·코너·G1F 위치 효과를 독립 초처럼 누적하지 않는다.

## 채택을 결정할 비교

1. 원시 과거 기록을 쓰는 기준모형.
2. 현재 함수율만 보정한 과거 기록을 쓰고 재학습한 모형.
3. 함수율과 완만한 계절 곡선을 공동 보정한 모형.
4. 게이트까지 공동 보정한 모형. 실제 주행위치를 쓴 설명 분석은 구분한다.

과거 기록의 계수와 수축 강도는 해당 기록 이후 정보를 보지 않고 정하며, 선택기간과 이후 평가기간을 분리한다. 동일한 평가 표본에서 완주시간 오차를 비교하고, 원래 목적에 맞춰 출전마 전체의 우승·Top3 확률 검증도 별도로 한다. 평균 오차의 작은 개선만으로 순위·수익 개선을 주장하지 않는다. 희소 조합은 지원 여부와 불확실성을 보존하며, 약한 항의 가중치를 0으로 선택하는 것도 허용한다.

현재 권장 구조는 **함수율을 기본 보정으로 유지하고, 월과 게이트는 공동 전체시간 검증을 거쳐 추가하며, 실제 내외측은 전개 해석으로 함께 보는 방식**이다. 한 개의 보정시간을 제공하더라도 원시시간·항목별 기여초·표본 지원·계수 학습 종료일·버전을 함께 보존한다. 전체시간 보정을 구간기록에 비례 배분하지 않는다. 풍향·풍속과 주로빠르기는 이번 범위에서 제외한다.

새 수치 채택, 운영 반영, 웹 구현·배포는 이 종합 정리에 포함하지 않는다. 기존 연구 수 33개와 채택 결정은 유지한다.
