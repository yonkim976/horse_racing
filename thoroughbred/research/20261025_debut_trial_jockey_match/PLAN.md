# 주행심사와 데뷔전 기수 일치 연구59A

2026-10-25. 성적·예측 차이 계산 전에 고정한다. 연구59의 국내산 신마8,884두와2024~2026 평가2,573두를 그대로 사용한다. 기존 데이터·모델·예측·중앙59는 읽기 전용이다. 운영 반영과 새 자료 수집은 하지 않는다.

## 기수 정의

주 비교는연구59가 선택한 T-2 이전 마지막 합격 심사의 실제 완료 기수와 데뷔전 실제 기수의 공식ID 문자열 일치다. `jockey_id_for_completed_trial`을 사용하며 API 직접8,424건·공식 완료심사 보완460건을 구분한다. 원문 이름이나0초 심사의 편성 기수로 매칭하지 않는다. 확인 불가는별도이고 불일치로 채우지 않는다. 현재 실제 출전 기수는최종 결과의ID이므로 당시 출전표·교체시각의이용가능성은 미검증이다.

보조 분류는직전365일 T-2 이전의 양수 완료 심사/연습에서 같은 기수 기승이 한번이라도 확인됐는지와 마지막 완료 심사 기수 일치다. ‘마지막 합격 불일치’와‘과거 심사에서 함께 탄 적 없음’을 구분하되, 이번 범위는 일반 일별조교가 아닌 주행심사다.

## 성적과 기존 예측의 차이

2018~2023은원시 비교 참고,2024~2025와2026부분연도 및합계는원시 우승/Top3·심사기록·심사간격·현재/심사 기수의과거 성적을 요약한다. 연구59의고정 total/sections 예측을 일치/불일치로 나눠 AUC·AP·Brier·log loss·실제률과예측률 차이를 평가한다. 집단별 AUC 차이는 말의구성·실제률에 영향받으므로 기수효과로 단정하지 않는다.

입상/우승의 원시 일치-불일치 차이와 ‘실제-기존예측’ 잔차 차이에 날짜 단위 군집95% 구간을 계산한다. 보조적으로같은 경주FE의 선형확률 모형에서 일치표식·기존 logit예측/제곱·심사간격·현재/심사기수 과거실력과 표본을 통제한다. 같은 말은 첫출전1행뿐이므로 말FE를 넣지 않는다. 말기수 선택·준비상태가 남는후향적 관측차이이며 인과효과가 아니다. 같은 경주에서 일치/불일치 신마가 함께 있는 지원 수를 표시한다.

## 기수 정보의 추가 예측 가치

기존 고정 sections 기본선에 대해2×2 입력 비교를 한다.

- identity: 마지막 합격 기수 일치1열과 결측표식만 추가.
- quality: 심사 기수의직전365일·T-2 성적/표본을 심사일 시점과 데뷔전 시점에서 계산하고, 현재 데뷔 기수와의과거 우승/입상률 차이를 추가. 신원ID·이름 자체는 모델 입력으로 쓰지 않는다.
- quality_identity: 두 묶음을 함께 추가.

total+identity와Logistic sections+identity는민감도다. 시간 경계·파라미터·Platt 교정·예측 상위 경계는연구59와 동일하게 고정한다. 각Y에2018~Y-2 학습, Y-1 교정, Y 평가다. 기존모델은재학습하지 않고 보존된예측·모형을 재현한다. 신모델30개만새 폴더에 저장한다. 테스트 결과로튜닝·사양변경·임계값선택을 하지 않는다.

주 지표는우승/Top3 AUC·AP·Brier·log loss이며 전체·연도·지역·기수 일치별로 보존한다. identity-base, quality-base, quality_identity-base, quality_identity-quality를 날짜 단위 paired bootstrap2,000회로 비교한다. 고정기본선의 그룹별 오차와 새모델의 추가 개선을 구분한다. CI는다중비교 미보정·학습모형 조건부이며2024~2026은반복 분석된 후향 평가다. 예측 개선이작거나기간별 불안정하면함께 보고하며 운영이나고정가산으로채택하지 않는다.

공식 기수 연결·선택 사건·이전 전체 연구 파일 해시·과거날짜 경계·새예측과 지표를 독립 검증한다. 연구 폴더와중앙59A·게시요약·용량명세를갱신한다.
