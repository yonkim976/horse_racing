## 계산 정의와 예시

전체거리D,전체시간T,해당 구간거리d,구간 소요시간t에 대해:

`구간 상대속도 R = 100 × (d / t) / (D / T) = 100 × d × T / (D × t)`

거리는 동일 단위,시간은 초로 통일한다. t에는 출발부터의 누적시간을 그대로 넣지 않고 해당 구간의 소요시간을 넣는다.100%는 자기 전체 평균속도와 같다는 뜻이고105%는 그보다5% 빠르다는 뜻이다. 출발 구간에는 정지 상태에서의 가속이 포함된다. 시간의 백분위 기록점수와 다른 지표다.

아래는 실제 경주 결과가 아닌 가상 계산 예시다.1200m를75초에 달리면 전체 평균속도는16m/s다.

| 구간 | 거리 | 시간 | 상대속도 |
|---|---:|---:|---:|
| 출발~200m | 200m | 14초 | 89.29% |
| 200~600m | 400m | 24초 | 104.17% |
| 600~1000m | 400m | 25초 | 100.00% |
| 마지막200m | 200m | 12초 | 104.17% |

같은 가정에서4C 누적시간43초라면4C 이후32초다. 공식 설명의 명목530m를 사용한 상대속도는103.515625%,표시값103.52%다. 실제 달린 경로 길이를 계측한 속도가 아니다. 서울4C와 다른 계측점 사이의 정확한 거리·자료 시대별 정의를 검증하고 명목거리 기반임을 표시한다. 거리 정의를 확정하지 못한 구간은 시간·순위 정보를 유지하고 상대속도 표시를 보류한다.

## 기준 전개와 검증

Timeform의par finishing speed는 코스·거리·조건에 맞는 기준 마무리 비율이다.100%를 모든 조건의 최적값으로 고정하지 않는다. 기존 평균 시간표는 상대속도par가 아니다. 각 출전의 비율을 계산한 뒤 분포와 효율적인 전개 기준을 별도로 연구한다. 전체 평균시간÷구간 평균시간의 비율을 개별 상대속도의 평균으로 간주하지 않는다.

기준이102%,실제106%라는 가상 예시의 편차는+4%p다. 기준 자체를 아직 추정하지 않은 화면에는 실제 편차를 채우지 않는다. 코스·거리·구간별 기준과 참조기간·버전을 고정하고,소표본 및 추정 여부를 표시한다. 구간별 기본 분포를 만들었다는 사실만으로 최적par를 찾았다고 표현하지 않는다.

전체75초·마지막200m12초와 전체90초·마지막200m14.4초는 같은104.17%다. 상대속도만으로 절대 능력이나 좋은 추입을 확정할 수 없으므로 기존 전체·구간 기록 수준과4C→G1F→결승의 실제 순위·시간차 회복을 함께 보여준다. 겹치는 마지막600m와4C 이후를 독립 능력 점수처럼 합산하지 않는다.

주로빠르기는 제외한다. 원기록 비율과 함수율을 조정한 연구용 비율은 구분한다. 전체시간만 보정한 값과 원시 구간시간을 섞어 상대속도를 생성하지 않는다. 구간과 전체의 합계·시점·보정 정의를 맞추고 새 구간 보정 채택은 별도 검증한다.

사전 예측에 사용한다면 목표 경주 이전의 구간 이력과 당시 이전 자료로 추정한 기준만 사용한다. 해당 경주 종료 후 구한 상대속도는 그 경주의 사후 평가 값이다. 시간순 평가·기능 추가 전후 비교로 미래 성능을 확인한다. 설명용 가상 계산과 실제 기준 연구·예측 효과를 구분한다.
