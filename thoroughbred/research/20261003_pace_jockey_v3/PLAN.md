# 전개 v3: 기수·초반 안정성·게이트별 경쟁

2026-10-03, 결과 계산 전 정의. 기존 게이트 v2를 기준으로 jockey / stability / competition / all 네 후보를 각각 추가한다. 함수율 추가 효과가 뚜렷하지 않았으므로 v2 gate의 원기록 피처를 유지한다. 기존 함수율 연구 합의를 변경하지 않는다. 서울·부산 별도, 이력2010–2016 warm-up, 정답학습2017+, 평가2024–2026 보존 경주 동일.

- 1차 지표 S1F 상대순위 MAE. 통과순위 MAE·통과1위 선택·상위3두·Brier/NLL, G3F·초반시간을 함께 보고한다. 기존−후보 동일 경주 차이 및 all−jockey 차이를 날짜bootstrap1000회로 확인한다. 연도·기수교체/동일·이력부족·게이트구간별 민감도를 보존한다. 결과를 본 뒤 후보/상수/피처를 바꾸지 않는다.
- 기수는 공식 ID로 연결하되 ID/이름은 모델 입력에 넣지 않는다. 현재 기수는 결과표 기수로 재구성한 선언 대리값이며 사전 공개·교체 시점은 아직 입증되지 않았다. 실시간 예측 성능이라고 주장하지 않는다.
- 기수 성향의 원자료는 말의 과거 성향·기록, 거리·편성·게이트를 통제한 예상 S1F 상대순위와 실제의 차이다. 매2018년 이후 관측 연도의 이전2017+자료로 Ridge(alpha25)를 적합해 외부 예측을 만든다. G3F 진입까지의 이동도 같은 방식으로 예상 변화 대비 잔차를 만든다. 평가 연도 자기경주를 학습한 잔차를 사용하지 않는다. 잔차 생성 모델에는 기수·현재 실제 통과순위·현재 함수율을 입력하지 않는다.
- 미래 결과를 제외한 T−2까지의 기수 잔차 누계·최근180일·외곽·단거리(1400m이하)/그 외, 말×기수 조합을 만든다. 기수30관측·조합10관측만큼0평균 쪽으로 완화한다. 신규/부족 조합은0값과 실제 관측 수를 함께 제공한다. 기수 교체 여부와 현재 기수−직전 기수의 해당 지역 사전 성향 차이, 말 성향/게이트와의 상호작용을 사용한다. 이는 관찰 자료의 조건부 성향이며 말 능력을 완전히 통제한 인과효과나 당일 의도가 아니다.
- warm-up의 기승 수·과거 통과위치 이력은 사용하되 학습 잔차는2018+부터 있다. 현재 기수의 당일 먼저 끝난 경주를 사용하지 않는다. 같은 날 여러 기승을 한꺼번에 처리해 같은 날짜 안 순서로 정보를 누설하지 않는다.
- 초반 안정성은 과거5/10전 S1F 상대순위 표준편차·과거10전 출발200m 시간 표준편차/범위/관측 수, 직전까지 평균보다0.4초 느린 초반시간의 과거10전 비율이다. 시간은2017+만 사용. 공식 출발 사고나 기수 의도를 직접 측정한 지표가 아니며 함수율·상대편성 변동이 섞일 수 있다.
- 경쟁은 상대들의 과거 초반시간·앞선 진입 비율만으로 자신보다 안쪽/바깥쪽에 있는 빠른 상대 수, 가까운 게이트의 상습 선행마 수, 앞선 성향 상대의 게이트 압력, 빠른1·2두의 과거 시간 차이 등을 만든다. 현재 실제 위치/경합을 입력하지 않으며 기수 추가군과 독립된 base 성향을 사용한다.
- 주행심사·현재 부담중량·출발사고 상세 원문·횡방향 위치는 이번 피처군에 포함하지 않는다. 확인된 범위부터 비교하고 추가 도입은 별도 실험으로 남긴다.
- 동일 split/모델200나무상한/보정기간/경주가중치. 이번 후보의 학습/평가 자체는 v1 helper를 사용하고 기준 예측은 v2 gate 출력 그대로 재사용한다. 각 묶음 출력과 메타데이터를 저장하여 중단 시 완성된 묶음은 재학습하지 않고 이어갈 수 있게 한다.
- 입력/코드/모델 해시·T−2·외부 예측 연도·동일날짜 배제·키/확률합·기수 이력 별도 재현·모델 출력 재현을 검증한다. 원천 DB와 기존 모델·운영 등록부는 수정하지 않는다. 최종 우승·삼복승 개선은 별도 시간순 전개→입상 연결 실험을 하기 전에는 주장하지 않는다.

## 독립검증 중 수치 경계 수정

첫 계산의 독립검증에서 정확히0.4초인 차이가 pandas rolling 평균과 독립 NumPy 평균의 부동소수점 오차로 다르게 분류되는 경우를 발견했다. 기준 자체를 바꾸지 않고 `차이 > 0.4 + 1e−9초`로 수치 허용오차를 명시한다. 원천 ms 해상도보다 훨씬 작은 오차이며0.4초 초과라는 원래 정의를 보존한다. 수정 전 코드·입력·결과는 outputs_before_threshold_fix에 보존하되 최종 결과로 채택하지 않는다.

변경된 피처를 사용하는 stability/all 후보는 재학습한다. jockey/competition 묶음은 새/옛 입력의 해당 모델 화이트리스트 열 전체와 정답·키·분할이 동일함을 확인하고 모델/출력 해시를 검증한 뒤 재사용한다. 재사용 증거는 reuse_audit.json에 보존한다. 평가 수치를 보고 임계값을 튜닝한 변경이 아니다.
