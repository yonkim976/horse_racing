# 전개 v3: 기수 성향·초반 안정성·게이트별 경쟁

사용자 요청에 따라 기존 게이트 v2에 기수 성향, 초반 기록 안정성, 게이트별 선행 경쟁을 각각 추가한 후보와 전체 결합 후보를 구현했다. [결과 계산 전 계획](PLAN.md), [설정](config.json), [계산](run.py), [독립검증](verify.py), [단위검증](test_v3.py)을 보존한다. 수치는 [보고서](outputs/REPORT.md), [전체/연도 지표](outputs/metrics.csv), [동일 경주 차이](outputs/paired_differences.json)에서 확인한다.

## 결과와 다음 후보

2024년부터2026-09-20까지 S1F 관측이 완전한 서울2,756·부산1,946경주를 동일하게 비교했다. 오차는 초반 통과위치의 평균 절대 순위차이며 최종 착순 오차나 삼복승 적중률이 아니다.

| 입력 | 서울 S1F 순위 MAE ↓ | 서울 통과1위 선택 | 부산 S1F 순위 MAE ↓ | 부산 통과1위 선택 |
|---|---:|---:|---:|---:|
| 게이트 v2 기준 | 1.880두 | 42.82% | 1.952두 | 41.62% |
| +기수 성향 | 1.869두 | 43.25% | 1.934두 | 40.90% |
| +초반 안정성 | 1.878두 | 42.96% | 1.951두 | 41.37% |
| +게이트별 경쟁 | 1.879두 | 43.18% | 1.953두 | 41.37% |
| +전체 | 1.868두 | 43.11% | 1.935두 | 41.32% |

**기수 성향 추가는 평균 위치를 조금 더 정확히 예측했다.** 서울 오차−0.01149두(경주일bootstrap95% 구간−0.01427~−0.00892), 부산−0.01787두(−0.02264~−0.01324)였다. 두 지역의3개 연도 모두 S1F·G3F 순위오차가 감소했다. 막판600m 진입 G3F 위치오차도 서울1.980→1.970두, 부산2.033→2.007두로 줄었고 두 지점의 Top3 Brier도 개선됐다. 기존 게이트 대비 S1F 오차 감소는 약0.6%·0.9%로 큰 도약은 아니다.

**평균 위치 개선을 선두 선택 개선으로 읽으면 안 된다.** 서울 S1F 통과1위 선택은+0.44%p지만 보조 구간이0을 포함했다. 부산은−0.72%p이고3개 연도 모두 선택률이 낮아졌다. 부산2026은38.61%→37.66%다. 해당 변경의 전체 구간도0을 포함해 실제 차이의 확정적 추정은 어렵지만, 선두 선택 목적에서 채택 근거가 없다. G3F 통과1위와 상위3두 적중도 평균오차만큼 일관되게 좋아졌다고 주장하지 않는다.

초반 안정성의 효과는 작았고 부산 구간은0을 포함했다. 게이트별 경쟁의 평균오차 차이는 두 지역 모두 구간이0을 포함했으며 부산 점추정은 악화했다. 전체 결합−기수만의 차이 역시 양쪽 구간이0을 포함했다. 후속 입상 연결에는 **기수 성향만 추가한 후보를 먼저 사용**하고 나머지는 연구 자산으로 보존한다. 후보를 선택하는 데 사용한 같은 후향 기간이므로 독립 미래 확인은 필요하다. 기존 운영 모델을 승격하거나 바꾸지 않았다.

초반시간은 부산에서 기수 추가 MAE가3개 연도 모두 줄었다(2024:0.14731→0.14611초,2025:0.14333→0.14128초,2026:0.13971→0.13816초). 서울은2024·2025 악화,2026 개선으로 일관되지 않았다. 빠름/보통/느림 분류에는 여전히 단순 보통 기준과의 비교가 필요하며 그 적중률로 전체 전개 경합을 확정하지 않는다.

이력이 없는 말의 S1F 오차는 기수 추가로 서울2.613→2.583두, 부산2.660→2.596두였지만 여전히 경력마보다 크다. 이는 말 가중 민감도이며 별도 신마 전용모델의 성능 검증이 아니다. 기수교체/동일/미상 표도 함께 보존했다. 주행심사·초반 능력·출발사고 자료가 이 빈 부분을 보완할 다음 후보이며, 이 자료를 이번에 이미 도입했다고 주장하지 않는다.

관련 단위검증29개 통과. [독립검증](outputs/verification.json)1,308개 통과/0실패, 최대 모델 재현오차 약1.8×10−15. 기존 입력·예측·원천 DB·운영 등록부 해시와 재사용36개 모델의 입력 동일성도 확인했다. 최종 입상·삼복승 적중 효과는 시간순 외부 전개 예측을 입상모델에 연결한 뒤 같은 조합 수로 따로 검증해야 한다.

## 기수 성향의 의미

선행마를 많이 기승한 기수의 단순 선행률을 적극성으로 간주하지 않는다. 말의 과거 성적·초반 성향·구간기록·게이트·거리·편성을 입력한 Ridge 기대모델로 S1F 상대순위와 S1F→G3F 위치 변화를 예측한다. 각 관측연도 이전2017+자료만 학습하여2018년부터 외부 예측을 만든다. 기수 ID·당일 결과는 기대모델의 피처가 아니다.

`초반 적극성 잔차 = 예상 S1F 상대순위 − 실제 S1F 상대순위`

양수는 해당 말·편성 조건의 기대보다 앞에 간 관측이다. 위치는 `(통과순위−1)/(두수−1)`로 정규화했다. 잔차0.05를 승률+5%p로 바꾸거나 당일에0.5두 앞에 갈 확률로 해석하면 안 된다. 관측하지 못한 말 상태·능력·전개 등이 남아 있어 인과적 기수 효과도 아니다.

기수 전체·외곽·단거리/그 외·최근180일 잔차, G3F까지 예상보다 앞으로 이동한 잔차, 말×기수 조합 및 기수 교체를 사용한다. 기수 전체는30관측, 조합은10관측에 해당하는0평균 prior로 완화한다. 표본이 없으면0값과0관측 수를 함께 제공하며 성향이 정확히0이라고 단정하지 않는다. 기수 전체 기승 수는 warm-up까지 포함하지만 학습 잔차는2018+만 있다. 현재 기수와 직전 기수의 과거 성향 차이도 같은 시점에 비교한다.

이력은 T−2까지이며 같은 날 다른 경주도 제외한다. 기수의 하루 여러 기승을 일별로 합쳐 날짜 내 순서로 결과가 새지 않게 한다. 최근값은 실제 예측일을 기준으로180일 전보다 뒤이면서 T−2까지인 기록이며, 오래 쉬었던 기수의 마지막 기승일을 기준으로 창을 옮기지 않는다. 현재 기수는 결과표에 기록된 기수 대리값이며 출전표 공개·변경 시점은 독립 확인되지 않았다.

## 나머지 피처와 비교

초반 안정성은 과거5/10전 상대 통과순위 표준편차, 과거10전 출발200m 시간의 표준편차·범위·관측 수, 당시 직전3전 평균보다0.4초 느린 초반시간의 최근10전 비율이다. 원시 시간은2017년 이후만 사용한다. 환경·거리·편성 차이가 섞이며 출발 사고·늦발을 직접 측정한 변수가 아니다.

독립검증에서 정확히0.4초인 차이가 부동소수점 연산 순서 때문에 초과로 분류되는 경계 사례를 확인해,1e−9초 허용오차를 명시하고 영향을 받은 stability/all 후보를 재학습했다. 기준은0.4초 **초과**로 유지한다. 최초 출력과 코드 보존본은 outputs_before_threshold_fix이며 최종 검증 결과는 outputs다. jockey/competition은 모델 입력 전체와 정답이 바이트 수준 수치로 동일함을 확인하고36개 모델을 재사용했다. 재사용 증거는 outputs/reuse_audit.json에 있다.

게이트별 경쟁은 자신보다 안/바깥쪽의 빠른 상대, 안쪽의 비슷한 속도 상대, 가까운2번호 이내 상습 선행마, 앞선 진입 성향 상대의 게이트 배치 및 빠른1·2두 기록 차이·빠른3두 기록 분산이다. 모두 상대들의 과거 기록과 현재 게이트 대리값으로 계산하며, 현재 실제 경합·기수 의도를 입력하지 않는다. 기수 추가와 독립된 기존 말 성향을 사용해 군별 비교를 구분한다.

기준은 v2 gate 보존 예측 그대로다. 후보는 `jockey`, `stability`, `competition`, `all`. 같은 서울·부산 경주, 학습2017+, 이전 연도까지 훈련/보정한2024–2026 후향 평가이며 학습모형·최대200나무·경주가중치·확률보정 범위를 유지한다. 전체 주파기록 함수율 보정·현재 부담중량·주행심사·공식 출발사고·실제 주행 내외측은 이번 변경에 포함하지 않았다.

1차 지표는 S1F 상대순위 MAE. 순위 MAE·통과1위 선택·상위3두·Brier/NLL, G3F·초반시간을 함께 보고한다. 경주별 평균 오차를 다시 경주 동일가중으로 집계하며 경험/기수교체/게이트/거리별 민감도는 말 가중 오차다. 작은 차이나 일부 연도만의 개선은 그대로 구분한다. 같은 후향 기간을 여러 후보에 반복 사용해 독립 미래 성능을 보장하지 않는다. 최종 입상·삼복승 적중은 별도 연결 검증 전이다.

## 실행과 재현

프로젝트 루트에서 `.venv/bin/python thoroughbred/research/20261003_pace_jockey_v3/run.py prepare`, `train`, 이어서 같은 폴더의 `verify.py`를 실행한다. 준비는 기존 출력 덮어쓰기를 거부하고 학습은 완성된 묶음의 해시를 확인해 재사용한다. 중단된 불완전 묶음은 자동 덮어쓰기하지 않는다.

`external_expectations.parquet`·`expectation_models.json`: 기대모델·외부 잔차·훈련연도·수치변환 상수. `history.parquet`·`jockey_states.parquet`·`pair_states.parquet`: 원천 연결과 날짜별 누계. `coverage.csv`: 표본·교체·조합 지원. `feature_contract.json`: 입력 화이트리스트와 군별 정의. `models/`: 지역/연도/후보별 모델·확률/시간 보정·완성 출력 및 해시. `verification.json`: 과거 이력 별도 재집계·기대모델 및 전개모델 재현 결과. 원천 DB·기존 v1/v2·운영 등록부는 보존한다.
