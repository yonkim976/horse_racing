1. [마사회 API 날짜 원장](../20260929_calendar_api_v1/README.md)을 기준으로 2010년부터 조사일까지 모든 날짜의 경주 **계획**, 실제 **시행 근거**, 공식 **휴장 근거**를 별도 상태로 기록한다. 경주계획만 있는 행은 시행으로 간주하지 않고, 자료가 없는 날짜를 임의로 휴장 처리하지 않는다.
2. 마사회 주행심사 API의 실제 `trainDate`로 심사 실행일·회차를 기록한다. 부산경남과 영천이 합쳐진 `영남` 응답은 장소를 별도 확인하며, API 공백·날짜 충돌에만 보관 RPT를 보조 대조한다.
3. 날짜와 장소가 확인된 경주·심사부터 결과 및 경주 종류·거리·주로 등 상세 속성을 추가한다. 결과를 조회해 시행 여부를 확인한 경우에도 이 단계 전에는 착순·기록을 학습 라벨로 적재하지 않는다.
4. 말·기수·조교사·마주 연결을 검증하고, 이후 구간기록·통과착순·통과조·심판 리포트·조교·진료·관계 변동을 순차 추가한다.
5. 각 단계의 API 응답 원문·해시·요청 변수와 미확정 원장을 남기고, 2017년 이후 학습 범위를 시간순 검증한다.

### 1. 말·기수·조교사·마주 식별 기반

- 원천별 공식 ID, 내부 ID, 원문 이름, 프로필 관측 기록을 보존하고 확정 가능한 기준 엔티티를 만든다. 이름만 같은 대상을 자동으로 합치지 않는다.
- 출전 당시 기록된 마주·조교사 ID와 이름을 코어에 남길 준비를 한다. 현재 프로필의 관계를 과거 경주에 소급하지 않는다. 상세 변동 이력은 7단계에서 판정한다.
- 통과 조건: 공식 ID의 중복·충돌 검사, ID/이름 연결 근거, 미확정·동명이인 원장. 기준정보 연결이 미확정이어도 출전·심사 원천 행은 유지한다.

### 2. 정식 경주와 주행심사 일정·출전·결과

- 정식 경주의 일정, 출전, 결과를 각각 원천 레코드로 보존하고 (개최지, 날짜, 경주번호)로 연결한다. 경주 종류·등급/경주명·거리·부담중량 방식·날씨·주로상태·함수율, 출전번호·말·관계자·부담중량·마체중·레이팅·장구, 착순·기록·취소/제외 등 결과 상태를 남긴다.
- 예정 정보와 실제 경주 후 확정된 날씨·주로·출전 상태를 구별하고 각각의 관측 시점을 남긴다.
- 주행심사·연습주행은 별도 이벤트로 관리하고 일정과 참가 결과를 분리한다. 심사 종류·회차·번호·거리·날씨·주로, 참가 말·기수·조교사·부담중량·기록·판정·결격 사유를 남긴다. 원천에 없는 정식 경주 등급을 심사에 추정해 넣지 않는다.
- 통과 조건: 정식 경주와 심사의 키 중복·누락 검사, 일정 없는 출전/참가행 0건, 결과 없는 행의 사유별 분류, 엔티티 연결률 및 미확정 원장. 운영 DB와 기존 연구 스냅샷의 2010년 이후 차이를 날짜·경주번호·출전 상태별로 판정한다.

### 3. 1차 코어 DB 검증·동결

- 1~2단계를 함께 조회 가능한 버전 DB로 묶고, 2010년 이후 원천별 최초/최종일·연도별 행 수·키·공백·출처 해시·미연결 원장을 manifest에 남긴다.
- 검토를 통과한 버전만 고정한다. 여기까지가 말·관계자, 정식 경주, 주행심사 기반 코어다.

### 4. 구간기록·통과착순·통과조

- 구간기록, 말별 통과착순, 경주 단위 통과조를 각각 보존한다. 통과착순은 말×경주×지점, 통과조는 경주×지점 구조다.
- 통과 조건: 지점·시간 의미 사전, 출전/경주 연결률, 중복·상충·결측률, 원천 표본 대조. 심사 참가의 `passing_order_raw`를 경주 단위 통과조로 사용하지 않는다.

### 5. 심판 리포트

- 개최지·날짜·경주번호로 먼저 연결하고, 말·기수별 처분은 근거가 명시된 경우에만 대상 엔티티에 연결한다.
- 통과 조건: 리포트 커버리지, 경주 연결률, 처분/사건 추출 표본 검토, 개별 연결 근거.

### 6. 일상조교·출발조교·수영조교·진료

- 각 자료군을 독립 원장으로 적재한다. 일상·출발·수영 세 종류 조교와 진료 원문 적재를 완료했다. 사건일, 관측일, 게시일, 수집일을 구분하며 반복 진료 관측은 실제 방문 횟수로 확정하지 않는다.
- 통과 조건: 말 ID 연결률, 날짜·중복·값 범위, 예측 시점의 정보 이용 가능 여부, 미연결 원장과 표본 대조.

### 7. 마주 변동·조교사 위탁/소속 이력

- 출전 당시 관계, 말 프로필 스냅샷, 조교사 소속 및 위탁 원천을 시기별로 보존한다. 실제 효력일이 명시된 경우에만 변동일을 확정하고, 스냅샷만 있으면 관측일로 기록한다.
- 통과 조건: 공식 ID 연결률, 관계의 효력일·관측일·정보 이용 가능 시각 구분, 상충 구간과 미확정 변경 원장, 경주 당시 관계 표본 대조.

#### 후속 추적 방안 — 2026-10-01 합의, 현재 보류

- **과거 변경 관찰:** 말의 공식 ID별로 경주·출전표의 마주 ID와 경주·주행심사의 조교사 ID를 날짜순 비교한다. 결측과 `휴양마` 같은 비인물 상태는 따로 기록하며, 값 누락을 관계 종료나 변경으로 판정하지 않는다. 이름 변경만으로 관계 변경을 만들지 않는다.
- A의 마지막 기록일과 B의 첫 기록일이 다르면 `관계 변경 관찰`로 남긴다. 사건 기록만으로 실제 변경일을 확정하거나 두 날짜 사이 내내 한 관계가 유지됐다고 가정하지 않는다. 중간의 A→B→A 변경은 관찰되지 않을 수 있고, 원천 정정이나 상충도 검토해야 한다.
- **향후 스냅샷:** 경주마 상세 API의 관계 ID를 주기적으로 저장해 이전 상태의 마지막 관측일, 새 상태의 최초 관측일, 수집 시각을 보존할 수 있다. 수집 간격과 원천 갱신 지연 때문에 변경 효력일은 별도로 미확정이다. 이 문서 기록으로 정기 수집을 예약하거나 시작하지 않는다.
- **정확한 기간 보완:** 공식 홈페이지의 `profileTrustContract.do`는 말별 위탁기간·조교사·마주와 `휴양마` 구간을 제공한다. [원더풀삭스 조회 예시](https://race.kra.co.kr/racehorse/profileTrustContract.do?hrNo=0053272&meet=1)를 확인했다. 위탁계약 표의 마주 변경을 법적 소유권 이전일로 곧바로 해석하지 않는다.
- 현재 승인 API 42개 목록과 공개 검색에서 계약 시작·종료일을 직접 주는 전용 OpenAPI는 확인되지 않았다. 전체 공개 서비스에 없다는 확정 판정은 아니다. 재개 시 일괄 파일·전용 API 제공 가능 여부를 먼저 확인하고, 필요하면 공공데이터 제공신청을 검토한다. 문의·신청 전송은 별도 사용자 지시가 있을 때 진행한다.
- **IP 차단 우려:** 현재 대상 말 ID는 23,814개다. 초당 1회 요청은 소요시간 설명용 가정일 뿐 허용 속도로 확인되지 않았다. 차단 기준·수집 허용 범위를 확인하지 않은 상태에서 대량 홈페이지 수집을 시작하지 않는다. 웹 보완이 필요하면 필요한 말만 대상으로 하고, 원문 재사용·중복 제거·이어받기와 접근 제한 시 중단을 적용한다.
- 과거 모델에는 해당 경주 이전에 이용 가능했던 관계만 사용한다. 현재 프로필을 과거 경주에 덮어쓰거나 이후 관찰된 관계를 앞선 경주로 소급하지 않는다. 공식 효력일이 있어도 과거 공개 시점 확인은 별도 검증한다.

### 8. 최종 범위·시점·활용 계약 검증

- 2010-01-01~2026-09-29 범위에서 각 원천의 실제 커버리지와 공백을 확인한다. 정식 경주와 부가자료의 첫 사건일·최종 관측일이 다를 수 있음을 명시한다.
- 2017년 이후 학습 프레임의 정답/결과 열을 설명변수에서 분리한다. 이력 피처는 대상 경주보다 앞서 발생하고 그때 이용 가능했던 자료만 쓴다.
- 모든 범위·연결·누출 검증과 표본 검토를 통과한 학습용 버전만 동결한다.

## 2026-09-29 원천 사전조사 메모

- 아래 경주·출전 수치는 **2010-01-01~2026-09-20에 한정한** 원천 사전조사이며 확정 적재 수치가 아니다. 운영 SQLite `data/horse_racing.sqlite3`에는 경주, 출전/결과, 주행심사/참가결과와 말·기수·조교사·마주 기준표가 있다.
- 운영 DB의 해당 기간 경주는 서울 17,341건(완료 17,322), 부산경남 12,377건(완료 12,376), 영천 12건(완료 12)이다. 출전행은 각각 192,661·134,775·119건이다.
- 같은 기간 운영 DB의 주행심사 일정은 서울 3,468건, 부산경남 2,713건이다. 영천 심사 일정은 현재 원천에 없다. 심사 원천의 최신일은 경주 최신일과 다를 수 있다.
- 운영 심사 결과에서 기수 ID가 없는 행은 서울 36,917행 중 18,059행, 부산경남 24,554행 중 2,377행이다. 조교사 ID가 없는 행은 각각 6,610·191행이다. 이름만으로 연결을 확정하지 않는다. 심사 원천에는 `grade` 컬럼이 없으며 부담중량도 대부분 비어 있다.
- 서울·부산경남 완료경주 엔트리의 거리·등급·부담중량·기수는 사전조사 기준 결측이 없었다. 부담중량 방식은 부산경남 134,763행 중 1,697행, 주로 함수율은 서울 192,438행 중 5,542행과 부산경남 134,763행 중 4,043행이 비어 있었다. 주로상태도 서울 190행, 부산경남 117행에서 비어 있었다.
- 기존 `thoroughbred.duckdb`와 운영 SQLite의 2010년 이후 수치는 경주 152건·출전 4,837행이 다르다. 기존 스냅샷을 새 DB의 기준 정답으로 승계하지 않는다.
- [2010년 이후 경주 충돌 감사](../20260929_2010plus_collision_audit/README.md)에서 152개 경주 키를 분해했다. KRA 공식 결과로 확인한 운영 DB 누락 1개, 말 ID·마번이 기존 경주와 완전히 일치하는 날짜/경마장 이동 중복 후보 56개, 취소 또는 미확정 상태 95개다. 기존 연구 v1은 중복 후보 15개 경주의 169개 출전행을 모델 대상에 포함하므로 코어 적재 전에 차단·원문 판정한다.
- 말 포함 여부는 제주마 품종 구분이 아니라 대상 더러브렛 경주/심사 및 공식 말 ID 연결을 기준으로 한다. 원산국·성별 등은 말 속성으로 보존한다.

## 범위 밖 원천 조사 기록

아래 2010년 이전 수치는 기존 원천의 차이를 이해하기 위한 조사 기록이며, 현재 새 DB의 적재 대상이 아니다.

- 운영 SQLite에서 2010년 이전 경주는 서울 11,058건, 부산경남 3,162건이다. 기존 통합 연구 스냅샷에는 같은 기간 서울 경주가 23건 더 있으므로 키별로 판정해야 한다.
- 기존 통합 연구 원천에서 주행심사는 서울 2003-07-03·부산경남 2004-11-07, 일상 조교는 서울 1998-09-25·부산경남 2004-06-30, 진료는 서울 2003-09-18·부산경남 2005-05-04부터 확인된다. 구간기록은 서울 2000-01-08·부산경남 2005-01-07부터 확인된다. 관측한 최초일이 중간 기간의 완전성을 보증하지 않는다.
- 운영 DB의 심판 리포트는 현재 서울·부산경남 2025년부터, 영천은 2026-09-13부터 확인된다. 영천 주행심사는 없다. 미보유 기간을 0건으로 해석하거나 임의 보완하지 않는다.
- 이전 가용성 조사에서는 현재 로컬 적재보다 오래된 공식 결과 화면을 확인했지만, 말별 결과의 연도별 완전성과 신원 연결은 검증되지 않았다. 원문을 추가 확보하고 검증한 뒤에만 확장 대상으로 삼는다.
