# 함수율·거리별 과거 기록 피처 재학습 검증

2026-10-02. 이번 단계 결과를 계산하기 전에 고정한 계약.

- 원천·기간·품질 제외는 앞선 `20261002_moisture_only` 연구와 동일하다. 주 분석은 82경주 제외, 민감도는 API 원문 모두 포함이다. 주로빠르기는 사용하지 않는다. 공식 DB와 이전 연구는 수정하지 않는다.
- 질문: 과거 동일 경기장·거리 직전 1·2회 기록을 함수율로 보정한 뒤 기대시간 모형을 다시 학습하면 원시기록 입력보다 다음 출전의 실제시간 예측이 좋아지는가? 단거리 1200·1300·1400m를 우선 해석하고 1600·1800m까지 확장한다. 서울 1700m와 기타 거리는 보조 집계에 보존한다.
- 주 목표는 전체시간, 출발200·마지막200·마지막600은 보조 목표다. 순위·우승·Top3·수익률은 검증하지 않는다.
- 환경 학습 정답은 앞선 연구의 연도 외부 말별 기대시간 잔차에서 만든 경주 중앙값(적격 말 4두 이상)이다. 경기장·목표별 Ridge α=25, 거리·월·연도추세·경주번호 통제는 동일하게 유지한다.
- 환경 후보: 함수율 없음(공통 잔차 평가 기준), 숫자 기반 5구간 공통 효과, 5구간+거리×5구간 효과. 거리 상호작용은 Ridge로 수축하며 표본 부족한 거리의 완전 독립 회귀를 하지 않는다. 각각 실제 함수율과 건조를 대입한 예측 차이를 환경효과로 정의한다.
- 모든 과거 경주 효과는 그 경주 연도 이전 잔차만 학습해 고정한다. 2020년부터 잔차가 있으므로 2021년부터 계수가 있다. 계수 학습 경주에 자신의 결과가 들어가지 않는다. 같은 모형을 적격 말 4두 미만 과거 경주에도 적용할 수 있지만 해당 결과를 계수 추정에 사용하지 않는다.
- `보정기록=원시기록−환경효과`. 직전 1·2회 모두를 보정한다. 두 번째 기록이 원래 없으면 직전 기록과 그 보정값을 복제한다. 존재하는 두 번째 기록에 계수가 없으면 출전 전체를 제외한다. 최근 동일 거리 유효 기록을 건너뛰어 다른 출전으로 대체하지 않는다.
- 세 기대시간 후보: 원시기록, 공통 구간 보정기록, 거리×구간 보정기록. Ridge α=20 및 거리·등급·월·간격·중량·마번 대용 게이트는 동일하다. 현재 경주 함수율·실제시간·착순은 예측 입력에서 제외한다. 정답은 현재 실제 원시시간이다. 보정 후보별로 전처리와 모델을 다시 학습한다.
- 모든 후보는 같은 학습행과 평가행을 사용한다. 두 과거 기록의 보정계수가 있는 공통 표본으로 제한하므로 기존 연구의 MAE와 직접 비교하지 않는다. 원시기록 후보도 같은 제한 표본으로 재학습한다.
- 2024·2025·2026년 각각 이전 연도까지 학습한다. 이미 관찰한 후향 기간이며 독립 미관측 테스트가 아니다. 모델·보정 강도·거리 선택을 결과에 맞춰 튜닝하지 않는다.
- 기본 판단은 MAE와 원시기록 대비 대응 MAE 차이, 현재 경주일 군집 부트스트랩 95% 구간(1,000회, seed=20261002)이다. 전체·연도별·거리별·직전 함수율별을 저장한다. 거리 표본 100출전·20경주일 미만은 근거 부족, 조건별 계수 학습 20일 미만은 낮은 지원으로 표시한다. 다중 비교 보정은 하지 않으며 하위집단은 탐색 결과다.
- 원천/계획/기존 잔차 파일 SHA256 보존, 말·경주 키 유일성, 직전 시간 및 거리 일치, 이전 날짜, 환경 학습연도 < 과거 경주연도, 기대시간 학습연도 < 평가연도, 모델 입력 허용목록 및 유한값을 검증한다.
- 전체 결과와 실패·악화도 보고한다. 운영 모델 승격·DB 발행·원시기록 덮어쓰기는 수행하지 않는다.
