# 함수율 구간기록 보정 검증

2026년 10월 2일. 출발200m·마지막200m·마지막600m의 구간별 함수율 환산값과 보정률을 검증했다. 주로빠르기는 사용하지 않는다. 전체시간 보정 결정과 운영 모델은 변경하지 않았다.

구간별 환경 차이를 추정해 건조 기준 기록으로 환산하는 것은 가능하다. 다만 다음 출전 시간 예측의 개선 폭은 대부분 0.001초 미만이고, 부산 막판 구간의 개선은 뚜렷하지 않다. 아래 보정률은 연구 후보이며 이번 결과만으로 구간 보정을 확정 채택하지 않는다.

## 구간과 계산 방법

S1F 출발200m, 결승선 직전 마지막200m, 결승선 직전 마지막600m를 별도 목표로 사용했다. 마지막200/600은 실제 구간 소요시간이며 누적 G1F/G3F와 구분한다. 마지막200m는 마지막600m에 포함되므로 두 보정값을 전체시간에 함께 더하지 않는다.

말별 극단 잔차 제외(horse_mad4)의 거리별 함수율 효과를 사용했다. 동일한 적격 과거 기록의 이전1·2회 시간 피처를 환산한 뒤 Ridge20을 재학습했다. 현재 정답은 추가로 절단하지 않았다. 과거 환경계수도 해당 경주 이전 연도로 학습했다.

0~300% 보정률을10% 간격으로 비교했다. 2024년 적용률은2022~2023 검증으로, 2025년은2022~2024로, 2026년은2022~2025로 선택했다. 경기장과 구간마다 선택했고 거리별·등급별 보정률은 별도로 최적화하지 않았다.

## 현재 판단과 남은 검증

부산 출발200m가 우선 검토할 후보이며 서울 구간도 별도 후보로 보존한다. 부산 막판200·600m는 예측용 보정 채택을 보류하는 것이 적절하다. 전체시간처럼 구간별 정책을 자동 확정하지 않는다. 사람이 과거 구간 기록을 비교할 때 사용할 환경 환산값과 다음 경주 예측 성능 개선은 서로 다른 판단이다.

2024~2026년은 이미 관찰한 후향 기간이다. 새 미래 표본의 결과가 아니며 순위·입상·수익 개선을 주장하지 않는다. 이 실험은 구간별 목표를 독립적으로 예측했으므로 세 보정 피처를 전체시간·입상 모델에 함께 넣는 효과는 따로 검증해야 한다.

누적 중간 기록 전체 또는 겹치지 않는 나머지400m 등은 이번 실험의 대상이 아니다. 그 구간을 추가하면 의미·산출 방법을 고정하고 별도 환경계수와 예측 성능을 검증한다.
