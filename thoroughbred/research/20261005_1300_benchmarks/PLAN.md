# 1300m 기준 연구 범위와 실행 계약

2026-10-05 사용자 요청: 서울·부산1300m의 등급·주로상태별 기록 기준을 만든다. 기존 세션 정책에 따라 전체/구간·상하위/착순·관측/추정·표본·시점 검증을 같이 보존한다. 영천·제주와 주로빠르기는 제외한다.

1. 검증된1300m 원천과 과거 이력 원장을 연결하고 DB는읽기 전용으로 사용한다. 완료된 이전 연구를 덮어쓰지 않는다.
2. 거리를200+500+400+200m로 정의하고 원API를 대조한다. 결측/넓은 물리 범위 제외 원장을 남기며 정상 꼬리를 비율 절사하지 않는다.
3. 국산·혼합 원천등급을 유지한다. 최근 같은등급 기준이 있을 때만 미관측 주로상태를 추정한다. 등급 자체가 없는 조합은null로 남긴다.
4. 2021~2023으로 주로효과 완화 강도를 선택하고2024~2026은각 연도 이전 학습/직전3년 기준으로 평가한다. 숨긴 셀 복원 검증과200회 날짜 재표집을 수행한다.
5. 평균·중앙·P10/P20/P80/P90·꼬리 평균, 실제 착순 집단과 전체시간별 집단의 구간 평균, 같은등급/전체등급 기록점수를 보존한다.
6. 중앙 결론과 게시용 Markdown/JSON을 갱신하고 모든 보관 산출물 용량을 보고한다. 실제 웹사이트/운영 모델 반영은별도 작업이다.

표본 확인 결과 서울/부산 최근각4등급만 참조가 있었다. 부산 국4는한 경주10두로 잠정치·재표집 신뢰구간 부재를 표시한다. 전체100조합 중40조합260구간행을 추정하고60조합은최근 등급 참조가 없다고 구분한다. 이것은요청한 모든 등급×상태 조합의 가용성을 기록한 것이다.
