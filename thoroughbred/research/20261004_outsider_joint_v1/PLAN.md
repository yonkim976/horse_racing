# 후순위 입상마와 동반입상 관계 — 고정 실험계획

2026-10-04 사용자 승인. 운영/원천/완료 연구를 변경하지 않고 기존 더러브렛 자료만 사용한다. 심판기록과 웹 자료를 추가하지 않는다. 2010–2016 warm-up, 정답 학습2017+, 이력T−2를 부모 데이터에서 유지한다.

## 후보와 목적

- context: 완료된 단계별1/2/3착 연구 기준선. 저장 가중치와 외부 예측을 재사용한다.
- direct: 같은243개 입력으로3착 이내 여부를 직접 학습. 말별 로짓 합으로 모든 삼복 조합을 정규화하고 삼복NLL로 온도를 보정한다.
- upside: direct + 사전에 정의한 기록 최고/최근 차이, 편성 대비 최고기록·막판·주행심사 순위, 이력 부족과 기록 변화/거리 변경·앞선 압력의 상호작용. 실제 후순위 입상 여부나 이번 통과착순은 입력하지 않는다.
- upside_joint: upside의 말 점수는 고정하고 조합 내 각질·초반 경쟁·게이트·막판 강점·기록 상승 여지·이력 부족의 쌍 상호작용을 삼복 전체 공동분포의 잔차로 학습한다. 단순 설명용 전개 시나리오 분류와 달리 선택3두 간 비가산 관계를 학습한다. 실제 전체 주행경로 또는 선행 붕괴 사건을 직접 예측했다고 부르지 않는다.

서울·부산/2024·2025·2026 연도별 독립 번들. 연도Y:2017..Y−3 초기 학습/Y−2 조기종료, ~Y−2 재학습, Y−1 삼복 보정/잔차 학습, Y 외부 평가. 카테고리 사전은 초기 학습에 한정한다. 이 조합 잔차의 고정 L2=50/보정 경주 수, 계수±1 제한, 온도0.35~4, 최대300회 L-BFGS-B. 후보를 결과에 맞춰 추가하거나 변경하지 않는다. 단계별 기준선의 순서 조건부확률을 새 삼복 분포 안에 재사용하여 합계1/2/3을 만족하는 말별 우승/Top2/Top3도 계산한다. 우승 확률 개선은 주목표가 아니다.

## 고정 평가

- 전체 동일4,799경주에서 삼복NLL, 최대6조합 적중, Top3 Brier, 상위5/6/7두의 실제 입상3두 전체 포함률, 기준선 상위5두 밖 실제 입상마의 새 상위5두 편입과 기존 포착 입상마의 탈락을 함께 확인한다.
- 단계적 비교 context→direct / direct→upside / upside→upside_joint와 context→최종 후보. 날짜 묶음bootstrap2,000회, seed20261004. 새로운 독립 미래 테스트가 아니며 반복 연구기간의 구간이다.
- 사전 선택정책: 이전 보정연도의6조합 합계확률 중앙값 이상 경주만 고르는 규칙. 평가기간 적중률을 보고 임계값을 조정하지 않는다. 선택률/조건부 적중/남긴 적중 수, 6조합 확률보정을 보존한다. ROI나 수익 개선으로 해석하지 않는다.
- 기존 연구와 운영 가중치의 공통 경주도 비교하지만 입력 시점/훈련시대 차이를 명시한다. 실전 운영 승격 근거로 단독 사용하지 않는다.
- 방향 유지 기준: 지역별 삼복NLL와6조합의 공동 개선, 연도 일관성, 포착/탈락 균형. 애매하면 연구 후보로만 보존하며 운영은 유지한다.
