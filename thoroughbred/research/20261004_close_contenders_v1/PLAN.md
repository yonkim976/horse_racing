# 비슷한 우승 확률 편성 진단

사용자 질문에 따라 같은 경주의 가까운 후보에 우승마/입상 3두가 포함되는지 진단한다. 학습, 확률 재보정, 운영 승격, DB 쓰기는 하지 않는다.

- 연구: 저장된 context/records 외부 예측, 2024–2026. 운영: 등록부가 지시하는 정확한 A/BC/WIN 가중치, 기존 재구성 피처로 2026년~9월13일 재추론. 과거 연도별 다른 가중치를 현재 운영 버전으로 부르지 않는다.
- 운영 전체 학습/보정 사용일은 2025년 이하인지 확인한다. 2026년 평가도 이미 반복 연구된 과거 자료이며 실전 출마 변경시각/미래 독립 검증이 아니다. 단독 1·2·3착이 각 한 두인 경주를 공통 진단 대상으로 한다. 동착/불완전 정답은 따로 제외 집계한다. 구현 시 여섯 삼복 조합이 존재하는 최소 출발마5두를 적용한다. 이보다 적은 경주의 출발마/정답 완전성은 별도 제한으로 보고한다.
- 가까운 후보: 우승확률 1위와 5%p 이내(3%p도 민감도 집계). 1–2위 차이는 <=2%p / 2–5%p / >5%p. 별도로 우승확률 15–25% 말이 2두 이상인 경주를 집계한다. 결과를 보고 기준을 바꾸지 않는다.
- 우승확률 상위 K의 우승마 포함률, 입상확률 상위 K의 실제 3두 전체 포함률(K=3,4,5,6,7), 가까운 후보 집단의 우승/전체 입상 포함률, 삼복 확률 상위 6조합 적중을 분리한다.
- 삼복 6조합 실패를 입상확률 상위5두 밖 말 존재 / 상위5두 안의 3두인데 조합 누락으로 분해한다. 이 분해는 진단 기준이며 두 모델의 선택 순위가 달라 후보 밖에 있어도 적중할 수 있다.
- 운영 삼복은 BC의 B 온도로 계산하고 말별 표시확률은 A 분포에서 계산한다. 둘을 한 공동 분포로 간주하지 않는다.
- 지역/연도와 출전두수를 함께 보존한다. 차이가 조합 관계 때문이라는 인과 확정이나 ROI 개선을 주장하지 않는다.

원천/등록부/기존 예측은 해시로 묶어 변경 여부를 확인하며 출력은 새 디렉터리에만 기록한다.
