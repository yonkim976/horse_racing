## 여섯 구간의 정확한 분할

부산1200m의 공식 명목 계측거리에 따른200m 구간이다. 개별 말의 실제 외측 이동거리나 장비 측량 좌표라는 뜻은 아니다. [마사회 거리별 측정거리표](https://race.kra.co.kr/raceScore/cornerRecordDesc.do).

| 구간 | 누적시간 차 | 길이 |
| --- | --- | --- |
| 0–200m | S1F | 200m |
| 200–400m | G4F−S1F | 200m |
| 400–600m | G3F−G4F | 200m |
| 600–800m | G2F−G3F | 200m |
| 800–1000m | G1F−G2F | 200m |
| 1000–1200m | 완주−G1F | 200m |

여기서 G계측값은 출발부터 해당 지점까지의 **누적시간**이다. 마지막600m·마지막200m 소요시간과 혼동하지 않는다. 여섯 구간의 합은 완주시간과 같다. 마지막600m는 뒤 세 구간, 마지막400m는 뒤 두 구간의 합으로 별도 요약할 수 있으나 겹친 점수를 중복 합산하지 않는다.

## 요청한100 기준과 부호

구간초t·완주초T일 때 `환산시간E=6t`, `지수I=100×T/E`, `차이Δ=I−100`이다. I는 구간 평균속도/자기 전체 평균속도×100과 같다. 빠르면100 위·차이 양수,느리면100 아래·차이 음수다.100은 본인 같은 경주의 평균이지 편성 평균·능력 점수·최적 페이스·우승확률이 아니다. E는 해당200m 속도를 유지한다고 놓은 단순 환산으로 실제 예상 완주시간이 아니다.

가상 완주72초에서 구간11초는E66초/I109.09/Δ+9.09,12초는E72초/I100/Δ0,13초는E78초/I92.31/Δ−7.69다. 지수의 산술평균을100으로 강제하지 않는다. 완전 분할에서는 `Σ(100/I)=6`이 성립한다.

제주의 기존 거리별 상대기록 연구는 과거 같은 구간의 기준초−실제초를 사용한다. 이번 자기 완주100 지수와 다른 정의다. 같은 속도 배분 취지를 따르되 제주 모델의 초 잔차나1110m의210m 예외를 부산으로 옮기지 않았다. 기존 더러브렛 연구의 상대속도 정의와는 같은 속도비다.

## 말 평가와 각질 형태를 찾는 방식

1. 실제 구간초·완주초와 편성 내 구간기록 순위로 이번 수행 수준을 본다. 등급·함수율별 순수 능력 보정 점수를 이번에 새로 만들지는 않았다.
2. 자기 완주100 곡선으로 속도 배분을 본다. 구간별 공통 가속 모양을 구분하기 위해 같은 경주 완전 정상 완주마의 구간 지수 중앙값 대비 차이도 별도로 보존했다. 이는 사후 편성 비교이며 최적 페이스 잔차가 아니다.
3. 초반 차이와 뒤 두200m의 평균 차이가 중앙값 이상/미만인지로4가지 배분 형태를 기술 분류했다. 이 규칙은 새 학습 모델이 아니고 실제 선행·추입 판정을 대신하지 않는다.
4. S1F 통과순위와 상대 위치, G2F→결승 순위 개선을 함께 본다. 선행은 관측1위,앞선·중단·후미는 정상완주마에서 관측된 최대 S1F순위를 기준으로 나눈 구간이다. 비완주를 포함한 실제 전체 출발두수를 확인한 분류와 구분한다.
5. 해당 말의 경주일보다 이전인 동일1200m 정상 출전 최근5개 슬롯에서 지수·구간초 평균과 구간별 유효n을 제공한다. 결측 슬롯을 더 오래된 출전으로 보충하지 않는다. 경력이 없으면NULL/n0이다.

최근5,660건의4형태는 초반↑·종반↑638건,초반↑·종반↓2,323건,초반↓·종반↑2,225건,초반↓·종반↓474건이다. 네 형태별 마지막400m 순위 개선 평균은 각각+0.70/−2.25/+2.27/−0.48위다. 이들은 현재 완주시간과 결과를 함께 사용한 사후 기술값이므로 예측 효용·인과 효과로 해석하지 않는다.

초반 지수와 앞선 상대위치의Spearman 상관은0.572,뒤 두 구간 지수 평균과G2F→최종 순위 개선은0.668이다. 완주시간·착순이 서로 관련되어 있고 경주 내 관측도 독립이 아니므로 별도 유의성·전향 예측 검증으로 표현하지 않는다.

같은 말의 직전 완전1200m 기록과 최근 대상의4형태가 같은 비율은4,556쌍 중48.40%다. 이 반복성 점검은 결측 출전을 건너뛴 인접 완전 출전쌍이며,최근5 피처의 슬롯 규칙과 다르다. 거친 사후 분류의 반복성일 뿐 ‘각질 예측 정확도48.4%’가 아니다. 편성·컨디션·기수·주로·출전간격을 통제한 고정 특성도 아니다.

독립 코드로 여섯 분할·합계(최대 오차0초),다른 속도식에 의한 지수·부호,최근5 슬롯207,978개 구간의평균/n,이전날짜 제한,83개 예시의원문498셀(오차0)을 대조했다. 여섯 구간이 불완전한3건을 보존하고 유효한 구간만 계산한다. 시간 순서 검사를 통과한 나머지 모든 원값이 실측 정확성까지 보증된다는 뜻은 아니다.

원천DB·모델 등록부·제주 자료 해시를 보존했다. 제주DB 접근·새 학습·운영모델 변경·기존 웹 수정·배포 없음. 현재 완주·구간값은 그 경주를 사전에 예측하는 입력으로 사용할 수 없다. 과거 프로필도 원천 공개시각이 입증된 실시간 당시 가용성 검증은 아니다.
