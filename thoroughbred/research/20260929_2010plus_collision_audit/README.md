# 더러브렛 2010년 이후 경주 충돌 사전 감사

점검일: 2026-09-29. 범위는 서울(`meet=1`), 부산경남(`meet=3`), 영천(`meet=4`)의 2010-01-01~2026-09-20 경주다. 2010~2016년은 이력 계산용, 2017년 이후는 연구·모델 평가 대상이다. 제주(`meet=2`)는 제외했다. 이 문서는 **새 DB 적재 결과가 아니라 원천 간 사전 대조**다.

## 재현 방법과 비교 기준

`audit.py`는 운영 SQLite `data/horse_racing.sqlite3`, 역사 통합본 `data/research/thoroughbred_unified_20260918/thoroughbred_unified.duckdb`, 기존 연구 v1 `thoroughbred/data/dataset_20260929_v1/thoroughbred.duckdb`를 읽기 전용으로 열고 `audit.json`을 만든다.

```bash
.venv/bin/python thoroughbred/research/20260929_2010plus_collision_audit/audit.py
```

경주 키는 `(경마장 코드, 경주일, 경주번호)`, 출전 키는 여기에 `마번`을 추가한 값이다. 말 동일성 대조에는 KRA 말 ID를 썼다. 이 수치는 원천의 **행/키 차이**이며 그대로 진짜 시행 경주 수를 뜻하지 않는다.

| 항목 | 운영 SQLite | 역사 통합본 | 기존 연구 v1 |
|---|---:|---:|---:|
| 경주 키 | 29,730 | 29,846 | 29,882 |
| 출전·결과 행 | 327,555 | 331,999 | 미집계 |

운영본과 역사 통합본의 공통 경주 키는 29,694개, 역사 통합본에만 있는 키는 **152개**(2010~2016년 33개, 2017년 이후 119개), 운영본에만 있는 키는 **36개**다. 기존 연구 v1의 경주 키는 두 원천의 합집합과 정확히 같다. 운영본에만 있는 36개는 2026-09-18~20의 서울·부산경남·영천 경주로, 역사 통합본의 오래된 스냅샷 범위 차이다.

## 152개 불일치 키의 판정

- **실제 누락 1개:** 2010-03-12 부산경남 3경주. [KRA 공식 경주 결과](https://race.kra.co.kr/globalEn/resultsRaceDetailBusan.do?rcDate=20100312&rcNo=3)에 5등급 1200m, 완주 10두, 우승마 BARAMKKEOT 1:18.6, 9번마 출전취소가 표시된다. 운영 DB에는 이 경주가 없고 역사 통합본에는 있으나, 통합본의 거리와 등급은 비어 있다. 공식 원문을 근거로 코어 적재 시 복원해야 한다. 2026-09-29 브라우저에서 직접 확인했으며 이 판정은 `audit.py`의 자동 검사는 아니다.
- **강한 중복 후보 56개:** 역사 통합본의 다른 날짜 경주가 운영본의 기존 경주와 **KRA 말 ID 집합 및 모든 말의 마번이 일치**한다. 581개 출전행이다. 이 중 10개는 역사 통합본에서 경마장까지 부산경남으로 바뀌어 있으나, 같은 말·마번이 서울 경주와 일치한다. 별도 시행 경주로 적재하지 않고 각 원천행을 증거와 함께 보류해야 한다. 경주 날짜의 최종 확정은 KRA 결과 원문과 대조한다.
- **그 외 95개:** `void` 88개, `special_only_unresolved` 7개다. 일정이나 취소 이력으로는 보존하되 완료 경주·결과 라벨로 승격하지 않는다. 개별 취소 사유와 실제 시행 여부는 추가 원문 확인 대상이다.

56개 후보의 대표적인 날짜 이동은 `2026-07-06 서울 1~6R → 2026-04-12 서울 1~6R`, `2026-07-07 서울 1~6R → 2026-04-11 서울 1~6R`, `2026-08-24 서울 1~10R → 2026-08-16 서울 1~10R`, `2026-08-26 서울/부산경남 각 1~10R → 2026-08-15 서울 1~10R`, `2026-08-31 서울 1~10R → 2026-08-23 서울 1~10R`이다. 모든 대응 키는 `audit.json`에 있다.

기존 연구 v1에서는 이 중 **15개 경주·169개 출전행이 `is_model_target=true`**다. 따라서 v1을 그대로 학습에 사용했다면 중복 라벨이 들어갈 수 있다. 실제 학습 여부는 별도 파이프라인 확인이 필요하다.

## 휴장·취소와 필드 충돌

[KRA의 2020년 경마 시행계획 변경](https://race.kra.co.kr/down/raceplan_2020.pdf)은 2020-02-23~06-18을 경마 미시행 기간으로 명시한다. 역사 통합본과 연구 v1에 남은 2020-02-23 서울 11개·부산경남 6개, 총 **17개 `void` 키**는 완료 경주가 아니다. 휴장 목록은 [별도 원장](../20260929_closure_inventory_v1/closures.csv)에 두었다. 목록은 아직 모든 연도의 완전한 휴장 달력이 아니므로, 목록에 없다는 이유로 시행을 추정하지 않는다.

공통 경주 29,694개에서 거리 값 차이는 0개, 등급 원문 차이는 17개(2015-02-06/08 부산경남의 `국6`/`국6등급` 등 표기 차이), 상태 의미 충돌은 1개(2025-12-26 부산경남 6R: 운영본 `completed`, 통합본 `special_only_unresolved`)다.

공통 출전행 327,162개에서 KRA 말 ID 충돌은 0개다. 원시 착순 값 차이는 586개이나 대부분 92/94/95 같은 특수 코드와 `NULL`의 차이이므로 일반 착순 충돌로 취급하면 안 된다. **일반 숫자 착순 충돌은 3개**이며 모두 2017-12-17 서울 13R의 4·6·11번마다. 현지 [KRA 결과 원문](../../../data/raw/kra_text/dacom11/meet=1/year=2017/month=12/day=17/20171217dacom11.rpt)에는 각각 8·9·7위로 적혀 운영본과 일치한다. 착순 6위 이후의 재번호 부여로 보이는 통합본 값은 사용하지 않는다.

기록 시간 차이는 15행이다. 2017년 이후 4행은 모두 2023-03-04 서울 8R로, 현지 [KRA 결과 원문](../../../data/raw/kra_text/dacom11/meet=1/year=2023/month=03/day=04/20230304dacom11.rpt)이 운영본의 8번마 1:15.0, 6번마 1:15.1, 4번마 1:16.3, 3번마 1:17.3을 뒷받침한다. 나머지 11행은 2015-04-10 부산경남이며 운영본 시간 누락과 통합본의 숫자 값 차이여서 원문 재확인이 남았다. 감사 JSON에는 두 현지 원문의 SHA-256이 기록되어 있다.

## 코어 적재 전 처리

1. 출전이 확정된 2010-03-12 부산경남 3R을 KRA 공식 결과로 복원하고 원천 URL을 남긴다.
2. 56개 날짜·경마장 이동 중복 후보를 미확정 원장에 보존하고 독립 시행 경주 및 모델 라벨에서는 보류한다. 특히 v1의 `is_model_target=true` 169행을 검토한다.
3. 취소·휴장·미확정 일정을 결과 테이블과 구분한다. 2020-02-23의 17개는 KRA 미시행 기간으로 판정한다.
4. 남은 2015년 기록 시간 11행과 2025년 상태 충돌 1개를 원문 대조한 뒤 확정한다.

통합본의 일부 `source_path`는 현재 파일이 없어 추적이 끊긴다. 이 때문에 기존 연구 v1을 정답 DB로 간주하지 않는다.
