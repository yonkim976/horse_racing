# 부산 전 거리 최소 계측구간·세부 각질·다음 경주 기록 평가

2026-10-21. 연구57G. 서울 코너거리 검토와 제주 연구는 보류/별도 유지한다.

## 자료와 표시

고정 코어DB의 부산1000·1200·1300·1400·1500·1600·1800·1900·2000·2200m 정상 완주를 사용한다. 실제 결과 종료2026-09-18, 자료 시작2010년. 미터 길이는 공식 명목 계측거리를 사용하고, 미계측400m를200m씩 추정 분할하지 않는다.1500·1900m는 과거 자료이고2200m는 소표본이다.

경주거리D,구간거리d,구간초t,완주초T일 때 환산초E=tD/d,지수I=100T/E,차이Δ=I−100. 동일 말·동일 출전의 전체 평균속도가100이다. 구간초,길이,지수,편성 내 기록 비교를 분리 보존한다. 원시 기록 분석이며 새 주로 보정이나 운영 입력 채택이 아니다.

## 사후 각질 세분화

초반 위치와 중반·종반 순위 변화를 사용해 선행잔류/선행이탈/선입잔류/선입이탈/중반진출/막판진출/후미정체/중단혼합8종을 사전 고정한다. 선행=초반1위,선입=그 외 관측 위치 상위1/3,잔류=최종 상위1/3. 중반진출은S1F→G3F 상대 위치0.2 이상 개선,막판진출은G2F→결승0.2 이상 개선이며 우선순위는 선행/선입→중반→막판→후미정체→혼합이다. 뒤 구간의 회복/밀림 표식도 별도로 남긴다.

관측 분모는 정상완주마의 통과순위·최종순위 최대값과 정상완주 수 중 큰 값이며 실제 전체 출발마 수의 확정치가 아니다. 결과가 들어간8종은 현재 경주의 사후 설명이다. 고정 성격이나 현재 경주의 사전 예측으로 표현하지 않는다.

## 말 능력 평가의 제한된 시간순 비교

목표는 `1000/D × (같은 경주 정상완주마 완주초 중앙값−해당 말 완주초)`다. 빠르면 양수인 편성 대비 수행 기록이며 순수 잠재능력이나 운영 입상확률이 아니다. 정상완주6두 이상 경주를 평가하며 비완주 위험을 평가하지 못한다.

훈련 정답은2017년부터,2010~2016은 과거 이력을 채우는 warm-up이다.2024/2025/2026각 연도는 이전 연도까지 학습한 새 고정 모델로 평가하고2026은부분연도다. 최근5개 정상출전(전체거리/같은거리)을 엄격히 이전 날짜로 이동한다. 무효 시간 슬롯을 오래된 출전으로 보충하지 않는다. 원천 공개시각이 실제 사전 가용성을 입증한 것은 아니다.

- B0 기본: 현재 거리·등급·성별·나이·부담중량·월,출전간격,직전거리/중량,최근5 전체거리/동일거리의 편성대비 전체기록·초/1000m·착순비율 평균/개수/직전·최고 기록.
- B1 곡선: B0+최근 동일거리 최소구간별 자기100지수 평균/n,전체거리 초반200·종반600/400/200 지수 평균/n.
- B2 구간·위치: B1+동일거리 구간별 편성중앙값 대비 실제초 우위(1000m당초) 평균/n,전체거리 공통 구간 우위,초반 상대위치와 큰4각질 이력.
- B3 세부8종: B2+전체거리 최근5개 출전의8종별 비율/유효n. 세부 분류의 추가 효과는B3−B2로 판단한다.
