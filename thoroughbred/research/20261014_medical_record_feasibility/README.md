# 의료기록과 이후 경주 성적의 분석 가능성

진료일과 공식 말 번호를 이용해 의료기록을 경주 이력에 연결할 수 있다. 다만 현재 자료로 먼저 구할 수 있는 것은 **진료 항목 뒤에 출전 공백이나 성적 변화가 나타나는지**이며, 병의 임상 중증도나 완치 여부는 아니다. 이번에는 자료 연결과 분석 가능 범위를 확인했다. 항목별 성적 효과를 추정한 결과는 아직 없다.

## 확인한 자료

2026년 10월 14일 로컬 연구 코어를 읽기 전용으로 조회했다. 최신 연도별 API16 수집본은 서울 2018년 5월 20일, 영남 2019년 4월 7일부터 2026년 9월 29일까지의 원문 관측 243,411행이다. 이 중 238,344행이 연구 코어의 공식 말 번호와 연결되며 연결되는 말은 총 2,631두다. 동일 내용 반복을 병원·말·지역·날짜·두 진료 문구가 같은 튜플로만 줄이면 226,770개다. 이는 실제 방문 또는 독립 질병 사건 수가 아니다.

| 연결 상태 | 후보 튜플 수 |
|---|---:|
| 해당 날짜보다 앞선 정상 착순 경주 있음 | 173,018 |
| 해당 날짜보다 뒤의 정상 착순 경주 있음 | 207,165 |
| 앞뒤 경주 모두 있음 | 159,547 |
| 이후 경주가 현재 스냅샷에서 확인되지 않음 | 19,605 |

경주 연결은 공식 말 번호로 하며, 동일 진료일의 경주는 앞뒤 모두에서 제외했다. 정상 착순과 시행 근거가 확인된 결과를 사용했다. 경주 자료 종료는 서울 2026년 9월 20일, 부산 9월 18일, 별도 영천 코드 9월 20일이다. 따라서 진료자료 종료일과 다르다. 이후 경주가 없는 경우에는 추적 종료, 데뷔 전 진료, 은퇴·이적 등도 섞일 수 있어 질병으로 인한 미복귀로 해석하지 않는다. 앞뒤 경주가 있어도 기록 품질·조건 비교와 진료 사건 정리를 마치기 전에는 효과 추정 표본으로 확정하지 않는다.

## 과거 자료 범위의 제약

현재 API16에서 공식 번호로 연결되는 2019년 진료 말은 서울 3두·영남 3두인 반면, 같은 해 경주 결과의 고유 출전마는 서울 2,339두·영남 1,485두다. 두 모집단은 같지 않으며 이를 진료율로 계산할 수 없다. 오래된 행이 존재한다는 사실만으로 당시 전체 말의 의료 이력이 확보됐다고 볼 수 없다. 현재 API의 2025년 연결 말은 서울 1,196두·영남 823두로 늘지만 이 또한 진료 누락이 없다는 증거는 아니다. 과거 말의 제외 또는 수집 범위 선택 여부는 별도 확인 대상이다.

공식 주간 Text 자료는 2010년부터 1,619,071행이 있지만 공식 말 번호가 없다. 이름만으로 코어에 연결하지 않는다. 보존된 API 과거 수집본 238,591행도 최신 수집본과 겹치므로 단순 합산할 수 없다. 초기 분석은 공식 번호가 연결되는 최근 자료의 관측 집단으로 범위를 한정하고, 전체 과거 경주마로 일반화하지 않는다. 장기 미복귀 위험을 추정하려면 은퇴한 말까지 포함한 진료 모집단의 누락 여부부터 검증해야 한다.

## 항목과 이후 영향을 나누는 방법

용어 단계에서는 질환·손상·증상, 처치·검사, 예방, 행정, 뜻이 불충분한 문구를 구분한다. 예를 들어 피로회복 처치와 예방접종을 질병 발생으로 세지 않으며, 파행 문구를 특정 원인 질환으로 바꾸지 않는다. 기존 용어 검토는 뜻과 분류 후보를 정리한 작업이며 이후 성적 효과의 검증은 아니다. 2026년 10월 2일 수정된 Text 파서와 문구별 검토 상태를 우선 사용하고 이전 분리 규칙을 무조건 재사용하지 않는다.

성적 단계에서는 다음 결과를 따로 평가한다.

| 질문 | 지표와 해석 |
|---|---|
| 출전이 늦어지는가 | 진료 뒤 30·60·90·180일 내 출전 여부와 출전까지 기간. 관찰 종료·은퇴·이적을 구분 |
| 복귀 첫 경주에서 덜 뛰는가 | 과거 능력과 직전 상태에 비해 입상률·출전두수 대비 착순·조건을 맞춘 기록이 달라지는지 |
| 변화가 이어지는가 | 복귀 후 두 번째·세 번째 경주에서 변화가 남는지. 재진료·중복 사건은 별도 처리 |
| 반복 기록이 다른가 | 같은 항목·부위의 반복 여부, 진료 기간, 다른 항목 동반 여부별 비교 |
| 경주 직전 시점이 다른가 | 마지막 진료 후 1~7·8~14·15~28·29~60·61~90일 등 사전 지정 구간별 비교 |

연속된 진료일을 각각 새 질병으로 세면 치료가 긴 말이 과대표집된다. 동일 항목·부위의 진료를 사건으로 묶는 기준을 정하고 다른 간격 기준에서도 결론이 유지되는지 확인한다. 세 경주를 모두 뛴 말만으로 첫 경주 효과를 평가하지 않는다. 각 추적 단계의 분모와 탈락 이유를 따로 제시한다.

말의 과거 능력·직전 성적과 기록·연령·지역·거리·등급·편성·함수율·부담중량·게이트 및 기수·마방 배경을 고려한다. 진료 이후의 출전 간격은 출전 지연 자체를 평가할 때 보정으로 제거하지 않는다. 복귀 성적에서는 간격을 포함한 조건부 비교와 제외한 비교를 구분한다. 진료가 없는 행은 건강한 말이 아니라 **해당 자료에 진료가 관측되지 않은 말**이다. 말별 반복과 여러 질환의 동시 발생, 여러 항목을 시험하는 다중비교를 고려하고 연도별·최근 기간에서 재확인한다.

최종 표는 임상적인 경증·중증 대신 **출전 지연 연관, 복귀 첫 경주 저하 연관, 이후에도 저하 연관, 뚜렷한 변화 미확인, 표본 부족**을 구분한다. 신뢰구간이 넓어 차이를 못 찾은 항목을 영향이 작다고 결론 내리지 않는다. 영향이 실용적으로 작다는 판단에는 사전에 정한 허용 차이보다 신뢰구간이 충분히 좁아야 한다.

## 읽는 예와 적용 범위

가령 어떤 항목 이후 첫 경주의 보정 기록은 나빠져도 두세 번째 경주에서 회복되는 결과가 나온다면, 단기 성적 변화와 지속 변화를 구분할 수 있다. 이는 설명을 위한 가상 예이며 현재 측정된 결과가 아니다. 동일 항목이라도 반복 횟수와 진료 후 경과일에 따라 신호가 다를 수 있다.

진료의 역사적 최초 공개 시각은 확인되지 않았다. 진료 날짜만으로 당시 출마 전에 볼 수 있었던 정보라고 가정하면 안 된다. 후향적 연관성 연구는 가능하지만 예측 모델에 넣는 효과는 공개 시점과 시간순 검증을 따로 확인해야 한다. 관측되지 않은 훈련 상태·회복 정도 등도 있어 연관성을 질병의 인과효과로 확정하지 않는다.

## 검증과 산출물

`audit.py`를 프로젝트의 `.venv/bin/python`으로 실행하면 `outputs/feasibility.json`을 재생성한다. 관측 합계와 기존 적재 보고서 대조, 튜플 보존, 날짜 선후관계를 확인했다. SQL의 앞뒤 경주 연결을 별도 Python 이분 탐색으로 453,540번 대조해 모두 일치했다. 기존 원천·운영·DB는 수정하지 않았다. 본 문서는 효과 추정 전 자료 점검으로, 독립적인 성적 효과 연구가 완료됐다는 뜻은 아니다.
