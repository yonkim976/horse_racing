# 모델 시험용 게이트 시간 보정 v1

2026-10-08. 사용자가 모델에 넣어 시험할 수치를 요청했다. 새 추정치를 계산하기 전에 공식 채택과 구분되는 적용 규칙을 고정한다. 이전 효과는 이미 알고 있으며 최적량 탐색이나 예측 개선 검증이 아니다. DB·운영 모델·웹사이트 배포는 변경하지 않는다.

## 고정 입력과 범위

같은 경주·같은 말을 통제한 게이트 시간 연구의 전체4MAD를 기본효과, 상태×게이트 교차 연구의 전체4MAD를 상태효과로 사용한다. 최근2024년 이후4MAD에도 같은 규칙을 적용하여 감도표를 만들되 기본표를 대체하지 않는다.151,074출전의 관측 모집단과149,624출전의 이상치 원장을 재사용한다. 영천·풍향·풍속·주로빠르기·실제 마군 내 주행위치 보정은 제외한다.

## 수축 규칙

각 지역×거리×두수 블록×게이트 수준에서 원시 기본 느림 효과e, 상태 효과e_s, 기본 셀 출전수n, 상태 셀 출전수n_s를 가져온다. 번호는 해당 번호의 행수, 그룹은 각 수준 비교 집단 중 최소 행수다. 출전수는 독립 표본 수와 같지 않으며, 통계적 사후확률이 아닌 규칙상 수축에만 쓴다.

기본 원시 반영량 b=0.30×n/(n+100)×e. 상태 원시 반영량 d_s=0.15×n_s/(n_s+100)×(e_s−e). 느린 양수 효과에 대해 적용하는 보정은 음수다.30%/15%/100출전은 잠정 정책값이며 추정된 최적값이나 베이지안 사후 평균이 아니다. 두 추정은 겹치는 자료에서 계산됐으므로 독립 증거로 취급하거나 합성 신뢰구간을 생성하지 않는다. q와100출전을 켜짐/꺼짐 기준으로 쓰지 않는다.

각 실제 출전두수의 원래 게이트 분포에서 b와d_s를 각각 평균0으로 중심화한다. 번호는 동일 가중,3그룹은 실제 두수의 상대 서열3등분 비중으로 가중한다. 이후 벡터 전체에 같은 비율을 곱해 기본 절댓값 최대0.15초·상태 추가 절댓값 최대0.05초로 제한한다. 그러면 평균0과 총 절댓값0.20초 상한을 동시에 유지한다. 표시용 반올림은 계산에 사용하지 않는다.

블록의 전체 번호/그룹 대비가 식별되는 경우에만 기본효과를 반영한다. 기본 모형이 없거나 식별되지 않으면 중립0과 이유를 남긴다. 상태 모형이 없거나 상태 블록의 전체 대비가 식별되지 않으면 상태 추가0으로 두고 기본효과만 유지한다. 미관측 상태에도 임의 상태 효과를 채우지 않는다. 이는0효과의 측정치가 아니라 적용 규칙의 기본값이다. 소표본이지만 식별되면 표본수로 작게 반영한다.

10/12두에서 마번1~N이 모두 존재하면 번호별 표만 사용한다. 다른 경우는 해당 두수 블록의 그룹 표만 사용하며 번호와 그룹을 중복하지 않는다. 실제로 관측된 두수 범위만 표를 만든다. 운영 적용 함수에는 전체 출전마 마번 목록을 전달해야 하며 취소마/경주후 데이터 품질 제외로 목록을 임의 축소하지 않는다.

## 기록 조합과 사용 시점

채택된 전체시간 함수율 보정에 위 게이트 후보를 추가하는 `moisture_gate_v1`과 기존 월 후보까지 더하는 `moisture_month_gate_v1` 두 경로를 예시로 제공한다. 채택 함수율이 미지원이면 총 보정기록은null로 남긴다. 해당 거리의 월 후보표가 없으면 월 추가0에 후보 부재를 표시한다. 전체시간 값을 구간에 복제하지 않는다.

연구 기준의 마지막 관측일은 서울2026-09-20·부산2026-09-18이고 자료 종료일 이후의 공통 기준 시점은2026-09-21이다. 실제 작성일과 이 파일 버전의 최초 사용일은2026-10-08로 구분하고, 적용 함수는 그 이전 as_of를 거부한다. 과거 출전기록을 현재 시점에서 읽는 후향 정규화 원장은 제공하지만 당시 예측용으로 만들었다고 표시하지 않는다. 향후 과거 시점 예측 검증에는 해당 시점 이전 자료만으로 같은 표를 다시 만들어야 한다.

## 검증과 산출물

원시표 연결·수축 산식·부호·평균0·상한·미관측/미식별 fallback·기존 함수율/월 보존·수치 예시·유효시점·입력 해시를 검증한다. 실전모델 성능 테스트는 사용자 지시대로 후속으로 남긴다. 적용 함수·상세 표·현재 시점 후향 원장·문서·게시용 JSON·중앙 결론·용량을 보존한다. 기존 확증적 채택 기준은 삭제하지 않고 이 v1은 그 기준과 구분하는 시험용 후속이다.
