### 서울·부산경남 2020-09-01~2020-10-15 경마중단

- [국회예산정책처 「2021년도 공공기관 예산안 분석Ⅰ【중점】」](https://nabo.go.kr/board/file/down.do?fid=33316361)의 물리 56쪽/인쇄 48쪽은 마사회 제출 자료를 출처로 `경마 중단 조치 (9.1~현재)`를 기록한다. 문서는 2020년 10월 발간됐으며 `현재`는 그 문서 당시이다.
- 종료일 10월 15일은 공지의 명시 날짜가 아니다. 보관한 마사회 결과 API 원문을 직접 확인해 양수 주파시간이 있는 첫 재개일이 두 경주장 모두 **10월 16일**(서울 15경주·부산경남 10경주)임을 확인하고 그 전날로 경계를 정했다.
- 두 경주장 각각 45일, 합계 90개 날짜가 추가됐다. 해당 구간의 계획·시행 경주는 모두 0건이다. 이 판정으로 주행심사 중단을 추정하지 않는다.
- `evidence_kind=official_start_api_resumption_delimited`와 [경계 검토 원장](core_review/closure_boundary_review.csv)에 종료일 판정 방법·원문 해시·공식 종료 공지 미확보를 기록했다.

### 부산경남 2015-03-29 5·6경주: 취소 확정

[마사회 해당 날짜 성적표 목록](https://race.kra.co.kr/raceScore/ScoretableDailyList.do?meet=3&realRcDate=20150329)의 **각 경주 행에 `취소`가 명시**돼 있다. 두 경주 모두 사유는 `경주 진행 장애 (고객들이 4경주 1번마 경주성적 불만으로 출장로 점거)`다.

이전 모바일 결과 화면에는 1~4경주만 있었고 5·6경주 상세 응답에는 대상 내용이 없었다. 이번에는 날짜 목록의 경주 행에서 날짜·경주번호·사유·취소 표기를 함께 확인했다. [HTTP 200 원문과 수집 기록](root_busan_direct/capture_manifest.json)을 보관했다. 두 행은 `race_cancelled`로 바꾸고 원래 API 키·결과·사유와 전체 `no_valid_completed_race` 판정은 보존했다.

현재 116경주의 상태는 경주 취소 51, 공식 일괄 취소 35, 공식 휴장에 따른 미시행 17, 경주 불성립 2, 보도 근거 일괄 취소 11이다. 세부 유형 미확정은 0건이다. 이는 모든 행의 근거가 같은 수준이라는 뜻이 아니다.

## 아직 확보하지 못한 휴장 자료

- **2010~2015년:** 연간 전체 휴장 계획과 변경 공지의 공식 원문을 확보하지 못했다. 월간 공지 게시판·연감·마주협회·정부 자료를 제한적으로 재조사했다.
- **2021년:** 기존 3분기 계획과 연말 근거는 유지했다. 1분기 설 전후 무경주 구간을 포함해 연간 전체 계획·다른 분기의 공식 휴장 날짜는 추가 확정하지 못했다.
- **2020년:** 9월 시작일 공백은 해결했다. 종료 공지는 확보하지 못해 API 재개일로 정한 경계임을 유지한다.
- 기존 연간 계획을 확보한 연도도 모든 변경 공지를 확보했다는 의미는 아니다. 따라서 **휴장 목록의 완전성은 여전히 부분**이다.

2012·2015년 보도에서 찾은 [10개 날짜 후보](core_review/reported_closure_interval_leads.csv)는 별도 검토 표에 저장했다. 2012년 서울 연말·부산경남 여름·부산경남 연말의 3개 구간에는 API 시행 경주가 각각 25·16·20개 있어 실제 휴장 구간으로 반영하지 않았다. 나머지 7개 후보도 무경주라는 이유만으로 공식 휴장으로 확정하지 않았다.

## 적재와 검증

[현재 코어 DB](../../data/core_api_2010_20260929_v1/thoroughbred_core.duckdb)에 휴장 보완, 취소 판정, 경계 원장 2행, 보도 후보 원장 10행을 반영했다. [승인 입력](core_review/approved_inputs.json)은 원천 파일 해시를 고정한다. 이전 v2 산출물과 반영 전 DB 사본을 보존했다.

- 빌더: [현재 manifest](../../data/core_api_2010_20260929_v1/manifest.json)의 검증 60개 통과.
- 주 에이전트: [백업 대조 검증](core_review/root_verification.json) 20개 통과. 경주·말별 결과·심사·엔티티·구간기록의 행 내용 보존, 116개 키와 판정 보존, 변경 대상 2경주, 추가 90개 날짜, 휴장과 시행 충돌 0건, 입력 해시를 검사했다.
- 서브에이전트: [독립 재검증](core_review/validation_independent.json) 17개 통과. 별도로 부산경남 5·6경주의 공식 원문 행도 독립 대조했다.

확정 시행 29,710경주·330,465출전행, 주행심사 6,199회차·61,777참가행, 구간기록 4,380,065행을 유지한다. 이 버전은 최종 동결 전이다.
