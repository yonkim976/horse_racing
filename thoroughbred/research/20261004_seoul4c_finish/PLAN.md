# 서울1200m 4C 이후 기록 연구 계획

2026-10-04. 직전 1200m 기준표를 서울 4C 계측점 이후로 확장한다.

- 기존 정상 경주·물리적 구간 검사를 통과한 2018년 이후 서울1200m 모집단을 유지한다. 최근 기준은 2024년부터 자료 종료일까지다. 주로빠르기는 제외한다.
- 마사회 공식 용어 설명의 결승선 전530m 표기를 사용한다. 계측점 사이 시간과 순위를 분석하며 실제 이동거리, 외측 손실거리, 정확한 가속도는 추정하지 않는다.
- 읽기 전용 core DuckDB의 4C/G1F 누적시간·순위를 원본 API 보관 파일과 대조한다. 전체−4C, G1F−4C, 전체−G1F를 계산한다.
- 등급·함수율 상태별 관측 분포와 연구용 추정 기준을 분리한다. 시간 상·하위20%와 실제 착순 상·하위3두를 구분한다.
- 4C 앞·중간·뒤 순위군, 4C→G1F→결승 순위 변화, 같은 4C 선두에 대한 시간차 회복을 분석한다. 순위군은 내·중·외측 경로가 아니다.
- 이전 연구에서 선택한 Ridge alpha10·등급별 함수율 상호작용 없음 설정을 고정해 새 구간을 적합한다. 2024/25/26년은 각 이전 연도만 학습해 검증한다. 4C 시점 정보를 추가한 마무리 기대시간은 사후 전개 평가용이다.
- 원자료 일치·시간 합·순위 범위·시간 분리 검증을 수행하고 결과를 중앙 결론 폴더에 추가한다. 새 산출물과 수정 파일의 용량을 기록한다. 기존 운영 보정치와 예측 모델은 변경하지 않는다.
