# 다음 개선의 우선순위와 실행 조건

이 문서는 연구58A 이후 제안이다. 아래 추가 학습·전향평가·수집 자동화는 아직 실행하지 않았다. 운영모델 교체 승인이 아니다.

## 1. 학습 상한이 너무 이른지 확인한다

이번 새 Top2_89의 6개 분할 중 5개는 검증 손실이 가장 낮은 반복수가 최대 200회와 같다. 나머지 1개도 198회다. 6개 모두 150회에서 200회로 갈 때 과거 검증연도의 binary log loss가 감소했다. [훈련 진단](outputs/training_diagnostics.csv)은 Y−2 검증 로그만으로 계산했다.

따라서 현재 200회가 충분한 학습 종료점인지 확인할 가치가 있다. ‘더 학습하면 실제 적중률이 오른다’는 증거는 아니다. 다음 실험에서는 같은 89열·손실·seed와 early stopping 25회를 유지하고 최대 반복수만 800으로 사전 고정한다. 모델과 파라미터 선택에는 Y−2만 사용하고, Y−1은 확률 교정에 사용한다. 기존 200회 모형과 비교한다. learning_rate/leaves/minleaf는 함께 바꾸지 않는다.

## 2. 복승에 필요한 조건부 3착을 직접 학습한다

이번 binary Top2는 전체 출발마를 1·2위와 그 외로 구분한 뒤, 후보 3두 안에서 누가 3위인지 고르는 데 사용했다. 이 목표 불일치가 남는다. 조건부 3착 NLL은 22열 대조군보다 89열에서 나아졌지만, 기존 EL89 대비 개선 구간은 0을 포함했다. 추가 학습이 복승 적중을 확실히 높이지 못했다.

다음 독립 대안은 **q_EL(trio)를 고정하고, 실제 상위 3두에 조건부한 3착 선택 softmax NLL을 직접 학습**하는 것이다. 입력은 각 후보의 기존 89개 사전 변수로 고정한다. 가상 trio 안의 상대적인 3착 가능성은 softmax 정규화로 계산하며 새 상대값 피처는 추가하지 않는다. 훈련 시 실제 trio는 조건부 likelihood의 조건이며, 추론 시에는 모든 가상 trio를 열거한다. 정답 3착 여부·현재 경주의 실제 통과순위·실제 구간기록을 피처에 넣으면 안 된다.

동일 경주 3두를 하나의 학습 그룹으로 유지하고, Y−2에서 조건부 NLL 조기 종료, Y−1 온도 교정, Y 평가를 분리한다. q_EL을 고정하면 축·복연은 보존되고 복승만 바뀐다. 기존 binary Top2 head와 직접 조건부 head를 같은 입력으로 비교해야 목표 변경 효과를 구분할 수 있다. 구현에는 custom softmax gradient/Hessian과 그룹 검증이 필요하므로 별도 단위 테스트가 필수다.

## 3. 축 개선은 경주 안의 1순위 선택 목표로 분리한다

축마 평가의 핵심은 ‘선택한 1두가 Top3인가’다. 후보는 경주 그룹을 유지한 ranking loss와 NDCG@1 검증이며, label은 Top3=1/그 외=0으로 둘 수 있다. 명시적인 LambdaRank/XE_NDCG 실험은 현재 감사 범위에서 발견하지 못했다.

다만 ranking score는 확률이 아니다. 새 점수를 공동분포와 이전 연도 교정에 연결하고 말·승식별 Brier와 합계 제약을 다시 검사해야 한다. 축 최적화가 복승·복연을 악화할 수 있으므로 모든 승식의 개선이라고 확대하지 않는다. [LightGBM 공식 objective 문서](https://lightgbm.readthedocs.io/en/latest/Parameters.html)가 구현 계약의 근거이며 성능은 미검증이다.

## 4. 새로운 결과보다 먼저 입력을 봉인한다

보유한 추가 사후 결과 79경주와 서울 10월 17~18일 결과에는 새 후보의 경기 전 입력이 보존되어 있지 않다. 기존 경기 전 아카이브 16경주의 피처는 89/103열 계약과 직접 일치하는 항목이 거리 1열뿐이다. [신규자료 감사](audit_fresh_data.md)에 원천·누락·수집시각을 기록했다.

필요한 산출물은 예측시각, 원출마표 hash, 출전·취소 상태, 현재 부담중량의 공개시각, 과거 결과·구간 원행의 source hash와 최대 시점, feature 코드 hash, 89/103열 feature snapshot, 모델·교정 hash다. 결과는 이후에 결합한다. 누락열을 사후 결과로 채워 과거에 봉인한 입력으로 표시하지 않는다. 증분 수집 자료는 기존 연구 DB에 쓰기 전에 독립 연구 snapshot으로 검증한다.

새로 봉인하는 미사용 경주에서 기간·중단시점·표본계획을 결과 열람 전에 고정하고 한 번 평가한다. 2026년 모형을 그대로 비교하면 학습 분할 변경의 효과가 섞이지 않는다. 현재 16경주만으로 작은 적중 차이를 확정할 수는 없다. 이번 5개 안의 결과를 보고 조건·가중치를 더 바꿔 동일한 4,799경주에서 다시 탐색하지 않는다.

제안한 추가 학습 상한은 한 번에 최대 2계열×6분할=12개 최종 모형(초기+재적합 24호출)이다. 먼저 학습 상한 진단과 직접 조건부 3착을 각각 별도 대조로 설계한다. 축 ranking은 그다음에 검토한다. 새 계획·중단 기준·자료 및 코드 hash를 정한 후 별도 실험으로 수행한다.
