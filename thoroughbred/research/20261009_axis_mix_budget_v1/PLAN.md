# 축 포함·제외 조합의 동시 사용과 예산

2026-10-09 후속 요청. 현재 선택된 더러브랫 연구 기준선 month_gate_weight22의 동결 2024–2026년 4,799경주로 계산한다. 새 학습·선택 변경·운영 변경·DB/제주 접근은 없다. 축은 입상 점수 1위 말이며 우승 확률 1위라고 부르지 않는다.

결과를 읽기 전에 비교를 고정한다. 축 포함 후보는 이전 연구와 같은 상위7두 중 원축 포함 조합을 기존 삼복확률 순으로 정렬한다. 축 제외 후보는 전체 출전마 중 원축 없는 조합을 같은 확률 순으로 정렬한다. 각 k=0..6에 대해 포함 k개+제외 (6−k)개를 모든 경주에 적용한다. 추가로 포함6+제외6(항상12개), 전체 확률 최고6/12개, 이전 연구의 context 고위험 신호 때만 제외6개를 추가(평소6/고위험12개)를 비교한다. 두 집합은 원축 포함 여부로 분리되므로 중복되지 않는다. 전체12개는 동일 예산 대조군이며, 고위험 추가형은 평균 조합 수와 총 조합 수도 보고한다.

적중은 선택 조합 안에 실제 1·2·3착 말의 순서 없는 집합이 존재하는 경주 비율이다. 축 붕괴율, 위헙 신호 정확도, 우승 예측률과 구분한다. 단위조합당 적중수는 예산 비교용으로만 제시하고 수익률로 부르지 않는다. 기존 기간을 재사용한 후향 평가이며 가장 높은 혼합비를 새 정책으로 선택하지 않는다.

원본 해시 보존, 6/12개 예산, 중복 여부, 기존 적중 재현, 전체 조합 별도 구현 재열거, 날짜 군집 2,000회 paired bootstrap 검증 후 보고서·중앙 결론·게시 요약·용량을 저장한다.
