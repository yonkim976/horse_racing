- 모든 DB 조회는 읽기 전용이었다. 운영 DB·외부 서비스·네트워크에는 접근하지 않았다. 서브에이전트는 사용자 지정 GPT-6 Luna xhigh로 검증하고, 주 에이전트가 보고서·원천 명세·해시·검증 범위를 점검했다.
- **현재 활성 코어 파일은 기존 심판리포트·제재 포함 208객체 상태로 그대로 보존했다.** 활성 파일에서도 해당 단계를 제외할지, 검증 대상에서만 제외할지는 사용자 확인 대기다. 이번 결과를 활성 208객체 전체의 검증 결과로 해석하지 않는다.

## 통과조는 어디까지 완료됐나

**원문 적재와 경주·지점 연결은 완료됐다.** 확정 시행29,710경주 모두 한 지점 이상의 통과조 값을 가진다.

- 선택값144,001개: API142,227개·공식 성적표 보완1,774개. 동일 경주·지점 중복, 출처 없는 선택값, 확정 경주와 연결되지 않는 값은0개다.
- 별도 독립 계산한 기대값과 양방향 전량 비교 결과 차이는0개다. 선택한 값이 동일 행의 원천 값 배열에 있는지도 확인했다.
- API 원문29,774경주 키 중 확정 시행29,710개와 취소·불성립 판정64개를 구분했다.
- **API/성적표 차이50지점·39경주**는 양쪽 원문과 차이 표시를 남기고 API를 우선했다.
- 지점 대응 근거가 부족한 **API414칸**은 미대응 원장에 보존했다. 같은 경주의 다른 지점이 연결돼 있어 경주 커버리지와 미대응 칸 수는 구분한다.
- 통과조 표기 원문은 저장했지만, 괄호·쉼표 등을 해석해 말별 그룹으로 변환하는 규칙은 아직 적용하지 않았다. 말별 통과착순과 다른 자료다.
