# 주로 관련 결과를 하나의 기록 보정으로 합치는 방법

2026년 10월 7일. 기존 연구 종합이며 새 독립 연구나 보정률 채택은 아니다.

**출전 기록마다 하나의 종합 보정초를 만들 수 있지만, 현재 연구값을 그대로 합산할 수는 없다.** 현재 채택된 전체시간 보정은 함수율이며 서울 80%·부산 90%의 건조 기준 환산이다. 예를 들어 서울 1200m 불량의 72.00초는 약 73.03초다. 미지원 거리·상태를 0초로 확정하지 않는다.

월별 결과는 초 단위지만 지역·거리·함수율·참조기간이 다르며 현재 보정으로 채택하지 않았다. 게이트와 실제 내외측 연구의 주요 결과는 Top3 차이 %p이므로 초로 직접 변환할 수 없다. 날짜·주말·월, 게이트·실제 위치, 서로 다른 통과 지점의 효과를 독립 항목처럼 더하지 않는다.

후속 후보는 `보정시간 = 원시시간 − 공동모형의 관측 조건과 기준 조건의 시간 차이`다. 함수율·완만한 계절 곡선·출발 게이트를 같은 전체시간 모형에서 추정하고 수축 강도를 과거 자료의 시간순 검증으로 고른다. 목표 기준은 경기장·거리별 건조, 연간 기준 환경, 평균적인 출발 조건이다. 현재 함수율만 보정한 모형을 넘어서는지 같은 평가 표본으로 확인한 뒤 채택한다.

내외측은 같은 마군 안의 상대 위치이며 실제 경로 길이가 아니다. 특히 막판 위치는 남은 힘·추월 등의 결과를 포함하므로 우선 전개 해석으로 보존한다. 위치가 유리해서 빨랐는지 능력이 좋아 유리한 위치에 있었는지를 구분하지 못한 상태에서 능력 기록을 자동 차감하지 않는다. 사전 예측에는 현재 경주의 실제 위치를 사용할 수 없다.

권장 순서는 **함수율 유지 → 월별 곡선 공동 검증 → 게이트 추가 검증**이다. 실제 내외측을 포함한 후향 설명은 구분한다. 원시시간과 항목별 기여·지원·학습 종료일을 보존하고, 전체시간 보정을 구간기록에 복제하지 않는다. 풍향·풍속·주로빠르기는 제외한다.
