# 서울·부산 personal_t2 운영 승격과 지속 개선

2026-10-25 사용자가 운영 모델 교체와 지속 개선을 명시적으로 요청했다. 서울·부산의 기본 프로필을 `thoroughbred-training-state-20261025-v1`로 전환했다. 대상은 연구58I의 `personal_t2_2026` 가중치이며 새로 학습하거나 다른 후보를 대신 선택하지 않았다. 이전 운영 프로필과 제주 모델은 내용 그대로 보존했다.

승격 판단의 비교 근거는 연구58K의 동일 1,258경주 축 800→830건(63.59→65.98%, +2.38%p, 경주일 재표집 95%구간 +0.07~+4.77%p)이다. 전체 삼복6조합 384→408건, 부산 삼복6조합 145→166건이었으나 부산 복연3조합은 314→299건으로 감소했다. 조교 없는 연구모델 817건과의 차이는 13건으로, 조교 추가분의 구간은 0을 포함한다. 사용자 선택으로 승격했으며 독립 미래검증이나 역사적 조교 공개시각 검증을 통과한 것으로 바꾸지 않았다.

운영용으로 서울/부산 2개 모델과 136개 입력의 수학, 확률 보정, 한국어 기여 설명, 결과 없는 전체 출마표 계약을 동결했다. 한 개의 3두 집합 분포와 집합 내 순서 분포로 A/B/C를 일관되게 계산한다. 과거 결과·조교는 T−2까지 사용하며, 현재 경주의 결과/배당을 요구하지 않는다. 취소마를 제외하면 편성 상대 입력을 다시 조립한다. 새 실행 경로는 `scripts/predict_thoroughbred_main.py`이며 이전 가중치를 직접 읽는 기존 빌더는 새 프로필에서 명시적으로 거부한다.

기술 검증은 결과 없는 40경주·432두의 58,752개 입력값 재조립 최대오차 2.84e−14, 연구의 1,288경주·13,638두 확률 40,914개 재현 오차 0, 축 선택 전체와 복승/복연 7,728조합 일치다. 모든 출전마 확률 합·순위·6개 부호 설명과 SHAP 합을 확인했다. 등록부 전환 후 resolver, 기본 경로의 40경주 시험 실행, 관련 pytest 10개가 통과했다. 이 검증은 새로운 미래 성능 검증이 아니다.
