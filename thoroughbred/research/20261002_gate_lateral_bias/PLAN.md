# 게이트와 상대 내외측 주행위치 유불리

- 기존 API 코어 출전 스냅샷과 이전 날짜까지 최근5회 성적·초반순위 이력을 재사용한다. 2018년부터2026-09-20까지 정상순위1~N이 완결된6두 이상 경주. 취소93/94/95는 출전마에서 제외하고 동착·사고·불완전 순위 경주는 제외한다.
- 숫자 함수율과 원천 기록의 충돌82경주를 제외한 quality_filtered를 주 분석으로 한다. 주로 상태는 숫자 함수율의 건조1~5·양호6~9·다습10~14·포화15~19·불량20이상이다.
- 게이트는 등록 마번의 대용값이다. 취소 후 실제 출발대 이동이나 독립적인 물리 출발대 좌표를 확인한 것이 아니다. 출전 마번순 상대 위치를 내측·중간·외측3등분한다. 빈 번호를 임의 출전마로 만들지 않는다.
- 주 목표Top3. 원시 우승·Top3율도 보존한다. 경주 고정효과·경주당 총가중치1·경주일 군집95% 구간으로 외측−내측 차이를 %p로 추정한다. 현재 레이팅·나이·부담중량, 이전 날짜 최근5회 상대착순·Top3·초반위치, 경험·간격을 조정한다. 게이트를 설명할 때 gate_pct는 통제항에서 제외한다. 현재 실제 초반위치·최종배당은 주 분석 통제에 넣지 않는다.
- 전체·정확한 거리·거리×함수율 및2024년 이후를 비교한다. 최소50경주·20경주일을 지원 기준으로 하고 전체기간 거리별 외측−내측 대비에 BH q값을 부여한다. 모든 개별 구간을 동시 신뢰구간으로 표현하지 않는다.
- 절대번호별 비교는 출전12두이며 마번집합이 정확히1~12인 경주로 제한한다. 번호1 대비2~12의 능력 조정Top3차이를 전체·거리별로 계산하고 전체기간 거리별 번호 대비를 별도 BH 가족으로 처리한다. 다른 출전두수와13·14번까지 일반화하지 않는다.

- 통과조는 검증된 파서로 해석하고 원문 마번집합과 전체출전마 집합이 일치하는 지점만 사용한다. 같은 마군의 가장 외측과 가장 내측을 짝지어Top3 여부의 차이를 비교한다. 한 경주·지점의 마군 짝 전체에 가중치합1을 부여하고 경주일 군집 오차를 계산한다.
- 주행위치 짝의 레이팅·나이·중량·과거이력 차이 및 출발 마번 상대위치 차이를 조정한 회귀를 추가한다. 같은 마군이므로 지점에서 종방향 위치는 비슷하지만 능력·기수의 진로선택·혼잡·남은힘 등 미관측 요소가 남는다. 원시·조정결과 모두 인과효과가 아니다. 종반G1F 위치는 해당경주 사전예측 피처로 사용할 수 없다.
