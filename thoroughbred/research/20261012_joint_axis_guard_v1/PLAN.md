# G3F·G1F·관측 수·최근 보정기록의 축 변경 확인 기준

2026-10-12. 연구47·48의2024~2026 결과를 이미 보고 정한 후향적 후보다. 이번 결과를 보기 전에 아래 기준을 동결한다. 기존122개 능력 모델을 재학습하는 시험이 아니라, 103개 모델의 기존 축과122개 모델의 제안 축이 다를 때 사용하는 선택 단계다. 이를 새로운 확률 학습으로 표현하지 않는다.

서울·부산 같은4,799경주/50,754출전. 축 후보A=baseline103의1위, B=combined122의1위. A=B면 그대로. 다르면 B가 아래 조건을 통과할 때만 B를 사용하고, 나머지는A를 유지한다. 다른 말들은122순위를 유지하며 선택 축을 맨 앞으로 이동한다. 고정103 대조만103 전체순위를 사용한다.

3. joint_supported: 위조건+keep_fast_n≥2. 결측은 통과시키지 않는다.
4. joint_recent(주후보): 위조건+양쪽최근3전보정기록의유효수profile_count3≥2+ B의moist_last3_record_index_mean≥A의값. 지수는높을수록좋다. 신마·관측부족은자동통과시키거나0으로채우지않는다.
5. recent_only(기여분리대조): 최근기록조건만 적용. 주후보를결과에맞춰교체하지않는다.
