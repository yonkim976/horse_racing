# 기수 교체·상위 기수·조교사 기용 관계

2026-10-12. 결과 조회 전 설계. 서울·부산 전체 실제 출전159,014행을 과거 연결에 사용한다. 주분석2024~2025, 재현 확인2026 자료 종료일까지. 기수·조교사·마주는 출전 당시 원문 ID를 사용하며 이름 변경으로 연결하지 않는다. 운영/DB/기존 연구는 보존한다.

1. 상위 기수: 출전 전년도, 같은 지역 정상 순위 출전100회 이상 기수. 입상률은 그 지역 평균50회 강도로 완화한다. 완화 입상률 상위 ceil(적격 기수 수×20%)를 상위로 분류한다. 동률은 원문 ID 정렬로 고정한다. 직전 기수도 현재 평가연도의 같은 순위표로 판단한다. 현년도·미래 성적 사용 금지. 미지원 기수는 보통 기수로 채우지 않는다. 최소50회 및 상위30%는 민감도.
2. 말별 전체 실제 직전 슬롯을 연결한다. 초출전/ID 미지원/직전 이상 결과를 건너뛰지 않는다. 주분석은 직전2~180일, 같은 지역·같은 조교사, 현재 정상 순위와 양 기수 순위지원. 유지보통/유지상위/보통→상위/상위→상위/상위→보통/보통→보통 6집단. 원시 전체 교체/유지 및 제외 사유도 보존. 730일·동일 마주·직전 정상 결과·50회/30% 기준 민감도.
3. 입상=실제3위 이내, 우승=1위. 착순상대값=(순위−1)/(실제두수−1), 낮을수록 좋음. 직전 대비 상대착순 변화 및 같은 지역·정확 거리·등급인 경우의 원시 전체시간 변화는 기술량이다. 현재시간−현재 경주 공식1위 원문시간을 시간 성과로 사용하고, 정상 구간 품질 모집단만 시간 분석에 포함한다. 초 단위 효과는 거리별로 별도 제시하며 다른 거리로 환산하지 않는다.
4. 가법 선형 회귀: 6집단에서 유지보통 기준. 같은 현재 경주 고정효과+과거5슬롯 상대착순/관측수·직전착순·직전입상·휴양·거리/등급 변화·연령·rating·부담중량·마체중·게이트 통제. 추가로 같은 말 고정효과를 넣어 고정 능력 차이를 완화한다. 현재 실제 전개/현재 착순/배당을 원인 통제에 사용하지 않는다. 같은 경주 고정효과는 지역·거리·주로·편성 공통조건을 흡수한다. 말/날짜/말×날짜 이원군집 중 최대 분산과 t구간, 각 분석군 BH. 결과는 조건부 연관성이며 개인 확률/인과효과가 아니다.
5. 특정 기수: 해당 기수로 교체≥100출전·30말·30경주만 비교표. 현재와 직전 입상률/상대착순, 같은 조건 원시시간 변화. 보조로 같은 기수에게 유지기승 대비 교체의 연관성을 같은 경주+말 고정효과/통제에서 비교(다른 기수 출전도 통제 배경으로 유지). 기수별 다중비교를 보정하고 일부 유리한 이름만 선별하지 않는다.
6. 조교사 관계: 전년도 해당 지역 조교사 기승≥50, 가장 자주 기용한 기수≥20회·점유율≥15%면 선호기수 후보. 교체 후 선호기수/기타의 입상률·통제연관성을 구분한다. 조교사×기수 실제 교체≥50·20말·20경주 조합을 전부 표로 남긴다. 각 조합의 교체 당시 과거 말 성적과 현재 성적을 병기한다. 이는 기용 관계이지 특별 승부의지 표식이 아니다.
7. 원문 식별/순위/시간/중량/마주, 독립 SQL 직전 슬롯, 전년도 순위·선호표, 분모·6집단, 집계·회귀·군집구간·다중비교, 입력 보존·게시 수치·그림·링크·용량을 검증한다. 구체적인 기수/조교사 사례는 실명과 표본 수를 함께 공개한다. 사고·부상·기승정지·당일 기수 가용성·마주 지시/인터뷰 자료가 없어 ‘교체=승부의지’는 직접 검정 불가. 후향 추가 연구이며 미래 예측 성능/수익률/운영 반영은 별도.
