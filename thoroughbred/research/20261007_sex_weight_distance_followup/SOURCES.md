# 체중과 거리별 성과 비교의 출처와 방법

2026-10-07. 원천은 [기존 성별 연구 모집단](../20261007_sex_ability_gap/outputs/population.parquet)이다. 이 파일은 성별·마필 ID·마체중을 경주 결과 원문과 대조한151,074행이며, 상세 원천18파일·선택 원장·원래 출전자 민감도는 [원 연구 출처](../20261007_sex_ability_gap/SOURCES.md)에 있다. 새 API 조회나 DB 변경 없이 읽기 전용으로 재사용했다. 출전 당시 성별·거세 상태이며 최신 상태를 과거에 덮어쓰지 않았다.

[분석 입력4개 SHA256와 종료일](outputs/source_and_method.json), [시작 전 관련 파일 목록](outputs/baseline_inventory.json), [후속 계획](PLAN.md), [검증 결과](outputs/verification.json)에 근거를 보존한다. 전체 날짜·구간 합·선택·과거 이력의 시간 방향은 원 연구 검증을 계승하고, 이번 계산에서는 입력 해시를 확인했다. 같은 원천을 독립 수집한 자료로 표현하지 않는다.

체중 기본 평균은 각 출전행에 동일 가중이다. 말별 평균 동일 가중은 지역×출전 당시 분류×마필로 평균을 낸 뒤 집계한다. 마체중 유효 관측151,074개이며 부담중량과 구분한다. 정확 거리·연도·월·나이·함수율 숫자·등급을 맞춘 공통층의 체중 차이도 별도다. 평균 부담중량 차이는 공식 감량 규정으로 해석하지 않았다.

거리 상호작용은 지역별로1000~1400m와1600~1800m의 두 성별 지시자 및 거리묶음별 별도 공변량 기울기로 적합했다. 정확 거리와 연도·월·나이·함수율·등급의 결합층 안에서 양쪽 분류가 모두 있어야 비교한다. 조건만/등급 추가/중량·체중 추가/이력 추가의 단계별 겹침이 다르다. 차이의 증감을 통제변수 하나의 인과 설명량으로 해석하지 않는다. 공변량 중앙값 대체와 결측 지시자는 행렬 안에서만 적용한다.

중거리−단거리 효과는 공동모형의 대비벡터(-1,+1)로 직접 계산한다. 두 별도 계수를 독립이라고 가정한 표준오차는 사용하지 않았다. 전체 초와 실제 거리로 나눈1000m당 초를 함께 확인했다. 이 단위는 거리환산 예측모형이나 보정시간이 아니다.

같은 경주는 실제 혼합·원래 출전자 전원 유지·비표준 편성 아님·암말 제한 원문 아님의 조건에서 해당 두 분류가 모두 출전한 경우만 비교한다. 경주 고정효과로 편성·날짜·거리 등 공통조건을 맞추고, 추가 통제는 나이/제곱항과 중량·체중·rating/제곱항·과거 성적·공백 등이다. 선형 확률 모형의 차이를 %p로 표시하며 종합능력·우승확률 예측이 아니다. 탈락·구간 결측 등이 있는 편성 전체를 대표하지 않으며 원래 전체 출전자 민감도는 원 연구를 따른다.

군집은 마필과 지역별 날짜다. 두 군집 공분산은 마필+날짜−마필/날짜 교집합의 score 합으로 계산하고, 이원 또는 각 단독 군집 중 최대 분산을 사용한다. 자유도는 행수−고정효과 층수−층 내 행렬 rank, t 자유도는 min(마필군집,날짜군집)−1이다. 비교 지원은 각 묶음의 양쪽100행·30두·20날짜·20층과 대비 식별이다. 미지원 구간은 null이고0으로 채우지 않는다. 방법 참고는 원 연구에서 확인한 [공식 statsmodels 이원 군집 문서](https://www.statsmodels.org/stable/generated/statsmodels.stats.sandwich_covariance.cov_cluster_2groups.html)이며 이번 수치 구현과 독립 대조는 NumPy/SciPy/pandas다.

세 성별 쌍 모두를 보존했다.2024~2025 완결연도 재분석은 같은 자료의 민감도다. 점별95%구간이고 다중 비교의 동시 보장이나 미래 예측검증이 아니다.1900m 이상은 암말 희소성과 종료일 차이로 일반 우열을 새로 추정하지 않았다. 기존 거리별 기준·함수율 연구 반영률·구간 보정 보류·운영 상태를 변경하지 않았다.
