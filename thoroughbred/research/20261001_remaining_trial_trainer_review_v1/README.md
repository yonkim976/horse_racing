# 미확정 주행심사 조교사 22행 표적 재검토

> 2026-10-01 후속 처리: 심사 조교사 22행은 [말 프로필·결측 원인 검토](../20261001_trial_22_profile_absence_review_v1/README.md) 후 사용자 지시에 따라 조교사 ID·이름의 원인 미상 오류값으로 검토 종료했다. 원문 및 아래 최초 미확정 목록은 보존하고, 현재 코어 조회에는 오류 처리 분류를 표시한다.

2026-10-01. 기존 공식 사건 페이지에 마번 행이 없었던 22개 기록에 대해 저장된 API 원문, RPT, 기타 공식 HTML 캡처에서 사건과 말 ID를 함께 뒷받침하는 조교사 ID 근거가 있는지 표적 재검토했다. **새로 확정된 조교사 ID는 없다.** 원천·검토 원장·운영 DB·연구 DB는 변경하지 않았다.

## 확인 결과

- `20260929_calendar_api_v1/raw/trial_result/`의 저장 API 원문 34개를 대조했다. 시행장, 날짜, 심사차수, 마번, 말 ID를 함께 키로 삼았을 때 22건 각각 정확히 한 원문 레코드가 있으며, 모두 `trNo`와 `trName`이 `-`다. 추가 API 원문 중 같은 사건·말 키를 보완하는 중복 레코드는 없었다.
- 기존 검토의 해시 검증된 공식 심사 페이지는 정확한 사건을 표시하지만 해당 마번의 참가 행이 없다. `20261001_trial_trainer_review_v1/trial_trainer_gap_review.jsonl`의 공식 페이지 경로·해시가 해당 검토 근거다. 페이지 재수집은 하지 않았다.
- 기존 연구 폴더의 공식 HTML 캡처 314개에서 22개 말 ID를 다시 찾았다. 18개 대상행은 다른 캡처에서 해당 ID가 발견되지 않았다. 나머지 네 대상행의 ID는 다른 사건 캡처에만 나타났다.
  - 말 ID `0031896`은 2016-12-24 서울 7경주 공식 성적표 캡처에 나온다. 대상 심사는 2014-07-12 영남 2차 및 2015-10-17·2015-10-31 영남 심사다.
  - 말 ID `0032248`은 2016-04-29 서울 1차 공식 심사 캡처에 나온다. 대상 심사는 2014-12-27 영남 2차다.
  이 네 관측은 사건 키가 달라 해당 과거 심사의 ID 근거로 쓰지 않았다.
- 기존 RPT 검토에서 18행은 같은 날짜·심사차수·마번의 조교사 **이름**을 제공하지만 조교사 ID는 제공하지 않는다. 나머지 네 행은 고유하게 일치하는 로컬 RPT 참가 행이 없다. `trial_trainer_gap_review.jsonl`에서 RPT 경로·해시·행·`rpt_provides_trainer_id=false`를 확인했다. 이름으로 ID를 역추정하지 않았다.

RPT 고유 행이 없는 네 사건은 2013-07-27 영남 4차 2번 해란강자, 2013-10-05 영남 5차 5번 무공훈장, 2014-01-11 영남 1차 1번 금포엔젤, 2014-04-05 영남 2차 4번 코지파크다. 전체 22행의 사건 키와 말 ID는 [기존 미확정 목록](../20261001_role_review_v1/unresolved_trial_trainers_22.csv)에 보존되어 있다.

## 결론 및 후속 조건

22행은 모두 `unresolved_no_exact_official_person_id`로 유지한다. 현재 프로필, 말 이름, 인접 경주나 다른 날짜의 조교사 관계로 빈칸을 채우지 않는다. 추가 보완에는 같은 심사 사건의 말 ID와 조교사 ID를 직접 함께 싣는 별도 공식 원문/API 또는 사건 행이 확인되는 자료가 필요하다. 그 근거를 확보하기 전까지는 현재 원장을 유지한다.
