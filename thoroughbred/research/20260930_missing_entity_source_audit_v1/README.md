# 경주 출전행 조교사·마주 결측 감사

더러브렛 코어 DB의 `confirmed_runners` 330,465행 중 조교사 ID·이름과 마주 ID·이름이 함께 비어 있는 38행을 원문과 재조회 자료로 확인했다. 이 문서는 2026-09-30 기준의 근거와 남은 한계를 기록한다.

## 확인 결과

- 38행 전부에서 저장된 KRA `API4_3/raceResult_3` 원문 항목의 `trNo`, `trName`, `owNo`, `owName` 키 네 개가 **모두 생략**됐다. 각 원본 파일의 SHA-256, 항목 위치, 날짜·경주·말 식별자를 [감사 원장](race_role_gap_audit.jsonl)에 남겼다. DB 정규화 중 누락된 값은 아니다.
- 38행 모두 결과 착순 코드 `95`, 경주시간 `0`, 완주 증거 없음으로 기록된 출전취소 행이다. 다만 같은 코드의 다른 1,992행에는 조교사·마주 ID가 있으므로 **취소라는 사실만으로 네 필드의 생략 원인을 설명할 수 없다.** KRA 내부 등록 또는 API 응답 생성 규칙은 확인하지 못했다.
- KRA `API26_2/entrySheet_2`를 37개 날짜·시행장 조합으로 재조회해 38개의 정확한 날짜·경주번호·마번·말 ID 행을 모두 찾았다. 2026-09-30 재조회 응답에서도 38행의 조교사·마주 ID는 비어 있었다. 요청별 원본 응답과 SHA-256은 `raw_api26_recheck/`와 [재조회 관찰 원장](api26_recheck_observations.json)에 있다.
- 로컬 KRA `dacom11` RPT는 38행 중 21행의 정확한 경주·마번·말 줄을 제공한다. 이 줄에는 조교사·마주 **이름**이 있으나 공식 ID는 없다. 그중 2016-11-06 부산경남 `퍼스트매지컬` 줄의 조교사 자리는 인명이 아닌 `휴양마`다. 나머지 17행의 해당 RPT는 로컬에 없다.
- 2026-08-23 서울 3경주 9번 `스마트워리어` 1행은 취소 전 보관된 공식 `API26_2` 응답 두 사본에서 조교사 `070166`(심승태), 마주 `010801`(박정재)을 정확한 사건 키로 확인했다. 같은 행의 최신 재조회에서는 두 ID가 비어 있다. 나머지 **37행의 공식 ID는 미확정**이다. 보관된 이전 응답이 있는 대상은 9행이며, 그중 ID가 채워진 대상은 이 1행이다.

## DB 적용 원칙

`race_role_gap_audit`에 38행의 증거를 적재한다. `confirmed_runners_entity_reviewed`는 원본 공식 ID 연결 결과에 위 1행의 이전 공식 API 근거 ID를 별도 검토 열로 표시한다. `confirmed_runners`와 `confirmed_runners_entity_linked`의 원문 ID 열은 바꾸지 않는다. RPT 이름만으로 공식 ID를 추정하지 않는다.

재현:

```sh
./.venv/bin/python thoroughbred/research/20260930_missing_entity_source_audit_v1/build_race_role_gap_audit.py
```

재조회 스크립트 `recheck_race_entries.py`는 KRA API 키가 설정된 환경에서 사용한다. 재현에 필요한 재조회 응답은 이미 보관했으며, 오프라인 감사 빌더는 이 보관본을 읽는다.
