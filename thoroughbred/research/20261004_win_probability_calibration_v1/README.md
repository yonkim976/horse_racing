# 표시 우승확률과 실제 우승·입상률

2026-10-04 사용자 요청으로 고정된 과거 예측의 확률 구간을 점검했다. **관련 이력 직접 입력 모델(context)에서 약15%와 약25% 구간의 실제 우승률은15.06%와22.91%로 구분됐다.** 차이+7.85%p의 날짜bootstrap95% 구간은+5.71~+9.98%p였다. 높은 표시 확률이 실제 우승률과 연결되는 신호가 있지만 모든 구간이 표시값과 정확히 일치하지는 않는다.

[계산 전 계획](PLAN.md), [전체 구간](outputs/probability_bins.csv), [연도별](outputs/annual_probability_bins.csv), [15%와25% 차이](outputs/15_vs_25.json), [검증](outputs/verification.json)을 보존한다. 새 학습/보정/운영 변경은 하지 않았다.

## 정의와 표본

- 이전 연결 연구의2024–2026년9월 일부까지 과거 외부 평가 예측을 사용했다. 주 후보context의 서울29,421·부산21,333, 합계50,754출전행·4,799경주. 반복 출전한 같은 말은 여러 출전행으로 포함된다.
- 전체 말(all_runners)과 우승확률1순위만 골랐을 때(win_rank1)를 구분한다.1순위는 우승확률 내림차순, 동률은 마번 오름차순이다. 입상확률 순위가 아니다.
- 표의 구간은 우승확률 기준이다. 입상률은 그 구간의 실제1~3착 비율이며, 별도로 표시한 입상확률을 구간화한 표나 연승 정산 적중률이 아니다.
- 정확히15.000%인 행만 선택하지 않았다. 약15%는12.5~17.5%, 약25%는22.5~27.5%다. 왼쪽 경계 포함/오른쪽 제외, 마지막 구간은1을 포함한다. 나머지도 중심5% 간격으로 고정했다.
- 같은 경주·날짜의 말들이 서로 독립이라는 가정을 피하기 위해 전체 경주일을 묶어2000회 재표집했다. 차이도 같은 날짜 선택으로 계산했다. 소표본은 넓은 구간과 함께 해석한다.

## 해석과 제한

표시 확률은 단순한 순위 점수 대신 실제 사건의 발생 빈도를 추정하려는 값이다.15%라면 비슷한 예측을 받은 출전100건에서 약15건의 우승이 기대되는 식으로 해석한다. 높은 확률의 말을 구분하는 능력과 숫자가 정확한 실제 빈도로 맞는지(확률 보정)는 다른 성질이다. 이번15/25 비교는 구분 능력을 보여주고,25% 구간의 과거 실제 우승은 평균 표시값보다 낮았다.

전체 말의 평균 우승 예측과 실제 우승률은 둘 다9.46%, 입상은 둘 다28.37%지만 경주마다 확률합이1/3이므로 이 전체 평균의 일치만으로 보정이 좋다고 판단하면 안 된다. 고정 구간 우승 ECE는 전체 말0.47%p,1순위1.63%p이며 단위는 출전행 동일가중이다. 이전 연결 연구의 경주 동일가중 Brier와 단위를 섞지 않는다.

그룹 차이는 기술통계이며 말의 확률 표시값을 올리는 조작의 인과 효과가 아니다. 현재 거리·등급·연도·편성 구성에 영향을 받는다. 향후 다른 구간에서도 매번 같은 비율이나10%p 차이를 보장하지 않는다. 상위 구간 입상률도 매 구간 엄격하게 단조 증가하지 않았다.

이미 사용한 과거2024–2026 연구 기간이며 독립 미래 평가가 아니다. 원래 입력의 결과표 기반 편성·기수·게이트 및 사전 공개시각 미검증 한계는 유지한다. 이 분석에서 모델 가중치/온도/DB/운영 등록부를 변경하지 않았다. 보조 context_pace의 같은 표도 CSV에 함께 있다.
