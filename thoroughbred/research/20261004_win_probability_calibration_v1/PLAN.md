# 우승확률 구간별 실제 성적 점검

2026-10-04 사용자가 높은 표시 확률이 실제 우승률 증가와 연결되는지,15%와25%의 차이가 명확한지 확인하도록 요청했다. 새 학습/보정/운영 교체 없이 연결 연구의 고정 과거 예측을 분석한다.

주 후보는 context(관련 이력 직접 입력), context_pace는 보조 비교다. 서울/부산과 두 지역 전체를 구분한다. 전체 말과 우승확률1순위 말만 골랐을 때를 각각 보고한다. 입상은 실제1~3착이며 연승 정산 정의와 구분한다. 확률과 같은 경주 결과를 학습에 다시 사용하는 절차가 아니다.

확률은 연속 값이므로 정확히15%인 행만 선택하지 않는다. 미리 고정한5% 너비의 중심 구간으로 집계한다:0~2.5%,2.5~7.5%,7.5~12.5%,12.5~17.5%(약15%),17.5~22.5%,22.5~27.5%(약25%),…57.5~62.5%,62.5~100%. 왼쪽 포함/오른쪽 제외이며 마지막은1을 포함한다. 표시15/25와 실제 평균 확률을 구분한다. 표본0은 결측으로 남긴다.

각 구간의 말 수·경주 수·경주일 수, 평균 예측우승/입상확률, 실제 우승/입상 건수·비율을 저장한다.95% 불확실성 구간은 경주일 묶음 bootstrap2000회(seed20261004)로 전체 날짜를 함께 재표집하여 같은 경주·날짜의 의존성을 보존한다.15%와25% 구간의 실제 우승률 차이는 같은 bootstrap 날짜 선택으로 계산한다. 차이 구간의0 포함 여부를 보고하되 전체 단조 증가나 매10% 증가의 효과를 보장하지 않는다. 두 구간 모두 관측되는 재표집 비율을 저장한다.

연도별 표, 우승/입상 전체 Brier·평균 예측/실제율·구간 ECE도 남긴다. pooled 차이는 서울/부산 및 연도 구성 차이가 있는 기술통계이며 인과 효과가 아니다. 이미 사용한2024–2026 연구 기간이고 독립 미래/배당 수익 검증은 아니다. 고확률·1순위15% 등 작은 집단의 표본 수와 불확실성을 강조한다.

원래 예측/모델/DB/운영 등록부는 변경하지 않는다. 입력 파일·코드/계획 해시와 재현 결과를 보존하고 별도 집계 검증으로 숫자를 확인한다.
