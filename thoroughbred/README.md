# 더러브렛 예측·연구 작업 폴더

2026-09-28부터 서울·부산 더러브렛의 새 예측·연구는 이 폴더에서 시작한다. 프로젝트 전체의 수집·DB·웹 기능은 상위 `horse_racing`에서 공유한다.

## 연구 목표

[예측 목표](docs/THOROUGHBRED_PREDICTION_OBJECTIVES_2026-09-28.md)를 먼저 읽는다. **축마는 우승 예상마**이며 선행마가 아니다. 말별 우승·Top2·Top3, 정확한 2·3위, 우승축 조건부 동반 후보, 실제 승식별 적중 확률을 구분한다. 추천 5두와 같은 조합 수·비용에서의 성능도 평가한다.

[데이터 분석 우선 계획](docs/THOROUGHBRED_RESTART_PLAN_2026-09-28.md)에 따라 보유 자료의 의미·품질·시점을 확정한 뒤 모델을 비교한다. 새 목표 전체가 현재 모델에 구현·검증된 것은 아니다.

## 합의된 연구 기준

[첫 기준모델 v1](research/20261003_baseline_v1/README.md)은 2010~2016년 warm-up, 2017년 이후 학습 기준으로 서울·부산을 각각 학습했다. 2024~2026년 시간순 후향 검증에서 성적 중심 입력과 완주·구간 기록 추가 입력을 같은 경주로 비교했다. 데이터·분할·가중치·말별 및 조합 확률·검증 결과를 해당 연구 폴더에 보존한다. 운영 등록부를 변경한 결과는 아니다.

[전개 예측 v1](research/20261003_pace_v1/README.md)은 S1F·G3F 통과순위와 출발200m 초반 페이스를 별도 예측한다. 같은 warm-up·학습 기준으로 최근 성향 단순 기준과 편성 모델을 시간순 비교했으며, 입상 모델에 연결한 개선 검증은 다음 단계다. 전체 경로·기수 의도·선행 경합을 확정하는 모델로 해석하지 않는다.

[전개 v2 게이트·함수율 비교](research/20261003_pace_gate_moisture_v2/README.md)는 기존/게이트/전체기록 함수율 보정/둘 다를 같은 경주로 검증했다. 게이트 추가는 서울·부산의 S1F·G3F 평균 위치오차를 줄였지만 부산 통과1위 선택은 불확실했고 일부 거리·연도에서 악화했다. 함수율의 추가 전개 개선은 뚜렷하지 않았다. 게이트 후보를 다음 입상 연결 실험 대상으로 보존하며 삼복승 개선·운영 반영은 아직 완료되지 않았다.

[전개 v3 기수·안정성·경쟁 비교](research/20261003_pace_jockey_v3/README.md)는 기수 성향을 말·게이트·편성 대비 외부 예측 잔차로 만들고 T−2까지 집계했다. 기수 추가는 서울·부산 S1F·G3F 평균 위치오차를 조금 줄였지만 선두 선택 개선은 확인되지 않았고 부산 S1F 선택률은 낮아졌다. 초반 안정성·게이트별 경쟁의 추가 효과는 작거나 불확실했다. 다음 입상 연결에는 기수 추가 후보를 우선 보존하며 최종 착순·삼복승 개선으로 해석하지 않는다.

[남은 전개 오차와 초반200m 기록 진단](research/20261003_pace_error_start_diagnostic/outputs/REPORT.md)은 예상보다3두 이상 뒤로 밀린 말의 기록 둔화와 선두 선택 실패를 구분했다. 최근3전 비교 가능 집단에서0.4초 초과 느림은 큰 후방 오차의 서울61%·부산53%, 선두 선택 실패의 서울20%·부산14%였다. 동일200m 순위와 시간의 사후 연관성이며 발주대 반응 지연의 인과증거나 사전 예측 성능으로 해석하지 않는다.

[전개 v4 주행심사·직접목표·초반부진 위험](research/20261004_pace_objectives_v4/README.md)은 심판기록 없이 보유 자료만 비교했다. 주행심사 추가는 양 지역 S1F·G3F 평균 위치오차와 신마의 큰 오차를 줄였다. 부산 선두 직접학습은 선두 선택을 개선했지만 초반3두 포착은 기존 후보보다 낮아 목표별 후보를 보존한다. 위험 예측은 별도 참고값으로 남기며 무조건 감점하거나 최종 입상·삼복승 개선으로 해석하지 않는다.

[거리·등급별 전개 v4 진단](research/20261004_pace_distance_grade_diagnostic/README.md)은 주행심사 추가의 초반 위치 개선이 주로1300m 이하·6등급에 집중되고 다른 구간에서는 작거나 불확실함을 확인했다. 당시 v4는 거리·등급·거리 증감을 입력했지만 말의 전개 이력은 여러 거리를 섞어 집계했다. 같은 말의 거리별 전개 이력과 거리 변경 문맥은 후속 v5에서 따로 학습해 비교했다.

[전개 v5 이번 거리·편성 학습](research/20261004_pace_context_v5/README.md)은 같은 거리·거리구간의 말 이력과 이번 편성 내 상대 비교, 거리 변경·기수 구간·등급 변화 문맥을 추가해 학습했다. 거리별 이력은 양 지역 S1F·G3F 평균 위치오차를 작게 줄였고 부산 선두 직접 전체 문맥 후보는 선두 선택을 개선했다. 초반3두 포착과 부산 거리 연장 집단의 오차는 일관되게 좋아지지 않아 목표별 후보를 보존한다. 운영 승격은 하지 않았으며 최종 입상·삼복승 연결은 후속 연구에서 비교했다.

[전개→입상 연결 v1](research/20261004_pace_finish_stack_v1/README.md)은 관련 이력을 직접 넣는 후보와 시간순 외부 전개 예측까지 추가하는 후보를 실제 입상 모델에 연결해 비교했다. 이력 직접 입력은 부산 삼복 확률 상위6조합25.91→27.74%와 입상 확률 지표를 개선했다. 서울6조합29.53→29.81%의 개선은 불확실하다. 전개 예측값 자체의 추가는 삼복 개선을 확인하지 못했으며 축 후보1두 적중 개선과 구분한다. 운영 모델은 유지했다.

[우승확률 구간 보정 점검](research/20261004_win_probability_calibration_v1/README.md)은 고정 과거 예측에서 우승확률 약15/25% 구간의 실제 우승15.06/22.91%, 실제 입상42.69/58.88%를 확인했다. 전체 말과 우승확률1순위 선택을 구분하고 지역·연도·표본 수와 날짜bootstrap 구간을 보존했다. 새 보정/학습/운영 변경 없이 확률 표시의 구분 능력과 실제 빈도의 차이를 분석했다.

**[주로·전개·게이트·주행심사 연구 결론 모음](research/conclusions/README.md)**에 이번 후속 연구14개와 전체시간·구간기록 결정 내용을 한 폴더로 모았다. 연구 항목별 결론·현재 채택 상태·거리별 환산표·공동 보정 후보·주행심사 시간 기준점·원 보고서 목록을 여기서 확인한다.

[함수율 기반 주로 보정 결정](docs/TRACK_MOISTURE_CORRECTION_DECISION_2026-10-02.md)에 따라 과거 완주시간의 건조 기준 환산은 서울 추정 효과의 80%, 부산 90%를 연구 기준으로 채택했다. 주로빠르기는 제외하며 거리별 환산표·표본 부족 조건·시간순 적용 방법은 결정 문서를 따른다. 운영 모델 적용은 아직 이루어지지 않았다.

[구간기록 보정 검토 기록](docs/TRACK_MOISTURE_SECTION_CORRECTION_STATUS_2026-10-02.md)에 출발200m·마지막200m·마지막600m의 후보값과 예측용 채택을 보류한 이유를 정리했다. 전체시간 기준은 유지하고 구간별 환산은 연구 후보로 보존한다.

[게이트와 상대 내외측 주행위치 분석](research/20261002_gate_lateral_bias/README.md)에서 서울·부산의 거리별 출발번호 차이와 같은 마군 안의 주행위치 차이를 구분했다. 관찰 차이를 확인한 단계이며 예측확률 가산이나 초 단위 보정으로 채택한 것은 아니다.

[날짜·주말·월별 세부 분석](research/20261003_gate_lateral_time_windows/README.md)은 이전 연도 자료로 만든 거리·함수율·말 능력 기준을 바탕으로 2020~2026년의 기간별 변화를 비교했다. 연간 평균이 가리는 월별 변화와 같은 주말 안의 날짜 차이를 정리했으며, 소표본 날짜·주말의 불확실성도 함께 표시했다.

[내측·중간·외측 세 단계 비교](research/20261003_three_lateral_positions/README.md)에서 게이트와 같은 마군의 주행위치에 중간을 추가했다. 주행위치는 3두 이상 마군의 세 위치를 같은 표본으로 비교했으며, 중간이 항상 내외측 평균이 되는 것은 아님을 확인했다. 전체·최근·거리·날짜·주말·월별 표와 세 대비를 함께 검정한 결과를 보존했다.

[2두 마군을 포함한 게이트·주행위치 공동 보정 연구](research/20261003_joint_gate_lateral_smoothing/README.md)는 2두 마군의 내외측과 3두 이상 마군의 세 위치를 함께 분석하고, 게이트 번호별 조건부 차이와 최근 편차를 완화하는 후보를 시간순 평가했다. 서울 2주·부산 8주 반감기의 최근 게이트 갱신이 연구 후보로 남았으며, 검증한 것은 관측된 마군 내 성적 차이의 설명력이다. 실제 출전마 예측확률의 개선이나 운영 적용을 확정한 결과는 아니다.

## 폴더 사용법

[서울·부산 주행심사 시간 기준점](research/20261003_trial_time_baselines/README.md)에 공식1000m 합격 시간 규정과 최근 신마 합격 전체·구간시간 분포를 보존했다. 전체시간 중앙값 서울64.5초·부산64.2초는 기초 비교 중심값이며, Timeform 방식의 최적 par나 실전 거리별 표준시간을 확정한 것은 아니다.

| 경로 | 용도 |
|---|---|
| `cli.py` | 운영 모델 확인, 보존 카드 재현, 준비된 피처 카드의 읽기 전용 추론 |
| `models/current_A`, `current_BC`, `current_order` | 현행 모델 폴더에 대한 연결. 실제 선택 기준은 운영 등록부 |
| `config/production_registry.json` | 공통 운영 등록부 연결. 더러브렛 도메인만 선택 |
| `data/` | 새 데이터셋·피처 스냅샷. `legacy_unified`는 기존 통합 자료 연결 |
| `research/` | 앞으로 작성할 분석 코드·가설·설정·실험 결과 |
| `predictions/` | 새 추론·재현 결과. 실행마다 새 하위 폴더 사용 |
| `docs/` | 합의된 목표·입력 목록·분석 보고서 연결 |
| `legacy/studies/` | 과거 더러브렛 연구 경로 연결. 재실행용 작업 디렉터리가 아닌 참조 이력 |
| `legacy/audits/` | 기존 입력·전개·정리 감사 연결 |
| `maintenance/` | 이번 정리의 삭제 목록·검증·보존 기록 |

`models/`, `legacy/`, 기존 `docs/` 연결은 복사본이 아닌 상대 심볼릭 링크다. 기존 코드가 `__file__` 위치와 등록 경로를 사용하므로 원본 위치를 유지했다. 이 폴더를 단독으로 복사하면 독립 실행 패키지가 되지 않는다. 프로젝트 전체 또는 링크 대상까지 함께 보관해야 한다. 새 모델이 명시적으로 승격되면 모델 연결도 함께 갱신한다.

## 실행

프로젝트 루트에서 사용할 파이썬은 `.venv/bin/python`이다. 이 폴더에 들어와서는 `../.venv/bin/python cli.py --help`로 명령을 확인한다. 출력 위치와 구체 인자는 CLI 도움말을 따른다.

이 폴더 안에서 실행:

```bash
# 현행 모델·해시 확인
PYTHONDONTWRITEBYTECODE=1 ../.venv/bin/python cli.py status

# 보존된 27경주·294두를 다시 계산해 원래 결과와 비교 (자동으로 새 결과 폴더 생성)
PYTHONDONTWRITEBYTECODE=1 ../.venv/bin/python cli.py replay

# 준비된 완전한 피처 카드로 추론 (입력 경로와 새 실행명을 지정)
PYTHONDONTWRITEBYTECODE=1 ../.venv/bin/python cli.py predict \
  --features data/새_피처_카드.parquet --output predictions/새_실행명
```

과거 결과 열을 포함한 입력은 `--historical-replay`를 명시한다. 영천은 현재 보존 모델의 재현 대상에 포함되지만 성능 검증이 부족하여 일반 추론에는 `--allow-unvalidated-venue`가 필요하다. 제주나 알 수 없는 경마장은 거부한다.

출력은 `A_predictions.parquet`(우승·Top2·Top3·정확한 2/3위·원점수), `B_C_top10_predictions.parquet`(기존 B/C 목표별 상위 조합), `inference_manifest.json`(입력·등록부·모델 해시와 시점 상태)이다. 기존 목표별 보정값을 유지하므로 A와 B/C를 하나의 공통 분포로 섞어 해석하지 않는다. 축마 조건부 추천·추천 5두·다섯 승식 전체 출력은 이후 새 목표 연구에서 구현·평가할 범위다.

예측 입력은 **완전한 출전마 명단과 현행 모델의 모든 필수 피처를 갖춘 Parquet**다. 출마표만 넣어 새 피처를 자동 수집·재계산하는 실전 파이프라인은 아직 검증되어 있지 않다. 준비된 입력의 추론 결과를 사전 시점이 입증된 실전 예측으로 표시하지 않는다. 보존 카드 재현은 기능 검증이며 새로운 예측 성능 평가가 아니다.

DB 발행은 이 CLI의 기능이 아니다. 운영 모델 확인과 파일 생성만 수행한다. 신규 실험의 성능이 좋아 보여도 운영 등록부를 자동 변경하지 않는다.

## 새 연구를 추가하는 규칙

1. `research/YYYYMMDD_주제/`에 `README.md`(질문·시점·평가 기준), 코드, 설정, 결과를 함께 둔다.
2. 입력은 `data/`의 버전별 스냅샷 또는 기존 원천의 읽기 전용 경로로 연결하고, 경로·SHA-256·범위·공개 시점 근거를 기록한다.
3. 기존 원천과 완료 연구를 덮어쓰지 않는다. 이전 `legacy/` 스크립트는 출력이 고정된 경우가 있으므로 새 연구의 실행기로 직접 사용하지 않는다.
4. 서울·부산을 구분해 시간순 평가한다. 이미 관찰한 과거 기간은 독립적인 신규 테스트라고 표현하지 않는다.
5. 운영 DB·제주 데이터와 모델은 공통 프로젝트 자산이다. 더러브렛 실험에서 수정하지 않는다.
6. 새 대용량 데이터·학습 가중치·추론 결과는 Git에 넣지 않고, 재현 코드·설정·요약·입력 해시를 관리한다.
